1. 就經濟本質而言，資產證券化所發揮的最核心功能為下列何者？
  1. (A)由創始機構保證證券本息，使投資人免於進行信用分析的成本
  2. (B)將流動性較差、難以交易的資產，轉換為可在市場流通的證券
  3. (C)提高資產池本身的收益率，使投資人取得高於市場水準的報酬
  4. (D)消除資產池所含的信用風險，使投資人不必承擔任何違約損失
解析

(A)錯誤。真實出售後創始機構原則上不再對證券本息負責，投資人正是要改為分析資產池與交易架構；若創始機構仍全面保證，該交易在性質上比較接近擔保融資。

(B)正確。證券化的本質是「資產的流動化」：把一群現金流量可預測但無法零星買賣的債權集合起來，重新包裝成標準化、可分割、可轉讓的有價證券，使原本只能持有到期的資產得以在資本市場定價與交易。

(C)錯誤。證券化不會提高基礎資產本身的收益率；投資人取得的收益仍來自資產池原有的現金流量，扣除服務費、信託報酬等交易成本後，整體可分配金額反而減少。

(D)錯誤。證券化是「重新分配」而非「消滅」信用風險。資產池的違約損失最終仍由持有各順位證券的投資人（及提供信用增強者）承擔，只是承擔的順序被重新安排。

2. 不動產資產信託中，下列何者為最典型的利益衝突情形？
  1. (A)同一投資人同時持有同一案件的優先順位與次順位受益證券，並參與受益人會議
  2. (B)委託人同時為信託財產的主要承租人或不動產管理機構，其租金與報酬條件可能不公允
  3. (C)受託機構委任其關係企業以外的獨立專業估價者辦理信託財產的定期估價
  4. (D)信託監察人同時受任擔任其他受託機構所發行之多檔證券化案件的信託監察人職務
解析

(A)錯誤。同一投資人跨順位持有反而使其在各層利益一致，參與受益人會議亦為受益人的固有權利，是實務上常見的配置，並非利益衝突。

(B)正確。委託人賣的是自己的資產，若又回頭承租或承接管理業務，租金訂太高可以美化募集時的收益率、管理費訂太高則侵蝕受益人的分配，兩端都由同一人決定。這正是資產信託最需要靠關係人交易揭露與信託監察人監督來防範的結構。

(C)錯誤。委任關係企業以外的外部獨立估價者，正是避免自我評價、強化客觀性的作法，屬於利益衝突的防範措施而非衝突本身。

(D)錯誤。監察人同時受任多案並不當然產生衝突，只要各案之間無對立的利益；實務上專業機構本即會承作多件。

3. REIT 設置信託監察人的主要制度功能是：
  1. (A)負責編製基金的財務報告並對不動產估價報告出具查核意見
  2. (B)受益人分散難以集體行動時，代為監督受託機構並主張權利
  3. (C)代替受託機構決定不動產的取得、處分價格與租金收取水準
  4. (D)對受益證券的市場價格提供最低擔保並於跌破時買回
解析

(A)錯誤。財務報告由受託機構編製、會計師查核，估價則由專業估價者出具，這些簽證責任均不在監察人的職掌範圍。

(B)正確。受益證券持分零散，單一受益人監督的成本往往高於其可得利益，容易產生搭便車問題；信託監察人是制度為此設置的常設監督者，得為受益人的利益採取必要行為，補上治理的空隙。

(C)錯誤。不動產的取得、處分與租金條件屬受託機構的經營判斷，監察人的角色是監督而非代為決策，否則監督者與被監督者將混為一談。

(D)錯誤。市場價格由供需決定，架構中沒有任何參與者為受益證券提供價格下限或負有買回義務，監察人更無此財務能力與職權。

4. 評估證券化交易時特別重視創始機構所提供的歷史違約與回收資料，主要理由為下列何者？
  1. (A)歷史資料是認定資產移轉在法律上是否構成真實出售的主要判準
  2. (B)歷史資料可取代交易文件中對移轉資產的承諾與保證條款
  3. (C)歷史資料是推估資產池未來損失分布與信用增強水準的基礎
  4. (D)歷史資料可用以核算受託機構應收取的信託報酬與服務費率
解析

(A)錯誤。真實出售的認定看的是移轉契約的條款、風險與報酬是否實質移轉、有無過度的買回或追索安排，而非資產過去的違約表現。

(B)錯誤。歷史資料說明的是同類資產過去的表現，承諾與保證則是就本次移轉標的品質所負的契約責任，兩者功能不同，不能互相替代。

(C)正確。分券厚度與信用增強要多少，取決於資產池可能發生多少損失；估計違約率、回收率與其波動，只能仰賴足夠長、且涵蓋景氣循環的歷史表現資料。資料期間過短或未經歷過壓力期間，是評等時常見的疑慮。

(D)錯誤。信託報酬與服務費是依約定的費率與資產池餘額計算的交易成本，與歷史違約資料無關。

5. 提前還款模型在房貸證券評價流程中所扮演的角色是:
  1. (A)取代利率期間結構的設定,使整個評價過程不必再另行建構完整的即期利率曲線
  2. (B)用以推算標的不動產於期末處分時所應適用的資本化率與處分價值
  3. (C)將每條模擬利率路徑轉換為各期提前還款速度,進而決定該路徑上的本息現金流量
  4. (D)決定該檔受益證券在發行時可以向評等機構取得的信用評等等級
解析

(A)錯誤。兩者互補而非替代:利率期間結構決定折現與再融資誘因,提前還款模型決定現金流量,缺一不可。

(B)錯誤。資本化率屬於不動產估價的範疇,與抵押債權的提前還款行為無關。

(C)正確。評價流程是「利率路徑 → 提前還款模型 → 現金流量 → 折現」;提前還款模型正是把利率情境翻譯成現金流量的那一環,通常以再融資誘因、貸齡、季節性與耗損等因子建構。

(D)錯誤。信用評等由評等機構依信用風險與信用增強程度評定,提前還款模型影響的是現金流量的時點而非違約損失。

6. 淨營運收益(NOI)在計算時排除融資利息與折舊費用,其主要理由是:
  1. (A)估價實務規定不動產評價於計算收益時,一律不得認列任何營業費用項目
  2. (B)利息與折舊金額相對於租金收入而言偏小,實務上為簡化計算而予以忽略不計
  3. (C)NOI 旨在衡量不動產本身的營運獲利能力,不應受個別投資人的融資結構與折舊政策影響
  4. (D)利息與折舊費用已內含於空置及呆帳損失的估列金額之中,若再行扣除將會造成同一成本的重複計算
解析

(A)錯誤。NOI 本身就已扣除管理費、保險費、稅捐與修繕等營業費用,並非不認列任何費用。

(B)錯誤。房貸利息與折舊往往是相當大的金額,排除的理由是概念上的歸屬問題,不是重要性太低。

(C)正確。同一棟不動產由高槓桿或全現金投資人持有、採不同折舊年限,利息與折舊會完全不同,但建築物的收租能力並未改變;排除這兩項,NOI 才能在不同持有人之間比較,也才適合搭配資本化率使用。

(D)錯誤。空置與呆帳損失處理的是租金收不到的部分,與融資成本、折舊分屬完全不同的項目,不存在重複計算。

7. 證券化交易於發行後持續提供定期服務報告與資產池表現報告（逾期率、違約率、提前清償率、信用增強餘額等），對次級市場最重要的作用為何？
  1. (A)使潛在買方能重新評估剩餘資產池而報價，降低流動性折價
  2. (B)使受託機構得依報告內容向創始機構請求補足資產池損失
  3. (C)使投資人得於報告公布後要求發行人依面額買回其證券
  4. (D)使該受益證券的評等得以維持發行時的水準而不被調整
解析

(A)正確。受益證券的價值取決於發行後資產池的實際表現。若買方無從得知剩餘資產池的品質與增強餘額，只能以極保守的價格出價或根本不報價，流動性折價即因此擴大。

(B)錯誤。除契約明定的瑕疵資產買回外，創始機構通常不對資產池嗣後的信用損失負補足義務。

(C)錯誤。受益證券原則上沒有依面額回售的權利，投資人退場須透過次級市場或等待依約攤還。

(D)錯誤。持續報告正是評等機構追蹤並「調整」評等的依據，其目的不是把評等凍結在發行時的水準。

8. 循環型資產（如信用卡債權）的證券化常設有加速攤還的觸發事由，例如超額利差轉為負值或違約率超過約定門檻，此一機制的用意為何？
  1. (A)於品質惡化時由創始機構買回全部資產，使交易提前結束
  2. (B)於品質惡化時暫停對投資人的一切分配，至品質回復為止
  3. (C)於品質惡化的早期停止循環購買，優先償還投資人的本金
  4. (D)於品質惡化時提高證券票面利率，以補償投資人的風險
解析

(A)錯誤。除契約另有約定的清理買回外，創始機構並無因資產池品質惡化而買回全部資產的義務。

(B)錯誤。加速攤還是加快而非停止對投資人的分配，暫停分配與其設計目的正好相反。

(C)正確。循環期間內收回的本金原本用於購買新債權，投資人的暴險因此持續延長。觸發條件是預設的早期警訊，一旦成立即改為把收回的本金交還投資人，在資產池進一步惡化前縮短暴險。

(D)錯誤。觸發事由改變的是本金償還的速度，而非票息；提高票息反而會更快消耗資產池的現金流。

9. 證券化架構中安排流動性支援機制（如流動性融資額度）之主要目的為何？
  1. (A)確保受益證券於次級市場維持一定之成交量與買賣報價深度
  2. (B)保證各順位受益證券之本金與利息最終均獲得全額清償
  3. (C)替代次順位受益證券，使交易免除信用增強之設計
  4. (D)因應資產池收款時點與證券付息時點錯開，避免技術性違約
解析

(A)錯誤。次級市場是否活絡取決於市場參與者與造市意願，並非流動性額度所能保證。

(B)錯誤。承擔最終信用損失的是信用增強機制（次順位、超額擔保、保證等），流動性支援並不保證最終獲得清償。

(C)錯誤。信用增強處理的是「收不收得回」的損失問題，流動性支援處理的是「何時收到」的時間問題，兩者功能不同且不能互相取代。

(D)正確。資產池的收款日與證券的付息日常有落差，或因部分帳戶延遲繳款而出現當期現金短缺；流動性支援填補這段時間差，使交易不致因暫時性缺口而構成違約。

10. 許多機構投資人之投資準則以維持一定信用評等作為得否繼續持有之條件，此一設計在市場壓力期間可能產生何種副作用？
  1. (A)評等調降時信用評等機構須對投資人所受損失負賠償責任
  2. (B)評等調降時交易之信用增強水準自動提高以維持原有評等
  3. (C)評等調降時觸發同向且集中之賣出，加劇價格下跌與流動性枯竭
  4. (D)評等調降時觸發集中之買進，使價格於短期內迅速回升至合理水準
解析

(A)錯誤。信用評等是對信用風險的意見，並非對投資結果的保證或承諾。

(B)錯誤。信用增強水準由發行時的結構所決定，不會因評等變動而自動增加。

(C)正確。當眾多投資人受相同的評等門檻拘束，一次調降會使他們在同一時點被迫賣出同一類資產；買方同時退場，價格因而超跌，並可能引發新一輪調降，形成順循環的惡性循環。

(D)錯誤。受評等限制拘束的投資人在調降後是被迫減碼，而非加碼。

11. 所謂「殘值風險」（residual value risk）在汽車相關資產證券化中，最直接反映於下列何種情形？
  1. (A)承租人於租賃期滿返還車輛時，車輛實際處分價格低於原先設定之預估殘值
  2. (B)受託機構因作業疏失未能按時將收取款項撥付予投資人
  3. (C)創始機構於資產移轉後發生破產，該資產池被法院認定應納入其破產財團

14. 房貸轉付證券付給投資人的轉付利率（pass-through rate），與資產池的加權平均票面利率（WAC）之間的關係通常是：
  1. (A)轉付利率高於 WAC，差額由受託機構以自有資金補貼
  2. (B)轉付利率等於 WAC，因為現金流係全額轉付，不得扣除任何費用
  3. (C)轉付利率與 WAC 無關，係由發行時的市場殖利率直接決定
  4. (D)轉付利率低於 WAC，差額用以支應服務費及保證費等相關費用
解析

(A)錯誤。證券化的架構設計是讓資產池自給自足，受託機構並不以自有資金補貼利息，否則風險就沒有真正移轉出去。

(B)錯誤。「轉付」指的是收到就分配的時間概念，不代表不扣費用；服務與保證都是有成本的作業，必須從利息流中支應。

(C)錯誤。發行時的市場殖利率影響的是證券的發行價格與投資人的實際報酬率，票面上的轉付利率仍是由 WAC 扣除費用後決定。

(D)正確。借款人繳的利息是按貸款契約利率計算，但在轉付給投資人之前，須先扣除服務機構的服務費以及（若有）保證機構的保證費，因此投資人實際收到的轉付利率必然低於資產池的加權平均票面利率。

15. 就不動產「流動性低、變現期間長」的特性而言，證券化改善此一問題的主要機制為何？
  1. (A)由受託機構承諾於投資人提出請求時，隨時以原價買回其受益證券
  2. (B)將不動產的權益轉化為得於次級市場流通轉讓的有價證券
  3. (C)縮短不動產本身買賣移轉登記所需的地政作業時間
  4. (D)由不動產管理機構保證於一定期限內處分標的並返還全部本金
解析

(A)錯誤。這是開放式基金的買回機制。不動產資產信託與封閉型的不動產投資信託通常不提供隨時買回，投資人須在次級市場出售，且原價買回等同保本，不符受益證券的性質。

(B)正確。不動產本身的買賣仍然費時，證券化並未改變這一點；它改變的是投資人的退場方式——投資人賣的是受益證券而不是房地，透過證券市場的轉讓取得流動性。

(C)錯誤。登記作業效率屬於地政制度層面，證券化架構並不會加速不動產本身的過戶；證券化提升的是投資人持有部位的流動性，而非標的物的流動性。

(D)錯誤。不動產管理機構的職能是租務與物業管理，並無保證處分或返還本金的義務；標的能否順利處分及處分價格，仍由受益人承擔。

16. 金融資產證券化條例之立法目的，最主要在於下列何者？
  1. (A)使投資人得直接向原借款人行使債權，取代金融機構之中介功能
  2. (B)限制金融機構承作長期放款之比重，以降低銀行業整體授信風險並強化其資本適足性
  3. (C)提高金融機構資產之流動性與資金運用效率，並保障投資、發展國民經濟
  4. (D)使金融機構得將不良債權出售予資產管理公司並享租稅減免，藉以改善逾期放款比率

(C)正確。條例的核心在於將缺乏流動性但具穩定現金流之金融資產轉換為證券，提高資金運用效率並健全金融市場，同時以資訊揭露與監理機制保障投資人。

(D)錯誤。將不良債權出售予資產管理公司並搭配租稅措施，是金融機構合併法等機制的設計；本條例之標的以現金流可預測之資產為主，租稅減免亦非其立法核心目的。
