1. 以下何種權利屬於智慧財產權？
  1. (A)債權
  2. (B)抵押權
  3. (C)商標權
  4. (D)姓名權
解析

(A)錯誤。債權是請求特定人為一定給付的權利，屬財產權但非智慧財產權。

(B)錯誤。抵押權是就不動產賣得價金優先受償的擔保物權。

(D)錯誤。姓名權是人格權，保護的是人格的同一性，不具財產權性質。

11. 我國「彈劾權」的設計，與三權分立的國家略有不同。關於我國彈劾權的行使，下列何者正確？
  1. (A)立法院可以對行政院院長提出彈劾案
  2. (B)立法院可調查且彈劾違法的公務人員
  3. (C)監察院可對違法失職的總統或副總統進行彈劾
  4. (D)監察院可彈劾縣、市首長並移送司法懲戒
解析

(A)錯誤。立法院對行政院院長提出的是「不信任案」，屬政治責任的追究，不是彈劾。

(B)錯誤。調查權與彈劾權原則上屬監察院；立法院有的是文件調閱與調查的權限，並無彈劾公務人員的權力。

(C)錯誤。總統、副總統的彈劾案改由立法院提出，並由憲法法庭審理，不再由監察院為之。

(D)正確。監察院對中央及地方公務人員（包括縣市首長）認有違法失職者，得提出彈劾案並移送懲戒法院審理。

12. 我國自1991 年至2005 年共經歷七次憲法增修，下列何者為修憲的成果？
  1. (A)憲法修正案及領土變更案須經人民連署提案
  2. (B)命令或法律有違憲之虞者由大法官進行解釋
  3. (C)正副總統彈劾案由立法院提案，憲法法庭審理
  4. (D)各縣市的縣市長及縣市議員，皆改由人民直選
解析

(A)錯誤。憲法修正案及領土變更案均由立法院提出，再交由自由地區選舉人複決，並無人民連署提案的設計。

(B)錯誤。大法官解釋憲法、審查法令是否違憲，是憲法本文即有的制度，不是增修的成果。

(C)正確。增修條文將正副總統的彈劾改為由立法院提案，交由司法院大法官組成憲法法庭審理，這正是歷次修憲的具體變動之一。

(D)錯誤。縣市長與縣市議員本即由人民直選；修憲所處理的是省長、省議員的選舉與其後的精省。

14. 公民投票指全體公民透過行使投票的權利，對國家或社會的重大或特定問題進行表決的制度。關於我國公民投票的制度與實施，下列何者最為適切？
  1. (A)每一年皆可舉行一次公民投票
  2. (B)投票資格與正副總統選舉相同
  3. (C)展現國民主權
  4. (D)保護社會上少數人的權益
解析

(A)錯誤。全國性公民投票日定於固定日期，每兩年舉行一次，並非每年一次。
