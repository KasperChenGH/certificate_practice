1. 一名15 歲的國中生，下載行政院人事行政總處天然災害停止辦公及上課情形查詢網頁的原始檔案，將其改成今日起停班、停課一年等內容。這名國中生被依偽造公文書罪函送法辦。下列敘述何者正確？
  1. (A)其行為已影響社會至鉅具該當性，所以由檢察官調查起訴
  2. (B)國中生缺乏對刑法的完整了解，所以其行為不具有違法性
  3. (C)他只是國中生的年齡，所以他的行為不具備完全的有責性
  4. (D)該國中生出於好玩，並非故意犯罪，因此他不須負有責性
解析

(A)錯誤。十五歲的少年觸犯刑罰法律者，由少年法院依少年事件處理法處理，不是逕由檢察官起訴。

(B)錯誤。不知法律不阻卻違法性，否則法律將形同虛設。

(C)正確。十四歲以上未滿十八歲人之行為得減輕其刑，因其辨識能力與自我控制能力尚未成熟，罪責（有責性）並不完全。

(D)錯誤。出於好玩仍屬明知並有意使結果發生，故意並不因動機輕率而消失。

2. 隨著全球化的發展，國際交流愈來愈頻繁，關於國際交流之敘述，下列何者正確？
  1. (A)國民外交係指國民受政府囑託進行跨國交流
  2. (B)各國政府之交流仍以中央政府外交機關為限
  3. (C)國際組織下建立的國際協定要求所有成員國皆須加入
  4. (D)聯合國無法直接管轄各成員國之國際關係與國內治理
解析

(A)錯誤。國民外交指民間人士、團體自發進行的跨國交流，不以受政府囑託為前提。

(B)錯誤。地方政府締結姊妹市、各部會與外國對口機關往來，都是政府間交流的形式。

(C)錯誤。國際協定原則上以自願簽署、批准為基礎，並非所有成員國一律強制加入。

(D)正確。聯合國是主權國家所組成的國際組織，尊重會員國主權平等與不干涉內政，並無直接管轄各國國內治理的權力。

  1. (A)兩國國家元首皆須取得絕對多數始能當選
  2. (B)元首發布緊急命令皆須閣揆及相關閣員副署

5. 若法官於審理案件時，認為行政機關所訂定之法規命令，其內容已明顯逾越母法規範，依法得為何種處置？
  1. (A)法官得於個案審理中拒絕適用，並宣告該法規命令於判決後正式失效
  2. (B)法官得停止審理，要求行政機關重新訂定法規命令
  3. (C)法官得直接宣告該法規命令因違法而自始無效
  4. (D)法官僅得於個案審理中拒絕適用，但該法規命令之效力不受影響
解析

(A)錯誤。法官可以拒絕適用，但無權宣告法規命令失效。

(B)錯誤。法官不能要求行政機關重新訂定命令，那侵入行政權的形成空間。

(C)錯誤。宣告法規命令無效不屬個案法官的權限。

(D)正確。命令是否牴觸法律，各級法院法官於審理個案時本得自行判斷並拒絕適用；但該判斷只拘束個案，命令對外的效力仍須由訂定機關廢止或由憲法法庭處理。

  2. (B)屬於地方自治與跨縣市區域經營合辦事項

13. 甲選區舉行立法委員罷免案投票，該區選舉人總數為235,024 人，依選舉委員會統計，投票率為41.93%，同意票54,813 張、不同意票43,340 張。依公職人員選舉罷免法規定，此罷免案通過與否的主要理由為何？
  1. (A)罷免案通過，因同意罷免的票數多於不同意罷免的票數
  2. (B)罷免案通過，因罷免案之投票率達選舉人總數四分之一
  3. (C)罷免案不通過，因罷免案之投票率未達選舉人總數二分之一
  4. (D)罷免案不通過，因同意票未達選舉人總數四分之一以上
解析

(A)錯誤。同意票多於不同意票只是要件之一，還須跨過票數門檻。

(B)錯誤。法律設定的門檻是「同意票數」須達選舉人總數四分之一，不是投票率。

(C)錯誤。罷免投票並無二分之一投票率的門檻。

(D)正確。罷免通過須同時具備兩項要件：同意票多於不同意票，且同意票達原選舉區選舉人總數四分之一以上。選舉人總數235,024人的四分之一為58,756票，而同意票僅54,813票，未達門檻，故不通過。

14. 某甲與伴侶乙之親密行為遭乙偷拍並上傳至網路。關於甲之救濟程序，下列何者正確？
  1. (A)甲須先經調解無效後方得提出民事訴訟求償
  2. (B)此侵害行為涉及刑事責任，甲須委任律師提出民事與刑事訴訟
  3. (C)若乙未成年，其法定代理人同為民事與刑事訴訟之被告
  4. (D)若甲未成年，須由法定代理人代為提起民事訴訟
解析

(A)錯誤。此類侵權求償並無一律先行調解的規定。
