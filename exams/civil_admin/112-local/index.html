  1. (A)行政運作與資訊管理
  2. (B)行政組織理論與行為

2. 威爾遜（W. Wilson）主張行政和政治二分的最主要原因為何？
  1. (A)因為行政學沉寂已久，在政治學底下無法受到應有的重視
  2. (B)公共行政和管理學不同，必須強調公共性，因此必須強調行政學這個領域
  3. (C)因為經營憲法比制訂憲法更為困難且重要
  4. (D)可幫助行政機關爭取更多預算
解析

(A)錯誤。爭取學科地位是後續發展的結果，不是他提出二分的理由。

(B)錯誤。強調公共性以區隔企業管理，是後來公共行政學界的主張。

(C)正確。威爾遜指出「執行一部憲法遠比制定一部憲法困難」，行政的執行面有其獨立的專業與方法，應與政治的價值決定分開研究。

(D)錯誤。爭取預算不是學理上主張政治行政二分的理由。

3. 有關我國自1990 年之後所推動的「政府再造」，下列敘述何者錯誤？
  1. (A)強調集權化的政府運作，追求大而美的政府
  2. (B)前瞻性的思考，強調事先預防重於事後補救
  3. (C)以目標和任務為導向，簡化不合時宜的法令章程
  4. (D)強調顧客導向，以創造民眾利益與服務民眾為主要目的
解析

(A)正確。政府再造的方向是分權、鬆綁與精簡，追求「小而能」的政府；集權化與大而美恰與其主張相反。此為錯誤敘述。

(B)錯誤。本題要選敘述錯誤者。前瞻預防重於事後補救，是再造的原則之一。

(C)錯誤。本題要選敘述錯誤者。以任務目標為導向並簡化不合時宜的法令，是再造的內容。

(D)錯誤。本題要選敘述錯誤者。顧客導向是政府再造的核心主張。

(D)錯誤。引進市場競爭以提升服務品質，是新公共管理的主張。

10. 關於公務員下列各項行為中，何者沒有違反公務人員行政中立法規定？

(C)錯誤。兼任候選人競選辦事處的職務，為法所禁止。

(D)錯誤。動用行政資源為候選人辦活動，是行政中立法明文禁止的行為。

12. 為了促進廉能政治、端正政風，有關我國「陽光法令」之敘述，下列何者正確？

  2. (B)所有公務人員都有財產申報的義務
  3. (C)各級民意機關之民意代表均適用公職人員利益衝突迴避法的規範

17. 有關我國中央行政機關的組織型態，下列何者正確？
  1. (A)行政院為「機關」
  2. (B)法務部行政執行署為「行政法人」
  3. (C)行政院主計總處為「機構」
  4. (D)國家科學及技術委員會為「政府捐助的財團法人」
解析

(A)正確。行政院依中央行政機關組織基準法為一級「機關」，就法定事務有決定並表示國家意思於外部的權限。
