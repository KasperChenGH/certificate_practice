1. 有關「公共行政」的內涵，下列何者錯誤？
  1. (A)專指現代政府職能中的政策執行
  2. (B)其觸角幾乎深入民眾生活的每個層面
  3. (C)政府活動的一部分
  4. (D)政府達成目標和目的的手段
解析

(A)正確。現代公共行政不只執行政策，也深度參與政策的規劃、倡議與評估；把它侷限於「執行」，正是政治行政二分早已被修正的舊觀點。此為錯誤敘述。

(B)錯誤。本題要選敘述錯誤者。從出生登記到殯葬管理，行政的觸角確實遍及生活各層面。

(C)錯誤。本題要選敘述錯誤者。公共行政是政府活動的一部分。

(D)錯誤。本題要選敘述錯誤者。行政是政府達成公共目標的手段。

2. 以漸進主義的視角來研究政府組織再造，這是偏向何種公共行政的分析途徑？
  1. (A)政治途徑
  2. (B)法律途徑
  3. (C)哲學途徑
  4. (D)批判途徑
解析

(A)正確。漸進主義強調在多元利益的協商妥協中小幅調整，重視代表性與可接受度；這種以政治互動理解行政的取向，即政治途徑。

(B)錯誤。法律途徑關注正當程序、個人權利保障與司法審查。

(C)錯誤。公共行政的三大分析途徑為管理、政治與法律，並無哲學途徑一項。

(D)錯誤。批判途徑質疑既有權力結構，非漸進主義的立場。

3. 新公共管理（NPM）主張將市場機制應用於政府治理，然而政府機關全面引入市場機制可能會造成什麼問題？
  1. (A)不會有問題，市場機制在任何地方都是較有效率的資源配置機制
  2. (B)有些公共領域有過高的資訊不對稱問題，價格機制可能會失靈
  3. (C)人民將政府視為公司行號
  4. (D)公務人員集體失業
解析

(A)錯誤。市場機制在資訊不對稱、外部性與獨占等情形下同樣會失靈，並非處處有效。

(B)正確。醫療、長照、教育等領域的服務品質，一般人難以事前判斷，資訊高度不對稱；此時價格無法正確反映品質，市場機制反而導致劣幣驅逐良幣。

(C)錯誤。民眾觀感的改變是可能的附帶效果，不是引入市場機制的核心問題。

(D)錯誤。市場化多以委外、法人化等方式進行，並不會造成公務人員集體失業。

(D)錯誤。該理論並無「封建型社會」這一分類。

(C)錯誤。他主張事實與價值分離，研究應採事實取向以求科學化。

(D)錯誤。他提出有限理性，認為人只能追求滿意而非最佳的決策。

9. 某政府機關欲建立民主國家之公共服務核心價值，下列那個組合最不恰當？
  1. (A)廉潔誠實、專業主義、無私公正
  2. (B)依法行政、行政中立、透明公開
  3. (C)效忠領袖、服從指揮、嚴守秘密
  4. (D)廉潔奉公、公共利益、利益迴避
解析

(A)錯誤。廉潔誠實、專業與無私公正，都是公共服務的核心價值。

(B)錯誤。依法行政、行政中立與透明公開，是民主行政的基本要求。

(C)正確。效忠「領袖」而非憲法與人民、一味服從指揮、以保密為常態，是威權體制對官僚的要求；民主國家的文官效忠的是法律與公共利益，並須接受公開監督。

(D)錯誤。廉潔奉公、追求公共利益與利益迴避，都是核心價值。

10. 有關公務人員行政中立法對於參與政治活動的規範，下列何者正確？
  1. (A)可以於自己辦公桌張貼特定公職候選人之宣傳貼紙
  2. (B)公務人員如其配偶登記為公職參選人，該公務人員不得為其公開站台
  3. (C)公務人員不得於加班時間參與政黨的造勢活動
  4. (D)公務人員得指示所屬同仁投票給特定公職候選人
解析

(A)錯誤。在辦公場所懸掛、張貼特定政黨或候選人的標誌，為行政中立法明文禁止。

(B)錯誤。公務人員的配偶或一親等直系血親登記為候選人時，法律例外允許其為公開站台。

(C)正確。加班時間仍屬執行職務的時間，公務人員不得於此期間從事政黨活動；法律容許的是「非上班或勤務時間」的政治參與。

(D)錯誤。利用職務上的權力或機會，要求他人投票給特定候選人，為法所禁止。

12. 有關「弊端揭發」（whistle-blowing）之概念和實務發展，下列敘述何者正確？

(D)錯誤。揭發前應盡合理查證之責，否則可能構成誣告或誹謗，也會損及制度的公信。

17. 依據中央行政機關組織基準法之規定，下列何者為我國獨立機關採用的組織運作模式？
  1. (A)首長制
  2. (B)合議制
  3. (C)審議制
  4. (D)統合制
解析

(A)錯誤。首長制由一人決策，難以確保職權行使不受政治干預。
