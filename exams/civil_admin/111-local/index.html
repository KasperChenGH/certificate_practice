3. 下列何者被稱為「制度觀點的新公共行政」？
  1. (A)新公共服務
  2. (B)黑堡宣言
  3. (C)新公共管理
  4. (D)行政人本主義
解析

(A)錯誤：新公共服務由丹哈特夫婦（R. & J. Denhardt）提出，主張公務員是服務公民而非服務顧客，強調公共利益與民主對話，是對新公共管理的反省，出現時間也晚於黑堡宣言。

(B)正確：黑堡宣言由萬斯萊（G. Wamsley）等維吉尼亞理工學者於1980年代提出，主張行政機關在憲政體制中具有正當地位，行政人員是公共利益的受託者與主權的代理人。它承接新公共行政的價值關懷，但把論證焦點從行政人員個人的社會公正責任，轉移到行政「制度」本身的正當性，故被稱為制度觀點的新公共行政。

(D)錯誤：行政人本主義關切組織中人的成長、尊嚴與自我實現，屬組織人文主義的取向，並不是以憲政制度重新定位行政機關地位的宣言。

6. 關於赫茲伯格（F. Herzberg）的激勵保健理論，下列何者正確？
  1. (A)激勵因素為能防止員工不滿意的因素
  2. (B)保健因素為能使員工滿意的因素
  3. (C)主管只要消除員工工作不滿足的因素，就能帶來激勵效果
  4. (D)保健因素、激勵因素的項目，可能會因人而異
解析

(A)錯誤。能防止不滿意的是「保健因素」，如薪資、工作環境、人際關係。

(B)錯誤。能帶來滿意與激勵的是「激勵因素」，如成就、賞識、責任、成長。

(C)錯誤。消除不滿只能使員工從「不滿意」回到「沒有不滿意」，並不等於產生滿意與激勵。

(D)正確。同一項因素對不同的人可能扮演不同角色——薪資對某些人只是保健因素，對另一些人卻具成就象徵的激勵意義，故其歸類因人而異。

  2. (B)司法控制
  3. (C)主計審核
  4. (D)審計查核

48. 下列何種背景最有可能是造成歐美社會非營利組織大量產生的原因？

  2. (B)獨裁國家的危機

  4. (D)福利國家的危機
解析

(A)錯誤：民粹危機影響的是政治信任與代議政治的品質，可能改變政黨競爭的樣貌，但不是歐美志願部門在二十世紀後期大量興起的結構性原因。

(B)錯誤：獨裁體制壓抑結社自由與集會自由，公民社會難以發展；非營利組織的成長需要結社自由、租稅減免與公私協力等制度環境，而這些是民主國家才具備的條件。

(C)錯誤：財團壟斷指的是市場過度集中的市場失靈問題，主要以競爭法與管制回應；它能解釋政府為何要管制企業，卻不足以說明民間自願部門為何開始承接公共服務。

(D)正確：二次戰後福利國家大幅擴張政府給付，到1970年代普遍遭遇財政負擔沉重、科層僵化與服務品質不佳的「福利國家危機」，政府既無力也不宜獨攬社會服務；於是出現由非營利組織提供服務、政府以補助與委託配合的第三部門興起。它同時回應市場失靈與政府失靈，成為非營利組織存在的主要理論解釋。
