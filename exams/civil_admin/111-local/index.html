2. 關於修正時期（1930～1960 年代）行政學理論的敘述，下列何者錯誤？

  2. (B)主張科際整合
  3. (C)強調行政管理的規範層面，故重視應然面的研究

(D)錯誤。本題要選敘述錯誤者。援用自然科學的方法研究人類行為，是行為科學的特徵。

6. 關於赫茲伯格（F. Herzberg）的激勵保健理論，下列何者正確？
  1. (A)激勵因素為能防止員工不滿意的因素
  2. (B)保健因素為能使員工滿意的因素
  3. (C)主管只要消除員工工作不滿足的因素，就能帶來激勵效果
  4. (D)保健因素、激勵因素的項目，可能會因人而異
解析

(A)錯誤。能防止不滿意的是「保健因素」，如薪資、工作環境、人際關係。

(B)錯誤。能帶來滿意與激勵的是「激勵因素」，如成就、賞識、責任、成長。

(C)錯誤。消除不滿只能使員工從「不滿意」回到「沒有不滿意」，並不等於產生滿意與激勵。

(D)正確。同一項因素對不同的人可能扮演不同角色——薪資對某些人只是保健因素，對另一些人卻具成就象徵的激勵意義，故其歸類因人而異。

10. 有關政府資訊公開之說明，下列何者正確？
  1. (A)政府資訊應依政府資訊公開法主動公開或應人民申請提供之
  2. (B)政府決算書不屬於政府資訊主動公開的範圍
  3. (C)政府資訊公開法所稱之政府資訊，專指以文書形式存在之政府紀錄或訊息
  4. (D)個人、法人或團體即使受政府機關委託行使公權力，亦不受政府資訊公開法之規範
解析

(A)正確。政府資訊公開法採「主動公開」與「依申請提供」雙軌並行，前者由機關自行揭露，後者由人民請求。

(B)錯誤。預算及決算書明列於應主動公開的政府資訊之中。

(C)錯誤。政府資訊包括文書、圖畫、照片、磁碟、光碟等各種媒介物所儲存的訊息，不以文書為限。

(D)錯誤。受政府機關委託行使公權力的個人、法人或團體，於其受託範圍內視同政府機關，同受該法規範。

(D)錯誤。同工同酬屬薪給政策，與結構高矮無關。

17. 有關民間捐助之財團法人，下列敘述何者正確？
  1. (A)董事長和常務監事對外共同代表財團法人
