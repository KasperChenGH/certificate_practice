1. 有關公共行政的敘述，下列何者正確？
  1. (A)能跳脫政治系絡而存在
  2. (B)專指提供直接服務給民眾
  3. (C)與公共政策之間的關係密不可分
  4. (D)專指以公務人員個人的力量來實現公共利益
解析

(A)錯誤。行政的目標、資源與正當性都來自政治過程，不可能脫離政治系絡而存在。

(B)錯誤。除直接服務外，行政還包括管制、課稅、政策規劃與資源分配等作用。

(C)正確。公共行政既參與政策的規劃與倡議，也負責政策的執行與評估；兩者互為表裡，難以切割。

(D)錯誤。公共利益須透過組織、制度與集體行動實現，非憑個別公務人員之力。

2. 有關行政學修正理論時期（1930-1960 年代）相關學派的論述，下列何者錯誤？
  1. (A)動態平衡理論認為組織中的權威係視受命者的同意程度而定
  2. (B)需要層級理論認為人有不同層次的需要
  3. (C)激勵保健理論區分消極防止不滿的因素及積極促進工作意願的因素
  4. (D)開放系統理論強調組織與外在環境的互動關係
解析

(A)錯誤。本題要選敘述錯誤者。權威取決於受命者是否接受，是巴納德動態平衡理論的觀點。

(B)錯誤。本題要選敘述錯誤者。需要層級理論屬修正時期的激勵理論。

(C)錯誤。本題要選敘述錯誤者。區分保健與激勵兩類因素，是修正時期的理論。

(D)正確。開放系統理論強調組織與環境的互動，是一九六〇年代之後「整合時期」的核心，不屬修正時期。此為錯誤敘述。

3. 對於韋伯官僚制度理論的批評中，所謂「訓練有素的無能」（trained incapacity）的涵義是：
  1. (A)未受過訓練的人員，容易成為組織中的無能者
  2. (B)組織中採取過多的政治思想訓練，造成組織人員的無能
  3. (C)專業人員只適合在特定的環境中工作，一旦環境改變即無以為適
  4. (D)對於組織中無能者，應加強其專業方面的訓練
解析

(A)錯誤。該詞的重點恰恰在於「受過訓練」的人也可能無能，而非未受訓練者。

(B)錯誤。該概念與政治思想訓練無關。

(C)正確。長期依既定程序訓練出來的專精能力，會使人形成固定的思考與反應方式；一旦情境改變，過去的專長反而成為束縛，無法應變。

(D)錯誤。加強專業訓練正可能加深此一僵化，並非解方。

8. 依據我國相關法規之規定，「行政法人」和「政府捐助之財團法人」二者具備下列那一項共同點？
  1. (A)組織成員不需具備公務人員任用資格
  2. (B)年度營運經費來源以財產收入為最大宗
  3. (C)由行政院人事行政總處指派董事長或理事長1 人，為無給職
  4. (D)不具備科層體制的特徵
解析

(A)正確。行政法人依其人事管理規章進用人員，政府捐助的財團法人則依其內部規章聘僱；兩者的員工都不具公務人員身分，也不需具備公務人員任用資格。

(B)錯誤。兩者的經費多來自政府補助、捐助基金孳息與業務收入，財產收入未必是最大宗。

(C)錯誤。董事長的產生依各該設置條例或捐助章程辦理，並非由人事行政總處指派，亦非一律無給職。

(D)錯誤。兩者內部仍有董事會、執行長與各級單位的層級分工，並未脫離科層特徵。

13. 如果想要增加主管的控制幅度（span of control），下列何種方法「作用不明顯」？

(C)錯誤。主管的能力與經驗越強，可管理的人數越多。

(D)錯誤。工作越單純標準化，越不需要個別指導，控制幅度可放大。

14. 關於組織垂直分化之原則，下列敘述何者錯誤？

50. 下列何者不是跨機關合作之原因？
  1. (A)公共問題本質日趨複雜
  2. (B)單一機關專業能力有限
  3. (C)提高公共問題解決的有效性
  4. (D)提升個別機關的施政自主性
解析

(A)錯誤。公共問題跨越單一機關的管轄，是跨機關合作的主要動因。

(B)錯誤。單一機關的專業與資源有限，須借助他機關的能量。

(C)錯誤。整合資源以提高問題解決的有效性，是合作的目的。

(D)正確。跨機關合作必然要求機關讓渡部分決定權、遷就共同的步調與目標，實際上是「限縮」而非提升個別機關的施政自主性。
