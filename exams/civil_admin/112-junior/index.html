1. 羅聖朋（D. Rosenbloom）和克拉夫丘克（R. Kravchuk）主張行政機關為主權受託者，下列敘述何者錯誤？
  1. (A)文官負責公共政策的制定與執行
  2. (B)文官可以動員政治支持為其政策倡議及辯護
  3. (C)文官體系應堅持功績取向，無須考量社會代表性
  4. (D)文官需具備旺盛的企圖心和長遠的眼光
解析

(A)錯誤。本題要選敘述錯誤者。主權受託者的觀點正是肯認文官同時參與政策的制定與執行。

(B)錯誤。本題要選敘述錯誤者。文官得為其專業判斷動員支持並公開辯護。

(C)正確。受託行使主權者必須反映社會的多元組成，代表性官僚正是其正當性的來源之一；只講功績而不顧社會代表性，與該主張相悖。此為錯誤敘述。

(D)錯誤。本題要選敘述錯誤者。以長遠眼光維護公共利益，是受託者應有的態度。

(D)正確。提升生產力正是新公共管理最核心的訴求，批評者指責它偏重效率而犧牲其他價值，不可能反過來說它忽略生產力。

3. 有關1968 年第一次明諾布魯克會議的主張，下列敘述何者錯誤？
  1. (A)公共行政扮演入世的積極角色
  2. (B)政府採用較多的民營化和契約外包
  3. (C)重視公共價值
  4. (D)主張適應動盪不安的環境

(A)錯誤。本題要選敘述錯誤者。該會議主張行政人員應積極入世，而非價值中立的旁觀者。

(B)正確。民營化與契約外包是一九八〇年代新公共管理的處方；第一次明諾布魯克會議談的是社會公正、入世相關與變遷，兩者是不同的思潮。此為錯誤敘述。

(C)錯誤。本題要選敘述錯誤者。重視社會公正等公共價值，是新公共行政的核心。

(D)錯誤。本題要選敘述錯誤者。因應動盪不安的環境，是該會議的關懷之一。

5. 關於泰勒（F. W. Taylor）的主張，下列敘述何者錯誤？
  1. (A)透過對工人進行動作與時間的研究，可找出最好的工作方法
  2. (B)應就工人專長加以訓練，擔任適合的工作
  3. (C)工人薪資應齊一，以示公平
  4. (D)應給予適當的工具
解析

(A)錯誤。本題要選敘述錯誤者。以動作與時間研究找出唯一最佳工作方法，是科學管理的核心。

(B)錯誤。本題要選敘述錯誤者。科學地選人並施以訓練，是泰勒四原則之一。

(C)正確。泰勒主張的是「差別計件工資」——依產量達標與否給予不同費率，以獎勵高效率者；齊一薪資恰是他認為助長怠工的作法。此為錯誤敘述。

(D)錯誤。本題要選敘述錯誤者。提供標準化的適當工具，是科學管理的內容。

6. 關於賽蒙（H. Simon）的決策理論，下列何者錯誤？
  1. (A)主張人們具有「完全理性」
  2. (B)人們僅能做到「滿意決策」
  3. (C)認為人們是「行政人」
  4. (D)組織決策的過程可分為情報、設計、抉擇等活動
解析

(A)正確。賽蒙的核心主張正是「有限理性」——人的資訊、時間與計算能力都有限，不可能達到完全理性。此為錯誤敘述。

(B)錯誤。本題要選敘述錯誤者。在有限理性下，人只能追求滿意而非最佳的決策。

(C)錯誤。本題要選敘述錯誤者。賽蒙以「行政人」對比古典經濟學的「經濟人」。

(D)錯誤。本題要選敘述錯誤者。決策過程可分為情報、設計與抉擇三階段。

7. 當人們提到「官僚」這個名詞時，會有很多不同的意涵，下列何者不屬之？
  1. (A)小型組織
  2. (B)行政制度或文官制度
  3. (C)科層組織
  4. (D)組織無效率的病象

(A)正確。官僚一詞或指文官制度、或指層級節制的科層結構、或作為僵化無效率的貶抑用語；組織規模大小並非其意涵，科層體制反而常與大型組織相連。

(B)錯誤。官僚可用以指涉一國的行政制度或文官體系。

(C)錯誤。官僚即韋伯所稱的科層組織。

(D)錯誤。日常用語中的官僚常指繁文縟節與無效率的病象。

8. 有關稅課收入之敘述，下列何者錯誤？
  1. (A)稅課的正當性需建立在增進公共福祉的基礎上
  2. (B)買賣動產契據為印花稅之課徵範圍
  3. (C)贈與稅為消費稅的一種
  4. (D)稅課是政府對經濟資源進行重分配的手段
解析

(A)錯誤。本題要選敘述錯誤者。課稅的正當性建立在其用於增進公共福祉。

(B)錯誤。本題要選敘述錯誤者。買賣動產契據是印花稅的課徵範圍之一。

(C)正確。贈與稅是就財產無償移轉所課徵的稅，屬財產（移轉）稅；消費稅課徵的對象是商品或勞務的消費行為，如營業稅、貨物稅。此為錯誤敘述。

(D)錯誤。本題要選敘述錯誤者。稅課與移轉支出並用，是政府重分配資源的主要手段。

9. 當官員試圖隱瞞不良的表現，這種行為直接違反了何種行政價值？
  1. (A)誠信（honesty）
  2. (B)公平性（fairness）
  3. (C)回應性（responsiveness）
  4. (D)效能性（effectiveness）
解析

(A)正確。隱瞞不良績效是對外提供不實資訊、蓄意誤導監督者，直接違反誠實信用這項最基本的行政倫理要求。

(B)錯誤。公平性指對待相同情形的人不得有無正當理由的差別待遇。

(C)錯誤。回應性指政府對民意與需求的反應程度。

(D)錯誤。效能性指目標的達成程度；表現不佳固然是效能問題，但「隱瞞」這個行為本身違反的是誠信。

11. 下列何種因素是決定組織發展成為高塔式或扁平式組織的關鍵？

  2. (B)管理格道
  3. (C)稜柱理論

(C)錯誤。稜柱理論是里格斯用以描述開發中國家行政生態的模型。

(D)錯誤。順適效果並非決定組織層級結構的因素。

(C)錯誤。合議決策較能容納不同意見，具民主性。

(D)錯誤。委員相互牽制，可避免權力集中於一人。

15. 下列何者是有機式（organic）的組織架構所具有的特徵？
  1. (A)組織成員的順從程度高
  2. (B)對於環境的調適能力高
  3. (C)決策制定的集權程度高
  4. (D)工作目標的明確性程度高
解析

(A)錯誤。強調成員順從與服從規則，是機械式組織的特徵。

(B)正確。有機式組織規則少、層級淺、橫向溝通頻繁、任務可隨時調整，因而能快速回應變動的環境——這正是它相對於機械式組織的核心優勢。

(C)錯誤。高度集權是機械式組織的特徵；有機式組織傾向分權。

(D)錯誤。工作定義明確、職掌固定，是機械式組織的特徵。
