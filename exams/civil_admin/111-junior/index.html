  1. (A)重視客觀性
  2. (B)重視解釋和預測的作用
  3. (C)強調規範的層面
  4. (D)強調行為的觀察
解析

(A)錯誤。本題要選敘述錯誤者。實證典範要求研究者價值中立、追求客觀。

(B)錯誤。本題要選敘述錯誤者。建立能解釋並預測現象的通則，是實證研究的目標。

(D)錯誤。本題要選敘述錯誤者。以可觀察的行為作為研究對象，正是實證取向的特徵。

2. 關於巴納德（C. Barnard）對於溝通的看法，下列何者錯誤？
  1. (A)應善用社群媒體以擴大溝通效果
  2. (B)溝通管道應廣為人知
  3. (C)溝通路線應盡量直接而簡短
  4. (D)兼顧正式與非正式的溝通管道
解析

(A)正確。巴納德提出溝通原則的年代遠早於社群媒體出現，其原則講的是組織內溝通體系應如何設計，與運用何種媒介無關。此為錯誤敘述。

(B)錯誤。本題要選敘述錯誤者。溝通管道應為組織成員所確知，是其原則之一。

(C)錯誤。本題要選敘述錯誤者。溝通路線應盡可能直接而簡短，以減少失真。

(D)錯誤。本題要選敘述錯誤者。巴納德重視非正式組織的溝通功能，主張兼顧正式與非正式管道。

3. 關於新公共管理（New Public Management）運動的描述，下列何者錯誤？
  1. (A)《新政府運動》（Reinventing Government）一書被視為是觸發新公共管理運動的代表作
  2. (B)提倡企業型政府的概念
  3. (C)主張政府扮演操槳者的角色
  4. (D)推崇顧客導向的政府
解析

(A)錯誤。本題要選敘述錯誤者。《新政府運動》確被視為觸發新公共管理的代表作。

(D)錯誤。本題要選敘述錯誤者。顧客導向是新公共管理的主要主張之一。

4. 如果你是支持「權變理論（contingency theory）」的學者，你會認同下列那一項敘述？
  1. (A)管理組織的方法存在一套最佳解方
  2. (B)組織為一個由封閉到開放的連續體

解析

(A)錯誤。「一套最佳解方」正是權變理論所要推翻的古典管理信念。

(C)錯誤。權變理論強調的是情境差異，而非穩定單一。

(D)錯誤。權變講的是手段隨情境調整，不是不擇手段。

5. 學者韋伯（M. Weber）認為，官僚制度的正當合理性（legitimacy），主要是來自於那一種權威（authority）？
  1. (A)傳統權威
  2. (B)合法合理權威
  3. (C)超人權威
  4. (D)情勢權威
解析

(A)錯誤。傳統權威建立在世襲與慣例之上，是前現代統治的基礎。

(B)正確。官僚制度的正當性來自「合法合理權威」：權力附麗於依法設置的職位而非個人，成員服從的是規則而不是某個人。

(C)錯誤。超人（魅力）權威來自領袖個人的非凡特質，具不穩定性。

(D)錯誤。韋伯的權威三分類中並無「情勢權威」一項。

6. 依據賽蒙（H. Simon）的理論，組織成員在做決策時，很難獲得最佳選擇，常只能追求滿意的決策，其主因為何？
  1. (A)決策者的自私自利
  2. (B)決策者的有限理性
  3. (C)組織的溝通不良
  4. (D)組織的保守文化
解析

(A)錯誤。賽蒙的論點是認知能力的限制，不是動機上的自私。

(B)正確。人受限於資訊不完全、時間有限與計算能力不足，無法窮盡所有方案與後果，因而只能在有限理性下選擇「夠好」而非最佳的方案。

(C)錯誤。溝通不良是組織問題，不是有限理性的核心意涵。

(D)錯誤。保守文化影響的是變革意願，與決策理性的界限無關。

7. 依據系統理論之觀點，開放系統能永續發展是因為具有下列何種作用？
  1. (A)反熵作用（negative entropy）
  2. (B)霍桑效應作用（Hawthorne effect）

(B)錯誤。霍桑效應指受觀察者因被注意而改變行為，屬人群關係學派的發現。

(C)錯誤。非正式組織是組織內部的現象，不解釋系統為何能永續。

(D)錯誤。激勵處理的是個人工作意願，層次與系統存續不同。

9. 下列那一項行為最有可能違反公務員廉政倫理規範？
  1. (A)教育局督學到國小視察，校長恰為其大學同學。校長為表達感謝及敘舊，作東邀請督學和學校其他主管到校外餐廳聚餐並暢飲一番
  2. (B)住院病人家屬為感謝某公立醫院內科病房全體醫護人員之辛勞，於中秋節贈送市價約800 元文旦一箱，由內科部主任代表同仁收受
  3. (C)某市政府科長喜獲麟兒，其直屬長官為表賀忱及感謝其平日工作辛勞，贈與一只金鎖片祝福平安富貴

(C)錯誤。這是公務員之間基於禮貌與人情的餽贈，並非與職務有利害關係者所提供。

(D)錯誤。月曆屬廣告或宣導性質的物品，價值輕微，不在禁止之列。

(D)錯誤。分部化標準決定依功能、地區、產品或顧客劃分單位，是結構設計的基本面向。

16. 下列何者並非設立行政法人考量之事由？
  1. (A)所涉公權力行使程度較低者
  2. (B)須強化成本效益及經營效能者
  3. (C)不適合由政府機關推動，亦不宜交由民間辦理者

解析

(A)錯誤。所涉公權力行使程度較低者，正是設立行政法人的考量事由之一。
