4. 如果你是支持「權變理論（contingency theory）」的學者，你會認同下列那一項敘述？
  1. (A)管理組織的方法存在一套最佳解方
  2. (B)組織為一個由封閉到開放的連續體
  3. (C)重視組織的穩定單一性
  4. (D)鼓勵為達目的不擇手段
解析

(A)錯誤：「唯一最佳方法」是泰勒科學管理與傳統理論的主張，權變理論正是要推翻它，認為有效的管理方式隨環境、技術與人員條件而變，不存在放諸四海皆準的最佳解方。

(B)正確：權變理論放棄封閉／開放、X／Y這類兩極化思考，改採連續體（continuum）觀點，認為組織依環境不確定性的高低，落在封閉系統與開放系統之間的某一位置；管理者的任務是先診斷情境變數，再選擇適配的結構與領導方式。唯有如此才能解釋同一套制度為何在不同機關成效迥異。

(C)錯誤：強調穩定、單一與標準化，是傳統（理性）理論對組織的假定；權變理論看重的恰是彈性與差異，承認多元的結構安排可以同時有效。

(D)錯誤：為達目的不擇手段是馬基維里式的權術主張，屬權謀而非權變；contingency 意為「視情境而定」，與目的能否正當化手段無關，只是中文譯名容易被聯想在一起。

5. 學者韋伯（M. Weber）認為，官僚制度的正當合理性（legitimacy），主要是來自於那一種權威（authority）？
  1. (A)傳統權威
  2. (B)合法合理權威
  3. (C)超人權威
  4. (D)情勢權威
解析

(A)錯誤：傳統權威來自世襲、習俗與長期沿襲的身分秩序，韋伯用它說明家產官僚制等前現代統治，而非現代官僚制度的正當性基礎。

(B)正確：韋伯把權威分為傳統權威、超人（卡里斯瑪）權威與合法合理（legal-rational）權威三類，現代官僚制度的正當性建立在合法合理權威上：權力附隨於法規所設置的職位，成員服從的是非人情化的規章，而不是某個人。這使行政行為可預測、可課責，也是依法行政的理論源頭。

(C)錯誤：超人權威建立在領袖個人魅力與追隨者的信仰上，高度不穩定且有繼承困難，正是官僚制希望以制度化、去人格化來取代的對象。

(D)錯誤：情勢權威出自傅麗德（M. P. Follett）的「情勢法則」，主張雙方共同服從情境的客觀要求而非服從某個人，不在韋伯的權威三分類之內。

6. 依據賽蒙（H. Simon）的理論，組織成員在做決策時，很難獲得最佳選擇，常只能追求滿意的決策，其主因為何？
  1. (A)決策者的自私自利
  2. (B)決策者的有限理性
  3. (C)組織的溝通不良
  4. (D)組織的保守文化
解析

(A)錯誤：以自私自利為行為動機的預設，是公共選擇學派與代理理論的作法；賽蒙的滿意決策並不假定決策者不誠實，一個全心追求公益的人同樣受認知限制。

(B)正確：賽蒙提出有限理性（bounded rationality）：人的資訊不完整、計算能力與時間有限，無法窮盡所有替選方案及其後果，因此改以「足夠好」的滿意解（satisficing）取代最佳解。這也說明行政決策為何大量倚賴標準作業程序與經驗法則，用制度替個人節省認知成本。

(C)錯誤：溝通不良會加重資訊落差，但屬於個別組織的管理缺陷；賽蒙的論點更強，即使溝通順暢、資訊充分供應，人類心智處理能力的上限仍使最佳化不可能。

(D)錯誤：保守文化影響的是組織願不願意冒險或改變，屬組織文化議題；滿意決策描述的是人類認知能力的一般限制，在創新或保守的組織裡同樣成立。

7. 依據系統理論之觀點，開放系統能永續發展是因為具有下列何種作用？
  1. (A)反熵作用（negative entropy）
  2. (B)霍桑效應作用（Hawthorne effect）
  3. (C)非正式組織作用（informal organization）
  4. (D)激勵作用（motivation）
解析

(A)正確：卡茲與卡恩（Katz & Kahn）指出，封閉系統受熵增趨勢支配而逐步解組，開放系統則能從環境輸入能量與資源，且取得的投入大於維持運作的消耗，形成反熵（negative entropy），因而得以維持穩定狀態並持續成長。這正是行政機關必須不斷向環境爭取預算、資訊與正當性支持的理由。

(B)錯誤：霍桑效應出自梅堯（E. Mayo）主持的霍桑實驗，指受試者因受到關注而改變行為表現，屬人群關係學派的發現，與系統如何存續無關。

(C)錯誤：非正式組織是霍桑實驗與巴納德所強調的組織內部人際結構，可以彌補正式結構的不足，但它是組織內部現象，不是開放系統對抗解組的能量交換機制。

(D)錯誤：激勵屬探討如何引發成員努力的動機理論（馬斯洛、赫茲伯格等），作用層次在個人行為，並非解釋系統與環境交換資源而得以永續的作用。

12. 為原住民舉辦特考，藉其服公職的過程來強化政府對原住民的回應力，這是下列何種行政責任之確保途徑？

  2. (B)內部非正式
  3. (C)外部正式
  4. (D)外部非正式
解析
