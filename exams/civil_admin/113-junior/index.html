1. 公私部門組織有其異同，有關二者異同之敘述，下列何者錯誤？
  1. (A)二者皆有必須遵循的法規
  2. (B)二者的主要經費來源相同
  3. (C)政府組織比企業組織面對更強大的公共監督
  4. (D)政府組織比企業組織面對更多的分權制衡
解析

(A)錯誤。本題要選敘述錯誤者。公私部門都受各自的法規範拘束。

(B)正確。政府的經費主要來自租稅等強制性的公課，企業則來自市場交易的營收；財源性質不同，正是兩者在課責對象與行為誘因上分歧的根源。此為錯誤敘述。

(C)錯誤。本題要選敘述錯誤者。政府須面對民意機關、媒體與公眾的高度監督。

(D)錯誤。本題要選敘述錯誤者。政府受權力分立與多重制衡的拘束，遠多於企業。

2. 在行政功能的特質中，認為公務員必須憑藉聰明才智、經驗知識、道德涵養等作隨機應變，所謂「運用之妙存乎一心」，是下列那一種特質？
  1. (A)規範性
  2. (B)藝術性
  3. (C)服務性
  4. (D)責任性
解析

(A)錯誤。規範性指行政受法令與倫理規範的拘束。

(B)正確。行政不能全靠既定規則涵蓋一切情境，許多場合須憑經驗、判斷與涵養臨機應變，這種「存乎一心」的成分即行政的藝術性。

(C)錯誤。服務性指行政以服務人民為目的。

(D)錯誤。責任性指行政人員須對其作為負責。

3. 有關形容政府職能擴張，人民依賴日深的「行政國」一詞，下列敘述何者錯誤？
  1. (A)由瓦爾多（D. Waldo）最早提出
  2. (B)意謂行政人員具有實質的政策影響力
  3. (C)形容行政機關眾多，公務人員人數龐大，預算經費驚人
  4. (D)表示行政部門的舉足輕重地位，已經取代了立法功能
解析

(A)錯誤。本題要選敘述錯誤者。行政國一詞由瓦爾多提出。

(B)錯誤。本題要選敘述錯誤者。行政國的特徵之一即行政人員實質影響政策形成。

(C)錯誤。本題要選敘述錯誤者。機關繁多、人員與預算龐大，是行政國的具體表徵。

(D)正確。行政國描述的是行政部門功能擴張、影響力增強，但立法權仍是政策的正當性來源與監督者，並未被取代。此項把「擴張」誇大為「取代」，為錯誤敘述。

5. 某機關首長找到了一套他認為最有效的管理方法，並且要求機關內所有中階主管一起採用這套管理方法，卻一直不見成效。從行政學「整合時期」的理論分析，這位首長的領導可能出了什麼問題？
  1. (A)管理方式不夠科學，應該強化科學管理
  2. (B)太過相信存在「最佳法則」，實際上主管面臨不同的環境所適用的管理方式可能不同
  3. (C)管理方式不夠人性化，主管應該學會關心部屬
  4. (D)這位首長沒有強力監督每位中階主管的管理
解析

(A)錯誤。加強科學管理正是「唯一最佳方法」思維的來源，只會加深問題。

(B)正確。整合時期的權變觀點指出，管理沒有放諸四海皆準的最佳法則；不同單位面對的環境、任務與人員條件不同，硬套同一套方法自然難有成效。

(C)錯誤。人性化管理是修正時期的處方，未觸及本題「一體適用」的問題。

(D)錯誤。加強監督只是強化控制，並未解決方法與情境不搭的根本問題。

6. 有關權威之敘述，下列何者正確？
  1. (A)巴納德（C. I. Barnard）提出權威接受論，認為權威應視當時情況及事實需要來運用
  2. (B)韋伯（M. Weber）認為超人權威（charismatic authority）較符合當代社會之權威模式
  3. (C)傅麗德（M. P. Follett）提出情勢法則，認為權威必須視受命者是否有能力加以執行
  4. (D)費堯（H. Fayol）提出14 點管理原則（principles of management），認為最後權力應握於最高領導者手中
解析

(A)錯誤。巴納德的權威接受論主張權威來自「部屬是否接受」；「視當時情況與事實需要」是傅麗德情勢法則的意旨。

(B)錯誤。韋伯認為最符合現代社會的是合法合理權威，超人權威具不穩定性。

(C)錯誤。傅麗德的情勢法則主張命令應源自客觀情勢的要求，而非上級的個人意志。

(D)正確。費堯的十四點管理原則中包含「集權」一項，主張最終的決定權應集中於最高領導者，再視情況決定授權的程度。

9. 有關公務員廉政倫理規範，下列敘述何者錯誤？
  1. (A)遇有請託關說時，應於3 日內簽報其長官並知會政風機構
  2. (B)在偶發而無影響特定權利義務之虞時，可接受長官之獎勵、救助或慰問
  3. (C)配偶收受財物時，推定為公務員之受贈財物
  4. (D)正常社交禮俗標準的禮尚往來，同一年度同一來源的受贈財物以新臺幣20,000 元為限
解析

(A)錯誤。本題要選敘述錯誤者。遇有請託關說應於三日內簽報長官並知會政風機構。
