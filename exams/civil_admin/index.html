1. 行政學的研究，若以實證典範為基礎，下列何者錯誤？
  1. (A)重視客觀性
  2. (B)重視解釋和預測的作用
  3. (C)強調規範的層面
  4. (D)強調行為的觀察
解析

(A)錯誤。本題要選敘述錯誤者。實證典範要求研究者價值中立、追求客觀。

(B)錯誤。本題要選敘述錯誤者。建立能解釋並預測現象的通則，是實證研究的目標。

(C)正確。實證典範主張事實與價值分離，處理的是「是什麼」而非「應該是什麼」；強調規範層面的是規範性或後實證的研究取向。此為錯誤敘述。

(D)錯誤。本題要選敘述錯誤者。以可觀察的行為作為研究對象，正是實證取向的特徵。

2. 依公務人員考績法規定，下列敘述何者正確？

  2. (B)各機關考列甲等比例不得超過四分之三

(C)錯誤。考列丙等者留原俸級；現行法並無連續三年丙等即應免職的規定。

(D)正確。年終考績應以平時考核為依據，使考績不致淪為年終一次性的印象評分。

6. 甲、乙和丙三個地方政府針對共同的流域展開污染防治計畫，此種府際關係具有下列何種特性？
  1. (A)高度地方自主性
  2. (B)高度目標調和性
  3. (C)高度手段確定性
  4. (D)高度決策權威性

(C)錯誤。跨域污染的成因複雜，防治手段的因果關係並不確定。

(D)錯誤。三個地方政府地位對等，並無一方具決策權威，這正是協力治理的難處。

7. 相較於首長制，下列何者不是委員制組織的優點？
  1. (A)事權責任明確
  2. (B)集思廣益
  3. (C)決策過程較具民主性
  4. (D)權力行使在內部受到制約

(B)錯誤。多人共同審議可集思廣益，是委員制的優點。

(C)錯誤。合議決策較能容納不同意見，具民主性。

(D)錯誤。委員相互牽制，可避免權力集中於一人。

8. 有關1968 年第一次明諾布魯克會議的主張，下列敘述何者錯誤？
  1. (A)公共行政扮演入世的積極角色
  2. (B)政府採用較多的民營化和契約外包
  3. (C)重視公共價值

(C)錯誤。本題要選敘述錯誤者。重視社會公正等公共價值，是新公共行政的核心。

(D)錯誤。本題要選敘述錯誤者。因應動盪不安的環境，是該會議的關懷之一。

9. 我國地方稅法通則中所稱的地方稅，不包括下列何者？
  1. (A)財政收支劃分法所稱直轄市及縣（市）稅
  2. (B)地方制度法所稱直轄市及縣（市）特別稅課
  3. (C)地方制度法所稱鄉（鎮、市）營業稅課
  4. (D)地方制度法所稱直轄市及縣（市）附加稅課
解析

(A)錯誤。財政收支劃分法所稱的直轄市及縣（市）稅，屬地方稅。

(B)錯誤。地方制度法所稱的直轄市及縣（市）特別稅課，屬地方稅。

(C)正確。營業稅是國稅，地方制度法並無「鄉（鎮、市）營業稅課」這一稅目；鄉（鎮、市）在地方稅上僅得開徵臨時稅課。

(D)錯誤。地方制度法所稱的直轄市及縣（市）附加稅課，屬地方稅。

  1. (A)鼓勵員工進修即參加各種訓練

(C)錯誤。改善空間布置屬改善「工作條件」的面向。

(D)錯誤。權變領導屬領導與管理方式，不是工作設計。

14. 有關何茲柏格（F. Herzberg）的激勵保健理論的敘述，下列何者錯誤？
  1. (A)保健因素能帶來工作上的滿足
  2. (B)人們對保健因素感到滿意，無助於提升績效
  3. (C)薪資屬於保健因素的一種
  4. (D)此理論影響了1960 年代後的工作設計
解析

(A)正確。保健因素只能消除不滿，使人從「不滿意」回到「沒有不滿意」，並不能產生積極的滿足感；帶來滿足的是激勵因素。此為錯誤敘述。

(B)錯誤。本題要選敘述錯誤者。保健因素獲得滿足只是消除不滿，對績效提升幫助有限。

(C)錯誤。本題要選敘述錯誤者。薪資屬保健因素。

(D)錯誤。本題要選敘述錯誤者。該理論促成工作豐富化等工作設計的發展。

17. 由基層人員針對該機關例行性重複高的業務進行自動化的資料處理和追蹤，以作為輔助行政管理，上述敘述最符合那一種行政資訊管理系統？
  1. (A)決策支援系統（decision support system）
  2. (B)管理資訊系統（management information system）
