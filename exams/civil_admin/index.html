1. 下列那一項行為最有可能違反公務員廉政倫理規範？
  1. (A)教育局督學到國小視察，校長恰為其大學同學。校長為表達感謝及敘舊，作東邀請督學和學校其他主管到校外餐廳聚餐並暢飲一番
  2. (B)住院病人家屬為感謝某公立醫院內科病房全體醫護人員之辛勞，於中秋節贈送市價約800 元文旦一箱，由內科部主任代表同仁收受
  3. (C)某市政府科長喜獲麟兒，其直屬長官為表賀忱及感謝其平日工作辛勞，贈與一只金鎖片祝福平安富貴
  4. (D)年節將近，印刷廠老闆送一本月曆給與其平常有業務往來的某區公所課長，並強調該月曆很熱門搶手，而課長欣然接受
解析

(A)正確。校長是該次視察的受督導對象，與督學有直接的職務利害關係；接受其作東的飲宴應酬，正是廉政倫理規範所禁止的行為。

(B)錯誤。市價八百元的節慶餽贈在正常社交禮俗標準之內，且屬偶發、無影響特定權利義務之虞，得予收受。

(C)錯誤。這是公務員之間基於禮貌與人情的餽贈，並非與職務有利害關係者所提供。

(D)錯誤。月曆屬廣告或宣導性質的物品，價值輕微，不在禁止之列。

2. 下列那一項財政收入最符合學理上「受益者付費」的精神？
  1. (A)所得稅收入
  2. (B)補助收入
  3. (C)統籌分配稅
  4. (D)規費收入
解析

(A)錯誤。所得稅依負擔能力課徵，屬量能課稅而非受益者付費。

(B)錯誤。補助收入來自上級政府的移轉，與受益者付費無關。

(C)錯誤。統籌分配稅是稅收的重分配機制。

(D)正確。規費是人民因請求特定服務或使用公物而支付的對價，誰使用誰付費，最能體現受益者付費的精神。

5. 民主國家之政府預算審議過程，有何共同之規定？
  1. (A)審議預算案時，只能刪減，不得增加支出
  2. (B)須在12 月底前完成新年度預算之審議
  3. (C)須送交立法機關完成審議
  4. (D)須遵守不得有年度財政赤字之規定
解析

(A)錯誤。「不得增加支出」是我國與部分國家的規定；美國國會即得增列支出，並非各國共通。

(B)錯誤。各國會計年度起訖不同，審議期限自然互異。

(C)正確。預算須經人民代表組成的立法機關審議通過，是民主國家共通的原則——沒有代議機關的同意，行政部門不得徵稅與支出。

(D)錯誤。多數國家容許在一定條件下舉債與赤字，並非一律禁止。

9. 有關政府發放之抵用券（voucher），下列敘述何者正確？
  1. (A)公益彩券為抵用券的一種
  2. (B)使用者不可選擇服務提供者
  3. (C)使用者可按照票券規定接受服務
  4. (D)票券視同現金可直接折現
解析

(A)錯誤。公益彩券是政府籌措財源的工具，不是提供給民眾兌換服務的抵用券。

(B)錯誤。抵用券的設計精神恰恰相反：讓使用者得在合格的供給者之間自由選擇，藉此引入競爭。

(C)正確。抵用券由政府發給特定對象，持券人得依票券所定的範圍與條件，向合格的服務提供者換取服務。

(D)錯誤。抵用券限用於指定用途，不能視同現金折現，否則就失去引導特定消費的政策目的。

(D)錯誤。國家科學及技術委員會是行政院所屬的二級機關，不是財團法人。

17. 下列何者不是後實證對於真實世界決策之看法？
  1. (A)決策者會隱藏真正的政策目標
  2. (B)窮盡各種方法來產生備選方案
  3. (C)決策者利用修辭在互斥政策備選方案中找出可能備選方案
  4. (D)政策實際上回應社會上有組織的民眾
解析
