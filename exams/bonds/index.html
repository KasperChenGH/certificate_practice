1. 依可貸資金理論（loanable funds theory），在其他條件不變下，政府為支應擴大的財政赤字而增加公債發行，對均衡利率最直接的影響為何？
  1. (A)可貸資金供給曲線右移，均衡利率下降
  2. (B)可貸資金需求曲線右移，均衡利率上升
  3. (C)可貸資金需求曲線左移，均衡利率下降
  4. (D)供給與需求等幅右移，均衡利率維持不變
解析

(A)錯誤。供給曲線右移對應的是民間儲蓄增加、外資淨流入或央行釋出準備金等情形，那會壓低均衡利率，與政府向市場借錢的方向剛好相反。

(B)正確。可貸資金理論把利率視為資金供需所決定的價格，政府舉債是向市場「借入」資金，屬於資金需求方的增加；需求曲線右移而供給不變，均衡利率因而上升。

(C)錯誤。需求曲線左移代表企業投資意願轉弱或政府減少舉債，此時利率才會下降；增加發債不可能使可貸資金需求減少。

(D)錯誤。唯有民間因預期未來加稅而同額增加儲蓄（李嘉圖等值的極端情形）供需才會等幅移動；標準可貸資金分析下利率仍會上升。

2. 「外國債券」與「歐洲債券（國際債券）」的區別，下列敘述何者正確？
  1. (A)外國債券限由外國政府發行，歐洲債券則限由歐洲地區的企業發行
  2. (B)外國債券在某國境內以該國貨幣發行，歐洲債券則在計價幣別國之外發行
  3. (C)兩者僅計價幣別不同，其適用法規、承銷程序與稅負規定則完全一致
  4. (D)外國債券必以發行地以外的外幣計價，歐洲債券一律以歐元發行
解析

(A)錯誤。兩者的發行人都可以是政府、金融機構或一般企業；「歐洲」指的是發行與銷售的方式，而非發行人所在地。

(B)正確。外國債券是外國發行人進入某一國內市場，以該國貨幣、依該國法規與承銷慣例發行；歐洲債券（國際債券）則在計價幣別所屬國以外，由國際承銷團於多個市場同時銷售，適用的發行監理相對寬鬆、多以無記名方式流通。

(C)錯誤。兩者最關鍵的差別正在於適用哪一套發行監理、承銷程序與租稅待遇，而不只是計價幣別不同。

(D)錯誤。外國債券對發行人而言是外幣，但對發行市場而言正是當地貨幣；歐洲債券的計價幣別也不限歐元，以美元、日圓等計價者同樣屬之。

3. 「餘額包銷」與「（全額）確定包銷」最主要的差別在於：
  1. (A)餘額包銷僅適用於政府公債標售後的銷售，確定包銷才適用於公司債
  2. (B)餘額包銷是先代為銷售、期滿再就未售出餘額認購；確定包銷則是先全數認購再自行對外銷售
  3. (C)餘額包銷之承銷商不收取任何承銷報酬，僅確定包銷才須支付承銷報酬
  4. (D)餘額包銷之下發行公司無法確定最終能取得多少資金，只有確定包銷才能在銷售之前事先確定金額
解析

(A)錯誤。兩種方式都是公司債（及股票）承銷的實務做法，與政府公債的標售制度分屬不同的銷售機制。

(B)正確。差別在承銷商「何時」以及「就多少數量」成為認購人：確定包銷一開始即買斷全部、承擔全額部位；餘額包銷先居間銷售，只有賣剩的部分才落到自己帳上，部位規模事前未知但上限相同。

(C)錯誤。兩者都收取報酬，只是確定包銷承擔的風險較高，其承銷報酬（或折價空間）通常也較高。

(D)錯誤。餘額包銷同樣讓發行公司確定取得全額資金，因為賣不掉的部分承銷商必須認購——這正是它與代銷的關鍵分野。

4. 總體經濟學所稱的「排擠效果（crowding-out effect）」，描述的是下列何種機制？
  1. (A)政府支出提高民間資本的預期報酬率，帶動民間投資與就業同步擴張
  2. (B)央行以直接發行貨幣支應政府支出，導致物價全面上漲而侵蝕民間實質消費能力
  3. (C)政府舉債推升利率，壓抑對利率敏感的民間投資與支出，抵銷部分財政擴張效果
  4. (D)外資大量流入使本國企業在債市籌資更為容易，整體籌資成本因而下降
解析

(A)錯誤。那是方向相反的「擠入效果」，多發生在政府支出投入基礎建設等能提高民間資本報酬率、且經濟仍有閒置資源的時候。

(B)錯誤。那描述的是通膨稅或貨幣融通的效果；排擠效果的核心傳導變數是利率，並不以央行融通為前提。

(C)正確。政府舉債增加可貸資金需求而推升利率，企業投資、購屋與耐久財等對利率敏感的支出因資金成本上升而縮減，使財政擴張對總需求的淨效果小於乘數所預測。當經濟接近充分就業、資源緊繃時排擠最明顯；在深度衰退、資源閒置且利率貼近下限時則相對輕微。

(D)錯誤。資金流入壓低利率、便利籌資，屬於擠入的方向，與排擠效果所描述的利率上升壓抑投資恰恰相反。

5. 投資人預期市場殖利率將上升、債券價格將下跌，欲在現貨市場建立債券空頭部位，可行的作法是：
  1. (A)將手中現金承作附買回交易並收進標的券，即自動形成該檔債券的空頭部位
  2. (B)直接在等殖成交系統申報無券賣出，待交割日屆至時再於市場設法補進債券
  3. (C)先以附條件交易或債券借貸取得標的券，於市場賣出，日後再買回返還
  4. (D)以買賣斷方式買進同一檔債券後續抱，待殖利率上升、價格下跌後獲利了結
解析

(A)錯誤。承作附買回是把資金貸出、收進債券作為擔保，本身並無市場部位；必須進一步把收進的券在市場上賣出，才會產生空頭曝險。

(B)錯誤。無券賣出而屆期交不出券即構成交割違約，須負賠償責任並可能遭市場機構處置，等殖成交系統的申報也不能免除交券義務，不是合法可行的放空管道。

(C)正確。債券現貨放空必須先「有券可交」：透過反向的附條件交易（付出資金、收進標的券）或債券借貸取得券源，在市場賣掉建立空頭，殖利率上升、價格下跌後低價買回並返還，價差即為獲利，成本則是資金利息或借券費。

(D)錯誤。買進是多頭部位，殖利率上升時價格下跌反而蒙受損失，方向完全相反。

6. 我國對債券利息所得採「分離課稅」，其意義是：
  1. (A)利息所得須先併入年度所得總額申報，再由稅捐機關另行單獨核定適用稅率
  2. (B)分離課稅僅適用於境外投資人，境內投資人的債券利息一律併入所得總額計稅
  3. (C)利息所得於給付時扣繳稅款後即完成納稅義務，不再併入年度所得總額合併計稅
  4. (D)該項利息所得完全免稅，發行人與投資人雙方均無須辦理任何扣繳或申報
解析

(A)錯誤。先併入再單獨核定，與「分離」的意義正好相反；分離課稅的重點就在於自始不進入所得總額。

(B)錯誤。分離課稅並非以境內外區分。稅負對不同投資人的影響確有差異——個人與營利事業的適用方式不同，營利事業的債券利息通常仍須計入其所得課稅、扣繳稅款得予抵繳——但這與是否為境外投資人並非同一件事。

(C)正確。分離課稅的精神是「就源扣繳、扣完了結」：稅在給付利息時一次結清，不再與其他所得合併適用累進稅率。對高所得的個人投資人而言，這使債券利息的實際稅負與其邊際稅率脫鉤，是影響債券相對吸引力的重要因素。

(D)錯誤。分離課稅是課稅方式而非免稅，稅款仍須於給付時扣繳，只是不再併計。

7. 某公司承作名目本金 5 億元的利率交換，支付固定利率 2.50%、收取 6 個月期浮動利率，每半年（以 180/360 計息）交換一次。若本期浮動利率重設為 3.20%，本期結算時該公司的淨現金流為何？
  1. (A)淨收 1,750,000 元
  2. (B)淨付 1,750,000 元
  3. (C)淨收 3,500,000 元
  4. (D)淨收 14,250,000 元
解析

(A)正確。固定端＝5 億×2.50%×0.5＝6,250,000 元（支付）；浮動端＝5 億×3.20%×0.5＝8,000,000 元（收取）。利率交換採淨額交割，該公司本期淨收 1,750,000 元。

(B)錯誤。方向相反。本期浮動利率 3.20% 高於所支付的固定利率 2.50%，支付固定的一方在本期是受益方而非付款方。

(C)錯誤。3,500,000 元是以 5 億×0.70% 按整年計算的結果，未乘上 180/360 的期間比例。

(D)錯誤。14,250,000 元是把兩端利息加總。利率交換不交換本金、利息採淨額交割，不會出現兩端相加的現金流。

8. 某發行人的 5 年期 CDS 利差為 120 個基本點，其相同天期債券相對於無風險利率的信用利差為 160 個基本點。若不考慮交易成本與融資限制，下列何者為此情形下典型的基差交易？
  1. (A)基差為負，賣出該債券並同時買進 CDS 保護，鎖住約 280 個基本點淨利差
  2. (B)基差為零，因為 CDS 利差與債券信用利差在無套利下必然趨於相等
  3. (C)基差為負，買進該債券並同時買進 CDS 保護，鎖住約 40 個基本點淨利差
  4. (D)基差為正，賣出該債券並同時賣出 CDS 保護，鎖住約 40 個基本點淨利差
解析

(A)錯誤。基差方向判斷正確，但操作方向相反；且兩個利差不能相加，賣出債券並買進保護等於同時付出兩筆成本。

(B)錯誤。受融資成本、交割券選擇權、流動性與市場分割等因素影響，CDS 利差與債券信用利差經常偏離，基差不為零正是這類交易存在的前提。

(C)正確。CDS 基差＝CDS 利差－債券信用利差＝120－160＝－40 個基本點，屬於負基差。此時買進債券可收取 160 bp，同時支付 120 bp 買進保護，鎖住約 40 bp 的淨收益，並大致中和了違約風險，是典型的負基差交易。

(D)錯誤。CDS 利差低於債券信用利差時基差為負而非為正；且賣出債券並賣出保護會同時付出 160 bp、收取 120 bp，反而形成淨損失。

9. 巨災債券（catastrophe bond）的核心設計邏輯為何？
  1. (A)以巨災保險理賠應收款為擔保，投資人於任何情況下均可於到期時全額收回本金
  2. (B)由政府提供最終擔保並於災害發生時代為清償，故其殖利率明顯低於公債
  3. (C)由再保險人保證本金，投資人僅承擔與一般公司債相同層級的發行人信用風險
  4. (D)將特定巨災風險移轉予資本市場投資人，觸發事件發生時減免本息以支應損失
解析

(A)錯誤。若在任何情況下都能全額收回本金，風險就沒有被移轉，巨災債券也就失去存在意義；本金可能損失正是其設計核心。

(B)錯誤。巨災債券並無政府擔保，其殖利率明顯高於公債，正是對承擔巨災風險的補償。

(C)錯誤。巨災債券的本金正是風險承擔的標的，並無保證；投資人所承擔的主要並非發行人信用風險，而是約定災害是否發生。

(D)正確。保險人或再保險人透過特殊目的機構發行巨災債券，將颶風、地震等特定巨災風險移轉給資本市場：未觸發時投資人領取較高票息，觸發時本息被減免以支應理賠。其報酬與傳統股債的相關性低，故對投資組合具有分散效果。

10. 永續債券的外部審查有多種型態，下列關於「第二方意見（second party opinion）」的敘述何者正確？
  1. (A)由主管機關就該檔債券是否准予於集中市場掛牌交易所作成的行政處分
  2. (B)由簽證會計師就發行人財務報表是否允當表達所出具的無保留查核意見
  3. (C)由具永續專業的獨立機構評估發行人架構是否符合相關原則並出具意見
  4. (D)由信用評等機構就發行人的違約機率所給予的長期債務信用評等等級
解析

(A)錯誤。掛牌與否是交易所或櫃買中心的市場准入決定，屬於審查制度的一環，並非外部審查機構所出具的專業意見。

(B)錯誤。財務報表查核意見處理的是財務資訊的允當性，與債券的永續屬性無涉，兩者的專業領域與受查對象都不同。

11. 某債券面額 100 元、票面利率 10%、每年付息一次，剛付完息且尚有 2 年到期，市場殖利率為 8%，目前價格約 103.57 元。若殖利率始終維持 8% 不變，則一年後（剛收到票息時）該債券價格約為多少？

  3. (C)105.30 元

13. 關於可贖回債券（callable bond）與可賣回債券（putable bond）對投資人的影響，下列敘述何者正確？
  1. (A)兩者的選擇權皆屬投資人，投資人可自行選擇提前終止，故殖利率皆低於條件相同的普通債券
  2. (B)可贖回債券的贖回權屬投資人，投資人可在利率下跌時要求提前償還，故其殖利率低於普通債券
  3. (C)可贖回債券的贖回權屬發行人，投資人承擔提前贖回風險，故其殖利率通常高於條件相同的普通債券
  4. (D)可賣回債券的賣回權屬發行人，發行人可在利率下跌時提前清償，故投資人須接受較低殖利率
解析

(A)錯誤。只有賣回權屬投資人；贖回權屬發行人，投資人無權自行終止一檔可贖回債券，兩種選擇權對殖利率的影響方向恰好相反。

(B)錯誤。贖回權屬「發行人」而非投資人，且「在利率下跌時要求提前償還」也不是投資人的權利；實際上是發行人在利率下跌時行使贖回權，使投資人被迫在低利率環境下把收回的本金再投資。

(C)正確。可贖回債券相當於投資人賣出一個買回選擇權給發行人，投資人必須被補償，故其殖利率高於（價格低於）條件相同的普通債券。投資人同時承擔再投資風險與價格上檔被贖回價格壓抑的損失。

(D)錯誤。賣回權屬「投資人」，投資人可在利率上升或發行人信用惡化時要求提前償還；本選項所描述的「發行人在利率下跌時提前清償」其實是贖回權。正因權利歸投資人，可賣回債券的殖利率才低於條件相同的普通債券。

14. 對於含選擇權的債券（如可贖回債券、不動產抵押貸款證券），為何應改用有效存續期間與有效凸性，而非修正存續期間與一般凸性？
  1. (A)因為有效存續期間可直接由市場報價讀出，不需要任何評價模型，計算上比修正存續期間簡便
  2. (B)因為含選擇權債券的價格與殖利率呈完全線性關係，一階近似不再有誤差，不需要凸性
  3. (C)因為含選擇權債券沒有法定到期日，現金流的期數無法確定，因此無法計算加權平均回收時點
  4. (D)因為修正存續期間假設現金流不隨殖利率改變，但含選擇權債券的現金流本身會因利率變動而改變
解析

(A)錯誤。恰好相反。市場報價只給出一個價格，有效存續期間必須先以二元利率樹或蒙地卡羅等模型在利率上下移動後重新評價才能求得，計算成本高於修正存續期間。

(B)錯誤。含選擇權債券的價格—殖利率關係不但不是線性，還可能出現負凸性；正因為非線性且一階近似的誤差更大，才需要有效凸性來衡量。

(C)錯誤。可贖回債券仍有法定到期日，現金流的期數上限是確定的；問題不在於沒有到期日，而在於到期前現金流有可能被提前終止或改變。

(D)正確。修正存續期間是由一組固定的現金流序列推導出來的，隱含「殖利率變動不影響現金流」的假設。含選擇權債券在利率變動時，發行人贖回或借款人提前還款的行為會改變現金流，因此必須把利率上下移動後重新評價的價格代入 (V₋−V₊)÷(2×V₀×Δy)，即有效存續期間；有效凸性亦同理。
