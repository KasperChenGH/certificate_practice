1. 非公開發行股份有限公司之董事，其每任任期最長為多久？
  1. (A)一年
  2. (B)三年
  3. (C)五年
  4. (D)七年
解析

(A)錯誤。公司法第一百九十五條把董事每任任期的上限訂為三年，一年只是章程可以自訂的較短任期，並非法律的天花板；若誤以為一年屆滿即當然解任，會錯估董事會的改選時點。

(B)正確。公司法第一百九十五條規定董事任期不得逾三年，但得連選連任，此限制不分公開發行或非公開發行股份有限公司均適用。定期改選是股東對經營層行使人事監督的基本機制，任期若拉得太長，股東就難以用改選汰換不適任的董事。

(C)錯誤。五年超過公司法三年的上限，章程即使訂為五年，逾三年的部分不生效力。任期屆滿而不及改選時，法律是讓原董事延長執行職務至改選就任為止，而不是承認更長的任期。

(D)錯誤。七年更遠高於三年的法定上限。會選到這個數字，多半是把特許事業的經營年限或公司債的發行年限，與董事的任期限制混為一談。

2. 下列何者不屬於股份有限公司派發建設股息之要件？
  1. (A)公司依其業務性質，自設立登記後，需二年以上之開業準備期間
  2. (B)須經主管機關許可
  3. (C)章程規定得分派
  4. (D)公司已開始營業
解析

(A)錯誤。公司法建設股息的規定，正是以「依其業務性質，自設立登記後需二年以上之準備始能開始營業」為前提，這是法定要件之一，不是不屬於的項目。

(B)錯誤。建設股息是在尚無盈餘時就先分派，實質上等於動用股本退還股東，對債權人保障影響重大，因此必須經主管機關許可，屬於法定要件。

(C)錯誤。建設股息須有章程的分派依據，公司不得僅憑董事會或股東會臨時決議發放；章程規定得分派是條文明列的要件之一。

(D)正確。建設股息的制度設計，是讓籌建期間特別長的公司在「開始營業前」先分派股息給股東，要件是尚未開業，而非已開始營業。一旦公司已開始營業，就回到以盈餘分派股息的常規，不再適用這個例外。其用意在於讓鐵路、電廠這類長期建設型事業，在漫長的無收入期間仍募得到股本。

3. 證券投資信託事業證券投資顧問事業經營全權委託投資業務，下列行為規範何者正確？
  1. (A)與客戶為投資有價證券收益共享或損失分擔之約定
  2. (B)利用客戶之帳戶，為他人買賣有價證券
  3. (C)將全權委託投資契約之全部或部分複委任他人履行或轉讓他人
  4. (D)依投資分析報告作成投資決定書
解析

(A)錯誤。與客戶約定分享收益或分擔損失，屬全權委託投資業務明文禁止之行為。

(B)錯誤。利用客戶帳戶為他人買賣有價證券，屬挪用客戶帳戶的禁止行為。

(C)錯誤。全權委託投資契約具高度信任關係，不得將契約之全部或一部複委任他人履行或轉讓他人。

(D)正確。受任人應依投資分析報告作成投資決定書，再據以執行下單。這套「分析報告—投資決定書—執行紀錄」三段式留痕，是要求投資決策有客觀依據並可事後查核，防止受任人恣意或為自己利益操作客戶資產。

4. 依公司法，公司為董事投保責任險部分，下列敘述何者正確？
  1. (A)相關重要內容，應報告股東會
  2. (B)相關重要內容，應報告董事會
  3. (C)相關重要內容，應報告監察人
  4. (D)以上皆非
解析

(A)錯誤。條文要求的報告對象是「最近一次董事會」，不是股東會。投保責任保險屬於董事會層次的資訊，股東會的報告事項另有規定，兩者不可互換。

(B)正確。公司法第一百九十三條之一規定，公司為董事投保責任保險或續保後，應將保險金額、承保範圍及保險費率等重要內容，提最近一次董事會報告。採事後報告而非事前同意，是在不妨礙公司即時投保的前提下，讓全體董事知悉這筆由公司出錢、受益人卻是董事個人的支出，避免成為變相的利益輸送。

(C)錯誤。監察人的職權是監督業務執行與查核財務，條文並未把監察人列為此項報告的對象。監察人固然得列席董事會，但那是列席權，與法定的報告義務對象是兩回事。

(D)錯誤。公司法第一百九十三條之一已明定報告對象為董事會，選項B與條文相符，因此並非以上皆非；這種選項只有在前三項全部與法條不合時才會成立。

5. 公開收購人與其關係人於公開收購後，所持有被收購公司已發行股份總數超過該公司已發行股份總數百分之多少比例者，得以書面記明提議事項及理由，請求董事會召集股東臨時會？
  1. (A)百分之二十
  2. (B)百分之三十
  3. (C)百分之四十
  4. (D)百分之五十
解析

(A)錯誤。百分之二十是強制公開收購制度所使用的門檻（預定於短期內取得公開發行公司已發行股份達一定比例者，應採公開收購方式為之），與收購完成後能否請求董事會召集股東臨時會是兩套不同的規定。

(B)錯誤。持股三成雖已是最大股東，表決時仍可能被其他股東聯合否決，法律因此沒有賦予這項請求權。未過半數的股東若想召集股東臨時會，仍須循公司法少數股東請求董事會召集、或報經主管機關許可自行召集的途徑。

(C)錯誤。四成同樣未過半，無法確保股東會決議能通過，而條文設定的正是過半數的控制權。會選到四成，通常是把商業上的「實質控制」感覺，套到法條明確的比例門檻上。

(D)正確。證券交易法第四十三條之五規定，公開收購人與其關係人於公開收購後，所持有被收購公司已發行股份總數超過百分之五十者，得以書面記明提議事項及理由，請求董事會召集股東臨時會，不受公司法第一百七十三條第一項的限制。理由是收購人既已取得過半控制權，遲早能改組董事會，讓他直接請求召集可縮短經營權交接的空窗期，避免舊董事會拖延。

6. 因減少資本換發新股票時，公司於減資登記後，至少應定多久以上之期限，通知各股東換取，並聲明逾期不換取者，喪失其股東之權利？
  1. (A)六個月
  2. (B)一年
  3. (C)二年
  4. (D)三年
解析

(A)正確。因減資換發新股票者，公司應於減資登記後定六個月以上之期限，通知各股東換取，並聲明逾期不換取者喪失股東權利。因為逾期效果極為嚴厲（喪失股東權利），法律要求給予相當充裕的期間，使股東有實際知悉並辦理的機會。

(B)錯誤。一年並非法定之最短換票期限；法定下限較此為短，公司自得訂定更長期限。

(C)錯誤。二年並非法定之最短換票期限，法律所定之最低期間並無如此之長。

(D)錯誤。三年並非法定之最短換票期限，公司雖得自訂較長期限，但非法定下限。

7. 董事會不為或不能行使職權，致公司有受損害之虞時，法院因利害關係人或檢察官之聲請，得選任幾人充任臨時管理人，代行董事長及董事會之職權？
  1. (A)一人
  2. (B)五人
  3. (C)十人
  4. (D)無限制
解析

(A)錯誤。條文寫的是「一人以上」，一人是下限而不是上限；把「以上」兩字讀漏，就會得到這個答案。實務上公司業務龐雜時，法院確實可能選任數人分擔。

(B)錯誤。五人是證券交易法對已依本法發行股票公司所設的董事最低席次，屬於董事會組成的規定，與法院選任臨時管理人的人數無關。

(C)錯誤。法律並未訂十人之類的具體上限。臨時管理人是公司治理癱瘓時的過渡性緊急安排，人數愈多反而愈難迅速決策，立法上交由法院依個案裁量，而非硬性規定一個數字。

(D)正確。公司法第二百零八條之一規定，董事會不為或不能行使職權致公司有受損害之虞時，法院因利害關係人或檢察官之聲請，得選任「一人以上」之臨時管理人，代行董事長及董事會職權，條文未設人數上限。留給法院裁量，是因為公司規模與治理癱瘓的程度差異極大，有的只需一人代行，有的需要數人分擔各項業務。

  2. (B)證券投資信託事業應於證券投資信託基金成立日起算三十日內，製作並交付受益憑證予申購人
  3. (C)發行受益憑證得不印製實體，而以帳簿劃撥方式交付之
  4. (D)證券投資信託基金受益憑證之交付，應由證券投資信託事業依各基金之證券投資信託契約約定為之，不得委由基金銷售機構辦理

9. 關於有價證券終止上市之規定，下列敘述何者不正確？
  1. (A)證券交易所得依法令或上市契約之規定終止有價證券上市，並應報請主管機關備查
  2. (B)於證券交易所上市之有價證券，其發行人得依上市契約申請終止上市
  3. (C)於證券交易所上市有價證券之公司，有違反證券交易法時，主管機關為保護公益或投資人利益，得命令該證券交易所終止該有價證券之上市
  4. (D)發行人依上市契約申請終止有價證券上市，主管機關核准時，應指定生效日期，並視生效日期之次日為上市契約終止之日期
解析

(A)錯誤（本敘述正確）。證券交易所得依法令或上市契約之規定終止上市，並應報請主管機關備查。

(B)錯誤（本敘述正確）。上市有價證券之發行人得依上市契約申請終止上市。

(C)錯誤（本敘述正確）。上市公司違反證券交易法時，主管機關為保護公益或投資人利益，得命令證券交易所終止其上市。

(D)正確（即敘述有誤者）。主管機關核准終止上市並指定生效日期時，上市契約應於該生效日終止，而非「生效日之次日」；若以次日為終止日，將出現終止已生效而契約仍存續一日的矛盾。

10. 依發行人募集與發行有價證券處理準則之規定，發行人募集與發行有價證券，經發現自申報生效通知到達之日起，逾三個月尚未募足並收足現金款項者，金管會得為下列如何之處分？
