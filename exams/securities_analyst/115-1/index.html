1. 股票未公開發行之甲股份有限公司（下稱甲公司）實收資本額新臺幣5 億元，首次辦理轉投資，擬轉投資乙股份有限公司（下稱乙公司），甲公司章程未規定轉投資限額，甲公司亦未經股東會決議，請問：依公司法規定，甲公司轉投資金額上限為何？
  1. (A)1 億元
  2. (B)2 億元
  3. (C)3 億元
  4. (D)無限制
解析

(A)錯誤。一億元是實收資本額五億元的百分之二十，公司法的轉投資條文從未採用這個比率，無論公開發行與否都對不上。

(B)錯誤。二億元是五億元的百分之四十，那是公司法第十三條對「公開發行股票之公司」所設的轉投資上限；甲公司股票未公開發行，不在適用範圍內。

(C)錯誤。三億元是百分之六十，既不是法定比率，也高於公開發行公司適用的百分之四十，兩邊都套不上。

(D)正確。公司法第十三條在一○七年修正後，把不得超過實收股本百分之四十的轉投資上限限縮為「公開發行股票之公司」才適用。甲公司股票未公開發行，縱使章程未訂限額、亦未經股東會決議，轉投資金額仍不受該條比率限制。立法理由是非公開發行公司股東人數少、監督關係緊密，可由股東自治處理，不必以法定比例代替。

2. 股票上市之X 公司擬就該公司之董事甲短線交易所獲利益行使歸入權，最遲自甲獲得利益之日起多久期間不行使而消滅？
  1. (A)六個月
  2. (B)一年
  3. (C)二年
  4. (D)五年
解析

(A)錯誤。六個月是短線交易的認定期間，即內部人取得後六個月內再賣出、或賣出後六個月內再買進，講的是行為的時間範圍，不是請求權的時效。

(B)錯誤。一年短於法定期間；公司往往要比對內部人持股申報與交易資料才會察覺短線交易，時效若只有一年，請求權可能在發現前就先消滅。

(C)正確。證券交易法第一五七條規定公司得請求內部人交還六個月內買賣所得的利益，該請求權自獲得利益之日起二年間不行使而消滅。採較短的時效，是因為短線交易的事實可由申報與交易紀錄查得，宜讓法律關係早日確定，也促使公司及得代位行使的股東及時追償。

(D)錯誤。五年不是本條所定的時效；歸入權刻意採取比一般民事請求權更短的期間，避免內部人長期處於責任未定的狀態。

3. 股票未公開發行之甲股份有限公司，較法定期間晚一日寄出股東常會之開會通知，若該次股東會仍作成決議，依公司法規定，該決議之法律效果為何？
  1. (A)決議無效
  2. (B)決議得撤銷
  3. (C)決議不成立
  4. (D)決議待補正
解析

(A)錯誤。決議無效係決議「內容」違反法令或章程之效果，本題瑕疵發生在召集程序。

(B)正確。開會通知未於法定期間前寄出，屬召集程序違反法令，效果為決議「得撤銷」，股東須於決議之日起三十日內訴請法院撤銷，未訴請撤銷者決議仍屬有效。程序瑕疵不當然使決議自始無效，是為兼顧交易安全與既成法律關係之安定。

(C)錯誤。決議不成立係指根本欠缺決議成立之外觀（如未達出席定額），本件已作成決議。

(D)錯誤。公司法並無「決議待補正」此一法律效果。

4. 甲股份有限公司擬於股東會提案讓與全部公司財產，該議案應經董事會如何決議通過，始得提出於股東會？
  1. (A)三分之一以上董事出席董事會，以出席董事過半數同意之決議
  2. (B)過半數董事出席董事會，以出席董事過半數同意之決議
  3. (C)三分之二以上董事出席董事會，以出席董事過半數同意之決議
  4. (D)三分之二以上董事出席董事會，以出席董事四分之三以上同意之決議
解析

(A)錯誤。三分之一以上董事出席不是公司法任何一種董事會決議的門檻；即便是一般議案，第二○六條也要求過半數董事出席。

(B)錯誤。過半數董事出席、出席董事過半數同意，是公司法第二○六條的普通董事會決議方式，適用於一般議案；讓與全部營業或財產另有加重規定。

(C)正確。讓與全部或主要部分之營業或財產屬公司法第一八五條的重大事項，股東會須有代表已發行股份總數三分之二以上股東出席、經出席股東表決權過半數同意；同條並規定該議案應由有三分之二以上董事出席之董事會，以出席董事過半數之決議提出於股東會。提高董事會的出席門檻，是不讓少數董事就把攸關公司存續的議案送上股東會。

(D)錯誤。三分之二的出席門檻正確，但同意門檻法條寫的是出席董事過半數，並未要求出席董事四分之三以上同意。

6. 公開發行股票之X 公司董事甲選任時持股10,000 股，任期中買進50,000 股，以其中30,000 股設質，甲參加股東會時，其不得行使表決權之股數為何？
  1. (A)5,000 股
  2. (B)10,000 股
  3. (C)20,000 股
  4. (D)25,000 股
解析

(A)正確。限制係以「選任當時所持有之股份」為計算基礎：甲選任時持股10,000股，其二分之一為5,000股，設質數已超過該半數，超過部分即5,000股不得行使表決權。任期中新買進的50,000股不列入計算，因為本條要防的是董事把當選所憑藉的持股質押套現後，仍保有原有表決影響力。

(B)錯誤。10,000股為甲選任時之全部持股，並非「超過二分之一」之部分。

(C)錯誤。20,000股無對應之計算基礎。

(D)錯誤。25,000股係以設質總數30,000股減去5,000股計得，惟本條之計算範圍限於選任當時所持有之股份，不含任期中買進者。

  1. (A)30 日
  2. (B)45 日
  3. (C)60 日
  4. (D)90 日
解析

(A)錯誤。三十日連召集程序都走不完：公開發行公司股東臨時會須於十五日前通知、辦理停止過戶並編製股東名冊，還要完成獨立董事的提名與資格審查。

(B)錯誤。四十五日是公開發行公司季度財務報告公告申報常見的天數，證券交易法對獨立董事全體解任後召開股東臨時會所定的期間並非四十五日。

(C)正確。依證券交易法第十四條之二，獨立董事因故解任致人數不足者，應於最近一次股東會補選；但獨立董事全體解任時，公司應自事實發生之日起六十日內召開股東臨時會補選。全體解任等於審計委員會與獨立監督機制全面停擺，因此不能等到下次股東常會，必須在六十日內補足。

(D)錯誤。九十日超過法定期間；獨立董事全部解任期間審計委員會無法運作，公司治理出現空窗，法規不容許拖到三個月才補選。

8. 下列關於證券交易法中審計委員會之敘述何者錯誤？
  1. (A)由全體獨立董事組成
  2. (B)人數不得少於三人
  3. (C)設召集人一人
  4. (D)召集人應具備會計或財務專長
解析

(A)錯誤（此項敘述無誤）。審計委員會確實應由全體獨立董事組成，不容非獨立董事參與，才能確保對經營階層的監督具有獨立性。

(B)錯誤（此項敘述無誤）。人數確實不得少於三人；三人以上才能形成合議與多數決，分散單一委員的影響力。

(C)錯誤（此項敘述無誤）。委員會確實設召集人一人，負責召集及主持會議、對外代表委員會行使職權。

(D)正確（此項敘述有誤）。證券交易法第十四條之四規定審計委員會由全體獨立董事組成、人數不得少於三人、其中一人為召集人，且「至少一人」應具備會計或財務專長。法條要求的是委員會中有成員具備該專長，並未限定必須由召集人具備。

9. 股票上市之甲股份有限公司因有正當理由致審計委員會無法召開時，該公司委任簽證會計師之議案，如何決定？

(A)錯誤。二分之一是審計委員會內部的同意比率（全體成員二分之一以上同意後提董事會決議），不是委員會無法召開時改由董事會決定的門檻。

(B)正確。委任簽證會計師屬證券交易法第十四條之五應經審計委員會全體成員二分之一以上同意並提董事會決議的事項；依同條及審計委員會行使職權辦法，公司因有正當理由致審計委員會無法召開時，該等事項得由全體董事三分之二以上同意行之。門檻高於一般董事會決議，是在少了獨立董事把關時，以更高的董事同意比例作為替代。

(D)錯誤。徵詢個別獨立董事的意見不是合法的替代程序，公司治理要求的是合議制的決議與可稽核的議事紀錄，不能以蒐集個別意見取代表決。

11. 甲公司為公開發行公司，依證券交易法規定，其設置董事最少為幾人？

  2. (B)減弱
  3. (C)不變
  4. (D)不一定
解析

(A)正確。依Mundell-Fleming模型，浮動匯率下擴張性貨幣政策使LM右移、國內利率下滑，資金外流推動本幣貶值，淨出口增加又使IS右移，產出增幅大於封閉體系。資本移動性越高，同樣的利差就引發越大的資金外流與貶值，匯率這條傳導管道越強，政策效果因而增強；資本完全移動時效果最大。

(B)錯誤。效果被削弱的是固定匯率制度：貨幣寬鬆造成的貶值壓力迫使央行賣出外匯、買回本幣，貨幣基數又被抵銷回去，且資本移動性越高抵銷得越快，極端情況下貨幣政策完全失效。此選項把固定匯率的結論套到浮動匯率上。

(C)錯誤。資本移動性決定資金對利差的敏感度，也就決定貶值幅度與淨出口的反應大小，它直接進入政策的傳導機制，不可能讓效果維持原樣；效果不受影響的情形只出現在資本完全不移動的假設下。

(D)錯誤。在Mundell-Fleming架構中方向是明確的：浮動匯率搭配高資本移動性會強化貨幣政策、同時弱化財政政策（貶值效果反轉為升值排擠出口）；結論既然確定，就不需以「不一定」迴避。
