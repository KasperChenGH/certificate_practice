1. 股票上市之甲股份有限公司設三席獨立董事，若三位獨立董事同時請辭，該公司應自事實發生之日起幾日內召開股東臨時會補選？
  1. (A)30 日
  2. (B)45 日
  3. (C)60 日
  4. (D)90 日
解析

(A)錯誤。三十日連召集程序都走不完：公開發行公司股東臨時會須於十五日前通知、辦理停止過戶並編製股東名冊，還要完成獨立董事的提名與資格審查。

(B)錯誤。四十五日是公開發行公司季度財務報告公告申報常見的天數，證券交易法對獨立董事全體解任後召開股東臨時會所定的期間並非四十五日。

(C)正確。依證券交易法第十四條之二，獨立董事因故解任致人數不足者，應於最近一次股東會補選；但獨立董事全體解任時，公司應自事實發生之日起六十日內召開股東臨時會補選。全體解任等於審計委員會與獨立監督機制全面停擺，因此不能等到下次股東常會，必須在六十日內補足。

(D)錯誤。九十日超過法定期間；獨立董事全部解任期間審計委員會無法運作，公司治理出現空窗，法規不容許拖到三個月才補選。

115年第1次｜證券交易相關法規與實務｜第 7 題
2. 證券投資信託及顧問法規定，證券投資信託及顧問事業侵權行為之損害賠償請求權，自有請求權人知有得受賠償之原因起幾年間不行使而消滅？
  1. (A)一年
  2. (B)二年
  3. (C)三年
  4. (D)四年
解析

(A)錯誤。一年短於本法所定的期間；投資損失往往要經過對帳、比對淨值與交易紀錄才會被發現，一年的窗口對請求權人過於嚴苛。

(B)正確。證券投資信託及顧問法就該等事業侵權行為的損害賠償請求權，規定自有請求權人知有得受賠償之原因起二年間不行使而消滅，與民法第一九七條一般侵權行為「自知有損害及賠償義務人時起二年」的短期時效一致。採短時效，是因為金融糾紛所依賴的交易紀錄、對帳單與從業人員說明都有保存年限，拖久了舉證與責任認定都會困難。

(C)錯誤。三年是票據等若干請求權採用的時效年期，本法對侵權損害賠償採的是與民法一致的短期時效，不是三年。

(D)錯誤。四年不是我國民事時效常見的年期，也不是本法所定；知悉後起算的短期時效與損害發生後起算的長期時效是兩個不同的期間，不能混用。

115年第1次｜證券交易相關法規與實務｜第 19 題
3. 依公司法，公司為董事投保責任險部分，下列敘述何者正確？
  1. (A)相關重要內容，應報告股東會
  2. (B)相關重要內容，應報告董事會
  3. (C)相關重要內容，應報告監察人
  4. (D)以上皆非
解析

(A)錯誤。條文要求的報告對象是「最近一次董事會」，不是股東會。投保責任保險屬於董事會層次的資訊，股東會的報告事項另有規定，兩者不可互換。

(B)正確。公司法第一百九十三條之一規定，公司為董事投保責任保險或續保後，應將保險金額、承保範圍及保險費率等重要內容，提最近一次董事會報告。採事後報告而非事前同意，是在不妨礙公司即時投保的前提下，讓全體董事知悉這筆由公司出錢、受益人卻是董事個人的支出，避免成為變相的利益輸送。

(C)錯誤。監察人的職權是監督業務執行與查核財務，條文並未把監察人列為此項報告的對象。監察人固然得列席董事會，但那是列席權，與法定的報告義務對象是兩回事。

(D)錯誤。公司法第一百九十三條之一已明定報告對象為董事會，選項B與條文相符，因此並非以上皆非；這種選項只有在前三項全部與法條不合時才會成立。

115年第2次｜證券交易相關法規與實務｜第 4 題
4. X 公司為一家從事運動器材販售之公開發行公司。依證券交易法之規定，X 公司應於每會計年度終了後多久內，向主管機關申報內部控制聲明書？
  1. (A)一個月
  2. (B)三個月
  3. (C)四個月
  4. (D)六個月
解析

(A)錯誤。一個月內連年度財務報告的查核簽證都尚未完成，公司無從據以評估整個年度內部控制制度的有效性，法規並未設這麼短的期限。

(B)正確。依公開發行公司建立內部控制制度處理準則第二十四條，公司應於每會計年度終了後三個月內，辦理內部控制制度聲明書的公告申報。這個期限與年度財務報告的申報期限一致，用意是讓投資人在看到財報數字的同時，也看得到公司自我評估「產生這些數字的內控是否有效」的結論。

(C)錯誤。四個月會使聲明書晚於年度財務報告公告，兩者脫鉤後就失去併同揭露、相互印證的意義；法規訂的是三個月。

(D)錯誤。六個月是公司法規定股東常會應於每會計年度終了後召開的期限，被誤植到內部控制聲明書的申報上；聲明書必須在股東常會前就完成公告，股東開會時才有資訊可用。

115年第2次｜證券交易相關法規與實務｜第 17 題
5. X 上櫃公司公開發行新股，順利完成增資後，股價立即暴跌，受損害之投資人欲援引證券交易法有關公開說明書不實之規定請求賠償，下列何者非屬證券交易法第32 條規定可求償之對象？
  1. (A)X 公司該發行案證券承銷商
  2. (B)X 公司
  3. (C)未在公開說明書上簽章之X 公司職員
  4. (D)X 公司負責人
解析

(A)錯誤（屬求償對象）。該次發行案之證券承銷商就公開說明書之不實內容應負賠償責任。

(B)錯誤（屬求償對象）。發行人X公司為公開說明書之編製主體，應負賠償責任。

(C)正確（即非求償對象者）。發行人之職員須「曾在公開說明書上簽章以證實其所載內容」者，始列為賠償義務人；未簽章之職員不在其列。責任範圍以有無為內容背書為界，是因為簽章代表對外承擔真實性擔保，未簽章者並未向投資人作出任何表示。

(D)錯誤（屬求償對象）。發行人之負責人為法定賠償義務人之一。

115年第2次｜證券交易相關法規與實務｜第 29 題
6. 為了在持有現貨資產的同時增加額外的收益(收取權利金)，並提供部位部分的下檔保護，某經理人決定在衍生性金融商品市場上建立一個「掩護性買權(covered call)」部位。此一交易策略的具體作法應為何？
  1. (A)買進股票並買進買權
  2. (B)買進股票並賣出買權
  3. (C)賣空股票並買進買權
  4. (D)賣空股票並賣出買權
解析

(A)錯誤。買進股票再買進買權是付出權利金加碼作多，沒有任何權利金收入，也不提供下檔保護；要保護下檔應搭配買進賣權（protective put）。

(B)正確。掩護性買權是持有標的股票的同時賣出該股的買權：賣出買權收取的權利金即為額外收益，股價下跌時這筆權利金可抵銷部分損失，形成有限的下檔保護。代價是股價大漲超過履約價時須依約交出股票，上檔獲利被鎖在履約價加權利金；「掩護」指的是手上有現股足以交割，不是無券裸賣。

(C)錯誤。賣空股票搭配買進買權是為放空部位買保險，用買權鎖住被軋空的風險，資金流向是付出權利金而非收取權利金。

(D)錯誤。賣空股票又賣出買權等於兩邊都押股價不漲，方向重疊而非互相掩護，且沒有現股可供交割，上檔風險理論上無限。

115年第1次｜投資學｜第 7 題
7. 當台股加權指數處於高檔震盪，某投資人預期未來走勢為盤整，最適合賣出下列何種選擇權部位以收取權利金？
  1. (A)僅買進買權
  2. (B)同時買進買權與賣權(跨式買進)
  3. (C)同時賣出買權與賣權(跨式賣出)
  4. (D)僅買進賣權
解析

(A)錯誤。買進買權是支付權利金、賭大漲的部位，時間價值流失對買方不利，與題目要「收取權利金」的需求相反。

(B)錯誤。買進跨式同時付出兩筆權利金，必須指數大幅偏離任一方向才賺，正是預期盤整時最該避開的部位。

(C)正確。同時賣出相同履約價的買權與賣權（賣出跨式）一次收進兩筆權利金，只要到期指數落在兩個損益平衡點之間即獲利，並靠時間價值衰減（Theta 為正）賺錢。代價是兩端風險理論上無限，一旦真的走出趨勢虧損擴大很快，必須嚴設停損與保證金。

(D)錯誤。買進賣權是付出權利金做空的部位，要大跌才有利；盤整時權利金會隨時間歸零，損失的正是付出的權利金。

115年第1次｜投資學｜第 19 題
8. 今張先生以每股140元，融券賣出台積電股票五千股，融券保證金成數為九成。若張先生在一個月後，以每股148元，融券買進台積電五千股，試計算張先生實現報酬率約為多少(假設不考慮證券商手續費率、證券交易稅率、融券手續費率與融券利率)？
  1. (A)-5.71%
  2. (B)-6.35%
  3. (C)-11.43%
  4. (D)-15.71%
解析

(A)錯誤。−5.71%＝−40,000÷700,000，分母用了賣出成交總額；融券實際投入的是保證金 630,000，不是整筆股票市值。

(B)正確。融券賣出價款＝140×5,000＝700,000，保證金成數九成表示自備 700,000×90%＝630,000。以 148 元回補，虧損＝(148−140)×5,000＝40,000，報酬率＝−40,000÷630,000≈−6.35%。分母用自有資金才反映真實的權益報酬；成數愈低槓桿愈大，同樣價差的報酬率就愈誇張。

(C)錯誤。−11.43%＝−40,000÷350,000，把保證金當成五成（融資自備款常見的成數）；本題明訂融券保證金成數為九成。

(D)錯誤。−15.71%＝−110,000÷700,000，把回補總價 740,000 減保證金 630,000 的差額 110,000 當成虧損；實際虧損只有價差 40,000，分母也應是 630,000。

115年第1次｜投資學｜第 32 題
9. 一個名目本金為$1,000,000 的三年期利率交換(IRS)，每半年交換一次，交換利率為3%。假設浮動利率一直維持在2.5%，則此IRS 每期的現金流量是：
  1. (A)買方支付給賣方$10,000
  2. (B)賣方支付給買方$5,000
  3. (C)買方支付給賣方$2,500
  4. (D)賣方支付給買方$1,250
解析

(A)錯誤。$10,000是先把全年淨額算成1,000,000×0.5%＝$5,000，再誤乘「每年交換兩次」得來的。每年交換兩次的意思是把年利率折半計息，不是把年度淨額加倍。

(B)錯誤。$5,000是一整年的淨利差(1,000,000×0.5%)，不是每半年一期的金額；方向也相反——浮動利率2.5%低於固定利率3%時，支付固定的買方才是淨付款方。

(C)正確。IRS買方支付固定、收取浮動。每半年固定端付1,000,000×3%÷2＝$15,000，浮動端收1,000,000×2.5%÷2＝$12,500，淨額為買方付給賣方$2,500。實務上兩端以淨額交割，只結算利差而不交換本金，這正是名目本金被稱為「名目」的原因。
