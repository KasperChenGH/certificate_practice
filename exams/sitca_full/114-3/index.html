投信投顧相關法規　46 題

1. 對客戶委任交付或信託移轉之委託投資資產，就有價證券、證券相關商品或其他經主管機關核准項目之投資或交易為價值分析、投資判斷，並基於該投資判斷，為客戶執行投資或交易之業務。以上是形容下列何項業務？
  1. (A)證券融資業務
  2. (B)全權委託投資業務
  3. (C)信託業務
  4. (D)基金保管業務
解析

(A)錯誤。證券融資業務是提供資金供投資人買進有價證券，屬信用交易的授信行為，不涉及代客戶作成投資判斷。

(B)正確。題目描述的三個要素——就客戶委任交付或信託移轉之資產、為價值分析與投資判斷、並基於該判斷為客戶執行投資或交易——正是全權委託投資業務（代客操作）的法定定義。關鍵在於「判斷」與「執行」都由受任人為之，客戶不逐筆下指令。

(C)錯誤。信託業務的核心是財產權移轉與受託管理，不以投資判斷與執行為必要內涵。

(D)錯誤。基金保管業務僅為資產之保管與交割，保管機構不作投資判斷。

2. 投信公司擔任4 家境外基金管理機構之總代理人，並擔任其他境外基金之銷售機構以自己名義為投資人向總代理人申購境外基金者，需提存多少營業保證金？
  1. (A)新臺幣2,000 萬元
  2. (B)新臺幣3,000 萬元
  3. (C)新臺幣7,000 萬元
  4. (D)新臺幣1 億1,000 萬元
解析

(A)錯誤。新臺幣二千萬元是境外基金管理辦法第10條對「銷售機構以自己名義為投資人向總代理人申購境外基金」所定的營業保證金，只涵蓋銷售機構身分，沒有計入擔任四家總代理人應提存的九千萬元。

(B)錯誤。新臺幣三千萬元是擔任一家境外基金管理機構總代理人的營業保證金；本例擔任四家，且另有以自己名義申購的銷售機構身分，遠不止此數。

(C)錯誤。新臺幣七千萬元是擔任三家境外基金管理機構總代理人的提存額；四家應提存九千萬元，再加上以自己名義申購的銷售機構身分二千萬元，合計一億一千萬元。

(D)正確。境外基金管理辦法第10條規定總代理人依所代理的境外基金管理機構家數提存營業保證金：一家三千萬元、二家五千萬元、三家七千萬元、四家九千萬元，每多一家加二千萬元；銷售機構以自己名義為投資人向總代理人申購者，另提存二千萬元。擔任四家總代理人9,000萬＋銷售機構2,000萬＝新臺幣1億1,000萬元。營業保證金是投資人求償的擔保，代理家數越多、以自己名義經手投資人款項的風險越高，提存額就越多。

3. 下列有關投信事業對於基金資產運用之指示權之敘述何者正確？
  1. (A)得複委任他人代行
  2. (B)原則上不得複委任他人處理
  3. (C)不需盤點檢查保管機構所保管的基金資產
  4. (D)投信事業不得指示基金保管機構處分資產
解析

(A)錯誤。指示權具高度屬人性，不得任意複委任他人代行。

(B)正確。投信事業對基金資產之運用指示權，原則上不得複委任他人處理。受益人是基於對該投信事業專業能力的信賴而投資，若可任意轉手他人操作，信賴基礎即不復存在。

(C)錯誤。投信事業仍應盤點檢查保管機構所保管之基金資產，這是其對受益人的監督義務。

(D)錯誤。投信事業本即得指示基金保管機構處分資產，此正是運用指示權的內容。

4. 債券型基金資產組合之加權平均存續期間應在一年以上，但下列何者不在此限？
  1. (A)基金成立未滿三個月
  2. (B)信託契約終止日前三個月
  3. (C)基金成立未滿六個月
  4. (D)信託契約終止日前六個月
解析

(A)正確。證券投資信託基金管理辦法第29條規定債券型基金資產組合之加權平均存續期間應在一年以上，但基金成立未滿三個月、證券投資信託契約終止日前一個月或主要投資於正向浮動利率債券者不在此限。成立初期資金仍在建倉、部位未定，強求存續期間達標既不合理，也會逼經理人為湊數而買，所以給三個月的緩衝。

(B)錯誤。契約終止日前確有豁免，因為清算前須逐步轉為短天期資產以備償還受益人，但第29條給的期間是終止日前一個月，三個月把豁免期多放寬了兩個月。

(C)錯誤。成立初期的豁免只有三個月，六個月是把緩衝期加倍；三個月已足以把資金配置到位，半年還未達標就不是建倉問題而是投資策略問題。

(D)錯誤。終止日前的豁免只有一個月，六個月會讓基金在存續末段有半年可以全部改抱短券，與債券型基金應維持一年以上存續期間的本旨不符。

114年第3次｜投信投顧相關法規｜第 4 題
5. 槓桿型ETF 或反向型ETF 投資於基金受益憑證之總金額不得超過本基金淨資產價值之多少比例？
  1. (A)20%
  2. (B)30%
  3. (C)50%
  4. (D)70%
解析

(A)錯誤。20%是第10條第1項第11款對一般基金投資基金受益憑證的總額上限；槓桿型、反向型ETF依第37條之1得不受該款限制，改以30%為上限。

(B)正確。證券投資信託基金管理辦法第37條之1規定，槓桿型或反向型ETF投資於基金受益憑證之總金額得不受第10條一般20%上限的拘束，但不得超過本基金淨資產價值之30%。放寬是因為此類ETF常需透過其他ETF或基金取得標的曝險，仍設30%上限則是避免基金淪為層層堆疊、費用與風險來源難以辨識的組合。

(C)錯誤。50%會讓基金一半資產都是別的基金，形同組合型基金；組合型基金另有專門規範且以投資基金為本業，與槓桿反向ETF追蹤指數倍數的定位不同。

(D)錯誤。70%是多重資產型基金投資任一資產種類的總額上限（第31條之1），套到槓桿反向ETF投資基金受益憑證的限制上是張冠李戴。

7. 證券投資信託基金之來源不包含以下何者？
  1. (A)申購受益憑證支付予投信事業之管理費
  2. (B)以受益憑證募集所取得之申購價款

(C)錯誤。募集所得價款運用所生之孳息歸屬基金，屬基金資產來源。

(D)錯誤。以募集所得價款購入之資產本身即為基金資產。

9. 下列敘述何者正確？
  1. (A)證券投資信託基金與證券投資信託事業及基金保管機構之自有財產應分別獨立
  2. (B)證券投資信託事業與基金保管機構就其自有財產所負債務，其債權人得對基金資產請求扣押或行使權利
  3. (C)證券投資信託基金管理辦法由行政院訂之
  4. (D)基金保管機構應依法及證券投資信託契約之規定混合保管基金
解析

(A)正確。基金資產與投信事業、基金保管機構之自有財產均應分別獨立。三方財產各自獨立，才能在任一機構發生財務危機時，確保基金資產不被牽連。

(B)錯誤。正因財產獨立，投信事業與保管機構就自有財產所負債務之債權人，不得對基金資產請求扣押或行使權利。

(C)錯誤。證券投資信託基金管理辦法由金融監督管理委員會訂定，非行政院。

(D)錯誤。基金保管機構應「分別」保管基金，不得混合保管，否則各基金的資產歸屬將無從辨識。

114年第3次｜投信投顧相關法規｜第 11 題
12. 針對非專業投資機構之客戶，投信投顧業務員為全權委託之投資執行，應遵守以下哪些事項？甲.不得依投資經理人之口頭指示執行；乙.投資經理人交付業務員執行買賣時應作成紀錄；丙.執行結果應於次日作成投資執行表；丁.投資執行表不須說明投資差異原因
  1. (A)僅甲
  2. (B)甲、乙
  3. (C)甲、乙、丙
  4. (D)甲、乙、丙、丁
解析

(A)錯誤。甲固然正確，但乙同樣是規範要求：投資經理人交付業務員執行買賣時必須作成紀錄，否則事後無法比對投資決定與實際執行，只選甲就漏掉了留痕的另一半。

(B)正確。依投信投顧公會全權委託投資業務操作辦法，投資執行必須以書面為之：業務員不得依投資經理人的口頭指示執行（甲），投資經理人交付執行時應作成紀錄（乙）。兩者合起來才能讓決策與執行對得上帳，稽核得以追查有無擅自偏離投資決定。丙錯在時點，投資執行表應於執行後即時作成，不是拖到次日；丁錯在內容，執行表正是要說明執行與決定之間的差異原因。

(D)錯誤。成交單位1,000股正確，但報價是以每股價格申報，報價單位是1股而非1,000股；把成交單位當成報價單位就會得到這個選項。
