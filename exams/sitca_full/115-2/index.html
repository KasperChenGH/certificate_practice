投信投顧相關法規　49 題

1. 下列何者得擔任投信基金保管機構？
  1. (A)投信事業持有其已發行股份總數10%以上股份之銀行
  2. (B)擔任投信基金簽證之銀行
  3. (C)投資於投信事業已發行總數5%股份之銀行
  4. (D)擔任投信事業董事之銀行
解析

(A)錯誤。投信事業持有其股份達一定比率以上之銀行，因關係過近而不得擔任該事業基金之保管機構。

(B)錯誤。擔任該基金簽證之銀行不得再擔任保管機構，否則簽證與保管功能重疊而失去查核意義。

(C)正確。持股比率甚低、未達法定利害關係門檻之銀行，得擔任基金保管機構。限制的核心在於保管機構必須與投信事業保持足夠距離，才能有效監督其運用指示。

(D)錯誤。擔任投信事業董事之銀行與該事業關係密切，不得擔任其基金之保管機構。

2. 境外基金管理機構最多得委任幾個總代理人在國內代理其基金之募集與銷售？
  1. (A)1 個
  2. (B)3 個
  3. (C)5 個
  4. (D)未有限制
解析

(A)正確。境外基金管理辦法第3條第1項規定，境外基金機構應委任「單一」之總代理人在國內代理其基金之募集及銷售。單一窗口使該機構在臺的募集銷售、資訊揭露、申購買回轉送與投資人申訴，責任歸屬只有一家，主管機關與投資人都知道該找誰。

(B)錯誤。若允許三家總代理人，同一檔境外基金會由三個窗口各自轉送申購與揭露資訊，責任歸屬與申訴對象都會分散，正與單一總代理人制度想避免的情形相同，辦法並無此設計。

(C)錯誤。五家是反方向的數字：境外基金管理辦法第3條第2項規定「總代理人」代理境外基金之募集及銷售，以五家境外基金管理機構為限。題目問的是一家境外基金機構可委任幾個總代理人，答案是一個。

(D)錯誤。「未有限制」描述的是銷售機構：境外基金管理辦法第3條第3項規定銷售機構得代理一個以上境外基金。對境外基金機構委任總代理人的家數則明定為單一，並非不設限。

3. 有關境外基金總代理提存之營業保證金，下列何者敘述錯誤？
  1. (A)應以現金、銀行存款、政府債券或金融債券提存
  2. (B)不得設定質權或以任何方式提供擔保
  3. (C)應分散提存於不同金融機構
  4. (D)提存金融機構之更換或營業保證金之提取，應經投信投顧公會轉報金管會核准後始得為之
解析

(A)錯誤。以現金、銀行存款、政府債券或金融債券提存，符合規範，敘述無誤。

(B)錯誤。營業保證金不得設定質權或以任何方式提供擔保，敘述無誤。

(C)正確（即敘述有誤者）。營業保證金不得分散提存於不同金融機構。集中提存才能在需要動用時迅速、完整地清償，分散反而增加執行成本與時間。

(D)錯誤。提存機構之更換或保證金之提取須經公會轉報金管會核准，敘述無誤。

4. 證券投資信託事業募集或追加募集投信基金，原則上採申報生效制，以下敘述何者正確？
  1. (A)國內募集，投資國內者：12 個營業日申報生效
  2. (B)國內募集，投資國(內)外者：30 個營業日申報生效。但符合一定條件之投信(如「躍進計畫」者)，得原則縮短為12 個營業日之優惠措施
  3. (C)辦理追加募集各類型投信基金案件：7 個營業日申報生效
  4. (D)選項(A)(B)(C)均正確
解析

(A)錯誤。此項敘述本身無誤，但僅涵蓋國內募集且投資國內之情形，未包含其餘兩類案件，非本題最完整之答案。

(B)錯誤。此項敘述本身無誤，含優良業者得縮短生效期間之優惠，惟仍僅為三種情形之一。

(C)錯誤。此項敘述本身無誤，但追加募集僅為其中一類案件，單選此項會遺漏另外兩種情形。

(D)正確。三項分別對應「國內募集投資國內」、「國內募集投資國外」及「追加募集」三類案件，其生效期間之長短，係依審查所需之複雜度與業者過往遵法表現而分級，故三者均正確。

  1. (A)最近一檔已成立且開放買回已屆滿6 個月之投信基金，其於該6 個月期間平均已發行總單位數較成立日減少50%以上

  3. (C)依主管機關規定應取得國外主管機關或其他機構之聲明或書函之募集案件

115年第2次｜投信投顧相關法規｜第 5 題
6. 為利投信事業將ESG 納入投資與風險管理作業流程，並如實揭露相關資訊，要求其於永續報告書或公司網站發布評估報告之頻率為何？
  1. (A)每月
  2. (B)每季
  3. (C)每半年
  4. (D)每年
解析

(A)錯誤。每月是基金月報的節奏：投信事業依證券投資信託及顧問法第100條須於每月終了後十日內編具基金月報申報。ESG納入投資與風險管理流程的評估報告是對整體作業的檢視，逐月發布並無新內容可比較。

(B)錯誤。每季是財務報告的週期，適合反映經營數字的變動；ESG流程評估報告談的是政策、方法與執行情形，一季之內不會有實質改變，規範也未要求逐季發布。

(C)錯誤。每半年並非規範採用的頻率。半年報同樣是財務揭露的節奏，ESG評估報告則被安排與永續報告書同步，用年度作為比較基準。

(D)正確。投信事業應每年於永續報告書或公司網站發布ESG納入投資與風險管理流程的評估報告。採年度週期，是為了與永續報告書及財務年度的揭露節奏一致，讓各年資訊可以相互比較，並讓投資人檢視業者是否如實把ESG做進流程，而不只是宣示。

115年第2次｜投信投顧相關法規｜第 6 題
7. 下列何者正確？
  1. (A)投信基金之受益權，按受益權單位總數，加權分割
  2. (B)每一受益憑證之受益權單位數，依保管機構之記載
  3. (C)每一受益憑證之受益權單位數，依投信事業之記載
  4. (D)投信基金之受益權，按受益權單位總數，平均分割
解析

(A)錯誤。受益權的分割方式是「平均」而非「加權」。證券投資信託及顧問法第35條明定受益權按受益權單位總數平均分割；若採加權分割，同樣一個單位的權利內容會因人而異，共同基金按單位數比例分享淨資產的基礎就不存在。

(B)錯誤。每一受益憑證的受益權單位數依「受益憑證」本身的記載，不是依保管機構的記載。保管機構負責保管基金資產與執行投信的指示，並不是受益權歸屬的證明文件。

(C)錯誤。投信事業是基金的經理人，負責運用基金資產，但受益權單位數的依據是受益憑證的記載，而非投信事業的帳冊。以憑證記載為準，才能讓受益人持有的權利有客觀的證明。

(D)正確。證券投資信託及顧問法第35條規定，受益權按受益權單位總數平均分割，每一受益憑證之受益權單位數依受益憑證之記載。平均分割是共同基金的基本設計：每一單位的權利內容完全相同，受益人僅依持有單位數按比例分享基金淨資產，不因加入先後或身分而有差別。

9. 有關投信事業私募投信基金應募人數之規定，除證券投資信託及顧問法第十一條第一項第一款對象除外，應募人總數不得超過多少人？
  1. (A)5 人
  2. (B)35 人
  3. (C)50 人
  4. (D)99 人
解析

(A)錯誤。五人的上限不曾出現在投信基金私募的規範中；若真以五人為限，私募基金幾乎只能對極少數對象募集，將失去作為機構或高資產客戶投資工具的功能。

(B)錯誤。三十五人是證券交易法私募有價證券對第二、三款應募人的人數上限，常與投信基金私募混淆。投信基金私募依證券投資信託及顧問法另有規範，上限是九十九人，兩者不可套用。

(C)錯誤。五十人不是投信基金私募的應募人上限，也不是證交法私募的數字。若記成五十人，代表把兩套私募規範的數字混在一起，實際上投信投顧法定的是九十九人。

(D)正確。證券投資信託及顧問法第11條規定，私募投信基金的應募人，除第一項第一款所列銀行、保險、證券等機構法人之外，第二款對象的應募人總數不得超過九十九人。設人數上限，是讓私募維持在小範圍、非公開的募集型態，因此可以豁免公開募集所需的申報核准與公開說明書程序。

10. 在基金存續期間，於到期時藉由基金投資工具提供受益人一定比率本金保護之基金，稱為：
  1. (A)保護型基金
  2. (B)保證型基金
  3. (C)平衡型基金
  4. (D)組合型基金
解析

(A)正確。於到期時藉由基金投資工具本身提供受益人一定比率本金保護者，為保護型基金。它與保證型基金的關鍵差別在於沒有第三人提供保證，保護效果來自投資組合設計。

(B)錯誤。保證型基金另有保證機構提供保證，並非僅以投資工具達成本金保護。

(C)錯誤。平衡型基金指同時投資股票與債券並維持一定配置比例者，與本金保護無關。

(D)錯誤。組合型基金係以投資其他基金為主，與本金保護機制無關。

115年第2次｜投信投顧相關法規｜第 11 題
12. 全權委託契約受任人與客戶簽訂全權委託投資契約前，應有幾日以上之期間，供客戶審閱全部條款內容？
  1. (A)五日
  2. (B)七日
  3. (C)十日
  4. (D)三日
解析

(A)錯誤。五日短於規範所定的期間。全權委託契約條款涵蓋投資方針、費用、風險與經紀商指定等事項，管理辦法要求至少七日，五日仍不足以讓一般客戶完整審閱，簽了也可能違反審閱期規定。

(B)正確。證券投資信託事業證券投資顧問事業經營全權委託投資業務管理辦法規定，受任人與客戶簽訂全權委託投資契約前，應有七日以上之期間供客戶審閱全部條款內容。全權委託是把投資決定權交給他人，審閱期讓客戶有時間理解授權範圍、費用與風險，避免在銷售壓力下倉促簽約。
