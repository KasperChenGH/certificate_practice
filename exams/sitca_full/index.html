1. 針對非專業投資機構之客戶，投信投顧業務員為全權委託之投資執行，應遵守以下哪些事項？甲.不得依投資經理人之口頭指示執行；乙.投資經理人交付業務員執行買賣時應作成紀錄；丙.執行結果應於次日作成投資執行表；丁.投資執行表不須說明投資差異原因
  1. (A)僅甲
  2. (B)甲、乙
  3. (C)甲、乙、丙
  4. (D)甲、乙、丙、丁
解析

(A)錯誤。甲固然正確，但乙同樣是規範要求：投資經理人交付業務員執行買賣時必須作成紀錄，否則事後無法比對投資決定與實際執行，只選甲就漏掉了留痕的另一半。

(B)正確。依投信投顧公會全權委託投資業務操作辦法，投資執行必須以書面為之：業務員不得依投資經理人的口頭指示執行（甲），投資經理人交付執行時應作成紀錄（乙）。兩者合起來才能讓決策與執行對得上帳，稽核得以追查有無擅自偏離投資決定。丙錯在時點，投資執行表應於執行後即時作成，不是拖到次日；丁錯在內容，執行表正是要說明執行與決定之間的差異原因。

(C)錯誤。丙把作成投資執行表的時點延到次日，與規範要求執行後即作成、當日即可核對的精神不符；隔日補作等於給了事後修改紀錄的空間。

(D)錯誤。丁與規範相反：投資執行表的功能就是揭露執行結果與投資決定之間的差異並說明原因，若不須說明，執行偏離決策便無從被發現。

114年第3次｜投信投顧相關法規｜第 13 題
2. 有關投顧事業之申請設立，依目前法律規範作業程序下列何者為正確？甲.分為二階段申請程序；乙.申請許可後一個月內應即加入投信投顧公會；丙.第二階段為申請核發營業執照
  1. (A)甲、乙
  2. (B)甲、丙
  3. (C)乙、丙
  4. (D)甲、乙、丙皆正確
解析

(A)錯誤。乙把加入公會的時點說成「申請許可後一個月內」，但投信投顧法第84條的要求是非加入同業公會不得開業，時點是開業前，而不是從許可起算一個月。

(B)正確。投顧事業的設立採二階段：第一階段向金管會申請設立許可，第二階段完成籌設後申請核發營業執照，甲、丙皆正確；兩階段分別把關「能不能設」與「有沒有設好」。乙的「申請許可後一個月內加入公會」與第84條規定的開業前入會不同，故不選。

(C)錯誤。乙的入會時點有誤，且此選項還漏掉正確的甲；投顧設立確實分為許可與核照兩個階段。

(D)錯誤。甲、丙正確但乙不正確，入會時點法定為開業前而不是許可後一個月內，三者皆正確不成立。

114年第3次｜投信投顧相關法規｜第 38 題
3. 信託業兼營全權委託投資業務，其單獨管理運用或集合管理運用之信託財產涉及運用於證券交易法§6 之有價證券之金額未達新臺幣多少時，得不受全權委託投資業務管理辦法第四章(信託業兼營全權委託投資業務)之規範？
  1. (A)5,000 萬元
  2. (B)3,000 萬元
  3. (C)2,000 萬元
  4. (D)1,500 萬元
解析

(A)錯誤。5,000 萬元高於規範所定的門檻。若門檻設在 5,000 萬元，大量中等規模的信託財產運用於有價證券時都可以不受全權委託規範，保護委託人的目的會大幅打折。

(B)錯誤。3,000 萬元不是規範所定的門檻金額。規範選擇 1,500 萬元，是在小額信託的法遵成本與委託人保護之間取的平衡點。

(C)錯誤。2,000 萬元不是規範所定的門檻。門檻金額決定哪些信託業務要納入全權委託的監理，規範把線畫在 1,500 萬元。

(D)正確。依全權委託投資業務管理辦法第 2 條，信託業單獨管理運用或集合管理運用的信託財產，涉及運用於證券交易法第 6 條之有價證券達新臺幣 1,500 萬元以上者，才須依該辦法第四章的規範辦理；未達 1,500 萬元即不受第四章規範。設此門檻是對小額信託運用免除較重的全權委託法遵成本，把監理資源集中在規模足以影響市場與委託人權益的業務上。

115年第1次｜投信投顧相關法規｜第 13 題
4. 投顧事業之證券分析人員在「廣播或電視媒體」及「報章雜誌」就個別有價證券之買賣進行推介或勸誘，下列敘述何者錯誤？
  1. (A)在「廣播或電視媒體」交易時間及前後一小時內，不可推介個別有價證券
  2. (B)在「廣播或電視媒體」交易時間及前後一小時以外，可推介個別有價證券，但須有合理研判分析依據
  3. (C)在「報章雜誌」，不可推介個別有價證券
  4. (D)在「報章雜誌」，可推介個別有價證券，但須有合理研判分析依據
解析

(A)錯誤。本項敘述正確：廣播或電視媒體於交易時間及其前後一小時內，不可推介個別有價證券，以免即時影響盤中交易。

(B)錯誤。本項敘述正確：在上述時段以外得推介個別有價證券，但須有合理研判分析依據。

(C)正確（即錯誤敘述者）。報章雜誌並非一律不可推介個別有價證券；其得推介，惟須有合理研判分析依據。兩種媒體的差別在於即時性：廣播電視能即時左右盤中交易，才有交易時間前後的時段限制，平面媒體則無此問題。

(D)錯誤。本項敘述正確，正是報章雜誌所適用的規則。

115年第1次｜投信投顧相關法規｜第 40 題
5. 全權委託投資契約存續期間是否可以增加或提取委託投資資產？
  1. (A)可增加不能提取
  2. (B)可提取不能增加
  3. (C)可增加，但要資產價值達新臺幣500 萬元以上才能提取
  4. (D)增加或提取均沒有限制
解析

(A)錯誤。契約存續期間並非不能提取，而是提取受有下限的限制：提取後資產仍須維持一定價值。若完全禁止提取，客戶資金將被鎖死在契約內，這不是規範的設計。

(B)錯誤。存續期間可以增加委託投資資產，只是增加時應一次全額存入保管機構。「可提取不能增加」把方向弄反了，受限制的是提取而非增加。

(C)正確。契約存續期間得增加委託投資資產；提取則須使委託投資資產價值仍達新臺幣五百萬元以上。管理辦法第12條規定受任人接受單一客戶委託投資資產不得低於五百萬元，若允許任意提取到低於此數，最低委託金額的要求就會被規避。

(D)錯誤。增加雖無上限，提取卻不是毫無限制，仍須符合五百萬元最低委託資產的要求。「均沒有限制」忽略了最低委託金額的規定。

115年第2次｜投信投顧相關法規｜第 14 題
6. 金融監督管理委員會得委託下列何機構受理境外基金管理辦法第二十七條之境外基金募集及銷售案件？
  1. (A)臺灣證券交易所
  2. (B)財團法人證券櫃檯買賣中心
  3. (C)臺灣期貨交易所
  4. (D)臺灣集中保管結算所
解析

(A)錯誤。臺灣證券交易所主管上市有價證券之交易與監視，並非受託受理境外基金募集及銷售案件之機構。

(B)錯誤。財團法人證券櫃檯買賣中心主管上櫃、興櫃及債券市場業務，未受託辦理境外基金案件之受理。

(C)錯誤。臺灣期貨交易所主管期貨及選擇權契約之交易，與境外基金募集銷售之申報受理無關。

(D)正確。金管會得委託臺灣集中保管結算所受理境外基金之募集及銷售案件。由集保結算所集中收件並搭配境外基金資訊觀測站揭露，可統一申報格式、集中管理資料，提高審查效率與資訊透明度。

115年第2次｜投信投顧相關法規｜第 39 題
7. 在市場投資組合右上方之投資組合，其市場投資組合與無風險資產權重可能為多少？
  1. (A)0.7 及0.3
  2. (B)0.8 及0.2
  3. (C)-0.2 及1.2
  4. (D)1.2 及-0.2
解析

(A)錯誤。權重0.7與0.3代表部分資金置於無風險資產（貸出），組合位於市場投資組合與無風險利率之間。

(B)錯誤。0.8與0.2同樣屬於貸出組合，風險與報酬均低於市場投資組合。

(C)錯誤。市場投資組合權重為負代表放空市場、資金全數存放於無風險資產，位於資本市場線的最左端。

(D)正確。位於市場投資組合右上方，代表風險與期望報酬均高於市場組合，須以無風險利率借入資金（權重為負的－0.2）再投入市場組合（權重1.2），即融資組合；權重合計仍為1。

114年第3次｜證券投資與財務分析｜第 11 題
8. 下列何者並非發行公司債取得資金的優點?
  1. (A)享有稅盾利益
  2. (B)資金成本低於普通股及特別股
  3. (C)流動比率上升
  4. (D)財務槓桿比率下降
解析

(A)錯誤。公司債利息可列為費用抵稅，享有稅盾，確為發債的優點。

(B)錯誤。債權人風險低於股東，要求報酬較低，加上稅盾，債務資金成本低於普通股與特別股，確為優點。

(C)錯誤。發行長期公司債取得現金，流動資產增加而流動負債不變，流動比率上升，確為優點。

(D)正確（即非優點者）。舉債會使負債增加、財務槓桿比率「上升」而非下降，槓桿上升代表財務風險提高，是發債的代價而非好處。

114年第3次｜證券投資與財務分析｜第 31 題
9. 以下敘述何者不正確？
  1. (A)風險溢酬未包含在預期報酬率中
  2. (B)風險愈低，投資人要求之風險溢酬愈低
  3. (C)高風險未必獲得高報酬
  4. (D)投資人對公債的風險溢酬要求低於股票
解析

(A)正確（即敘述不正確者）。預期報酬率＝無風險利率＋風險溢酬，風險溢酬本來就是預期報酬率的組成部分，說「未包含」是錯的。風險溢酬正是投資人承擔風險所要求的額外補償，若不含於預期報酬中，便沒有人願意持有風險性資產。

(B)錯誤。此敘述正確：風險愈低，投資人要求的補償愈少。

(C)錯誤。此敘述正確：高風險只是「要求」較高的期望報酬，實際結果可能虧損，否則就不叫風險。

(D)錯誤。此敘述正確：公債信用風險遠低於股票，所要求的風險溢酬也較低。

115年第1次｜證券投資與財務分析｜第 2 題
10. 一般而言，投資債券型基金可預期獲得：
  1. (A)高於市場平均之報酬率
  2. (B)等於市場平均之報酬率
  3. (C)低於市場平均之報酬率
  4. (D)等於無風險利率之報酬率
解析

(A)錯誤。債券型基金以固定收益為主，長期報酬通常不及股票為主的市場平均。

(B)錯誤。風險較低的資產長期報酬亦較低，不會等於市場平均。

(C)正確。債券型基金投資標的的違約與波動風險低於股票，依風險與報酬對稱原則，可預期的長期報酬率也低於市場平均，換得的是較穩定的收益與較小的波動。

(D)錯誤。債券仍有利率風險與信用風險，長期報酬一般高於無風險利率，不會恰等於它。

  2. (B)最小風險集合
  3. (C)最大報酬集合
  4. (D)最小變異數集合
解析

(A)正確。效率前緣是所有效率投資組合的集合，定義正是「相同風險下期望報酬最高、相同期望報酬下風險最低」。它是最小變異數集合在全域最小變異數組合以上的那一段，因為以下那一段在相同風險下有報酬更高的組合存在，被支配而不符效率。

(B)錯誤。「最小風險集合」不是投資組合理論的正式名稱。風險最低的那一個組合稱為全域最小變異數組合，而它只是效率前緣的左端點，不是整個集合。

(C)錯誤。「最大報酬集合」並非標準術語。期望報酬最高的組合通常是報酬最高的單一資產，它只是效率前緣的右端點，無法代表整條曲線。

(D)錯誤。最小變異數集合是每一報酬水準下變異數最小的組合所連成的整條曲線，包含效率前緣下方被支配的部分；那些組合在相同風險下報酬並非最高，故最小變異數集合的範圍比效率前緣大。

14. 關於審計委員會之獨立董事成員職權，下列敘述何者正確？
  1. (A)得以單獨召集董事會
  2. (B)得以單獨召集股東會
  3. (C)得以在董事為自己或他人與公司為買賣、借貸或其他法律行為時，由其為公司之代表
  4. (D)得以隨時調查公司業務及財務狀況，查核、抄錄或複製簿冊文件
解析

(A)錯誤。董事會由董事長召集，獨立董事沒有單獨召集董事會的權限；審計委員會本身可以召集的是審計委員會會議。獨立董事在董事會上若有反對意見，是以記載於議事錄的方式表達，不是另行召集董事會。

(B)錯誤。監察人於必要時得召集股東會是公司法第220條的規定，但證交法第14條之4第4項並未把這項權限列為獨立董事成員可個別行使的職權；設有審計委員會的公司是由審計委員會整體準用監察人規定，個別獨立董事不能單獨召集股東會。

(C)錯誤。董事為自己或他人與公司為買賣、借貸或其他法律行為時由監察人代表公司，是公司法第223條的規定；證交法第14條之4第4項列舉可由獨立董事成員個別行使的條文並不包括第223條，這項代表權是由審計委員會以整體準用監察人規定行使，不是個別獨立董事的職權。

(D)正確。證券交易法第14條之4第4項規定，公司法第218條第1項、第2項等監察人職權對審計委員會之獨立董事成員準用之，因此每位獨立董事成員均得隨時調查公司業務及財務狀況，查核、抄錄或複製簿冊文件。這項調查權是獨立董事發揮監督功能的基礎，若必須先經委員會決議才能查帳，監督會失去即時性，所以法律讓成員可以個別行使。

  2. (B)股東常會及股東臨時會之停止過戶期間不得請求轉換，不得辦理股東名簿記載之變更
  3. (C)股東常會及股東臨時會之停止過戶期間得請求轉換，得辦理股東名簿記載之變更
  4. (D)股東常會及股東臨時會之停止過戶期間不得請求轉換，得辦理股東名簿記載之變更
解析

(A)正確。轉換公司債持有人依轉換辦法得隨時請求轉換，在股東常會、臨時會的停止過戶期間也可以提出，但轉換後的股東名簿記載變更要等停止過戶期間結束才辦理。停止過戶期間股東名簿必須凍結，以確定有權出席會議與領取股利的股東名單；若期間內仍變更名簿，開會通知與分派對象就無法確定。

(C)錯誤。前半段對，但停止過戶期間正是為了凍結股東名簿而設，此時若辦理名簿變更，出席股東會及配股配息的名單就會變動，違背停止過戶的目的。

(D)錯誤。兩段都反了：停止過戶期間並不禁止請求轉換，反而禁止的是名簿記載的變更；此項把可以做的說成不可以、不可以做的說成可以。

  4. (D)返還本息並負民事及刑事責任
解析

(A)錯誤。只返還本金會讓投資人白白損失資金被占用期間的利息，發行人募集與發行有價證券處理準則第11條要求依法加算利息返還價款，並負損害賠償責任。

(B)錯誤。只返還利息而不還本金顯然無法回復投資人的地位；規定是本金連同利息一併返還，還要對投資人的損害負賠償責任。

(C)正確。依發行人募集與發行有價證券處理準則第11條，募集與發行案件經撤銷或廢止申報生效時，已收取有價證券價款者，發行人或持有人應於接獲通知之日起十日內依法加算利息返還該價款，並負損害賠償責任。加算利息是回復投資人資金被占用的損失，損害賠償則涵蓋利息以外的其他損失，兩者合起來才能讓投資人回到未認購前的狀態。

(D)錯誤。這項規定是民事上的返還與賠償義務，刑事責任要另外看發行人是否有證交法所定的詐欺、虛偽等犯罪行為，並不是一經撤銷就當然附帶刑事責任。
