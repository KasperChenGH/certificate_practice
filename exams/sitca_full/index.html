1. 下列關於證券投資信託事業或證券投資顧問事業(下稱「受任人」)經營全權委託投資業務之敘述，何者正確？
  1. (A)投資經理人及其代理人之指定，應由受任人決定
  2. (B)受任人與客戶簽訂全權委託投資契約後，應自行保管受託投資資產
  3. (C)受任人應與客戶個別簽訂全權委託投資契約，除法令或金融監督管理委員會另有規定外，不得接受共同委任或信託
  4. (D)受任人與客戶簽訂全權委託投資契約前，應有五日以上之期間，供客戶審閱全部條款內容
解析

(A)錯誤。管理辦法第22條第2項規定全權委託投資契約應載明「投資經理人之指定與變更」，因此經理人的指定是契約約定事項，須經客戶同意，不是由受任人單方決定。

(B)錯誤。受任人不得自行保管委託投資資產。委託投資資產應於簽約時一次全額存入全權委託保管機構，由保管機構保管並執行受任人的指示，操作與保管分離是防止挪用的核心設計。

(C)正確。管理辦法規定全權委託投資契約應與客戶個別簽訂，除法令或金管會另有規定外，不得接受共同委任或信託。個別簽約才能依各客戶的資力與目的分別議定投資方針，資產歸屬與權責也清楚可分，不會出現多名客戶共用一個帳戶而無法區分損益的情形。

(D)錯誤。日數錯了：管理辦法要求簽約前應有「七日以上」的期間供客戶審閱全部條款，五日短於法定最低審閱期。

2. 有關證券商經營特定外國債券業務，以下哪些債券可列入特定外國債券範圍？ 甲.信用評等一定等級以上之外國中央政府債券 乙.信用評等一定等級以上之外國公司債券 丙.可轉換公司債丁.不動產抵押貸款債券
  1. (A)僅甲
  2. (B)僅甲、乙
  3. (C)僅甲、乙、丙
  4. (D)甲、乙、丙、丁皆可
解析

(A)錯誤。只列外國中央政府債券過於狹隘，信用評等達一定等級以上的外國公司債券同樣屬於信用品質良好、結構單純的固定收益商品，也在特定外國債券的範圍內。

(B)正確。證券商經營特定外國債券業務，可承作的標的是信用評等達一定等級以上的外國中央政府債券與外國公司債券。範圍以信用評等與商品單純性為篩選標準，讓國內投資人能透過本國券商買賣信用良好的外國債券，同時避免複雜或含選擇權性質的商品。

(C)錯誤。可轉換公司債附有轉換為股票的權利，價值同時受發行公司股價影響，屬股債混合的衍生性商品，風險型態與純債券不同，不列入特定外國債券。

(D)錯誤。不動產抵押貸款債券是資產證券化商品，現金流量取決於底層房貸的提前清償與違約情形，評價複雜，加上可轉換公司債的股權性質，這兩類都不在特定外國債券的範圍內。

3. 已知某公司股票的β是1.2，市場預期報酬率是8%，銀行一年期定存利率是3%，試問：該股票的風險貼水(risk premium)是多少？
  1. (A)9%
  2. (B)15.5%
  3. (C)6%
  4. (D)7.5%
解析

(A)錯誤。9%是該股票的要求報酬率：3%＋1.2×（8%－3%）＝9%。題目問的是風險貼水，也就是超過無風險利率的部分，須把3%的無風險利率扣掉，得6%。

(B)錯誤。15.5%比市場報酬率8%還高出許多，β為1.2的股票不可能有這麼大的風險貼水，任何合理的CAPM代入方式都得不到這個數字。

(C)正確。個股風險貼水＝β×（市場報酬率－無風險利率）＝1.2×（8%－3%）＝6%。風險貼水指的是承擔系統風險所要求的超額補償，不含無風險利率本身；再加上3%的定存利率才是該股要求報酬率9%。

(D)錯誤。7.5%＝1.5×5%，等於把β誤記為1.5。市場風險溢酬是5%，乘上題目給的β1.2應為6%。

4. 甲公司X1 年底有關資料如下：10%累積特別股，每股面額$10，總面額$900,000；普通股，每股面額$10，總面額$1,000,000；稅前淨利$600,000；所得稅率25%。若甲公司當年度流通在外股數無變動，則每股盈餘為多少？
  1. (A)$3.6
  2. (B)$4.5
  3. (C)$5.1
  4. (D)$6.3
解析

(A)正確。稅後淨利＝600,000×(1－25%)＝450,000；累積特別股股利＝900,000×10%＝90,000，不論宣告與否均應減除；普通股股數＝1,000,000÷10＝100,000股。每股盈餘＝(450,000－90,000)÷100,000＝$3.6。

(B)錯誤。$4.5 是450,000÷100,000，漏扣了累積特別股當年度應計的90,000元股利。

(C)錯誤。此金額無法由題目資料以正確算式推得。

(D)錯誤。$6.3 等於以稅前淨利計算，每股盈餘的分子必須是稅後且歸屬普通股股東的盈餘。

5. 證券商除由金融機構兼營者依有關法令規定外，其經營自行買賣有價證券業務者，持有任一本國公司股份之總額不得超過該公司已發行股份總額之___；持有任一本國公司所發行有價證券之成本總額，並不得超過該證券商淨值之___。
  1. (A)5%；10%
  2. (B)5%；20%
  3. (C)10%；15%
  4. (D)10%；20%
解析

(A)錯誤。5% 與 10% 都低於證券商管理規則所設的上限，若採這組數字，自營商對單一公司的持股與投資額度都會被過度壓縮。持股上限是已發行股份的 10%，成本總額上限是淨值的 20%。

(B)錯誤。此選項把持股比率誤取為 5%，只有淨值 20% 這一半正確。單一公司持股上限 10% 是為了防止券商藉自營介入他公司經營權，5% 則是證券交易法大量持股申報門檻，兩者不要混淆。

(C)錯誤。持股不得超過該公司已發行股份 10% 這一半正確，但成本總額對淨值的上限是 20%，不是 15%；15% 並非規則採用的比例。

(D)正確。證券商管理規則第19條規定，證券商經營自行買賣業務者，持有任一本國公司股份之總額不得超過該公司已發行股份總額之 10%，持有任一本國公司所發行有價證券之成本總額不得超過該證券商淨值之 20%。前者避免券商以自營部位取得他公司經營權，後者控管單一發行人的集中度風險。

6. 公開收購人與其關係人於公開收購後，所持有被收購公司已發行股份總數超過該公司已發行股份總數比率達多少者，得以書面請求董事會召集股東臨時會，不受公司法規定之限制？
  1. (A)10%
  2. (B)20%
  3. (C)30%
  4. (D)50%
解析

(A)錯誤。持股百分之十只是相當程度的少數股權，未取得公司控制權，證券交易法只讓過半數的公開收購人享有直接請求召集股東臨時會的特權；一般持股達一定比例的股東仍須依公司法程序辦理。

(B)錯誤。百分之二十雖已是重要股東，但尚未過半，無法確保能在股東會改選董事，法律沒有讓此持股水準的收購人跳過公司法程序。

(C)錯誤。百分之三十未達過半數，法律未賦予其請求董事會召集股東臨時會而不受公司法限制的權利；門檻設在百分之五十是以是否取得控制權為判準。

(D)正確。證券交易法第43條之5規定，公開收購人與其關係人於公開收購後，所持有被收購公司已發行股份總數超過百分之五十者，得以書面記明提議事項及理由，請求董事會召集股東臨時會，不受公司法有關持股期間與比例的限制。取得過半數即已掌握控制權，讓其得儘速改組董事會，可避免經營權懸空期間過長。

1. 下列何者為「多重資產型基金」得投資之資產項目？甲.股票；乙.債券；丙.基金受益憑證；丁.不動產投資信託基金受益證券(REITs)
  1. (A)甲、丙
  2. (B)甲、乙、丙
  3. (C)甲、丙、丁
  4. (D)甲、乙、丙、丁皆可
解析

(A)錯誤。乙、丁同為多重資產型基金得投資之項目，本項不完整。

(B)錯誤。丁（REITs受益證券）同為得投資項目，本項漏列。

(C)錯誤。乙（債券）同為得投資項目，本項漏列。

(D)正確。多重資產型基金得投資股票、債券、基金受益憑證及不動產投資信託基金受益證券。「多重資產」的定義本就在於不受單一資產類別限制，並要求對各類資產設有配置比重規範。

2. 下列何者不得擔任投信事業之發起人？
  1. (A)使用票據曾經拒絕往來已恢復往來者
  2. (B)受破產宣告已復權者
  3. (C)曾任職證券商者
  4. (D)違反證券交易法或投信投顧法規定，經有罪判決確定，尚未執行完畢，或執行完畢、緩刑期滿或赦免後尚未逾三年
解析

(A)錯誤。設置標準第3條的消極資格是「使用票據經拒絕往來尚未恢復往來」，已恢復往來者信用障礙已消滅，不再受限。

(B)錯誤。消極資格是「受破產之宣告尚未復權」，已復權者法律上的資格障礙已除去，可以擔任發起人。

(C)錯誤。曾任職證券商是金融業經歷而非消極資格，設置標準反而以證券金融相關經驗作為發起人專業要求的一部分。

(D)正確。證券投資信託事業設置標準第3條規定，違反證券交易法或投信投顧法經有罪判決確定，尚未執行完畢，或執行完畢、緩刑期滿或赦免後尚未逾三年者，不得充任發起人。對照(A)(B)可看出條文的邏輯：看的是障礙狀態是否仍存在、隔離期間是否已經過，而不是有沒有發生過。

15. 甲為Z 上市公司之獨立董事，持有Z 公司已發行股份20 萬股。若甲於民國113 年11 月1日將所持有之股票10 萬股向X 商業銀行質押借款，下列敘述，何者正確？
  1. (A)Z 公司應於甲將股票質權設定後五日內，將甲之出質情形，向主管機關申報並公告之
  2. (B)甲應於同年11 月15 日以前將持有股數設質之情形，通知公司
  3. (C)甲應於同年12 月5 日以前將持有股票設質之情形，向公司申報
  4. (D)Z 公司應於同年12 月15 日以前，彙總向主管機關申報
解析

(A)正確。證券交易法第25條第4項規定，董事、監察人、經理人及持股超過10%股東的股票經設定質權者，出質人應即通知公司，公司應於其質權設定後五日內，將出質情形向主管機關申報並公告。甲為獨立董事，其設質須依此揭露，Z公司應於設質後五日內申報並公告。設質資訊要即時公開，是因為內部人高比例質押可能引發斷頭賣壓、影響經營權穩定，投資人有及早知道的必要。

(B)錯誤。設質的通知義務是「應即通知公司」，沒有十五日的緩衝期。十五日這個數字出現在同條第2項，是公司每月十五日前彙總向主管機關申報上月持股變動的期限，與設質通知無關。

(C)錯誤。「每月五日以前向公司申報」是證交法第25條第2項對上月持股股數變動的申報規定。設質並不移轉所有權，持股數不變，不屬於持股變動；設質適用的是第4項，出質人應即通知公司。

(D)錯誤。「每月十五日以前彙總向主管機關申報」是公司就內部人上月持股變動的月報義務。設質情形不是走月報，而是公司在質權設定後五日內個別申報並公告，時效要求嚴格得多。

17. 下列各項民事爭議中，依證券投資人及期貨交易人保護法申請調處，將不予受理？
  1. (A)已在第一審法院言詞辯論終結者
  2. (B)與證券發行人產生之民事爭議者
  3. (C)證券投資人提起之民事爭議者
  4. (D)有具體相對人之民事爭議者
解析

(A)正確。證券投資人及期貨交易人保護法第23條列出保護機構不予受理調處的情形，其中包括爭議已在第一審法院言詞辯論終結者。調處是訴訟外的替代機制，案件若已在法院辯論終結、即將判決，再由投保中心介入調處已無實益，也可能與法院的判斷相牴觸，所以排除受理。

(B)錯誤。與發行人之間因有價證券募集、發行、買賣所生的民事爭議，正是投保法第22條規定可申請調處的範圍；發行人和證券商、期貨業一樣都是可調處的相對人。

(C)錯誤。調處制度就是為證券投資人及期貨交易人設的，第23條反而規定「非由證券投資人或期貨交易人提起」的申請才不受理，投資人提起的爭議是受理的前提而不是排除事由。

(D)錯誤。有具體相對人是調處能進行的必要條件，第23條不受理的是「無具體相對人」的爭議；沒有明確的對造，保護機構根本無法通知對方出席協調。

19. 上市公司以低於實際買回股份之平均價格轉讓予員工，應經何者同意？
  1. (A)最近一次股東會有代表已發行股份總數過半數股東之出席，出席股東表決權三分之二以上之同意
  2. (B)最近一次股東會有代表已發行股份總數過半數股東之出席，出席股東表決權過半數之同意
  3. (C)最近一次股東會有代表已發行股份總數三分之二股東之出席，出席股東表決權三分之二以上之同意
  4. (D)最近一次股東會有代表已發行股份總數過半數股東之出席，出席股東表決權四分之三以上之同意
解析

(A)正確。依上市上櫃公司買回本公司股份辦法，以低於實際買回股份平均價格轉讓予員工者，須經最近一次股東會有代表已發行股份總數過半數股東之出席、出席股東表決權三分之二以上之同意，並在股東會召集事由中列舉說明。折價轉讓等於用公司資源補貼員工、稀釋既有股東權益，所以要求比普通決議更高的特別決議門檻。

(B)錯誤。過半數出席、出席表決權過半數同意是普通決議，只適用於一般議案；折價轉讓庫藏股影響股東權益，法規要求同意門檻提高到三分之二以上。

(C)錯誤。出席門檻是「過半數」股東出席，並非三分之二出席；三分之二是加在出席股東表決權的同意門檻上，這是公司法特別決議的標準結構。

(D)錯誤。同意門檻是出席股東表決權三分之二以上，四分之三並不是公司法或買回辦法所採用的比例，特別決議一律以三分之二計算。

  1. (A)證券商兼營自營或承銷業務者，應維持推介業務之獨立性
  2. (B)證券商應訂定防範利益衝突之內部控制制度
  3. (C)券商進行安定操作之股票不得為推介之標的
