1. 依我國期貨交易法與證券交易法之規定,下列何者是期貨交易法所規定之期貨交易之契約?
  1. (A)結構型債券
  2. (B)指數股票型基金
  3. (C)期貨信託事業募集期貨信託基金所發行之受益憑證
  4. (D)個股選擇權契約
解析

3. 公司制期貨交易所之組織,以股份有限公司為限;其單一股東持股比例除有特殊情形經主管機關核准者外,不得超過實收資本額百分之多少?
  1. (A)百分之一
  2. (B)百分之五
  3. (C)百分之十
  4. (D)百分之二十五
解析

(A)錯誤。期貨交易法規定的上限是百分之五，百分之一比法定門檻嚴格得多；若上限真是百分之一，等於連中小型金融機構都難以成為有實質參與的股東，不利交易所籌資。

(B)正確。期貨交易法明定公司制期貨交易所以股份有限公司為限，其單一股東持股比例除有特殊情形經主管機關核准者外，不得超過實收資本額百分之五。目的是讓交易所股權分散，避免單一股東主導交易所決策而損及市場的公正性與中立性。

(C)錯誤。百分之十是法定上限的兩倍。只要記得立法目的在防止單一股東控制交易所，就能理解上限訂得比一般公司的大股東門檻低很多，百分之十已足以在股權分散的公司中發揮重大影響力。

(D)錯誤。百分之二十五已接近可以左右股東會決議的持股水準，與交易所股權應充分分散的立法目的正好相反，遠超過法定的百分之五。

5. 期貨商之發起人、董事、監察人、經理人或業務員,經依期貨交易法第101條第1項解除職務者,必須滿多少年後始得擔任之?
  1. (A)3年
  2. (B)5年
  3. (C)7年
  4. (D)10年
解析

(A)錯誤。三年短於法律規定的期間。期貨交易法對曾受解除職務處分者設定的隔離期間是五年，三年不足以達到法律要求的懲戒與市場信任回復效果。

(B)正確。期貨交易法在期貨商發起人、董事、監察人、經理人及業務員的消極資格中規定，受依該法第 101 條第 1 項解除職務處分未滿五年者，不得充任。這是一種資格上的隔離期，讓曾因違法被主管機關解職的人不能立即回到期貨業擔任要職。

(C)錯誤。七年超過法定的五年。若把它與其他消極資格中的年限混淆，就容易誤選；法條對解除職務處分明定的隔離期間就是五年。

(D)錯誤。十年是法定期間的兩倍。消極資格是限制職業自由的規定，法律只在必要範圍內設定隔離期，對解除職務處分者訂的是五年而非十年。

6. 關於期貨商負責人及業務員之規定,下列何者不正確?
  1. (A)異動應向同業公會申報
  2. (B)異動應於十日內申報
  3. (C)業務員參加在職訓練成績不合格者應於一年內補訓一次
  4. (D)限於所屬期貨商開戶委託買賣
解析

(A)錯誤（此項敘述無誤）。依期貨商負責人及業務員管理規則，負責人及業務員有異動時，期貨商應向同業公會申報，由公會統一登記管理從業人員資料。

(B)正確（此項敘述有誤）。期貨商負責人及業務員管理規則規定，期貨商負責人及業務員有異動者，期貨商應於異動後五日內向同業公會申報，不是十日內。申報期限訂得短，是為了讓公會登記資料能即時反映實際在職人員，避免已離職者仍以期貨商名義對外執行業務。

(C)錯誤（此項敘述無誤）。管理規則規定，未參加訓練或訓練成績不合格者，應於一年內再行補訓一次，補訓後成績仍不合格者，撤銷其業務員登記。

(D)錯誤（此項敘述無誤）。管理規則明定期貨商負責人及業務員限在其所屬期貨商開戶委託買賣，目的是讓從業人員的自身交易受所屬公司監督，防止利用職務資訊在他處交易而難以稽核。

113 年第1 次｜期貨交易法規｜第 8 題
7. 期貨商之調整後淨資本額低於下列何者之一定比例時,應即向主管機關申報,主管機關並應限期令其改善?
  1. (A)交割結算基金
  2. (B)營業保證金
  3. (C)期貨交易人未沖銷部位所需之客戶保證金最低總額
  4. (D)最低實收資本額
解析

(A)錯誤。交割結算基金是結算會員繳存給結算機構、用來共同分攤違約損失的基金，它衡量的是結算層級的違約防護，不是期貨商自身淨資本額的比較基準。

(B)錯誤。營業保證金是期貨商依法繳存於指定金融機構、供期貨業務債權人優先受償的擔保，金額固定，與期貨商每日變動的客戶部位風險無關，不能拿來衡量財務適足。

(C)正確。期貨交易法規定，期貨商調整後淨資本額低於期貨交易人未沖銷部位所需之客戶保證金總額之一定比例時，應即向主管機關申報，主管機關並應限期令其改善。客戶未沖銷部位所需保證金代表期貨商當下承擔的客戶違約風險，淨資本額若跟不上這個風險規模，就表示自有資金可能不足以應付客戶違約，因此要以它為基準做動態監控。

(D)錯誤。最低實收資本額是設立時的門檻，法條另有規定業主權益低於最低實收資本額一定成數時也應申報，但題目問的是調整後淨資本額的比較基準，那是客戶保證金總額，不是實收資本額。

8. 期貨商分支機構僱用業務員,最低人數為:
  1. (A)一人
  2. (B)二人
  3. (C)三人
  4. (D)五人
解析

(A)錯誤。分支機構若只配置一名業務員，業務員請假或離職時就無人能執行業務，也無法做到職務分工與相互牽制，期貨商設置標準訂的下限高於一人。

(B)錯誤。二人仍未達期貨商設置標準對分支機構的要求；法規要求三人，是考量開戶、受託下單與帳務等工作至少要能分工並互相覆核。

(C)正確。期貨商設置標準規定，期貨商分支機構業務員最低人數不得低於三人。設定人數下限是為了確保分支機構有足夠的合格人員維持日常業務運作與內部控制，不會因一人不在而中斷客戶服務或失去覆核機制。

(D)錯誤。五人是期貨商總公司同時經營期貨經紀與自營業務時的業務員最低人數；分支機構業務單純，下限是三人，不要把總公司的標準套到分支機構。

11. 期貨商因期貨業務所生債務之債權人,對期貨商所繳納之何種款項有優先受清償之權限?
  1. (A)結算保證金
  2. (B)營業保證金
  3. (C)交割結算基金
  4. (D)賠償準備金
解析

(A)錯誤。結算保證金是結算會員繳給結算機構、用來擔保結算履約的款項，其受償對象是結算機構與結算體系，並非期貨商一般業務債權人可以優先主張的財產。

(B)正確。期貨交易法規定期貨商應繳存營業保證金，並明定期貨商因期貨業務所生債務之債權人，對於該營業保證金有優先受清償之權。營業保證金的用意就是預留一筆專供期貨業務債權人受償的資金，使客戶與交易對手在期貨商倒閉時不必與一般債權人平均分配。

(C)錯誤。交割結算基金是結算會員共同繳存、用來分攤會員違約損失的基金，它保護的是結算體系，不是期貨商業務債權人的優先受償標的。

(D)錯誤。賠償準備金是期貨商依規定自盈餘提列、用於賠償客戶損失的準備，屬於期貨商自己的帳上科目，法律沒有賦予債權人對它的優先受償權。

113 年第1 次｜期貨交易法規｜第 15 題
13. 證券商如欲擔任期貨信託事業之專業發起人者,該證券商之淨值應達下列何種規模?
  1. (A)新臺幣六十億元以上
  2. (B)新臺幣七十億元以上
  3. (C)新臺幣八十億元以上
  4. (D)新臺幣一百億元以上
解析

(A)錯誤。六十億元是期貨信託事業設置標準中證券商的另一項替代門檻，指的是實收資本額而非淨值；題目問的是淨值，淨值的門檻是八十億元。

(B)錯誤。七十億元不是設置標準所列的任何門檻，它介於實收資本額六十億元與淨值八十億元之間，是把兩個數字記混時容易寫出的數字。

  4. (D)結算保證金履約彙總表
解析

(A)正確。期交所每日結算作業中，結算會員依結算保證金收付通知在結算銀行完成款項轉帳後，期交所據以確認各結算會員的資金到位，並編製結算保證金款項餘額表，記錄每一結算會員當日的保證金餘額。這份表是結算保證金專戶的當日對帳基準，有它才能確認保證金足額，並作為下一交易日計算追繳的起點。

(B)錯誤。結算保證金收付通知書是轉帳「之前」發給結算會員與結算銀行的指示，告知應收付的金額；餘額表是轉帳完成「之後」的確認文件，先後順序相反。

(C)錯誤。期貨交易部位及保證金彙總表彙整各結算會員的部位與應計保證金，用來計算應收付金額，是產生收付通知的依據，不是轉帳完成後的餘額確認。

(D)錯誤。「履約」是指選擇權到期履約或期貨到期交割的作業，與每日保證金款項轉帳後的餘額確認無關；這個名稱不是期交所每日結算作業中的文件。
