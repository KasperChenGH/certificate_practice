1. 有關在臺灣期貨交易所交易的契約，以下敘述何者錯誤？
  1. (A)黃金期貨屬於期貨交易法所定義的期貨契約
  2. (B)臺指選擇權屬於期貨交易法所定義的期貨選擇權契約
  3. (C)臺股期貨屬於期貨交易法所定義的期貨契約
  4. (D)股票選擇權屬於期貨交易法所定義的選擇權契約
解析

(A)錯誤。此為正確敘述：黃金期貨約定於未來特定期間依約定價格交割或結算標的，屬期貨交易法所定的期貨契約。

(B)正確。本題問錯誤者。臺指選擇權的標的是臺股加權指數，屬「選擇權契約」；「期貨選擇權契約」是以期貨契約為標的之選擇權，故此敘述錯誤。

(C)錯誤。此為正確敘述：臺股期貨以加權指數為標的、約定未來依價差結算，屬期貨契約。

(D)錯誤。此為正確敘述：股票選擇權以股票為標的，屬期貨交易法所定的選擇權契約。

2. 依我國期貨交易法之規定，下列有關主管機關得撤銷期貨交易契約之情形何者正確？
  1. (A)連續跌停板，喪失流動性
  2. (B)有被操縱或壟斷之虞
  3. (C)不符公共利益
  4. (D)經全體期貨商申請
解析

(A)錯誤。連續跌停、流動性降低屬市場異常，主管機關可採調整保證金、限制交易等措施，並非撤銷期貨交易契約之事由。

(B)錯誤。有被操縱或壟斷之虞時，主管機關得採取調整保證金、限制部位、停止交易等措施，並非撤銷契約。

(C)正確。依本題所採規定，主管機關核定交易所得上市之期貨交易契約後，若該契約不符公共利益，得撤銷該期貨交易契約。

(D)錯誤。撤銷契約由主管機關依公益判斷，不以全體期貨商申請為要件，法無此規定。

3. 依我國期貨交易法，會員被停止交易時，期貨交易所得採取之措施，下列何者正確？
  1. (A)期貨交易所應依章程規定，責令本人了結其於期貨交易所所為之交易
  2. (B)期貨交易所得對該會員處以罰鍰
  3. (C)期貨交易所得沒收其繳交之結算保證金
  4. (D)期貨交易所不得指定其他會員了結其於期貨交易所所為之交易
解析

(A)正確。會員被停止交易時，期貨交易所應依章程規定，責令本人了結其於期貨交易所所為之交易，或指定其他會員代為了結，以免未了結部位危及市場。

(B)錯誤。罰鍰是主管機關的行政處分，期貨交易所只能依章程、契約課違約金等，不能處以罰鍰。

(C)錯誤。停止交易時的措施重在了結交易，交易所並無因此沒收結算保證金之規定。

(D)錯誤。期貨交易所得指定其他會員了結其交易，並非「不得」，此敘述與規定相反。

13. 期貨結算機構之交割結算基金，可為下列何種運用？
  1. (A)銀行存款
  2. (B)借予他人
  3. (C)購買營業用之不動產
  4. (D)購買非營業用之不動產
解析

(C)錯誤。購買營業用不動產會把擔保履約的資金轉成流動性極低的固定資產，違約時無法迅速變現支應，交割結算基金不得作此運用。

(D)錯誤。購買非營業用不動產同樣使資金流動性喪失，且帶有投資風險，與交割結算基金須保守、可隨時動用的性質不符，不得如此運用。

14. 下列有關期貨業務員之行為，何者符合期貨交易法規之規定？
  1. (A)利用期貨業務員配偶或未成年子女名義，為交易人從事期貨交易
  2. (B)依交易人書面委託書指示，由其配偶為代理人代理下單
  3. (C)期貨業務員於自己家中以電話為交易人進行交易委託
  4. (D)選項(A)(B)(C)行為均違反規定
解析

(A)錯誤。業務員利用配偶或未成年子女等他人名義為交易人從事期貨交易，屬於借名交易，會掩蓋真實交易人與利益關係，是法規明文禁止的行為。
