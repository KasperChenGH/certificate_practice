1. 依據我國期貨交易法之規定，對於期貨交易之敘述，以下何者正確？甲、僅包括國內期貨交易所之交易，不包括國外期貨交易所部分；乙、包括國內外期貨交易所之交易；丙、僅包括集中市場之期貨交易；丁、包括集中市場與店頭市場之交易
  1. (A)甲、丙
  2. (B)甲、丁
  3. (C)乙、丁
  4. (D)乙、丙
解析

(A)錯誤。甲、丙的範圍都過窄，期貨交易法所稱期貨交易不以國內交易所、集中市場為限。

(B)錯誤。甲將範圍限於國內期貨交易所有誤，國外交易所之期貨交易亦屬之。

(C)正確。期貨交易法所稱之期貨交易兼含國內外期貨交易所之交易，也涵蓋集中市場與店頭市場（如槓桿保證金契約），故乙、丁為是。定義採廣義，才能把國人參與的境外及店頭交易一併納入監理。

(D)錯誤。丙把範圍限於集中市場有誤，店頭市場之期貨交易同受規範。

2. 依我國期貨交易法之規定，有關選擇權契約之敘述，以下何者錯誤？
  1. (A)選擇權契約包括股票選擇權契約
  2. (B)選擇權契約包括外幣選擇權契約
  3. (C)選擇權契約賣方須支付權利金
  4. (D)選擇權契約可採現金結算或實物交割方式
解析

(A)錯誤。以股票為標的之選擇權契約屬選擇權契約，敘述正確。

(B)錯誤。外幣選擇權契約亦屬選擇權契約之一種，敘述正確。

(C)正確（即敘述有誤者）。權利金是買方為取得權利而支付、賣方收取者。賣方收取權利金並負擔履約義務，因此須繳交保證金，而非支付權利金。

(D)錯誤。選擇權履約得採現金結算或實物交割，視契約設計而定，敘述正確。

3. 依我國期貨交易法，下列敘述何者正確？
  1. (A)本法所稱之主管機關，係指金融監督管理委員會
  2. (B)得公告期貨交易不適用本法之機關為本法所稱之主管機關及經濟部
  3. (C)制訂本法的目的之一為維持物價穩定
  4. (D)期貨商受託從事的期貨交易種類及交易所，不以主管機關公告者為限
解析

(A)正確。期貨交易法所稱之主管機關為金融監督管理委員會。金管會統合銀行、證券、期貨與保險之監理，期貨業務自屬其主管範圍。

(B)錯誤。公告期貨交易不適用本法之權限屬主管機關，不包含經濟部。

(C)錯誤。維持物價穩定是貨幣政策目標，非期貨交易法之立法目的；本法目的在健全期貨市場發展與維護交易秩序。

(D)錯誤。期貨商受託從事之期貨交易種類及交易所，以主管機關公告者為限；若不設限，期貨商可能引進未經評估的境外商品。

5. 我國期貨商受託從事之期貨交易，其種類及交易所以何公告者為限？
  1. (A)期貨商品管理委員會
  2. (B)金融監督管理委員會
  3. (C)財政部
  4. (D)經濟部
解析

(A)錯誤。我國沒有「期貨商品管理委員會」這個機關；期貨商品的審查與公告由金管會統籌，實務上由其下的證券期貨局承辦，不是另設委員會。

(B)正確。期貨交易法第4條規定主管機關為金融監督管理委員會，第5條規定期貨商受託從事之期貨交易，其種類及交易所以主管機關公告者為限。以正面表列方式公告可承作的商品與交易所，主管機關才能事先把關商品風險、結算安全與資訊揭露，避免期貨商代客承作監理不及的境外商品。

(C)錯誤。財政部在金管會成立前曾主管證券期貨業務，二○○四年金管會成立後主管權已移轉，現行期貨交易法第4條明定主管機關是金管會。

(D)錯誤。經濟部主管公司登記與商業事務，期貨商設立時的公司登記由經濟部辦理，但期貨業務的許可、監理與商品公告都屬金管會權責。

6. 會員制期貨交易所申請核發許可證照的期限，下列何者不正確？
  1. (A)應自主管機關許可之日起6 個月內完成法人設立登記
  2. (B)有正當理由者，得向主管機關申請延展
  3. (C)延展期限不得超過3 個月
  4. (D)申請延展以1 次為限
解析

(A)錯誤（此項敘述無誤）。期貨交易所設立標準第8條規定會員制期貨交易所應自主管機關許可之日起六個月內完成法人設立登記，並申請核發許可證照。

(B)錯誤（此項敘述無誤）。同條規定有正當理由者，得在期限屆滿前向主管機關申請延展，避免因籌設中的客觀障礙就喪失許可。

(C)正確（此項敘述有誤）。設立標準第8條規定延展期限不得超過「六個月」，而非三個月，選項所載期間與規定不符。六個月本身期限加最多六個月延展，籌設期上限為一年；「期限、延展長度、延展次數」三個要素要分別記憶。

(D)錯誤（此項敘述無誤）。同條規定申請延展以一次為限，避免籌設方反覆延期占用許可資源。

7. 公司制期貨交易所應於每月10 日以前，向主管機關申報上月份：甲.綜合損益表；乙.資產負債表；丙.現金流量表；丁.股東權益變動表；戊.會計項目月計表
  1. (A)甲、乙、丙、丁、戊

  4. (D)甲、乙、戊

8. 依我國期貨交易法之規定，下列有關公司制期貨交易所之敘述何者正確？
  1. (A)組織型態為股份有限公司
  2. (B)可由單一股東獨資
  3. (C)股東人數須超過7 人
  4. (D)最低實收資本額為新臺幣3 億元
解析

(A)正確。期貨交易法第34條規定，公司制期貨交易所之組織以股份有限公司為限。股份有限公司有明確的資本結構、董事會與監察人的治理機制，能承擔市場經營與違約處理責任，也便於主管機關要求提列特別盈餘公積等財務監理。

(B)錯誤。第34條並規定單一股東持股比例原則上不得超過實收資本額百分之五，正是要防止交易所被單一股東掌控，獨資顯然違反此設計。

(C)錯誤。期貨交易法沒有公司制交易所股東人數的規定；「不得少於七人」是第22條對會員制期貨交易所會員人數的要求，把會員數套到股東數是常見混淆。

(D)錯誤。期貨交易所設立標準第10條規定公司制期貨交易所最低實收資本額為新臺幣十億元，兼營期貨結算機構者為二十億元；三億元是期貨信託事業的最低實收資本額。

115年第1次｜期貨交易法規｜第 11 題
11. 某期貨結算機構之實收資本額為新臺幣二十億元，請問其應繳存之營業保證金金額為何？
  1. (A)新臺幣二億元
  2. (B)新臺幣一億元
  3. (C)新臺幣五千萬元
  4. (D)新臺幣二千五百萬元
解析

(A)錯誤。二億元是實收資本額的百分之十，比率取錯一倍；二億元另一個容易混淆的出處是結算機構發起人於申請許可時應存入的款項，那是設立階段的存入款而非營業保證金。

(B)正確。期貨結算機構管理規則第12條規定，結算機構應向國庫繳存營業保證金，金額為實收資本額百分之五，並以現金、政府債券或金融債券繳存。代入：二十億元×5%＝一億元。以資本額的固定比率計算，保證金隨機構規模等比例成長，規模愈大、對市場影響愈廣者提存愈多。

(C)錯誤。五千萬元是二十億元的百分之二點五，等於把法定比率5%再對半；也可能是與期貨交易所固定額的營業保證金五千萬元混淆，結算機構採比率制而非固定額。

(D)錯誤。二千五百萬元只有二十億元的百分之一點二五，是5%的四分之一；此數字是期貨信託事業發起人申請時的存入款項，與結算機構營業保證金無關。

115年第1次｜期貨交易法規｜第 12 題
12. 依期貨交易法之規定，下列關於期貨交易所之敘述，何者錯誤？
  1. (A)期貨交易所之組織，分會員制及公司制
  2. (B)期貨交易所應向國庫繳存營業保證金
  3. (C)公司制期貨交易所得發行無記名股票
  4. (D)期貨交易所以提供期貨集中交易市場為其業務，非經主管機關核准，不得經營其他業務或投資其他事業
解析

(A)錯誤。期貨交易所之組織確分為會員制與公司制兩種，敘述正確。

(B)錯誤。期貨交易所應向國庫繳存營業保證金，敘述正確（期貨商則是向主管機關指定之金融機構繳存）。
