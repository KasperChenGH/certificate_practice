準備建議

合格看兩科總分：合計達 140 分，且任一科不得低於 60 分（見上方考試資訊）。所以一科略弱可以由另一科補，但不能讓任何一科掉到 60 分以下。

這是本站收錄的考試中歷屆重出最明顯的一項（見上方「歷屆重出」表），兩科都有相當比例的題目與舊卷幾乎相同，另有一些只改了數字或問法。先把近幾回的試卷完整做過一遍、錯題回頭看解析，是投報率最高的準備方式。

兩科的出題型態不同：期貨交易法規的否定式題目（問「何者錯誤」「何者不包括」）明顯比實務科多，讀題時先確認問的是哪一邊；期貨交易理論與實務則有少數計算題，例如選擇權價差的損益、保證金的追繳，改題重出時通常就是換了履約價或價格。

1. 在美國，期貨交易所擬上市的期貨交易契約，其標的為國庫券或政府公債，商品期貨交易委員會在該期貨交易契約上市前，應將期貨交易所之申請書副知下列何機構？
  1. (A)農業部
  2. (B)證券管理委員會(SEC)
  3. (C)財政部(Department of Treasury)及聯邦儲備局理事會(Board of Governors of the FederalReserve System)
  4. (D)全國期貨公會(NFA)
解析

(A)錯誤。農業部是美國農產品期貨的相關部會，CFTC 的前身即設於農業部之下；國庫券與政府公債期貨的標的是聯邦債務，與農業無涉。

(B)錯誤。SEC 是美國證券主管機關，就股票期貨與證券選擇權類商品與 CFTC 分工協調；政府公債期貨的協商對象是負責發債與貨幣政策的機關，不是 SEC。

(C)正確。依美國商品交易法，交易所申請上市以國庫券或政府公債為標的的期貨契約時，CFTC 應將申請書副本送交財政部及聯邦準備理事會並徵詢意見。因為政府債券期貨會影響國債的發行成本與利率市場，而財政部負責發債、聯準會負責貨幣政策，兩者是最直接的利害關係機關。

(D)錯誤。NFA（全國期貨公會）是期貨業的自律組織，負責期貨業者與從業人員的登記與自律管理，不是政府部門間協商政府公債期貨上市的副知對象。

2. 吳先生買一個履約價為15000 的臺指買權、權利金為230，同時賣一個履約價15500 的臺指買權、權利金為180，在臺股指數為多少時，吳先生可以達到損益兩平（不考慮交易手續費及稅）？
  1. (A)15050
  2. (B)15230
  3. (C)15320
  4. (D)15410
解析

(A)正確。買進15000買權付230、賣出15500買權收180，淨支出權利金＝230－180＝50。多頭買權價差的損益兩平點＝較低履約價＋淨權利金＝15000＋50＝15050；指數到15050時，15000買權的內含價值50剛好補回淨成本。

(B)錯誤。15230是15000＋230，只計算買進買權的成本，忽略了賣出15500買權收回的180；那是單獨買進買權的損益兩平點。

(C)錯誤。15320是15500－180，把賣出買權的權利金從高履約價減去；賣出買權單獨的損益兩平點應是履約價加權利金，而價差部位的兩平點更要從低履約價起算。

(D)錯誤。15410是15000＋230＋180，把收取的180也當成支出加上去；賣出買權收到的權利金應減少成本，而不是增加。

3. 臺灣期貨交易所結算會員，依其業務範圍分為：甲.個別結算會員；乙.一般結算會員；丙.全席結算會員；丁.特別結算會員
  1. (A)甲、乙、丙、丁皆是
  2. (B)僅甲、乙
  3. (C)僅甲、乙、丁
  4. (D)僅乙、丙、丁
解析

(A)錯誤。「全席結算會員」不是期交所業務規則的類別，結算會員只分個別、一般、特別三種，把丙也算進去就多列了一項。

(B)錯誤。只列個別與一般結算會員，遺漏了由金融機構擔任、專為期貨商辦理結算交割的特別結算會員。

(C)正確。期交所結算會員依業務範圍分為三種：個別結算會員只為自己的交易辦理結算交割，一般結算會員除自身外還可受託為其他期貨商結算，特別結算會員則是非期貨商的金融機構，專為委託的期貨商辦理結算。業務範圍愈廣、承擔的違約風險愈大，所需的財務能力與保證要求也愈高。

(D)錯誤。個別結算會員確實存在，而且是最基本的類別；反而丙的全席結算會員是虛構名稱，不在規則之中。

4. 生產沙拉油的廠商通常會如何避險？
  1. (A)買黃豆期貨，賣黃豆油期貨
  2. (B)買黃豆油期貨，賣黃豆期貨
  3. (C)買黃豆粉期貨，賣黃豆油期貨
  4. (D)買黃豆油期貨，賣黃豆粉期貨
解析

(A)正確。沙拉油廠買進黃豆壓榨成黃豆油出售，現貨曝險是原料可能漲價、產品可能跌價；因此買黃豆期貨鎖住原料成本，賣黃豆油期貨鎖住產品售價，兩邊一起鎖住加工利潤，這就是壓榨價差（crush spread）避險。

(B)錯誤。買油賣豆的方向剛好相反：黃豆漲價時期貨空頭再虧一次，油價下跌時期貨多頭也跟著虧，反而把現貨曝險加倍，這是押注壓榨利潤擴大的投機，不是避險。

(C)錯誤。黃豆粉是壓榨的另一項產品而非沙拉油廠的原料，買黃豆粉期貨無法鎖住黃豆進料成本。

(D)錯誤。買進產品油、賣出副產品粉，兩邊都是壓榨的產出，完全沒有鎖到黃豆原料成本，與廠商的曝險方向不符。

8. 下列何種情況，歐式買權和賣權的Delta 敏感度最小？
  1. (A)買權深價外，賣權深價外
  2. (B)買權價平，賣權價平
  3. (C)買權深價內，賣權深價外
  4. (D)買權深價外，賣權深價內
解析

(A)正確。深價外的買權與賣權履約機率都極低，Delta絕對值同時趨近於零，敏感度最小。Delta是選擇權價值對標的價格的變動率，深價外時標的小幅變動幾乎不改變「到期會作廢」的判斷，權利金也就幾乎不動。

(B)錯誤。價平時買權Delta約0.5、賣權約－0.5，標的每動1元權利金約動0.5元，敏感度屬中等，且Gamma在此最大，並非最小。

(C)錯誤。買權深價內時Delta趨近1，價格幾乎與標的同步變動，是敏感度最大的情況；即使賣權深價外接近零，兩者合計也不是最小。

(D)錯誤。賣權深價內時Delta趨近－1，絕對值最大；買權深價外雖接近零，整體敏感度並非最小。

1. 期貨商申請設置分支機構,應自主管機關許可之日起,多少時間之內完成分支機構之設立登記?
  1. (A)一個月
  2. (B)二個月
  3. (C)三個月
  4. (D)六個月
解析

(A)錯誤。一個月內完成分支機構設立登記在實務上難以達成：許可後還要找營業處所、建置交易與資訊系統、登記業務員並辦理公司變更登記，法規給的期間比這長得多。

(B)錯誤。二個月仍遠短於法定期間。期貨商設置標準對分支機構設立與期貨商本身的公司設立登記都給六個月，兩個月不是任何一種登記的期限。

(C)錯誤。三個月是法定期間的一半。若記成三個月，會誤以為期貨商必須在許可後一季內完成所有籌備，與期貨商設置標準第17條「六個月內」的規定不符。

115年第2次｜期貨交易理論與實務｜第 6 題
15. 玉米期貨賣權之買方,要求履約時:
  1. (A)以履約價買入玉米
  2. (B)以履約價賣出玉米
  3. (C)以履約價賣出玉米期貨合約,取得玉米期貨空頭部位
  4. (D)以履約價買入玉米期貨合約,取得玉米期貨多頭部位
解析

(A)錯誤。「以履約價買入」是買權（call）履約的結果，而且這裡的標的是期貨契約，不是玉米現貨；賣權買方履約後得到的是賣方部位。

(B)錯誤。方向對了但標的錯了：玉米期貨賣權是「期貨選擇權」，履約時交割的是玉米期貨部位，不是把玉米現貨賣給對方，現貨交割要等期貨到期才會發生。

(C)正確。玉米期貨賣權賦予買方在到期前以履約價「賣出」一口玉米期貨契約的權利。買方要求履約時，結算機構會為買方建立一口以履約價為成本的玉米期貨空頭部位，同時為賣方建立對應的多頭部位。買方之所以想履約，是因為期貨市價低於履約價，取得高價的空單後可立刻以低價回補獲利。

(D)錯誤。以履約價買入期貨、取得多頭部位是「期貨買權」買方履約的結果；賣權的權利是賣出，履約後不可能拿到多頭部位。

112 年第3 次｜期貨交易理論與實務｜第 10 題
17. MSCI臺指期貨目前市價為184.5,則下列委託單何者為正確的委託單?
  1. (A)180.1的停損買單
  2. (B)180.1的觸價買單
  3. (C)180.1的觸價賣單
  4. (D)180.1的限價賣單
解析

(A)錯誤。停損買單是為了在價格漲破某一水準時追價買進（例如空單的停損），觸發價必須設在市價之上；市價 184.5 而觸發價 180.1 在下方，一掛單就立即被觸發，失去停損的意義。

(B)正確。觸價買單（MIT）是在價格跌到指定價位時轉為市價單買進，用來在回檔時逢低承接，因此觸發價必須設在市價之下。市價 184.5、觸價 180.1 位於下方，符合 MIT 買單的方向，是四個選項中唯一方向正確的委託。

(C)錯誤。觸價賣單是等價格漲到指定價位時賣出，觸發價要設在市價之上；180.1 低於市價 184.5，方向相反，屬於無效的設定。

(D)錯誤。限價賣單是要求以指定價或更高的價格賣出，正常設在市價之上等待反彈；設在市價之下的 180.1 會立刻以市價成交，等同市價單，失去以限價控制成交價的作用。

113 年第2 次｜期貨交易理論與實務｜第 10 題
19. 小瑛進行多頭避險,基差應如何變化才會有利潤?
  1. (A)轉弱(由-4變-6)
  2. (B)轉強(由+1變+4)
  3. (C)不變
  4. (D)不一定
解析

(A)正確。多頭避險是預計未來買進現貨而先買進期貨。多頭避險者的損益＝期初基差－期末基差，基差走弱（下降）時獲利。由 −4 變 −6 是基差下降，表示期貨相對現貨漲得更多，期貨部位的獲利超過現貨買價上升的成本，避險反而有額外利潤。直覺上，多頭避險者是「未來要買現貨的人」，期貨相對現貨越強對他越好。

(B)錯誤。由 +1 變 +4 是基差走強，這對空頭避險（持有現貨、賣出期貨）有利，對多頭避險則是期貨漲不過現貨，會產生損失。

(C)錯誤。基差不變代表期貨與現貨等幅變動，期貨損益剛好抵銷現貨成本變動，是完全避險但沒有額外利潤。

(D)錯誤。多頭避險的損益方向由基差走強或走弱唯一決定：走弱獲利、走強虧損，並不是不一定。

  1. (A)賣小麥期貨,賣玉米期貨
  2. (B)買小麥期貨,賣玉米期貨
  3. (C)賣小麥期貨,買玉米期貨
  4. (D)選項(A)(B)(C)皆非

(B)錯誤。方向相反。合理價比小麥:玉米＝1:2，意思是小麥應為玉米的一半，玉米5對應的合理小麥價是2.5，而小麥現在是3.2，代表小麥相對玉米偏貴。買偏貴的小麥、賣偏便宜的玉米，是押價比繼續偏離，不是押回歸。

(D)錯誤。價比偏離合理值本身就是可操作的訊號，選項C的賣小麥、買玉米正是對應的價比套利，並非無解。
