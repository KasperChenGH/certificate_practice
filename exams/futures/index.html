1. 在美國，期貨交易所擬上市的期貨交易契約，其標的為國庫券或政府公債，商品期貨交易委員會在該期貨交易契約上市前，應將期貨交易所之申請書副知下列何機構？
  1. (A)農業部
  2. (B)證券管理委員會(SEC)
  3. (C)財政部(Department of Treasury)及聯邦儲備局理事會(Board of Governors of the FederalReserve System)
  4. (D)全國期貨公會(NFA)
解析

(A)錯誤。農業部是美國農產品期貨的相關部會，CFTC 的前身即設於農業部之下；國庫券與政府公債期貨的標的是聯邦債務，與農業無涉。

(B)錯誤。SEC 是美國證券主管機關，就股票期貨與證券選擇權類商品與 CFTC 分工協調；政府公債期貨的協商對象是負責發債與貨幣政策的機關，不是 SEC。

(C)正確。依美國商品交易法，交易所申請上市以國庫券或政府公債為標的的期貨契約時，CFTC 應將申請書副本送交財政部及聯邦準備理事會並徵詢意見。因為政府債券期貨會影響國債的發行成本與利率市場，而財政部負責發債、聯準會負責貨幣政策，兩者是最直接的利害關係機關。

(D)錯誤。NFA（全國期貨公會）是期貨業的自律組織，負責期貨業者與從業人員的登記與自律管理，不是政府部門間協商政府公債期貨上市的副知對象。

2. 生產沙拉油的廠商通常會如何避險？
  1. (A)買黃豆期貨，賣黃豆油期貨
  2. (B)買黃豆油期貨，賣黃豆期貨
  3. (C)買黃豆粉期貨，賣黃豆油期貨
  4. (D)買黃豆油期貨，賣黃豆粉期貨
解析

(A)正確。沙拉油廠買進黃豆壓榨成黃豆油出售，現貨曝險是原料可能漲價、產品可能跌價；因此買黃豆期貨鎖住原料成本，賣黃豆油期貨鎖住產品售價，兩邊一起鎖住加工利潤，這就是壓榨價差（crush spread）避險。

(B)錯誤。買油賣豆的方向剛好相反：黃豆漲價時期貨空頭再虧一次，油價下跌時期貨多頭也跟著虧，反而把現貨曝險加倍，這是押注壓榨利潤擴大的投機，不是避險。

(C)錯誤。黃豆粉是壓榨的另一項產品而非沙拉油廠的原料，買黃豆粉期貨無法鎖住黃豆進料成本。

(D)錯誤。買進產品油、賣出副產品粉，兩邊都是壓榨的產出，完全沒有鎖到黃豆原料成本，與廠商的曝險方向不符。

3. 臺灣期貨交易所結算會員，依其業務範圍分為：甲.個別結算會員；乙.一般結算會員；丙.全席結算會員；丁.特別結算會員
  1. (A)甲、乙、丙、丁皆是
  2. (B)僅甲、乙
  3. (C)僅甲、乙、丁
  4. (D)僅乙、丙、丁
解析

(A)錯誤。「全席結算會員」不是期交所業務規則的類別，結算會員只分個別、一般、特別三種，把丙也算進去就多列了一項。

(B)錯誤。只列個別與一般結算會員，遺漏了由金融機構擔任、專為期貨商辦理結算交割的特別結算會員。

(C)正確。期交所結算會員依業務範圍分為三種：個別結算會員只為自己的交易辦理結算交割，一般結算會員除自身外還可受託為其他期貨商結算，特別結算會員則是非期貨商的金融機構，專為委託的期貨商辦理結算。業務範圍愈廣、承擔的違約風險愈大，所需的財務能力與保證要求也愈高。

(D)錯誤。個別結算會員確實存在，而且是最基本的類別；反而丙的全席結算會員是虛構名稱，不在規則之中。

4. 吳先生買一個履約價為15000 的臺指買權、權利金為230，同時賣一個履約價15500 的臺指買權、權利金為180，在臺股指數為多少時，吳先生可以達到損益兩平（不考慮交易手續費及稅）？
  1. (A)15050
  2. (B)15230
  3. (C)15320
  4. (D)15410
解析

(A)正確。買進15000買權付230、賣出15500買權收180，淨支出權利金＝230－180＝50。多頭買權價差的損益兩平點＝較低履約價＋淨權利金＝15000＋50＝15050；指數到15050時，15000買權的內含價值50剛好補回淨成本。

(B)錯誤。15230是15000＋230，只計算買進買權的成本，忽略了賣出15500買權收回的180；那是單獨買進買權的損益兩平點。

(C)錯誤。15320是15500－180，把賣出買權的權利金從高履約價減去；賣出買權單獨的損益兩平點應是履約價加權利金，而價差部位的兩平點更要從低履約價起算。

(D)錯誤。15410是15000＋230＋180，把收取的180也當成支出加上去；賣出買權收到的權利金應減少成本，而不是增加。

5. 若客戶原已持有3口6月黃金期貨的多頭部位,當他下達賣出1口6月黃金期貨的委託單,則此一委託單是:
  1. (A)平倉單
  2. (B)新倉單
  3. (C)既不是新倉單,亦非平倉單
  4. (D)可能是新倉單,亦可能是平倉單
解析

(A)正確。客戶持有3口6月黃金期貨多頭部位，再賣出同一契約1口，是把既有多單沖銷1口，剩餘2口多單，屬於平倉單。期貨部位以淨額計算，同一契約的反向交易即為沖銷；平倉後該口的保證金釋放、損益實現。

(B)錯誤。新倉單是建立與現有部位不重疊的新部位，例如在沒有部位時賣出、或買進更多口數加碼；對既有多單作反向賣出不會產生新部位。

(C)錯誤。期貨委託對部位的效果只有兩種：增加部位是新倉、減少部位是平倉。已知持有多單再反向賣出，必然屬於平倉，不存在兩者皆非的情形。

(D)錯誤。若賣出口數超過持有的3口（例如賣5口），超出的2口才會是新倉；賣1口小於持有口數，全數沖銷既有多單，沒有不確定性。

6. 一般而言，大多數期貨契約交割時對標的物有關條件都由賣方決定，下列何種期貨契約交割的地點及方式是由買方決定的？
  1. (A)外匯期貨
  2. (B)T-Bond 期貨
  3. (C)T-Note 期貨
  4. (D)糖期貨
解析

(A)正確。外匯期貨到期交割時，由買方指定收受外幣的銀行帳戶與地點，因為交付的是資金而非實體商品，收款行只有買方知道。其餘商品與債券期貨則多由賣方在合約允許範圍內選擇交割標的、時點與地點。

(B)錯誤。T-Bond期貨由賣方在可交割債券中選擇券別與交割日，屬賣方選擇權。

(C)錯誤。T-Note期貨同樣由賣方決定交割的債券與時點。

(D)錯誤。糖等商品期貨的交割倉庫與等級由賣方在契約規定內選擇。

7. 期貨商之最低實收資本額，發起人於發起時：
  1. (A)可分次認足
  2. (B)應一次認足
  3. (C)法規無明文規定
  4. (D)於發起人會議議決之
解析

(A)錯誤。若允許分次認足，設立時實際到位的資本可能遠低於法定最低額，期貨商從開業起就要承擔客戶部位的履約與結算風險，法規因此不接受分期到位。

(B)正確。期貨商設置標準第8條規定，期貨經紀商最低實收資本額為新臺幣二億元、期貨自營商為四億元，且發起人應於發起時一次認足。期貨商一開業就要為客戶部位負結算履約責任，資本基礎必須自始完整到位，這也是為何不適用公司法分次發行股份的一般彈性。

(C)錯誤。設置標準第8條第2項有明文規定一次認足，並非法規未規定；認為無明文是漏看了資本額條文的第二項。

(D)錯誤。一次認足是法定要求，發起人會議只能決定發起人之間如何分配認股，不能決議改為分次認足或降低到位資本。

8. 若交易人同時買一個履約價為100 的期貨買權，賣一個履約價為140 的期貨買權，則該交易人最大可能損失為：
  1. (A)兩權利金之和
  2. (B)兩權利金之差
  3. (C)無窮大
  4. (D)選項(A)、(B)、(C)皆非
解析

(A)錯誤。兩權利金之和是同時買進兩個選擇權（例如跨式部位）時的最大損失；這裡是一買一賣，收取的權利金會抵掉一部分支出，成本只有兩者之差。

(B)正確。買進履約價100的買權、賣出履約價140的買權，是多頭買權價差；建立時淨支出＝支付的權利金－收取的權利金，即兩權利金之差。若標的到期跌到100以下，兩個買權都無價值，損失就是這筆淨支出，這是該部位的最大可能損失；上漲時獲利則被140的履約價封頂。

(C)錯誤。無窮大是裸賣買權才有的風險。這裡賣出的140買權已被買進的100買權保護，標的漲越高兩邊履約損益互抵，損失不會無限擴大。

(D)錯誤。多頭買權價差的最大損失有明確答案，就是建立部位時的淨支出，即兩權利金之差；選項(B)已正確描述，並非皆非。

1. 有關期貨交易法中各項規定,下列敘述何者錯誤?
  1. (A)期貨商受託從事之期貨交易,其種類及交易所以金管會公告者為限
  2. (B)集中結算之期貨交易範圍涉及外匯事項者,應先會商中央銀行同意
  3. (C)金管會與外國機構合作簽訂須經總統府核准
  4. (D)金管會應參酌創新實驗之辦理情形檢討期貨交易法之妥適性
解析

(A)錯誤。期貨商受託期貨種類以金管會公告者為限，敘述正確。

(B)錯誤。涉及外匯之集中結算期貨應先會商央行同意，敘述正確。

(C)正確（即敘述錯誤）。金管會與外國機構合作簽訂協議無須經總統府核准，僅依職權辦理。

(D)錯誤。金管會應參酌創新實驗檢討期貨交易法妥適性，敘述正確。

2. 於期貨商負責人及業務員管理規則施行前取得期貨業務員資格者，若自取得後一直未辦理期貨業務員登錄達五年，其資格是否喪失？
  1. (A)其資格永久有效
  2. (B)自資格測驗放榜公告日起算，滿五年即喪失資格
  3. (C)由期貨商業同業公會依個案認定
  4. (D)自期貨商負責人及業務員管理規則施行日起算，滿五年即喪失資格
解析

(A)錯誤。業務員資格並非永久有效，長期未登錄者會喪失資格，以確保執業人員專業不脫節。

(B)錯誤。規則施行前取得資格者，若自放榜日起算，可能在規則施行前即喪失資格，有溯及既往問題，因此不以放榜日起算。

(C)錯誤。業務員資格是否喪失由管理規則明定起算點與期間，不是由期貨商業同業公會依個案認定。

(D)正確。依期貨商負責人及業務員管理規則，規則施行前已取得資格者，未登錄的五年期間自規則施行日起算，避免溯及既往，滿五年未登錄即喪失資格。

3. 依我國期貨交易法之規定，最重法定刑處七年有期徒刑之行為，以下何者錯誤？
  1. (A)非期貨商受託從事期貨交易
  2. (B)期貨商有對作之行為
  3. (C)期貨商有詐欺之行為
  4. (D)期貨商對期貨交易人作獲利之保證
解析

(A)錯誤。非期貨商而經營受託期貨交易業務，屬期貨交易法中處罰最重的行為類型之一（七年以下有期徒刑），此敘述正確。

(B)錯誤。期貨商與客戶對作（自為交易相對人）屬期貨交易法所定最重處七年以下有期徒刑的行為，此敘述正確，故非本題答案。

(C)錯誤。期貨商於期貨交易有詐欺行為，嚴重侵害交易人權益，屬最重處七年以下有期徒刑的行為，此敘述正確，故非本題答案。

(D)正確。本題問錯誤者；期貨商對期貨交易人作獲利保證屬違反業務規範的行為，其法定刑較輕，不屬最重處七年有期徒刑的行為。

4. 有關期貨信託契約之規定，下列敘述何者錯誤？
  1. (A)由期貨信託事業為委託人，基金保管機構為受託人所簽訂
  2. (B)用以規範期貨信託事業、基金保管機構及受益人間權利義務之信託契約
  3. (C)應記載運用期貨信託基金從事期貨交易與投資期貨相關現貨商品之基本方針及範圍
  4. (D)期貨信託契約範本由主管機關訂定
解析

(A)錯誤。本敘述正確：期貨信託契約是由期貨信託事業擔任委託人、基金保管機構擔任受託人所簽訂，這是期貨信託基金的法律架構，所以不是本題要選的錯誤敘述。

(B)錯誤。本敘述正確：期貨信託契約的功能正是規範期貨信託事業、基金保管機構與受益人三方的權利義務，因此不是錯誤選項。

(C)錯誤。本敘述正確：信託契約應記載運用基金從事期貨交易及投資期貨相關現貨商品的基本方針與範圍，讓受益人知悉投資策略，非錯誤敘述。

(D)正確。本敘述錯誤，故為答案。期貨信託契約範本並非由主管機關自行訂定，而是由同業公會擬訂後報請主管機關核定，體現自律組織參與訂定規範的機制。

5. 期貨信託事業對不特定人募集之期貨信託基金，除用於交易及投資外，不得以下列何種方式保持之？
  1. (A)向票券商買入短期票券
  2. (B)放款
  3. (C)存放於銀行
  4. (D)債券附買回交易
解析

(A)錯誤。向票券商買入短期票券屬安全、短期且流動性高的資金保持方式，是期貨信託基金閒置資金得採用的方式之一。

(B)正確。期貨信託基金的資產屬受益人所有，除交易及投資外，閒置資金只能以存放銀行、買入短期票券、債券附買回等安全且流動的方式保持；放款會使基金承擔借款人信用風險並可能被挪用，因此不得為之。

(C)錯誤。存放於銀行是基金閒置資金最基本的保持方式，安全且可隨時動用，屬允許範圍。

(D)錯誤。債券附買回交易期限短、有債券擔保、風險低，屬基金閒置資金得採用的保持方式，並非禁止事項。

110年第1次｜期貨交易法規｜第 16 題
6. 假設公司制期貨交易所之交易業務委員會共有9 位委員，依我國期貨交易法之規定，至少應有幾位為在該交易所交易之期貨商？
  1. (A)1 位
  2. (B)2 位
  3. (C)3 位
  4. (D)沒有限制
解析

(A)錯誤。1 位只占 9 位的九分之一，低於期貨交易法第38條要求的三分之一；把「至少要有期貨商代表」誤解為「有一位即可」就會得到此答案。

(B)錯誤。2 位占 9 位的九分之二，仍未達三分之一（9÷3＝3）；若把 9×1/3 取整時誤向下捨去成 2，就會得到此錯誤答案。

(C)正確。期貨交易法第38條規定公司制期貨交易所應設業務委員會及紀律委員會，成員至少應有三分之一為在該交易所交易的期貨商。9×1/3＝3，故至少 3 位。納入實際交易者是要讓交易規則能反映市場實務，而以三分之一為最低比例，既保障業者聲音，又避免業者主導。

(D)錯誤。期貨交易法第38條對委員會的期貨商比例設有明文下限，並非毫無限制；「沒有限制」是把交易所自治誤當成完全不受法律規範。

  1. (A)Gramm-Leach-Bliley Act
  2. (B)Glass-Steagall Act
  3. (C)Dodd-Frank Act
  4. (D)Commodity Exchange Act
解析

(D)錯誤。Commodity Exchange Act為1936年即已存在的商品交易基本法，並非2010年制定。

112 年第2 次｜期貨交易法規｜第 37 題
9. 依我國期貨交易法,會員被停止交易時,期貨交易所得採取之措施,下列何者正確?
  1. (A)期貨交易所應依章程規定,責令本人了結其於期貨交易所所為之交易
  2. (B)期貨交易所得對該會員處以罰鍰
  3. (C)期貨交易所得沒收其繳交之結算保證金
  4. (D)期貨交易所不得指定其他會員了結其於期貨交易所所為之交易
解析

(A)正確。期貨交易法規定，會員退會或被停止交易時，會員制期貨交易所應依章程之規定，責令本人或指定其他會員了結其於期貨交易所所為之交易。停止交易後該會員不能再下單，但既有部位不能懸而未決，法律要求交易所依章程強制其了結，以免未平倉部位的風險持續累積並波及市場。

(B)錯誤。罰鍰是行政罰，由主管機關依期貨交易法罰則章裁處；期貨交易所對會員能採取的是章程或業務規則所定的違約金、停止交易等自律措施，不是罰鍰。

(C)錯誤。結算保證金是繳存於結算機構的履約擔保，只能依結算規則用來抵充該會員違約所造成的損失，交易所無權因會員被停止交易就逕行沒收。

(D)錯誤。法條明文允許交易所責令本人或指定其他會員了結交易，指定其他會員代為了結正是本人無法處理時的備援機制，說不得指定與法律規定相反。

113 年第3 次｜期貨交易法規｜第 35 題
11. 臺灣期貨商的客戶繳交保證金的方式為:
  1. (A)攜帶現金至期貨商繳給出納人員
  2. (B)由客戶的銀行帳戶匯款或轉帳至期貨商的客戶保證金專戶
  3. (C)攜帶支票至期貨商繳給出納人員
  4. (D)法規沒有規定
解析

(A)錯誤。保證金若以現金交給期貨商出納，資金就進不了與期貨商自有資產分離的客戶保證金專戶，等於由員工經手客戶資金，正是挪用風險最高的路徑，法規要求款項須經銀行帳戶入專戶。

(B)正確。期貨交易法要求期貨商將客戶保證金存入獨立的客戶保證金專戶，與自有財產分離；期貨商管理規則第44條並規定專戶款項的收付應以轉帳方式辦理並留下收付憑證。因此客戶繳交保證金須由自己的銀行帳戶匯款或轉帳至期貨商的客戶保證金專戶，讓每一筆資金都有銀行紀錄可稽，不經人手。

(C)錯誤。支票同樣是交到期貨商人員手上的票據，須另行提示兌現，資金未直接進入專戶且有退票風險，不符合以銀行轉帳入專戶的要求。

(D)錯誤。保證金的收付方式是有明文規範的，期貨交易法設有客戶保證金專戶制度，期貨商管理規則也規定專戶款項以轉帳方式收付，並不是法規未規定。

102年第4次｜期貨交易理論與實務｜第 35 題
13. 在風險告知書中，強調交易人雖下達停損單，其損失有時不一定可以控制在交易人預定範圍之內，其原因是：
  1. (A)市場上於停損價附近成交量太大
  2. (B)市場上於停損價附近發生崩盤或噴出走勢，以致沒有成交量
  3. (C)市場行情呈現牛皮走勢
  4. (D)市場行情呈緩慢下跌狀況
解析

(A)錯誤。停損價附近成交量大，停損單較容易在接近停損價的價位成交，反而有利於控制損失。

(B)正確。停損單觸發後轉為市價單，若停損價附近出現崩盤或噴出、市場沒有成交量，成交價可能遠離停損價，損失就無法控制在預定範圍內，這正是風險告知書強調的原因。

(C)錯誤。牛皮盤整走勢價格變動小，停損單成交價通常接近停損價，不是損失失控的原因。

(D)錯誤。緩慢下跌時市場仍有連續成交，停損單可在停損價附近成交，不會使損失明顯超出預期。

16. 某廠商必須進口小麥，為了避險買進了10 口小麥期貨，每口契約規格為5,000 蒲氏爾(Bushels)。若基差由+40 美分放大為+60 美分，則避險的損益為何？

  3. (C)損失5,000 美元
  4. (D)獲利5,000 美元
解析

(B)錯誤。方向相反：基差走強獲利的是賣出避險者（持有現貨、放空期貨），買進避險者在基差走強時是損失。

113 年第1 次｜期貨交易理論與實務｜第 41 題
20. 臺灣期貨交易所之結算會員,應於何時增繳交割結算基金?甲、財產經法院為終局執行者;乙、簽發之票據因存款不足退票,且未經註銷紀錄者;丙、內部稽核作業評等欠佳,經輔導考核仍未見改善者;丁、依該期貨交易所結算會員經營風險預警作業辦法評等欠佳者
  1. (A)僅乙、丙、丁
  2. (B)僅甲、乙、丙
  3. (C)僅甲、乙
  4. (D)甲、乙、丙、丁皆是
解析

(A)錯誤。財產經法院為終局執行，代表結算會員已有債務無法清償而被強制執行，是最直接的信用惡化訊號，當然屬於應增繳交割結算基金的情事，不能排除甲。

(B)錯誤。依期交所結算會員經營風險預警作業辦法評等欠佳，正是期交所用來提早偵測會員財務與作業風險的機制，評等欠佳即應增繳基金，排除丁並不合理。

(C)錯誤。內部稽核評等欠佳且經輔導仍未改善（丙）與風險預警評等欠佳（丁）雖不像被執行或退票那樣是已發生的違約事件，但都是作業與財務風險升高的警訊，同樣列為增繳事由。

(D)正確。依臺灣期貨交易所結算會員管理相關章則，結算會員財產經法院終局執行、票據因存款不足退票且未註銷紀錄、內部稽核評等欠佳經輔導仍未改善、依風險預警作業辦法評等欠佳者，都應增繳交割結算基金。交割結算基金是會員違約時的共同損失填補來源，會員信用轉弱時要求其多繳，等於讓風險升高者自己承擔更多擔保。
