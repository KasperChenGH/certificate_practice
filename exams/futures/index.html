1. 關於期貨商設置分支機構之規定,下列何者正確?
  1. (A)分支機構業務員人數不得低於三人
  2. (B)期貨商於申請設置許可時,得同時申請設置分支機構
  3. (C)期貨商於申請設置許可時,同時申請設置分支機構者,每申請設置一家分支機構,應增加申請設立許可保證金一千萬元
  4. (D)以上皆是
解析

(A)錯誤。這一項本身是對的：期貨商設置標準第15條規定分支機構業務員最低人數不得低於三人。但B與C也是正確的規定，所以只選A不完整。早年已廢止的期貨經紀商設置標準曾定五人，記成五人就會誤判此項。

(B)錯誤。這一項本身是對的：期貨商設置標準第13條規定期貨商於申請設置許可時，得同時申請設置分支機構。但A與C同樣是現行規定，單選B會漏掉其他正確敘述。

(C)錯誤。這一項本身是對的：期貨商設置標準第10條規定，期貨商設置時同時申請設置分支機構者，每設置一家分支機構，應存入的款項增加新臺幣一千萬元。但A與B也正確，單選C不完整。

(D)正確。三項都是期貨商設置標準的現行規定：第15條分支機構業務員不得低於三人，第13條期貨商申請設置許可時得同時申請設置分支機構，第10條每同時申請設置一家分支機構應增加存入款項新臺幣一千萬元。三人是維持一家分支機構最基本的分工需求，增加一千萬元則是讓每個新據點都有對應的資本擔保。

2. 依我國期貨交易法規定，期貨交易所執行市場監視時，發現期貨交易有嚴重影響市場交易秩序之虞者，得對該期貨交易採取之措施，不包括下列何者？
  1. (A)沒收保證金
  2. (B)限制期貨商受託買賣數量
  3. (C)停止該期貨交易
  4. (D)其他維護市場秩序或保護期貨交易人之必要措施
解析

(A)正確（即不包括者）。沒收保證金屬剝奪財產權之處分，非期貨交易所市場監視所得採取之措施；交易所的監視手段是限制、暫停交易等市場管理作為，財產權之剝奪須有明確法律依據並由司法或主管機關為之。

(B)錯誤。限制期貨商受託買賣數量屬得採取之市場監視措施。

(C)錯誤。停止該期貨交易屬得採取之市場監視措施。

(D)錯誤。其他維護市場秩序或保護交易人之必要措施為概括授權，屬得採取之措施。

114年第3次｜期貨交易法規｜第 9 題
3. 我國期貨商受託從事之期貨交易，其種類及交易所以何公告者為限？
  1. (A)期貨商品管理委員會
  2. (B)金融監督管理委員會
  3. (C)財政部
  4. (D)經濟部
解析

(A)錯誤。我國沒有「期貨商品管理委員會」這個機關；期貨商品的審查與公告由金管會統籌，實務上由其下的證券期貨局承辦，不是另設委員會。

(B)正確。期貨交易法第4條規定主管機關為金融監督管理委員會，第5條規定期貨商受託從事之期貨交易，其種類及交易所以主管機關公告者為限。以正面表列方式公告可承作的商品與交易所，主管機關才能事先把關商品風險、結算安全與資訊揭露，避免期貨商代客承作監理不及的境外商品。

(C)錯誤。財政部在金管會成立前曾主管證券期貨業務，二○○四年金管會成立後主管權已移轉，現行期貨交易法第4條明定主管機關是金管會。

(D)錯誤。經濟部主管公司登記與商業事務，期貨商設立時的公司登記由經濟部辦理，但期貨業務的許可、監理與商品公告都屬金管會權責。

115年第1次｜期貨交易法規｜第 6 題
4. 關於期貨交易之規定，下列何者有誤？
  1. (A)原則上應在期貨交易所進行
  2. (B)期貨交易法之主管機關為期貨交易所
  3. (C)期貨交易法之立法目的為健全發展期貨市場，維護期貨交易秩序
  4. (D)期貨業得依金融科技發展與創新實驗條例申請辦理期貨業務創新實驗，而不適用期貨交易法之規定
解析

(A)錯誤（此敘述正確）。期貨交易原則上應於期貨交易所進行。

(B)正確（即敘述有誤者）。期貨交易法的主管機關為金融監督管理委員會；期貨交易所是被監理的市場經營機構，其章則仍須報主管機關核准。監理者與被監理者不能是同一人。

(C)錯誤（此敘述正確）。健全發展期貨市場、維護期貨交易秩序確為該法之立法目的。

(D)錯誤（此敘述正確）。依金融科技發展與創新實驗條例辦理之創新實驗，於實驗期間得不適用期貨交易法之相關規定。

115年第2次｜期貨交易法規｜第 3 題
5. 在美國，期貨交易所擬上市的期貨交易契約，其標的為國庫券或政府公債，商品期貨交易委員會在該期貨交易契約上市前，應將期貨交易所之申請書副知下列何機構？
  1. (A)農業部
  2. (B)證券管理委員會(SEC)
  3. (C)財政部(Department of Treasury)及聯邦儲備局理事會(Board of Governors of the FederalReserve System)
  4. (D)全國期貨公會(NFA)
解析

(A)錯誤。農業部是美國農產品期貨的相關部會，CFTC 的前身即設於農業部之下；國庫券與政府公債期貨的標的是聯邦債務，與農業無涉。

(B)錯誤。SEC 是美國證券主管機關，就股票期貨與證券選擇權類商品與 CFTC 分工協調；政府公債期貨的協商對象是負責發債與貨幣政策的機關，不是 SEC。

(C)正確。依美國商品交易法，交易所申請上市以國庫券或政府公債為標的的期貨契約時，CFTC 應將申請書副本送交財政部及聯邦準備理事會並徵詢意見。因為政府債券期貨會影響國債的發行成本與利率市場，而財政部負責發債、聯準會負責貨幣政策，兩者是最直接的利害關係機關。

(D)錯誤。NFA（全國期貨公會）是期貨業的自律組織，負責期貨業者與從業人員的登記與自律管理，不是政府部門間協商政府公債期貨上市的副知對象。

112 年第2 次｜期貨交易法規｜第 49 題
7. 證券商申請其分支機構經營期貨交易輔助業務,以下列何者為限?
  1. (A)證券商同時兼營期貨經紀業務者
  2. (B)以其總公司有經營期貨交易輔助業務者為限
  3. (C)以其總公司有經營期貨自營業務者為限
  4. (D)選項(A)(B)(C)皆可
解析

(A)錯誤。證券商是否同時兼營期貨經紀業務不是分支機構申請期貨交易輔助業務的條件；兼營期貨經紀的是期貨商資格，與輔助人資格是兩套不同的許可。

(B)正確。依證券商經營期貨交易輔助業務管理規則第十四條，證券商申請其分支機構經營期貨交易輔助業務，以其總公司有經營期貨交易輔助業務者為限。輔助業務是受期貨商委任招攬客戶與接受委託，分支機構的作業與內控都要納入總公司的管理，所以總公司必須先取得輔助人資格，分支機構才能跟著辦理。

(C)錯誤。期貨自營業務是期貨商自己用自有資金交易，與替期貨商招攬客戶的輔助業務無關；總公司有無經營期貨自營業務不是分支機構申請輔助業務的要件。

(D)錯誤。三個條件不是任選其一，規則只承認一種情形：總公司本身有經營期貨交易輔助業務；兼營期貨經紀或期貨自營都不是替代條件。

112 年第3 次｜期貨交易法規｜第 48 題
8. 期貨經理事業應設置部門專責辦理之業務項目,下列何者不包括在內?
  1. (A)推廣招攬
  2. (B)研究分析
  3. (C)交易執行
  4. (D)內部稽核
解析

(A)錯誤。推廣招攬是期貨經理事業管理規則第9條明列的專責業務之一，招攬客戶簽訂全權委託契約必須由專責部門與登記合格的業務員辦理。

(B)錯誤。研究分析是期貨經理事業管理規則第9條明列的專責業務，為交易決定提供依據，必須與交易執行分開以避免利益衝突。

(C)錯誤。交易執行是期貨經理事業管理規則第9條明列的專責業務，負責依交易決定下單並管理客戶的部位。

(D)正確。期貨經理事業管理規則第9條規定，期貨經理事業應設置部門專責辦理全權委託期貨交易業務之研究分析、交易決定、交易執行及推廣或招攬。內部稽核不在這份業務部門清單內，它是依內部控制制度另設、直屬董事會的獨立單位，職責是檢查前述各業務部門；若把稽核列在同一層的業務部門裡，就失去了獨立性。

113 年第1 次｜期貨交易法規｜第 45 題
9. 公司制期貨交易所之非股東董事、監察人,由主管機關指派者,至少占全體董事、監察人之:
  1. (A)四分之一
  2. (B)六分之一
  3. (C)八分之一
  4. (D)十分之一
解析

(A)錯誤。四分之一是期貨交易法第36條規定非股東相關專家在董事、監察人中的最低總比例，而不是主管機關指派的部分；指派者只占其中半數。

(B)錯誤。六分之一不對應法條中的任何比例；若主管機關指派占六分之一，會超過非股東專家總數（四分之一）的半數，與「其中半數由主管機關指派」不符。

(C)正確。期貨交易法第36條規定公司制期貨交易所之董事、監察人至少四分之一由非股東之相關專家擔任，其中半數由主管機關指派，餘由董事會遴選後報主管機關核定。四分之一的一半即八分之一，這就是主管機關指派者的最低占比。設計用意是在股東主導的公司制交易所中保留公益席次，避免交易所決策完全由股東利益左右。

(D)錯誤。十分之一低於法定的八分之一；把四分之一的半數算錯，或誤以為公益董事只需象徵性席次，才會得到這個數字。

113 年第3 次｜期貨交易法規｜第 5 題
10. 有關經營證券全權委託業務之證券投資顧問公司,可經營之期貨業務項目,以下敘述何者正確?
  1. (A)期貨經紀業務及期貨自營業務
  2. (B)期貨顧問業務及期貨經理業務
  3. (C)期貨信託業務及期貨信託基金之銷售機構
  4. (D)期貨交易輔助人業務及期貨結算機構業務
解析

(A)錯誤。期貨經紀與期貨自營是期貨商的業務，必須依期貨商設置標準另行取得期貨商許可並具備相應資本額；證券投資顧問公司不能以兼營方式經營這兩項業務。

(B)正確。經營全權委託投資業務的證券投資顧問事業，得申請兼營期貨顧問事業與期貨經理事業。這兩項期貨業務的性質（提供分析建議、受託操作）與投顧原有的顧問及全權委託業務相同，只是標的從證券擴展到期貨，人員資格與內控架構可以延伸使用，所以法規允許兼營。

(C)錯誤。期貨信託業務是募集基金並運用，需要期貨信託事業的資格；至於期貨信託基金的銷售機構是基金銷售通路，並非投顧公司「經營之期貨業務項目」，此項的組合不成立。

19. 下列有關期貨避險的敘述,何者是正確的判斷多頭避險(longhedge)與空頭避險(shorthedge)?
  1. (A)依避險時間的長短來判斷
  2. (B)依買進或賣出期貨部位來判斷
  3. (C)依現貨部位是多頭或空頭來判斷
  4. (D)依期貨和現貨價格變動是正向或負向來判斷
解析

(A)錯誤。避險時間長短影響的是選擇哪個月份的期貨契約與基差風險大小，不影響避險屬於多頭或空頭。

(B)正確。多頭避險（long hedge）與空頭避險（short hedge）以避險者在期貨市場所建立的部位命名：買進期貨避險即多頭避險，賣出期貨避險即空頭避險。這個命名對應現貨狀況：未來需要買進現貨（現貨空頭）的人買期貨鎖住成本，持有現貨（現貨多頭）的人賣期貨鎖住售價，但判斷名稱時看的是期貨部位方向。

(C)錯誤。現貨部位的多空與避險名稱剛好相反：現貨多頭做的是空頭避險，現貨空頭做的是多頭避險；用現貨方向判斷會把名稱弄反。

(D)錯誤。期貨與現貨價格幾乎總是同向變動，價格變動的正負向是避險能否有效的前提，不是區分多頭或空頭避險的依據。
