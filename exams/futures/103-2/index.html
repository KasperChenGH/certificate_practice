1. 依我國期貨交易法，得公告不適用期貨交易法之期貨交易的規定，下列何者正確？
  1. (A)須由經濟部公告
  2. (B)不必基於金融、貨幣、外匯、公債等政策考量
  3. (C)須由期貨商向主管機關申請核准
  4. (D)須非在期貨交易所進行之期貨交易
解析

(A)錯誤。公告不適用期貨交易法的權限屬於主管機關（金融監督管理委員會），並非經濟部。

(B)錯誤。法律明定此公告須基於金融、貨幣、外匯、公債等政策考量，不是可以不必有政策理由。

(C)錯誤。此為主管機關依政策考量主動公告的事項，並非由期貨商向主管機關申請核准。

(D)正確。期貨交易法規定，非在期貨交易所進行之期貨交易，基於金融、貨幣、外匯、公債等政策考量，得由主管機關公告不適用本法。

2. 依我國期貨交易法，槓桿保證金契約買方取得權利的方式，下列何者正確？Ⅰ.支付價金的一定成數；Ⅱ.雙方達成約定即可；Ⅲ.取得他方授與之一定信用額度；Ⅳ.向期貨商辦理登記
  1. (A)Ⅲ、Ⅳ
  2. (B)Ⅰ、Ⅲ
  3. (C)Ⅱ、Ⅳ
  4. (D)Ⅰ、Ⅳ
解析

(A)錯誤。Ⅳ向期貨商辦理登記並不是槓桿保證金契約的定義要件，買方取得權利的方式是支付一定成數價金或取得信用額度。

(B)正確。期貨交易法定義槓桿保證金契約：一方支付價金一定成數之款項（Ⅰ）或取得他方授與之一定信用額度（Ⅲ），於未來結算差價或交付約定物。

(C)錯誤。Ⅱ僅雙方達成約定並不足以構成，Ⅳ向期貨商登記也不是定義要件，兩者皆非法定的取得權利方式。

(D)錯誤。Ⅰ支付價金一定成數雖正確，但Ⅳ向期貨商辦理登記不是法定方式，且漏列Ⅲ取得信用額度。

4. 依我國期貨交易法之規定，下列有關選擇權契約與期貨選擇權契約之敘述，何者正確？
  1. (A)兩者之買方均須支付權利金，有履約義務
  2. (B)兩者之賣方收受權利金，無履約權利
  3. (C)兩者之標的物皆為期貨契約
  4. (D)兩者均只能於到期時結算差價
解析

(A)錯誤。選擇權與期貨選擇權的買方支付權利金後取得的是權利而非義務，可選擇是否履約，並無履約義務。

(B)正確。依期貨交易法的定義，兩種契約的賣方都是收受權利金，於買方要求履約時負有履約義務，本身不享有要求履約的權利。

(C)錯誤。選擇權契約的標的為約定的商品（如股價指數、股票等），只有期貨選擇權契約的標的才是期貨契約。

(D)錯誤。兩者依約定可交付標的物或結算差價，美式選擇權更可在到期前隨時履約，並非只能於到期時結算差價。

14. 對於結算會員之結算、交割行為違背誠實信用，以致他人受損害者，期貨結算機構得採取下列何種處分？Ⅰ.限制其交易數量；Ⅱ.課以違約金；Ⅲ.停止或限制其於期貨結算機構所為結算、交割；Ⅳ.命令該結算會員追加交割結算基金
