期貨交易法規　42 題

1. 依我國期貨交易法之規定，下列何者非全由主管機關定之或限制？
  1. (A)公告非在期貨交易所進行之期貨交易不適用期貨交易法
  2. (B)公司制期貨交易所公益董事之遴選辦法
  3. (C)主管機關檢查與期貨商財務業務往來關係人的範圍
  4. (D)主管機關派員監理期貨結算機構的監理辦法
解析

(A)正確。依本題之鍵，非在期貨交易所進行之期貨交易是否排除適用期貨交易法，並非僅由主管機關單獨決定，涉及其他機關職掌與法定條件，故為「非全由主管機關定之」之項目。

(B)錯誤。公司制期貨交易所公益董事之遴選辦法，期貨交易法明定由主管機關定之，屬全由主管機關訂定之事項，不符題意。

(C)錯誤。主管機關得檢查與期貨商有財務、業務往來之關係人，其範圍依法由主管機關定之，屬全由主管機關決定之事項。

(D)錯誤。主管機關得派員監理期貨結算機構，其監理辦法依法由主管機關定之，屬全由主管機關訂定之事項，不符題意。

114年第2次｜期貨交易法規｜第 2 題
2. 依據我國期貨交易法之規定，所稱期貨交易，下列敘何者錯誤？
  1. (A)指依國內外期貨交易所或其他期貨市場之規則或實務
  2. (B)從事衍生自商品、貨幣、有價證券、利率、指數或其他利益之契約(例如：期貨契約)或其組合之交易
  3. (C)槓桿保證金契約指當事人約定，於未來特定期間內，依約定方式交換約定標的物或其所產生現金流量之契約
  4. (D)期貨選擇權契約指當事人約定，選擇權買方支付權利金，取得購入或售出之權利，得於特定期間內，依特定價格數量等交易條件買賣期貨契約；選擇權賣方，於買方要求履約時，有依選擇權約定履行義務；或雙方同意於到期前或到期時結算差價之契約
解析

(A)錯誤。期貨交易法所稱期貨交易，確係指依國內外期貨交易所或其他期貨市場之規則或實務所從事之交易，此敘述正確，非本題答案。

(B)錯誤。期貨交易之標的確係衍生自商品、貨幣、有價證券、利率、指數或其他利益之契約或其組合，此為法定定義，敘述正確。

(C)正確。此描述「於未來特定期間內依約定方式交換約定標的物或其所產生現金流量」者，是交換契約的定義；槓桿保證金契約是支付價金一定成數或取得信用額度，於未來結算差價或交付約定物之契約，故此敘述錯誤。

(D)錯誤。所述買方支付權利金取得買賣期貨契約之權利、賣方於買方要求時履約或雙方結算差價，正是期貨選擇權契約之法定定義，敘述正確。

3. 下列有關期貨業務創新實驗之敘述，何者錯誤？
  1. (A)依金融科技發展與創新實驗條例申請辦理期貨業務創新實驗
  2. (B)創新實驗於主管機關核准辦理之期間及範圍內，得不適用期貨交易法
  3. (C)主管機關應參酌創新實驗之辦理情形檢討期貨交易法之妥適性
  4. (D)期貨業務創新實驗僅能由期貨業申請辦理
解析

(A)錯誤。期貨業務創新實驗確係依金融科技發展與創新實驗條例申請辦理，此敘述正確，非本題所問之錯誤敘述。

(B)錯誤。經主管機關核准之創新實驗，於核准之期間及範圍內得不適用期貨交易法之相關規定，此為監理沙盒之核心機制，敘述正確。

(C)錯誤。期貨交易法規定主管機關應參酌創新實驗之辦理情形，檢討期貨交易法之妥適性，以回饋法規修正，敘述正確。

(D)正確。依金融科技發展與創新實驗條例，申請創新實驗者不以期貨業為限，非期貨業之自然人、法人等亦可申請，故「僅能由期貨業申請」之敘述錯誤。

4. 下列何者得擔任期貨交易所之經理人？
  1. (A)期貨機構工作經驗3 年以上，並曾擔任期貨機構副理職務
  2. (B)證券機構工作經驗5 年以上，並曾擔任證券機構副理職務

5. 期貨交易所之設立標準及管理規則由何機關定之？
  1. (A)財政部
  2. (B)金融監督管理委員會
  3. (C)期貨交易所董事會
  4. (D)經濟部
解析

(A)錯誤。財政部並非期貨交易法之主管機關；期貨市場之監理已由金融監督管理委員會掌理，交易所設立標準不由財政部訂定。

(D)錯誤。經濟部主管一般公司登記與商業事務，並非期貨交易法之主管機關，無權訂定期貨交易所之設立標準及管理規則。
