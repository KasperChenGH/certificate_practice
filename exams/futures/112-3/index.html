1. 我國期貨交易法之立法目的為何?
  1. (A)發展國民經濟,提升國際競爭力
  2. (B)促進公共利益,確保期貨市場交易之公正
  3. (C)健全發展期貨市場,維護期貨交易秩序
  4. (D)保障公益,維護市場秩序
解析

(A)錯誤。「發展國民經濟」是證券交易法第1條的用語（發展國民經濟，並保障投資），提升國際競爭力則是產業政策法規的宣示語句，期貨交易法第1條並未採用。

(B)錯誤。公共利益與交易公正是監理法規的一般性目標，期貨交易法在第96條「損害公益」等處才用到類似字眼，第1條的立法目的並沒有這兩個詞。

(C)正確。期貨交易法第1條明定「為健全發展期貨市場，維護期貨交易秩序，特制定本法」，立法目的就是這兩項。市場健全與交易秩序是期貨交易人權益的前提，所以條文用這兩句概括，而不另列保障投資人。

(D)錯誤。只講對了一半：第1條說的是「維護期貨交易秩序」，另一半是「健全發展期貨市場」，條文中沒有「保障公益」的字樣。

2. 依我國現行期貨交易之相關法令,有關目前期貨商受託從事國外期貨交易之管理,下列何者正確?
  1. (A)受期貨交易法之規範
  2. (B)受國外期貨交易法之規範
  3. (C)期貨交易法僅規範國內期貨交易,有關國外期貨交易目前無特別法規範
  4. (D)選項(A)(B)(C)皆非
解析

(A)正確。期貨交易法第3條所稱期貨交易，包含依國內外期貨交易所或其他期貨市場的規則或實務進行的契約，因此期貨商受託從事國外期貨交易，同樣受期貨交易法及其授權訂定的期貨商管理規則規範。國內外交易納入同一部法律，是為了避免同一家期貨商的兩類業務適用不同監理標準。

(B)錯誤。國外期貨交易法是民國81年為開放國外期貨交易而制定的舊法，期貨交易法施行後國內外期貨交易已一併納入規範，該法於民國88年廢止，現行法令下不再有國外期貨交易法。

(C)錯誤。期貨交易法第3條定義的期貨交易明文包含依國外期貨市場規則進行的交易，國外期貨受託業務是期貨經紀商的法定業務之一，並不是法規空白。

(D)錯誤。選項A的敘述符合現行法令，期貨商受託從事國外期貨交易確實受期貨交易法規範，因此不是三者皆非。

4. 甲期貨經紀商為結算會員,甲因違法經主管機關依期貨交易法之規定為停業處分時,下列何者得將甲及其客戶之相關帳戶,移轉於與甲有承受契約之其他結算會員?
  1. (A)中央銀行
  2. (B)期貨結算機構
  3. (C)期貨公會
  4. (D)期貨交易所之結算業務委員會
解析

(A)錯誤。中央銀行主管貨幣與外匯政策，並非期貨市場的主管機關或結算機構，不參與結算會員帳戶的移轉。

(B)正確。期貨交易法第54條規定，期貨結算機構於結算會員有破產、解散、停業或不履行結算交割義務時，得將該會員及其與期貨交易人的相關帳戶移轉於與該會員訂有承受契約的其他會員，必要時並得指定移轉於未訂承受契約的會員。目的是在會員出事時保全客戶部位與保證金，維持結算的連續性，所以由掌握帳戶與保證金的結算機構執行。

(C)錯誤。期貨公會是自律組織，負責會員自律與人員資格管理，不持有結算會員的帳戶與保證金，沒有移轉帳戶的法定權限。

(D)錯誤。法條授權的主體是期貨結算機構本身；我國雖由期交所兼營結算業務，但權限來自其結算機構的身分，並非交易所內部的某個委員會。

112 年第3 次｜期貨交易法規｜第 7 題
5. 期貨結算機構遇到因不可抗拒之偶發事故,臨時停止當市之全部或部分結算、交割情事時,應向下列何者申報備查?
  1. (A)期貨交易所
  2. (B)期貨公會
  3. (C)金管會
  4. (D)選項(A)(B)(C)皆是
解析

(A)錯誤。我國期貨交易所與結算機構實際上是同一家公司，結算機構向交易所申報並無監督意義；法規要求的是向上級監理機關報告。

(B)錯誤。期貨公會是業者的自律組織，沒有監督結算機構的職權，結算機構停止結算交割不須向公會申報備查。

(C)正確。期貨結算機構管理規則第9條規定，期貨結算機構因不可抗拒之偶發事故臨時停止當市之全部或部分結算、交割時，除即為適當處置外，應向主管機關申報備查；期貨交易法第4條所定主管機關即金融監督管理委員會。申報備查是讓主管機關即時掌握結算中斷對市場的影響。

(D)錯誤。法規只要求向主管機關金管會申報備查，並未要求同時向期貨交易所與期貨公會申報，因此不是三者皆是。

112 年第3 次｜期貨交易法規｜第 8 題
6. 期貨結算機構替結算會員進行結算工作時,向結算會員所收取之保證金,應如何處理?甲.可與自有資產合併存放;乙.須與自有資產分離存放;丙.自營結算會員與經紀結算會員所繳之款項合併存放;丁.自營結算會員與經紀結算會員所繳之款項分離存放
  1. (A)甲、丙
  2. (B)甲、丁
  3. (C)乙、丁
  4. (D)乙、丙
解析

(A)錯誤。甲與丙都與期貨交易法第51條相反：保證金若可與自有資產合併，結算機構的債權人便可能對其請求扣押；自營與經紀款項若合併，會員的自營損失會牽連客戶資金。

(B)錯誤。丁（自營與經紀分離）符合規定，但甲不對：結算保證金必須與結算機構的自有資產分離存放，不得合併。

(C)正確。期貨交易法第51條規定，期貨結算機構收取的結算保證金應與其自有資產分離存放，並應將結算會員繳交的結算保證金依自營與經紀分離處理。與自有資產分離是為了結算機構本身財務出狀況時保證金不被其債權人扣押；自營與經紀分離則是為了結算會員的自營虧損不會侵蝕其客戶的保證金。

(D)錯誤。乙（與自有資產分離）符合規定，但丙不對：第51條明定結算保證金應依自營與經紀分離處理，不能合併存放。

8. 本國證券商申請兼營期貨業務,則其最近期經會計師查核簽證或核閱之財務報告,必須達到下列哪一項標準?
  1. (A)累積盈餘至少為實收資本額的10%
  2. (B)累積盈餘至少為實收資本額的50%
  3. (C)無累積虧損
  4. (D)累積虧損最多不超過實收資本額的10%
解析

(A)錯誤。期貨商設置標準第24條要求的是「無累積虧損」，並未設定累積盈餘須達實收資本額某個比例的門檻，累積盈餘為零也符合條件。

(B)錯誤。累積盈餘達實收資本額50%是遠高於法規的門檻，第24條只要求沒有累積虧損，不要求累積盈餘達到任何比例。

(C)正確。期貨商設置標準第24條規定，本國證券商申請兼營期貨業務，最近期經會計師查核簽證之財務報告應無累積虧損，並符合證券交易法第49條所定的財務標準，同時自有資本適足比率不得低於150%。要求無累積虧損是因為兼營期貨業務會增加證券商的風險暴露，主管機關只讓財務體質健全者跨業。

(D)錯誤。法規不容許任何累積虧損，並沒有「10%以內可以接受」的緩衝；累積虧損無論多寡都不符合第24條第一款。

12. 期貨信託事業之專業發起人如欲轉讓持股,是否有何限制?
  1. (A)該專業發起人應於轉讓持股前申報主管機關備查
  2. (B)該專業發起人應於轉讓持股後5日內申報主管機關備查
  3. (C)期貨信託事業應於該專業發起人轉讓持股前申報主管機關備查
  4. (D)期貨信託事業應於該專業發起人轉讓持股後5日內申報主管機關備查
解析

(A)錯誤。事前申報的時點正確，但申報義務人不對：法規課予的是期貨信託事業的義務，主管機關監理的對象是事業本身，不直接對個別發起人課以申報義務。

(B)錯誤。申報義務人錯了，時點也錯了：法規要求在轉讓前申報，事後5日內申報會使主管機關無法在專業股東退出前審視事業是否仍符合設置條件。

(C)正確。期貨信託事業設置標準要求期貨信託事業須有符合專業發起人資格的股東持股達一定比例，該專業股東轉讓持股時，期貨信託事業應於轉讓前向主管機關申報備查。事前申報是讓主管機關在專業股東退出前確認事業仍符合設置條件，申報義務落在受監理的事業而非個別股東。

(D)錯誤。申報主體是期貨信託事業沒錯，但法規要求「轉讓前」申報備查，轉讓後5日內申報屬事後通知，失去讓主管機關事先審查的意義。
