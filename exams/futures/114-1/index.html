114 年第1 次｜期貨交易法規｜第 7 題
6. 下列有關期貨結算機構得運用交割結算基金之範圍,何者正確?甲.銀行存款;乙.購買國庫券;丙.購買政府債券;丁.購買商業本票;戊.購買公司債
  1. (A)僅甲、乙、丙
  2. (B)僅甲、乙、丙、丁
  3. (C)僅甲、乙、丙、戊
  4. (D)甲、乙、丙、丁、戊皆正確
解析

(A)正確。期貨結算機構管理規則第14條規定，交割結算基金的運用限於銀行存款、購買國庫券與政府債券，以及其他經主管機關核准之用途，且政府債券的持有比率另有上限。交割結算基金是會員違約時的緊急填補來源，必須隨時能變現且本金不能有損失，所以只允許幾乎沒有信用風險的資產。

(B)錯誤。商業本票是企業發行的短期票券，帶有發行公司的信用風險，若發行公司違約，基金本身會蒙受損失，與交割結算基金要在他人違約時「保證可用」的目的相衝突，因此不在運用範圍。

(C)錯誤。公司債的期間更長、信用風險更高，價格也隨利率與發行公司信用波動，作為緊急填補用的基金資產既不安全也不易即時變現，法規未將其列入。

(D)錯誤。此項把商業本票與公司債都納入。兩者都是民間企業的債務，交割結算基金若持有這類資產，等於把市場的違約風險轉嫁到基金身上，違反基金保守運用的原則。

114 年第1 次｜期貨交易法規｜第 8 題
7. 期貨商之最低實收資本額,發起人於發起時:
  1. (A)可分次認足
  2. (B)應一次認足
  3. (C)法規無明文規定
  4. (D)於發起人會議議決之
解析

(A)錯誤。分次認足會讓期貨商在開業初期只有部分資本到位，卻已開始承擔客戶交易的履約風險，資本不足時無法吸收虧損，所以法規排除了分期認足的做法。

(B)正確。期貨商設置標準第8條規定，期貨商最低實收資本額（期貨經紀商新臺幣二億元、期貨自營商四億元），發起人應於發起時一次認足。期貨商替客戶保管保證金並對結算機構負履約責任，資本必須在設立時就全部實際到位，這是資本充實原則的具體要求。

(C)錯誤。法規對此有明文規定，並非空白；發起人一次認足是期貨商設置標準中明確的設立條件之一。

(D)錯誤。資本認足方式是法規強制的設立要件，發起人會議不能自行議決改為分次繳納；發起人會議決定的是章程、董監選任等公司內部事項。

9. 原則上至少最近幾年內未曾受期貨交易所或期貨結算機構依其章則所為停止或限制買賣處分之期貨商,始得於開始營業後申請設置分支機構?
  1. (A)一年
  2. (B)二年
  3. (C)三年
  4. (D)五年
解析

(A)正確。期貨商設置標準第13條規定，期貨商申請設置分支機構，須最近一年未經期貨交易所或期貨結算機構依其章則所為停止或限制買賣處分。分支機構會擴大期貨商承作的客戶與部位規模，主管機關以近期的違規紀錄作為是否允許擴張的門檻，一年是對這類交易所層級處分所定的觀察期。

(B)錯誤。二年是同一條文中對「未曾被撤銷部分營業許可」所定的觀察期，那是主管機關層級的重大處分；交易所或結算機構的停止或限制買賣處分較輕，觀察期是一年。

(C)錯誤。三年並非此項條件的觀察期。同條文對不同輕重的處分設有三個月到二年不等的觀察期，交易所或結算機構的停止或限制買賣處分適用的是一年。

(D)錯誤。五年遠超過設置標準對任何一項處分所定的觀察期，若以五年為門檻，多數曾受輕微處分的期貨商都會被長期排除在擴點之外，與法規的比例設計不符。

114 年第1 次｜期貨交易法規｜第 13 題
10. 依我國期貨交易法之規定,期貨信託事業未依規定交付公開說明書者,對於善意相對人因而所受之損害,應負賠償責任,下列有關損害賠償請求權之敘述,何者正確?
  1. (A)自知有得受賠償之原因時起半年內不行使而消滅
  2. (B)自知有得受賠償之原因時起一年內不行使而消滅
  3. (C)自賠償原因發生之日起逾三年不行使而消滅
  4. (D)自賠償原因發生之日起逾五年不行使而消滅
解析

(A)錯誤。半年不是期貨交易法所定的任何一種時效。自知悉時起算的短期時效是二年，此項把它記成半年，且題目問的是自賠償原因發生日起算的絕對時效。

(B)錯誤。自知有得受賠償之原因時起算的短期時效，期貨交易法第84條定為二年而非一年；一年是把數字記錯的結果。

(C)錯誤。三年不是自賠償原因發生日起算的絕對時效；法定的絕對時效是五年，三年會使受害人在尚未發現損害前就喪失請求權。

(D)正確。期貨交易法第84條規定，期貨信託事業未依規定交付公開說明書，對善意相對人所受損害應負賠償責任，其請求權自知有得受賠償之原因時起二年間不行使而消滅，自賠償原因發生之日起逾五年者亦同。二年是知悉後的短期時效，五年是不論是否知悉的絕對上限，兩者擇先屆至者適用。

11. 有關經營證券全權委託業務之證券投資顧問公司,可經營之期貨業務項目,以下敘述何者正確?
  1. (A)期貨經紀業務及期貨自營業務
  2. (B)期貨顧問業務及期貨經理業務
  3. (C)期貨信託業務及期貨信託基金之銷售機構
  4. (D)期貨交易輔助人業務及期貨結算機構業務
解析

(A)錯誤。期貨經紀與期貨自營是期貨商的業務，必須依期貨商設置標準另行取得期貨商許可並具備相應資本額；證券投資顧問公司不能以兼營方式經營這兩項業務。

(B)正確。經營全權委託投資業務的證券投資顧問事業，得申請兼營期貨顧問事業與期貨經理事業。這兩項期貨業務的性質（提供分析建議、受託操作）與投顧原有的顧問及全權委託業務相同，只是標的從證券擴展到期貨，人員資格與內控架構可以延伸使用，所以法規允許兼營。

(C)錯誤。期貨信託業務是募集基金並運用，需要期貨信託事業的資格；至於期貨信託基金的銷售機構是基金銷售通路，並非投顧公司「經營之期貨業務項目」，此項的組合不成立。

(D)錯誤。期貨交易輔助人業務是證券商為期貨商招攬客戶與接受委託的業務，主體是證券經紀商；期貨結算機構業務更是專屬於結算機構，投顧公司都無法兼營。

114 年第1 次｜期貨交易法規｜第 16 題
13. 證券商經營期貨交易輔助業務,以何種業務為限?
  1. (A)外匯期貨業務
  2. (B)證券相關期貨業務
  3. (C)委任期貨商可從事之期貨業務
  4. (D)金管會核准之期貨業務
解析

(A)錯誤。外匯期貨只是眾多期貨商品之一，法規並未把證券商的期貨交易輔助業務限縮在外匯期貨；相反地，證券商招攬的多半是與其客群相關的股價指數類商品。真正的界線是主管機關核准了哪些期貨業務，而不是商品種類本身。

(B)錯誤。避險者也可以有自己的價格看法，只是他們選擇用期貨把現貨的價格風險鎖住，而不是靠預測賺價差。「能不能預測」不是區分兩者的標準。
