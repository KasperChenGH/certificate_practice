  1. (A)交換契約
  2. (B)槓桿保證金契約
  3. (C)選擇權契約
  4. (D)期貨選擇權契約
解析

(A)依期貨交易法第3條,當事人約定於未來特定期間依約定方式交換約定標的或現金流量者,即為交換契約(Swap)。

(C)選擇權契約是買方支付權利金取得買賣權利,非雙方互換現金流量。

(D)期貨選擇權是以期貨契約為標的之選擇權,非交換約定標的或現金流量之契約。

2. 期貨交易所發現期貨商有下列何情事,得對期貨商專案檢查?甲、期貨商經營不善致信用難以維持;乙、有突發事件;丙、內部稽核作業有重大缺失;丁、不能履行結算交割義務
  1. (A)甲、乙、丙、丁
  2. (B)甲、丙、丁
  3. (C)乙、丙、丁
  4. (D)丙、丁
解析

(A)正確。依期貨交易所管理規則，期貨交易所發現期貨商有經營不善、發生虧損致信用難以維持，或遇有突發事件，或內部稽核作業有重大缺失者，應即為專案檢查並予輔導；期貨商不能履行結算交割義務時，更應會同期貨結算機構專案檢查。四種情形都是期貨商違約風險升高的訊號，交易所必須及早介入以保護市場與其他交易人。

(B)錯誤。漏掉乙：突發事件（如系統當機、重大營運事故）雖非財務問題，但可能立即影響期貨商履約能力，同樣是規則明列的專案檢查事由。

(C)錯誤。漏掉甲：經營不善致信用難以維持是最典型的專案檢查事由，因為信用惡化直接威脅其結算交割能力，交易所不可能將它排除。

(D)錯誤。只保留內稽缺失與無法履行交割義務兩項，遺漏了經營不善與突發事件；規則列舉的四種情形均可觸發專案檢查，不限於後兩項。

3. 公司制期貨交易所之非股東董事、監察人,由主管機關指派者,至少占全體董事、監察人之:
  1. (A)四分之一
  2. (B)六分之一
  3. (C)八分之一
  4. (D)十分之一
解析

(A)錯誤。四分之一是期貨交易法第36條規定非股東相關專家在董事、監察人中的最低總比例，而不是主管機關指派的部分；指派者只占其中半數。

(B)錯誤。六分之一不對應法條中的任何比例；若主管機關指派占六分之一，會超過非股東專家總數（四分之一）的半數，與「其中半數由主管機關指派」不符。

(C)正確。期貨交易法第36條規定公司制期貨交易所之董事、監察人至少四分之一由非股東之相關專家擔任，其中半數由主管機關指派，餘由董事會遴選後報主管機關核定。四分之一的一半即八分之一，這就是主管機關指派者的最低占比。設計用意是在股東主導的公司制交易所中保留公益席次，避免交易所決策完全由股東利益左右。

(D)錯誤。十分之一低於法定的八分之一；把四分之一的半數算錯，或誤以為公益董事只需象徵性席次，才會得到這個數字。

113 年第3 次｜期貨交易法規｜第 6 題
5. 期貨結算機構之交割結算基金,可為下列何種運用?
  1. (A)借予他人
  2. (B)購買政府債券
  3. (C)購買營業用之不動產
  4. (D)購買非營業用之不動產
解析

(A)錯誤。交割結算基金是結算會員繳存、用來承擔違約損失的共同擔保，期貨結算機構管理規則明定不得借予他人或移作其他用途，借出去就失去隨時可動用的擔保功能。

(B)正確。依期貨結算機構管理規則，交割結算基金除銀行存款外，只能購買國庫券及政府債券，或作經主管機關核准之其他運用；政府債券幾乎沒有信用風險、隨時可變現，符合基金必須在會員違約時立即動用的性質。也因此規則對購買國庫券及政府債券的比率設有上限，以保留足夠的現金部位。

(C)錯誤。營業用不動產雖是結算機構自身營運資產，但流動性極低，違約時無法迅速變現填補損失，不在交割結算基金允許的運用範圍。

(D)錯誤。非營業用不動產屬於投資性資產，既無法迅速變現又承受價格風險，與交割結算基金安全、流動的要求相去最遠，當然不得運用。

113 年第3 次｜期貨交易法規｜第 7 題
6. 依期貨商管理規則之規定,有關期貨商宣傳資料、廣告物之形式及內容之審核程序,下列何項敘述正確?
  1. (A)不須審核,但應保留備查
  2. (B)須經期貨業商業同業公會審核、簽章後,始可使用
  3. (C)須經期貨商經理人審核、簽章後,始可使用
  4. (D)須經期貨交易所審核、簽章後,始可使用
解析

(A)錯誤。期貨商管理規則要求廣告物在使用前必須經過內部審核簽章，不是不審核只留底備查；備查只是事後義務，無法防止不當招攬。

(B)錯誤。期貨業商業同業公會訂定廣告招攬的自律規範並可事後查核，但個別廣告物的使用前審核責任在期貨商自己，公會不做逐件簽章。

(C)正確。期貨商管理規則規定，期貨商之宣傳資料及廣告物之形式及內容，應經期貨商經理人審核及簽名或蓋章後始可使用。由經理人簽章是要讓公司高階管理層對廣告內容負責，避免業務員誇大獲利、隱匿風險，主管機關事後追究時也有明確的責任歸屬。

(D)錯誤。期貨交易所負責市場交易與期貨商的結算交割監理，不審核期貨商的宣傳廣告；廣告內容的把關是期貨商經理人與公會自律的範圍。

113 年第3 次｜期貨交易法規｜第 10 題
7. 取得期貨商業務員資格前半年已參加經主管機關認定之職前訓練,且成績合格者,於取得期貨商業務員資格起多久時間之內登記為業務員執行業務,得免參加初任業務員之職前訓練?
  1. (A)半年內
  2. (B)一年內
  3. (C)二年內
  4. (D)三個月內
解析

(A)正確。依期貨商負責人及業務員管理規則，初任及離職滿二年再任的業務員應於到職後半年內參加職前訓練；若取得業務員資格前半年內已參加主管機關認定的職前訓練且成績合格，並於取得資格起半年內登記執行業務，即可免除初任職前訓練。兩個半年的設計是要讓訓練內容在登記時仍屬新近，超過半年就視為需要重新受訓。

(B)錯誤。一年會讓受訓與實際執業之間相隔太久，法規以半年為訓練有效的認定期間；期貨業務員的職前訓練規定中沒有一年的免訓期限。

(C)錯誤。二年是規則中「離職滿二年再任者須重新參加職前訓練」所用的期間，是判斷是否視同初任的門檻，與免訓登記期限無關。

(D)錯誤。三個月比規定嚴格，會讓已受訓合格者只因求職空窗稍長就得重訓；規則採半年，與「受訓後半年內取得資格」的前段條件對稱。

113 年第3 次｜期貨交易法規｜第 11 題
8. 期貨商得自客戶保證金專戶內提領款項的情形,下列何者正確?甲、購買非營業用之不動產;乙、為期貨交易人預先扣繳稅額;丙、為期貨交易人支付必須支付之清算差額;丁、依期貨交易人指示,交付賸餘保證金;戊、為交易人支付期貨經紀商之佣金、利息
  1. (A)乙、丙、丁
  2. (B)甲、丙、丁
  3. (C)丙、丁、戊
  4. (D)甲、乙、丁
解析

(A)錯誤。丙、丁正確，但乙不在期貨交易法第71條列舉的提領事由中；期貨交易所得的稅務並非由保證金專戶預先扣繳，專戶只能為交易人支付與交易直接相關的款項。

(B)錯誤。甲是最典型的違規：客戶保證金專戶的款項屬於交易人，與期貨商自有財產分離，期貨商拿去購買不動產等於挪用客戶資金。

(C)正確。期貨交易法第71條規定期貨商不得自客戶保證金專戶提領款項，但下列情形除外：依期貨交易人指示交付賸餘保證金、權利金（丁）；為期貨交易人支付必須支付之保證金、權利金或清算差額（丙）；為期貨交易人支付期貨經紀商之佣金、利息或其他手續費（戊）；及經主管機關核准者。共同點是提領都是為了交易人自己的交易與債務，專戶隔離制度就是為了讓客戶資金不受期貨商自身財務狀況牽連。

(D)錯誤。甲的購買不動產是挪用客戶資金，乙的預扣稅額也不是法定提領事由，三項中只有丁正確。

113 年第3 次｜期貨交易法規｜第 12 題
9. 期貨經紀商因業務關係與客戶發生民事訴訟時,最遲應於下列何時向主管機關申報?
  1. (A)應於知悉之日起十五日內申報
  2. (B)應於訴訟發生之日起十日內申報
  3. (C)應於次月五日前申報
  4. (D)應於知悉或訴訟發生之日起五日內申報
解析

(A)錯誤。十五日比規定寬鬆，主管機關要求即時掌握期貨商涉訟情形，以評估對其財務與履約能力的影響，等半個月才通報會失去監理時效。

(B)錯誤。十日仍超過規定期限，且申報起算點只用「訴訟發生之日」也不完整，規則同時以「知悉」為起算點，避免期貨商以未接到訴狀為由拖延。

(C)錯誤。次月定期申報是財務報表類的申報方式（期貨商管理規則另定每月十日前申報上月月計表等），涉訟屬突發性事項，須個案即時申報，不能併入月報。

(D)正確。期貨商管理規則規定，期貨商或其負責人、業務員因業務上關係發生訴訟、仲裁或成為強制執行債務人等情事，應於知悉或事實發生之日起五日內向主管機關申報（現行條文文字為五個營業日）。以「知悉或發生」較早者起算，是要確保主管機關能及早評估訴訟對客戶權益與期貨商財務的影響。

113 年第3 次｜期貨交易法規｜第 14 題
10. 以下何者可以申請為期貨交易輔助人?
  1. (A)信用合作社
  2. (B)票券業
  3. (C)證券經紀商
  4. (D)證券商兼營期貨經紀業務者
解析

(A)錯誤。信用合作社是基層金融機構，業務為存放款，不經營證券經紀，而期貨交易輔助人以經營證券經紀業務者為限，它根本不具申請資格。

(B)錯誤。票券業經營短期票券的簽證、承銷與買賣，與證券經紀無關，不符合證券商經營期貨交易輔助業務管理規則對申請人的限制。

(C)正確。依證券商經營期貨交易輔助業務管理規則，申請為期貨交易輔助人以經營證券經紀業務者為限。制度用意是讓已有客戶基礎與營業據點的證券經紀商代期貨商招攬客戶、接受委託並轉單，擴大期貨市場的通路，同時由委任的期貨商負最終責任。

(D)錯誤。規則明定證券商兼營期貨經紀業務者不得申請經營期貨交易輔助業務，因為它已經是期貨商，能直接受託從事期貨交易，沒有再當輔助人的必要，也避免角色混淆。

113 年第3 次｜期貨交易法規｜第 16 題
11. 如欲擔任期貨信託事業業務部門之副總經理,已取得期貨交易分析人員,並具資訊專業領域之工作經驗至少達幾年以上,成績優良者,方能符合期貨信託事業管理規則要求?
  1. (A)一年
  2. (B)二年
  3. (C)三年
  4. (D)四年
解析

(A)錯誤。一年是取得期貨交易分析人員資格後，以「專業投資機構相關工作經驗」申請副總經理的年限要求；題目問的是資訊等專業領域經驗，法規要求較長。

(B)正確。期貨信託事業管理規則第44條規定，業務部門之副總經理、協理、經理，取得期貨交易分析人員資格者，須另具專業投資機構相關工作經驗一年以上，或具資訊、科技、法律、電子商務或數位經濟等專業領域工作經驗二年以上且成績優良。非金融背景的專業經驗要求較長，是因為它與基金經理業務的關聯較間接，需要更多年資來補足。

(C)錯誤。三年是同條第二款的門檻：專科以上學歷並具專業投資機構相關工作經驗三年以上者，不需分析人員資格；有分析人員資格者的資訊專業經驗要求是二年。

(D)錯誤。四年不是第44條任何一款的年限；副總經理的三種資格路徑分別要求一年、二年、三年經驗，並無四年之規定。
