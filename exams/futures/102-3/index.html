  2. (B)商品

(A)正確。依出題當時（102年）臺灣期貨交易所上市的契約，標的涵蓋股價指數、利率（公債、利率期貨）與商品（黃金等），尚無以貨幣（匯率）為標的之期貨（期交所自104年底起已上市匯率期貨）。

2. 主管機關在核准涉及新臺幣與外幣間兌換之貨幣期貨契約在期貨交易所上市時，應先會商何者同意？

3. 期貨交易所取得或處分不動產及設備，其每筆交易價格超過新臺幣多少金額者，應依所定取得或處分不動產及設備處理程序辦理？

  2. (B)五千萬元

(A)錯誤。三千萬元不是法規所定的金額門檻；期貨交易所取得或處分不動產及設備，達規定金額以上之單筆交易才須依所定處理程序辦理。

  2. (B)申請設立許可保證金應由董事長於申請核發許可證照時繳存

(A)正確。依期貨交易所設立之相關規定，公司制期貨交易所申請設立許可時，應繳存許可保證金新臺幣二億元，以擔保設立程序之履行，本敘述正確。

(B)錯誤。許可保證金是在申請設立許可階段繳存，並非由董事長於申請核發許可證照時才繳存，繳存時點與繳存人均與規定不符。

(D)錯誤。保證金得以現金或政府債券等指定方式繳存，公司債信用風險較高，不在得繳存之範圍內，故本敘述錯誤。

6. 依我國期貨交易法之規定，結算制度相關款項之計收或提存標準，以下敘述何者錯誤？
  1. (A)結算保證金依未平倉口數計收
  2. (B)交割結算基金依辦理結算交割之據點數或其他標準計算
  3. (C)賠償準備金首次應提存新台幣五千萬元
  4. (D)賠償準備金除首次提撥外，依結算、交割手續費收入之一定比例提存
解析

(A)錯誤。本敘述正確，故不是答案。結算保證金是結算機構向結算會員收取以擔保履約的款項，依其未平倉部位口數計收，部位愈大收取愈多。

(B)錯誤。本敘述正確，故不是答案。交割結算基金是結算會員共同承擔違約風險的基金，依其辦理結算交割之據點數或其他標準計算繳存。

(C)正確。本題問錯誤者。賠償準備金首次提撥金額並非新臺幣五千萬元（同卷另題所列首次提撥為三億元），故此敘述錯誤，為本題答案。

(D)錯誤。本敘述正確，故不是答案。賠償準備金除首次提撥外，嗣後依結算、交割手續費收入之一定比例持續提存，以逐步累積違約支應能力。

  1. (A)提存單位為期貨結算機構
  2. (B)遇有結算會員不履行結算交割義務時，其支應之順位為最後位

(A)錯誤。本敘述正確，故不是答案。賠償準備金是由期貨結算機構提存，作為結算會員違約時支應之財源，提存單位確為期貨結算機構。

(D)錯誤。本敘述正確，故不是答案。賠償準備金累積達資本總額或指撥之專用營運資金時，已具足夠支應能力，得免予繼續提存。

10. 依我國期貨交易法之規定，期貨結算會員不履行結算交割義務時，下列款項支應順序之敘述何者正確？
  1. (A)違約期貨結算會員繳存於期貨結算機構之結算保證金及交割結算基金分列為最優先及次優先順位
  2. (B)其他期貨結算會員所繳存之結算保證金，其支應之順序在期貨結算機構賠償準備金之前
  3. (C)其他期貨結算會員所繳存之交割結算基金，其支應之順序在期貨結算機構賠償準備金之後
  4. (D)期貨結算機構之賠償準備金為最後順位
解析

(A)正確。結算會員違約時，應先以違約者自身財產承擔：違約結算會員繳存之結算保證金為最優先、其繳存之交割結算基金為次優先，其後才動用他人及結算機構之資金。

(B)錯誤。其他（未違約）結算會員繳存之結算保證金是擔保其自身部位的款項，並不列入違約支應順序，更不會排在賠償準備金之前。

(C)錯誤。依本題所據之支應順序，其他結算會員繳存之交割結算基金排在期貨結算機構賠償準備金之前動用，而非之後。

(D)錯誤。賠償準備金之後尚有其他結算會員依比例分擔之順位，故賠償準備金並非最後順位。

102年第3次｜期貨交易法規｜第 15 題
13. 有關期貨商對客戶保證金專戶存款之動支規定，下列敘述何者正確？
  1. (A)得設定擔保或他項權利
  2. (B)得依期貨交易人指示交付超額保證金
  3. (C)得進行透支
  4. (D)得挪用為其他客戶代墊不足之保證金
