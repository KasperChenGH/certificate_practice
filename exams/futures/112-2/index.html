1. 各國期貨交易之管理法規,下列敘述何者正確?
  1. (A)在美國,須受金融期貨法之規範
  2. (B)在日本,商品期貨受金融商品交易法之規範
  3. (C)在我國,須受期貨交易法之規範
  4. (D)在日本,金融期貨受商品期貨交易法之規範
解析

(A)錯誤。美國期貨市場的基本法是商品交易法（Commodity Exchange Act），由CFTC執行，金融期貨與商品期貨同受該法規範；美國並沒有一部叫金融期貨法的法律。

(B)錯誤。日本的商品期貨受商品先物取引法（商品期貨交易法）規範，由經濟產業省與農林水產省主管；金融商品交易法管的是金融期貨與證券，此項把兩部法律對調了。

(C)正確。我國期貨交易法是期貨市場的基本法，期貨契約、選擇權契約、期貨選擇權契約及槓桿保證金契約等在集中市場的交易，以及期貨交易所、結算機構、期貨商與期貨服務事業的設立管理，都依該法規範。各國的差異在於美國以單一商品交易法涵蓋所有期貨，日本則依標的把商品期貨與金融期貨分由兩部法律管轄。

(D)錯誤。日本的金融期貨受金融商品交易法規範，2007年金融先物取引法併入該法後即如此；商品先物取引法只管商品期貨，此項與B項是同一組對調錯誤。

112 年第2 次｜期貨交易法規｜第 1 題
2. 會員制期貨交易所之設立,應於主管機關許可之日起多久內完成法人設立登記?
  1. (A)3個月
  2. (B)6個月
  3. (C)9個月
  4. (D)1年
解析

(A)錯誤。三個月短於期貨交易所設立標準所定的期限；會員制交易所的法人設立登記須先完成會員出資、章程與組織等程序，法規給予六個月，三個月是把期限砍半的錯誤數字。

(B)正確。期貨交易所設立標準第8條規定，會員制期貨交易所之設立，應自主管機關許可之日起六個月內完成法人設立登記，並申請核發許可證照；同標準第13條對公司制交易所的公司設立登記也是六個月。逾期未完成者許可失效，但得於期限屆滿前申請延展，延展以一次且不超過六個月為限，這種原期限加一次延展的設計是為了避免取得許可卻遲不設立而占用市場資源。

(C)錯誤。九個月既不是原始的六個月期限，也不是加計延展後的最長期限（六加六為十二個月），與設立標準的任何規定都對不上。

(D)錯誤。一年是原始六個月期限加上一次最長六個月延展後才可能達到的總時間，是例外情形下的上限，並不是法規要求完成法人設立登記的原始期限。

3. 依我國期貨交易法之規定,有關選擇權契約之敘述,以下何者錯誤?
  1. (A)選擇權契約包括股票選擇權契約
  2. (B)選擇權契約包括外幣選擇權契約
  3. (C)選擇權契約賣方須支付權利金
  4. (D)選擇權契約可採現金結算或實物交割方式
解析

(A)錯誤(指敘述正確)。依《期貨交易法》第3條規定，選擇權契約包含股票選擇權契約。

(B)錯誤(指敘述正確)。外幣選擇權契約亦屬期交法所稱選擇權契約之一。

(C)正確(此敘述為錯誤)。選擇權契約之權利金係由「買方」支付給賣方以取得權利，賣方則收取權利金並承擔履約義務，本選項顛倒買賣方角色，故為錯誤敘述。

(D)錯誤(指敘述正確)。選擇權之結算方式可採現金結算或實物交割，視合約規格而定。

(A)錯誤。財政部主管國庫、稅務與公股事務，早年證券期貨主管機關雖曾隸屬財政部，但新臺幣匯率政策從來不是財政部的職掌，期貨交易法要求會商的是中央銀行。

112 年第2 次｜期貨交易法規｜第 4 題
5. 依我國期貨交易法令之規定,下列何者如在集中市場交易應受期貨交易法的規範?甲、政府債券期貨契約;乙、美元對新臺幣匯率期貨選擇權契約;丙、外幣選擇權契約;丁、認購(售)權證
  1. (A)僅甲、丙
  2. (B)僅甲、乙
  3. (C)僅甲、乙、丙
  4. (D)甲、乙、丙、丁
解析

(A)錯誤。只列甲、丙會漏掉乙。美元對新臺幣匯率期貨選擇權契約是以期貨為標的的選擇權，屬期貨交易法第3條所稱的期貨選擇權契約，在集中市場交易當然受期貨交易法規範。

(B)錯誤。只列甲、乙會漏掉丙。外幣選擇權契約是第3條明定的選擇權契約類型，在期貨交易所交易時受期貨交易法規範，不因標的是外幣而排除。

(C)正確。期貨交易法第3條規定，本法所稱期貨交易，指在集中市場交易的期貨契約、選擇權契約、期貨選擇權契約、槓桿保證金契約等。政府債券期貨屬期貨契約，美元對新臺幣匯率期貨選擇權屬期貨選擇權契約，外幣選擇權屬選擇權契約，三者都在範圍內；認購（售）權證則是發行人依證券交易法發行的有價證券，在證券市場交易，受證券交易法而非期貨交易法規範。

(D)錯誤。多列了丁。認購（售）權證雖然在經濟上也是選擇權，但它是由證券商發行、在證交所以有價證券方式交易，適用證券交易法，不是期貨交易法所稱在期貨集中市場交易的選擇權契約。

112 年第2 次｜期貨交易法規｜第 7 題
7. 依期貨結算機構管理規則之規定,結算會員入會或退會時,期貨結算機構除依情形處置外,至遲並應於何時向主管機關申報備查?
  1. (A)事實發生二日內
  2. (B)事實發生或處理完成後五日內
  3. (C)按月彙報
  4. (D)不需申報
解析

(A)錯誤。事實發生二日內是很短的逐件申報期限，適用於緊急重大事項；結算會員入會退會屬會籍管理，期貨結算機構管理規則第9條把它列為按月彙報事項，不需逐件在兩日內申報。

(B)錯誤。事實發生或處理完成後五日內的申報方式，是期貨商管理規則對客戶保證金專戶開設變更等事項所採的逐件短期限申報（五個營業日）；結算會員入會退會不採此種方式。

(C)正確。期貨結算機構管理規則第9條將結算會員入會或退會列為期貨結算機構應向主管機關申報的事項，並規定按月彙報主管機關備查。結算會員的資格審查與退會處理由結算機構依自訂的會員資格條件辦理，主管機關只需事後掌握名單變動，所以採按月彙總的申報方式即可，不必逐件即時申報。

(D)錯誤。結算會員是承擔結算違約責任的主體，其名單變動關係整個市場的風險承擔結構，主管機關必須掌握，規則明定須申報備查，並非免申報。

112 年第2 次｜期貨交易法規｜第 8 題
8. 期貨商之資金不得運用於下列何者?
  1. (A)購買商業票據
  2. (B)購買政府債券
  3. (C)購買經金管會核定之短期票券
  4. (D)購買黃金
解析

(A)錯誤。商業票據屬於期貨商管理規則第23條列舉的可運用標的之一，與國庫券、可轉讓銀行定期存單同列為短期票券，流動性高、到期日短，隨時可變現應付客戶保證金需求。

(B)錯誤。政府債券與金融債券是期貨商管理規則第23條明文允許購買的標的，信用風險低、變現容易，正是主管機關希望期貨商自有資金停泊的地方。

(C)錯誤。「其他經金管會核定之短期票券」是第23條的概括條款，凡經主管機關核定的短期票券都可運用，本質仍是高流動性、低風險的資產。

(D)正確。期貨商管理規則第23條把期貨商自有資金的用途限定在銀行存款、政府債券或金融債券、國庫券與短期票券，以及其他經主管機關核准的用途。黃金屬價格波動大的大宗商品，既不在列舉之內，也不符合「保本、可隨時變現」的立法目的：期貨商資金必須隨時能因應客戶保證金與結算需求，若投入黃金這類價格會大幅起落的資產，一旦跌價就可能侵蝕財務結構、危及客戶權益。

112 年第2 次｜期貨交易法規｜第 9 題
9. 依國外期貨交易法取得期貨商業務員資格者,於期貨交易法施行後,是否可以執行業務?
  1. (A)須參加期貨從業人員職前訓練,訓練合格者即可執行業務
  2. (B)必須加考法規,若及格就可執行業務
  3. (C)得憑原證照執行業務
  4. (D)必須專案呈主管機關檢核後才能決定
解析

(A)錯誤。職前訓練是對新任、尚未取得資格者的要求；依國外期貨交易法已通過測驗取得資格的人員，其專業能力已被舊法認可，法規未要求他們重新受訓。

(B)錯誤。加考法規是新制下取得業務員資格的途徑之一，但期貨商負責人及業務員管理規則對舊法合格者訂了過渡條款，不必另行補考。

(C)正確。期貨商負責人及業務員管理規則第20條規定，期貨交易法施行前依國外期貨交易法取得期貨經紀商業務員資格者，於本法施行後得憑原證照執行業務。這是新舊法銜接的過渡條款：舊法下的資格已經經過測驗檢核，沒有必要讓既有從業人員全部重考，否則市場人力會在新法生效時出現斷層。

(D)錯誤。過渡條款已直接賦予原證照效力，是「當然得執行業務」，不是逐案送主管機關審查才能決定；專案檢核是針對外國期貨交易所測驗合格者等其他情形的認可途徑。

112 年第2 次｜期貨交易法規｜第 12 題
11. 期貨結算機構之業務為下列何者?甲、提供期貨集中交易市場;乙、擔保期貨交易之履約;丙、期貨交易之結算;丁、受託交易期貨商品;戊、期貨交易之交割
  1. (A)甲、乙、丙
  2. (B)乙、丙、戊
  3. (C)乙、丙、丁
  4. (D)乙、丁、戊
解析

(A)錯誤。「提供期貨集中交易市場」是期貨交易所的職能，期貨交易法將交易所與結算機構分開規範，結算機構不負責提供撮合市場。
