1. 我國期貨交易法所管轄之交易，不包括下列何者？
  1. (A)國內店頭期貨交易
  2. (B)國內證券交易所之認購權證交易
  3. (C)國內期貨交易所之交易
  4. (D)國內槓桿保證金契約交易
解析

(A)錯誤。國內店頭期貨交易屬期貨交易法所稱之期貨交易。

(B)正確。認購權證屬有價證券，其交易由證券交易法規範，不在期貨交易法管轄範圍。判斷標準在於該商品被定性為有價證券或期貨契約，而非其是否具槓桿或選擇權性質。

(C)錯誤。國內期貨交易所之交易當然受期貨交易法管轄。

(D)錯誤。槓桿保證金契約屬期貨交易法所定之期貨交易類型之一。

114年第3次｜期貨交易法規｜第 2 題
2. 依我國期貨交易法之規定，非在期貨交易所進行之期貨交易，基於下列哪些政策考量，得經主管機關於主管事項範圍內公告，不適用本法之規定？甲、金融；乙、貨幣；丙、外匯；丁、公債；戊、賦稅
  1. (A)甲、乙、丙、丁
  2. (B)甲、乙、丙、戊
  3. (C)甲、丙、丁、戊
  4. (D)乙、丙、丁、戊
解析

(A)正確。期貨交易法第3條第2項規定，非在期貨交易所進行的期貨交易，基於金融、貨幣、外匯、公債等政策考量，得經主管機關於主管事項範圍內或中央銀行於掌理事項範圍內公告不適用本法。這四項都是總體金融調控工具，若一律納入期貨交易法管制，會與央行貨幣政策及國庫債務管理相衝突。

(B)錯誤。賦稅不在第3條第2項列舉的政策考量之內；此組合漏掉公債，而公債正是政府債務管理與央行公開市場操作的核心工具。

(C)錯誤。此組合誤列賦稅並漏列貨幣；貨幣政策是中央銀行的掌理事項，央行外匯與利率相關的店頭衍生性交易正是排除適用的主要對象。

(D)錯誤。此組合誤列賦稅並漏列金融；金融政策考量是排除條款的第一項，賦稅則屬財政政策，與期貨交易的管制無涉。

114年第3次｜期貨交易法規｜第 3 題
3. 下列產業中，何者得依金融科技發展與創新實驗條例申請辦理期貨業務創新實驗？
  1. (A)僅期貨業
  2. (B)僅期貨及證券業
  3. (C)僅期貨、證券及銀行業
  4. (D)任何行業皆能依法申請
解析

(A)錯誤。金融科技發展與創新實驗條例並未把申請人限於期貨業；監理沙盒的重點是讓創新技術在有限範圍試行，若只准期貨業申請，就失去引入新業者的意義。

(B)錯誤。申請主體不以期貨及證券業為限；創新實驗要試的是金融科技，技術多半來自既有金融業以外的業者。

(C)錯誤。並非僅限期貨、證券及銀行業三種金融業；條例開放自然人、獨資、合夥或法人申請，不設行業門檻。

(D)正確。金融科技發展與創新實驗條例採開放申請，自然人、獨資或合夥事業、法人均得向主管機關申請辦理創新實驗，不限行業別。監理沙盒的用意就是讓非金融業者也能在核准的範圍與期間內試行涉及金融業務的創新，才可能引入既有業者以外的技術與商業模式。

114年第3次｜期貨交易法規｜第 4 題
4. 期貨交易所發生下列何種事項時，應先申報金管會核准？甲.與自律組織簽訂合作協議；乙.期貨商與期貨交易所間，關於期貨集中交易市場使用契約之訂立、變更或終止；丙.經營其他業務或投資其他事業；丁.受讓其他交易所之全部或主要部分營業或財產
  1. (A)乙、丙
  2. (B)甲、乙、丙
  3. (C)甲、丙、丁
  4. (D)丙、丁
解析

(A)錯誤。乙（市場使用契約之訂立、變更或終止）依期貨交易所管理規則第7條屬應申報主管機關核備的事項，不必事前核准；丙則確實屬核准事項。

(B)錯誤。甲（與自律組織簽訂合作協議）與乙（市場使用契約）均只須申報核備；合作協議與使用契約是交易所的日常對外關係，不改變其業務範圍，故採事後備查。

(C)錯誤。丙、丁屬核准事項無誤，但甲（與自律組織簽訂合作協議或備忘錄）依第7條僅須申報核備，此組合多列了甲。

(D)正確。期貨交易所管理規則第6條列為應先報主管機關核准的事項包括經營其他業務或投資其他事業、受讓或讓與全部或主要部分之營業或財產、變更名稱或資本額、合併或解散等。這些會改變交易所的業務範圍、財務結構或存續狀態，涉及市場基礎設施的穩定，故須事前核准；合作協議與使用契約則只須核備。

114年第3次｜期貨交易法規｜第 5 題
5. 依我國期貨交易法，關於期貨交易所的規定，下列何者正確？
  1. (A)期貨交易所經經濟部核准後，即可兼營期貨結算機構之業務
  2. (B)自受領許可證照後，6 個月內未開始營業者，主管機關得撤銷其許可
  3. (C)分為會員制與公司制
  4. (D)期貨交易所業務人員之資格條件，由期貨交易所訂定，報主管機關備查
解析

(A)錯誤。期貨業的主管機關是金融監督管理委員會，不是經濟部；期貨交易所兼營期貨結算機構業務也須經金管會核准，經濟部只負責公司登記。

(B)錯誤。期貨交易法第17條規定的是受領許可證照後三個月內未開始營業，或開業後自行停業連續三個月以上，主管機關得撤銷許可；六個月不是本條的期限。

(C)正確。期貨交易法第7條規定期貨交易所之組織分為會員制及公司制。會員制為非以營利為目的的社團法人，由會員共同組成；公司制為股份有限公司，以股東出資經營。兩者在治理結構與盈餘分配上的差異，正是分類的實益所在。

(D)錯誤。期貨交易所業務人員的資格條件由主管機關定之，並非由交易所自訂後報備；交易所業務人員的登記或異動才是按月列冊彙報主管機關的事項。

114年第3次｜期貨交易法規｜第 7 題
6. 假設公司制期貨交易所之交易業務委員會共有9 位委員，依我國期貨交易法之規定，至少應有幾位為在該交易所交易之期貨商？
  1. (A)1 位
  2. (B)2 位
  3. (C)3 位
  4. (D)沒有限制
解析

(A)錯誤。1 位只占 9 位的九分之一，低於期貨交易法第38條要求的三分之一；把「至少要有期貨商代表」誤解為「有一位即可」就會得到此答案。

(B)錯誤。2 位占 9 位的九分之二，仍未達三分之一（9÷3＝3）；若把 9×1/3 取整時誤向下捨去成 2，就會得到此錯誤答案。

(C)正確。期貨交易法第38條規定公司制期貨交易所應設業務委員會及紀律委員會，成員至少應有三分之一為在該交易所交易的期貨商。9×1/3＝3，故至少 3 位。納入實際交易者是要讓交易規則能反映市場實務，而以三分之一為最低比例，既保障業者聲音，又避免業者主導。

(D)錯誤。期貨交易法第38條對委員會的期貨商比例設有明文下限，並非毫無限制；「沒有限制」是把交易所自治誤當成完全不受法律規範。

114年第3次｜期貨交易法規｜第 9 題
8. 會員或期貨商不能履行結算交割義務時，期貨交易所應採取下列何種措施？甲.督導承受之會員或期貨商接辦相關事務；乙.立刻通知該會員或期貨商追加交割結算基金；丙.會同期貨結算機構進行專案檢查；丁.交由金管會進行專案檢查
  1. (A)甲、丙
  2. (B)乙、丙
  3. (C)乙、丙、丁
  4. (D)甲、丙、丁
解析

(A)正確。期貨交易所管理規則第13條規定，會員或期貨商不能履行結算交割義務時，期貨交易所應即會同期貨結算機構進行專案檢查，並督導承受之會員或期貨商接辦相關事務。重點在維持客戶部位與交割不中斷，並釐清違約缺口的實際規模。

(B)錯誤。追加交割結算基金是結算機構對結算會員財務要求的機制，在會員已經無法履約時通知其追加，並不能解決當下的交割問題；這一項不是本情形下交易所的法定措施。

(C)錯誤。乙（追加基金）非本情形的措施，且專案檢查由交易所會同期貨結算機構辦理，不是交由金管會執行；金管會是監理機關，不代替市場機構處理個案違約。

(D)錯誤。甲、丙為正確措施，但丁錯：專案檢查由期貨交易所會同期貨結算機構進行，金管會接受事後報告與監督，不親自執行專案檢查。

10. 期貨交易所業務人員之登記或異動，應按______列冊彙報金管會或金管會指定機構？
  1. (A)日
  2. (B)月
  3. (C)季
  4. (D)年
解析

(A)錯誤。按日彙報不是期貨交易所管理規則所定的頻率；人員登記異動不會天天發生，逐日造冊只會增加無意義的作業負擔。

(B)正確。期貨交易所管理規則第31條規定，期貨交易所業務人員之登記或異動，應按月列冊彙報主管機關或其指定機構。按月的頻率既能讓監理機關追蹤人員資格與異動，又不至於造成逐日申報的負擔；期貨結算機構與同業公會的業務人員異動也採相同的按月彙報。

(C)錯誤。按季彙報並非法規所定；每三個月才彙報一次，會使人員資格的變動在監理端延遲數月才反映，不符管理時效。

(D)錯誤。按年彙報頻率過低，一年間可能已有多次人員進出，年度彙報無法及時反映實際任職狀況，法規未採此頻率。

114年第3次｜期貨交易法規｜第 12 題
11. 期貨結算機構應依期貨交易法第五十三條規定，分別一次提存多少金額之賠償準備金？
  1. (A)新臺幣二億元
  2. (B)新臺幣三億元
  3. (C)新臺幣四億元
  4. (D)新臺幣五億元
解析

(A)錯誤。二億元並非期貨結算機構管理規則所定的賠償準備金金額；賠償準備金是結算機構自身的履約擔保財力，法規要求的是一次提存五億元的較高水準。

(B)錯誤。三億元並非期貨結算機構管理規則所定的一次提存金額；法規要求五億元，且其後仍須按季以結算手續費收入的百分之二十繼續提存。

(C)錯誤。四億元並非法規所定的賠償準備金金額；結算機構為全市場的最終履約者，故法規要求一次提存五億元，再依手續費收入持續累積。

(D)正確。期貨交易法第53條授權主管機關訂定賠償準備金的攤提條件，期貨結算機構管理規則第15條規定應就期貨交易所內及所外的期貨交易分別一次提存新臺幣五億元，其後按季以結算手續費收入百分之二十繼續提存，直至達資本額的一點五倍。賠償準備金與交割結算基金不同：前者是結算機構自身預先提存的履約財力，後者由結算會員共同繳存。

114年第3次｜期貨交易法規｜第 13 題
12. 有關期貨結算機構與其結算會員所訂立之期貨結算交割契約中，下列何者並非明定之事項？
  1. (A)期貨交易經手費標準
  2. (B)結算會員有違反規定之情事時，應繳納違約金或停止或限制其交易或終止契約
  3. (C)期貨結算機構對於拒絕承受破產會員帳戶之結算會員，得採取之處置
  4. (D)結算會員於被指定代為了結他結算會員之結算、交割事務時，有依約履行之義務

(B)錯誤。盤後交易時段的漲跌幅同樣是10%，不是7%。7%是2015年6月以前臺灣股市與臺股期貨的漲跌幅限制，放寬為10%後期貨各時段一體適用，盤後時段並沒有比較窄的限制。

(C)正確。臺股期貨無論盤後交易時段或次一一般交易時段，漲跌幅限制都是以「前一一般交易時段每日結算價」為基準上下10%。也就是說每個交易日只在一般交易時段收盤時計算一次每日結算價，接下來的盤後時段與隔天日盤都錨定這個價格。盤後時段成交量較小，若以其價格作為隔天日盤的基準，容易被少量交易牽動漲跌停的位置，統一錨定日盤結算價可避免此問題。

(D)錯誤。盤後交易時段的基準是前一一般交易時段的每日結算價，不是前一盤後交易時段的結算價，因為期交所並不對盤後時段單獨計算結算價。此選項把「前一盤後時段」誤當成有結算價可用的時段。

46. 臺灣期貨交易所鉅額交易最低買賣申報數量下列何者正確？
  1. (A)臺股期貨與小型臺指期貨同一契約為200 口
  2. (B)臺指選擇權同一契約為200 口
  3. (C)匯率類及黃金類期貨同一契約為200 口
  4. (D)匯率類及黃金類選擇權同一契約為200 口
解析

(A)錯誤。依期交所現行鉅額交易規定，臺股期貨與小型臺指期貨同一契約的最低申報數量是100口，並非200口。這兩個契約流動性最好，門檻反而比較低；200口是臺指選擇權以及「其他期貨」類別的門檻，容易被混用。

(B)正確。依期交所鉅額交易規定，臺指選擇權同一契約的最低買賣申報數量為200口。鉅額交易設有數量門檻，目的是讓大額委託透過議價或逐筆撮合在鉅額交易平台成交，避免一次丟進一般集中市場瞬間衝擊價格；門檻按各商品的流動性與契約規模訂定，臺指選擇權因單口價值小、市場深，所以門檻高於黃金選擇權。

(C)錯誤。匯率類與黃金類期貨（以及客製化期貨）同一契約的最低申報數量是50口，是所有期貨類別中最低的，因為這些契約市場深度較淺，若門檻設得和指數期貨一樣高，實務上幾乎沒有人能使用鉅額交易。

(D)錯誤。黃金類選擇權同一契約的最低申報數量是100口，而非200口；不屬於黃金類的其他選擇權則是400口。此選項把期貨與選擇權、以及不同商品類別的門檻混在一起，沒有任何一類選擇權的門檻是200口，除了臺指選擇權。

114年第3次｜期貨交易理論與實務｜第 46 題
47. 在計算整戶風險保證金計收方式(SPAN)時，各商品組合之「跨月風險值」及不同商品組合間之「風險折抵值」分別被視為保證金的加項或減項？
  1. (A)前者為減項；後者為加項
  2. (B)前者為加項；後者為減項
  3. (C)兩者均為加項
  4. (D)兩者均為減項
解析

(A)錯誤。加減方向恰好相反。跨月風險值是同一商品不同月份價差部位額外承擔的風險，只能往上加；風險折抵值是不同商品間相關性帶來的沖銷利益，只能往下減。把加減方向對調，會讓價差部位保證金過低、跨商品部位保證金過高。

(B)正確。SPAN先對每個商品組合算出價格掃描風險值，但同一商品多空不同月份的部位在掃描時會互相抵銷，實際上兩個月份的價格不會完全同步，因此要加回「跨月風險值」以反映價差風險；反之，不同商品組合（例如臺股期貨與電子期貨）價格高度相關，多空對作的部位風險部分沖銷，所以給予「風險折抵值」作為減項。SPAN以此逐層加減，最後與選擇權最低風險值取大者，得到整戶應繳保證金。

(C)錯誤。風險折抵值代表兩個相關商品一多一空時風險相互抵銷的利益，是SPAN給予的優惠，屬減項。若也當成加項，等於對沖部位反而被多收保證金，違反整戶風險計收的精神。

(D)錯誤。跨月風險值是價格掃描時因同商品多空月份互抵而被低估的價差風險，必須補加回來，屬加項。若當成減項，跨月價差部位的保證金會被計得過低，無法涵蓋兩個月份價差擴大的損失。

114年第3次｜期貨交易理論與實務｜第 47 題
48. 臺灣期貨交易所之結算會員應向其繳存：
  1. (A)營業保證金
  2. (B)違約損失準備金
  3. (C)儲備基金
  4. (D)交割結算基金
解析

(A)錯誤。營業保證金是期貨商依期貨交易法及期貨商管理規則，向主管機關指定的金融機構繳存的款項，用以擔保期貨商對交易人的責任，繳存對象不是期貨交易所或結算機構，繳存者也不限於結算會員。

(B)錯誤。「違約損失準備金」不是期貨交易法或期交所業務規則所定的繳存項目名稱。與結算違約有關的法定資源是結算會員繳存的交割結算基金，以及結算機構自行提列的準備金，前者才是結算會員的繳存義務。

(C)錯誤。「儲備基金」同樣不是法定名詞。結算機構處理會員違約時依序動用違約會員的結算保證金、其交割結算基金、結算機構自身的準備金，再動用其他結算會員的交割結算基金，其中沒有稱為儲備基金的項目。

(D)正確。依期貨交易法，結算會員應向期貨結算機構繳存交割結算基金，臺灣期貨交易所兼具結算機構身分，所以結算會員應向期交所繳存交割結算基金。交割結算基金是所有結算會員共同出資的損失分攤池，當某一會員違約、其自有保證金不足以彌補時，由基金吸收損失，藉此維持結算機構對所有交易履約的擔保能力，是集中結算防衛體系的核心。

114年第3次｜期貨交易理論與實務｜第 49 題
49. 結算會員應於收到臺灣期貨交易所之保證金款項追繳通知後，應於何時繳足？
  1. (A)一小時內
  2. (B)二小時內
  3. (C)一日內
  4. (D)翌日開盤前半小時內
解析

(A)正確。依期交所盤中保證金追繳規定，結算會員於電腦系統接獲追繳通知後，應於一小時內立即將保證金補足。結算會員的部位風險以分鐘計，行情在盤中可能持續往不利方向走，補繳時限必須極短，才能確保結算機構手上的擔保品隨時能涵蓋部位損失；逾時未補足者，期交所可限制其新增委託甚至代為沖銷部位。

(B)錯誤。二小時不是規定的時限。盤中追繳的設計是通知後立刻補足，一小時已是給結算銀行撥款作業的時間，若放寬到二小時，部位在行情劇烈波動時可能在補繳前就累積超過保證金的損失。

(C)錯誤。一日內過長。即使是收盤後的盤後追繳，期交所也要求結算會員在當天下午（1:45收盤的商品為3:30前、4:15收盤的商品為5:30前）補足，不會讓追繳款項拖到隔天；盤中追繳更只有一小時。

(D)錯誤。翌日開盤前不是結算會員的補繳期限。期交所會在次日一般交易時段開盤前對結算會員部位執行洗價並發出追繳通知，這是交易所的作業時點，不是給會員的繳款期限；會員接獲通知後仍須在一小時內補足。
