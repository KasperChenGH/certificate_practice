1. 依我國期貨交易法有關主管機關簽訂合作協定之規定，下列何者正確？
  1. (A)主管機關與外國政府機關簽訂合作協定應先經行政院核准
  2. (B)主管機關根據合作協定提供資料予外國政府機關得不受保密原則之規範
  3. (C)主管機關無須經相關機關核准即得自行授權其他機關與外國政府機關簽訂合作協定
  4. (D)主管機關僅得與外國政府機關簽訂，不可與其他機構或國際組織簽訂合作協定
解析

(A)正確。依期貨交易法，主管機關為促進國際合作，得與外國政府機關、機構或國際組織簽訂合作協定，但應先經行政院核准。

(B)錯誤。主管機關依合作協定提供資料予外國政府機關時，仍應受保密原則等條件之規範，並非得不受保密原則拘束。

(C)錯誤。簽訂合作協定須先經行政院核准，主管機關不能未經核准即自行授權其他機關對外簽訂。

(D)錯誤。期貨交易法允許主管機關與外國政府機關、機構或國際組織簽訂合作協定，並不限於外國政府機關。

4. 依我國期貨交易法規定，由當事人約定，一方支付價金一定成數之款項或取得他方授與之一定信用額度，雙方於未來特定期間內，依約定方式結算差價或交付約定物之契約，該契約係指：
  1. (A)期貨契約
  2. (B)選擇權契約
  3. (C)槓桿保證金契約
  4. (D)交換契約
解析

(A)錯誤。期貨契約是約定於未來特定期間，依特定價格及數量等交易條件買賣約定標的物，或於到期前或到期時結算差價之契約，不以支付價金一定成數或取得信用額度為要件。

(B)錯誤。選擇權契約是買方支付權利金，取得於特定期間依特定價格買賣約定標的物之權利，與題述支付價金一定成數之契約不同。

(C)正確。期貨交易法定義槓桿保證金契約為：一方支付價金一定成數之款項或取得他方授與之一定信用額度，雙方於未來特定期間內依約定方式結算差價或交付約定物之契約，與題述完全相符。

(D)錯誤。交換契約是約定於未來特定期間內，依約定方式交換約定標的物或其所產生現金流量之契約，與題述內容不同。

5. 依期貨商管理規則之規定，下列敘述何者正確？
  1. (A)期貨商業務員從事期貨交易者，限在所屬期貨商開戶，但其配偶之期貨交易開戶，不在此限
  2. (B)期貨商業務員從事期貨交易者，不限在所屬期貨商開戶，但應由其他業務員執行之
  3. (C)期貨商業務員或其配偶從事期貨交易者，限在所屬期貨商開戶，並不得利用他人名義為之
  4. (D)期貨商業務員不得於期貨商開戶從事期貨交易
解析

(A)正確。依本題所據的期貨商管理規則，期貨商業務員為自己從事期貨交易，限在所屬期貨商開戶，目的是讓所屬期貨商能監督其交易、避免與客戶利益衝突；該限制規範的是業務員本人，配偶的開戶不在此限。

(B)錯誤。業務員自行交易必須在所屬期貨商開戶，才便於公司控管與稽核，並非「不限在所屬期貨商開戶」；另外「應由其他業務員執行」也不是法規設定的條件。

(C)錯誤。限在所屬期貨商開戶的規範對象是業務員本人，本題依據的規定並未把配偶一併納入此限制，因此「業務員或其配偶」的說法擴大了適用範圍。

(D)錯誤。法規並未禁止業務員從事期貨交易，而是允許其交易但限在所屬期貨商開戶，以便控管利益衝突，所以「不得開戶交易」與規定不符。

6. 關於期貨交易輔助人的規定，下列何者正確？ 甲.期貨商可以同時委任一家以上的期貨交易輔助人；乙.應與委任期貨商簽訂委任契約；丙.證券商經營期貨交易輔助業務，應由專責部門辦理；丁.得同時接受多家期貨商之委任
  1. (A)甲、乙、丁
  2. (B)乙、丙、丁
  3. (C)甲、丙、丁
  4. (D)甲、乙、丙
解析

(A)錯誤。此組合包含丁；期貨交易輔助人只能接受一家期貨商委任，不得同時接受多家期貨商委任，以免招攬、轉單責任歸屬不清，因此丁不正確。

(B)錯誤。此組合包含丁「得同時接受多家期貨商之委任」，但期貨交易輔助人僅得受一家期貨商委任，所以此組合不成立。

(C)錯誤。甲、丙正確，但丁錯誤：期貨交易輔助人不得同時受多家期貨商委任；且此組合漏掉同樣正確的乙（應與委任期貨商簽訂委任契約）。

(D)正確。甲：一家期貨商可同時委任一家以上的期貨交易輔助人；乙：輔助人應與委任之期貨商簽訂委任契約，以明確雙方權責；丙：證券商兼營期貨交易輔助業務應設專責部門辦理。丁錯在輔助人只能接受一家期貨商委任，故選甲、乙、丙。

  4. (D)資本額須增加新臺幣二千五百萬元

(B)錯誤。本題選錯誤敘述，此敘述本身正確：設置分支機構須營業滿一年，是確認事業已有一定營運經驗的門檻條件之一，此敘述符合規定。

(C)錯誤。本題選錯誤敘述，此敘述本身正確：最近期經會計師查核簽證之財務報告每股淨值不低於面額，是確保財務健全、未嚴重虧損的條件，此敘述符合規定。

(D)正確。本題問錯誤者。設置分支機構的條件是營業滿一年、每股淨值不低於面額等，並無「資本額須增加新臺幣二千五百萬元」的要求，此數字不是法規所定的條件，故此敘述錯誤。

11. 期貨結算機構不得以賠償準備金貸予他人或移作他項用途，其運用以下列何者為限？ 甲.銀行存款；乙.購買國庫券；丙.購買政府債券；丁.購買股票
  1. (A)僅甲
  2. (B)僅甲、丙
  3. (C)僅甲、乙、丙
  4. (D)甲、乙、丙、丁

(D)錯誤。股票價格波動大，與賠償準備金要求的安全性、流動性不符，不在允許的運用範圍內，故丁不應列入。
