1. 依我國期貨交易法對於槓桿保證金契約定義之敘述，下列何者正確？
  1. (A)當事人約定於未來特定期間依特定價格及數量等交易條件買賣約定標的物，或於到期前或到期時結算差價之契約
  2. (B)當事人約定一方支付價金一定成數之款項或取得他方授與之一定信用額度，雙方於未來特定期間內，依約定方式結算差價或交付約定物之契約
  3. (C)當事人約定選擇權買方支付權利金，取得購入或售出之權利，得於特定期間內，依特定價格數量等交易條件買賣期貨契約
  4. (D)當事人約定選擇權買方支付權利金，取得購入或售出之權利，得於特定期間內，依特定價格及數量等交易條件買賣約定標的物；選擇權賣方於買方要求履約時，有依約履行義務
解析

(A)錯誤。此為期貨契約（狹義）之定義，重點在未來特定期間依約定條件買賣或結算差價。

(B)正確。槓桿保證金契約的特徵是一方支付價金一定成數之款項，或取得他方授與之一定信用額度，再於未來特定期間依約結算差價或交付約定物。「成數給付＋信用額度」正是它與期貨契約的分野。

(C)錯誤。此為期貨選擇權契約之定義，其標的為期貨契約。

(D)錯誤。此為選擇權契約之定義，其標的為約定標的物。

2. 依我國期貨交易法之規定，下列有關選擇權契約之敘述何者錯誤？

  2. (B)選擇權買方可於特定期間內依特定價格數量買賣期貨契約
  3. (C)選擇權契約可約定採實物交割或現金結算方式
  4. (D)選擇權賣方於買方要求履約時有依約履行之義務

(C)錯誤（此敘述正確）。選擇權契約得約定以實物交割或現金結算方式履約。

(D)錯誤（此敘述正確）。買方要求履約時，賣方負有依約履行的義務。

115年第2次｜期貨交易法規｜第 5 題
6. 期貨交易所送審期貨契約，主管機關准駁之期間，除有特殊情形外，不得超過多少時間？
  1. (A)3 個月
  2. (B)6 個月
  3. (C)1 年
  4. (D)1 個月
解析

(A)錯誤。三個月不是期貨交易法所定的准駁期限。新契約審查需要評估標的市場、契約規格與結算機制，法律給主管機關的時間是六個月；三個月會讓審查過於倉促。

(B)正確。依期貨交易法第10條第2項，期貨交易所送審期貨交易契約，主管機關准駁之期間，除有特殊情形外，不得超過六個月。設定期限的目的是避免新商品的審查無限期延宕，讓交易所能規劃上市時程；「除有特殊情形外」則保留主管機關在複雜案件中延長的空間。

(C)錯誤。一年比法定期限長一倍。若准駁可以拖到一年，交易所送審的商品可能錯過市場時機，與本條要求主管機關限期准駁的立法目的相反。

(D)錯誤。一個月過短，主管機關來不及完成契約設計、標的市場與風險控管的審查。法律定的是六個月，並允許特殊情形例外。

7. 會員制期貨交易所之設立，應於主管機關許可之日起多久內完成法人設立登記？
  1. (A)3 個月
  2. (B)6 個月
  3. (C)9 個月
  4. (D)1 年
解析

(A)錯誤。三個月不是設立標準所定的期限。會員制期貨交易所取得許可後還要完成章程、會員招募與法人登記，設立標準給的是六個月，且有正當理由可申請延展一次。

(B)正確。依期貨交易所設立標準第8條，會員制期貨交易所之設立，應自主管機關許可之日起六個月內完成法人設立登記；有正當理由者，得於期限屆滿前申請延展，延展期限不得超過六個月，並以一次為限。限期登記是為了避免許可長期閒置，讓已核准的交易所在合理時間內實際成立。

(C)錯誤。九個月不是規定的期限，也不是延展後的上限。基本期限是六個月，延展最多再六個月，合計最長十二個月，九個月不對應任何一個節點。

(D)錯誤。一年是「六個月加一次六個月延展」後可能達到的最長時間，不是原始期限。題目問的是許可之日起應完成登記的法定期限，答案是六個月。

8. 期貨交易所業務人員之登記或異動，應按___列冊彙報金管會或金管會指定機構。
  1. (A)日
  2. (B)月
  3. (C)季
  4. (D)年
解析

(A)錯誤。按日彙報並非規則要求。業務人員的登記與異動並不會每天發生，逐日造冊只會增加作業成本，對監理沒有實質幫助，管理規則採按月彙報。

(B)正確。依期貨交易所管理規則第31條，期貨交易所業務人員之登記或異動，應按月列冊彙報主管機關或其指定機構。按月的頻率兼顧兩端：主管機關能在合理時間內掌握交易所人員的資格與變動，交易所也不必承擔逐日申報的作業負擔。

(C)錯誤。按季彙報的間隔太長。若人員異動要等最多三個月後才被主管機關知悉，不具資格者可能已執行業務一整季，管理規則要求的是按月。

(D)錯誤。按年彙報的頻率過低，主管機關對交易所業務人員的異動幾乎無法即時掌握，與登記制度的目的不符；規則定的是按月列冊彙報。

115年第2次｜期貨交易法規｜第 8 題
9. 期貨商違反期貨交易所業務規則或其他章則情節重大，經公司制期貨交易所依期貨交易法第39條第1 項第2 款規定，終止與期貨商所訂之使用期貨集中交易市場之契約者，應如何處理？
  1. (A)僅須提期貨交易所董事會通過即可
  2. (B)向期貨公會申報核備
  3. (C)應得主管機關核准
  4. (D)應申報主管機關備查
解析

(A)錯誤。董事會決議只是交易所內部形成處分的程序，期貨交易法第41條另要求終止契約後申報主管機關備查，內部決議不能取代對外的申報義務。

(B)錯誤。期貨公會是期貨業者的自律團體，負責會員業者的自律規範與人員登記，不是交易所終止市場使用契約的申報對象；法定申報對象是主管機關金管會。

(C)錯誤。「核准」是事前許可，終止契約若須先經核准，交易所的第一線紀律權就會被架空。法條用語是事後「備查」，與第39條第2項契約訂立時須「核備」也不同，兩者要分開記。

(D)正確。期貨交易法第41條規定，公司制期貨交易所依第39條第1項第2款終止期貨商之契約者，應申報主管機關備查。終止契約是交易所依業務規則對違規期貨商的自律處分，交易所先動手、再向金管會報備，既保留自律機構的即時紀律權，也讓主管機關掌握重大處分並得事後監督。

115年第2次｜期貨交易法規｜第 9 題
10. 依我國期貨交易法之規定，在公司制期貨交易所交易之期貨商，應與交易所訂立何項契約？
  1. (A)使用期貨集中交易市場之契約
  2. (B)期貨交易全權委任契約
  3. (C)受託辦理結算交割契約
  4. (D)委任契約
解析

(A)正確。期貨交易法第39條規定，在公司制期貨交易所交易之期貨商，應與交易所訂立「使用期貨集中交易市場之契約」，並訂明經手費標準、違約時的違約金與停止交易、被指定代為了結他期貨商交易的義務等事項。公司制交易所沒有會員，期貨商不是股東而是市場使用者，所以要靠這份契約建立雙方權利義務並受交易所章則拘束。

(B)錯誤。全權委任契約是期貨經理事業接受客戶委託代為操作時所簽的契約，規範的是業者與投資人之間的關係，與期貨商取得市場使用資格無關。

(C)錯誤。結算交割契約是非結算會員期貨商與結算會員之間、或結算會員與結算機構之間就結算交割所訂的契約，處理的是成交後的結算履約，不是進場交易的資格。

(D)錯誤。委任契約是民法上一方委託他方處理事務的契約，期貨商與交易所之間不是委託處理事務的關係，而是使用集中市場設施並受章則規範的契約關係。

115年第2次｜期貨交易法規｜第 10 題
11. 依我國期貨交易法，有關期貨交易所之規定，下列敘述何者正確？
  1. (A)會員制期貨交易所之組織，為非以營利為目的之財團法人
  2. (B)會員制期貨交易所之會員，不得少於20 人
  3. (C)公司制期貨交易所之組織，限定為股份有限公司
  4. (D)在正常情形下，公司制期貨交易所之會員，不得少於7 人
解析

(A)錯誤。期貨交易法第21條規定會員制期貨交易所為非以營利為目的之「社團法人」。社團法人以人（會員）為成立基礎，財團法人則以捐助的財產為基礎，會員制交易所由會員組成，性質上屬社團。

(B)錯誤。期貨交易法第22條規定會員制期貨交易所之會員不得少於七人，下限是七人而非二十人；把門檻記成二十人是與其他組織法規的人數要求混淆。

(C)正確。期貨交易法第34條規定，公司制期貨交易所之組織以股份有限公司為限，且單一股東持股原則上不得超過實收資本額百分之五。限定股份有限公司是因為交易所要承擔市場經營與違約處理責任，需要明確的資本結構、董事會與監察人治理機制；持股上限則防止單一股東掌控市場。

(D)錯誤。公司制期貨交易所由股東組成，沒有「會員」，期貨商是以使用市場契約取得交易資格；「不得少於七人」是第22條對會員制交易所會員人數的規定。

115年第2次｜期貨交易法規｜第 11 題
12. 期貨結算機構應設置業務委員會及紀律委員會，其成員至少應有幾分之幾為其結算會員？
  1. (A)三分之一
  2. (B)三分之二
  3. (C)二分之一
  4. (D)四分之一
解析

48. 棉花期貨原始保證金為$1,000，維持保證金為$750，交易人存入$2,000，買進2 口棉花期貨，價位為$0.7210，當期貨上漲至$0.7250，交易人未平倉，他可以提領的金額為：(棉花期貨每口為50,000 磅，手續費不計)

  2. (B)$400
  3. (C)不得提領
  4. (D)$900
解析

(A)錯誤。二百元低估了實際獲利，未按每口五萬磅正確換算。

(C)錯誤。權益已超過原始保證金總額，超額部分即為超額保證金，可以提領。

(D)錯誤。九百元超過帳戶的超額保證金，提領後權益將低於原始保證金要求。

49. 某農夫在6 月時預測9 月時至少可以收成50,000 英斗黃豆，為了防止黃豆價格下降，決定賣黃豆期貨避險，價格為7.35 美元／英斗。等到9 月收成時，以每英斗6.85 美元賣給當地穀倉，並於6.90 美元／英斗平倉黃豆期貨，則農夫的淨銷售價應為每英斗多少美元？
  1. (A)6.4
  2. (B)7.3
  3. (C)6.85
  4. (D)6.9
解析

(A)錯誤。6.4是把期貨利得0.45從現貨售價扣掉（6.85－0.45）的結果，方向弄反了；空頭期貨在價格下跌時是獲利，應加回現貨售價。

(B)正確。期貨以7.35賣出、6.90買回平倉，獲利7.35－6.90＝0.45；現貨售價6.85加上期貨利得0.45，淨銷售價為7.30美元。空頭避險的作用就是用期貨端的獲利補回現貨跌價，把售價鎖回接近當初的期貨價位，剩下的0.05差距來自基差變動。

(C)錯誤。6.85只是賣給穀倉的現貨價格，忽略了期貨端0.45的獲利；避險的意義正是把期貨損益併入現貨售價。

(D)錯誤。6.90是期貨平倉價，不是農夫實際實現的價格；淨售價要把現貨售價加上期貨部位的損益。

50. 下列何種情況，歐式買權和賣權的Delta 敏感度最小？
  1. (A)買權深價外，賣權深價外
  2. (B)買權價平，賣權價平
  3. (C)買權深價內，賣權深價外
  4. (D)買權深價外，賣權深價內
解析

(A)正確。深價外的買權與賣權履約機率都極低，Delta絕對值同時趨近於零，敏感度最小。Delta是選擇權價值對標的價格的變動率，深價外時標的小幅變動幾乎不改變「到期會作廢」的判斷，權利金也就幾乎不動。

(B)錯誤。價平時買權Delta約0.5、賣權約－0.5，標的每動1元權利金約動0.5元，敏感度屬中等，且Gamma在此最大，並非最小。

(C)錯誤。買權深價內時Delta趨近1，價格幾乎與標的同步變動，是敏感度最大的情況；即使賣權深價外接近零，兩者合計也不是最小。

(D)錯誤。賣權深價內時Delta趨近－1，絕對值最大；買權深價外雖接近零，整體敏感度並非最小。
