2. 我國期貨業之主管機關為：
  1. (A)金融監督管理委員會
  2. (B)財政部
  3. (C)行政院經濟建設委員會
  4. (D)中央銀行
解析

(A)正確。期貨交易法所稱主管機關為金融監督管理委員會，實際由其所屬證券期貨局負責期貨市場與期貨業的監理。

(B)錯誤。財政部曾是證券期貨的主管機關（舊證期會隸屬財政部），但金管會成立後監理權已移轉，財政部已非期貨業主管機關。

(C)錯誤。行政院經濟建設委員會負責經濟規劃，從未主管期貨業，且已於2014年與研考會合併為國家發展委員會。

(D)錯誤。中央銀行掌理貨幣政策與外匯管理，涉及外匯相關業務時會參與，但期貨業的主管機關是金管會而非央行。

6. 期貨交易所發現期貨商有經營不善致信用難以維持時，應對期貨商：

7. 依我國期貨交易法之規定，期貨結算機構應將結算會員所繳交之何項款項，依自營與經紀分離處理？

  2. (B)交割結算基金
  3. (C)營業保證金
  4. (D)賠償準備金
解析

(A)正確。期貨交易法規定，期貨結算機構應將結算會員繳交的結算保證金，依自營與經紀分離處理，避免自營虧損牽連客戶部位，保障期貨交易人。

(D)錯誤。賠償準備金是期貨商為因應客戶損害賠償而提存的準備，不是繳交給結算機構的結算款項。

(A)錯誤。未獲許可或被撤銷許可時，申請人可領回所繳存的款項，但這是返還而非本題所問的可動用時點。

(B)正確。期貨結算機構申請許可時繳存於指定金融機構的款項，須待完成公司設立登記後方可動用，確保籌設確實完成、資本到位。

(C)錯誤。款項於公司設立登記後即可動用，不必等到結束營業，此說法與規定不符。

(D)錯誤。繳存款項的目的就是確保籌設誠意與資本到位，動用時點有明確限制，並非沒有限制。

103年第1次｜期貨交易法規｜第 8 題
9. 依我國期貨交易法，期貨結算會員因期貨結算所生之債務，其債權人對該會員之結算交割基金的受償順序為何？甲.期貨結算機構；乙.期貨結算會員；丙.期貨交易人
  1. (A)丙、乙、甲
  2. (B)乙、丙、甲
  3. (C)甲、乙、丙
  4. (D)甲、丙、乙
解析

(A)錯誤。此順序把結算機構放在最後，與期貨交易法的規定不符；結算機構對結算交割基金享有最優先受償。

(B)錯誤。此順序讓結算會員優先於結算機構與期貨交易人受償，與保護結算制度與交易人的立法精神相反。

(C)錯誤。此順序將結算會員排在期貨交易人之前，不符期貨交易法保障交易人的規定，交易人應優先於結算會員。

(D)正確。依期貨交易法，結算會員因期貨結算所生之債務，其結算交割基金的受償順序為期貨結算機構、期貨交易人、期貨結算會員，即甲、丙、乙。

13. 下列敘述何者不正確？
  1. (A)期貨商內部控制制度之訂定或變更，應報經董事會同意，並留存備查
  2. (B)期貨商得藉主管機關之營業許可，作為營業能力及財務健全之宣傳或保證

(A)錯誤。此敘述正確：內部控制制度是公司治理核心，其訂定或變更應經董事會通過並留存備查，故不是本題要選的不正確敘述。

(D)錯誤。此敘述正確：讓與全部或主要部分營業或財產屬重大事項，影響客戶權益，須事先報經主管機關核准，故不是本題答案。

103年第1次｜期貨交易法規｜第 14 題
15. 期貨商之業務員，不包括從事下列何項業務者？
  1. (A)招攬、開戶、受託、執行
  2. (B)全權委託
  3. (C)自行查核或法令遵循
  4. (D)交易決定
解析

(A)錯誤。招攬、開戶、受託、執行是期貨商最典型的業務員工作，依期貨商管理規則須登記為業務員。
