期貨交易法規　50 題

1. 我國期貨業之主管機關為:
  1. (A)金融監督管理委員會
  2. (B)中央銀行
  3. (C)國家發展委員會
  4. (D)財政部
解析

(A)正確。期貨交易法第4條明定「本法所稱主管機關，為金融監督管理委員會」。期貨市場的契約核准、期貨商許可、期交所與結算機構監理，全部由金管會（實際由其證券期貨局承辦）統籌，與證券市場採同一監理口徑，避免證券與期貨兩邊各管各的而出現套利縫隙。

(B)錯誤。中央銀行掌管貨幣政策、外匯管理與支付系統，對期貨業的關係只到外匯交易與資金流動面，不核發期貨商執照、不核准期貨契約。

(C)錯誤。國家發展委員會負責國家發展計畫、經濟研究與法規鬆綁政策協調，是規劃幕僚機關，不具金融業許可與監理權限。

(D)錯誤。財政部在2004年金管會成立前，曾透過其下的證券暨期貨管理委員會監理期貨業，這是本選項容易被誤選的原因；現行法已改由金管會主管，財政部僅掌國庫與賦稅。

112 年第1 次｜期貨交易法規｜第 2 題
3. 期貨交易契約經主管機關核准後,依我國期貨交易法規定,下列何種情事者,主管機關得撤銷之?甲.不符公共利益;乙.喪失經濟利益;丙.經期貨交易所申請
  1. (A)甲、乙
  2. (B)甲、丙
  3. (C)乙、丙
  4. (D)甲、乙、丙
解析

(A)錯誤。這組漏掉「經期貨交易所申請」。交易所最了解某契約是否已無人交易、維護成本是否高於效益，法律因此讓交易所可以主動提出撤銷申請，這是第三個法定事由。

(B)錯誤。這組漏掉「喪失經濟效益」。一個已經沒有避險或價格發現功能的契約繼續掛牌只會浪費監理與結算資源，所以法律把喪失經濟效益列為主管機關得撤銷的事由。

(C)錯誤。這組漏掉「不符公共利益」。期貨契約核准的前提之一就是對市場有益，若上市後發現契約設計被用於操縱或損及公共利益，主管機關當然可以收回核准。

(D)正確。期貨交易法第11條規定，期貨交易契約經主管機關核准後，有喪失經濟效益、不符公共利益、或經期貨交易所申請三種情事之一者，主管機關得撤銷之。三者分別對應契約沒有用、契約有害、以及交易所自己不想再維持這三種情境，題目所列甲乙丙全部都是法定事由。

112 年第1 次｜期貨交易法規｜第 3 題
4. 會員制期貨交易所各會員除依章程規定分擔經費,各會員對於期貨交易所之責任,以其出資額之幾倍為限?
  1. (A)20倍
  2. (B)10倍
  3. (C)5倍
  4. (D)2倍
解析

(A)錯誤。20倍會使會員的潛在責任高達出資額的二十倍，實務上沒有會員願意承擔如此開放的連帶風險，法律因此不採此倍數；把「責任愈重愈安全」直覺套上去就會選到這裡。

(B)正確。期貨交易法第24條規定，除依章程分擔經費及應繳款項外，各會員對於期貨交易所之責任，以其出資額之十倍為限。設上限是為了讓會員的最大暴險可以事先計算，否則無限責任會嚇退合格的會員；設在十倍而非一倍，則是讓交易所在發生重大違約時仍有足夠的追償基礎。

(C)錯誤。5倍是把法定倍數記成一半的結果。若責任只到出資額五倍，交易所在會員大規模違約時可追償的金額會明顯不足，法律採十倍正是為了拉高這個緩衝。

(D)錯誤。2倍接近一般有限責任公司股東「以出資額為限」的觀念，但會員制交易所的會員不是單純的股東，還要共同擔保市場履約，所以法律要求的責任遠高於兩倍。

112 年第1 次｜期貨交易法規｜第 4 題
5. 依我國期貨交易法,關於期貨交易所的規定,下列何者正確?甲.應經財政部許可並發給許可執照;乙.促進公共利益為其設立宗旨之一;丙.其組織分為會員制與公司制;丁.應向中央銀行繳存營業保證金
  1. (A)甲、丁
  2. (B)乙、丙
  3. (C)甲、丙
  4. (D)丙、丁
解析

(A)錯誤。甲與丁都不對。期貨交易法第4條明定主管機關是金管會，交易所的設立許可與執照由金管會核發（第8條）；營業保證金依第14條是向國庫繳存，不是向中央銀行。

(B)正確。期貨交易法第7條規定，期貨交易所之設立應以促進公共利益及確保期貨市場交易之公正為宗旨，其組織分會員制及公司制。乙、丙正確；甲錯在主管機關是金管會而非財政部，丁錯在營業保證金是繳存國庫而非中央銀行。

(C)錯誤。丙正確但甲不對。財政部在2004年以前曾是主管機關，現行法第4條已改為金管會，交易所的許可證照也由金管會發給；記成財政部是沿用舊制的結果。

(D)錯誤。丙正確但丁不對。期貨交易法第14條規定期貨交易所應向國庫繳存營業保證金，中央銀行只是國庫的代理機關，法條上的繳存對象是國庫。

112 年第1 次｜期貨交易法規｜第 5 題
6. 期貨交易所從事下列業務者,何者為法令規定之業務人員?
  1. (A)法令遵循
  2. (B)全權委託
  3. (C)集中交易市場資訊管理
  4. (D)主辦會計
解析

(A)錯誤。法令遵循是期貨交易所內部控制制度下的遵循單位工作，負責檢視業務是否合規，不在期貨交易所管理規則第3條所列的六類業務人員之內。

(B)錯誤。全權委託是期貨經理事業的業務，由經理事業接受客戶委任代為操作期貨；期貨交易所提供集中交易市場，本身不做全權委託，這一項與交易所的業務人員無關。

(C)正確。期貨交易所管理規則第3條列舉業務人員從事的六類業務：契約設計與研究、集中市場交易監視與保證金作業、與結算機構辦理結算交割、集中交易市場電腦作業及資訊管理、會員或期貨商財務業務查核、內部稽核。集中交易市場資訊管理屬第四款，直接影響撮合與行情揭示的正確性，所以被列為須具備資格的業務人員。

(D)錯誤。主辦會計是公司會計制度下的職務，處理交易所自身的帳務與財務報表，屬一般行政人員，不是管理規則第3條為期貨市場運作而定義的業務人員。

112 年第1 次｜期貨交易法規｜第 8 題
9. 期貨結算機構應依期貨交易法第五十三條規定,分別一次提存多少金額之賠償準備金?
  1. (A)新臺幣二億元
  2. (B)新臺幣三億元
  3. (C)新臺幣四億元
  4. (D)新臺幣五億元
解析

(A)錯誤。新臺幣二億元不到法定金額的一半。賠償準備金是市場發生違約而交割結算基金仍不足時的最後一道緩衝，太低的一次提存會讓結算機構在成立初期就缺乏承擔重大違約的能力。

(B)錯誤。新臺幣三億元仍低於法定的五億元。期貨結算機構管理規則第15條除了一次提存外，還要求每季按結算交割手續費收入的20%繼續提存，直到達資本總額的1.5倍，起始金額設得高才能讓這條累積曲線一開始就有足夠厚度。

(C)錯誤。新臺幣四億元只差一億就到法定門檻，但法規要求的是一次提存足額五億元，不是分期補到位；記成四億通常是把「五」與相鄰數字混淆。

(D)正確。期貨結算機構管理規則第15條規定，期貨結算機構應依期貨交易法第53條分別一次提存新臺幣五億元作為賠償準備金，其後並於每季終了後十五日內按結算交割手續費收入的百分之二十繼續提存，直到達資本總額或指撥營運資金的一點五倍為止。一次提存五億元是為了讓結算機構自開業起就具備承擔結算會員違約的財務能力。

112 年第1 次｜期貨交易法規｜第 9 題
10. 本國證券商申請兼營期貨業務,其自有資本適足比率不得低於多少?
  1. (A)百分之二百
  2. (B)百分之一百五十
  3. (C)百分之一百三十
  4. (D)百分之一百
解析

(A)錯誤。百分之二百比法定門檻高出許多。若門檻設在200%，自有資本只要沒有到達風險約當額的兩倍就不能兼營，大量財務健全的證券商都會被排除，法規沒有訂得這麼嚴。

(B)正確。期貨商設置標準第24條列出證券商申請兼營期貨業務的條件，其中第七款是證券商自有資本適足比率未低於百分之一百五十。自有資本適足比率是合格自有資本除以各類風險約當額，150%代表資本比風險暴險多出一半的緩衝，證券商要再承接期貨業務的保證金與違約風險，主管機關要求先有這層緩衝。

(C)錯誤。百分之一百三十低於法定的150%。這個水準下自有資本對風險的緩衝只有三成，主管機關認為不足以再承受期貨業務帶來的額外風險，因此不符兼營條件。

(D)錯誤。百分之一百表示自有資本剛好與風險約當額打平，完全沒有緩衝，是資本適足制度中最低限度的存活線，不可能被拿來當作可以再擴張業務的門檻。

(D)錯誤。限制數量仍可能使客戶承擔過高風險，並非法令認可之主要處理方式。
