1. 期貨信託事業向公司董事、監察人之關係人購買不動產，應於事實發生之日起二日內公告，所稱之關係人，不包括下列何者事項？
  1. (A)董事之配偶
  2. (B)監察人三親等以內之血親
  3. (C)監察人配偶為負責人之企業
  4. (D)董事為負責人之企業
解析

(A)錯誤。董事之配偶屬關係人範圍，購買其不動產須依規定公告。

(B)正確（即不包括者）。關係人所涵蓋之血親範圍未及於三親等。關係人採列舉而非概括，是為了讓事業與稽核有一條可操作的界線；範圍若無限擴張，反而難以落實查核。

(C)錯誤。監察人配偶為負責人之企業屬關係人，交易須受規範。

(D)錯誤。董事為負責人之企業屬關係人，係防範以法人形式迂迴進行關係人交易。

  4. (D)應同時申請由改制之期貨信託事業兼營期貨經理事業，以維護期貨經理事業原有客戶之權益

(A)錯誤。取得金管會核發兼營期貨信託事業之許可證照，屬改制應具備之條件。

(C)錯誤。改制並兼營期貨經理事業之議案須經股東會決議通過，敘述正確。

(D)錯誤。應同時申請兼營期貨經理事業，以維護原有客戶權益，敘述正確。

6. 期貨信託事業應有一名符合期貨信託事業設置標準第十二條所定資格條件之股東，該股東持股除以發行新股分配員工紅利、發行新股保留由員工承購或符合一定條件者外，其合計持有股份不得少於已發行股份總數百分之幾？
  1. (A)百分之十
  2. (B)百分之十五
  3. (C)百分之二十
  4. (D)百分之二十五
解析

(A)錯誤。百分之十並非規範所定之最低持股比率，比率過低無從確保專業股東之實質影響力。

(B)錯誤。百分之十五並非規範所定之最低持股比率；該門檻以已發行股份總數為計算基礎。

(C)正確。符合設置標準第十二條資格條件之股東，合計持股不得少於已發行股份總數百分之二十。要求專業股東維持一定持股，是確保具備專業能力者對公司有實質影響力，避免許可取得後專業股東退場。

(D)錯誤。百分之二十五並非規範所定之最低持股比率，該數字高於法規實際要求。

7. 關於期貨信託事業之資金運用，下列何者錯誤？
  1. (A)不得購置非營業用之不動產
  2. (B)得購買國內外政府債券
  3. (C)得購買符合主管機關核准或認可之信用評等機構評等達一定等級以上之有價證券
  4. (D)得購買商業票據或其他經核定之短期票券
解析

(A)錯誤。此為正確敘述：不得購置非營業用之不動產，以免資金流動性遭鎖住。

(B)正確（即敘述有誤者）。期貨信託事業自有資金之運用限於法定列舉項目，購買政府債券以國內者為限，不包括國外政府債券。自有資金是清償能力的最後屏障，故只准放在流動性高且監理可及的標的。

(C)錯誤。此為正確敘述：得購買評等達一定等級以上之有價證券。

(D)錯誤。此為正確敘述：得購買商業票據或其他經核定之短期票券。

114年第2次｜期貨信託法規及自律規範｜第 10 題
9. 期貨信託事業之風險管理委員會主要職能在有效規劃、監督與執行期貨信託事業運用期貨信託基金之風險管理事務，依規定委員會至少多久開會一次？
  1. (A)每日
  2. (B)每週
  3. (C)每月
  4. (D)每季
解析

(A)錯誤。逐日監控部位、保證金與風險值是風險管理執行單位的日常作業，由系統與專責人員持續進行；風險管理委員會處理的是限額設定、模型與政策等規劃監督層次的事項，不以每日開會的方式運作。

(B)錯誤。每週開會不是規範所定的最低頻率。期貨信託事業當然可以在內部規章中約定更密集的會議，但那屬於自我加嚴，法規要求的底線是每月一次。

(C)正確。風險管理委員會的職能在規劃、監督與執行期貨信託事業運用期貨信託基金之風險管理事務，依規定至少應每月開會一次。每月一次的節奏，讓委員會的檢討頻率快到足以反映期貨部位與市場波動的變化，又與日常由風險管理單位進行的即時監控，以及至少每季一次對全部基金總風險暴露的整體檢視，在層次上有所分工。

(D)錯誤。每季是期貨信託基金管理辦法第三十七條要求檢視所經理全部基金總風險暴露、風險計算方式與最大可能損失的頻率，屬更高層級、更長週期的審視；風險管理委員會的開會頻率比它密集，至少每月一次。

10. 依據「期貨信託基金管理辦法」之規定，期貨信託事業投資外國期貨基金，該外國期貨基金投資於臺灣地區期貨與證券市場之比率不得超過其淨資產價值之百分之多少？
  1. (A)百分之五十
  2. (B)百分之六十
  3. (C)百分之七十
  4. (D)百分之八十
解析

(A)錯誤。百分之五十只是「是否過半」的直覺分界，規範並未以過半為標準；真正的界線訂在百分之七十，容許外國期貨基金對臺灣市場有相當比重的布局。

(B)錯誤。百分之六十是期貨信託基金管理辦法對組合型基金投資子基金支付總額所設的下限，是一道最低投入比率，與本題的最高回投比率方向相反。

(C)正確。期貨信託基金所投資的外國期貨基金，其投資於臺灣地區期貨與證券市場的比率，不得超過該外國期貨基金淨資產價值之百分之七十。設這道上限，是避免資金以投資外國期貨基金為名，實質上幾乎又全數回投國內市場，藉境外架構迂迴規避國內基金應遵守的投資範圍與集中度限制，也確保投資人真的取得分散境外市場的效果。

(D)錯誤。百分之八十已逾規範所定的七成上限。到這個程度，該外國期貨基金的損益幾乎完全由臺灣市場決定，以「投資外國期貨基金」名義持有它已名實不符。

12. 有關期貨信託事業從業人員之規定，下列敘述何者錯誤？
  1. (A)總經理原則上不得兼任該公司之董事長
  2. (B)基金經理人不得兼任執行交易及投資之業務員
  3. (C)總經理得兼任該公司之基金經理人
  4. (D)他業兼營期貨信託事業之內部稽核人員，如具期貨信託事業內部稽核資格，得由他業登記之內部稽核人員兼任
解析

  1. (A)期貨信託事業經核發許可證照後，除他業兼營期貨信託事業者外，應於二個月內申請募集期貨信託基金
  2. (B)期貨信託事業首次申請募集期貨信託基金係對不特定人募集者，應在國外募集
  3. (C)期貨信託事業首次申請募集期貨信託基金係對不特定人募集者，最低成立金額為新臺幣三億元
  4. (D)期貨信託基金應於募集之核准函送達日起六個月內開始募集
解析

(A)錯誤。取得許可證照後應於一定期間內申請募集基金的要求確實存在，用意是避免事業長期持照不營業；但該期間不是二個月——募集申請須先備妥公開說明書與期貨信託契約，並與基金保管機構及銷售機構完成約定，兩個月內客觀上難以完成。

(B)錯誤。方向顛倒了。首次申請募集而對不特定人募集者應在國內募集，先在國內市場留下可供主管機關與投資人檢驗的募集與運作紀錄，才談在國外募集；一開始就赴國外募集將使監理難以落實。

(C)錯誤。首次對不特定人募集之期貨信託基金最低成立金額為新臺幣五億元，不是三億元。三億元是期貨信託事業設置標準第十一條所定事業本身的實收資本額下限，衡量的是事業的資本而非基金規模。

(D)正確。期貨信託基金管理辦法規定，期貨信託基金應於募集之核准函送達日起六個月內開始募集；非首次募集者若有正當理由不能如期開始，得於期限屆滿前申請展延一次，並以六個月為限。設起募期限是防止事業取得核准後長期擱置，占住核准額度卻不進入市場，甚至以已獲核准為名對外招攬而實際並未募集。

36. 有關期貨信託事業投資外國期貨事業之規定，下列敘述何者錯誤？

  2. (B)最近期經會計師查核簽證之財務報告，每股淨值不低於面額
  3. (C)除專案核准外，投資外國期貨事業之總金額，不得超過期貨信託事業淨值百分之二十
  4. (D)期貨信託事業投資外國期貨事業，應以該期貨信託事業所營業務為限
解析

(A)錯誤（此項敘述無誤）。期貨信託事業管理規則第三十九條就投資外國期貨事業所列的條件之一是本業營業須滿二年，要求事業先有一定的經營與風險管理實績，才把資本投向境外，本敘述與條文相符。

(B)錯誤（此項敘述無誤）。同條並要求最近期經會計師查核簽證之財務報告每股淨值不低於面額，也就是本業未有累積虧損侵蝕資本的情形；財務體質未站穩之前不宜對外轉投資，本敘述無誤。

(C)正確（此項敘述有誤）。期貨信託事業管理規則第三十九條所定的上限是：除經專案核准外，投資外國期貨事業之總金額不得超過期貨信託事業淨值之百分之十，本項寫成百分之二十，把額度放寬了一倍。海外轉投資的資金無法用來支撐經理業務與賠償責任，監理與資訊取得又較困難，故上限訂得相當保守。

(D)錯誤（此項敘述無誤）。同條要求投資外國期貨事業應以該期貨信託事業所營業務為限，不得藉轉投資跨足與本業無關的事業，以免資本流向主管機關監理範圍外的業務，本敘述與條文相符。

37. 關於期貨信託事業內部控制制度之敘述，何者正確？甲.應依證券暨期貨市場各服務事業建立內部控制制度處理準則之規定；乙.內部控制制度之訂定應報經董事會同意；丙.經主管機關通知變更內部控制制度者，期貨信託事業應於期限內變更
  1. (A)僅甲、乙
  2. (B)僅乙、丙
  3. (C)僅甲、丙
  4. (D)甲、乙、丙
解析

(A)錯誤。漏列經主管機關通知變更時應於期限內變更之義務。

(B)錯誤。漏列應依證券暨期貨市場各服務事業建立內部控制制度處理準則辦理。

(C)錯誤。漏列乙：內部控制制度之訂定應報經董事會同意，此為公司治理之必要程序。

(D)正確。三者皆是。其共同點在於：內部控制制度須有法定依據（處理準則）、須經公司最高治理機關（董事會）同意，並受主管機關事後監督與命令變更，形成外部規範、內部授權、事後監理三層架構。
