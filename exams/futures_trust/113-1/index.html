1. 依「期貨信託事業管理規則」第二十條規定，期貨信託事業應依規定編製財務報告。該年度財務報告最遲應於每會計年度終了後幾個月內公告？
  1. (A)一個月內
  2. (B)二個月內
  3. (C)三個月內
  4. (D)四個月內
解析

(A)錯誤。一個月不足以完成查核簽證程序，非規範所定期限。

(B)錯誤。二個月並非年度財務報告所定之公告期限。

(C)正確。年度財務報告最遲應於每會計年度終了後三個月內公告。年報須經會計師查核，故給予較長作業期間；期限化的目的是讓受益人能在可預期的時點取得經稽核的財務資訊。

(D)錯誤。四個月已逾規範所定之公告期限。

2. 下列有關期貨信託事業行使期貨信託基金持有股票之投票表決權之敘述，何者錯誤？
  1. (A)除法令另有規定外，應由期貨信託事業指派該事業人員代表為之
  2. (B)期貨信託事業行使投票表決權，不得間接參與該股票發行公司有不當之安排情事
  3. (C)期貨信託事業行使投票表決權，得直接參與該股票發行公司經營
  4. (D)期貨信託事業於出席基金所持有股票之發行公司股東會前，應將行使表決權之評估分析作業，作成說明
解析

(A)錯誤。除法令另有規定外，應由期貨信託事業指派該事業人員代表行使，敘述正確。

(B)錯誤。不得間接參與發行公司之不當安排，敘述正確，非本題所選。

(C)正確（即敘述有誤者）。行使表決權應本於受益人最大利益，不得直接或間接參與該股票發行公司之經營。基金持股是為受益人理財，一旦介入經營，事業的利益與受益人的利益即可能分歧。

(D)錯誤。出席股東會前應就表決權行使作成評估分析說明，以留下決策依據，敘述正確。

8. 依「期貨信託基金管理辦法」之規定，有關期貨信託基金會計之敘述，下列何者正確？
  1. (A)期貨信託基金之淨資產價值，應依投信投顧公會訂定之會計原則計算之
  2. (B)期貨信託基金淨資產價值之計算，應由期貨信託事業擬訂期貨信託基金資產價值之計算標準，報經主管機關核定
  3. (C)對不特定人募集期貨信託基金之期貨信託事業，應於每三營業日公告前一營業日期貨信託基金每受益權單位之淨資產價值
  4. (D)期貨信託事業應於每一營業日計算期貨信託基金之淨資產價值
解析

(A)錯誤。期貨信託基金之會計與淨值計算不適用投信投顧公會訂定之原則，主管機關與期貨公會另有規範。

(B)錯誤。淨資產價值之計算標準係由期貨公會擬訂報主管機關核定，若任由各家事業自行擬訂，同類基金的淨值將失去可比性。

(C)錯誤。公告頻率並非每三營業日一次，對不特定人募集者須逐日公告。

(D)正確。期貨信託事業應於每一營業日計算基金之淨資產價值。期貨部位每日結算、槓桿高，淨值一天之內即可能大幅變動，逐日評價才能反映真實資產狀況並支應買回作業。

9. 依「期貨信託基金管理辦法」之規定，有關基金保管機構得依期貨信託事業指示而處分期貨信託基金資產之行為，不包括下列何者？

  2. (B)給付依期貨信託契約約定應由期貨信託基金負擔之款項

(C)錯誤。依契約約定應分配予受益人之可分配收益，屬得依指示給付之項目。

(D)錯誤。給付受益人之買回價金，屬得依指示給付之項目。

10. 依「期貨信託基金管理辦法」之規定，期貨信託基金銷售機構辦理期貨信託基金銷售，下列何者正確？
  1. (A)期貨信託基金銷售機構辦理期貨信託基金銷售業務之人員，不得挪用客戶款項
  2. (B)期貨信託基金受益憑證之交付，得採實券交付
  3. (C)期貨信託基金受益憑證之交付，得委由期貨信託基金銷售機構辦理
  4. (D)期貨信託基金銷售機構辦理期貨信託基金銷售業務之各項憑證之保存方式及期限，僅需依期貨公會規定辦理
解析

(A)正確。銷售人員不得挪用客戶款項。客戶款項自始不屬於銷售機構或其人員，此為受託關係最基本的財產分離要求，違反者不僅是內控瑕疵，更直接侵害受益人財產。

(B)錯誤。受益憑證採無實體發行，以帳簿劃撥交付，不得採實券交付。

(C)錯誤。受益憑證之交付係以帳簿劃撥方式為之，並非委由銷售機構代為交付實體憑證。

(D)錯誤。各項憑證之保存方式及期限應依法令規定辦理，並非僅依期貨公會規定即可。

113年第1次｜期貨信託法規及自律規範｜第 18 題
11. 依「期貨信託基金管理辦法」之規定，期貨信託事業運用對不特定人所募集之期貨信託基金從事經主管機關依期貨交易法第五條公告期貨商得受託從事之期貨交易，應符合之規定，下列何者正確？
  1. (A)持有單一標的商品或金融工具期貨契約、期權契約及選擇權契約未平倉部位所需原始保證金，加計從事同一標的商品或金融工具期權契約與選擇權契約交易所支付與收取權利金淨額之合計數，不得超過本期貨信託基金淨資產價值之百分之二十
  2. (B)持有相同單一期貨契約各其他月份之未平倉部位所需原始保證金，不得超過本期貨信託基金淨資產價值之百分之三
  3. (C)持有期貨契約、期貨選擇權（以下簡稱期權）契約及選擇權契約未平倉部位所需原始保證金，加計從事期權與選擇權契約交易所支付與收取權利金淨額之合計數，不得超過本期貨信託基金淨資產價值之百分之六十
  4. (D)持有單一期貨契約，其最近及次近月份之未平倉部位所需原始保證金，分別不得超過本期貨信託基金淨資產價值之百分之五
解析

(A)正確。持有單一標的商品或金融工具之期貨、期權及選擇權未平倉部位所需原始保證金，加計期權與選擇權權利金收付淨額，合計不得超過基金淨資產價值之百分之二十。此為單一標的的集中度上限，避免基金押注於單一商品。

(B)錯誤。百分之三並非規範對相同單一期貨契約其他月份所定之比率。

(C)錯誤。百分之六十並非規範對全部未平倉部位原始保證金合計數所定之上限，法定比率低於此數。

(D)錯誤。最近及次近月份未平倉部位所需原始保證金之上限，分別為基金淨資產價值之百分之十，非百分之五。

12. 依據「期貨信託基金管理辦法」之規定，於國內募集之期貨信託基金，自期貨信託基金成立屆滿三個月之日起，一般而言其持有第五十條第一項第二款至第五款之總額（即流動資產），訂有不得超過該期貨信託基金淨資產價值之一定比率之規定，但有例外情形，該例外下列何者為真？

  3. (C)募集發行非保本型及組合型期貨信託基金

113年第1次｜期貨信託法規及自律規範｜第 22 題
13. 依「期貨信託基金管理辦法」之規定，期貨信託事業至少應多久一次檢視所經理之所有期貨信託基金之總風險暴露程度、計算風險之方式及最大可能損失？
