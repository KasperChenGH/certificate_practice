  1. (A)研究分析部門

6. 期貨信託事業減資退回股本後，最低實收資本額不低於新台幣?
  1. (A)二億元
  2. (B)三億元
  3. (C)五億元
  4. (D)十億元
解析

(A)錯誤。二億元低於法定門檻。期貨信託事業設置標準第十一條所定最低實收資本額為新臺幣三億元，若准許減資降到兩億，事業承擔操作錯誤與賠償責任的自有財力就低於設立時的要求。

(B)正確。期貨信託事業管理規則第二十四條第二項規定，減資退回股本後資本額不得低於期貨信託事業設置標準第十一條所定最低實收資本額，該金額為新臺幣三億元。資本額是事業吸收操作錯誤、賠償責任與營運成本的自有財力基礎，若能以減資把資本抽到門檻以下，受益人的保障將隨股東退場而削弱，故減資後的底線與設立時完全相同。

(C)錯誤。五億元高於法定門檻，容易與期貨信託基金管理辦法第十五條首次對不特定人募集基金「最低成立金額新臺幣五億元」混淆；那是基金本身的規模門檻，與期貨信託事業的實收資本額是不同層次的要求。

(D)錯誤。十億元並非資本額門檻。期貨信託事業管理規則第二十四條第二項另要求減資後之淨值除主管機關另有規定外不得少於新臺幣九億元，那是對淨值的限制，與實收資本額三億元是兩道不同的檢查，不可混為一談。

9. 下列有關期貨信託事業行使期貨信託基金持有股票之投票表決權之規定，何者為正確?
  1. (A)原則上應由期貨信託事業指派基金經理人為之
  2. (B)應基於事業之最大利益行使
  3. (C)期貨信託事業應將期貨信託基金所持有股票發行公司之股東會通知書及出席證登記管理，並應就出席股東會行使表決權，表決權行使之評估分析作業、決策程序及執行結果作成書面紀錄，循序編號建檔，至少保存三年
  4. (D)選項(A)、(B)、(C)皆非
解析

(A)錯誤。期貨信託事業管理規則第三十四條第一項規定，行使基金持有股票之投票表決權，應由期貨信託事業指派該事業人員代表為之，法規並未限定須為基金經理人；經理人的職責在基金運用，出席股東會的代表人由事業指派即可。

(B)錯誤。同條第二項明定應基於受益人之最大利益行使表決權，並不得直接或間接參與該股票發行公司經營。股票是基金資產、經濟利益歸受益人，若允許事業以自身利益行使，就可能拿受益人的持股去換取商業往來或人事影響力。

(C)錯誤。股東會通知書及出席證登記管理、評估分析作業與決策程序作成書面紀錄並循序編號建檔，這些要求本身正確，錯的是年限：同條第四項要求至少保存五年，不是三年。三年將使事後查核落在紀錄已可銷毀之後。

(D)正確。三項各有錯處：代表人是由事業指派的該事業人員而非限定基金經理人，表決權須基於受益人而非事業之最大利益行使，書面紀錄的保存年限是至少五年而非三年，故皆非正確。核心觀念是表決權為受益人利益而行使，並須留下足以事後查核的完整軌跡。

11. 下列敘述何者錯誤?
  1. (A)期貨信託事業之分支機構經理人、其他業務員或受僱人，應本誠實信用原則執行業務
  2. (B)除法令另有規定外，期貨信託事業之受僱人得代理客戶從事期貨交易或期貨相關現貨商品買賣
  3. (C)非業務員之其他從業人員不得執行業務員職務
  4. (D)非業務員之其他從業人員不得執行代理業務員職務
解析

(A)錯誤（此項敘述無誤）。期貨信託事業管理規則第五十四條第一項明定負責人、部門主管、分支機構經理人、其他業務員或受僱人，應以善良管理人之注意義務及忠實義務，本誠實信用原則執行業務，本項與條文相符。

43. 期貨信託事業運用所募集之期貨信託基金從事經主管機關核准非在期貨交易所進行之衍生性商品，其交易總風險暴露，除主管機關核准外，不得超過本期貨信託基金淨資產價值之比例為多少?
  1. (A)百分之五
  2. (B)百分之十
  3. (C)百分之十五
  4. (D)百分之二十
解析

(A)錯誤。百分之五是第三十九條第一項第二款對相同單一期貨契約其他月份未平倉部位原始保證金所設的限制，不是場外衍生性商品總風險暴露的上限。

(B)正確。期貨信託基金管理辦法第四十條第一項規定，從事第三十八條第一項第二款（經核准非在期貨交易所進行）之交易，其交易總風險暴露除主管機關核准外，不得超過本基金淨資產價值之百分之十；同條第二項並以交易所生最大可能損失為衡量標準，且不含為規避未來交割匯率風險而承作的外匯期貨交易。場外交易沒有集中結算機構承擔履約責任，交易對手信用風險由基金自負，故額度訂得比交易所交易嚴格。

44. 期貨信託基金受益憑證買回價格之計算，應以受益人買回請求到達後之第幾個營業日為基準：
  1. (A)到達當日
  2. (B)到達次一營業日
  3. (C)到達次二營業日
  4. (D)到達次三營業日
解析

(A)錯誤。以請求到達當日計算，申請人將在已看到當日行情走向後才決定是否贖回；且當日淨值須待收盤結算後才能確定，受理當日實務上也算不出價格。

(B)正確。期貨信託基金管理辦法第七十四條第二項規定，受益憑證之買回價格，以買回請求到達期貨信託事業或其銷售機構之次一營業日的基金淨資產價值核算之。基金雖依第七十六條逐日計算淨值，但當日淨值要到收盤結算後才確定；若以到達日計價，等於讓贖回者在已知行情下擇時，把損失轉嫁給留下的受益人，改以次一營業日則價格對申請人而言是未知的。

(C)錯誤。次二營業日會讓申請人多承擔一個營業日的市場風險，卻不增加任何價格公平性；淨值在次一營業日即已客觀確定。同辦法只在給付價金的起算日對店頭交易改採次二營業日，那是給付時程而非計價基準。

(D)錯誤。次三營業日與買回價金應自次一營業日起五個營業日內給付的時程不相容：計價日一再延後，受益人的資金將長期處於價格未定狀態，也使買回申請與實際成交的行情落差過大。
