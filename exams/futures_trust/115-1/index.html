2. 關於期貨信託事業開業、變更董事、監察人或經理人，因業務上關係發生訴訟等事項之申報，下列何者正確？

  3. (C)應函送中華民國證券暨期貨市場發展基金會彙報金管會
  4. (D)應逕行函送金管會

(B)正確。期貨信託事業開業、變更董事、監察人或經理人，以及因業務上關係發生訴訟等事項，應函送中華民國期貨業商業同業公會彙報金管會。經公會彙轉可使自律機構與主管機關同步掌握會員的人事與訟爭狀況，申報格式也得以統一，公會後續的自律查核才有依據。

(C)錯誤。財團法人中華民國證券暨期貨市場發展基金會辦理專業測驗、教育宣導與研究出版，並非期貨業的自律機構，沒有會員管理與彙報職能。

(D)錯誤。規定採公會彙報的架構，逕行函送金管會會使公會無從掌握會員異動，與自律機構先行受理、再彙轉主管機關的設計不符。

5. 有關期貨信託事業及其委任之基金銷售機構之宣傳資料及廣告物，其形式、內容、製作、傳播及申報等管理規範之訂定，下列敘述何者正確？
  1. (A)由期貨公會訂定，毋須報請主管機關
  2. (B)由主管機關訂定
  3. (C)由期貨信託事業擬訂管理規範，申報主管機關備查
  4. (D)由期貨公會擬訂管理規範，申報主管機關備查
解析

(A)錯誤。自律規範不能停在公會內部：宣傳資料及廣告物的管理規範由公會擬訂後，仍須申報主管機關備查，主管機關才保有最後的審查與糾正空間。

(B)錯誤。該管理規範不是由主管機關逕行訂定；廣告用語與媒體形式變動快，交由最貼近市場的公會擬訂較能因應，主管機關則以備查的方式把關。

(C)錯誤。若由各期貨信託事業各自擬訂，同一市場會出現寬嚴不一的廣告標準，投資人難以比較，公會也失去查核會員廣告的共同依據。

(D)正確。期貨信託事業及其委任之基金銷售機構的宣傳資料與廣告物，其形式、內容、製作、傳播及申報等管理規範，由中華民國期貨業商業同業公會擬訂後申報主管機關備查。這種自律先行、主管機關備查的架構，既保留業界隨市場調整的彈性，又維持監理的最終把關，會員違反時並得由公會依自律規範處置。

8. 依「期貨信託基金管理辦法」之規定，期貨信託事業委任之期貨信託基金銷售機構從事期貨信託基金之廣告、公開說明會及其他促銷活動違反規定時，應由何者負責？
  1. (A)基金保管機構
  2. (B)銷售機構的業務員
  3. (C)期貨信託事業的負責人
  4. (D)期貨信託事業及該基金銷售機構
解析

(A)錯誤。基金保管機構的職責是保管基金資產、辦理帳務與淨值計算並監督經理事業的運用，它不參與基金的銷售與促銷，自不因銷售機構的廣告違規而負責。

(B)錯誤。責任不僅止於承辦的業務員；若機構能以個人行為為由脫身，等於放棄對廣告文稿與公開說明會內容的內部控制，規範要求的正是機構層級的管理責任。

(C)錯誤。這不是負責人個人的違規責任問題；規範課責的對象是期貨信託事業與該基金銷售機構這兩個法人，負責人的責任另依相關規定認定。

(D)正確。委任之期貨信託基金銷售機構從事基金之廣告、公開說明會及其他促銷活動違反規定時，期貨信託事業與該基金銷售機構均應負責。委任人不因把銷售委外而免除責任，這樣的雙重課責才能迫使期信事業在遴選通路、審核廣告文稿與教育訓練上確實把關。

9. 依「期貨信託基金管理辦法」之規定，期貨信託事業對不特定人募集期貨信託基金從事於外國期貨基金之投資時，該外國期貨基金投資於臺灣地區期貨與證券市場之比率不得超過其淨資產價值之百分之多少？

  2. (B)五十
  3. (C)六十
  4. (D)七十

(A)錯誤。百分之四十是期貨信託基金持有有價證券總市值須申請兼營證券投資信託事業的界線（第四十二條所指主管機關訂定之比率），不是外國期貨基金回頭投資臺灣市場的上限。

12. 期貨信託事業募集期貨信託基金，如該期貨信託基金為以外幣計價之期貨信託基金，除經主管機關核准者外，應經何機關或單位同意？

  2. (B)中央銀行
  3. (C)經濟部
  4. (D)國發會
