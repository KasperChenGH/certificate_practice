  2. (B)期貨信託事業之業務員於從事期貨信託業務之行為，視為該事業授權範圍內之行為

2. 證券投資信託事業申請兼營期貨信託事業，應具備之條件有哪些？

解析

5. 期貨信託事業應充分了解其客戶，下列敘述何者錯誤？

7. 依期貨信託事業管理規則之規定，期貨信託事業從事下列業務之人員，何者須登錄為期貨信託事業之業務員？(甲).辦理受益憑證之募集發行及銷售；(乙).法令遵循；(丙).期貨交易之投資分析
  1. (A)僅甲、乙
  2. (B)僅乙、丙

  4. (D)甲、乙、丙

9. 所列期貨信託基金公開說明書應揭露期貨信託契約所訂期貨信託事業之權利、義務與責任部分，何者為真？
  1. (A)期貨信託基金損失超過基金淨資產時，超額損失部分應由受益人負擔
  2. (B)期貨信託基金受益人之責任不限於申購時所支付之申購價款
  3. (C)期貨信託基金損失超過基金淨資產時，超額損失部分應由期貨信託事業負擔
  4. (D)期貨信託基金之損失可能超過基金淨資產，超額損失部分應由期貨信託事業與受益人約定負擔方式
解析

(A)錯誤。受益人責任以其申購價款為限，不負擔超額損失。

(B)錯誤。受益人之責任限於申購時所支付之申購價款，此為受益憑證有限責任之本質。

(C)正確。基金損失超過淨資產時，超額損失部分由期貨信託事業負擔。期貨具槓桿性，理論上虧損可超過本金，若讓受益人負無限責任，基金將無從銷售，故由具專業與資本之事業承擔尾端風險。

(D)錯誤。超額損失之歸屬為強制規定，不得由雙方約定分擔方式。

(A)錯誤。此為正確敘述：保管機構依期貨信託事業之指示處分運用基金資產，本身不作投資決策。

(B)錯誤。此為正確敘述：應按基金帳戶別獨立設帳保管，使各基金資產彼此分離。

(C)正確（即敘述有誤者）。基金保管機構須具備法定資格條件，且與期貨信託事業間不得有法定之利害關係，並非事業得自由選定。若保管機構與經理事業關係過近，資產保管與投資決策分離的防弊設計即失去意義。

(D)錯誤。此為正確敘述：基金資產獨立於保管機構自有財產，其債權人不得對基金資產聲請扣押。

114年第3次｜期貨信託法規及自律規範｜第 47 題
40. 依「期貨信託基金管理辦法」之規定，期貨信託事業應依期貨信託契約運用對符合一定資格條件之人募集之期貨信託基金，下列何者正確？
  1. (A)得為放款
  2. (B)得投資於本期貨信託事業或與本期貨信託事業有利害關係之公司所發行基金受益憑證、基金股份及投資單位以外之證券
  3. (C)得運用期貨信託基金買入本期貨信託基金之受益憑證
  4. (D)不得交付或出售期貨信託基金所購入股票發行公司股東會之委託書
解析

(A)錯誤。基金不得為放款，放款屬授信業務且與基金投資目的不符。

(B)錯誤。對本事業或與其有利害關係之公司所發行之證券，原則禁止投資，以避免利益衝突與資金回流。

(C)錯誤。不得以基金資產買入本基金之受益憑證，否則將形成自我持有並影響淨值計算。

(D)正確。不得交付或出售基金所購入股票發行公司股東會之委託書。基金持股所生之表決權應為受益人利益行使，委託書若可交付或出售，即等同以受益人資產換取事業自身利益。

41. 有關期貨信託基金配售之規定，下列何者敘述有誤？
  1. (A)客戶申購總組數超過可分配之組數時即須啟動公平配售機制，包括期貨信託事業於特殊情形自行控管額度致發生超額申購之情形
  2. (B)受託申購客戶超額認購如採抽籤之配售方式，則應由基金保管機構派員監督，並得邀請基金法律顧問、基金簽證會計師或期貨公會派員監督
  3. (C)配售作業流程及相關配售資訊應於每次啟動前於公司官網及公開資訊觀測站公告
  4. (D)期貨信託事業應將辦理配售作業之完整流程紀錄及相關資料保存二年備查

(C)錯誤。此為正確敘述：配售作業流程及相關資訊應於每次啟動前公告。

  1. (A)立即督促其改善，並通知主管機關
