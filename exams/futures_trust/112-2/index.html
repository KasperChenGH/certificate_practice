  1. (A)發行新股保留由員工承購
  2. (B)發行新股分配員工紅利
  3. (C)符合主管機關所定一定條件
  4. (D)購入庫藏股票
解析

(A)錯誤。發行新股保留由員工承購會稀釋專業股東持股，屬所定之特定條件。

(B)錯誤。發行新股分配員工紅利同屬稀釋持股之情形，列為特定條件。

(C)錯誤。符合主管機關所定一定條件者，亦屬得排除適用之情形。

(D)正確（即不包括者）。購入庫藏股票係公司買回自己已發行之股份，並非因發行新股而使專業股東持股遭稀釋，故不在得排除百分之二十持股要求的特定條件之內。

2. 下列何者得擔任期貨信託事業之專業發起人？
  1. (A)基金管理機構
  2. (B)證券商
  3. (C)保險公司
  4. (D)選項(A)(B)(C)皆可
解析

(A)錯誤。基金管理機構確實是期貨信託事業設置標準第十二條所列的專業發起人之一（須成立滿三年、具國際期貨基金管理經驗且管理資產達一定規模），但它不是唯一一類；只選它會漏掉銀行、保險公司、證券商、期貨商與金融控股公司。

(B)錯誤。證券商若成立滿三年、近三年未受重大處分且淨值或實收資本額達一定金額，同樣得列為專業發起人。本題問的是得擔任的範圍，單挑證券商並不完整。

(C)錯誤。保險公司符合成立滿三年、資金運用總額達一定規模且每股淨值不低於面額者，亦得擔任專業發起人；三個選項各自都站得住，故不能只取其中一個。

(D)正確。期貨信託事業設置標準第十二條規定，發起人中應有符合所定資格條件之基金管理機構、銀行、保險公司、證券商、期貨商或金融控股公司，其所認股份合計不得少於第一次發行股份之百分之二十。要求專業發起人實際入股並持有相當比例，是讓具備資產管理或金融業經驗與資本實力的股東在事業內部承擔成敗，而不是由不具專業的資金設立期信事業後再對外招攬。

3. 依「期貨信託事業管理規則」之規定，下列何者正確？
  1. (A)期貨信託事業不得擔任股票之發行公司之董事
  2. (B)期貨信託事業不得擔任期貨信託基金所持有股票之發行公司之董事
  3. (C)期貨信託事業報經主管機關核准後，得擔任期貨信託基金所持有股票之發行公司之董事
  4. (D)期貨信託事業得擔任期貨信託基金所持有股票之發行公司之董事，但應向主管機關申報並公告
解析

(A)錯誤。禁止的範圍不是所有股票發行公司的董事席位，而限於其所經理期貨信託基金「所持有」股票之發行公司；對基金未持股的公司，並無這一律禁止，本項把限制擴張得過寬。

(B)正確。期貨信託事業不得擔任其所經理之期貨信託基金所持有股票之發行公司的董事。基金持股所附的表決權是為受益人利益而行使，若事業本身進入該公司董事會，便同時站在資產管理人與被投資公司經營者兩端，可能取得內部消息，或為維護董事職位而遲延賣出持股，故以身分禁止直接切斷利益衝突。

(C)錯誤。這是絕對禁止，不是報經主管機關核准即可解除的相對限制。利益衝突來自身分重疊本身，核准並不能消除事業一面決定基金是否繼續持有該股票、一面在該公司董事會任職的矛盾。

(D)錯誤。申報並公告只是事後的資訊揭露，無法排除上述衝突；受益人縱然知情也無從阻止，故規範採事前的身分禁止，而非以揭露作為替代手段。

4. 關於期貨信託事業應向主管機關申報之事項，下列何者錯誤？
  1. (A)期貨信託事業開業，公司應於開業起五個營業日內申報
  2. (B)期貨信託事業因業務上關係發生訴訟、非訟事件，或為破產人或強制執行之債務人，應於知悉或事實發生之日起五個營業日內申報
  3. (C)期貨信託事業董事、監察人、經理人或持有已發行股份總數百分之五以上之股東持股變動者，應於次月五日前向公司申報，公司應於同月十五日前彙總申報
  4. (D)期貨信託事業申報事項應函送中華民國期貨業商業同業公會彙報金管會
解析

(A)正確（即敘述有誤者）。開業之申報時點並非「開業起五個營業日內」。開業屬事業本身可預先掌握的計畫性事項，其申報時點與訴訟、破產等偶發事項的事後申報不同，正是本題要區辨之處。

(B)錯誤。訴訟、非訟事件或成為破產人、強制執行債務人，於知悉或事實發生之日起五個營業日內申報，敘述正確。

(C)錯誤。董監事、經理人及持股百分之五以上股東之持股變動採次月五日前申報、同月十五日前彙總申報，敘述正確。

(D)錯誤。申報事項函送期貨公會彙報金管會，是既定之申報路徑，敘述正確。

5. 專營期貨信託事業應設置哪些部門？甲、研究分析部門；乙、財務會計部門；丙、內部稽核部門；丁、業務推廣部門
  1. (A)甲、乙、丙
  2. (B)乙、丙、丁
  3. (C)甲、丙、丁
  4. (D)甲、乙、丁
解析

(A)正確。專營期貨信託事業應設置研究分析、財務會計及內部稽核部門。研究分析部門提供期貨交易與投資標的的分析，是基金運用決策的依據；財務會計部門處理帳務與財務報告編製；內部稽核部門則獨立查核各項業務是否遵循內部控制制度並直接對董事會負責。三者分別對應決策品質、帳務真實與遵循查核，是受託管理他人資產最基本的組織要求。

(B)錯誤。業務推廣（丁）並非法定應設置的部門，事業得依營運需要自行編制；本組合又漏掉研究分析部門，而基金運用若缺乏獨立的研究分析支撐，等於讓經理人憑個人判斷操作受益人的資金。

(C)錯誤。財務會計部門是法定應設置部門，本組合卻把它換成業務推廣。基金的帳務處理、淨值計算與財務報告編製須有專責單位，否則財報揭露與淨值公告都失去內部把關。

(D)錯誤。本組合遺漏內部稽核部門。內部稽核必須獨立於業務單位、直接向董事會負責，是內部控制制度能否落實的檢查機制，不能以負責招攬的業務推廣部門取代。

6. 有關期貨信託基金之宣傳資料及廣告物的管理，下列何者有誤？
  1. (A)宣傳資料、廣告物及相關紀錄應保存二年
  2. (B)期貨信託事業對符合一定資格條件之人募集期貨信託基金，於開始募集之後，才能為一般性廣告或公開勸誘之行為
  3. (C)宣傳資料及廣告物，其形式等相關事項，由期貨公會擬訂管理規範

(C)錯誤。宣傳資料及廣告物之形式等相關事項由期貨公會擬訂管理規範，敘述正確。

(D)錯誤。主管機關或其指定機構得隨時抽查宣傳資料、廣告物及相關紀錄，敘述正確。

7. 依「期貨信託基金管理辦法」之規定，當非屬指數股票型期貨信託基金最近三個營業日之平均單位淨資產價值較基金最初單位淨資產價值累積跌幅達百分之多少時，應通報主管機關？
  1. (A)二十
  2. (B)三十
  3. (C)四十
  4. (D)五十
解析

(A)錯誤。百分之二十的跌幅對操作期貨、槓桿較高的基金而言仍屬常見波動，若以兩成為通報門檻，日常市況即會頻繁觸發，通報反而失去警示作用；第三十七條第五項所定的門檻是四成。

(B)錯誤。百分之三十在本辦法中另有用處（例如第四十一條第二項組合型期貨信託基金對每檔子基金支付總額不得超過淨值百分之三十），但不是非指數股票型基金單位淨值累積跌幅的通報門檻。

(C)正確。期貨信託基金管理辦法第三十七條第五項規定，非屬指數股票型之期貨信託基金，最近三個營業日平均單位淨資產價值較最初單位淨資產價值累積跌幅達百分之四十時，應立即通報主管機關及同業公會，事業並應即擬具改善計畫提報董事會。取三個營業日平均而非單日數字，是為濾掉單日極端行情；門檻設在四成，則讓主管機關在基金嚴重減損、可能面臨大量買回或終止之前就能掌握並介入。

(D)錯誤。等到淨值腰斬（百分之五十）才通報已失時機，受益人的損失多半難以回復；辦法把通報點提前到累積跌幅四成，正是為了留下擬具改善計畫與對受益人溝通的時間。

9. 專營期貨信託事業對不特定人募集期貨信託基金，自成立後滿多少時間，受益人始得申請買回？
  1. (A)一個月
  2. (B)四十五日
  3. (C)九個月
  4. (D)一年
解析

(A)錯誤。一個月不是第十五條所定的閉鎖期間。這個數字容易與同條第一項「期貨信託事業經核發許可證照後應於一個月內申請募集期貨信託基金」混淆，兩者規範的對象與階段完全不同。

(B)正確。期貨信託基金管理辦法第十五條第二項第三款規定，期貨信託事業首次申請對不特定人募集之基金，自成立日後滿四十五日，受益人始得申請買回。首檔基金是事業建立操作紀律與交易流程的起點，給一段不受買回干擾的期間，可避免基金剛成立即因大量買回而被迫平倉、連帶損及其餘受益人；四十五日也與同條第三項首檔基金須於四十五日內募集成立的期間相互呼應。

(C)錯誤。九個月的閉鎖期會使受益人長期無法退出，與期貨信託基金須逐日計算淨值、原則上開放買回的性質不符；第十五條第二項第三款所定的期間是四十五日。

(D)錯誤。一年的鎖定期是封閉型或私募商品常見的安排，不是首檔公開募集期貨信託基金的法定閉鎖期；把四十五日記成一年，會大幅高估受益人資金被鎖住的時間。

10. 依「期貨信託基金管理辦法」之規定，有關期貨信託事業於國外募集期貨信託基金從事國外期貨交易及投資國外有價證券之種類及範圍，依下列何者之規定辦理？
  1. (A)募集地之法令規定
  2. (B)我國主管機關之法令規定
  3. (C)我國期貨公會之自律規範
  4. (D)我國期貨交易所之相關規定
解析

(A)正確。期貨信託基金管理辦法第五條第四項規定，期貨信託事業於國外募集期貨信託基金從事國外期貨交易與投資期貨相關現貨商品之種類及範圍，悉依募集地法令規定辦理。資金來自當地投資人、受益憑證也在當地銷售，投資人保護自應交由募集地的監理機關與法令處理；我國法規若再疊加一套投資範圍限制，將形成雙重管制並使該基金在當地市場失去競爭力。

(B)正確。依中華民國期貨業商業同業公會期貨信託基金宣傳資料及廣告管理辦法第十條，以基金定時定額投資績效為廣告者，該基金至少須成立滿一年以上。定時定額訴求的是分批進場攤平成本，其效果必須經過一段完整的漲跌起伏才看得出來；要求滿一年，可避免事業挑選剛好順風的短期區間，把運氣包裝成策略效果。

(D)錯誤。二年是更嚴的標準，但不是第十條所定門檻；誤記為二年，會把已成立滿一年、依規定得揭露定時定額績效的基金誤認為不得作此廣告。
