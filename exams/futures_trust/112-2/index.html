1. 期貨信託事業應有一名以上符合期貨信託事業設置標準所定資格條件之專業股東，除特定條件外，其合計持有股份原則上不得少於已發行股份總數之百分之二十，所稱之特定條件，不包括下列何者？
  1. (A)發行新股保留由員工承購
  2. (B)發行新股分配員工紅利
  3. (C)符合主管機關所定一定條件
  4. (D)購入庫藏股票
解析

(A)錯誤。發行新股保留由員工承購會稀釋專業股東持股，屬所定之特定條件。

(B)錯誤。發行新股分配員工紅利同屬稀釋持股之情形，列為特定條件。

(C)錯誤。符合主管機關所定一定條件者，亦屬得排除適用之情形。

(D)正確（即不包括者）。購入庫藏股票係公司買回自己已發行之股份，並非因發行新股而使專業股東持股遭稀釋，故不在得排除百分之二十持股要求的特定條件之內。

2. 下列何者得擔任期貨信託事業之專業發起人？
  1. (A)基金管理機構
  2. (B)證券商
  3. (C)保險公司
  4. (D)選項(A)(B)(C)皆可
解析

(A)錯誤。基金管理機構固得擔任專業發起人，但並非唯一符合資格者。

(B)錯誤。證券商得擔任專業發起人，惟本選項未涵蓋全部符合資格者。

(C)錯誤。保險公司得擔任專業發起人，惟本選項未涵蓋全部符合資格者。

(D)正確。基金管理機構、證券商與保險公司均得擔任期貨信託事業之專業發起人。三者的共同點在於本身即具備資產管理或金融專業，並有相當的財務規模，足以支撐期貨信託事業的營運與風險承擔。

3. 依「期貨信託事業管理規則」之規定，下列何者正確？
  1. (A)期貨信託事業不得擔任股票之發行公司之董事
  2. (B)期貨信託事業不得擔任期貨信託基金所持有股票之發行公司之董事
  3. (C)期貨信託事業報經主管機關核准後，得擔任期貨信託基金所持有股票之發行公司之董事
  4. (D)期貨信託事業得擔任期貨信託基金所持有股票之發行公司之董事，但應向主管機關申報並公告
解析

(A)錯誤。禁止範圍限於基金所持有股票之發行公司，並非一切股票發行公司。

(B)正確。期貨信託事業不得擔任期貨信託基金所持有股票之發行公司之董事。基金持股是為受益人理財，不是取得經營權的工具；若事業出任董事，將同時是投資人與被投資公司的經營者，形成無法迴避的利益衝突。

(C)錯誤。此為絕對禁止事項，不因報經主管機關核准而得為之。

(D)錯誤。並非申報並公告即可擔任，法規係直接禁止。

4. 關於期貨信託事業應向主管機關申報之事項，下列何者錯誤？
  1. (A)期貨信託事業開業，公司應於開業起五個營業日內申報
  2. (B)期貨信託事業因業務上關係發生訴訟、非訟事件，或為破產人或強制執行之債務人，應於知悉或事實發生之日起五個營業日內申報
  3. (C)期貨信託事業董事、監察人、經理人或持有已發行股份總數百分之五以上之股東持股變動者，應於次月五日前向公司申報，公司應於同月十五日前彙總申報
  4. (D)期貨信託事業申報事項應函送中華民國期貨業商業同業公會彙報金管會
解析

(A)正確（即敘述有誤者）。開業之申報時點並非「開業起五個營業日內」。開業屬事業本身可預先掌握的計畫性事項，其申報時點與訴訟、破產等偶發事項的事後申報不同，正是本題要區辨之處。

(B)錯誤。訴訟、非訟事件或成為破產人、強制執行債務人，於知悉或事實發生之日起五個營業日內申報，敘述正確。

(C)錯誤。董監事、經理人及持股百分之五以上股東之持股變動採次月五日前申報、同月十五日前彙總申報，敘述正確。

(D)錯誤。申報事項函送期貨公會彙報金管會，是既定之申報路徑，敘述正確。

6. 有關期貨信託基金之宣傳資料及廣告物的管理，下列何者有誤？
  1. (A)宣傳資料、廣告物及相關紀錄應保存二年
  2. (B)期貨信託事業對符合一定資格條件之人募集期貨信託基金，於開始募集之後，才能為一般性廣告或公開勸誘之行為
  3. (C)宣傳資料及廣告物，其形式等相關事項，由期貨公會擬訂管理規範
  4. (D)主管機關或其指定機構得隨時抽查期貨信託事業之宣傳資料、廣告物及相關紀錄
解析

(A)錯誤。宣傳資料、廣告物及相關紀錄應保存二年，敘述正確，非本題所選。

(C)錯誤。宣傳資料及廣告物之形式等相關事項由期貨公會擬訂管理規範，敘述正確。

(D)錯誤。主管機關或其指定機構得隨時抽查宣傳資料、廣告物及相關紀錄，敘述正確。
