1. 期貨信託事業之業務員從事之業務，包括：甲.辦理受益憑證之募集發行及銷售；乙.期貨交易及相關投資之研究分析；丙.執行基金之交易及投資；丁.基金之經營管理；戊.內部稽核；己.主辦會計。下列有關上開業務員不得相互兼任之規定何者為真?
  1. (A)甲、乙不得相互兼任
  2. (B)乙、丙不得相互兼任
  3. (C)乙、丁不得相互兼任
  4. (D)選項(A)(B)(C)皆非
解析

(A)錯誤。辦理受益憑證之募集發行及銷售（甲）與期貨交易及相關投資之研究分析（乙）分屬通路招攬與研究工作，規範並未將這兩項列為不得相互兼任；真正必須分離的是研究分析與執行交易。

(B)正確。期貨交易及相關投資之研究分析（乙）與執行基金之交易及投資（丙）不得相互兼任。研究分析產生買賣建議，執行交易則實際下單；若由同一人兼任，該人可先行布局再以研究意見推動基金進場，事後也無人能獨立檢核下單是否確實依循研究結論。把兩者分開，形成建議與執行相互勾稽的制衡，這正是內部控制中職能區隔的核心。

(C)錯誤。期貨交易及相關投資之研究分析（乙）與基金之經營管理（丁）之間並無不得相互兼任的規定；基金經理人本於研究結論作投資決策正是其職務內容，被禁止的是研究分析與實際執行交易的兼任。

(D)錯誤。確有不得相互兼任的組合，即乙與丙。認為三組皆非，等於否認研究分析與執行交易必須分離這項基本的職能區隔要求，而該要求正是防止人員藉研究意見掩護自身交易的關鍵。

  1. (A)期貨業商業同業公會之「期信基金資訊觀測站」

4. 期貨信託事業減資退回股本後，最低實收資本額不低於?
  1. (A)二億元
  2. (B)三億元
  3. (C)五億元
  4. (D)十億元
解析

(A)錯誤。二億元低於法定門檻。期貨信託事業設置標準第十一條所定的最低實收資本額為新臺幣三億元，減資退回股本後仍不得低於此數，否則等於藉減資規避資本門檻。

(B)正確。期貨信託事業設置標準第十一條規定最低實收資本額為新臺幣三億元，事業辦理減資退回股本後，實收資本額仍不得低於三億元。資本額是事業承擔操作錯誤、賠償責任與營運成本的自有財力基礎；若准許以減資把資本降到門檻以下，受益人的保障將隨股東抽回資金而削弱，故減資後的底線與設立時相同。

(C)錯誤。五億元是期貨信託事業首次對不特定人募集基金的最低成立金額（期貨信託基金管理辦法第十五條第二項第二款），衡量的是基金規模，不是事業自身的實收資本額下限。

(D)錯誤。十億元遠高於設置標準第十一條的三億元門檻；把資本門檻誤記為十億元，會讓多數合法設立的專營期貨信託事業被誤判為資本不足而不得減資。

10. 有關下列機構擔任期貨信託基金清算人之先後順序，何者正確?
  1. (A)期貨信託事業、基金保管機構、受益人會議選任符合規定之其他期貨信託事業或基金保管機構
  2. (B)期貨信託事業、受益人會議選任符合規定之其他期貨信託事業或基金保管機構
  3. (C)基金保管機構、期貨信託事業、受益人會議選任符合規定之其他期貨信託事業或基金保管機構
  4. (D)受益人會議選任符合規定之其他期貨信託事業或基金保管機構、期貨信託事業
解析

(A)正確。期貨信託基金管理辦法第八十五條第一項規定，清算人由期貨信託事業擔任；期貨信託事業有解散、破產、撤銷或廢止核准等情事時，應由基金保管機構擔任；基金保管機構亦有同樣情事時，才由受益人會議決議選任符合主管機關規定之其他期貨信託事業或基金保管機構。順序依最熟悉基金部位者優先排列：經理事業最清楚未平倉部位與交易對手，其次是保管全部資產、掌握帳務的保管機構，最後才由受益人自行另覓適格機構。

(B)錯誤。本選項跳過基金保管機構。保管機構本就持有基金全部資產並掌握帳務，是期貨信託事業無法擔任時最自然的接手者；直接跳到受益人會議選任，會在清算最需要即時平倉的時點出現空窗。

(C)錯誤。順序顛倒。第八十五條第一項以期貨信託事業為原則上的清算人，基金保管機構是在期信事業有解散、破產或核准被撤銷廢止等情事時才接手，並非一開始即由保管機構擔任。

(D)錯誤。受益人會議選任並非第一順位，而是期貨信託事業與基金保管機構都無法擔任時的最後手段。召開受益人會議費時，若列為首選，基金部位在清算期間將長時間無人管理。

11. 關於期貨信託事業募集期貨信託基金所提供風險預告書之敘述，何者正確？甲.期貨信託事業應向申購人告知該基金之性質與可能風險；乙.風險預告書由申購人簽名並加註日期；丙.風險預告書一份由期貨信託事業留存，一份交付申購人存執
  1. (A)僅甲、乙
  2. (B)僅乙、丙
  3. (C)僅甲、丙
  4. (D)甲、乙、丙
解析

(A)錯誤。丙亦為正確敘述，僅列甲、乙並不完整。

(B)錯誤。甲亦為正確敘述，僅列乙、丙並不完整。

(A)正確。除募集發行保本型期貨信託基金者外，對不特定人募集之每一基金，依期貨信託基金管理辦法第五十條第一項第二款至第五款方式（存放於銀行、向票券商買入短期票券、債券附買回交易及其他經主管機關規定之方式）所保持之資產，應至少達該基金淨資產價值之百分之三十。期貨部位只需少量保證金即可建立，其餘資金必須停泊在流動性高、交易對手符合主管機關條件的工具上，才能隨時支應保證金追繳與買回價金。

(B)錯誤。百分之二十不足以承受期貨基金的資金需求：保證金追繳與大量買回可能同時發生，流動性資產只有兩成時，事業將被迫在不利價格下平倉變現，損及全體受益人。

(C)錯誤。百分之十是第四十條第一項場外衍生性商品交易總風險暴露的上限等處所用的比率，性質是曝險的天花板；把它當作流動資產的下限，正是把「不得超過」誤讀成「至少須達」。

(D)錯誤。百分之五是第三十九條第一項第二款相同單一期貨契約其他月份未平倉部位原始保證金的上限，與流動資產的最低比率無關；若流動性資產僅占淨值百分之五，一次保證金追繳就可能耗盡，基金將被迫平倉求現。

112年第1次｜期貨信託法規及自律規範｜第 47 題
47. 依據期貨公會自律規範，下列何者應負期貨信託基金風險管理之最終責任?
  1. (A)期貨信託事業之董事長
  2. (B)期貨信託事業之董事會
  3. (C)期貨信託事業之總經理
  4. (D)期貨信託事業之風險管理委員會
解析

(A)錯誤。董事長對外代表公司並主持董事會，但風險管理的最終責任屬於作為集體決策機關的董事會，而非董事長個人；否則風險政策的核定與定期檢視將取決於一人判斷。

(B)正確。期貨信託基金風險管理的最終責任由期貨信託事業的董事會承擔。這與期貨信託基金管理辦法第三十七條的架構一致：風險監控管理措施須訂於董事會通過之內部控制制度中，董事會並至少每季檢視所經理各基金及委外運用部分的總風險暴露程度、計算風險的方式與最大可能損失。把最終責任放在董事會，是因為風險胃納的設定牽動受益人利益與事業存續，必須由對股東與受益人負責的集體決策機關拍板，並留下可追究的會議紀錄。

(C)錯誤。總經理負責日常業務的執行與內部控制的落實，是風險管理制度的執行者；制度的核定與總風險暴露的定期檢視屬董事會職責，執行層無從承擔最終責任。

(D)錯誤。風險管理委員會若有設置，是提供專業評估與建議的功能性組織，其結論仍須提報董事會決定；把最終責任推給委員會，會讓董事會藉專業分工卸責。

48. 依期貨公會「期貨信託基金宣傳資料及廣告管理辦法」，期貨信託事業及委任之基金銷售機構從事期貨信託基金之廣告及製發宣傳文件時，應遵守事項，下列何者為非?
