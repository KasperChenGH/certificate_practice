  2. (B)未成年子女
  3. (C)已成年子女
  4. (D)利用他人名義持有者
解析

(A)錯誤。配偶持股應併入計算，以防藉家庭成員名義分散持股規避限制。

(D)錯誤。利用他人名義持有者屬人頭持股，本即應併入計算，否則規定形同虛設。

2. 對保本型期貨信託基金之敘述，何者有誤?
  1. (A)投資保本型期貨信託基金絕無風險
  2. (B)投資人須持有基金至到期日方可享有本金保證
  3. (C)保本型期貨信託基金應於公開說明書中加強敘明保本比率
  4. (D)保本型期貨信託基金之類型可分為保證型或保護型
解析

(A)正確（即敘述有誤者）。保本型基金只在符合約定條件下保障本金，仍存在保證機構之信用風險、提前贖回不保本及通膨侵蝕等風險。任何投資商品都不能宣稱毫無風險，這也正是廣告用語禁止絕對化表述的原因。

(B)錯誤。須持有至到期日始享有本金保證，敘述正確。

(C)錯誤。公開說明書應加強敘明保本比率，敘述正確。

(D)錯誤。保本型基金可分為保證型與保護型兩類，敘述正確。

3. 下列何者非期貨信託事業對不特定人為營業促銷活動時之禁止行為?

5. 下列何者情況不需經期貨信託基金受益人會議決議?
  1. (A)更換基金保管機構
  2. (B)更換全權委託專業機構
  3. (C)更換期貨信託事業
  4. (D)重大變更期貨信託基金從事期貨交易及投資期貨相關現貨商品之基本方針及範圍
解析

(A)錯誤。更換基金保管機構涉及信託架構中當事人之變動，須經受益人會議決議。

  3. (C)保護型期貨信託基金

(C)錯誤。保護型基金無保證機構保證，係以投資策略（如債券部位配置）追求到期保本，並非由他人提供保證。

(D)錯誤。傘型基金指一母基金下設數檔子基金之架構，與保本無關。
