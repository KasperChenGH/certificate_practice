1. 下列有關期貨信託事業行使期貨信託基金持有股票之投票表決權之規定，何者為正確?
  1. (A)原則上應由期貨信託事業指派基金經理人為之
  2. (B)應基於事業之最大利益行使
  3. (C)期貨信託事業應將期貨信託基金所持有股票發行公司之股東會通知書及出席證登記管理，並應就出席股東會行使表決權，表決權行使之評估分析作業、決策程序及執行結果作成書面紀錄，循序編號建檔，至少保存三年
  4. (D)選項(A)、(B)、(C)皆非
解析

(A)錯誤。期貨信託事業管理規則第三十四條第一項規定，行使基金持有股票之投票表決權，應由期貨信託事業指派該事業人員代表為之，法規並未限定須為基金經理人；經理人的職責在基金運用，出席股東會的代表人由事業指派即可。

(B)錯誤。同條第二項明定應基於受益人之最大利益行使表決權，並不得直接或間接參與該股票發行公司經營。股票是基金資產、經濟利益歸受益人，若允許事業以自身利益行使，就可能拿受益人的持股去換取商業往來或人事影響力。

(C)錯誤。股東會通知書及出席證登記管理、評估分析作業與決策程序作成書面紀錄並循序編號建檔，這些要求本身正確，錯的是年限：同條第四項要求至少保存五年，不是三年。三年將使事後查核落在紀錄已可銷毀之後。

(D)正確。三項各有錯處：代表人是由事業指派的該事業人員而非限定基金經理人，表決權須基於受益人而非事業之最大利益行使，書面紀錄的保存年限是至少五年而非三年，故皆非正確。核心觀念是表決權為受益人利益而行使，並須留下足以事後查核的完整軌跡。

2. 依「期貨信託基金管理辦法」之規定，有關期貨信託契約之規定，下列敘述何者正確?
  1. (A)期貨信託事業為受託人
  2. (B)基金保管機構為受益人
  3. (C)用以規範期貨信託事業與基金保管機構雙方之權利義務
  4. (D)受益人毋須於期貨信託契約簽名或蓋章
解析

(A)錯誤。期貨信託契約中，期貨信託事業居於委託人之地位，受託人為基金保管機構。

(B)錯誤。基金保管機構為受託人；受益人是持有受益憑證的投資人。

(C)錯誤。期貨信託契約規範的是期貨信託事業、基金保管機構與受益人三方之權利義務，不只雙方。

(D)正確。受益人毋須於期貨信託契約上簽名或蓋章，其係因申購受益憑證而依契約取得受益權。這正是信託架構的特徵：契約由委託人與受託人訂立，受益人是契約利益的享有者。

3. 信託業募集發行共同信託基金從事期貨交易，除因避險目的，或依證券投資信託基金管理辦法第三十七條之一規定之槓桿型ETF 及反向型ETF 外，其期貨交易契約價值超過其淨資產價值多少百分比，應依規定申請兼營期貨信託事業?
  1. (A)百分之二十
  2. (B)百分之三十
  3. (C)百分之四十
  4. (D)百分之五十
解析

(A)錯誤。百分之二十是期貨信託基金管理辦法第三十九條第一項第四款對單一標的商品期貨與選擇權部位的集中度上限，管的是基金內部的部位分散，與共同信託基金是否須改受期貨信託法制監理無關。

(B)錯誤。百分之三十是組合型期貨信託基金投資每一子基金的上限等處所用的比率。若把兼營門檻降到三成，避險以外只做三成期貨部位的共同信託基金就須取得期信資格，管制範圍將明顯過度擴張。

(C)正確。期貨信託基金管理辦法第二條第二項規定，信託業募集發行共同信託基金從事期貨交易，其契約價值超過基金淨資產價值一定比率者，應依主管機關規定申請兼營期貨信託事業，該比率為百分之四十；避險目的及槓桿型、反向型ETF除外。避險是為既有資產降低風險，槓反ETF的期貨運用另有規範；一旦非避險的期貨契約價值超過四成，基金損益已主要由期貨部位決定，實質上就是期貨基金，自應改受期信法制的部位限制與風險揭露要求。

(D)錯誤。百分之五十意味要等期貨契約價值占到淨值一半才須納入期貨信託監理，屆時基金的風險屬性早已由期貨主導，投資人在整個過程中都取不到期信法制的保護；規範把界線提前到四成正是為此。

4. 依「期貨信託基金管理辦法」之規定，期貨信託基金之資產組成來源不包括下列何者?
  1. (A)基金孳息
  2. (B)發行受益憑證所取得之申購價款
  3. (C)申購手續費
  4. (D)動用基金所購置之各項資產
解析

(A)錯誤。基金孳息由基金資產所生，仍屬基金資產。

(B)錯誤。發行受益憑證所取得之申購價款是基金資產最主要的來源。

(C)正確（即不包括者）。申購手續費是投資人支付給銷售機構或期貨信託事業的報酬，並未進入基金，故不構成基金資產。判別關鍵在於該筆款項最終歸屬於基金，還是歸屬於業者。

(D)錯誤。動用基金所購置之各項資產屬基金資產之型態轉換，仍為基金資產。

5. 依「期貨信託基金管理辦法」，有關期貨信託事業接受客戶申購期貨信託基金之規定，以下敘述何者錯誤?
  1. (A)應向申購人告知期貨信託基金之性質及可能之風險
  2. (B)應向申購人交付期貨信託契約，並由雙方共同簽署
  3. (C)申購人瞭解期貨信託基金之風險後，應在風險預告書上簽名或蓋章及加註日期
  4. (D)應向申購人交付依相關法令規定編製之公開說明書
解析

(A)錯誤。此為正確規定：應向申購人告知基金之性質及可能之風險。

(D)錯誤。此為正確規定：應交付依相關法令編製之公開說明書。

6. 期貨信託事業對不特定人募集之每一期貨信託基金，平時所保持之流動資產應至少達該期貨信託基金淨資產價值之多少百分比?
  1. (A)百分之三十
  2. (B)百分之二十
  3. (C)百分之十
  4. (D)百分之五
解析

(A)正確。除募集發行保本型期貨信託基金者外，對不特定人募集之每一基金，依期貨信託基金管理辦法第五十條第一項第二款至第五款方式（存放於銀行、向票券商買入短期票券、債券附買回交易及其他經主管機關規定之方式）所保持之資產，應至少達該基金淨資產價值之百分之三十。期貨部位只需少量保證金即可建立，其餘資金必須停泊在流動性高、交易對手符合主管機關條件的工具上，才能隨時支應保證金追繳與買回價金。

(B)錯誤。百分之二十不足以承受期貨基金的資金需求：保證金追繳與大量買回可能同時發生，流動性資產只有兩成時，事業將被迫在不利價格下平倉變現，損及全體受益人。

(C)錯誤。百分之十是第四十條第一項場外衍生性商品交易總風險暴露的上限等處所用的比率，性質是曝險的天花板；把它當作流動資產的下限，正是把「不得超過」誤讀成「至少須達」。

(D)錯誤。百分之五是第三十九條第一項第二款相同單一期貨契約其他月份未平倉部位原始保證金的上限，與流動資產的最低比率無關；若流動性資產僅占淨值百分之五，一次保證金追繳就可能耗盡，基金將被迫平倉求現。

  1. (A)應於董事會通過之內部控制制度中訂定風險監控管理措施
  2. (B)每一期貨信託基金出借所持有任一有價證券數額，原則上不得超過所持有該有價證券數額之百分之五十
  3. (C)出借證券之借貸期間自借貸成交日起算，最長以一年為限
  4. (D)出借證券其交易型態屬議借交易者，借券人提供擔保品之種類，以現金、政府債券、得為融資融券交易之上市或上櫃公司股票為限
解析

(A)錯誤。出借有價證券應於董事會通過之內部控制制度中訂定風險監控管理措施，屬正確規定。

(B)錯誤。每一基金出借任一有價證券之數額，原則上不得超過所持有該有價證券數額之百分之五十，屬正確規定。

(D)錯誤。議借交易之擔保品以現金、政府債券、得為融資融券交易之上市或上櫃公司股票為限，屬正確規定。

8. 期貨信託事業運用所募集之期貨信託基金從事經主管機關核准之店頭衍生性商品，下列何者錯誤？
  1. (A)應確保取得交易之公平或合理價格並通知基金保管機構
  2. (B)交易之總風險暴露，除主管機關核准外，不得超過本期貨信託基金淨資產價值之百分之二十
  3. (C)總風險暴露不包含為規避未來交割之匯率風險而承作之外匯店頭衍生性商品
  4. (D)總風險暴露應至少包括市場風險暴露及信用風險暴露
解析

(A)錯誤。店頭商品無集中市場報價，取得公平合理價格並通知保管機構是明定義務，敘述正確，非本題所選。

(D)錯誤。總風險暴露至少應包括市場風險與信用風險暴露，敘述正確，非本題所選。

9. 依「期貨信託基金管理辦法」之規定，期貨信託基金銷售機構辦理期貨信託基金銷售，下列何者正確？
  1. (A)期貨信託基金銷售機構辦理期貨信託基金銷售業務之人員，不得挪用客戶款項
  2. (B)期貨信託基金受益憑證之交付，得採實券交付
  3. (C)期貨信託基金受益憑證之交付，得委由期貨信託基金銷售機構辦理
  4. (D)期貨信託基金銷售機構辦理期貨信託基金銷售業務之各項憑證之保存方式及期限，僅需依期貨公會規定辦理
解析

(A)正確。銷售人員不得挪用客戶款項。客戶款項自始不屬於銷售機構或其人員，此為受託關係最基本的財產分離要求，違反者不僅是內控瑕疵，更直接侵害受益人財產。

(B)錯誤。受益憑證採無實體發行，以帳簿劃撥交付，不得採實券交付。

(C)錯誤。受益憑證之交付係以帳簿劃撥方式為之，並非委由銷售機構代為交付實體憑證。

(D)錯誤。各項憑證之保存方式及期限應依法令規定辦理，並非僅依期貨公會規定即可。
