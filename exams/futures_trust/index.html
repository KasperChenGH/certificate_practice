1. 期貨信託事業對不特定人募集發行「傘型期貨信託基金」，應遵守哪些事項？甲.子期貨信託基金數不得超過五檔；乙.每一子期貨信託基金應簽訂個別之期貨信託契約；丙.當任一子期貨信託基金未達成立條件時，該傘型期貨信託基金即不成立
  1. (A)僅甲、乙
  2. (B)僅乙、丙
  3. (C)僅甲、丙
  4. (D)甲、乙、丙
解析

(A)錯誤。乙（每一子基金應簽訂個別之期貨信託契約）確為規定，但甲把檔數上限寫成五檔，期貨信託基金管理辦法第八條第一款所定的上限是三檔；本組合又漏掉丙這項真正的要求——任一子基金未達成立條件時整檔傘型基金即不成立。

(B)正確。依期貨信託基金管理辦法第八條，傘型基金的每一子基金應簽訂個別之期貨信託契約（乙），且任一子基金未達成立條件時該傘型基金即不成立（丙）；甲的錯誤在檔數，第八條第一款定為不得超過三檔而非五檔。個別立約使各子基金的資產與損益各自獨立、淨值分別計算，全部子基金都成立才生效，則避免傘型架構在缺角狀態下運作而使受益人的轉換安排落空。

(C)錯誤。丙正確，但甲所稱五檔並非法定上限（第八條第一款定為三檔），且本組合漏列乙——每一子基金必須各自簽訂期貨信託契約，這正是傘型架構下各子基金得以獨立計算淨值、各自負擔損益的基礎。

(D)錯誤。乙、丙都是規定，甲卻把第八條第一款的三檔上限記成五檔；三者全選會讓一個放寬近一倍的檔數限制被當成法定要件，實際上傘型期貨信託基金最多只能有三檔子基金，並應一次申請同時募集。

2. 所列期貨信託基金公開說明書應揭露期貨信託契約所訂期貨信託事業之權利、義務與責任部分，何者為真？
  1. (A)期貨信託基金損失超過基金淨資產時，超額損失部分應由受益人負擔
  2. (B)期貨信託基金受益人之責任不限於申購時所支付之申購價款
  3. (C)期貨信託基金損失超過基金淨資產時，超額損失部分應由期貨信託事業負擔
  4. (D)期貨信託基金之損失可能超過基金淨資產時，超額損失部分應由期貨信託事業與受益人約定負擔方式
解析

(A)錯誤。受益人之責任以其申購時所支付之價款為限，不負擔超額損失。

(B)錯誤。受益人責任正是以申購價款為限，本敘述與規定相反。

(C)正確。基金損失超過基金淨資產時，超額部分應由期貨信託事業負擔。期貨交易具槓桿性、可能出現負值，將超額損失歸於事業，才能使受益人之風險以出資額為上限。

(D)錯誤。超額損失之歸屬係規範所定，不容期貨信託事業與受益人另行約定分擔方式。

3. 期貨信託事業對符合一定資格條件之人募集期貨信託基金，應先檢具之相關書件申請核准，下列何者為是？甲.申請書；乙.期貨信託基金審查表；丙.期貨信託契約；丁.期貨信託基金現況資料表
  1. (A)僅甲、乙、丙
  2. (B)僅甲、丙、丁
  3. (C)僅乙、丙、丁
  4. (D)甲、乙、丙、丁
解析

(A)正確。對符合一定資格條件之人募集期貨信託基金，應檢具申請書、期貨信託基金審查表及期貨信託契約申請核准。私募的書件較公募精簡（例如無須公開說明書），但申請書表明申請事項、審查表供主管機關逐項核對法定要件、期貨信託契約界定投資範圍與受益人權益，這三者是核准與否的判斷基礎，都不能省略。

(B)錯誤。本組合漏掉期貨信託基金審查表，那是主管機關逐項勾稽法定要件的文件；又納入期貨信託基金現況資料表，該表反映基金成立後的實際運用狀況，在基金尚未成立的申請階段並不存在。

(C)錯誤。本組合缺少申請書。任何申請核准案件都須以申請書表明申請人、申請事項與檢附文件，欠缺申請書在程序上無從受理；此外現況資料表也不屬申請階段應檢具的書件。

(D)錯誤。期貨信託基金現況資料表是基金成立並開始運用後，用以申報或更新基金實際狀況的書件；募集申請時基金尚未成立、無從填載，故不在應檢具之列。

4. 有關期貨信託事業出席期貨信託基金所持有基金之受益人會議表決權之行使，何者錯誤？
  1. (A)應基於該期貨信託基金受益人之最大利益行使表決權
  2. (B)應就出席股東會行使表決權，表決權行使之評估分析作業、決策程序及執行結果作成書面紀錄
  3. (C)出席基金受益人會議前，應將行使表決權之評估分析作業，作成說明
  4. (D)表決權行使之評估分析、決策程序及執行結果書面紀錄，僅須保存兩個月
解析

(A)錯誤。表決權應基於該期貨信託基金受益人之最大利益行使，本敘述正確。

(B)錯誤。評估分析作業、決策程序及執行結果均應作成書面紀錄，本敘述正確。

(C)錯誤。出席受益人會議前應將表決權行使之評估分析作業作成說明，本敘述正確。

5. 依「期貨信託基金管理辦法」之規定，當非屬指數股票型期貨信託基金最近三個營業日之平均單位淨資產價值較基金最初單位淨資產價值累積跌幅達百分之多少時，即達應通報主管機關之標準？
  1. (A)二十
  2. (B)三十
  3. (C)四十
  4. (D)五十
解析

(A)錯誤。百分之二十的跌幅對操作期貨、槓桿較高的基金而言仍屬常見波動，若以兩成為通報門檻，日常市況即會頻繁觸發，通報反而失去警示作用；辦法所定的門檻是四成。

(B)錯誤。百分之三十在本辦法中另有用處（例如第四十一條第二項組合型期貨信託基金對每檔子基金支付總額不得超過淨值百分之三十），但不是非指數股票型基金單位淨值累積跌幅的通報門檻。

(C)正確。非屬指數股票型之期貨信託基金，最近三個營業日平均單位淨資產價值較最初單位淨資產價值累積跌幅達百分之四十時，即應通報主管機關。取三個營業日平均而非單日數字，是為濾掉單日極端行情；門檻設在四成，則讓主管機關在基金嚴重減損、可能面臨大量買回或終止之前就能掌握並介入。

(D)錯誤。等到淨值腰斬（百分之五十）才通報已失時機，受益人的損失多半難以回復；辦法把通報點提前到累積跌幅四成，正是為了留下處理與溝通的時間。

6. 依「期貨信託基金管理辦法」之規定，期貨信託事業運用期貨信託基金持有有價證券總市值超過本期貨信託基金淨資產價值多少比率時，應依主管機關規定申請兼營證券投資信託事業？
  1. (A)百分之十
  2. (B)百分之二十
  3. (C)百分之三十
  4. (D)百分之四十
解析

(A)錯誤。百分之十是第四十條場外衍生性商品交易總風險暴露的上限，也是第四十九條第一項第九款對單一上市櫃發行人的集中度上限，不是必須申請兼營證券投資信託事業的門檻。

(B)錯誤。百分之二十是第三十九條第一項第四款（單一標的商品之期貨與選擇權部位）及第四十七條（於國外募集之基金投資國內單一上市櫃公司）所用的比率，與是否須兼營證券投資信託事業無關。

(C)錯誤。百分之三十出現在第四十一條第二項（組合型基金對每檔子基金支付總額上限）等處，並不是持有有價證券總市值須申請兼營的界線。

(D)正確。期貨信託基金管理辦法第四十二條規定，運用期貨信託基金持有有價證券之總市值占本基金淨資產價值不得超過主管機關所定比率，超過者應依主管機關規定申請兼營證券投資信託事業，該比率為百分之四十。基金若把四成以上資產放在有價證券，實質已在從事證券投資信託業務，自應取得相應資格並受該業之監理。

7. 下列何者非期貨信託基金按季更新公開說明書應記載基金運用狀況之事項？
  1. (A)投資單一股票金額占期貨信託基金淨資產價值百分之一以上之股票名稱、股數及每股市價
  2. (B)投資單一債券金額占期貨信託基金淨資產價值百分之一以上之名稱、投資金額及比率
  3. (C)淨資產總額之組成項目、金額及比率
  4. (D)期貨信託事業最近一年之信用評等狀況

(C)錯誤。淨資產總額之組成項目、金額及比率，是基金運用狀況之核心揭露。

8. 下列何者情況不需經期貨信託基金受益人會議決議？
  1. (A)更換基金保管機構
  2. (B)更換全權委託專業機構
  3. (C)更換期貨信託事業
  4. (D)重大變更期貨信託基金從事期貨交易及投資期貨相關現貨商品之基本方針及範圍
解析

(A)錯誤。更換基金保管機構直接影響受益人資產之保管安排，須經受益人會議決議。

(B)正確（即無須經受益人會議決議者）。全權委託專業機構是期貨信託事業為執行操作所選任之機構，屬事業之業務執行事項，最終責任仍由事業承擔，故不以受益人會議決議為必要。

(C)錯誤。更換期貨信託事業係變更基金之經理者，須經受益人會議決議。

(D)錯誤。重大變更基金從事期貨交易及投資之基本方針與範圍，改變了受益人原始投資標的，須經受益人會議決議。

1. 期貨信託事業為因應期貨信託基金受益人依約定買回受益憑證所需支付買回價金缺口時，下列有關之敘述何者錯誤?
  1. (A)得依規定以該期貨信託基金之資產為擔保向金融機構辦理借款
  2. (B)所稱買回價金缺口，指流動資產加計當日申購受益憑證發行價額扣除應保持之最低流動準備金及當日受益權單位買回價金總額後之餘額
  3. (C)期貨信託事業辦理借款期間，受益人申請買回應支付買回價金百分之二之買回費用
  4. (D)借款之利息費用，由期貨信託基金負擔
解析

(A)錯誤。得依規定以該基金之資產為擔保向金融機構辦理借款，敘述正確。

(B)錯誤。買回價金缺口之計算方式如該項所述，與規定相符。

(C)錯誤。借款期間受益人申請買回應支付一定比率之買回費用，此為規定內容。

(D)正確（即敘述有誤者）。借款所生之利息費用不由期貨信託基金負擔。借款是為填補流動性缺口所為之管理行為，若讓基金吸收利息，等於由全體受益人替少數贖回者付費。

2. 對保本型期貨信託基金之敘述，何者有誤?
  1. (A)投資保本型期貨信託基金絕無風險
  2. (B)投資人須持有基金至到期日方可享有本金保證
  3. (C)保本型期貨信託基金應於公開說明書中加強敘明保本比率
  4. (D)保本型期貨信託基金之類型可分為保證型或保護型
解析

(B)錯誤。須持有至到期日始享有本金保證，敘述正確。

(C)錯誤。公開說明書應加強敘明保本比率，敘述正確。

(D)錯誤。保本型基金可分為保證型與保護型兩類，敘述正確。

3. 關於期貨信託基金收益分配應記載之事項，下列何者為是?
  1. (A)分配之項目
  2. (B)分配之時間
  3. (C)給付之方式
  4. (D)選項(A)、(B)、(C)皆是
解析

(A)錯誤。分配之項目固然必須記載，但它只回答分配什麼；受益人還需知道何時可領與以何方式給付，缺少後兩者仍無法據以主張權利。

(B)錯誤。分配之時間只說明何時分配，未涵蓋分配標的與給付途徑；僅記載時間，受益人無從判斷可分配的收益來源與金額。

(C)錯誤。給付之方式（例如匯撥入指定帳戶或轉為再投資）只是最後一段作業；若未同時記載分配項目與時間，受益人仍不知可分配金額與請求權發生的時點。

(D)正確。期貨信託契約與公開說明書就收益分配，應記載分配之項目、分配之時間及給付之方式。三者合起來才構成一項可執行的權利：項目界定可分配的收益來源，時間確定請求權發生的時點，給付方式決定款項如何到受益人手中；缺任何一項，分配時都會產生爭議。

5. 依「期貨信託基金管理辦法」之規定，下列敘述何者正確?
  1. (A)期貨信託事業募集之期貨信託基金，不須與其事業及基金保管機構之自有財產分別獨立
  2. (B)期貨信託事業及基金保管機構就自有財產所負債務，其債權人不得對於期貨信託基金資產請求扣押或行使其他權利
  3. (C)基金保管機構應依法令及期貨信託契約之規定，一般管理人之注意義務及忠實義務，保管期貨信託基金資產
  4. (D)基金保管機構之董事，不是內線交易規範主體，所以得將基於職務上所知悉之消息從事期貨交易或投資期貨相關現貨商品或將該消息洩漏予他人
解析

(A)錯誤。基金資產必須與期貨信託事業及基金保管機構之自有財產分別獨立，這是信託架構的基礎。

(B)正確。基金資產既獨立於事業與保管機構之自有財產，兩者自有財產所負債務之債權人即不得對基金資產請求扣押或行使權利。此即信託財產獨立性，用以隔離受任人自身的倒閉風險。

(C)錯誤。保管機構所負者為善良管理人之注意義務，標準高於「一般管理人」之注意義務。

(D)錯誤。保管機構之董事同受規範，不得利用職務上所知消息從事交易或將該消息洩漏予他人。

6. 依據期貨公會自律規範，下列何者應負期貨信託基金風險管理之最終責任?
  1. (A)期貨信託事業之董事長
  2. (B)期貨信託事業之董事會
  3. (C)期貨信託事業之總經理
  4. (D)期貨信託事業之風險管理委員會
解析

(A)錯誤。董事長對外代表公司並主持董事會，但風險管理的最終責任屬於作為集體決策機關的董事會，而非董事長個人；否則風險政策的核定與定期檢視將取決於一人判斷。

(B)正確。期貨信託基金風險管理的最終責任由期貨信託事業的董事會承擔。這與期貨信託基金管理辦法第三十七條的架構一致：風險監控管理措施須訂於董事會通過之內部控制制度中，董事會並至少每季檢視所經理各基金及委外運用部分的總風險暴露程度、計算風險的方式與最大可能損失。把最終責任放在董事會，是因為風險胃納的設定牽動受益人利益與事業存續，必須由對股東與受益人負責的集體決策機關拍板，並留下可追究的會議紀錄。

(C)錯誤。總經理負責日常業務的執行與內部控制的落實，是風險管理制度的執行者；制度的核定與總風險暴露的定期檢視屬董事會職責，執行層無從承擔最終責任。

(D)錯誤。風險管理委員會若有設置，是提供專業評估與建議的功能性組織，其結論仍須提報董事會決定；把最終責任推給委員會，會讓董事會藉專業分工卸責。

  1. (A)由期貨信託事業自行訂定完善之控管計畫，毋須依期貨公會所定相關規範辦理
  2. (B)期貨信託事業董事會應至少每季檢視基金之總風險暴露程度、計算風險之方式及最大可能損失

8. 依據期貨公會自律規範，期貨信託基金不成立時，期貨信託事業應立即指示基金保管機構，自確定不成立日起幾個營業日內，退還申購人申購價金並加計利息？
  1. (A)三個營業日
  2. (B)五個營業日
  3. (C)七個營業日
  4. (D)十個營業日
解析

(A)錯誤。三個營業日不足以完成基金不成立後的退款作業：須先確認全部申購人名單與各筆已繳價款、計算應加計的利息，再透過基金保管機構逐筆退回專戶款項。

(B)錯誤。五個營業日常與買回價金的給付期限混淆（對不特定人募集投資國內之基金，為自買回請求到達之次一營業日起五個營業日內），但基金募集不成立時退還申購價金的期間為十個營業日。

(C)錯誤。七個營業日出現在部分買回時辦理受益權單位登錄及帳簿劃撥的作業期間，屬既存基金的帳務作業；募集不成立是基金自始未成立、須全額退款，兩者的程序與期限不同。

(D)正確。期貨信託基金不成立時，期貨信託事業應立即指示基金保管機構，自確定不成立之日起十個營業日內，將申購價金並加計利息退還申購人。價款自繳納時起即存入專戶由保管機構保管、從未歸屬事業，基金既未成立，申購人與基金之間沒有應承擔的損益，故必須原額返還並補償資金被占用期間的時間價值。

10. 依「期貨信託基金管理辦法」之規定，期貨信託事業運用所募集之期貨信託基金持有單一期貨契約，其最近及次近月份之未平倉部位所需原始保證金，分別不得超過本期貨信託基金淨資產價值之多少比率？
  1. (A)百分之五
  2. (B)百分之十
  3. (C)百分之十五
  4. (D)百分之二十
解析

(A)錯誤。百分之五是第三十九條第一項第二款對相同單一期貨契約「其他月份」未平倉部位所需原始保證金的限制；遠月份契約流動性較差、價差波動大，額度才訂得比最近及次近月份的百分之十更低，兩者不可互換。

(B)正確。期貨信託基金管理辦法第三十九條第一項規定，持有單一期貨契約最近月份及次近月份之未平倉部位所需原始保證金，分別各不得超過本基金淨資產價值之百分之十。近月契約流動性最佳、進出容易，容許額度高於其他月份的百分之五；以「分別」計算則避免把近月與次近月合併認定而放大實際曝險，這是單一契約層級的集中度控制。

(C)錯誤。百分之十五不是第三十九條使用的比率。該條第一項用到的是百分之七十（全部未平倉原始保證金加計權利金淨額）、百分之十（單一契約最近及次近月份，各別計算）、百分之五（其他月份）與百分之二十（單一標的商品）。

(D)錯誤。百分之二十是第三十九條第一項第四款對單一標的商品或金融工具之期貨、期貨選擇權及選擇權部位，以原始保證金加計權利金淨額合計計算的上限；那是跨契約、跨月份的標的層級管制，範圍比本題所問的單一契約近月份額度更廣。

16. 期貨信託事業運用對不特定人所募集之期貨信託基金投資於不動產信託受益證券，每一基金投資於任一不動產投資信託基金受益權單位總數，不得超過該不動產投資信託基金已發行受益權單位總數之多少比率？
  1. (A)百分之二十
  2. (B)百分之十五
  3. (C)百分之十
  4. (D)百分之五

(C)正確。期貨信託基金管理辦法第四十五條第二款規定，每一基金投資於任一受託機構發行之不動產投資信託基金之受益權單位總數，不得超過該不動產投資信託基金已發行受益權單位總數之百分之十。以「單位數」而非金額設限，管的是對被投資基金的持分與影響力，避免期貨信託基金成為某檔封閉型不動產基金的主要持有人而承受其流動性風險。

(D)錯誤。百分之五低於本款所定的上限；第四十五條除以被投資基金已發行受益權單位總數百分之十設限外，第四款另以本基金淨資產價值百分之十設限，兩端都用百分之十，沒有採百分之五的款項。

115年第1次｜期貨信託法規及自律規範｜第 16 題
17. 期貨信託事業申請於國外募集期貨信託基金投資於國內者，下列何者為真？
  1. (A)僅得從事國外期貨交易
  2. (B)僅得從事國內期貨交易
  3. (C)得從事國內及國外期貨交易
  4. (D)選項(A)(B)(C)皆非
解析

(A)錯誤。這正好把核准範圍顛倒過來：基金既以投資於國內為由申請並獲准，資金匯入後即應用於國內市場，不得轉去從事國外期貨交易。

(B)正確。於國外募集而申請投資於國內的期貨信託基金，其期貨交易限於國內期貨交易，與核准的投資地區一致；此類基金並受期貨信託基金管理辦法第四十七條限制，投資國內任一上市或上櫃公司股票及公司債或金融債券之總金額不得超過基金淨資產價值之百分之二十。資金以投資國內為理由獲准匯入，自不得改作國外交易之用，否則主管機關對資金流向與投資範圍的核准將無從落實。

(C)錯誤。兼及國外期貨交易會超出核准的投資範圍；若原本就要從事國外期貨交易，依第四十八條應依募集地法令規定辦理，而非以投資國內的名義獲准後再行擴張。

(D)錯誤。選項(B)的敘述與核准的投資地區一致，是正確的，故非三者皆非；本題的判斷關鍵就在於資金用途必須與核准的投資地區相符。

  2. (B)百分之十
  3. (C)百分之十五
  4. (D)百分之二十

(B)正確。期貨信託基金管理辦法第四十九條第一項第九款規定，每一期貨信託基金投資於任一上市或上櫃公司股票及公司債或金融債券之總金額，不得超過本基金淨資產價值之百分之十。同條第三項並把普通、轉換、交換及附認股權公司債都算入公司債，股票與各類債券須對同一發行人合併計算，避免藉商品種類不同而規避集中度上限。
