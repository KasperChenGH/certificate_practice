2. 假設小何所擁有的資金在過去一年賺取了8%的名目利率，該期間通貨膨脹率為4%，請問小何的實際購買力成長了多少？
  1. (A)3.5%
  2. (B)3.3%
  3. (C)3.8%
  4. (D)3.6%
解析

(A)錯誤。3.5%不是名目利率8%與通膨率4%依費雪方程式換算出的結果；若只是把名目利率減去通膨率，得到的是近似值4%，也不是3.5%，此數字無法由題目資料推得。

(B)錯誤。3.3%比正確的3.85%還低，等於把通膨的侵蝕效果高估了；無論用精確的除法還是相減的近似法，都得不到3.3%，此數字不出自題目資料。

(C)正確。費雪方程式指出(1+名目利率)=(1+實質利率)×(1+通膨率)，因此實質利率=(1+8%)÷(1+4%)−1=1.08÷1.04−1≈3.85%，四捨五入為3.8%。實質利率衡量的是購買力真正增加的幅度，因為4%的通膨已經吃掉了名目報酬的一部分；用相減的近似法會得到4%，略高於精確值，所以選項中最接近的是3.8%。

(D)錯誤。3.6%介於精確值3.85%與其他選項之間，但既不是1.08÷1.04−1的結果，也不是8%−4%的近似結果，此數字不能由題目給的名目利率與通膨率算出。

4. 下列何者列有對債權人較為有利之條款？甲.可轉換公司債；乙.可贖回公司債；丙.附認股權公司債
  1. (A)僅甲、乙
  2. (B)僅乙、丙
  3. (C)僅甲、丙
  4. (D)甲、乙、丙
解析

(A)錯誤。可轉換公司債賦予債權人轉換為股票之選擇權，對債權人有利；但可贖回公司債賦予發行公司提前贖回之權利，對發行人有利、對債權人較不利。

(D)錯誤。三者全選混淆了可贖回對發行人有利之特性。

115年第1次｜投資學｜第 4 題
5. 甲、乙兩種具有相同票面利率，面額及到期殖利率之中央政府債券，目前均屬溢價債券，若甲債券尚餘4 年到期，乙債券尚餘2 年到期，則：
  1. (A)甲債券溢價額較乙債券溢價額大
  2. (B)甲債券溢價額與乙債券溢價額相等
  3. (C)甲債券溢價額較乙債券溢價額小
  4. (D)無法比較
解析

(A)正確。溢價債券的票面利率高於到期殖利率，溢價額等於每一期「票息高於市場要求利息」的差額折現後加總。甲債券還有4年，可以多收2年的超額票息，折現後累積的溢價額自然比只剩2年的乙債券大。這也說明為什麼溢價債券的價格會隨時間逐漸向面額收斂：剩餘期數愈少，可折現的超額票息愈少。

(B)錯誤。溢價額相等只會發生在兩債券剩餘期限相同的情況；題目已說明甲剩4年、乙剩2年，甲多出的兩期超額票息折現值必為正，兩者不可能相等。

(C)錯誤。這個方向把折現效果想反了：期限拉長雖然讓遠期現金流折現後變小，但每多一期就多一筆正的超額票息現值，總溢價額只會增加不會減少，所以甲的溢價額不會比乙小。

(D)錯誤。題目已經固定票面利率、面額與到期殖利率三個條件，唯一的差異就是剩餘期限，溢價額與剩餘期限的關係是明確的正向關係，因此是可以比較的。

115年第1次｜投資學｜第 5 題
6. 一般而言，公司債贖回條款(call provision)中的贖回溢價(call premium)距到期日愈近會：
  1. (A)愈小
  2. (B)愈大
  3. (C)不變
  4. (D)不確定
解析

(A)正確。贖回溢價是發行公司提前贖回債券時，在面額之外多付給投資人的補償。愈接近到期日，投資人被剝奪的剩餘票息愈少，需要的補償也愈少，因此贖回條款通常設計成贖回溢價隨到期日接近而遞減，到期前常降至零。這樣的設計讓發行人在利率下降時能以合理成本再融資，也讓投資人在早期被贖回時獲得較多補償。

(B)錯誤。若贖回溢價愈接近到期愈大，等於發行人在債券快到期、投資人損失最小的時候反而付最多補償，與贖回溢價補償投資人剩餘利息損失的用意相反，實務契約不會這樣設計。

(C)錯誤。固定不變的贖回溢價忽略了投資人的損失會隨剩餘期間縮短而減少，實務上贖回條款多採階梯式遞減的溢價時程表，而不是單一固定金額。

(D)錯誤。贖回溢價的時程在發行時即寫入公司債契約，是事先確定的遞減表，並不是隨市場狀況而不確定的數字。

115年第1次｜投資學｜第 6 題
7. 道氏理論中，告訴投資人主要的市場趨勢方向，是以下列何者來表達？
  1. (A)成交量
  2. (B)價格
  3. (C)時間
  4. (D)指數
解析

(A)錯誤。成交量在道氏理論裡是趨勢的「確認」工具，例如多頭趨勢中上漲時量增、回檔時量縮才算健康，但成交量本身不用來表達主要趨勢的方向。

(B)錯誤。個別股票價格是觀察的對象之一，但道氏理論關心的是整體市場的主要趨勢，單一股票價格無法代表整個市場，所以它用的是彙總後的指數。

(C)錯誤。時間只用來區分主要趨勢、次級趨勢與日常波動的長短，例如主要趨勢通常持續一年以上，但時間長短不會指出趨勢是向上或向下。

(D)正確。道氏理論以道瓊工業指數與運輸指數兩個平均指數來表達市場的主要趨勢，並要求兩個指數互相確認：只有兩者同時創新高或新低，才確認主要趨勢的方向。用指數而非個股，是因為指數彙總了整體市場的價格行為，能濾掉個別公司的雜訊。

8. 假設某甲買了一張三年期的抗通膨指數債券(TIPS)，票面金額1,000 美元、債息率為3%，若三年的通貨膨脹率分別為10%、5%、3%，請問第一年某甲可得到的債息為多少美元？
  1. (A)55
  2. (B)33
  3. (C)100
  4. (D)1,100
解析

(A)錯誤。55美元是把第一年調整後本金1,100美元乘以5%得到的數字，但5%是第二年的通膨率，不是票面利率，第一年的債息應以3%計算。

(B)正確。抗通膨指數債券的本金會隨通膨調整，票面利率則固定，債息等於調整後本金乘以票面利率。第一年通膨10%，本金由1,000美元調整為1,000×(1+10%)=1,100美元，債息為1,100×3%=33美元。這種設計讓票息與本金都跟著物價走，投資人領到的實質報酬不會被通膨侵蝕。

(C)錯誤。100美元是1,000美元本金乘以10%的結果，等於把通膨率當成票面利率來算利息；通膨率只用來調整本金，利息仍按3%計算。

(D)錯誤。1,100美元是第一年經通膨調整後的本金金額，不是債息；投資人在第一年領到的只是這筆本金的3%利息，本金要到到期時才會收回。

115年第1次｜投資學｜第 8 題
9. 甲公司每年固定配發現金股利4 元，不配發股票股利，其股票必要報酬率為10%，若其貝它係數為1.1，在零成長之股利折現模式下，其股價應為：
  1. (A)44.4 元
  2. (B)33.3 元
  3. (C)40 元
  4. (D)48.8 元
解析

(A)錯誤。44.4元相當於4÷0.09，等於從10%的折現率中扣掉了一個不存在的1%成長率；題目說明股利固定不成長，分母應為完整的10%。

(B)錯誤。33.3元相當於4÷0.12，是把折現率墊高到12%的結果，可能來自把貝它係數再加到必要報酬率上；但10%已經是考慮風險後的必要報酬率，不需再調整。

(C)正確。零成長股利折現模式把股票視為永續年金，股價P=D÷r=4÷0.10=40元。貝它係數1.1是用來推導必要報酬率的因子，題目已直接給出必要報酬率10%，貝它的影響已包含其中，不必再另外計算。

(D)錯誤。48.8元接近把股利乘以貝它係數1.1再除以9%的結果，等於把貝它當成股利的乘數；貝它只影響折現率的推導，不會放大股利金額。

115年第1次｜投資學｜第 9 題
10. 某股票在除權交易日前一天收盤價為100 元，若盈餘轉增資配股率15%，資本公積轉增資配股率10%，則除權參考價為：
  1. (A)64 元
  2. (B)72 元
  3. (C)69.5 元
  4. (D)80 元
解析

(A)錯誤。64元相當於100÷1.25再除以1.25，等於把配股率的稀釋效果重複計算了兩次；盈餘配股與資本公積配股是同時發放，分母只需加總一次。

(B)錯誤。72元不是任何正確的除權公式能得到的數字；若誤用「收盤價乘以(1−配股率)」的減法，得到的是100×0.75=75元，也不是72元。

(C)錯誤。69.5元無法由收盤價100元與合計25%的配股率推導出來，無論是除法或減法都得不到此數，此數字不出自題目資料。

(D)正確。無償配股不會改變公司總市值，只是股數增加，因此除權參考價=除權前收盤價÷(1+配股率)=100÷(1+0.15+0.10)=100÷1.25=80元。盈餘轉增資與資本公積轉增資都是無償配股，兩者的配股率要合併計入分母，這樣參考價乘以除權後股數才等於除權前的市值。

12. 所謂量價背離，指下列何項？
  1. (A)量增價漲
  2. (B)量減價跌
  3. (C)量平價平
  4. (D)量增價跌
解析

(A)錯誤。量增價漲是成交量與價格同向，屬於量價配合，表示買盤有量能支撐，通常視為健康的上漲，並非背離。

(B)錯誤。量減價跌同樣是量價同向，屬於量價配合，代表賣壓隨價格下跌逐漸減輕，不是背離現象。

(C)錯誤。量平價平表示市場處於平靜、沒有明顯動能的狀態，成交量與價格都沒有趨勢可言，談不上兩者走勢不一致。

(D)正確。量價背離指成交量的趨勢與價格的趨勢方向不一致，量增價跌就是典型例子：成交量放大，價格卻下跌，代表雖然交易活絡但賣壓大於買盤，市場對價格走勢缺乏共識。技術分析視背離為原有趨勢可能反轉的警訊，因為價格缺乏對應的量能支撐。

1. 依公司法規定，下列何者股份有限公司人員，於執行職務範圍內，亦為負責人？ 甲、檢查人；乙、重整人；丙、發起人；丁、發言人
  1. (A)僅甲、乙、丙
  2. (B)僅乙、丙、丁
  3. (C)僅甲、丙、丁
  4. (D)僅甲、乙、丁
解析

(A)正確。公司法第8條第2項規定，公司之經理人、清算人或臨時管理人，以及股份有限公司之發起人、監察人、檢查人、重整人或重整監督人，在執行職務範圍內亦為公司負責人。檢查人、重整人、發起人三者皆在列，發言人則否。把這些人納入負責人，是要讓他們在執行職務時同受忠實義務與善良管理人注意義務的拘束，違反時須對公司負損害賠償責任。

(B)錯誤。這組把發言人算進去而漏掉檢查人。發言人只是公司對外揭露資訊的窗口，屬職務分工而非公司法列舉的法定負責人；檢查人則是法院或股東會選派查核公司業務帳目的人，執行職務時確實視為負責人。

(C)錯誤。此組漏掉重整人而納入發言人。重整人在公司重整程序中接管公司業務與財產的經營管理，法律因此明定其在執行職務範圍內為負責人；發言人並無此地位。

(D)錯誤。此組漏掉發起人。發起人負責籌備設立、認股與召開創立會，公司法明定其在執行職務範圍內為負責人，且對設立中公司的行為負連帶責任；發言人則不在第8條的名單內。

  2. (B)應經董事會過半數出席及出席董事過半數同意之決議行之

3. 發行人公告申報之財務報告主要內容有虛偽之情事者，對所發行證券之善意取得人、出賣人因而所受之損害負賠償責任，但下列何者得舉證免責？
  1. (A)發行人之董事長
  2. (B)發行人之總經理
  3. (C)簽證會計師
  4. (D)發行人之會計主管
解析

(A)錯誤。董事長是發行人的代表負責人，財務報告須由其簽名或蓋章，證券交易法第20條之1將其列為與發行人並列的第一順位賠償義務人，本題的命題立場是董事長不得以已盡注意為由免責（104年修法後已改採推定過失責任，得舉證免責）。

(B)錯誤。總經理與董事長同為在財務報告上簽章的經營負責人，命題立場是其與發行人同負責任，不得舉證免責；簽證會計師則因是外部專業人員而有不同的責任基礎。

(C)正確。財務報告不實的民事責任由證券交易法第20條之1規範，發行人負無過失責任，董事長、總經理與簽章的會計主管傳統上被視為公司內部的主要責任人；簽證會計師是外部專業第三人，其責任以有不正當行為或違反、廢弛業務上應盡之義務為前提，因此得舉證已依審計準則盡專業注意而免責。須留意104年修正後，第20條之1第2項已改為除發行人外之各款人（含董事長、總經理、簽章職員）均得證明已盡相當注意而免責，本題係以會計師為唯一得舉證免責者的傳統命題方式作答。

(D)錯誤。會計主管是在財務報告上簽名或蓋章的公司職員，屬證交法第20條之1第1項第2款的責任人，本題將其歸為與董事長、總經理相同的公司內部責任人，不是得舉證免責的外部簽證會計師。

4. 上市公司發行轉換公司債，其持有人得依發行人所定之轉換辦法隨時請求轉換，以下敘述何者正確？
  1. (A)股東常會及股東臨時會之停止過戶期間得請求轉換，但不得辦理股東名簿記載之變更
  2. (B)股東常會及股東臨時會之停止過戶期間不得請求轉換，不得辦理股東名簿記載之變更
  3. (C)股東常會及股東臨時會之停止過戶期間得請求轉換，得辦理股東名簿記載之變更
  4. (D)股東常會及股東臨時會之停止過戶期間不得請求轉換，得辦理股東名簿記載之變更
解析

(A)正確。停止過戶是為了在股東會或除權息前固定股東名簿，讓公司確認有權出席或受配的股東，限制的是名簿記載的變更，不是轉換權本身。轉換公司債持有人在停止過戶期間仍得依轉換辦法請求轉換，公司先受理，待停止過戶期間屆滿後再辦理股東名簿的變更登記。這樣既維持名簿在基準日的確定性，也不剝奪債權人契約上的轉換權。

(B)錯誤。此項把停止過戶期間當成連轉換請求也一併凍結。實際上凍結的只是股東名簿的記載變更，債券持有人的轉換請求權來自轉換辦法，並不因公司停止過戶而暫停。

(C)錯誤。此項承認得請求轉換，卻認為名簿也可以同時變更。若停止過戶期間仍可辦理名簿記載變更，公司就無法確定基準日的股東，停止過戶制度便失去意義，因此名簿變更必須等期間屆滿。

(D)錯誤。此項恰好顛倒：轉換請求不受限而名簿變更受限才是正確的組合。此項既禁止請求轉換又允許名簿變更，與停止過戶制度的目的完全相反。

  3. (C)30 日

解析

(A)正確。公司法第22條之1要求公司每年定期將董事、監察人、經理人及持股逾10%股東的資料申報至「公司負責人及主要股東資訊申報平臺」，資料有變動者應於變動後十五日內申報。此制度是配合洗錢防制的實質受益人透明化要求，變動後即時更新，主管機關與金融機構才能掌握公司的實際控制者。

  1. (A)十二個月
  2. (B)九個月
  3. (C)六個月
  4. (D)三年
解析

(A)錯誤。十二個月不是內部人取得身分後的禁止轉讓期。一年出現在證交法第22條之2第2項：經由向特定人轉讓方式受讓股票者，一年內再轉讓仍須依同條方式辦理，這是對受讓人的限制，不是對新取得身分的大股東。

(B)錯誤。九個月並非任何內部人持股期間規定。內部人取得身分後的持有期間是主管機關依證交法第22條之2授權所定的六個月，九個月既不對應該規定，也不是其他持股限制的期間。

(C)正確。證券交易法第22條之2規定，董事、監察人、經理人及持股超過股份總額10%的股東轉讓股票，必須依主管機關所定持有期間與每日得轉讓數量比例事前申報後才能在市場出售；主管機關所定的持有期間即取得內部人身分之日起六個月內不得轉讓。甲於六月十日成為大股東，六個月內不得轉讓乙公司股票。用意在防止內部人短期進出、利用資訊優勢套利。

  2. (B)新臺幣20 億元
  3. (C)新臺幣30 億元
  4. (D)新臺幣40 億元

(C)錯誤。三十億元較接近但仍低於四十億元的法定下限。證金公司的資本門檻是以其信用中介功能所需的風險承擔能力設定的，未達四十億元即不符合設立條件。

9. 證券投資信託事業之董事、監察人、經理人、業務人員及其他受僱人員，不得為下列何種行為？
  1. (A)以職務上所知悉之消息洩漏予他人
  2. (B)為虛偽、詐欺或其他足致他人誤信之行為
  3. (C)運用證券投資信託基金買賣有價證券及其相關商品時，收取證券商退還手續費
  4. (D)選項(A)(B)(C)皆不得為之
解析

(A)錯誤。洩漏職務上所知悉之消息確為禁止行為，但它只是禁止項目之一。投信人員知悉基金的買賣決策與持股，若洩漏給他人，會讓對方搶先交易而損害受益人，因此本項與其他兩項同屬不得為之。

(B)錯誤。虛偽、詐欺或足致他人誤信的行為確實被禁止，但選項未涵蓋其他兩項。投信事業以募集大眾資金為業，對投資人的說明與廣告必須真實，這是禁止規定之一而非全部。

(C)錯誤。收取證券商退還的手續費是典型的利益衝突：投信事業可能為了退佣而增加基金的交易量，交易成本卻由受益人負擔，故被明文禁止；但它同樣只是禁止行為之一。

(D)正確。證券投資信託及顧問法對投信事業的董事、監察人、經理人、業務人員及其他受僱人明定多項禁止行為，包括洩漏職務上知悉的消息、為虛偽詐欺或足致他人誤信的行為，以及運用基金買賣有價證券時收取證券商退還的手續費。三者都會使受託人的利益與受益人衝突，違背投信事業對基金受益人的忠實義務，故皆在禁止之列。

10. 證券投資信託事業違反「證券投資信託及顧問法」或依該法所發布之命令者，除依證券投資信託及顧問法處罰外，金融監督管理委員會並得視情節輕重，為何處分？
  1. (A)警告
  2. (B)命令該證券投資信託事業解除其董、監或經理人職務
  3. (C)六個月以下停業
  4. (D)選項(A)(B)(C)皆是
解析

(A)錯誤。警告是主管機關得採的最輕處分，但並非唯一手段；違規情節較重時，法律同時允許命令解除職務或停業，故單選警告不完整。

(C)錯誤。六個月以下停業是對公司或分支機構的較重處分，適用於情節重大的情形，但主管機關同樣可以選擇警告或解除職務，故三者皆是才完整。
