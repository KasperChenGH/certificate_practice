1. 有關政府債券的敘述，何者「正確」？
  1. (A)政府債券的風險較公司債低
  2. (B)政府債券的利率較公司債高
  3. (C)政府債券發行採詢價圈購
  4. (D)政府債券屬於短期債券
解析

(A)正確。政府債券由中央政府以租稅收入與發債能力擔保還本付息，違約機率極低，被視為近乎無風險的資產；公司債則依賴個別企業的獲利與償債能力，違約風險較高。因此政府債券的信用風險低於公司債，其殖利率也成為其他債券定價的基準。

(B)錯誤。利率高低反映違約風險的補償，政府債券風險最低，投資人要求的殖利率也最低；公司債必須提供高於公債的利率，才能補償投資人承擔的信用風險，所以政府債券利率通常較公司債低而非高。

(C)錯誤。詢價圈購是股票或公司債承銷時，由承銷商向投資人詢問認購意願與價格來決定配售的方式；我國中央政府公債是由中央銀行以標售（競標與非競標）方式發行，並不採詢價圈購。

(D)錯誤。政府債券依期限有短期國庫券與二年、五年、十年、二十年、三十年等中長期公債，並非只有短期債券；一般所稱政府公債反而以中長期為主。

114年第3次｜投資學｜第 3 題
4. 投資風險性資產的報酬率與無風險利率的差額，稱之為？
  1. (A)投資利得
  2. (B)投資報酬
  3. (C)風險溢酬
  4. (D)風險係數
解析

(A)錯誤。投資利得通常指資本利得，也就是賣出價格高於買進價格的價差，是實際實現的獲利金額，並沒有扣除無風險利率的概念。

(B)錯誤。投資報酬是投資所獲得的全部收益（含利息、股利與價差）占投入成本的比率，是總報酬率而非超過無風險利率的部分，風險溢酬只是報酬中補償風險的那一段。

(C)正確。風險溢酬（risk premium）是風險性資產的預期報酬率減去無風險利率的差額，代表投資人為了承擔額外風險所要求的補償。例如股票預期報酬率8%、國庫券利率2%，風險溢酬即為6%。它是資本資產定價模型的核心，說明報酬與風險必須相稱。

(D)錯誤。風險係數如貝他值或標準差，是衡量資產風險大小的指標，用來解釋為何需要多少溢酬，本身不是報酬率的差額。

114年第3次｜投資學｜第 6 題
7. 甲公司發行一永續債券，票面利率為6%，每張面額10 萬元，若目前同類型債券可提供7%，請問其發行價格應為：
  1. (A)$85,714 元
  2. (B)$70,000 元
  3. (C)$80,000 元
  4. (D)$75,000 元
解析

(A)正確。永續債券沒有到期日，只是無限期支付固定利息，價值等於永續年金現值：價格＝每年利息÷市場利率。每年利息＝100,000×6%＝6,000元，市場利率7%，價格＝6,000÷0.07＝85,714元。因票面利率低於市場利率，債券須折價發行，投資人才能獲得與同類債券相當的7%報酬。

(B)錯誤。70,000元並非由題目資料計算得出，要讓6,000元的年息折現為70,000元，市場利率須約8.57%；把面額直接扣掉三成也會得到此數，但折價幅度必須由利息與市場利率之比決定，不是憑印象打折。

(C)錯誤。80,000元對應的市場利率為6,000÷80,000＝7.5%，題目給的是7%，並不吻合；若只是憑票面利率低於市場利率而粗估折價兩成，就會得到這個未經公式計算的數字。

(D)錯誤。75,000元是6,000÷0.08的結果，也就是誤把市場利率當成8%才會算出的價格；題目的市場利率是7%，正確折現後為85,714元。

114年第3次｜投資學｜第 7 題
8. 當發行公司預期市場呈下列何種趨勢時，將發行浮動利率債券來籌措資金？
  1. (A)利率上升
  2. (B)股價上漲
  3. (C)股價下跌
  4. (D)利率下跌
解析

(A)錯誤。預期利率上升時，發行浮動利率債券會使未來票息跟著上升，付息成本增加；此時公司應趁利率仍低發行固定利率債券鎖住成本，而不是選浮動利率。

(B)錯誤。股價上漲影響的是公司選擇以股權或可轉債籌資的意願，與債券票息採固定或浮動無關；浮動利率債券的決策取決於對利率走勢的預期。

(C)錯誤。股價下跌時公司可能避免增資而改用債務籌資，但這只決定籌資工具的類別，不決定票息形式；固定或浮動的選擇仍看利率預期，與股價無關。

(D)正確。浮動利率債券的票息隨市場指標利率定期重設，發行公司若預期利率將下跌，發行浮動利率債券可讓未來的付息成本隨利率下降而減少，比鎖定目前較高固定利率的成本更低。這是把利率風險留給自己承擔以換取預期成本下降，前提正是看跌利率。

114年第3次｜投資學｜第 8 題
9. 債券組合管理中的免疫策略（Immunization Strategies）可規避何種風險？
  1. (A)信用風險
  2. (B)流動性風險
  3. (C)利率風險
  4. (D)個別公司風險
解析

(A)錯誤。信用風險是發行人違約或信評下降造成的損失，與存續期間配對無關；免疫策略假設債券按約付息還本，無法防範違約，信用風險要靠分散持有與挑選信評來控制。

(B)錯誤。流動性風險是債券無法以合理價格迅速變現的風險，取決於市場交易深度，免疫策略只調整組合對利率的敏感度，不會改變債券的流動性。

(C)正確。免疫策略是使債券組合的存續期間與負債（或投資期限）的存續期間相等，讓利率變動時債券價格變動與利息再投資收益的變動互相抵銷，使組合到期時的價值不受利率升降影響。它針對的正是利率風險，也就是價格風險與再投資風險兩者的合成。

(D)錯誤。個別公司風險是特定發行人本身的非系統風險，透過分散投資才能降低；免疫策略不涉及分散或挑選個別發行人，而是處理整體利率變動對組合價值的影響。

114年第3次｜投資學｜第 9 題
10. 在S&P500 的採樣股中，市值愈大的股票，其價格波動對S&P500 指數的影響將如何？
  1. (A)愈小
  2. (B)沒影響
  3. (C)愈大
  4. (D)無法直接判斷
解析

(A)錯誤。「愈小」是價格加權或等權指數才可能出現的直覺：在等權指數裡每檔股票影響一樣，不會因市值而縮小；S&P500 以市值決定權重，大市值股票的影響只會放大。

(B)錯誤。任何採樣股的漲跌都會經由權重進入指數，只是幅度不同；「沒影響」等於說該股權重為零，與其被納入 S&P500 採樣的事實矛盾。

(C)正確。S&P500 是市值加權（實務上為公眾流通市值加權）指數，指數值等於各採樣股市值加總除以基期除數，因此某檔股票市值占比愈高，其價格變動對指數的貢獻愈大。這也是為什麼少數巨型權值股就能左右整體指數走勢。

(D)錯誤。既然編製方法明訂為市值加權，影響大小可直接由市值占比推得，並非無法判斷；「無法直接判斷」適用於題目未說明指數編製方式的情況。

11. 下列何者是行情多頭之訊號？
  1. (A)W 底
  2. (B)M 頭
  3. (C)寶塔線翻紅
  4. (D)價穩量縮
解析

(A)正確。W 底（雙重底）是股價兩次回測同一低點附近都獲得支撐、再向上突破頸線的底部反轉型態，代表賣壓在該價位已被消化，多方重新取得主導，屬於中期多頭訊號。型態完成的確認點是帶量突破頸線。

(B)錯誤。M 頭（雙重頂）是 W 底的鏡像：股價兩次挑戰同一高點都無法突破，跌破頸線後確認頭部成立，是空頭反轉訊號。

(C)錯誤。寶塔線翻紅只表示當日收盤價突破前幾日高點，是短線由跌轉漲的即時參考，容易反覆翻紅翻黑；它不像 W 底是經兩次測底確認的反轉型態，命題上以 W 底為典型多頭訊號。

(D)錯誤。價穩量縮通常解讀為籌碼沉澱、盤整或跌勢末期的觀察訊號，方向尚未確立；必須等到價漲量增才視為多頭啟動，本身不是多頭訊號。

114年第3次｜投資學｜第 13 題
14. 掌握底部量及頭部量，可用何項技術指標？
  1. (A)OBV
  2. (B)TAPI
  3. (C)平均量
  4. (D)ADL
解析

(A)錯誤。OBV（能量潮）是把每日成交量依收盤漲跌累加或累減的累積線，用來觀察量價是否背離、資金是否持續流入，它顯示的是累積方向，不直接呈現某段期間量能的絕對高低。

(B)錯誤。TAPI（每一加權指數點的成交值）是把總成交值除以加權指數點數，衡量指數每一點所需的資金，用來判斷人氣冷熱，不是辨識底部量或頭部量的工具。

(C)正確。平均量（成交量移動平均）把一段期間的成交量平滑後畫成基準線，當日成交量遠低於平均量即為底部量縮，遠高於平均量即為頭部爆量，因此是掌握底部量與頭部量的直接工具。底部量縮代表賣壓枯竭，頭部爆量代表籌碼大量換手，兩者都是趨勢可能反轉的量能徵兆。
