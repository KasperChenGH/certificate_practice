範例題目與解析（20 題）

1. 下列何者是行情多頭之訊號？
  1. (A)W 底
  2. (B)M 頭
  3. (C)寶塔線翻紅
  4. (D)價穩量縮
解析

(A)正確。W 底（雙重底）是股價兩次回測同一低點附近都獲得支撐、再向上突破頸線的底部反轉型態，代表賣壓在該價位已被消化，多方重新取得主導，屬於中期多頭訊號。型態完成的確認點是帶量突破頸線。

(B)錯誤。M 頭（雙重頂）是 W 底的鏡像：股價兩次挑戰同一高點都無法突破，跌破頸線後確認頭部成立，是空頭反轉訊號。

(C)錯誤。寶塔線翻紅只表示當日收盤價突破前幾日高點，是短線由跌轉漲的即時參考，容易反覆翻紅翻黑；它不像 W 底是經兩次測底確認的反轉型態，命題上以 W 底為典型多頭訊號。

(D)錯誤。價穩量縮通常解讀為籌碼沉澱、盤整或跌勢末期的觀察訊號，方向尚未確立；必須等到價漲量增才視為多頭啟動，本身不是多頭訊號。

114年第3次｜投資學｜第 11 題
2. 在其他條件不變下，當標的股票市價愈低時，則可轉換公司債的價值會：
  1. (A)愈低
  2. (B)愈高
  3. (C)不變
  4. (D)不一定
解析

(A)正確。可轉換公司債的價值可拆成純債券價值加上轉換選擇權價值；標的股價愈低，轉換價值（股價×轉換比率）愈低，轉換選擇權也愈價外，兩者都使可轉債價值下降。當股價跌到很低時，可轉債價值會趨近純債券價值形成下限，但方向仍是「愈低」。

(B)錯誤。「愈高」是股價上漲時的結果：股價上升使轉換價值提高，可轉債跟著上漲；與題目股價愈低的情境相反。

(C)錯誤。「不變」只有在轉換權完全沒有價值、可轉債等同純債券時才近似成立；一般情況下可轉債價格會隨標的股價變動，至少轉換選擇權的價值會受影響。

(D)錯誤。「不一定」適用於多個影響方向相反的因素同時變動，但題目已限定其他條件不變，僅股價變動，此時可轉債價值與股價同向，方向明確。

3. 某甲半年前買進了廣達股票1 張，每股成本為100 元，持股期間獲發股票股利5 元，目前股價為120 元，請問這半年以來某甲的投資報酬率為多少？(忽略交易成本)

(D)10%未考慮除權後股數倍增之效益。

115年第1次｜投資學｜第 3 題
4. 轉換公司債資產交換對證券商的優點，何者正確？甲.活絡證券商資金之運用；乙.承擔發行公司之信用風險以獲取較高收益
  1. (A)僅甲
  2. (B)僅乙
  3. (C)甲、乙皆正確
  4. (D)甲、乙皆不正確
解析

(A)正確。轉換公司債資產交換是證券商把持有的可轉債拆成兩部分：固定收益部分賣給偏好債息的投資人，證券商自己保留轉換權。這樣證券商不必把資金壓在整張可轉債上，收回的資金可以再運用，所以甲正確。乙則錯誤，因為發行公司的信用風險是隨固定收益部分移轉給交換對手承擔，證券商並非藉承擔信用風險來獲取較高收益。

(B)錯誤。乙把風險的移轉方向說反了：資產交換後，承擔發行公司違約風險並收取債息的是買下固定收益部分的交換對手，證券商反而是把信用風險移轉出去，只留下轉換權。

(C)錯誤。甲對證券商而言是正確的優點，但乙的敘述與資產交換的結構相反，證券商並沒有承擔發行公司信用風險，所以不能說兩者皆正確。

(D)錯誤。甲的敘述符合資產交換的用意，證券商透過出售固定收益部分釋出資金，確實達到活絡資金運用的效果，不能說兩者皆不正確。

115年第1次｜投資學｜第 24 題
5. 俊浩將其資金的35%投資於預期報酬率(expected rate of return)為0.18 且變異數(variance)為0.10之風險性資產(risky asset)，剩下的65%投資於報酬率為0.04 之國庫券。試問：該投資組合的預期報酬率(expected rate of return)及標準差(standard deviation)各為多少？
  1. (A)0.087；0.144
  2. (B)0.087；0.063
  3. (C)0.096；0.126
  4. (D)0.089；0.111
解析

(A)錯誤。預期報酬率0.087不等於0.35×0.18+0.65×0.04=0.089；標準差0.144需要約45%的風險資產權重(0.144÷0.3162)才會出現，與題目35%的權重不符。

(B)錯誤。預期報酬率0.087同樣不是正確的加權結果；0.063只是0.35×0.18，也就是風險資產對預期報酬率的貢獻，並不是投資組合的標準差。

(C)錯誤。預期報酬率0.096高於正確的0.089，等於給風險資產過高的權重；標準差0.126對應約40%的風險資產權重(0.126÷0.3162)，也與35%不符。

(D)正確。投資組合預期報酬率是各資產報酬率的加權平均：0.35×0.18+0.65×0.04=0.063+0.026=0.089。國庫券是無風險資產，標準差為0且與風險資產無共變，因此投資組合標準差=風險資產權重×風險資產標準差=0.35×√0.10=0.35×0.3162≈0.111。這正是資本配置線的性質：風險與報酬都隨風險資產權重呈直線變動。

115年第1次｜投資學｜第 44 題
6. 下列敘述何者不是道氏理論的缺點？
  1. (A)技術指標有鈍化的現象
  2. (B)道氏理論的買賣訊號往往落後於大盤約20%至25%
  3. (C)道氏理論只告訴投資人市場趨勢，不能告訴投資人買進何種股票
  4. (D)投資人不能接受指數將反映所有的新聞和統計的基本觀念
解析

(A)正確（即非其缺點者）。鈍化是KD、RSI等有上下限的技術指標在極端行情下的現象，道氏理論談的是趨勢的三種級數與確認原則，並不產生指標值，自然無鈍化問題。

(B)錯誤。訊號落後於大盤相當幅度，確實是道氏理論常被指出的缺點。

(C)錯誤。只指出市場整體趨勢、無法選股，確實是道氏理論的侷限。

(D)錯誤。其前提假設指數已反映所有訊息，不被部分投資人接受，屬其受質疑之處。

115年第2次｜投資學｜第 17 題
7. 使用反向策略可以獲得超額報酬的假設原因為：
  1. (A)市場反應過度
  2. (B)市場反應不足
  3. (C)報酬不具可預測性
  4. (D)投資人的不理性行為是隨機的
解析

(A)正確。反向策略買進過去輸家、賣出過去贏家，其獲利前提是市場對消息反應過度，價格偏離基本價值後會反轉修正。

(B)錯誤。反應不足是動能策略（順勢操作）能獲利的假設，方向相反。

(C)錯誤。若報酬完全不可預測，任何策略都無法系統性獲得超額報酬。

(D)錯誤。若不理性行為純屬隨機，將互相抵消而不會形成可利用的價格偏誤。

114年第3次｜財務分析｜第 36 題
10. 某機器設備定價$1,000,000，購入時現金折扣為$50,000，支付運費$40,000，安裝費$80,000，搬運不慎發生損壞而付出修理費$20,000，則該機器設備之帳面成本應為：
  1. (A)$1,000,000
  2. (B)$1,050,000
  3. (C)$1,070,000
  4. (D)$1,090,000
解析

(A)錯誤。$1,000,000 只是定價，既沒有扣掉實際少付的現金折扣 $50,000，也沒有加上使設備達到可用狀態必要的運費與安裝費，不是取得成本。

(B)錯誤。$1,050,000 是 $1,070,000 再減掉修理費 $20,000，或是把折扣 $50,000 誤當加項的結果；修理費既不資本化也不從成本扣除，它是當期費用。

(C)正確。設備成本包含使資產達到可供使用狀態前一切必要而合理的支出：定價 $1,000,000 減現金折扣 $50,000，加運費 $40,000，加安裝費 $80,000，等於 $1,070,000。搬運不慎造成的修理費 $20,000 不是取得資產所必要的支出，屬損失或當期費用，不能資本化。

(D)錯誤。$1,090,000 是把修理費 $20,000 也加進成本，但資本化只限必要支出，因過失造成的損壞修復不會增加設備的價值或效益，應直接列為當期費用。

115年第1次｜財務分析｜第 9 題
11. 母公司和子公司相互間持有債券，在合併報表中的處理方式為：
  1. (A)視為發行公司收回債券處理
  2. (B)不需要作任何沖銷，但合併報表中仍會出現債券項目
  3. (C)以上(A)、(B)選項都有可能，視債券發行公司為母公司或子公司而定
  4. (D)將債券列為權益的一部分
解析

(A)正確。合併報表把母子公司視為單一經濟個體，集團內一方發行、另一方持有的債券，從集團角度看就是自己買回了自己發行的債券，因此視同發行公司收回債券處理：沖銷應付公司債與債券投資，購買價格與債券帳面金額的差額認列為推定贖回損益。這樣才不會讓集團對自己的債權債務出現在合併報表上。

(B)錯誤。不沖銷會使合併資產負債表同時出現集團對自己的債券投資與應付公司債，虛增資產與負債，違反合併報表消除內部交易的基本原則。

(C)錯誤。無論發行者是母公司或子公司，合併時都必須沖銷，沒有例外；發行方是誰只影響推定贖回損益歸屬於母公司股東或非控制權益的分攤，不影響是否沖銷。

(D)錯誤。債券是負債工具，即使在集團內部持有也不會變成權益；合併處理是把它消除，而不是重分類為權益。

14. 關於審計委員會之獨立董事成員職權，下列敘述何者正確？

  2. (B)得以單獨召集股東會

16. 發行人公告申報之財務報告主要內容有虛偽之情事者，對所發行證券之善意取得人、出賣人因而所受之損害負賠償責任，但下列何者得舉證免責？
  1. (A)發行人之董事長
  2. (B)發行人之總經理
  3. (C)簽證會計師
  4. (D)發行人之會計主管
解析

(A)錯誤。董事長是發行人的代表負責人，財務報告須由其簽名或蓋章，證券交易法第20條之1將其列為與發行人並列的第一順位賠償義務人，本題的命題立場是董事長不得以已盡注意為由免責（104年修法後已改採推定過失責任，得舉證免責）。

(B)錯誤。總經理與董事長同為在財務報告上簽章的經營負責人，命題立場是其與發行人同負責任，不得舉證免責；簽證會計師則因是外部專業人員而有不同的責任基礎。

(C)正確。財務報告不實的民事責任由證券交易法第20條之1規範，發行人負無過失責任，董事長、總經理與簽章的會計主管傳統上被視為公司內部的主要責任人；簽證會計師是外部專業第三人，其責任以有不正當行為或違反、廢弛業務上應盡之義務為前提，因此得舉證已依審計準則盡專業注意而免責。須留意104年修正後，第20條之1第2項已改為除發行人外之各款人（含董事長、總經理、簽章職員）均得證明已盡相當注意而免責，本題係以會計師為唯一得舉證免責者的傳統命題方式作答。

(D)錯誤。會計主管是在財務報告上簽名或蓋章的公司職員，屬證交法第20條之1第1項第2款的責任人，本題將其歸為與董事長、總經理相同的公司內部責任人，不是得舉證免責的外部簽證會計師。

17. 下列何者得擔任境外基金之總代理人？ 甲、證券投資信託事業；乙、證券投資顧問事業；丙、證券經紀商；丁、信託業

  2. (B)僅甲、乙、丙
  3. (C)僅甲、乙
  4. (D)甲、乙、丙、丁皆可
解析

(A)錯誤。此組漏掉證券投資信託事業。投信事業本身就是募集及經理基金的專業機構，是最典型的境外基金總代理人，許多國內投信即代理其集團的境外基金。

(B)正確。境外基金管理辦法規定，境外基金機構應委任單一總代理人在國內代理其基金的募集及銷售，而得擔任總代理人者為證券投資信託事業、證券投資顧問事業及證券經紀商。總代理人要對境外基金在國內的募集、銷售、資訊揭露與投資人服務負責，因此限於受投信投顧法或證交法監理、具備基金業務能力的三類機構。

(D)錯誤。信託業不得擔任境外基金總代理人。信託業是依特定金錢信託契約受託投資境外基金，扮演的是銷售機構或受託人的角色，適用的是辦法中對銷售機構的相關規定，而非總代理人資格。

  3. (C)三年
  4. (D)五年
解析

  2. (B)五十人
  3. (C)九十九人
  4. (D)七十人

(B)錯誤。五十人並不是私募股權基金引介業務所採的人數門檻；若以五十人為限，可參與的高資產客戶將縮減近半，與主管機關參照私募基金九十九人上限的設計不符。

(C)正確。證券商引介高資產客戶投資其子公司擔任普通合夥人或受託管理之私募股權基金，每一基金之高資產客戶人數總數不得超過九十九人。此數字對齊證券投資信託及顧問法私募基金應募人不得超過九十九人的上限，目的在維持「私募」性質，避免透過引介變相對不特定多數人銷售。金管會近期已研議放寬此人數限制，作答時仍以九十九人為準。

(D)錯誤。七十人並非任何私募相關規範所採的人數上限；私募制度以九十九人為界，七十人既非證交法私募的三十五人，也非投信投顧法私募基金的九十九人。
