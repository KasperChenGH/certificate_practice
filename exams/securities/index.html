1. 有一投資組合過去10 年的平均年報酬率為12%，標準差為50%，無風險利率為4%，貝它係數為1.2，請試算其夏普指數為多少？
  1. (A)0.8
  2. (B)0.16
  3. (C)1.6
  4. (D)1.25
解析

(A)錯誤。0.8是把超額報酬8%除以10%的結果，等於把標準差50%誤看成10%（或誤用10年的年數作分母）；夏普指數的分母必須是投資組合報酬的標準差50%。

(B)正確。夏普指數＝（投資組合平均報酬－無風險利率）÷報酬標準差＝（12%－4%）÷50%＝0.16。它衡量每承擔一單位總風險所獲得的超額報酬，分母用標準差而非貝它，因此貝它1.2在此題是多餘資訊，只有計算崔納指數時才用得到。

(C)錯誤。1.6是把標準差50%誤讀為5%後以8%÷5%所得，小數點位置錯了一位。

(D)錯誤。1.25並非以此題數據代入夏普公式能得到的結果；若改以貝它為分母，8%÷1.2＝0.067是崔納指數，也不會得到1.25。

2. 下列敘述何者為非？
  1. (A)損失規避是指個體會避免損失，因為損失的痛苦程度大於同等金額利得所帶來的滿足程度
  2. (B)過度自信是指投資人高估自己的過去績效，因而不願意處理績效不佳的投資決策
  3. (C)可取性捷思(availability heuristic)是指容易令人聯想到的事件會讓人誤以為這個事件常常發生
  4. (D)小數法則(law of small numbers)是指人們誤以為小樣本下也能代表整體結果
解析

(A)錯誤。此敘述正確：損失規避即損失帶來的痛苦大於等額利得的快樂。

(B)正確（即敘述有誤者）。所述「不願處理績效不佳的投資」是處分效果或後悔規避的內容；過度自信指的是投資人高估自身能力與資訊的準確度，因而過度交易、低估風險。

(C)錯誤。此敘述正確：可取性捷思即以易於回想的程度取代真實發生機率。

(D)錯誤。此敘述正確：小數法則指誤把小樣本結果當作母體的代表。

3. 有關證券商經營特定外國債券業務，以下哪些債券可列入特定外國債券範圍？ 甲.信用評等一定等級以上之外國中央政府債券 乙.信用評等一定等級以上之外國公司債券 丙.可轉換公司債丁.不動產抵押貸款債券
  1. (A)僅甲
  2. (B)僅甲、乙
  3. (C)僅甲、乙、丙
  4. (D)甲、乙、丙、丁皆可
解析

(A)錯誤。特定外國債券不限於外國中央政府債券；信用評等達一定等級的外國公司債券同樣列入，只納入甲過於狹隘。

(B)正確。證券商經營特定外國債券業務，其範圍為信用評等達一定等級以上之外國中央政府債券與外國公司債券。篩選標準在於信用品質與商品結構單純，故以評等作門檻並排除含權或結構型債券，以控制投資人承擔的風險。

(C)錯誤。可轉換公司債含股權轉換條款，價格同時受股價與利率影響，屬股債混合商品，不在特定外國債券範圍內。

(D)錯誤。不動產抵押貸款債券是以貸款組合現金流支撐的結構型商品，有提前還款與信用分層風險，評估複雜，不列入特定外國債券。

4. 根據IFRS 3，廉價購買利益應如何處理？
  1. (A)認列為當期損益
  2. (B)計入其他綜合損益
  3. (C)計入資本公積
  4. (D)作為商譽的一部分
解析

(A)正確。廉價購買利益＝取得之可辨認淨資產公允價值超過收購對價的差額。IFRS 3規定收購者應先重新評估所有可辨認資產、負債與對價的衡量是否正確，確認後將該利益於收購日認列為當期損益。要求先重評估，是因為「買便宜」通常源於衡量錯誤，只有賣方被迫出售等情況才會真正發生。

(B)錯誤。其他綜合損益用於FVOCI金融資產、資產重估增值、外幣換算差額等特定項目，廉價購買利益不在其中，IFRS 3明定它進入損益表。

(C)錯誤。資本公積來自股東的投入（如股票發行溢價），不是企業活動產生的利得；廉價購買利益是收購交易的結果，與股東投入無關，不能繞過損益表直接列入權益。

(D)錯誤。商譽是收購對價「超過」可辨認淨資產公允價值的部分，是一項資產；廉價購買利益方向相反（對價低於淨資產），兩者不會同時存在，也不能以負商譽的形式列在資產項下。

5. 何者「不是」用來衡量投資風險的方法？
  1. (A)全距(Range)
  2. (B)β係數
  3. (C)變異數
  4. (D)算術平均數
解析

(A)錯誤。全距為最大值減最小值，是衡量報酬分散程度的簡易風險指標。

(B)錯誤。β係數衡量個股相對市場的系統風險。

(C)錯誤。變異數是報酬率離散程度的標準衡量，為風險的基本定義。

(D)正確。算術平均數描述報酬的中心位置（期望報酬），不含離散程度的資訊，屬報酬面而非風險面的統計量。風險衡量的重點在於分散度或對市場的敏感度。

6. 由無風險利率和風險溢酬組成，描述預期報酬率和多個因子存在線性關係的理論是：
  1. (A)套利定價理論(Arbitrage Pricing Theory)
  2. (B)投資組合理論(Portfolio Theory)
  3. (C)資本資產定價模式(Capital Asset Pricing Model)
  4. (D)效率市場理論(Efficient Market Theory)
解析

(A)正確。套利定價理論（APT）將預期報酬率表示為無風險利率加上多個系統性因子各自的風險溢酬，且與因子敏感度呈線性關係。它不需要市場組合與投資人效用的假設，只以無套利條件推導，因此比CAPM更有彈性，是多因子模型的理論基礎。

(B)錯誤。投資組合理論（Markowitz）討論在平均數與變異數架構下如何分散風險與建構效率前緣，並不提供報酬與因子之間的定價關係。

(C)錯誤。CAPM同樣是無風險利率加風險溢酬的線性式，但只有市場風險單一因子（貝它）；題目強調「多個因子」，指的是APT。

(D)錯誤。效率市場理論探討價格是否充分反映資訊，屬市場資訊效率的假說，不涉及預期報酬的因子結構。

7. 證券商除由金融機構兼營者依有關法令規定外，其經營自行買賣有價證券業務者，持有任一本國公司股份之總額不得超過該公司已發行股份總額之___；持有任一本國公司所發行有價證券之成本總額，並不得超過該證券商淨值之___。
  1. (A)5%；10%
  2. (B)5%；20%
  3. (C)10%；15%
  4. (D)10%；20%
解析

(A)錯誤。5%與10%都不是證券商管理規則第19條所定的搭配；5%是證券交易法第43條之1大量持股申報的門檻，與自營部位的持股上限無關，淨值10%也低於規則所定的20%。

(B)錯誤。淨值20%的部分正確，但持有任一本國公司股份的上限是該公司已發行股份總額的10%而非5%；5%是大量持股申報門檻，不是自營持股上限。

(C)錯誤。持股比例上限10%正確，但單一發行人有價證券成本總額對證券商淨值的上限是20%而非15%；兩個數字要同時符合第19條才對。

(D)正確。證券商管理規則第19條規定，經營自行買賣有價證券業務的證券商，持有任一本國公司股份之總額不得超過該公司已發行股份總額之百分之十；持有任一本國公司所發行有價證券之成本總額，不得超過該證券商淨值之百分之二十。前者防止券商藉自營部位介入他公司經營權，後者控管單一發行人的集中度風險，避免一家公司出事就拖垮券商淨值。

答案為官方標準答案；以上解析由 AI 撰寫，非官方解析，僅供理解參考。

8. 公開收購人與其關係人於公開收購後，所持有被收購公司已發行股份總數超過該公司已發行股份總數比率達多少者，得以書面請求董事會召集股東臨時會，不受公司法規定之限制？
  1. (A)10%
  2. (B)20%
  3. (C)30%
  4. (D)50%
解析

(A)錯誤。百分之十是證券交易法第四十三條之一取得公開發行公司股份達百分之十須向主管機關申報的門檻，與召集股東臨時會無關。

(B)錯誤。百分之二十是強制公開收購的門檻，預定於五十日內取得已發行股份百分之二十以上者應採公開收購方式，不是請求召集股東臨時會的持股比率。

(C)錯誤。百分之三十並非證券交易法所設的持股門檻；持有三成尚未過半，仍未取得公司控制權，不足以排除公司法對召集股東會的限制。

(D)正確。依證券交易法第四十三條之五，公開收購人與其關係人於公開收購後持有被收購公司已發行股份總數超過百分之五十者，得以書面記明提議事項及理由，請求董事會召集股東臨時會，不受公司法第一百七十三條第一項持股期間與比率的限制。取得過半數即已掌握控制權，讓其得儘速改組董事會，可避免經營權懸空期間過長。

1. 下列何者是行情多頭之訊號？
  1. (A)W 底
  2. (B)M 頭
  3. (C)寶塔線翻紅
  4. (D)價穩量縮
解析

(A)正確。W 底（雙重底）是股價兩次回測同一低點附近都獲得支撐、再向上突破頸線的底部反轉型態，代表賣壓在該價位已被消化，多方重新取得主導，屬於中期多頭訊號。型態完成的確認點是帶量突破頸線。

(B)錯誤。M 頭（雙重頂）是 W 底的鏡像：股價兩次挑戰同一高點都無法突破，跌破頸線後確認頭部成立，是空頭反轉訊號。

(C)錯誤。寶塔線翻紅只表示當日收盤價突破前幾日高點，是短線由跌轉漲的即時參考，容易反覆翻紅翻黑；它不像 W 底是經兩次測底確認的反轉型態，命題上以 W 底為典型多頭訊號。

(D)錯誤。價穩量縮通常解讀為籌碼沉澱、盤整或跌勢末期的觀察訊號，方向尚未確立；必須等到價漲量增才視為多頭啟動，本身不是多頭訊號。

115年第1次｜法規與實務｜第 11 題
18. 證券投資信託事業募集之基金，投資於任一公司所發行無擔保公司債之總額，不得超過該公司所發行無擔保公司債總額之多少？
  1. (A)3%
  2. (B)5%
  3. (C)10%
  4. (D)15%
解析

(A)錯誤。百分之三不是管理辦法對無擔保公司債的比率。若上限只有百分之三，基金幾乎無法有意義地配置公司債部位，管理辦法對此類集中度限制設定的是百分之十。

(B)錯誤。百分之五不是無擔保公司債的上限。管理辦法對基金投資的分散規範有多項不同比率，但就任一公司所發行無擔保公司債總額的比率而言，規定為百分之十。

(C)正確。證券投資信託基金管理辦法規定，每一基金投資於任一公司所發行無擔保公司債之總額，不得超過該公司所發行無擔保公司債總額之百分之十。無擔保公司債沒有擔保品，違約時回收率低，限制基金對單一發行人此類債券的持有比率，是為了分散信用風險，避免單一公司違約重創基金淨值。

(D)錯誤。百分之十五超過管理辦法所定的百分之十。無擔保公司債的信用風險高於有擔保債券，允許基金持有單一公司無擔保公司債總額的一成半，會使基金對該公司的違約暴露過大。

115年第1次｜法規與實務｜第 34 題
19. 上市公司每年年度稽核計畫，應包括下列哪項管理？
  1. (A)薪資報酬委員會運作之管理
  2. (B)審計委員會議事運作之管理
  3. (C)永續資訊之管理
  4. (D)選項(A)(B)(C)皆是
解析

(A)錯誤。薪資報酬委員會運作之管理確實是上市上櫃公司年度稽核計畫應納入的項目（公開發行公司建立內部控制制度處理準則第13條），但同條還要求納入審計委員會議事運作與永續資訊之管理，單選此項不完整。

(B)錯誤。設有審計委員會的公司，年度稽核計畫應包含審計委員會議事運作之管理，這是準則第13條的明文要求；但薪資報酬委員會運作與永續資訊管理也同樣列入，不應只選此項。

(C)錯誤。永續資訊之管理是準則第13條近年增列、上市櫃公司年度稽核計畫應納入的項目，反映永續報告書的資訊須有內控可稽；但它與另外兩項並列，並非唯一。

(D)正確。公開發行公司建立內部控制制度處理準則第13條規定，年度稽核計畫應包括法令遵循、重大財務業務行為控制作業、對子公司之監督、董事會議事運作、財報編製流程、資通安全檢查與重要營運循環；設審計委員會者加列審計委員會議事運作之管理，上市櫃公司再加列薪資報酬委員會運作之管理與永續資訊之管理。三者都是公司治理與資訊揭露的內控環節，故皆應納入。
