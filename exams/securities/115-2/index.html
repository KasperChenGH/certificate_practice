2. 下列有關可轉換公司債的敘述何者有誤？
  1. (A)發行公司發行可轉換公司債可以減少利息費用
  2. (B)發行之後，轉換價格就不會再變動
  3. (C)可轉換公司債投資人可於股價上漲時用約定「轉換價格」將債券轉換為股票
  4. (D)可轉換公司債的受償順序優先於股東
解析

(C)錯誤。此敘述正確：股價上漲超過轉換價格時，投資人可依約定轉換價格換成股票獲利。

(D)錯誤。此敘述正確：可轉債本質為公司債，清償順序優先於股東。

3. 何者「不是」用來衡量投資風險的方法？
  1. (A)全距(Range)
  2. (B)β係數
  3. (C)變異數
  4. (D)算術平均數
解析

(A)錯誤。全距為最大值減最小值，是衡量報酬分散程度的簡易風險指標。

(B)錯誤。β係數衡量個股相對市場的系統風險。

(C)錯誤。變異數是報酬率離散程度的標準衡量，為風險的基本定義。

(D)正確。算術平均數描述報酬的中心位置（期望報酬），不含離散程度的資訊，屬報酬面而非風險面的統計量。風險衡量的重點在於分散度或對市場的敏感度。

4. 下列有關基金之敘述何者正確？甲.開放型基金期限和規模不固定；乙.封閉型基金則是以淨值贖回，所以不會有折價之現象；丙.投資保本型基金最少可以領回全部本金；丁.指數型基金的績效與大盤股價指數有一致性
  1. (A)僅甲、丁
  2. (B)僅乙、丁
  3. (C)甲、乙、丁
  4. (D)甲、乙、丙
解析

(A)正確。甲：開放型基金可隨時申購與贖回，規模隨資金進出變動，通常也沒有固定的存續期限。丁：指數型基金以複製追蹤指數為目標，報酬與大盤指數走勢一致。乙、丙皆為錯誤敘述，故只有甲、丁正確。

(B)錯誤。乙不成立：封閉型基金發行後不接受贖回，投資人須在集中市場依供需價格買賣，市價常低於淨值形成折價；「以淨值贖回」描述的是開放型基金。

(C)錯誤。此組合納入了乙；封閉型基金的市價與淨值可以脫節，折價現象正是封閉型基金的典型特徵，並非不會發生。

(D)錯誤。乙、丙皆不成立：丙的保本型基金保本比率依契約約定，可能低於100%，且通常須持有至到期才享有保本，提前贖回未必能領回全部本金。

115年第2次｜投資學｜第 4 題
5. 有一投資組合過去10 年的平均年報酬率為12%，標準差為50%，無風險利率為4%，貝它係數為1.2，請試算其夏普指數為多少？
  1. (A)0.8
  2. (B)0.16
  3. (C)1.6
  4. (D)1.25
解析

(A)錯誤。0.8是把超額報酬8%除以10%的結果，等於把標準差50%誤看成10%（或誤用10年的年數作分母）；夏普指數的分母必須是投資組合報酬的標準差50%。

(B)正確。夏普指數＝（投資組合平均報酬－無風險利率）÷報酬標準差＝（12%－4%）÷50%＝0.16。它衡量每承擔一單位總風險所獲得的超額報酬，分母用標準差而非貝它，因此貝它1.2在此題是多餘資訊，只有計算崔納指數時才用得到。

(C)錯誤。1.6是把標準差50%誤讀為5%後以8%÷5%所得，小數點位置錯了一位。

(D)錯誤。1.25並非以此題數據代入夏普公式能得到的結果；若改以貝它為分母，8%÷1.2＝0.067是崔納指數，也不會得到1.25。

8. 假設有一債券的存續期間為10，當時的殖利率(YTM)為5%，請問當其YTM 變動1bp 時，該債券價格變動的百分比為何？
  1. (A)10%
  2. (B)200%
  3. (C)0.072468%
  4. (D)0.095238%
解析

(A)錯誤。10%是直接把存續期間10當成價格變動率，漏掉了殖利率變動幅度；1bp只有0.01%，價格變動必須再乘以這個幅度。

(B)錯誤。200%沒有任何合理計算可得；1bp的利率變動只能造成不到0.1%的價格變動，這個數量級明顯不合理。

(C)錯誤。0.072468%無法由存續期間10、殖利率5%與變動1bp代入任何公式得到，不是此題數據可推導的結果。

(D)正確。價格對殖利率的敏感度是修正存續期間＝麥考利存續期間÷(1+YTM)＝10÷1.05＝9.5238；殖利率變動1bp＝0.0001，價格變動百分比≈9.5238×0.0001＝0.095238%，殖利率上升則價格下跌。先除以(1+YTM)是關鍵步驟，因為麥考利存續期間是現金流的加權平均期限，須轉成修正存續期間才是價格對殖利率的彈性。

115年第2次｜投資學｜第 8 題
9. 在利率期限結構中的市場區隔理論(Market Segmentation Theory)中，理論上如果長期利率下跌，則短期利率將：
  1. (A)上漲
  2. (B)不受影響
  3. (C)下跌
  4. (D)選項(A)(B)(C)皆非
解析

(A)錯誤。市場區隔理論下長短期市場各自獨立，長期利率下跌不會反向推升短期利率。

(B)正確。市場區隔理論主張長期與短期資金的供給者與需求者屬不同族群，期限之間不可替代，各期限利率由該期限市場自身的供需決定，因此長期利率的變動理論上不影響短期利率。

(C)錯誤。認為長短期利率會同向連動，是預期理論或流動性偏好理論的推論，不是市場區隔理論。

(D)錯誤。本題在市場區隔理論下有明確結論，即短期利率不受影響。

115年第2次｜投資學｜第 9 題
10. 在債券評等中，下列哪一等級以下(不含)是Moody's 債券評等為垃圾債券(Junk Bond)？
  1. (A)Baa
  2. (B)Ba
  3. (C)B
  4. (D)Caa
解析

(A)正確。Moody's評等以Baa（含Baa3）為投資等級的最低一級，Baa以下不含Baa的Ba、B、Caa、Ca、C皆屬投機級，即所謂垃圾債券。這條界線重要，是因為許多退休基金與保險公司依規定只能持有投資等級債券，一旦評等跌破Baa便會被迫出售，債券價格往往因此重挫。

(B)錯誤。Ba是投機級的第一級，本身已屬垃圾債券，不是投資等級的最低一級；題目問的是分界所在的等級。

(C)錯誤。B等級比Ba更差，已深入投機級，若以B為分界會把Ba誤歸為投資等級。

(D)錯誤。Caa是違約風險甚高的高度投機級，遠在投資等級的界線之下，不可能是分界點。
