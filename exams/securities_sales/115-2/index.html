3. 公開發行公司內部稽核單位作成之稽核報告、工作底稿及相關資料應至少保存幾年？
  1. (A)3 年
  2. (B)4 年
  3. (C)5 年
  4. (D)7 年

(A)錯誤。三年短於公開發行公司建立內部控制制度處理準則所定的最低年限。稽核報告是主管機關事後查核內控是否落實的證據，若只留三年，前一個三年期稽核循環的底稿可能已銷毀，缺失的追蹤脈絡便中斷。

(B)錯誤。四年並非該準則所採的年限，也沒有其他證券法規以四年作為文件保存期間。保存年限通常對齊查核與追訴的時間跨度，四年既短於準則要求，也對不上任何配套規定。

(C)正確。依公開發行公司建立內部控制制度處理準則，內部稽核單位作成之稽核報告、工作底稿及相關資料應至少保存五年，內控自行評估之工作底稿及報告亦同。設定最低年限是讓主管機關檢查或追究違規時仍有完整稽核軌跡可查，五年大致涵蓋一個完整的查核與追訴週期。

(D)錯誤。七年長於準則要求。準則寫的是「至少」五年，公司自願保存七年並不違法，但題目問的是法定最低保存年限，答案應取五年而非更長的年限。

4. 上市公司買回股份之數量比例，不得超過該公司已發行股份總數多少比例？
  1. (A)百分之五
  2. (B)百分之十
  3. (C)百分之十五
  4. (D)百分之二十
解析

(A)錯誤。百分之五低於證券交易法第二十八條之二所定的上限。若上限只有百分之五，公司為員工認股、轉換公司債換股或護盤所能買回的數量會少一半，與現行規定不符；百分之五在證交法中另是第四十三條之一大量持股申報的門檻。

(B)正確。依證券交易法第二十八條之二第二項，上市上櫃公司買回股份之數量比例不得超過已發行股份總數百分之十，且收買總金額不得逾保留盈餘加發行股份溢價及已實現資本公積之金額。設有數量與金額雙重上限，是因為買回股份等於以公司資產減少流通在外股數，過度買回會掏空資本並損及債權人與其他股東。

(C)錯誤。百分之十五超過法定上限。若公司可買回一成半的股份，將動用相當可觀的公司資產，數量上限正是要防止經營者以庫藏股名義大幅減資或操縱股價，證交法把數量限制在百分之十。

(D)錯誤。百分之二十是法定上限的兩倍，並非庫藏股規定所採的比例。百分之二十在證交法體系中出現於強制公開收購的門檻（預定於一定期間內取得公司股份達百分之二十以上者應採公開收購），與買回自家股份的數量限制是不同的制度。

5. 某證券商流動資產為二十億元，則其流動負債不得超過多少元？
  1. (A)10 億元
  2. (B)12 億元
  3. (C)18 億元
  4. (D)20 億元
解析

(A)錯誤。流動負債僅十億元時，流動比率為二十億除以十億等於百分之二百，遠優於規定要求。證券商管理規則只要求流動負債總額不得超過流動資產總額，並未要求流動資產須達負債的兩倍，十億元不是法規推得的上限。

(B)錯誤。十二億元對應的流動比率約為百分之一百六十七，仍高於規定的最低標準。這個數字沒有任何法規依據，是把「不得超過」的界線設得比證券商管理規則更嚴，題目問的是法規所容許的最大值。

(C)錯誤。十八億元對應的流動比率約為百分之一百一十一，雖然比規定寬鬆的界線更保守，但仍不是法規所定的上限。證券商管理規則的界線正好落在流動負債等於流動資產處，因此可容許的流動負債可以到二十億元。

(D)正確。證券商管理規則第十三條規定，證券商流動負債總額不得超過其流動資產總額，即流動比率至少須維持百分之百。流動資產二十億元時，流動負債上限就是二十億元。此規範確保證券商隨時有足夠的可變現資產應付對客戶與交割的即期債務；同條並另有對外負債總額不得超過淨值一定倍數的限制。

6. 依「公司法」規定，公司虧損達實收資本額____時，董事會應於最近一次股東會報告？
  1. (A)三分之二
  2. (B)二分之一
  3. (C)三分之一
  4. (D)四分之一
解析

(A)錯誤。三分之二是公司法中股東會特別決議常見的出席門檻，並不是虧損報告的觸發比例。若要等虧損吃掉三分之二資本才報告，股東知悉時公司財務可能已接近資不抵債，喪失預警功能。

(B)正確。公司法第二百十一條第一項規定，公司虧損達實收資本額二分之一時，董事會應於最近一次股東會報告；同條第二項並規定資產顯有不足抵償債務時，除依重整規定辦理外，董事會應即聲請宣告破產。以半數資本為警戒線，是讓股東在公司尚有半數資本可運用時就能決定增資、改組或止損。

(C)錯誤。三分之一比法定門檻更早觸發，若採此比例董事會會更頻繁地被要求向股東會報告，但公司法並未採如此保守的標準，而是以實收資本額的一半作為警訊。

(D)錯誤。四分之一的虧損在許多產業景氣循環中屬常見範圍，公司法並未將其列為必須向股東會報告的法定事由；法定的報告義務是在虧損達實收資本額二分之一時才發生。

8. 下列何者係屬取得之股票非證券交易法第一百五十七條第一項所定「取得」之範圍，故不列入歸入利益之情形？
  1. (A)受讓公司之庫藏股或行使可轉換公司債之轉換權而取得之公司股票
  2. (B)發行股票公司董事對公司之上巿股票，於取得後六個月內再行賣出，因而獲得利益者
  3. (C)發行股票公司監察人對公司之上巿股票，於賣出後六個月內再行買進，因而獲得利益者
  4. (D)持有公司股份超過百分之十之股東，對公司之上巿股票，於取得後六個月內再行賣出，因而獲得利益者
解析

(A)正確。依主管機關解釋，內部人受讓公司庫藏股或行使可轉換公司債轉換權而取得之股票，並非證券交易法第一百五十七條第一項所稱之「取得」，故其後六個月內賣出不列入歸入利益。歸入權要防止的是內部人利用資訊優勢在市場上短線進出獲利，這類基於公司既定安排或既有權利的取得，價格與時點都不是內部人自行選擇，沒有短線套利的疑慮。

(B)錯誤。董事對公司上市股票於取得後六個月內再行賣出而獲利，正是證券交易法第一百五十七條第一項規定公司應請求歸入利益的典型情形，並不在排除之列。

(C)錯誤。監察人於賣出後六個月內再行買進而獲利，同樣在第一百五十七條第一項的文字範圍內（「取得後六個月內再行賣出，或於賣出後六個月內再行買進」），先賣後買與先買後賣都受歸入權規範。

(D)錯誤。持有公司股份超過百分之十之股東，與董事、監察人、經理人並列為第一百五十七條的規範對象，其取得後六個月內賣出獲利應歸入公司，不因其非公司職務人員而排除。

10. 上市公司有何項情事，得經董事會三分之二以上董事之出席及出席董事超過二分之一同意，於有價證券集中交易市場買回其股份？

  4. (D)選項(A)(B)(C)皆是
解析

(A)錯誤。轉讓股份予員工是證券交易法第二十八條之二第一項第一款所列的買回事由，但只是三款事由之一，單選此項會漏掉其餘兩款。

(B)錯誤。配合附認股權公司債、可轉換公司債等之發行作為股權轉換之用，是同條項第二款的事由，同樣只涵蓋部分情形，並非唯一得買回的事由。

(C)錯誤。為維護公司信用及股東權益所必要而買回並辦理銷除股份，是同條項第三款的事由；此款買回的股份須辦理變更登記銷除，而非留作轉讓，但它仍只是三款之一。

(D)正確。證券交易法第二十八條之二第一項列舉三款得買回股份的事由：轉讓予員工、配合股權轉換證券之發行、為維護公司信用及股東權益而買回並銷除，均須經董事會三分之二以上董事出席及出席董事超過二分之一同意。以列舉方式限定用途，是因為買回自家股票會減少公司資產並可能影響股價，不能任由經營者以其他理由動用。

11. 甲證券經紀商現行實收資本額為二億元，其欲增加四家分公司，則該證券商「最低實收資本額」及「營業保證金」須增加之總額合計為多少？
  1. (A)一億四千萬元
  2. (B)一億五千萬元
  3. (C)一億六千萬元
  4. (D)一億七千五百萬元
解析

(A)正確。證券商設置標準第二十一條規定每設置一家分支機構最低實收資本額應增加三千萬元；證券商管理規則第九條規定每設置一家分支機構應增提營業保證金五百萬元。四家分公司即三千萬乘四得一億二千萬元，加上五百萬乘四得二千萬元，合計一億四千萬元。資本與保證金按據點逐家加計，反映每個營業據點都會帶來新的客戶交割與賠償風險。

  1. (A)股票分割的目的是為了便於流通
  2. (B)股票股利不改變股票面額
  3. (C)股票股利使得股本增加
  4. (D)股票股利與股票分割皆不用作分錄
解析

(A)錯誤。此敘述正確。股票分割降低每股價格、提高流通股數，目的即在改善市場流通性。

(B)錯誤。此敘述正確。股票股利係以面額將保留盈餘轉為股本，每股面額維持不變，改變的是股數。

(C)錯誤。此敘述正確。股票股利使保留盈餘減少、股本增加，權益總額不變。

(D)正確（即敘述有誤者）。股票股利須作分錄，將保留盈餘轉列股本（及資本公積）；股票分割僅使股數增加、每股面額等比例下降，權益各科目金額均不變，故僅作備忘記錄。兩者的差別正在於是否牽動權益科目金額。
