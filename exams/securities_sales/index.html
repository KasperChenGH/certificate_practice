1. 下列有關公司法第一百五十六條股份之規定，何者錯誤？
  1. (A)股份有限公司之資本，應分為股份，擇一採行票面金額股或無票面金額股
  2. (B)公司股份之一部分得為特別股；其種類，由章程定之
  3. (C)股東之出資，以現金為限
  4. (D)公司章程所定股份總數，得分次發行
解析

(A)錯誤。本項敘述正確：資本應分為股份，擇一採行票面金額股或無票面金額股。

(B)錯誤。本項敘述正確：股份之一部分得為特別股，其種類由章程定之。

(C)正確（即錯誤敘述者）。股東之出資不以現金為限，尚得以對公司所有之貨幣債權、公司事業所需之財產或技術抵充。若限於現金，公司將無法藉由取得技術或營運所需財產的方式引進資源。

(D)錯誤。本項敘述正確：章程所定股份總數得分次發行。

114年第3次｜證券交易相關法規與實務｜第 8 題
2. 公司在預定買回期間，執行買回本公司股份所預定之最高及最低之買回價格，稱為：
  1. (A)買賣區間價格
  2. (B)買賣預計價格
  3. (C)買回區間價格
  4. (D)買回預計價格
解析

(A)錯誤。「買賣區間價格」把買回與賣出混為一談；庫藏股制度規範的是公司從市場買回自己股份的價格範圍，並沒有「賣出」的一面，名稱不會用「買賣」。

(B)錯誤。「買賣預計價格」既用錯了「買賣」，也以「預計價格」這種單一價格的說法取代區間；法規要求公司事先公告的是最高與最低價格構成的範圍。

(C)正確。依上市上櫃公司買回本公司股份辦法，公司在預定買回期間執行買回本公司股份所預定之最高及最低買回價格，稱為買回區間價格。事先公告價格區間，讓市場知悉公司進場的價格範圍，可降低公司利用庫藏股操縱股價的空間，也讓股東能檢視公司是否在合理價位動用資金。

(D)錯誤。「買回預計價格」雖然正確使用了「買回」，但預計價格是一個數字，而法規要求載明的是最高與最低價格構成的區間，名稱上以「區間」表達才符合制度內容。

114年第3次｜證券交易相關法規與實務｜第 22 題
3. 發行人募集與發行有價證券處理準則所稱「營業日」係指：
  1. (A)人事行政局所公布之上班日
  2. (B)非國定假日
  3. (C)證券市場交易日
  4. (D)證券商營業日
解析

(A)錯誤。人事行政總處公布的上班日是政府機關的辦公日，例如颱風停班或補班日與證券市場是否開市未必一致，募集發行的期間若以此計算會與市場實際運作脫節。

(B)錯誤。非國定假日的範圍過廣，週六、週日以及證券市場因結算或其他原因休市的日子都不是國定假日，卻也不是交易日，用它計算期間會把休市日算進去。

(C)正確。發行人募集與發行有價證券處理準則所稱營業日，指證券市場交易日。募集發行的申報生效期間、承銷期間等都與市場交易緊密相關，以證券市場交易日為準才能與實際運作接軌，也避免發行人與主管機關對期間起迄的認定不一。

(D)錯誤。證券商營業日是各證券商自己的營業安排，可能因公司內部因素而與市場開市日不同，且各證券商未必一致，無法作為法規計算期間的統一標準。

114年第3次｜證券交易相關法規與實務｜第 38 題
4. 上市公司有何項情事，得經董事會三分之二以上董事之出席及出席董事超過二分之一同意，於有價證券集中交易市場買回其股份？
  1. (A)轉讓股份予員工
  2. (B)配合可轉換公司債股權憑證之發行，作為股權轉換之用
  3. (C)為維護公司信用及股東權益所必要而買回，並辦理銷除股份
  4. (D)以上皆是
解析

(A)錯誤。轉讓股份予員工確實是證券交易法第28條之2所列的買回事由之一，但同條同時還列了配合股權轉換與維護公司信用兩種情形，單選這一項會遺漏其他兩項。

(B)錯誤。配合附認股權公司債、可轉換公司債等股權憑證之發行作為股權轉換之用，是第28條之2的第二款事由，但並非唯一的一款，另外兩種情形同樣得依董事會特別決議買回。

(C)錯誤。為維護公司信用及股東權益所必要而買回並辦理銷除股份，是第28條之2的第三款，也是唯一必須註銷股份的一款；不過另外兩款同樣是法定買回事由，因此不能只選這一項。

(D)正確。證券交易法第28條之2第1項列舉三種情形：轉讓股份予員工；配合附認股權公司債、可轉換公司債等股權憑證之發行作為股權轉換之用；為維護公司信用及股東權益所必要而買回並辦理銷除股份。三者都須經董事會三分之二以上董事出席及出席董事超過二分之一同意，且買回數量不得超過已發行股份總數百分之十。以列舉方式限定用途並要求特別決議，是為了防止公司用股東的錢隨意進場護盤。

115年第1次｜證券交易相關法規與實務｜第 3 題
5. 公開發行公司董事缺額達章程所定席次三分之一時，公司應自事實發生之日起幾日內，召開股東臨時會補選之？
  1. (A)30 日
  2. (B)45 日
  3. (C)60 日
  4. (D)90 日
解析

(A)錯誤。30日是公司法第201條對「非公開發行公司」的規定：董事缺額達三分之一時，董事會應於三十日內召開股東臨時會補選。公開發行公司因股東人數多、召集程序較繁複，同條但書放寬為六十日。

(B)錯誤。45日不是公司法第201條所定的期限，該條只有兩個數字：非公開發行公司三十日、公開發行公司六十日。45日可能與證券交易法季報四十五日的期限混淆。

(C)正確。公司法第201條規定，董事缺額達三分之一時，董事會應於三十日內召開股東臨時會補選之；但公開發行股票之公司，董事會應於六十日內召開股東臨時會補選之。缺額達三分之一表示董事會的代表性與決議正當性已受影響，必須儘快補足；公開發行公司因須辦理停止過戶、寄發開會通知等程序，期限較非公開發行公司寬鬆一倍。

(D)錯誤。90日長於公司法第201條對公開發行公司所定的六十日。董事會在缺額達三分之一的狀態下運作越久，決議的正當性爭議越大，因此法律不允許拖到三個月。

115年第1次｜證券交易相關法規與實務｜第 17 題
6. 初次申請股票上市之發行公司，其有價證券上市契約生效後，於證交所函知之日起多久以內未依規定上市，其上市案會被撤銷？
  1. (A)一個月
  2. (B)三個月
  3. (C)六個月
  4. (D)十二個月
解析

(A)錯誤。一個月短於證交所規定的期限。上市契約生效後公司還須完成公開承銷、集保登錄等掛牌前作業，這些流程通常需要數週，一個月的期限在實務上過於緊迫。

(B)正確。初次申請股票上市的公司，其有價證券上市契約生效後，自證交所函知之日起三個月內未依規定上市者，證交所將撤銷其上市案。設定期限是避免公司取得上市資格後長期不掛牌，使審查結論所依據的財務業務狀況隨時間失真；三個月足以完成公開承銷等掛牌前程序，又不至於讓資格懸而未決。

(C)錯誤。六個月長於規範所定的期限。若容許半年不掛牌，證交所審查時所依據的財務報告可能已跨越一個半年度，審查結論的基礎會過時，因此規範採較短的三個月。

(D)錯誤。十二個月等於整整一個年度，公司在這段期間的營運與財務可能已經大幅變動，原上市審查等於失去意義，這正是規範設定較短期限所要防止的情形。

115年第1次｜證券交易相關法規與實務｜第 34 題
7. 委託人融資買進之股票，於發行公司停止過戶前幾個營業日，由證券金融公司編製過戶清冊及媒體資料送交證券集中保管事業，代辦過戶？
  1. (A)前一個營業日
  2. (B)前二個營業日
  3. (C)前三個營業日
  4. (D)前四個營業日
解析

(A)正確。委託人融資買進的股票登記在證券金融公司或證券商名下作為擔保，須在發行公司停止過戶前完成過戶作業，委託人才能以股東身分享有該次股利或表決權。規範定於停止過戶前一個營業日，由證券金融公司編製過戶清冊及媒體資料送交集中保管事業代辦過戶，這是仍能完成過戶的最後一個營業日，可讓清冊反映最接近停止過戶時點的融資部位。

(B)錯誤。前二個營業日比規範時點早了一天，屆時編製的清冊會遺漏最後一個營業日新增或了結的融資部位，使過戶內容與停止過戶時的實際持有狀況不一致。

(C)錯誤。前三個營業日更早於規範時點。編製清冊的時點愈早，遺漏之後變動的融資部位就愈多，需要事後補正的機會也愈大，規範因此把時點定在最接近停止過戶日的前一個營業日。

(D)錯誤。前四個營業日與規範時點相差三天，屬於把時間提前過多的誤解。過戶清冊的目的是在停止過戶前反映最終的融資持股，提前數日編製反而失去精確性。

115年第1次｜證券交易相關法規與實務｜第 49 題
8. 私人間直接讓受上市有價證券，其數量不得超過一個成交單位，且前後兩次之讓受行為相隔不少於多少期間？
  1. (A)3 個月
  2. (B)6 個月
  3. (C)9 個月
  4. (D)12 個月
解析

(A)正確。證券交易法第一百五十條規定上市有價證券之買賣應於集中交易市場為之，但私人間之直接讓受，其數量不超過該證券一個成交單位，且前後兩次讓受行為相隔不少於三個月者，不在此限。限制數量與頻率，是讓例外只容納零星的私下轉讓，避免有人以連續的場外過戶規避集中市場的公開撮合與價格揭露。

(B)錯誤。六個月是證券交易法第一百五十七條歸入權所用的期間（內部人取得後六個月內賣出），並不是私人間直接讓受的間隔要求；若採六個月，每年可私下讓受的次數只剩兩次，比第一百五十條實際容許的更嚴。

(C)錯誤。九個月沒有任何證交法規定以此為期間。第一百五十條所設的間隔只有三個月，也就是一年內最多可有四次一個成交單位的私人讓受。

(D)錯誤。十二個月會把私人間讓受限縮到一年一次，這比第一百五十條的規定嚴格得多。該條的目的只是防止頻繁場外交易架空集中市場，並不打算把偶發的私下轉讓完全堵死，所以間隔定在三個月。

115年第2次｜證券交易相關法規與實務｜第 14 題
9. 申請股票上市之發行公司雖符合上市審查準則之上市條件，但有以下何種情況，經證交所認為不宜上市，得不同意其股票上市？
  1. (A)有足以影響公司財務業務正常營運之重大勞資糾紛或污染環境情事，但已經改善
  2. (B)有重大非常規交易，但已經改善
  3. (C)申請公司或其現任董事、總經理或實質負責人於五年前有違反誠信原則，但後未再犯
  4. (D)有虛偽不實或違法情事，足以影響其上市後之證券價格，而及於市場秩序或損害公益之虞
解析

(A)錯誤。重大勞資糾紛或污染環境情事須是尚未改善者才構成不宜上市之事由；已完成改善即不再構成障礙。

(B)錯誤。重大非常規交易同樣以尚未改善為要件，已改善者不作為否准上市之理由。

(C)錯誤。違反誠信原則之審查係針對最近一定期間內之行為，五年前且事後未再犯者，已逾該審查期間。

114年第3次｜證券投資與財務分析｜第 23 題
13. 下列哪一事項可能會導致資本公積之金額變動？
  1. (A)發放現金股利
  2. (B)前期損益調整
  3. (C)提撥法定盈餘公積
  4. (D)庫藏股票交易
解析

(A)錯誤。以盈餘發放現金股利時借記保留盈餘、貸記應付股利或現金，減少的是保留盈餘與資產，資本公積不受影響；股利只是把已賺得的盈餘分給股東，不是股東與公司之間的資本交易。

(B)錯誤。前期損益調整是更正前期錯誤或會計政策變動的追溯影響，直接調整期初保留盈餘，屬於保留盈餘項下的變動，與資本公積無關。

(C)錯誤。提撥法定盈餘公積是把未分配盈餘的一部分轉為受限制的盈餘公積，只是保留盈餘內部的重分類，權益總額與資本公積都不變；盈餘公積來自營業成果，資本公積來自股東投入，兩者來源不同。

(D)正確。資本公積來自非營業結果的股東投入或權益交易，例如股票發行溢價與庫藏股票交易。買回的庫藏股以高於成本再出售時，差額貸記資本公積—庫藏股票交易；以低於成本出售或註銷時，先沖減同類的資本公積，因此庫藏股交易會使資本公積金額變動。因為這是公司與股東之間的權益交易，不能認列損益，只能反映在資本公積。

115年第2次｜證券投資與財務分析｜第 2 題
18. 何者不屬於衍生性金融工具？
  1. (A)期貨契約
  2. (B)選擇權
  3. (C)公司債
  4. (D)遠期契約
解析

(A)錯誤。期貨契約是約定未來以特定價格買賣標的資產的標準化契約，本身沒有獨立價值，價格完全隨標的（股價指數、商品、利率）變動而變動，是典型的衍生性金融工具。

(B)錯誤。選擇權賦予買方在未來以履約價買進或賣出標的資產的權利，其權利金隨標的價格、波動率與到期時間而變動，價值衍生自標的資產，屬衍生性金融工具。

(C)正確（即不屬於者）。衍生性金融工具的定義是價值衍生自其他標的資產（股票、利率、匯率、商品）的契約，期貨、選擇權、遠期、交換都是。公司債則是企業直接向投資人借款所發行的債務憑證，投資人取得對發行公司本身的債權，價值來自發行人的還本付息能力，不依附於其他標的，因此屬於原始（現貨）金融工具。

(D)錯誤。遠期契約是買賣雙方私下約定在未來某日以約定價格交易標的資產的契約，功能與期貨相同，只是未標準化、不在交易所交易，價值同樣取決於標的資產的未來價格，屬衍生性金融工具。

20. 某公司X7 年淨利$87,000，稅率50%，唯一負債為6%公司債，面額$100,000，全年流通在外，平均權益為$900,000，則權益報酬率為何？
  1. (A)9.67%
  2. (B)9.33%
  3. (C)4.84%
  4. (D)4.50%
解析

(A)正確。權益報酬率＝稅後淨利÷平均股東權益＝$87,000÷$900,000≒9.67%。題目給的$87,000已是淨利，公司債利息$6,000與50%稅率在算出淨利的過程中早已扣除，不能再扣一次。稅率與公司債資料是用來計算總資產報酬率（須加回稅後利息）的干擾條件，權益報酬率不需要它們。

(B)錯誤。9.33%是先把公司債利息$100,000×6%＝$6,000乘以(1－50%)得稅後利息$3,000，再從淨利中扣除：($87,000－$3,000)÷$900,000＝9.33%。淨利本來就已扣過利息，這樣算是重複扣除；加回稅後利息是算總資產報酬率才需要的步驟，而且方向是加不是減。

(C)錯誤。4.84%是把已經是稅後的淨利再乘一次(1－50%)：$87,000×50%÷$900,000≒4.83%。$87,000是稅後淨利，稅已經扣過，再乘稅後係數等於課了兩次稅。

(D)錯誤。4.50%是把淨利扣除全部利息$6,000後再乘(1－50%)：($87,000－$6,000)×50%÷$900,000＝4.5%。這同時犯了重複扣利息與重複扣稅兩個錯誤。
