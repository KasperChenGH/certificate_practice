1. 甲公司所生產的礦泉水每瓶售價$25，其中變動成本占60%，已知目前每年產量為40,000 瓶，該公司剛好損益兩平，請問其固定成本約為多少？
  1. (A)$400,000
  2. (B)$189,000
  3. (C)$207,000
  4. (D)$198,000
解析

(A)正確。單位變動成本＝$25×60%＝$15，單位邊際貢獻＝$25－$15＝$10。損益兩平的定義是邊際貢獻總額恰好等於固定成本，所以固定成本＝$10×40,000瓶＝$400,000。也可以驗算：收入$1,000,000－變動成本$600,000－固定成本$400,000＝0，利潤為零。

(B)錯誤。若固定成本只有$189,000，40,000瓶的邊際貢獻$400,000扣掉它之後還剩$211,000的利潤，公司並非損益兩平。損益兩平意味邊際貢獻全部用來回收固定成本，一分不剩。

(C)錯誤。若固定成本為$207,000，利潤＝$400,000－$207,000＝$193,000，仍是獲利狀態，與題目「剛好損益兩平」矛盾。要讓利潤為零，固定成本必須恰好等於$400,000的邊際貢獻總額。

(D)錯誤。若固定成本為$198,000，利潤＝$400,000－$198,000＝$202,000，公司會有可觀獲利而非損益兩平。這個數字大約是邊際貢獻的一半，可能是把單位邊際貢獻誤算成約$5所致。

2. 依「證券交易法」規定，因命令停業之證券商，於其了結停業前所為有價證券之買賣或受託事務之範圍內，視為：
  1. (A)強制停業
  2. (B)尚未停業
  3. (C)暫時停業
  4. (D)永久停業
解析

(A)錯誤。強制停業是主管機關對證券商採取的處分手段，描述的是停業的原因，不是法律對停業後了結事務所設的擬制效果。證券交易法第68條處理的是停業「之後」如何善後。

(B)正確。證券交易法第68條規定，因命令停業之證券商，於其了結停業前所為有價證券之買賣或受託事務之範圍內，視為尚未停業。若停業命令一下達證券商就立刻喪失營業資格，先前已成交但尚未交割的買賣與尚未了結的委託將無人處理，受害的是客戶與交易相對人；因此法律在了結既有事務的範圍內擬制它仍在營業，讓善後得以完成。同條對經撤銷特許的證券商也有相同設計，在了結目的範圍內仍視為證券商。

(C)錯誤。暫時停業是一種事實狀態的描述，不是第68條的用語。條文的擬制是「視為尚未停業」，重點在於停業前已發生的買賣與受託事務仍能合法了結，而非給予一段暫停期。

(D)錯誤。永久停業與第68條的意旨相反：條文的目的是讓證券商在停業後仍能合法完成先前未了結的買賣與受託事務，若視為永久停業，這些善後行為反而失去依據。

3. 依照證券交易法之規定，下列何者非為內線交易規範主體？
  1. (A)持有該公司之股份百分之五之股東
  2. (B)該公司之法人董事代表人
  3. (C)該公司離職三個月的董事
  4. (D)從董事長獲悉消息之董事長司機
解析

(A)正確（即非規範主體者）。內線交易的規範主體之一是持有公司股份「超過百分之十」之股東；持股百分之五之股東未達此門檻，不在其列。設定持股門檻的理由是：達一定持股比例者通常有管道接觸公司內部資訊。

(B)錯誤。法人董事之代表人屬規範主體，其因職務當然接觸重大消息。

(C)錯誤。離職未滿六個月之董事仍屬規範主體，離職三個月者在內；否則只要辭職即可規避。

(D)錯誤。自董事長獲悉消息之司機屬「消息受領人」，同受規範，內線交易不以身分職位為限，而及於實際知悉消息者。

1. 依「發行人募集與發行有價證券處理準則」之規定，轉換公司債「發行及轉換辦法」所定發行屆滿一定期間得開始請求轉換，所稱一定期間指：
  1. (A)一律以三個月為限
  2. (B)一律不超過六個月
  3. (C)一律不超過一年
  4. (D)由發行人於轉換辦法訂定
解析

(A)錯誤。三個月不是準則規定的統一閉鎖期；準則只要求發行人在轉換辦法中載明「發行屆滿一定期間」，這段期間由發行人自行決定，可以較短也可以較長，法規並不強制一律三個月。

(B)錯誤。「一律不超過六個月」把發行人自行決定的商業條件說成了法定上限；準則並未替閉鎖期設定六個月的天花板，發行人依資金規劃與市場條件訂定較長的期間同樣合法。

(C)錯誤。「一律不超過一年」同樣是把法規沒有設定的上限套了進去；準則的規範方式是要求發行人於轉換辦法中明定一定期間，再透過公開說明書讓投資人事前知悉，而不是由法規統一設定期限。

(D)正確。依發行人募集與發行有價證券處理準則，轉換公司債自發行屆滿一定期間起得請求轉換，所稱一定期間由發行人於轉換辦法中訂定。轉換條件屬於商業安排，發行人依資金需求與市場條件決定閉鎖期長短，法規不代為設定固定天數，只要求載明於轉換辦法並公開，讓投資人在認購前即可評估。

2. 仲裁庭認定仲裁達於可為判斷之程度者，依當事人聲明之事項，應於幾日內作成判斷書？
  1. (A)7 日
  2. (B)10 日
  3. (C)14 日
  4. (D)20 日
解析

(A)錯誤。七日短於仲裁法所給的期間；判斷書須記載主文、事實及理由並由參與評議的仲裁人簽名，仲裁法定為十日是兼顧迅速與讓仲裁庭有足夠時間完成書面。

(B)正確。仲裁法第33條規定，仲裁庭認仲裁達於可為判斷之程度者，應宣告詢問終結，依當事人聲明之事項，於十日內作成判斷書。仲裁制度以迅速解決爭議為特色，因此在可為判斷後即課予明確且短促的作成期限，避免程序拖延抵銷仲裁相對於訴訟的效率優勢。

(C)錯誤。十四日長於仲裁法所定的十日；仲裁法第21條對整個程序另設自仲裁人受通知起六個月內作成判斷書（必要時得延長三個月）的總期限，詢問終結後的十日則是最後階段的期限，兩者不可混淆。

(D)錯誤。二十日是仲裁法所定期間的兩倍；詢問終結時證據調查已經完成，只剩撰寫判斷書，若允許二十日反而削弱仲裁迅速終結爭議的功能。

3. 下列何者為年報編製內容應記載之事項？
  1. (A)致股東報告書
  2. (B)公司治理報告
  3. (C)募資情形
  4. (D)選項(A)(B)(C)皆是
解析

(A)錯誤。致股東報告書是年報的第一部分，內容涵蓋上年度營業結果與本年度營業計畫，確為應記載事項，但年報還包括公司治理報告與募資情形等內容，只選此項並不完整。

(B)錯誤。公司治理報告揭露董事會、審計委員會運作與內部控制情形，是年報的必載章節之一；然而募資情形與致股東報告書同樣是應記載事項，單選此項會遺漏其他項目。

(C)錯誤。募資情形記載資本及股份、公司債、特別股、海外存託憑證等發行情形與資金運用計畫，屬年報應記載事項，但致股東報告書與公司治理報告也在其中，不能只選這一項。

(D)正確。依公開發行公司年報應行記載事項準則，年報應記載致股東報告書、公司簡介、公司治理報告、募資情形、營運概況、財務概況等事項，(A)(B)(C)都是其中的必載章節。年報是股東每年檢視公司經營、治理與資金運用的整合性文件，內容才會涵蓋這麼多面向。

4. 上市公司有何項情事，得經董事會三分之二以上董事之出席及出席董事超過二分之一同意，於有價證券集中交易市場買回其股份？
  1. (A)轉讓股份予員工
  2. (B)配合可轉換公司債股權憑證之發行，作為股權轉換之用
  3. (C)為維護公司信用及股東權益所必要而買回，並辦理銷除股份
  4. (D)以上皆是
解析

(A)錯誤。轉讓股份予員工確實是證券交易法第28條之2所列的買回事由之一，但同條同時還列了配合股權轉換與維護公司信用兩種情形，單選這一項會遺漏其他兩項。

(B)錯誤。配合附認股權公司債、可轉換公司債等股權憑證之發行作為股權轉換之用，是第28條之2的第二款事由，但並非唯一的一款，另外兩種情形同樣得依董事會特別決議買回。

(C)錯誤。為維護公司信用及股東權益所必要而買回並辦理銷除股份，是第28條之2的第三款，也是唯一必須註銷股份的一款；不過另外兩款同樣是法定買回事由，因此不能只選這一項。

(D)正確。證券交易法第28條之2第1項列舉三種情形：轉讓股份予員工；配合附認股權公司債、可轉換公司債等股權憑證之發行作為股權轉換之用；為維護公司信用及股東權益所必要而買回並辦理銷除股份。三者都須經董事會三分之二以上董事出席及出席董事超過二分之一同意，且買回數量不得超過已發行股份總數百分之十。以列舉方式限定用途並要求特別決議，是為了防止公司用股東的錢隨意進場護盤。
