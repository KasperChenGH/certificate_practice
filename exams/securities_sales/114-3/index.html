1. 股份有限公司之股東常會，每年至少應召集幾次？
  1. (A)1 次
  2. (B)2 次，即每半年1 次
  3. (C)4 次，即每季1 次
  4. (D)6 次，即每2 個月一次
解析

(A)正確。公司法第一百七十條規定股東會分為股東常會與股東臨時會，股東常會每年至少召集一次，並應於每會計年度終了後六個月內召開。股東常會的主要功能是承認年度財務報表與盈餘分派、改選董監事，這些事項一年產生一次，故一年一會即足；有臨時需要則另召集股東臨時會。

(B)錯誤。公司法未要求每半年召開股東常會。半年度財務報告由董事會通過並依證券交易法申報即可，不須提交股東會承認，因此沒有每半年召集一次的必要。

(C)錯誤。每季一次是公開發行公司季報申報的節奏，或是董事會定期召開的頻率，並非股東常會的最低次數；股東常會若每季召開，召集成本與公告程序將過於繁重。

(D)錯誤。每兩個月一次遠高於公司法所定的最低頻率。公司若有必要在常會以外討論事項，可召集股東臨時會，而不是提高常會的次數。

2. 依現行法規定，股份有限公司不得發行下列何種特別股？
  1. (A)每股10 表決權之特別股
  2. (B)對於公司「董事選舉之結果」具否決權之特別股
  3. (C)發行滿2 年後，1 股特別股得轉換為10 股普通股之特別股
  4. (D)無表決權，但具優先分派當年度得分派股息之特別股
解析

(A)錯誤。公司法容許非公開發行公司發行複數表決權特別股，每股10表決權並非當然不得發行。

(B)正確。特別股得對特定事項具否決權（黃金股），但不得對「董事選舉之結果」具否決權。董事選舉是股東行使控制權的核心，若容許以否決權推翻選舉結果，等同架空股東會的意思決定，故明文排除。

(C)錯誤。特別股得約定轉換為複數普通股，1股轉10股之轉換比例並非法所不許。

(D)錯誤。無表決權但優先分派股息之特別股，是最典型的特別股型態。

4. 股份有限公司讓與全部營業或財產，依「公司法」第一百八十五條規定，應有代表已發行股份總數三分之二以上股東出席之股東會，以出席股東表決權超過多少比例之同意行之？
  1. (A)三分之一
  2. (B)二分之一
  3. (C)三分之二
  4. (D)四分之三
解析

(A)錯誤。三分之一從未被公司法用作股東會決議的同意門檻；若只要三分之一的出席股東同意就能讓與全部營業，等於少數股權即可決定公司存續，與特別決議保護多數股東的目的相反。

(B)正確。公司法第185條第1項規定，讓與全部或主要部分之營業或財產，應有代表已發行股份總數三分之二以上股東出席之股東會，以出席股東表決權過半數之同意行之。嚴格性放在出席門檻而非同意比例：先確保足夠多的股權到場，再以普通多數決定。同條第2項另允許公開發行公司在出席不足時，以過半數出席、出席表決權三分之二以上同意作為替代。

(C)錯誤。三分之二是出席門檻（代表已發行股份總數三分之二以上出席），不是同意比例；它同時也是公開發行公司出席不足時替代方案中「出席表決權三分之二以上同意」的數字，兩個位置容易混淆。

(D)錯誤。四分之三高於公司法為任何股東會特別決議所設的同意比例；公司法對重大事項只有「三分之二出席、過半數同意」與「過半數出席、三分之二同意」兩種組合，沒有四分之三的設計。

5. 依「證券交易法」規定，因命令停業之證券商，於其了結停業前所為有價證券之買賣或受託事務之範圍內，視為？
  1. (A)強制停業
  2. (B)尚未停業
  3. (C)暫時停業
  4. (D)永久停業
解析

(A)錯誤。強制停業描述的是主管機關命令停業這個處分本身，也就是該證券商已被命令停止營業；條文要處理的是停業後尚未了結事務的法律效果，而不是再重申停業處分的性質。

(B)正確。證券交易法規定，因命令停業之證券商，於其了結停業前所為有價證券之買賣或受託事務之範圍內，視為尚未停業。若停業命令使證券商的業務能力即刻消滅，停業前已成交而尚未交割的買賣與尚未了結的委託將無人履行，受害的是客戶與交易相對人，所以在「了結」這個範圍內擬制其仍在營業，讓善後得以完成。

(C)錯誤。暫時停業指的是停業處分本身附有期間，屬處分的態樣；條文採用的擬制是「視為尚未停業」，目的在讓停業前的買賣與受託事務能夠了結，與停業期間的長短無關。

(D)錯誤。永久停業等於撤銷許可、終止營業；若停業前的未了結事務也被視為在永久停業狀態下所為，交割與委託反而無從善後，與條文要求了結未完成事務的意旨正好相反。

6. 股份有限公司發行新股時，除有特別規定者外，應保留原發行新股總額百分之多少股份由公司員工承購？
  1. (A)百分之十至百分之十五
  2. (B)百分之十二
  3. (C)百分之十
  4. (D)百分之二十至百分之二十五
解析

(A)正確。公司法第267條第1項規定，公司發行新股時，除經目的事業中央主管機關專案核定者外，應保留發行新股總數百分之十至十五之股份由公司員工承購。定為區間而非單一數字，讓公司可依人力政策在下限與上限之間自行決定；保留員工認股是把員工利益與公司成長綁在一起的制度設計。

(B)錯誤。百分之十二落在百分之十至十五的區間內，是公司可以自行選定的其中一個比例，但法條規定的是整個區間，並未固定於百分之十二；把公司實務上的某個選擇當成法定比例就會選到這個數字。

(C)錯誤。百分之十只是區間的下限；同條第2項對公營事業另設「保留股份不得超過發行新股總數百分之十」的上限，那是公營事業經專案核定時的特別規定，不是一般公司的保留比例。

(D)錯誤。百分之二十至二十五高於法定區間；若保留這麼多股份給員工，原有股東依同條第3項按比例儘先分認的權利會被過度稀釋，法條把上限定在百分之十五正是要在員工參與與股東權益之間取得平衡。

7. 公開發行公司募集、發行有價證券，應向政府何單位申報生效？
  1. (A)國家發展委員會
  2. (B)金融監督管理委員會
  3. (C)財政部
  4. (D)經濟部
解析

(A)錯誤。國家發展委員會負責國家整體發展規劃與跨部會政策協調，不是證券交易法的主管機關，也不受理有價證券募集發行的申報。

(B)正確。證券交易法的主管機關為金融監督管理委員會，公開發行公司募集、發行有價證券須向金管會申報生效。募集發行採申報生效制而非核准制：申報後經過法定等待期間即生效，主管機關保留退回或命令補正的權力，重點放在資訊揭露是否充分，而不是由政府替投資人判斷投資價值。

(C)錯誤。財政部主管國庫、稅務與公股管理，證券交易稅由其課徵；證券市場的監理職權在民國93年金管會成立後，已由財政部證券暨期貨管理委員會移轉至金管會。

(D)錯誤。經濟部是公司法的主管機關，負責公司登記事項，例如發行新股後的資本額變更登記；但有價證券的募集與發行受證券交易法規範，申報的對象是金管會。

9. 依「發行人募集與發行有價證券處理準則」之規定，轉換公司債「發行及轉換辦法」所定發行屆滿一定期間得開始請求轉換，所稱一定期間指：
  1. (A)一律以三個月為限
  2. (B)一律不超過六個月
  3. (C)一律不超過一年
  4. (D)由發行人於轉換辦法訂定
解析

(A)錯誤。三個月不是準則規定的統一閉鎖期；準則只要求發行人在轉換辦法中載明「發行屆滿一定期間」，這段期間由發行人自行決定，可以較短也可以較長，法規並不強制一律三個月。

(B)錯誤。「一律不超過六個月」把發行人自行決定的商業條件說成了法定上限；準則並未替閉鎖期設定六個月的天花板，發行人依資金規劃與市場條件訂定較長的期間同樣合法。

(C)錯誤。「一律不超過一年」同樣是把法規沒有設定的上限套了進去；準則的規範方式是要求發行人於轉換辦法中明定一定期間，再透過公開說明書讓投資人事前知悉，而不是由法規統一設定期限。

(D)正確。依發行人募集與發行有價證券處理準則，轉換公司債自發行屆滿一定期間起得請求轉換，所稱一定期間由發行人於轉換辦法中訂定。轉換條件屬於商業安排，發行人依資金需求與市場條件決定閉鎖期長短，法規不代為設定固定天數，只要求載明於轉換辦法並公開，讓投資人在認購前即可評估。

10. 已公開財務預測之公司，應隨時評估敏感度大之基本假設變動對財務預測結果之影響，並按___就營運結果分析其達成情形並評估有無更新財務預測之必要？

  2. (B)月
  3. (C)季
  4. (D)年

(B)正確。依公開發行公司公開財務預測資訊處理準則，已公開財務預測之公司應隨時評估敏感度大之基本假設變動對財測結果之影響，並按月就營運結果分析其達成情形，評估有無更新財務預測之必要。公開發行公司本即須按月公告營收，以相同頻率檢視財測達成度，可在偏離擴大前及時更新，避免投資人持續依據已失真的預測作判斷。

(D)錯誤。按年分析等於等到會計年度結束才比對預測與實際，此時財測已無任何前瞻價值，完全無法達到讓投資人及時知悉偏離的目的。

114年第3次｜證券交易相關法規與實務｜第 10 題
11. 內線交易情節重大者，法院得提高賠償額之倍數為下列何者？
  1. (A)3 倍
  2. (B)4 倍
  3. (C)5 倍
  4. (D)10 倍
解析

解析

(B)錯誤。前期損益調整是更正前期錯誤或會計政策變動的追溯影響，直接調整期初保留盈餘，屬於保留盈餘項下的變動，與資本公積無關。

37. 不動產、廠房及設備不以淨變現價值為評價依據，係基於：
  1. (A)成本原則
  2. (B)穩健原則
  3. (C)收入與費用配合原則
  4. (D)繼續經營之假設
解析

(A)錯誤。以歷史成本入帳並作為後續衡量基礎是成本原則的內容，但成本原則能成立的前提正是繼續經營：企業會持續使用設備直到效益耗盡，用成本逐期折舊才有意義；問的是為什麼不用淨變現價值，根源在假設而不在原則。

(B)錯誤。穩健原則要求在不確定時不高估資產、不低估負債，例如存貨採成本與淨變現價值孰低；它處理的是不確定情況下的取捨，不能解釋為何不動產、廠房及設備一律不以變現價值評價。

(C)錯誤。收入與費用配合原則說明的是設備成本如何透過折舊在使用年限內分攤，以配合各期產生的收入；它本身是以繼續經營為前提運作的，不是拒絕淨變現價值評價的理由。
