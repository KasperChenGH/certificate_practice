1. 下列何項之有價證券得為融資融券之標的？
  1. (A)政府債券
  2. (B)上市股票
  3. (C)上市公司債券
  4. (D)上櫃公司債券
解析

(A)錯誤。政府債券在債券市場以買斷或附條件交易方式進行，價格主要隨利率變動、波動有限，且以到期還本付息為目的，有價證券得為融資融券標準所列的信用交易標的不含債券。

(B)正確。依有價證券得為融資融券標準，得為融資融券的是上市（櫃）股票，以及受益憑證、臺灣存託憑證等權益型證券，並須符合上市滿一定期間、每股淨值在票面以上等條件後由證交所或櫃買中心公告。信用交易是借錢買股或借股放空，用槓桿放大價格漲跌的損益，因此標的必須具備價格波動性與充足的流動性，才有融資融券的需求與可行性。

(C)錯誤。上市公司債券雖在交易所掛牌，但其性質仍是債權憑證，價格波動遠低於股票，也沒有借券放空的市場需求，不在融資融券標準所列的標的範圍內。

(D)錯誤。上櫃公司債券與上市公司債券相同，都是固定收益工具，融資融券制度是為股票等權益證券設計的，債券不論在集中市場或櫃檯買賣都不是信用交易標的。

2. 依「公司法」規定，公開發行股票公司之公司債發行總額，不得逾：
  1. (A)公司現有資產之總價值
  2. (B)公司現有全部資產減去全部負債之餘額
  3. (C)公司淨資產之半數
  4. (D)並無限制
解析

(A)錯誤。若以資產總價值為上限，等於完全忽略公司既有的負債：一家資產10億、負債9億的公司也能再發10億公司債，新債權人幾乎沒有任何淨資產可作保障。公司法第247條因此以資產減負債後的餘額為基準。

(B)正確。公司法第247條規定，公開發行股票公司之公司債總額，不得逾公司現有全部資產減去全部負債後之餘額，也就是淨資產。公司債持有人是新增的債權人，扣除既有負債後真正屬於公司的部分才是他們能依賴的償債來源，用淨資產設限才能確保發債規模與償債能力相稱。

(C)錯誤。淨資產之半數是公司法第247條第2項對「無擔保公司債」的更嚴限制：無擔保公司債總額不得逾淨資產餘額的二分之一。題目問的是公司債總額的一般上限，是全部淨資產而非半數。

(D)錯誤。公司法第247條對公開發行公司的公司債總額明定上限，並非毫無限制。發債是舉債，若不設上限，公司可無限擴大負債，債權人與股東都會暴露在過度槓桿的風險下。

3. 上市公司有何項情事，得經董事會三分之二以上董事之出席及出席董事超過二分之一同意，於有價證券集中交易市場買回其股份？
  1. (A)轉讓股份予員工
  2. (B)配合可轉換公司債股權憑證之發行，作為股權轉換之用
  3. (C)為維護公司信用及股東權益所必要而買回，並辦理銷除股份
  4. (D)以上皆是
解析

(A)錯誤。轉讓股份予員工確實是證券交易法第28條之2所列的買回事由之一，但同條同時還列了配合股權轉換與維護公司信用兩種情形，單選這一項會遺漏其他兩項。

(B)錯誤。配合附認股權公司債、可轉換公司債等股權憑證之發行作為股權轉換之用，是第28條之2的第二款事由，但並非唯一的一款，另外兩種情形同樣得依董事會特別決議買回。

(C)錯誤。為維護公司信用及股東權益所必要而買回並辦理銷除股份，是第28條之2的第三款，也是唯一必須註銷股份的一款；不過另外兩款同樣是法定買回事由，因此不能只選這一項。

(D)正確。證券交易法第28條之2第1項列舉三種情形：轉讓股份予員工；配合附認股權公司債、可轉換公司債等股權憑證之發行作為股權轉換之用；為維護公司信用及股東權益所必要而買回並辦理銷除股份。三者都須經董事會三分之二以上董事出席及出席董事超過二分之一同意，且買回數量不得超過已發行股份總數百分之十。以列舉方式限定用途並要求特別決議，是為了防止公司用股東的錢隨意進場護盤。

4. 下列何種證券商業務人員，不得辦理登記範圍以外之業務或由其他業務人員兼辦？
  1. (A)辦理結算交割人員
  2. (B)集保業務人員
  3. (C)風險管理人員
  4. (D)代理股務作業人員
解析

(A)錯誤。結算交割是後檯作業，證券商負責人與業務人員管理規則第4條把它列在招攬、銷售等前檯人員「不得兼辦」的職務清單裡，用來隔離前後檯，但結算交割人員本身並不在必須專責、不得由他人兼辦的三類人員之列。

(B)錯誤。集保業務人員辦理有價證券集中保管相關作業，屬一般登記業務人員，管理規則第4條列為專責的只有辦理自行買賣業務之人員、內部稽核人員與風險管理人員三類，集保業務人員不在其中。

(C)正確。證券商負責人與業務人員管理規則第4條規定，辦理有價證券自行買賣業務之人員、內部稽核人員及風險管理人員，不得辦理登記範圍以外之業務，也不得由其他業務人員兼辦。風險管理人員的職責是對各業務部門的部位與曝險設限並提出警示，一旦兼辦被監控的業務，就變成自己管自己，監控功能會失效，因此必須專責。

(D)錯誤。代理股務作業人員處理發行公司委託的股務登記，管理規則第4條同樣把代辦股務列為前檯招攬人員不得兼辦的職務之一，但它本身不是專責人員，可由登記範圍相符的其他人員辦理。

5. 受益憑證原則於上市(櫃)滿多久，由證券交易所或證券櫃檯買賣中心公告得為融資融券交易？
  1. (A)一個月
  2. (B)三個月
  3. (C)六個月
  4. (D)一年
解析

(A)錯誤。一個月只有二十個左右的交易日，累積不出足以判斷流動性與價格穩定度的成交紀錄。有價證券得為融資融券標準對普通股與受益憑證都要求六個月的觀察期，一個月遠短於此。

(B)錯誤。三個月並非標準所定的期間。受益憑證的觀察期與普通股上市滿六個月的規定相同，若只要三個月，受益憑證反而比股票更容易取得信用交易資格，與制度設計不符。

(C)正確。有價證券得為融資融券標準第3條規定，受益憑證上市（櫃）滿六個月，由證券交易所或證券櫃檯買賣中心公告得為融資融券交易；指數股票型基金等特定類型另有規定，不受此六個月限制。設觀察期是為了先累積足夠的成交量與價格資料，確認流動性穩定後再開放具槓桿性質的信用交易，避免剛掛牌、籌碼未沉澱的證券被融資融券放大波動。

(D)錯誤。一年比標準所定的六個月長了一倍，會讓受益憑證的信用交易開放時點晚於普通股。標準對受益憑證與普通股採相同的六個月觀察期，一年並無依據。

6. 公司董事會設有常務董事者，其名額至少三人，最多不得超過董事人數多少比例？
  1. (A)二分之一
  2. (B)三分之一
  3. (C)四分之一
  4. (D)五分之一
解析

(A)錯誤。若上限是二分之一，半數董事就能組成常務董事會，在董事會休會期間代行職權，等於用一半的人取代整個董事會運作，架空其他董事。公司法第208條的上限是三分之一，比這嚴格。

(B)正確。公司法第208條規定，董事會設有常務董事者，由董事互選，名額至少三人，最多不得超過董事人數三分之一。常務董事在董事會休會期間依法令、章程及董事會決議執行職務，人數若太多就等於以少數人取代董事會，人數若太少又不足以合議，因此設下三人的下限與三分之一的上限。

(C)錯誤。四分之一比法定的三分之一更嚴格。以九人董事會為例，三分之一是三人，正好達到至少三人的下限；若限為四分之一只能有二人，連法定最低人數都湊不到，可見四分之一不是公司法的規定。

(D)錯誤。五分之一遠低於公司法第208條的三分之一上限，在多數規模的董事會中根本無法同時滿足至少三人的下限，例如十二人的董事會五分之一只有2.4人。

7. 依「證券交易法」規定，因命令停業之證券商，於其了結停業前所為有價證券之買賣或受託事務之範圍內，視為：
  1. (A)強制停業
  2. (B)尚未停業
  3. (C)暫時停業
  4. (D)永久停業
解析

(A)錯誤。強制停業是主管機關對證券商採取的處分手段，描述的是停業的原因，不是法律對停業後了結事務所設的擬制效果。證券交易法第68條處理的是停業「之後」如何善後。

(B)正確。證券交易法第68條規定，因命令停業之證券商，於其了結停業前所為有價證券之買賣或受託事務之範圍內，視為尚未停業。若停業命令一下達證券商就立刻喪失營業資格，先前已成交但尚未交割的買賣與尚未了結的委託將無人處理，受害的是客戶與交易相對人；因此法律在了結既有事務的範圍內擬制它仍在營業，讓善後得以完成。同條對經撤銷特許的證券商也有相同設計，在了結目的範圍內仍視為證券商。

(C)錯誤。暫時停業是一種事實狀態的描述，不是第68條的用語。條文的擬制是「視為尚未停業」，重點在於停業前已發生的買賣與受託事務仍能合法了結，而非給予一段暫停期。

(D)錯誤。永久停業與第68條的意旨相反：條文的目的是讓證券商在停業後仍能合法完成先前未了結的買賣與受託事務，若視為永久停業，這些善後行為反而失去依據。

8. 第一次上市股票上市滿半年，每股淨值在票面以上，且無下列何種情形者，得核准其為融資融券交易股票？
  1. (A)股價波動過度劇烈
  2. (B)公司負責人形象不佳
  3. (C)公司營業額減少
  4. (D)發行公司與所屬財團之其他公司有嚴重交互持股
解析

(A)正確。有價證券得為融資融券標準第2條規定，普通股股票上市滿六個月、每股淨值在票面以上者得為融資融券交易，但有股價波動過度劇烈、股權過度集中、成交量過度異常等情形之一者，不予核准。信用交易本身帶有槓桿，若標的股價原本就劇烈波動，融資戶容易被追繳、斷頭，融券戶則面臨軋空，風險會被放大並外溢到證券商與整個市場。

(B)錯誤。公司負責人形象屬主觀評價，無法客觀衡量，融資融券標準所列的排除事由都是股價、股權與成交量等可量化的市場指標，負責人形象不在其中。

(C)錯誤。營業額減少是經營績效的變化，屬基本面資訊，投資人可自行評估。融資融券標準關心的是股票在市場上的交易特性是否適合槓桿操作，不以公司業績好壞作為核准條件。

(D)錯誤。與所屬財團其他公司交互持股影響的是公司治理與股權結構，屬公司法關係企業章與資訊揭露的規範範疇，不是融資融券標準第2條所列的排除事由。標準所列的是股價波動、股權集中與成交量異常三種市場面情形。

9. 公開發行公司除情形特殊，經主管機關另予規定者外，於每月幾日以前，公告並申報上月份營運情形？
  1. (A)2 日
  2. (B)5 日
  3. (C)10 日
  4. (D)15 日
解析

(A)錯誤。2日是證券交易法第36條對「重大事項」的申報期限：對股東權益或股票價格有重大影響之事項，應於事實發生之日起二日內公告申報。每月營運情形是例行資訊，月結後兩天內無法完成彙整，期限是次月10日。

(B)錯誤。每月5日是證券交易法第25條規定董事、監察人、經理人及大股東向「公司」申報上月份持股變動的期限，處理的是內部人持股，不是公司的營運情形申報。

(C)正確。證券交易法第36條規定，公開發行公司除情形特殊經主管機關另予規定者外，應於每月十日以前公告並申報上月份營運情形，實務上就是每月的營收公告。月營收是投資人最即時可得的經營指標，訂在次月10日是在資訊時效與公司作業可行性之間取得平衡；財務報告則另有年度後三個月、季後四十五日的期限。

(D)錯誤。每月15日是證券交易法第25條規定公司將內部人上月份持股變動「彙總向主管機關申報」的期限，與月營運情形的申報是兩件不同的事，後者的期限是10日。

10. 依照證券交易法之規定，下列何者非為內線交易規範主體？
  1. (A)持有該公司之股份百分之五之股東
  2. (B)該公司之法人董事代表人
  3. (C)該公司離職三個月的董事

  2. (B)報請主管機關核准終止甲公司有價證券櫃檯買賣
  3. (C)得終止甲公司有價證券櫃檯買賣，並報請主管機關備查
  4. (D)逕行終止甲公司有價證券櫃檯買賣
解析

(A)錯誤。撤銷櫃檯買賣契約通常針對上櫃時的申請文件有虛偽不實等根本瑕疵，屬於溯及否定上櫃資格的處置；淨值轉負是掛牌後發生的財務惡化事實，規範對此適用的是終止櫃檯買賣，而非撤銷契約。

115年第1次｜證券投資與財務分析｜第 40 題
36. 下列何者為公司使用財務槓桿有利時須滿足之條件？
  1. (A)舉債利率大於ROA
  2. (B)舉債利率大於ROE
  3. (C)舉債利率小於ROA
  4. (D)舉債利率小於ROE
解析

(A)錯誤。舉債利率大於資產報酬率時，借來的資金投入營運所賺的報酬不足以支付利息，差額由股東承擔，槓桿反而侵蝕股東報酬，使ROE低於ROA，這是財務槓桿不利的情況。

(B)錯誤。ROE本身已經包含槓桿效果，用它與舉債利率比較無法判斷槓桿是否有利；正確的比較基準是尚未扣除利息的資產報酬率，因為它才代表借款投入營運所能賺得的報酬。

(C)正確。當舉債利率低於資產報酬率，借入資金投入營運所賺取的報酬扣除利息後仍有剩餘，這部分剩餘全歸股東，使ROE高於ROA，這就是財務槓桿的正面效果，財務槓桿指數也會大於1。反之若舉債利率高於ROA，舉債愈多股東報酬愈低。

(D)錯誤。以ROE作為判斷基準會產生循環論證，因為ROE是槓桿的結果而不是原因；舉債利率小於ROE的公司仍可能因舉債利率大於ROA而使槓桿不利，判斷標準必須是ROA。
