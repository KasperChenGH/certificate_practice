3. 民法第106 條規定：「代理人，非經本人之許諾，不得為本人與自己之法律行為。」甲贈送一只手錶予其6 歲之子乙，甲為贈與人，同時也是乙之法定代理人，甲之贈與違反上開規定。但通說認為，此種贈與對被代理人乙並無不利，因此應排除該規定之適用。此一結論係基於何種解釋方法而得出？
  1. (A)類推適用
  2. (B)擴張解釋
  3. (C)當然解釋
  4. (D)目的性限縮解釋
解析

(A)錯誤。類推適用處理的是法律「未」規定的情形，把性質相類的規定比附援引過來填補漏洞，屬法律補充；本題第106條的文義原本就涵蓋這種自己代理，方向恰好相反。

(B)錯誤。擴張解釋是把文義由核心往邊緣情形推，使原本可疑是否包含的事例納入適用；本題要做的是把文義已包含的事例排除出去，是縮小而非擴大適用範圍。

(C)錯誤。當然解釋是「舉重以明輕、舉輕以明重」的推論，例如明文禁止攜犬入場，攜猛獸當然也在禁止之列；它並不涉及依規範目的限縮條文的適用範圍。

(D)正確。禁止自己代理的規範目的在防止代理人與本人之間的利益衝突。父親贈與6歲之子手錶，對被代理人純獲法律上利益，根本不存在這種衝突，於是雖在文義射程內，仍依規範目的把它排除於條文適用範圍之外，這就是目的性限縮解釋；解釋以目的為準，才不會讓條文在毫無保護必要之處僵化適用。

4. 法官於審理案件時，就應適用之法律，依其合理確信，認為有違憲疑慮，且於該案件之裁判結果有直接影響時，如何處理？

(D)錯誤。宣告法律違憲的權限專屬憲法法庭，個別法官不得自行拒絕適用法律。

6. 依中央法規標準法規定，法規規定之事項已執行完畢者，屬於下列何者？
  1. (A)修正原因
  2. (B)終止原因
  3. (C)廢止原因
  4. (D)失效原因
解析

(A)錯誤。修正是對仍有存在必要的法規增刪變更其內容，例如因政策或事實需要而增減內容，或配合其他法規的修正；規範的事項已消失時，要處理的不是改寫條文，而是讓整部法規退場。

(B)錯誤。中央法規標準法只設「修正」、「廢止」以及施行期限屆滿的當然廢止，並無「終止」這一法定類型；終止是契約法上使繼續性契約向後失效的用語。

(C)正確。中央法規標準法第21條列舉廢止事由，其中包含法規規定之事項已執行完畢，或因情勢變遷已無繼續施行之必要者。規範目的既已達成，法規繼續留在法典中只會造成體系混亂與適用疑義，故應由原制定機關依法定程序廢止。

(D)錯誤。失效是法規經廢止或所定施行期限屆滿後所生的結果——廢止的法規自公布或發布之日起算至第三日起失效；題目問的是使法規退場的原因，不是退場後的狀態。

7. 依司法院大法官解釋，關於資訊隱私權之敘述，下列何者正確？

  3. (C)人民對於國家所記載之個人資料，僅得請求閱覽，但無法請求更正
  4. (D)行政機關得逕行以命令限制資訊隱私權

(C)錯誤。人民對國家所記載的個人資料，除得請求閱覽外，於記載錯誤時亦得請求更正。

(D)錯誤。限制資訊隱私權須有法律或法律明確授權的命令為依據，機關不得逕以命令為之。

12. 依司法院大法官解釋，關於總統之國家機密特權，下列敘述何者正確？
  1. (A)憲法增修條文設有明文規定
  2. (B)不受權力分立原則之限制
  3. (C)基於國家機密特權，總統得決定不公開其職權範圍內有關國家安全、國防及外交之資訊
  4. (D)於刑事訴訟程序中，總統不得就國家機密事項主張拒絕證言權
解析

(A)錯誤。憲法及增修條文對國家機密特權並無明文規定，大法官是從總統依憲法所享有的職權（國家安全大政方針、國防、外交、締結條約等）屬行政權核心領域推導出這項權限。

(B)錯誤。國家機密特權仍受權力分立與制衡原則的拘束，不是不受審查的空白權力；大法官解釋同時設計了由法院審查機密主張是否成立的機制。

50. 下列何者不是刑法上的公務員？
  1. (A)直轄市長
  2. (B)承攬政府文宣之印製廠商
  3. (C)監獄管理員
  4. (D)法院法警
解析

(A)錯誤。直轄市長依法令服務於地方自治團體所屬機關且具法定職務權限，是身分公務員。

(B)正確。承攬政府文宣印製的廠商，是基於私法承攬契約提供勞務的相對人，既不從事公共事務，也無任何法定職務權限，不是刑法上的公務員。

(C)錯誤。監獄管理員執行戒護職務，是公務員。

(D)錯誤。法警依法令服務於法院並具法定職務權限，是公務員。
