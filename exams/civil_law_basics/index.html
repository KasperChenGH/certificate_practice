1. 關於公法與私法之區別，下列敘述何者錯誤？
  1. (A)救濟之方式不同，公法適用行政爭訟，私法則適用民事訴訟
  2. (B)強制執行之依據不同，公法適用行政執行法與行政訴訟法，私法適用強制執行法
  3. (C)損害賠償管道不同，公法適用國家賠償法，私法適用民法
  4. (D)勞動基準法之規範客體為私法上僱傭關係，故屬純粹的私法
解析

(A)錯誤。本題要選敘述錯誤者。公法爭議循行政爭訟、私法爭議循民事訴訟，此項正確。

(B)錯誤。本題要選敘述錯誤者。公法上金錢給付與行政處分的執行依行政執行法，私法上債權的執行依強制執行法，此項正確。

(C)錯誤。本題要選敘述錯誤者。公務員行使公權力致人民受損由國家賠償法處理，私人間的侵害則依民法，此項正確。

(D)正確。勞動基準法雖以僱傭關係為規範客體，但其中主管機關的勞動檢查、監督與罰則屬公法規範，通說認為它兼具公私法性質，並非「純粹的私法」。

2. 下列關於民事訴訟上和解，何者錯誤？
  1. (A)土地疆界糾紛之訴訟，得成立訴訟上和解
  2. (B)法院調解成立者，與訴訟上和解有同一之效力
  3. (C)當事人就未聲明之事項成立和解者，不得為執行名義
  4. (D)當事人於和解之意思已甚接近，得聲請法院於當事人表明之範圍內，定和解方案，於法院將和解方案送達兩造時，視為和解成立
解析

(A)錯誤。本題要選敘述錯誤者。土地疆界糾紛之訴訟得成立訴訟上和解。

(B)錯誤。本題要選敘述錯誤者。法院調解成立者，與訴訟上和解有同一效力。

(C)正確。當事人就未聲明的事項成立和解者，該部分同樣具有執行力，得為執行名義。此項為錯誤敘述。

(D)錯誤。本題要選敘述錯誤者。兩造和解意思已甚接近時，得聲請法院於其表明的範圍內定和解方案，方案送達兩造時視為和解成立。

(D)錯誤。移送檢察官偵查時，被告得選任辯護人。

5. 下列關於民事訴訟類型之敘述，何者正確？
  1. (A)確認法律關係之訴，非被告有即受確認判決之經濟上利益者，不得提起之。但胎兒身分之確認者，不在此限
  2. (B)請求將來給付之訴，以有預為請求之必要者為限，得提起之
  3. (C)確認法律關係之金錢相關基礎事實存否之訴，以被告不能提起其他訴訟，且其訴訟標的金額超過新臺幣10 萬元者為限
  4. (D)確認證書真偽者，在刑事偽造文書判決確定前，不得提起確認之訴。但原告有數人者，不在此限
解析

(A)錯誤。條文要求的是「原告」有即受確認判決之「法律上」利益，此項寫成被告的經濟上利益，兩處都錯。

(B)正確。將來給付之訴以有預為請求之必要者為限，才能就尚未到期的給付先行起訴。

(C)錯誤。確認基礎事實存否之訴，以「原告不能提起其他訴訟」者為限，且無訴訟標的金額的門檻。

(D)錯誤。確認證書真偽之訴得逕行提起，不以刑事偽造文書判決確定為前提。

6. 某公營事業依政府採購法辦理公開招標，並組成評選委員會，私立大學教授甲獲聘擔任評選委員，則甲之身分為何？
  1. (A)非屬刑法上之公務員
  2. (B)屬刑法上之身分公務員
  3. (C)屬刑法上之授權公務員
  4. (D)屬刑法上之委託公務員
解析

(A)錯誤。評選委員行使的是具有公共事務性質的職權，並非全然的私人身分。

(B)錯誤。身分公務員指依法令服務於國家、地方自治團體所屬機關而具有法定職務權限者；甲是外聘的私立大學教授，不具此身分。

(C)正確。甲雖非機關所屬人員，但依政府採購法令從事採購評選這項公共事務，並具有法定的職務權限，屬「依法令從事於公共事務而具有法定職務權限」的授權公務員。

(D)錯誤。委託公務員是受國家機關「委託」承辦公共事務者；甲的權限直接來自採購法令而非個別委託關係。

8. 下列關於權利能力與行為能力之敘述，何者錯誤？
  1. (A)人之權利能力，始於出生，終於死亡
  2. (B)受輔助宣告之人，無行為能力
  3. (C)法人於法令限制內，有享受權利負擔義務之能力。但專屬於自然人之權利義務，不在此限

(C)錯誤。本題要選敘述錯誤者。法人於法令限制內有權利能力，專屬於自然人者除外。

(D)錯誤。本題要選敘述錯誤者。權利能力及行為能力不得拋棄。

10. 關於行政行為應符合比例原則之要求，下列敘述何者錯誤？
  1. (A)行政機關採取之方法應有助於目的之達成
  2. (B)行政機關應選擇對人民權益損害最少之方法
  3. (C)行政機關應考量行政成本而選擇最具經濟效益之方法
  4. (D)採取方法所造成損害不得與欲達成目的之利益顯失均衡
解析

(A)錯誤。本題要選敘述錯誤者。手段有助於目的達成，即適當性原則。

(B)錯誤。本題要選敘述錯誤者。選擇損害最小的方法，即必要性原則。

(C)正確。比例原則衡量的是手段對人民權益的侵害與所追求公益之間的關係，行政成本與經濟效益屬行政效能的考量，不是比例原則的內涵。此項為錯誤敘述。

(D)錯誤。本題要選敘述錯誤者。損害與利益不得顯失均衡，即狹義比例原則。

11. 下列何者得依民法規定請求返還不當得利？
  1. (A)債務人甲於未到期之債務因清償而為給付者
  2. (B)因債務人乙清償債務而為給付，於給付時明知無給付之義務者
  3. (C)加工物所有權歸屬於材料所有人丙時，加工人丁請求償還價額
  4. (D)債務人戊之給付，係履行道德上之義務
解析

(A)錯誤。清償未到期債務者，債務本身存在，只是提前履行，不得請求返還。

(B)錯誤。給付時明知無給付義務仍為給付者，不得請求返還。

(C)正確。加工物依法歸材料所有人取得時，加工人因此受有損害而材料所有人受有利益，法律明定得依不當得利的規定請求償還價額。

(D)錯誤。履行道德上義務所為的給付，不得請求返還。

15. 下列何者不是形成權？
  1. (A)甲、乙二人共有一筆土地，因協議分割不成，甲提起訴訟，請求法院為裁判分割
  2. (B)甲售予車輛於乙，惟該車有瑕疵，乙向甲主張減少價金
  3. (C)甲與乙成立買賣契約，甲未給付價金，15 年後乙向甲請求給付價金，甲主張已超過15 年，拒絕給付價金
  4. (D)甲與乙成立買賣契約，但乙未於期限內給付，甲向乙解除契約
解析

(A)錯誤。共有人請求裁判分割，是行使分割請求權以形成新的權利狀態，性質上為形成權（形成之訴）。

(B)錯誤。減少價金是買受人單方意思表示即變更契約內容，屬形成權。

(C)正確。時效完成後債務人拒絕給付，行使的是時效抗辯權——它只讓債務人得以拒絕履行，並不使既存的法律關係發生變動，屬抗辯權而非形成權。

18. 依司法院大法官解釋，關於資訊隱私權之敘述，下列何者正確？
  1. (A)基於保障人性尊嚴所不可或缺之權利，應受到絕對保障
  2. (B)人民有決定是否揭露其個人資料之權利，以及知悉其個人資料被使用之權利
  3. (C)人民對於國家所記載之個人資料，僅得請求閱覽，但無法請求更正
  4. (D)行政機關得逕行以命令限制資訊隱私權
解析

(A)錯誤。資訊隱私權並非絕對保障，得以法律或法律明確授權的命令，於必要範圍內加以限制。

(B)正確。資訊隱私權保障人民自主決定是否揭露其個人資料、在何種範圍內揭露，並保障其知悉個人資料如何被使用與請求更正的權利。

(C)錯誤。人民對國家所記載的個人資料，除得請求閱覽外，於記載錯誤時亦得請求更正。

(D)錯誤。限制資訊隱私權須有法律或法律明確授權的命令為依據，機關不得逕以命令為之。
