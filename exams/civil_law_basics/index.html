1. 關於法律與命令的區別，下列敘述何者錯誤？
  1. (A)法律係由立法機關制定，而命令則由各機關訂定
  2. (B)通則為法律，細則為命令
  3. (C)法律與命令，均需經過總統公布後生效
  4. (D)以命令限制人民之權利義務，應有法律授權
解析

(A)錯誤。本題要選敘述錯誤者。法律由立法機關制定、命令由各機關依職權或授權訂定，此項正確。

(B)錯誤。本題要選敘述錯誤者。中央法規標準法規定法律得定名為法、律、條例、通則，命令則得稱規程、規則、細則、辦法等，此項正確。

(C)正確。法律須經立法院通過、總統公布始生效力；命令則由各主管機關自行發布，並不經總統公布。此項把兩者混為一談，是錯誤敘述。

(D)錯誤。本題要選敘述錯誤者。限制人民權利義務須有法律或法律明確授權，正是法律保留原則，此項正確。

2. 下列事件何者為人民不服時可提起訴願的標的？
  1. (A)稅捐稽徵機關對業者實施實地查核之行為
  2. (B)甲機關聘僱臨時人員所生薪資給付不足之爭議
  3. (C)丙所有之土地被乙機關徵收而對徵收價格不服之爭議
  4. (D)丁警員執行勤務不慎駕車撞傷人民戊所生的糾紛
解析

(A)錯誤。實地查核屬事實行為，不是行政處分，不得對之提起訴願。

(B)錯誤。機關聘僱臨時人員所生的薪資爭議屬私法契約關係，應循民事途徑解決。

(C)正確。土地徵收及其補償價格的核定屬行政處分，人民不服者得提起訴願。

(D)錯誤。警員執行勤務駕車撞傷人民，屬國家賠償事件，應依國家賠償法請求，非訴願標的。

3. 下列關於刑法第136 條聚眾妨害公務罪構成要件之敘述，何者正確？
  1. (A)行為主體限於公務員執行職務之相對人
  2. (B)行為地限於公共場所或公眾得出入之場所
  3. (C)聚集人數須達5 人以上
  4. (D)首謀及下手實施強暴脅迫，因而致公務員於死或重傷，與傷害致死或傷害致重傷罪，數罪併罰
解析

(A)錯誤。行為主體不限於公務員執行職務的相對人，在場聚集而下手或在場助勢之人均可能成立。

(B)正確。本罪以「在公共場所或公眾得出入之場所」聚集為要件，行為地確有限制。

(C)錯誤。本罪的聚集人數為三人以上，不是五人以上。

(D)錯誤。因而致公務員於死或重傷者，本條就首謀及下手實施之人另有加重處罰的規定，並非與傷害致死、致重傷罪數罪併罰。

5. 下列關於民事訴訟一事不再理與當事人恆定原則之敘述，何者正確？
  1. (A)訴訟繫屬中為訴訟標的之法律關係，雖移轉於第三人，於訴訟無影響
  2. (B)訴訟繫屬中為訴訟標的之法律關係，移轉於第三人時，第三人應於言詞辯論程序開始前，聲請承受訴訟，否則原訴訟程序無效
  3. (C)訴訟繫屬中為訴訟標的之法律關係，移轉於第三人時，當事人僅限於言詞辯論程序開始前，聲請訴訟告知，否則原訴訟程序無效
  4. (D)當事人不得就已起訴之事件，於訴訟繫屬中，更行起訴。但其訴訟標的超過新臺幣150 萬元或訴訟標的與公益相關者，不在此限
解析

(A)正確。這正是當事人恆定原則：訴訟繫屬中訴訟標的的法律關係縱已移轉於第三人，於訴訟並無影響，程序仍由原當事人續行。

(B)錯誤。受讓人並無在言詞辯論前聲請承受訴訟的義務，未承受也不會使原程序無效。

(C)錯誤。訴訟告知並非強制，未告知亦不影響原程序的效力。

(D)錯誤。重複起訴的禁止並無金額或公益的例外。

6. 甲、乙二人為丙女爭風吃醋，乃相約互毆，致甲、乙均受輕傷而互相提出刑事告訴。依實務見解，下列敘述何者正確？
  1. (A)甲、乙相約互毆不能主張正當防衛
  2. (B)甲、乙相約互毆不能提告，因為雙方均同意互相傷害對方
  3. (C)丙應負不作為幫助傷害責任
  4. (D)甲、乙相約互毆不能提告，因為雙方可主張同時履行抗辯
解析

(A)正確。相約互毆時，雙方都是出於侵害對方的意思而動手，不具防衛意思，實務見解一貫認為互毆的任一方均不得主張正當防衛。

(B)錯誤。傷害罪雖為告訴乃論，但事前的相約並不使告訴權消滅，雙方仍得互相提出告訴。

(C)錯誤。丙對甲乙的鬥毆並無法律上的防止義務，不成立不作為幫助。

(D)錯誤。同時履行抗辯是雙務契約的民事概念，與刑事追訴毫無關係。

8. 若具體事實不明或難以證明時，法律得為何種立法技術以暫時認定事實？
  1. (A)準用
  2. (B)類推
  3. (C)推定
  4. (D)但書
解析

(A)錯誤。準用是就性質相近的事項比照適用另一規定，處理的是規範的適用，不是事實的認定。

(B)錯誤。類推適用是填補法律漏洞的方法，同樣不是認定事實的技術。

(C)正確。推定是在事實不明時，先依常態經驗暫定其存在，容許當事人舉反證推翻——正是為事實難以證明而設的立法技術。

(D)錯誤。但書是條文中設定例外的體例，與事實認定無關。

9. 下列關於刑法第15 條第1 項規定不作為犯之敘述，何者錯誤？
  1. (A)以法律上有防止之義務者為限
  2. (B)須消極不作為與積極作為等價
  3. (C)須能防止而不防止
  4. (D)不作為犯按作為犯之刑減輕之
解析

(A)錯誤。本題要選敘述錯誤者。不純正不作為犯以行為人在法律上負有防止義務（保證人地位）為前提。

(B)錯誤。本題要選敘述錯誤者。不作為須與積極作為在不法內涵上等價。

(C)錯誤。本題要選敘述錯誤者。須有防止的可能性而不防止。

(D)正確。不純正不作為犯與作為犯適用同一法定刑，法律並未設減輕的規定。此項為錯誤敘述。

10. 依司法院大法官解釋，下列何者違反法律保留原則之要求？
  1. (A)行政院環境保護署（環境部）依據空氣污染防制法之授權規定訂定施行細則

(D)錯誤。裁罰基準是機關為統一裁量所訂的行政規則，得依職權訂定。

11. 關於除斥期間，下列敘述何者正確？
  1. (A)除斥期間經過後，縱當事人未援用，法院亦應依職權調查之
  2. (B)除斥期間，因債務人承認債務而中斷
  3. (C)除斥期間中斷者，自中斷之事由終止時，重行起算
  4. (D)除斥期間之適用客體為請求權
解析

(A)正確。除斥期間是權利存續的不變期間，期間一過權利當然消滅，法院應依職權調查，不待當事人主張。

(B)錯誤。中斷是消滅時效的制度，除斥期間不生中斷問題。

(C)錯誤。重行起算同樣是時效中斷的效果，除斥期間並無此制度。

(D)錯誤。除斥期間的客體是形成權；請求權適用的是消滅時效。

13. 一行為違反數個行政法上義務規定而應處罰鍰者，下列敘述何者錯誤？
  1. (A)依法定罰鍰額最高之規定裁處
  2. (B)裁處之額度，不得低於各該規定之罰鍰最低額
  3. (C)除應處罰鍰外，另有沒入或其他種類行政罰之處罰者，得依該規定併為裁處
  4. (D)一行為違反社會秩序維護法而應受處罰，如已裁處拘留者，得再裁處罰鍰
解析

(A)錯誤。本題要選敘述錯誤者。一行為違反數規定而應處罰鍰者，依法定罰鍰額最高之規定裁處。

(B)錯誤。本題要選敘述錯誤者。裁處額度不得低於各該規定的罰鍰最低額。

(C)錯誤。本題要選敘述錯誤者。沒入或其他種類的行政罰不被罰鍰吸收，得併為裁處。

14. 下列何種情形，鄰地所有人得請求拆除地上物？
  1. (A)土地所有人輕過失越界建築立體停車場，而鄰地所有人未即時異議
  2. (B)普通地上權人輕過失越界建築房屋，而鄰地所有人未即時異議
  3. (C)土地無權占有人輕過失越界建築納骨塔，而鄰地所有人未即時異議
  4. (D)土地承租人輕過失越界建築倉庫，而鄰地所有人未即時異議
解析

(A)錯誤。土地所有人非因故意或重大過失越界建築房屋，鄰地所有人知情而未即提出異議者，不得請求移去或變更；立體停車場屬與房屋價值相當的建築物，準用之。

(B)錯誤。越界建築的保護規定於地上權人等土地利用人準用，故亦不得請求拆除。

(C)正確。越界建築的保護以「土地所有人」及依法準用的地上權人、承租人等有權利用人為限；無權占有人本無使用該土地的權源，不受此保護，鄰地所有人仍得請求拆除。

(D)錯誤。承租人是土地利用人，準用越界建築的保護規定。

17. 下列何者不構成信賴利益的賠償？

  2. (B)自始主觀不能
  3. (C)締約上過失
  4. (D)錯誤意思表示之撤銷
解析

(A)錯誤。以自始客觀不能之給付為契約標的者契約無效，明知或可得而知的一方應賠償相對人因信契約有效而受的損害，正是信賴利益。

(B)正確。自始主觀不能（僅該債務人不能給付）契約仍屬有效，債權人得依債務不履行請求賠償「履行利益」，也就是契約若順利履行本可得到的利益，而不是信賴利益。

(C)錯誤。締約上過失的賠償範圍是相對人因信契約能成立而受的損害，屬信賴利益。

(D)錯誤。因錯誤而撤銷意思表示者，表意人對信其意思表示為有效而受損害的相對人負賠償責任，屬信賴利益。

18. 依司法院大法官解釋，關於法律保留原則，下列敘述何者正確？
  1. (A)對於人民生命之剝奪，應由憲法明文規範
  2. (B)對於人民財產權之限制，僅能以法律為之
  3. (C)對於人民入出境自由之限制，得由立法機關授權主管機關以命令限制之
  4. (D)社會福利給付之資格、方式，皆非法律保留事項，行政機關得自行發布命令加以規範
解析

(A)錯誤。剝奪生命的要件與程序，以法律規定即可，憲法未要求須由憲法本身明文規範。

(B)錯誤。依層級化法律保留，財產權的限制得由法律授權主管機關以命令為之，不以法律直接規定為限。

(C)正確。入出境自由的限制屬得以法律授權訂定命令加以規範的事項，只要授權的目的、內容、範圍具體明確即可。

(D)錯誤。社會福利給付雖屬給付行政，但涉及公共利益的重大事項者，仍應有法律或法律授權的命令為依據。

20. 司法警察詢問被逮捕之犯罪嫌疑人時，忘了告知犯罪嫌疑人可以保持緘默，不須違背自己之意思而陳述之要旨，而犯罪嫌疑人出於自由意志承認犯罪，犯罪嫌疑人此項自白有沒有證據能力？
  1. (A)沒有證據能力，因為違反權利告知的誡命規定
  2. (B)沒有證據能力，因為該自白是實施刑事訴訟程序之公務員因違背法定程序所取得
  3. (C)有證據能力，警察是有過失，但沒有惡意，且自白具有任意性
  4. (D)有證據能力，因為緘默權保障是被告的特權，可以放棄，一旦放棄，事後不能再假藉警察沒有告知此項權利而否定其自白真實性
解析

(A)錯誤。違反權利告知並非一律導致排除，法律另設有例外。

(B)錯誤。違背法定程序的效果須依條文所定的要件判斷，本件正落在例外之內。

(C)正確。詢問受拘提逮捕之人違反緘默權告知者，所得自白原則上不得為證據；但經證明其違背「非出於惡意」，且該自白係出於「自由意志」者，不在此限——本件警察是疏忽而非惡意，且自白出於自由意志，故有證據能力。

(D)錯誤。緘默權雖得放棄，但放棄須以已受告知為前提；本件之所以有證據能力，是因為符合法定的例外要件，不是因為權利一經放棄即不得再爭執。
