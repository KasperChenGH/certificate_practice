1. 下列關於法源的敘述，何者錯誤？
  1. (A)憲法為國家的根本大法，規範政府組織及人民的權利義務
  2. (B)法律經立法機關通過後，不待總統公布，即可發生效力
  3. (C)命令係指行政機關基於法律授權或職權，所發布之規章，必須要注意不得超越母法的規定

(D)錯誤。本題要選敘述錯誤者。憲法、法律、命令的位階順序確實如此。

4. 下列何者不是形成權？
  1. (A)甲、乙二人共有一筆土地，因協議分割不成，甲提起訴訟，請求法院為裁判分割
  2. (B)甲售予車輛於乙，惟該車有瑕疵，乙向甲主張減少價金
  3. (C)甲與乙成立買賣契約，甲未給付價金，15 年後乙向甲請求給付價金，甲主張已超過15 年，拒絕給付價金
  4. (D)甲與乙成立買賣契約，但乙未於期限內給付，甲向乙解除契約
解析

(A)錯誤。共有人請求裁判分割，是行使分割請求權以形成新的權利狀態，性質上為形成權（形成之訴）。

(B)錯誤。減少價金是買受人單方意思表示即變更契約內容，屬形成權。

(C)正確。時效完成後債務人拒絕給付，行使的是時效抗辯權——它只讓債務人得以拒絕履行，並不使既存的法律關係發生變動，屬抗辯權而非形成權。

(D)錯誤。解除契約是以單方意思表示消滅契約關係，是典型的形成權。

7. 依司法院大法官解釋，關於法律保留原則，下列敘述何者正確？

15. 關於辯護人之規定，下列敘述何者錯誤？
  1. (A)被告得隨時選任辯護人
  2. (B)審判中的被告才可選任辯護人
  3. (C)辯護人於偵查中之羈押審查程序，除法律另有規定外，得檢閱卷宗及證物並得抄錄或攝影
  4. (D)最輕本刑為3 年以上有期徒刑案件於審判中未經選任辯護人者，審判長應指定公設辯護人或律師為被告辯護
解析

(A)錯誤。本題要選敘述錯誤者。被告得隨時選任辯護人。

解析

(A)錯誤。聚合犯是須多數行為人朝同一方向共同實行的必要共犯，如聚眾犯罪。

(B)錯誤。集合犯指立法上預定同種行為反覆實行而僅論以一罪，如常業犯。

(C)錯誤。結合犯是立法將兩個獨立犯罪結合為一罪，如強盜殺人罪。

(D)正確。收賄與行賄是兩個方向相對、彼此合致才能完成的行為，屬必要共犯中的對向犯，各依其所犯的罪名分別處罰。

48. 關於刑法第24 條第1 項緊急避難規定之適用，下列敘述何者正確？
  1. (A)緊急避難情狀僅限於不法侵害情狀
  2. (B)以因避免緊急危難而出於不得已為要件
  3. (C)緊急避難過當與否，依據最後手段性原則判斷
  4. (D)以避免自己生命、身體之緊急危難為限
解析

(A)錯誤。緊急避難的危難來源不限於人的不法侵害，天災、動物侵襲、疾病等自然事實同樣可能構成——這正是它與正當防衛的重要差別。

(B)正確。條文要求須「因避免緊急危難而出於不得已」，即已無其他侵害較小的方法可資選擇。

(C)錯誤。是否過當，須綜合避難行為的必要程度與所保全、所犧牲法益的權衡而定，不是僅憑最後手段性一項判斷。

(D)錯誤。得保全的法益包括生命、身體、自由與財產，且不以自己的法益為限，他人的法益亦可。

49. 甲欲殺乙，誤丙為乙而殺之，屬於何種錯誤型態？

  2. (B)等價的客體錯誤
  3. (C)打擊錯誤
  4. (D)包攝錯誤
解析

(A)錯誤。因果歷程錯誤是結果雖如所欲發生，但發展過程與預想不同。

(B)正確。甲對行為客體的同一性發生誤認，而丙與乙同為「人」，兩者在構成要件上等價，故屬等價的客體錯誤；通說認為不阻卻故意，甲仍成立殺人既遂。

(C)錯誤。打擊錯誤是行為人瞄準的客體正確，卻因手段偏差而擊中他人；本件甲從頭到尾針對的就是眼前這個人。

(D)錯誤。包攝錯誤是行為人對法律概念的涵攝發生誤解，屬法律錯誤的一種。
