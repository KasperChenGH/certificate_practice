  4. (D)胎

(C)錯誤。典是以不動產供擔保並移轉占有使用收益的關係，後成為典權。

(D)錯誤。胎是以土地收益供債務擔保的舊慣，性質接近擔保物權。

3. 關於法規範與其他社會規範之區別，下列敘述何者正確？
  1. (A)法律規範與倫理道德，均需經過一定機關依一定程序制定
  2. (B)違反法律規範，可能會遭到國家公權力處罰，此係因為法律所具有之強制力
  3. (C)法律與倫理道德，均係成文規範
  4. (D)法律是社會上最高的道德標準

(C)錯誤。倫理道德並非成文規範。

(D)錯誤。法律通常被理解為「最低限度的道德」，而不是最高的道德標準。

4. 民法第860 條規定：「稱普通抵押權者，謂債權人對於債務人或第三人不移轉占有而供其債權擔保之不動產，得就該不動產賣得價金優先受償之權。」據此，動產不得作為民法上抵押權之標的物。下列何種解釋方法可得出此一結論？
  1. (A)反面解釋
  2. (B)限縮解釋
  3. (C)擴張解釋
  4. (D)類推解釋
解析

(A)正確。條文正面規定抵押權的標的是「不動產」，由此反面推論非不動產者不得為標的，這正是反面解釋。

(B)錯誤。限縮解釋是把文義所及的範圍縮小，本題並未縮小「不動產」的範圍。

(C)錯誤。擴張解釋是把文義擴及邊緣情形，與本題的推論方向相反。

(D)錯誤。類推適用是把規定比附援引至未規定的類似情形，結論會是「動產也適用」，與本題相反。

6. 關於自治法規，下列敘述何者錯誤？
  1. (A)自治條例係指經地方立法機關通過，並由各該行政機關公布者
  2. (B)自治規則係指由地方行政機關訂定，並發布或下達者
  3. (C)自治條例與憲法、法律或基於法律授權之法規或上級自治團體自治條例牴觸者，無效
  4. (D)創設、剝奪或限制地方自治團體居民之權利義務者，得以自治規則定之
解析

(A)錯誤。本題要選敘述錯誤者。自治條例經地方立法機關通過、由行政機關公布。

(B)錯誤。本題要選敘述錯誤者。自治規則由地方行政機關訂定並發布或下達。

(C)錯誤。本題要選敘述錯誤者。自治條例牴觸憲法、法律或上級自治團體自治條例者無效。

(D)正確。創設、剝奪或限制居民權利義務的事項，屬地方層級的法律保留，應以「自治條例」定之，不得僅以行政機關訂定的自治規則為之。此項為錯誤敘述。

8. 依司法院大法官解釋，下列何者不涉及基本權之防禦權功能？
  1. (A)國家機關就已服刑期滿之人民再行交付未定期限之管訓
  2. (B)民法未許相同性別二人可以結婚
  3. (C)法律限制原住民只能使用自製獵槍狩獵
  4. (D)公務人員就影響其權利之違法侵害，得向法院提起相應之行政訴訟
解析

(A)錯誤。服刑期滿後再交付未定期限的管訓，是國家對人身自由的積極侵害，人民請求排除，屬防禦權。

(B)錯誤。未許同性二人結婚，是國家對婚姻自由的限制，涉及防禦權功能。

(C)錯誤。限制狩獵所用槍枝的種類，是對原住民文化與生存權利的限制，屬防禦權。

(D)正確。請求國家「提供」訴訟途徑以獲得救濟，是要求國家有所作為，屬程序保障與受益權的功能；防禦權要求的則是國家「不作為」，兩者方向相反。

11. 憲法規定行政院向立法院負責，下列何者不是憲法增修條文所規定之負責方式？

(C)錯誤。「為受規範者所得預見」是明確性三要件之一。

(D)錯誤。「可經由司法審查加以確認」是明確性三要件之一。

16. 依司法院大法官解釋，下列何者違反法律保留原則之要求？
  1. (A)行政院環境保護署（環境部）依據空氣污染防制法之授權規定訂定施行細則
  2. (B)財政部國稅局就關稅法中所稱進口免稅物品之認定範圍發函解釋
  3. (C)經濟部為促進市場交易，依職權逕自向全國人民發放高額消費券
  4. (D)行政院農業委員會（農業部）自行訂定家畜家禽屠宰違法案件裁罰基準
解析

(A)錯誤。依母法授權訂定施行細則，正是合乎法律保留的作法。

(B)錯誤。就法律用語的認定範圍發布函釋，屬解釋性行政規則，不生法律保留問題。

(C)正確。發放高額消費券雖屬給付行政，但涉及龐大公帑與公共利益的重大事項，依層級化法律保留仍應有法律或法律授權的命令為依據；機關逕依職權為之，違反法律保留。

(D)錯誤。裁罰基準是機關為統一裁量所訂的行政規則，得依職權訂定。
