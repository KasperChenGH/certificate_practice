1. 關於法律與道德之比較，下列敘述何者正確？
  1. (A)法律與道德的成立與修改皆須經由一定程序才完成
  2. (B)法律與道德的強制力基礎皆是以國家公權力為後盾
  3. (C)法律與道德皆為個人行為的規範與評價標準
  4. (D)法律與道德在我國法體系中皆屬成文法規範
解析

(A)錯誤：道德的形成與變遷來自社會長期累積的共識，並無制定與修正的法定程序；須經提案、三讀、公布等程序的只有法律。

(B)錯誤：道德的拘束力來自良心、輿論與社會非難，並無國家公權力的強制執行；以公權力為後盾是法律特有的性質。

(C)正確：法律與道德都是評價並指引個人行為的社會規範，都對「應為」與「不應為」作出判斷，這是二者的共同點。差別在於制定程序、強制手段與規範範圍——法律只把道德中最低度、可強制執行的部分明定下來，其餘留給道德。

(D)錯誤：道德不是成文規範，我國法體系中的成文法源是憲法、法律與命令；道德最多透過公序良俗、誠信原則等概括條款間接進入法律。

2. 依民國108 年1 月4 日修正後的法院組織法，關於最高法院判例的適用，下列敘述何者正確？
  1. (A)無裁判全文可資查考之最高法院判例，停止適用
  2. (B)無裁判全文可資查考之最高法院判例，其效力與未經選編為判例之最高法院裁判相同
  3. (C)最高法院判例，無論有無裁判全文可資查考，均停止適用
  4. (D)有裁判全文可資查考之最高法院判例，其效力位階高於未經選編為判例之最高法院裁判
解析

(A)正確：民國一○八年一月四日修正的法院組織法設有判例效力的過渡規定：修正施行前依法選編的最高法院判例，若無裁判全文可資查考者，應停止適用。理由是判例原以摘要形式呈現，缺少裁判全文即無從檢驗其事實基礎與法律見解，繼續援用有違審判應以具體案件事實為據的要求。

(B)錯誤：「效力與未經選編為判例之最高法院裁判相同」講的是有裁判全文、未被停止適用的那些判例，它們降格為一般裁判；無全文可查考者是直接停止適用，兩種情形被對調了。

(C)錯誤：修法並未一律停止所有判例的適用。有裁判全文可資查考者繼續存在，只是不再享有拘束下級法院的特殊地位。

(D)錯誤：修法方向恰好相反，是取消判例的優越效力、使其與一般裁判等同，不再有位階高於其他最高法院裁判的說法。

3. 若具體事實不明或難以證明時，法律得為何種立法技術以暫時認定事實？
  1. (A)準用
  2. (B)類推
  3. (C)推定
  4. (D)但書
解析

(A)錯誤：準用是立法技術上明文指示「某事項比照另一規定辦理」，處理的是規範的援用而非事實的認定，例如民法把買賣的規定準用於其他有償契約。

(B)錯誤：類推是法官在法無明文時，就性質相類的事項比附援引既有規定以填補漏洞，屬法律適用（漏洞補充）方法而非立法技術，且刑法上禁止不利於行為人的類推。

(C)正確：推定是立法者在具體事實不明或難以證明時，先依經驗法則暫時認定某事實存在，藉此分配舉證責任，例如受婚生推定的子女、失蹤人的死亡推定。推定的關鍵在於允許舉反證推翻，這正是它與不容反證的「視為」（擬制）之間的分界。

(D)錯誤：但書是條文結構上的用語，用來為本文設定例外要件，例如「……但……者，不在此限」，與事實的暫時認定無關。

4. 行政機關可在數個合法、可行的途徑中選擇其認為最適合、最可以達成行政目的之方法，此種原則為：
  1. (A)行政一體
  2. (B)裁量
  3. (C)事實之涵攝
  4. (D)一事不再理
解析

(A)錯誤：行政一體是組織法上的原則，指行政權歸屬統一、上級得指揮監督下級以確保責任歸屬明確，與個案中選擇何種手段無關。

(B)正確：這是行政裁量。法律就手段或法律效果留有選擇空間時，行政機關得在合法範圍內選擇其認為最能達成行政目的者；行政程序法第10條同時設限——行使裁量權不得逾越法定之裁量範圍，並應符合法規授權之目的。授與裁量是因為立法者無法預見所有個案，需由熟悉現場的機關作合乎事理的調整。

(C)錯誤：事實之涵攝是法律適用的推論過程，把具體事實歸入法條的構成要件之下，屬認定工作，不是在數個合法手段間作選擇。

(D)錯誤：一事不再理是程序法原則，禁止就同一事件重複起訴或重複處罰，與手段選擇的判斷空間無關。

5. 關於自律規則，下列敘述何者錯誤？
  1. (A)自律規則係地方立法機關基於議會自律權而來，性質上為議會的內部事項規範
  2. (B)與地方居民之權利義務相關之事項，亦得以自律規則定之
  3. (C)自律規則除法律或自治條例另有規定外，原則上係由各該立法機關發布，並且須報各該上級政府備查
  4. (D)自律規則不得牴觸上級自治法規

6. 修正法規時，如欲廢止或增加少數條文時，應為如何之處理？
  1. (A)不保留所廢條文之條次
  2. (B)保留所廢條文之內容，且須註明「刪除」二字
  3. (C)得將增加之條文，列在適當條文之後，冠以前條「之一」、「之二」等條次
  4. (D)增加編或章時，不得冠以「之一」、「之二」等編或章次
解析

(A)錯誤：中央法規標準法第10條第1項規定修正法規廢止少數條文時，得保留所廢條文之條次；保留條次才能避免其後條文全部挪動、引用關係全面錯亂。

(B)錯誤：保留的是條次而不是內容。依中央法規標準法第10條第1項，應在該條次下加括弧註明「刪除」二字，原條文內容並不留存。

(C)正確：中央法規標準法第10條第2項規定修正法規增加少數條文時，得將增加之條文列在適當條文之後，冠以前條「之一」、「之二」等條次。這種作法讓新增規定放在體系上正確的位置，又不必變動其後所有條次與大量引用該條次的條文。

(D)錯誤：同條第3項規定廢止或增加編、章、節、款、目時準用前二項，因此增加編或章時同樣得冠以「之一」、「之二」等次別。

  1. (A)雙首長制
  2. (B)權力分立與制衡
  3. (C)國家固有疆域
  4. (D)修憲程序
解析

(A)錯誤：行政院長與總統之間的權責配置屬憲政體制的制度設計，歷次修憲已數度調整行政院長的任命與對立法院的責任，並非不可變動的憲法核心。

(B)正確：司法院釋字第499號指出，憲法中具有本質重要性而為規範秩序存立基礎者，如民主共和國原則、國民主權原則、人民權利之保障，以及權力分立與制衡之憲政原則，乃憲法整體基本原則所在，不容以修憲程序變更。否則修憲權將可自我廢棄憲法，形成披著合法外衣的憲政破毀。

(C)錯誤：固有疆域見於憲法第4條，其變更依憲法增修條文第4條設有明定程序，屬得依程序處理的事項；釋字第328號更認為疆域範圍的界定屬重大政治問題，不受司法審查。

(D)錯誤：修憲程序本身即由憲法增修條文所規定，且已多次改變——由國民大會修憲改為立法院提案、公民複決，可見它是可以變動的規定，而非不可變動的核心。

9. 國立警察大學碩士班入學之招生簡章，限制有色盲者不得報考。依司法院憲法解釋意旨，該規定所涉及之基本權，下列敘述何者最正確？

12. 下列何者不屬於「法律保留原則」之內涵？
  1. (A)行政行為或其他一切行政活動，均不得與法律相牴觸
  2. (B)憲法要求特定事項須由立法機關以法律加以規定

(B)錯誤。特定事項須由立法者以法律規定，正是法律保留的核心。

(C)錯誤。依規範對象與所涉法益輕重決定保留密度，即層級化法律保留，屬其內涵。

(D)錯誤。組織法的授權不等於作用法的授權，是法律保留在行政組織上的具體要求。

48. 刑法關於過失之敘述，何者錯誤？

  4. (D)按照情節應注意，並能注意，而不注意者，為過失
解析

(A)錯誤（此項敘述無誤）。刑法第12條第2項明定過失行為之處罰以有特別規定者為限，因此過失致死、過失傷害等須有明文，並非每個故意犯都配有對應的過失犯。

(B)正確（此項敘述有誤）。刑法第14條第2項規定，行為人對於構成犯罪之事實雖預見其能發生而確信其不發生者「以過失論」，這正是有認識過失；此項稱其非過失，把條文的結論說反了。有認識過失與間接故意的分界在於行為人主觀上是否容認結果發生，而不在有無預見。

(D)錯誤（此項敘述無誤）。刑法第14條第1項的無認識過失定義正是「按其情節應注意，並能注意，而不注意」，此項與條文相符。
