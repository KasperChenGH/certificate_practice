1. 關於法律與道德之比較，下列敘述何者正確？
  1. (A)法律與道德的成立與修改皆須經由一定程序才完成
  2. (B)法律與道德的強制力基礎皆是以國家公權力為後盾
  3. (C)法律與道德皆為個人行為的規範與評價標準
  4. (D)法律與道德在我國法體系中皆屬成文法規範
解析

(A)錯誤。法律的制定與修改須經立法程序，道德則在社會生活中自然形成與變遷，沒有既定程序。

(B)錯誤。法律以國家公權力為後盾，道德的制約力來自輿論、良心與社會評價。

(C)正確。兩者都在指引人應如何行為，並據以評價行為的對錯，這是法律與道德最主要的共通點。

(D)錯誤。道德不是成文法規範，也不在法體系的位階之中。

3. 若具體事實不明或難以證明時，法律得為何種立法技術以暫時認定事實？
  1. (A)準用
  2. (B)類推
  3. (C)推定
  4. (D)但書
解析

(A)錯誤。準用是就性質相近的事項比照適用另一規定，處理的是規範的適用，不是事實的認定。

(B)錯誤。類推適用是填補法律漏洞的方法，同樣不是認定事實的技術。

(C)正確。推定是在事實不明時，先依常態經驗暫定其存在，容許當事人舉反證推翻——正是為事實難以證明而設的立法技術。

(D)錯誤。但書是條文中設定例外的體例，與事實認定無關。

6. 修正法規時，如欲廢止或增加少數條文時，應為如何之處理？
  1. (A)不保留所廢條文之條次
  2. (B)保留所廢條文之內容，且須註明「刪除」二字
  3. (C)得將增加之條文，列在適當條文之後，冠以前條「之一」、「之二」等條次
  4. (D)增加編或章時，不得冠以「之一」、「之二」等編或章次
解析

(A)錯誤。廢止少數條文時，得保留所廢條文的條次，以免其後條文全部變動。

(B)錯誤。保留的是條次而非內容，並在該條次下加括弧註明「刪除」。

(C)正確。增加少數條文時，將其列在適當條文之後，冠以前條的「之一」「之二」等條次，原有條次因而不必更動。

(D)錯誤。增加編、章、節、款、目時，同樣得冠以「之一」「之二」等次。

12. 下列何者不屬於「法律保留原則」之內涵？
  1. (A)行政行為或其他一切行政活動，均不得與法律相牴觸
  2. (B)憲法要求特定事項須由立法機關以法律加以規定

(B)錯誤。特定事項須由立法者以法律規定，正是法律保留的核心。

(C)錯誤。依規範對象與所涉法益輕重決定保留密度，即層級化法律保留，屬其內涵。

(D)錯誤。組織法的授權不等於作用法的授權，是法律保留在行政組織上的具體要求。

15. 若交通監理機關依職權要求，換發行車執照前，須先繳清違規罰鍰，否則不得辦理。此可能涉及下列何原則？

  2. (B)法律優位原則
  3. (C)不當聯結禁止原則
  4. (D)信賴保護原則
解析

(A)錯誤。問題不在手段是否過度，而在兩件事根本不該綁在一起。

(B)錯誤。法律優位處理的是行政行為牴觸法律的問題。
