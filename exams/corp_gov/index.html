1. 依代理理論,股東與專業經理人之間之所以產生代理問題,最根本的原因是下列何者?
  1. (A)公司規模過大,組織層級過多而使上下溝通失真
  2. (B)所有權與經營權分離,雙方目標不一致且資訊不對稱
  3. (C)公司採行過高的財務槓桿,使利息負擔加重而償債壓力升高
  4. (D)主管機關對公開發行公司的申報與行政檢查過於寬鬆
解析

(A)錯誤。組織層級過多屬管理效率與內部溝通議題,可能放大代理問題,但不是代理關係產生的原因;代理問題在小型公司只要所有權與經營權分離同樣存在。

(B)正確。代理關係源自委託人(股東)將決策權授予代理人(經理人),兩者效用函數不同(經理人偏好在職消費、規模擴張、低風險以保住職位),且股東無法完全觀察經理人的努力與資訊,因而產生代理問題與代理成本。

(C)錯誤。高財務槓桿引發的是股東與債權人之間的代理衝突(如資產替代、投資不足),屬於代理問題的另一種類型,而非股東與經理人衝突的根源。

(D)錯誤。法規密度屬外部治理機制的強弱,影響代理問題被抑制的程度;即使監理極為嚴格,只要經營權與所有權分離,代理問題仍然存在。

2. 除各項交易循環外，處理準則另要求公司就特定事項建立控制作業。下列何者屬之？
  1. (A)證券交易所對上市公司所為之定期財務業務查核及缺失改善列管
  2. (B)董事會議事運作之管理、關係人交易之管理及防範內線交易之管理
  3. (C)股東會出席委託書之徵求、價購與使用行為之查核、處理及列管
  4. (D)會計師事務所查核品質管制制度之建立、定期覆核及缺失改善追蹤
解析

(A)錯誤。交易所查核屬自律機構的外部監理行為，非公司自建之控制作業。

(B)正確。該準則除交易循環外，另列有印鑑使用、財務及非財務資訊之管理、關係人交易之管理、財務報表編製流程之管理、對子公司之監督與管理、董事會議事運作之管理及防範內線交易之管理等控制作業；把董事會運作與內線交易防範寫進內控，正是內部控制與公司治理接合之處。

(C)錯誤。委託書之徵求與價購另受公開發行公司出席股東會使用委託書規則規範，不是本準則所列的控制作業項目。

(D)錯誤。會計師事務所之品質管制屬事務所本身與會計師相關規範的範疇，與受查公司的內部控制制度分屬不同主體。

3. 上市上櫃公司依公司治理實務守則推動董事進修，下列敘述何者最為適當？
  1. (A)進修內容宜限於財務會計，其餘專業領域屬經理人的職能範圍
  2. (B)公司應建立進修制度、編列必要預算，並揭露董事進修情形
  3. (C)進修僅適用於新任董事，連任董事已熟悉業務而無須進修
  4. (D)董事進修屬個人事務，公司不宜介入安排或提供任何協助
解析

(A)錯誤。進修範圍涵蓋公司業務與財務、風險管理、法律、會計、公司治理及永續發展等主題，目的是使董事有能力監督全面性的經營風險，不限於單一領域。

(B)正確。守則要求公司建立董事進修制度、編列必要預算並主動規劃安排課程，且將進修情形列入揭露，使進修成為可被檢視的公司制度，而非委諸董事個人自覺。

(C)錯誤。新任者需要的是就任前後的職務認知課程，連任董事則須因應法規修正與產業環境變動持續進修，兩者性質不同但都不可省略。

(D)錯誤。董事的專業能力直接影響董事會決議品質，屬公司治理制度的一環，守則明確課予公司協助與安排的責任。

4. OECD 公司治理原則就資訊揭露與透明度所揭示的精神,最接近下列何者?
  1. (A)揭露義務僅及於持股逾半數的控制股東,其餘股東與投資人不得請求
  2. (B)只需揭露法令明文列舉的財務數字,其餘事項一概由公司視需要自行決定
  3. (C)就公司財務、經營績效、股權結構與治理狀況等重大事項適時且正確揭露
  4. (D)為維護商業機密與競爭地位,治理相關資訊原則上不宜對外公開
解析

(A)錯誤。揭露的對象是市場與全體股東,目的正是讓不具資訊優勢的少數股東與潛在投資人能取得判斷所需資訊,而非只服務控制股東。

(B)錯誤。以列舉項目為上限的思維會讓公司迴避揭露真正影響判斷的事項;原則採重大性標準,凡足以影響投資判斷者即應揭露,不以法定清單為限。

(C)正確。該原則要求確保公司所有重大事項(包括財務與經營成果、公司目標、主要股權與表決權結構、董事及經理人資訊與報酬、關係人交易、可預見的風險因素、治理架構與政策)適時、正確揭露,且應依高品質的會計與揭露標準編製。

(D)錯誤。原則承認商業機密與成本效益的界限,但那是例外而非通則;以機密為由普遍不揭露,將使外部監督與市場定價功能失靈。

5. 關於監察人與審計委員會在職權行使方式上的差異,下列敘述何者正確?
  1. (A)監察人各得單獨行使職權,審計委員會則採合議制以決議行使
  2. (B)兩者均採合議制行使職權,差別僅在於法定成員人數的多寡
  3. (C)兩者均得單獨行使職權,差別僅在於任期長短與報酬決定方式
  4. (D)監察人須開會決議始得行使職權,審計委員會則採獨任制
解析

(A)正確。監察人為獨任制,縱設有數名,各得單獨調查業務財務狀況、查核簿冊文件並在必要時代表公司,不必取得其他監察人同意;審計委員會是董事會下的合議機關,須召開會議並依決議行使職權,個別委員不能單獨代表委員會作成意思表示。

(B)錯誤。監察人並非合議機關,毋須開會決議即可行使職權;兩者的差別在於組織原理,不只是人數。

(C)錯誤。審計委員會不能由單一委員逕行行使職權,且兩者的關鍵區別在獨任與合議的組織原理,不在任期或報酬決定方式。

(D)錯誤。敘述完全顛倒。監察人數人時各自獨立,審計委員會則須以會議決議方式行使職權。

6. 依公司法，股份有限公司之股東會、董事會與監察人三個法定機關，其基本功能定位下列何者正確？
  1. (A)股東會為意思機關，董事會為業務執行機關，監察人為監督機關
  2. (B)股東會為監督機關，董事會為意思機關，監察人為業務執行機關
  3. (C)股東會為意思機關，董事會為監督機關，監察人為業務執行機關
  4. (D)股東會為業務執行機關，董事會為監督機關，監察人為意思機關
解析

(A)正確。公司法將股東會定位為形成公司意思的機關、董事會為執行業務的機關、監察人為監督業務執行與財務的機關，三者權責分立、互相制衡，此即所有與經營分離下的機關分工。

(B)錯誤。監察人不參與業務執行，公司法明文將業務執行歸屬董事會，監察人若介入執行即失其監督者的中立地位。

(C)錯誤。董事會是執行機關而非監督機關；監察人負責監督，不得兼任董事、經理人或其他職員，自不可能是業務執行機關。

(D)錯誤。股東會並不執行業務，其功能在於形成公司意思；監督權則屬監察人，而非股東會或董事會之外的第三種安排。

7. 關於股東請求查閱公司章程、簿冊等文件之權利，下列敘述何者正確？
  1. (A)股東得檢具利害關係證明文件，指定範圍，請求查閱或抄錄章程及法定簿冊
  2. (B)股東須先取得董事會之同意，始得查閱公司之任何文件或簿冊
  3. (C)查閱權為少數股東權，須持股達一定比例並繼續持有一定期間始得行使
  4. (D)股東欲查閱公司簿冊，須先向法院聲請裁定許可後，始得為之
解析

(A)正確。公司法賦予股東（及公司債權人）檢具利害關係證明文件並指定範圍後查閱抄錄的權利。要求「證明文件」與「指定範圍」是為防止漫無邊際的搜索，但不必先取得公司同意——否則資訊權將由被監督者掌控。

(B)錯誤。若查閱須經董事會同意，最需要被檢視的情形反而最查不到；查閱權正是為避免此一結果而設。

(C)錯誤。查閱法定簿冊屬單獨股東權，並無持股門檻；持股比例與期間的要件出現在聲請法院選派檢查人等場合。

(D)錯誤。一般簿冊的查閱是逕向公司請求，不必先經法院；法院介入的是選派檢查人這類更具侵入性的調查。

8. 某人並未經股東會選任為董事，卻實質控制公司之人事、財務或業務經營，並實質指揮董事執行業務。依公司法之規範，其法律地位為何？
  1. (A)僅於其自認具有董事身分並對外表明時，始須負董事之責任
  2. (B)因未經合法選任為董事，故不負任何公司法上之董事責任
  3. (C)與公司法所稱之董事同負民事、刑事及行政罰之責任
  4. (D)僅須負民事上之損害賠償責任，不生刑事及行政罰責任問題
解析

(A)錯誤。認定標準是客觀上是否實質執行董事業務或實質指揮董事，不取決於當事人主觀的自我認知或對外宣稱。

(B)錯誤。若以「未經選任」即可免責，幕後操控者只要不掛名就能享有支配之利而不負其責，公司治理將出現最大的漏洞。

(C)正確。這就是實質董事（影子董事、事實上董事）的概念：法律看的是誰實際上在行使董事的職權，而非形式上的名分，因此使其與董事同負民事、刑事及行政罰責任，讓權力與責任重新對齊。

(D)錯誤。實質董事的責任範圍及於民事、刑事與行政罰，並未限於民事賠償。

9. 關於薪資報酬委員會的法源地位,下列敘述何者正確?
  1. (A)係公司章程得自行約定之自治事項,法律上並未要求任何類型的公司必須設置
  2. (B)係股東會下設之常設監督機關,其成員由股東會逐一選任並對股東會負責
  3. (C)係證券交易所自律規範所創設之組織,其設置與證券交易法並無關聯
  4. (D)係證券交易法明定應設置之委員會,其設置及行使職權辦法由主管機關訂定
解析

(A)錯誤。對上市櫃公司而言其設置是強制的,公司無從以章程約定排除;章程僅能在法律框架內作補充規定。

(B)錯誤。薪資報酬委員會是董事會下設的功能性委員會,成員由董事會決議委任,對董事會負責並向董事會提出建議,並非股東會的下設機關。

(C)錯誤。其設置義務直接來自證券交易法,交易所規章只是配套落實的規範,並非創設依據。

(D)正確。證券交易法明定股票已在證券交易所上市或於證券商營業處所買賣之公司應設置薪資報酬委員會,並授權主管機關訂定其成員資格、人數、職權行使等事項的辦法,故屬法定而非任意設置的委員會。

10. 就公開發行公司財務報告不實的民事責任,下列敘述何者正確?
  1. (A)所有責任主體一律負無過失責任,縱已盡相當注意亦無舉證免責的空間
  2. (B)發行人以外之責任主體,得證明已盡相當注意且有正當理由確信其內容無虛偽隱匿而免責
  3. (C)所有責任主體不論其行為情節,一律就全部損害負連帶賠償責任,而不區分責任比例的高低
  4. (D)責任主體僅對持有該公司股票滿一年以上之股東負賠償責任,其餘不得請求
解析

(A)錯誤。若連已盡專業注意之人都無從免責,將無人願意擔任董事或簽證會計師;法律因此對發行人以外之人保留舉證免責的空間。

(B)正確。制度採推定過失並倒置舉證責任:請求權人不必證明被告有過失,被告則須舉證自己已盡相當注意,且有正當理由可合理確信財務報告內容無虛偽或隱匿,始得免負賠償責任。

(C)錯誤。對發行人以外之人及簽證會計師,法律採責任比例的設計,依其行為對損害所應負責的程度定其賠償金額,而非一律全額連帶。

(D)錯誤。請求權人是善意取得或出賣該有價證券之人,並不以持股期間長短為條件。
