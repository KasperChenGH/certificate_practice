1. 《氣候變遷綱要公約》(UNFCCC)是於哪一個會議中所提出？
  1. (A)人類環境會議(Conference on the Human Environment)
  2. (B)巴黎會議(Paris Conference)
  3. (C)日內瓦會議(Geneva Conference)
  4. (D)聯合國環境與發展會議(UNCED)
解析

(A)錯誤。1972 年斯德哥爾摩的人類環境會議是全球環境治理的起點，成果為人類環境宣言與聯合國環境規劃署(UNEP)的成立，當時氣候公約尚未成形。

(B)錯誤。巴黎會議即2015 年的COP21，是UNFCCC 生效後的第21 次締約方大會，成果為巴黎協定；它運作於公約之下，不可能是公約的提出場合。

(C)錯誤。與日內瓦相關的是世界氣候會議與COP2 的部長宣言，屬公約體系運作過程中的會議，並非公約的誕生地。

(D)正確。1992 年在里約熱內盧舉行的聯合國環境與發展會議（UNCED，即地球高峰會）開放簽署《氣候變遷綱要公約》，同場並促成生物多樣性公約與21 世紀議程。UNFCCC 於1994 年生效，其後每年召開的COP 以及京都議定書、巴黎協定都建立在這部母公約之上。

  1. (A)碳邊境調整機制(CBAM)
  2. (B)永續金融揭露規範(SFDR)
  3. (C)企業永續報告指令(CSRD)

(A)錯誤。CBAM是針對進口產品碳含量課徵成本的邊境機制，非揭露規範。

(D)錯誤。永續分類標準界定何謂永續經濟活動，本身不直接課予金融機構揭露義務。

3. 按照永續金融揭露規範(SFDR)的規定，金融市場參與者和財務顧問需揭露哪兩類金融產品的資訊？
  1. (A)促進環境或社會特徵的產品及促進獲利目標的產品
  2. (B)促進環境或社會特徵的產品及促進永續性目標的產品
  3. (C)促進氣候公平正義的產品及促進永續性目標的產品
  4. (D)促進氣候公平正義的產品及促進獲利目標的產品
解析

(A)錯誤。前半正確，但SFDR 沒有「促進獲利目標的產品」這一類。獲利是所有金融產品的共同屬性，無法作為永續揭露的分類軸。

(B)正確。SFDR 對兩類產品課予加重揭露：促進環境或社會特徵的產品（第8 條，俗稱淺綠）與以永續投資為目標的產品（第9 條，深綠），並要求說明永續指標、達成方式與主要不利影響。分成兩級是為了區別「納入ESG 考量」與「以永續為明確目標」，避免前者被行銷成後者，屬防漂綠的制度設計。

(C)錯誤。「氣候公平正義」是氣候政策的倡議語彙，不是SFDR 的產品分類；SFDR 第一類講的是環境或社會特徵，涵蓋範圍比氣候正義寬。

(D)錯誤。兩個名稱都不是SFDR 的分類。把揭露義務理解成區分「氣候正義產品」與「獲利產品」，會完全錯失第8 條與第9 條的分級邏輯。

5. 金融業如何讓企業及投資人能重視永續議題，下列哪一項是建議採取的方法？
  1. (A)提供ESG 投資商品
  2. (B)將ESG 納入投融資授信參考
  3. (C)提供企業綠色轉型貸款服務
  4. (D)以上皆是
解析

(A)錯誤。提供ESG 投資商品可引導投資人資金，但它只作用在資產管理端，未涵蓋授信審查與企業轉型的資金需求。

(B)錯誤。將ESG 納入投融資授信參考是關鍵作法，讓企業的永續表現直接影響取得資金的條件，不過這只是三項並行手段之一。

(C)錯誤。綠色轉型貸款協助企業取得減碳所需資金，屬轉型金融的具體工具，同樣只是其中一項。

(D)正確。金融業影響永續的槓桿在於資金配置：提供ESG 商品引導投資人選擇、把ESG 納入投融資與授信審查形成價格與額度誘因、再以綠色轉型貸款支持企業實際減碳，三者分別覆蓋投資端、審查端與資金供給端。金管會綠色金融行動方案也是沿同一邏輯同時推動商品、授信與轉型金融。

6. 《企業永續報告指令》(CSRD)主要規定歐盟的哪些企業需根據歐洲永續性報告標準(ESRS)揭露其所面臨的社會和環境風險，以及企業活動對民眾和環境影響之報告？

  2. (B)中小型企業
  3. (C)未上市上櫃企業

解析

(A)錯誤。新創企業規模小、未達員工數與營收門檻，不在CSRD 的適用範圍；歐盟另以自願性簡化標準處理中小企業的永續揭露。

7. 聯合國政府間氣候變遷專門委員會(IPCC)主要提供何種資訊？
  1. (A)揭露碳排放量數據
  2. (B)氣候變遷的科學評估報告
  3. (C)制定能源政策
  4. (D)永續分類標準
解析

(A)錯誤。揭露碳排放量數據是各國依UNFCCC 提交國家溫室氣體清冊、企業依GHG Protocol 盤查的工作；IPCC 只制定盤查方法指引，不代為揭露。

(B)正確。IPCC 由世界氣象組織與聯合國環境規劃署於1988 年共同成立，本身不執行研究，而是彙整全球既有文獻，產出評估報告（現為AR6）與特別報告，作為談判與政策的科學基礎。它刻意維持「政策相關但不指定政策」的立場，才能被所有締約方共同接受為科學參考。

(D)錯誤。永續分類標準由歐盟Taxonomy、我國永續經濟活動認定參考指引等金融監理文件訂定，屬金融領域的認定工具，與IPCC 的科學評估工作無關。

12. 氣候變遷是地球和人類的重大課題，亦於哪個協定中，揭示為全世界共通的長期目標？
  1. (A)「柏林授權」(Berlin Mandate)
  2. (B)《日內瓦部長宣言》(The Geneva Ministerial Declaration)
  3. (C)「巴黎協定」(Paris Agreement)
  4. (D)京都議定書(Kyoto Protocol)
解析

(A)錯誤。柏林授權是1995 年COP1 的決議，內容是授權談判、要求為已開發國家訂出量化減量義務，最終成果是京都議定書，本身並未揭示全球長期目標。

(B)錯誤。《日內瓦部長宣言》為1996 年COP2 的政治文件，重點在確認IPCC 第二次評估報告的科學結論並推動具拘束力的議定書談判。

(C)正確。2015 年通過的巴黎協定首次把「將全球平均氣溫升幅控制在低於工業化前水準2°C 以內，並努力限制在1.5°C」寫成全體締約方共通的長期目標，另訂有提升調適能力與使資金流與低碳發展一致的目標。它以各國自主貢獻(NDC)加五年全球盤點的棘輪機制取代自上而下的分配，才得以把開發中國家一併納入。

(D)錯誤。京都議定書為附件一國家設定量化減量承諾（第一承諾期相對1990 年約減5%），屬分配式的階段性義務，並未訂出全球共通的溫升上限目標。

64. 金融機構發行永續金融商品和傳統金融商品主要的不同考量為何？

  2. (B)考量金融商品名稱是否有永續

(C)正確。差別在於商品的標的篩選、授信或投資決策、定價與後續監控是否實際納入環境、社會與治理因子，例如永續連結貸款把利率與借款人的減碳 KPI 連動、ESG 基金以負面排除或同類最佳方式建構組合。有無這層實質的 ESG 整合，才是永續商品與傳統商品的分界，也是判斷是否漂綠的關鍵。

65. 永續保險如何協助個人或企業應對環境風險？
  1. (A)針對自然災害提供保險保障
  2. (B)協助企業投資於高風險的專案
  3. (C)提供低成本的意外險
  4. (D)提供現金回饋作為投資誘因
解析

(A)正確。永續保險最直接的功能是把氣候實體風險造成的損失予以移轉與分攤：颱風、洪水、乾旱等自然災害透過巨災保險、農業保險等商品承保，使個人與企業在災後能迅速取得復原資金。保險同時以費率與承保條件反映風險高低，引導被保險人採取防災與調適措施，這也是聯合國永續保險原則（PSI）所強調的角色。

(B)錯誤。協助企業投資高風險專案不是永續保險的功能；保險業資金運用受法規限制並須配合負債特性，永續保險關注的是承保端如何因應環境風險，以及資金是否投向低碳與具永續效益的活動。

(C)錯誤。低成本、低保額的保單屬微型保險，對應的是普惠金融這項社會面議題，讓經濟弱勢者也能取得基本保障；意外險承保的是意外傷害事故，與颱風、洪水等環境風險的移轉並非同一件事。

(D)錯誤。現金回饋屬行銷或保費折扣誘因（例如外溢效果保單以健康行為換取折扣），回饋本身不移轉任何環境風險；真正因應環境風險的是承保範圍、費率設計與理賠給付的安排。
