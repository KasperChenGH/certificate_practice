  2. (B)僅涉及公司內部管理措施

  4. (D)管理公司對經濟、環境及社會風險與影響

  2. (B)永續分類標準(Taxonomy Regulation)
  3. (C)歐洲綠色政綱(European Green Deal)
  4. (D)碳邊境調整機制(CBAM)

(A)錯誤。企業永續報告指令（CSRD）規範的是企業永續資訊的報導範圍、適用準則與確信義務，本身不界定何種經濟活動屬於永續。

(B)正確。永續分類標準（Taxonomy Regulation）以六大環境目標、實質貢獻、不造成重大危害（DNSH）與最低社會保障等技術篩選標準，界定哪些經濟活動可被視為永續，成為各國制定綠色標準與指引的共同參考，我國的永續經濟活動認定參考指引亦以其為藍本。建立一致定義的目的，就是讓綠色宣稱可被檢驗，從源頭防止漂綠。

(C)錯誤。歐洲綠色政綱是歐盟達成 2050 氣候中和的整體政策藍圖與目標宣示，分類標準與 CBAM 都是在它之下推出的工具，它本身不是分類法規。

(D)錯誤。碳邊境調整機制（CBAM）針對進口貨品的碳含量課予相當於歐盟碳價的成本，目的在防止碳洩漏，不涉及永續經濟活動的認定。

(C)正確。依國際資本市場協會(ICMA)的分類，可持續發展債券(Sustainability Bond)屬資金用途型債券，募得資金須同時投入綠色投資計畫與社會效益投資計畫，並依其原則揭露資金用途、專案評選與資金管理。設計目的是讓同一筆募資兼顧環境與社會效益，例如兼具節能與可負擔性的社會住宅這類難以單獨歸類的專案。

71. 以下有關影響力投資之說明何者是正確的？

  4. (D)僅注重社會效益
解析
