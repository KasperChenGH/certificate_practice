1. 歐盟界定永續的經濟活動，成為多數國家制定相關標準或指引的參考；而為此目的而制定的法律稱為以下何者？
  1. (A)企業永續報告指令(CSRD)
  2. (B)永續分類標準(Taxonomy Regulation)
  3. (C)歐洲綠色政綱(European Green Deal)
  4. (D)碳邊境調整機制(CBAM)
解析

(A)錯誤。CSRD規範企業永續資訊的報導與確信義務，並未界定何種經濟活動屬於永續。

(B)正確。永續分類標準以技術篩選門檻界定何種經濟活動可被視為永續，成為各國制定綠色標準與指引的共同參考，其目的在建立一致定義以杜絕漂綠。

(C)錯誤。歐洲綠色政綱是政策藍圖與目標宣示，本身不是分類法規。

(D)錯誤。CBAM是針對進口產品碳含量課徵成本的邊境調整機制。

2. 針對所謂的「用電大戶條款」，以下敘述何者為非？
  1. (A)用電大戶電力係指用電契約容量達5,000 瓩以上者
  2. (B)用電大戶適用對象需要建置至少契約容量10%的再生能源裝置容量
  3. (C)可選擇購買再生能源電力及憑證履行義務
  4. (D)無法藉由繳納相對應金額取代應盡義務
解析

(A)錯誤。本項敘述正確：用電契約容量達 5,000 瓩以上者為用電大戶。

(B)錯誤。本項敘述正確：適用對象需建置至少契約容量 10% 的再生能源裝置容量。

(C)錯誤。本項敘述正確：可選擇購買再生能源電力及憑證以履行義務。

(D)正確（即敘述為非者）。用電大戶得以繳納代金的方式替代應盡義務。條款提供多元履行途徑——自建、購電購憑證、設儲能或繳代金——目的在於讓義務可行，而非只有單一作法。

3. IFRS S2「氣候相關揭露」規定為使一般財務報告之使用者，能了解與個體氣候相關風險與機會有關之績效，個體應揭露的指標與目標，不包括哪一項？
  1. (A)跨行業指標
  2. (B)行業基礎指標
  3. (C)公司特定指標
  4. (D)外部機構評比指標
解析

(A)錯誤。跨行業指標（如溫室氣體排放、轉型風險曝險）為 IFRS S2 要求揭露者。

(B)錯誤。行業基礎指標為 IFRS S2 要求揭露者，反映各產業特有的氣候議題。

(C)錯誤。公司特定指標為 IFRS S2 要求揭露者，用以呈現企業自訂的管理目標。

(D)正確（即不包括者）。外部機構評比指標不是 IFRS S2 要求個體揭露的指標。準則要求的是企業自身衡量與管理績效所用的指標；第三方評分是別人對企業的評價，並非企業的績效衡量。

4. 有關GRI 準則中與重大議題相關的敘述，下列何者正確？
  1. (A)所有行業須報導的重大議題數量都相同
  2. (B)所有行業皆須報導至少10 項重大主題
  3. (C)同一行業別的所有組織須報導的重大議題數量都相同
  4. (D)行業準則為組織提供其可能相關的重大主題資訊
解析

(A)錯誤。重大議題數量取決於各組織的衝擊，不會各行業相同。

(B)錯誤。GRI 並未規定至少報導 10 項重大主題。

(C)錯誤。同一行業的不同組織，其營運規模與價值鏈不同，重大議題數量也不會相同。

(D)正確。GRI 行業準則的作用是提供該行業「可能相關」的重大主題資訊，供組織參考判斷。它是輔助鑑別的清單，不是強制報導的題項——最終仍由組織依自身實際衝擊決定。

6. 金融機構發布永續聲明時，應避免何種情況的發生？
  1. (A)具體的永續目標及成果
  2. (B)提供支持聲明的數據
  3. (C)透明的揭露程序
  4. (D)在基金銷售網頁中同時包含永續商品及一般商品

(D)正確。永續商品與一般商品混陳於同一銷售網頁，易使投資人誤以為一般商品亦具永續屬性，屬應避免的誤導情形。防漂綠的核心在於避免以整體印象暗示不存在的永續特性。

(D)錯誤。慈善不要求財務回報，影響力投資則必須有財務報酬，兩者並不相同。

  3. (C)企業於官網公開永續報告書，供利害關係人查閱審視
  4. (D)企業於永續報告書中增加更多圖表說明
解析

(A)錯誤。管理階層自己出具切結書屬自我聲明，缺乏外部獨立性，公信力最低。

(B)正確。委由具獨立性與專業準則規範之會計師執行確信並出具確信報告，是提升永續資訊可靠度最具公信力的方式。可靠度來自查核者與被查核者分離，加上有一致的確信準則可供檢驗。

(C)錯誤。公開揭露只是讓外界看得到資訊，並未對內容之真實性提供任何獨立驗證。

(D)錯誤。增加圖表僅改善資訊之易讀性，與資料是否真實可靠無關。

17. Z 公司位於一棟辦公大樓內，每月除了向台電繳交電費之外，還需要向大樓管委會繳納公共空間電費以及清潔費，關於溫室氣體盤查涵蓋範圍的敘述，以下何者正確？
  1. (A)計算範疇一溫室氣體排放量時，需計算用電造成的溫室氣體排放
  2. (B)範疇二溫室氣體排放量包含台電用電以及大樓分攤電力
  3. (C)範疇二電力不包含向大樓管委會繳納的公共空間電力分攤
  4. (D)台電用電度數，以及大樓分攤的用電都屬於範疇三的溫室氣體排放
解析

(A)錯誤。範疇一是自有或可控制排放源之直接排放，如自有鍋爐、車輛與冷媒逸散，用電不屬之。

(B)正確。範疇二為外購能源所產生之間接排放，公司自向台電購電與向管委會分攤之公共空間用電，都是公司營運實際使用的外購電力，均應計入。

(C)錯誤。公共空間分攤電力仍是公司使用之外購電力，不得排除於範疇二之外。

(D)錯誤。外購電力屬範疇二；範疇三是其他價值鏈上下游之間接排放，如商務差旅、採購商品。
