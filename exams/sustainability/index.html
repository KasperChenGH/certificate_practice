1. 比較碳費及碳稅兩種制度，就其差異之描述下列何者有誤？
  1. (A)皆為政府向排碳者收取費用
  2. (B)碳稅由環境部收取、碳費則由財政部收取
  3. (C)碳稅屬政府財政總體收支之一環，用途不限於氣候減碳領域
  4. (D)碳費必須專款專用於氣候減碳
解析

(A)錯誤。兩者皆為政府向排碳者收取費用，敘述正確。

(B)正確（即敘述有誤者）。收取機關恰好相反：碳費由環境主管機關收取，碳稅則屬稅制、由財政稅捐機關徵收。這也是我國先行採行碳費而非碳稅的制度背景之一。

(C)錯誤。碳稅併入政府總體財政收支，用途不限於減碳領域，敘述正確。

(D)錯誤。碳費具特別公課性質，須專款專用於氣候減碳用途，敘述正確。

1. 歐盟界定永續的經濟活動，成為多數國家制定相關標準或指引的參考；而為此目的而制定的法律稱為以下何者？
  1. (A)企業永續報告指令(CSRD)
  2. (B)永續分類標準(Taxonomy Regulation)
  3. (C)歐洲綠色政綱(European Green Deal)
  4. (D)碳邊境調整機制(CBAM)
解析

(A)錯誤。企業永續報告指令（CSRD）規範的是企業永續資訊的報導範圍、適用準則與確信義務，本身不界定何種經濟活動屬於永續。

(B)正確。永續分類標準（Taxonomy Regulation）以六大環境目標、實質貢獻、不造成重大危害（DNSH）與最低社會保障等技術篩選標準，界定哪些經濟活動可被視為永續，成為各國制定綠色標準與指引的共同參考，我國的永續經濟活動認定參考指引亦以其為藍本。建立一致定義的目的，就是讓綠色宣稱可被檢驗，從源頭防止漂綠。

(C)錯誤。歐洲綠色政綱是歐盟達成 2050 氣候中和的整體政策藍圖與目標宣示，分類標準與 CBAM 都是在它之下推出的工具，它本身不是分類法規。

(D)錯誤。碳邊境調整機制（CBAM）針對進口貨品的碳含量課予相當於歐盟碳價的成本，目的在防止碳洩漏，不涉及永續經濟活動的認定。

2. 針對所謂的「用電大戶條款」，以下敘述何者為非？
  1. (A)用電大戶電力係指用電契約容量達5,000 瓩以上者
  2. (B)用電大戶適用對象需要建置至少契約容量10%的再生能源裝置容量
  3. (C)可選擇購買再生能源電力及憑證履行義務
  4. (D)無法藉由繳納相對應金額取代應盡義務
解析

(A)錯誤。本項敘述正確：用電契約容量達 5,000 瓩以上者為用電大戶。

(B)錯誤。本項敘述正確：適用對象需建置至少契約容量 10% 的再生能源裝置容量。

(C)錯誤。本項敘述正確：可選擇購買再生能源電力及憑證以履行義務。

(D)正確（即敘述為非者）。用電大戶得以繳納代金的方式替代應盡義務。條款提供多元履行途徑——自建、購電購憑證、設儲能或繳代金——目的在於讓義務可行，而非只有單一作法。

3. 「IFRS S2 之行業基礎施行指引」第57 冊敘明『含有IEC 62474 應申報物質之產品收入百分比』為半導體業的氣候相關指標，請問該指標屬於IFRS S2 準則中的哪一類指標？
  1. (A)跨行業指標
  2. (B)行業基礎指標
  3. (C)公司特定指標
  4. (D)投資機構評比指標
解析

(A)錯誤。跨行業指標指IFRS S2 要求所有企業一律揭露的項目，例如範疇一至三溫室氣體排放、面臨轉型風險與實體風險的資產比重、與氣候相關的薪酬連結，不會限定於半導體業。

(B)正確。IFRS S2 的行業基礎揭露指引由SASB 產業準則發展而來，按產業列出具財務重大性的氣候相關指標；含IEC 62474 應申報物質之產品收入占比只對半導體供應鏈有意義，正屬半導體業的行業基礎指標。分產業設計的理由是氣候風險的傳導管道因產業而異，同一套指標無法反映各業真實曝險。

(C)錯誤。公司特定指標是企業針對自身情況自行補充、自行定義的衡量項目；本題指標印在準則的行業基礎施行指引中，並非公司自訂。

(D)錯誤。投資機構評比指標指MSCI、Sustainalytics 等ESG 評等機構的自有評分項目，屬第三方評級體系，IFRS S2 並無這個分類。

4. 有關GRI 準則中與重大議題相關的敘述，下列何者正確？
  1. (A)所有行業須報導的重大議題數量都相同
  2. (B)所有行業皆須報導至少10 項重大主題
  3. (C)同一行業別的所有組織須報導的重大議題數量都相同
  4. (D)行業準則為組織提供其可能相關的重大主題資訊
解析

(A)錯誤。重大議題數量取決於各組織的衝擊，不會各行業相同。

(B)錯誤。GRI 並未規定至少報導 10 項重大主題。

(C)錯誤。同一行業的不同組織，其營運規模與價值鏈不同，重大議題數量也不會相同。

(D)正確。GRI 行業準則的作用是提供該行業「可能相關」的重大主題資訊，供組織參考判斷。它是輔助鑑別的清單，不是強制報導的題項——最終仍由組織依自身實際衝擊決定。

6. 金融機構發布永續聲明時，應避免何種情況的發生？
