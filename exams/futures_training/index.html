1. 下列何者非期貨交易法之期貨服務事業：
  1. (A)期貨顧問事業
  2. (B)期貨信託事業
  3. (C)期貨結算機構
  4. (D)期貨經理事業
解析

(A)錯誤。期貨顧問事業提供期貨交易分析建議，是期貨交易法所列期貨服務事業之一，不是本題要找的答案。

(B)錯誤。期貨信託事業募集期貨信託基金從事期貨交易，屬期貨交易法所稱期貨服務事業。

(C)正確。期貨結算機構辦理期貨交易的結算交割並承擔履約責任，屬市場基礎設施，期貨交易法另立專章規範，不屬期貨服務事業。

(D)錯誤。期貨經理事業接受全權委託操作期貨交易，屬期貨交易法所稱期貨服務事業。

2. 下列敘述何者正確：
  1. (A)期貨業務員可私下調閱非屬自己客戶之委託資料
  2. (B)期貨業務員為謀取客戶最大利益，可告知其他客戶之委託資料供自己客戶參考
  3. (C)除法令之查詢，在任何情況下，都不可洩漏客戶之委託事項
  4. (D)以上皆非
解析

(A)錯誤。業務員只能在職務必要範圍內處理自己負責的客戶資料，私下調閱他人客戶委託資料違反保密與內控。

(B)錯誤。把其他客戶的委託資料告知自己客戶，是洩漏客戶秘密並可能形成跟單，不能以謀取客戶利益為藉口。

(C)正確。客戶委託事項屬職務上獲悉的秘密，除依法令所為之查詢外不得洩漏。保密使客戶可以放心下單，不擔心部位被他人利用。

(D)錯誤。選項C所述「除依法令查詢外不得洩漏客戶委託事項」是正確規範，有正確選項存在，因此以上皆非不成立。

3. 期貨商對客戶保證金專戶存款，得作下列哪種運用：
  1. (A)得設定擔保或他項權利
  2. (B)得挪用為其他客戶代墊不足之保證金
  3. (C)得進行透支
  4. (D)得依期貨交易人指示交付超額保證金
解析

(A)錯誤。期貨商管理規則明文禁止對保證金專戶設定擔保或他項權利，否則客戶資金可能被期貨商的債權人追索。

(B)錯誤。挪用為其他客戶代墊不足保證金是規則明文禁止的，每位客戶資金只能用於本人交易。

(C)錯誤。保證金專戶不得透支，透支等於期貨商以客戶專戶融資，破壞資金隔離。

(D)正確。依期貨交易人指示交付超額保證金，是專戶款項允許的用途之一。超額部分屬客戶所有，依本人指示返還是正當運用。

4. 有關業務推廣與執行之敘述，下列敘述何者正確：
  1. (A)為避免客戶賠錢生氣，製作不實之期貨交易對帳單
  2. (B)利用業務關係得知的訊息，提供客戶從事期貨交易
  3. (C)告知委託人各項期貨商品的風險
  4. (D)以任何方式向委託人建議買賣，以增加手續費
解析

(A)錯誤。製作不實對帳單是偽造文書並隱瞞損益，客戶無法及時停損，違反法令與職業道德。

(B)錯誤。把業務關係得知的訊息提供客戶交易，屬洩漏秘密，也可能構成內線交易。

(C)正確。業務推廣與執行時，應告知委託人各項期貨商品的風險，讓客戶在了解損失可能後再決定交易。

(D)錯誤。以增加手續費為目的勸誘買賣屬過度交易，違反應以客戶利益為先的原則。

113年3月版｜期貨業從業人員在職訓練｜第 53 題
5. 委任期貨商與期貨交易輔助人之敘述下列何者正確：
  1. (A)期貨交易輔助人從事期貨交易之招攬業務，應以委任期貨商名義為之
  2. (B)期貨交易輔助人以接受一家期貨商之委任為限
  3. (C)期貨商可同時委任一家以上之期貨交易輔助人
  4. (D)以上皆是
解析

(A)錯誤。期貨交易輔助人從事招攬業務應以委任期貨商名義為之，此敘述正確但非唯一。

(B)錯誤。期貨交易輔助人以接受一家期貨商委任為限，此敘述正確，但A、C也正確。

(C)錯誤。期貨商可同時委任一家以上的期貨交易輔助人，此敘述正確但非唯一。

(D)正確。輔助人以委任期貨商名義招攬、只接受一家期貨商委任、期貨商可委任多家輔助人，三者皆符合規定。輔助人專屬於一家期貨商，客戶才清楚由誰負責，因此以上皆是。

113年3月版｜期貨業從業人員在職訓練｜第 68 題
6. 負責人及業務員應本誠實及信用原則，忠實執行業務，下列行為何者正確：
  1. (A)與期貨交易人約定分享利益
  2. (B)對期貨交易人承諾保證獲利
  3. (C)開戶時解說風險預告書之內容
  4. (D)與期貨交易人約定共同承擔損失
解析

(A)錯誤。與交易人約定分享利益，會讓業務員為自身利益推動交易，違反誠信原則並為法規禁止。

(B)錯誤。承諾保證獲利是期貨交易法禁止並設有刑罰的行為，會誘使客戶低估期貨的槓桿風險。

(C)正確。開戶時解說風險預告書內容，讓客戶了解期貨交易的槓桿與損失可能，是誠實信用原則下忠實執行業務的表現。

(D)錯誤。約定共同承擔損失同樣把業務員與客戶損益綁在一起，與分享利益一樣被禁止。

113年3月版｜期貨業從業人員在職訓練｜第 83 題
7. 喬大公司為做期貨避險，找上期貨商開戶買賣，下列何者為是：
  1. (A)客戶交易目的為避險，就不需再徵信
  2. (B)法人不需徵信
  3. (C)不論證券或期貨等交易，業務員受託前應先對客戶辦理徵信，了解客戶背景
  4. (D)因為期貨交易為保證金交易，不需徵信
解析

(A)錯誤。避險目的不代表沒有風險，避險部位仍需繳保證金與面臨追繳，交易目的不能免除徵信。

(B)錯誤。法人同樣須徵信，了解其財務狀況與授權代表，法人身分不是免徵信的理由。

(C)正確。不論證券或期貨交易，業務員受託前都應先對客戶辦理徵信、了解背景。徵信可確認財力與交易能力，也是洗錢防制下認識客戶的要求。

(D)錯誤。保證金交易有槓桿，損失可能超過保證金，正是更需要徵信的原因，而不是免徵信的理由。

8. 期貨交易輔助人應於每月幾日以前，向主管機關、期貨交易所或主管機關指定機構申報上月份業務量月報表：
  1. (A)十日

解析

(C)錯誤。七日不是規則所定的期限；題庫依規則所定的月報申報日為十日以前。

(D)錯誤。五日是期貨商負責人及業務員異動申報常見的天數，容易與月報表期限混淆，但不是本項申報期限。

113年3月版｜期貨業從業人員在職訓練｜第 113 題
9. 期貨商內部從業人員之開戶帳號：
  1. (A)必須在其他期貨商依流水帳號順序開戶，以避免利益衝突
  2. (B)不須與其他委託人區分，但須依流水帳號順序、不得選號
  3. (C)應與其他委託人區分
  4. (D)內部人不可以開戶，應以客戶服務至上，以免影響服務品質
解析

(A)錯誤。規定是內部人員應在所屬期貨商開戶以便監督，要求到其他期貨商開戶正好相反，所屬公司反而看不到其交易。

(B)錯誤。內部人員帳號若與一般委託人混同，公司就無法辨識並監控其交易，流水號不得選號並不能解決利益衝突。

(C)正確。期貨商內部從業人員的開戶帳號應與其他委託人區分。帳號可辨識，公司內控與稽核才能追蹤內部人員的交易，查核其是否利用客戶委託資訊跟單或對作。

(D)錯誤。規定並未禁止內部人員開戶，而是要求在所屬期貨商開戶並區分帳號，完全禁止並非規範內容。

113年3月版｜期貨業從業人員在職訓練｜第 128 題
10. 期貨商受理期貨交易委託時之電話錄音，至少應保存多久：
  1. (A)四個月
  2. (B)一年
  3. (C)六個月
  4. (D)二年
解析

(A)錯誤。四個月短於規定期間，客戶往往在對帳單累積後才發現問題，錄音保存太短會在爭議時無從查證。

(B)正確。期貨商受理期貨交易委託的電話錄音至少應保存一年；若委託發生爭議，則應保存至爭議消除為止。錄音是電話委託唯一的證據，保存期間要夠長，才能涵蓋客戶事後查對與申訴的時間。

(C)錯誤。六個月不是規定的最低保存期間；題庫依規定所定期間為一年，六個月可能不足以涵蓋客戶事後申訴的時間。

(D)錯誤。二年是宣傳資料、廣告物及審核紀錄的保存期間，容易與電話錄音的保存期限混淆。

113年3月版｜期貨業從業人員在職訓練｜第 143 題
11. 下列有關期貨業務員之行為，何者違反規定：
  1. (A)利用配偶的戶頭，為客戶從事期貨交易
  2. (B)接受未具期貨交易人委任書之代理人委託從事期貨交易
  3. (C)於家中以電話為交易人進行交易委託
  4. (D)以上皆是
解析

(A)錯誤。利用配偶帳戶替客戶交易，是借用他人帳戶，會讓實際交易人與帳戶名義人不一致，屬違規，但B、C也是。

(B)錯誤。接受未具委任書之代理人委託違反規定，因為無法確認代理人確有授權，但不是唯一違規行為。

(C)錯誤。業務員應在營業處所執行受託業務，在家中以電話替交易人委託下單，脫離公司的錄音與監督，屬違規。

(D)正確。利用配偶帳戶替客戶交易、接受未具委任書之代理人委託、在家以電話替交易人委託，三者皆違反規定。共通問題是交易脫離了帳戶本人與公司監督，事後發生爭議無從查證。

113年3月版｜期貨業從業人員在職訓練｜第 158 題
12. 期貨商業務員有何種情事者應予撤銷登記：
  1. (A)未依規定參加在職訓練者
  2. (B)有事實證明從事不誠信或不正當之活動，顯示其不適合擔任業務員者
  3. (C)最近三年內在金融機構使用票據有拒絕往來紀錄者
  4. (D)以上皆是
解析

(A)錯誤。未依規定參加在職訓練者應撤銷登記，此項是情形之一，但B、C也是，單選不完整。

(B)錯誤。有事實證明從事不誠信或不正當活動、顯示不適任者應撤銷登記，此項是情形之一，但不是唯一。

(C)錯誤。在金融機構有票據拒絕往來紀錄顯示其信用有問題，題庫所列期間即規定內容，屬撤銷登記情形之一，但A、B也成立。

(D)正確。未依規定參加在職訓練、有事實證明不誠信或不正當、近期有票據拒絕往來紀錄者，均屬應撤銷業務員登記的情形。三者分別對應專業、操守與信用三項適任條件，任一欠缺都不宜經手客戶交易。

13. 期貨商對客戶辦理徵信時，下列敘述何者正確：
