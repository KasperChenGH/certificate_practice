  1. (A)人民之自由權利，除為防止妨礙他人自由等所必要者外，不得以法律限制之
  2. (B)增加立法委員報酬或待遇之規定，概應自次屆起實施
  3. (C)立法委員在開會時，有向行政院院長及行政院各部會首長質詢之權
  4. (D)法官須超出黨派以外，依據法律獨立審判
解析

(A)錯誤。本題要選敘述錯誤者。憲法第23條正是以防止妨礙他人自由等四項事由為限制基本權的前提。

(B)正確。增修條文所定的是「除年度通案調整者外」，單獨增加報酬或待遇之規定應自次屆起實施；隨物價或通案調薪而為的調整不受此限，並非一概自次屆施行。此為錯誤敘述。

(C)錯誤。本題要選敘述錯誤者。立法委員於開會時有向行政院院長及各部會首長質詢之權。

(D)錯誤。本題要選敘述錯誤者。法官須超出黨派以外，依據法律獨立審判，不受任何干涉。

2. 有關平等權與平等原則，下列敘述何者錯誤？
  1. (A)憲法所保障之各種權利，均應受法律平等保護，私法自治原則亦應遵循，故依居住權利平等，出租人不得因承租人年紀因素而拒絕出租
  2. (B)當聲請釋憲之人民無法主張憲法上之平等權時，立法機關行使職權仍須遵循平等原則者，違憲審查機關亦應依平等原則審查系爭規定
  3. (C)憲法第7 條不僅為主觀權利，並為客觀價值規範，應適用於所有法領域，指導行政、立法與司法
  4. (D)國家機關為達成公行政任務，縱以私法形式所為之行為，亦應遵循平等原則
解析

(A)正確。平等權首要拘束的是國家，於私人間僅有間接的第三人效力；出租人依私法自治選擇締約相對人，除法律另設禁止歧視的明文外，不能逕以平等權課予其出租義務。此為錯誤敘述。

(B)錯誤。本題要選敘述錯誤者。平等原則作為客觀法拘束立法者，違憲審查機關仍應據以審查。

(C)錯誤。本題要選敘述錯誤者。平等權兼具主觀權利與客觀價值秩序的性質，指導行政、立法與司法。

(D)錯誤。本題要選敘述錯誤者。國家以私法形式達成行政任務者，仍受平等原則拘束。

(D)錯誤。五權分立係權力分立原則之具體設計，旨在分工與制衡，並非民主正當性之表現。

6. 刑法第151 條恐嚇公眾安全罪，下列敘述何者錯誤？
  1. (A)為了保護公眾安全，本罪的行為只能對不特定人或是多數人為之
  2. (B)行為人對於恐嚇的內容要有支配可能性，而恐嚇之內容是否實現，則非所問
  3. (C)恐嚇的結果，已使公眾心生畏懼，而有不安全的感覺即足成立，不以果生實害為必要
  4. (D)以生命、身體、自由、名譽、財產之事恐嚇公眾，造成公安上的危害，始可成立本罪
解析

(A)錯誤。本題要選敘述錯誤者。本罪保護的是公眾安全，恐嚇對象須為不特定人或多數人。

(B)錯誤。本題要選敘述錯誤者。行為人須對恐嚇內容有支配可能性，至於是否真的實現則非所問。

(C)錯誤。本題要選敘述錯誤者。本罪為具體危險犯，公眾心生畏懼而有不安全感即足，不以實害發生為必要。

(D)正確。本罪所定的恐嚇內容限於「生命、身體、財產」之事，並不包括自由與名譽；本項擴張了法定的恐嚇客體。此為錯誤敘述。

  2. (B)甲以殺人之意思緊勒乙，導致乙昏迷，但甲誤認乙已死，故將其埋入土中，最後乙因被土覆蓋口鼻而窒息死亡，此時依實務見解甲仍應負擔殺人罪責
