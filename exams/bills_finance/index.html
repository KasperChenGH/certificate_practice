1. 票券金融管理法之制定，其主要立法目的最適當之描述為下列何者？
  1. (A)建立中央銀行調節金融、實施存款準備與重貼現制度之法源依據
  2. (B)健全票券商之經營與發展，維持票券金融市場秩序並保障交易人權益
  3. (C)規範公司之設立、組織、董事會運作及股東權利等內部治理事項
  4. (D)統一規範有價證券之募集、發行、買賣及證券交易所之集中交易秩序
解析

(A)錯誤。存款準備與重貼現等制度之法源在中央銀行法與銀行法，係中央銀行調節金融之貨幣政策工具，並非票券金融管理法之立法目的。

(B)正確。本法以健全票券商經營、維持票券金融市場秩序、保障票券交易人權益為目的，故其條文集中於票券商之許可、業務規範與監督管理。

(C)錯誤。公司之設立、組織、董事會運作與股東權利屬公司法之規範對象；票券金融管理法僅就票券商負責人之資格與行為另設特別規定。

(D)錯誤。有價證券之募集、發行、買賣與證券交易所集中交易秩序係證券交易法之規範範疇；票券金融管理法所處理者為貨幣市場短期票券之發行、交易及票券商之管理。

2. 短期票券的買賣斷交易與附條件交易,在雙方權利義務上的主要差異為何?
  1. (A)二者均由賣方負買回的義務,差別僅在於成交價格的計算方式不同
  2. (B)買賣斷的賣方不負買回義務,附條件交易則約定於特定日買回或賣回
  3. (C)買賣斷的買方報酬隨市價變動,附條件交易的買方亦承擔市價變動風險
  4. (D)附條件交易的票券所有權不移轉,買賣斷交易則須辦理所有權的過戶
解析

(A)錯誤。買回義務的有無正是兩者的分野。買賣斷是一次了結的交易,賣方交付票券收取價金後即與該票券脫離關係。

(B)正確。買賣斷是票券所有權的終局移轉,買方持有至到期並承擔發行人的信用風險與期間的利率風險;附條件交易則約定於將來特定日以事先議定的價格買回或賣回,買方的報酬在成交時即已鎖定,經濟實質接近以票券為擔保的短期資金融通。

(C)錯誤。前半正確,後半錯誤。附條件交易的買方收益依約定的承作利率計算,不隨標的票券的市價變動,這正是它被用作短期資金調度工具的原因。

(D)錯誤。恰好說反。附條件交易在法律形式上仍是買賣,票券所有權隨之移轉,只是附有將來買回的義務;誤以為所有權不移轉是常見的錯誤。

3. 將客戶區分為專業投資人與一般投資人，其在法令遵循上之主要意義為何？
  1. (A)專業投資人得就其票券交易所得，適用較一般投資人為低之稅率
  2. (B)兩者所受保護之密度不同，對一般投資人之說明與適合度要求較嚴
  3. (C)專業投資人不得承作短期票券，僅得投資於長天期之公司債商品
  4. (D)一般投資人之單筆交易金額上限，設定為高於專業投資人之水準
解析

(A)錯誤。稅負依所得類型與稅法規定而定，與投資人是否具專業身分無關，分類制度並非租稅優惠之分流機制。

(B)正確。分類之實益在於資訊落差之大小：專業投資人被認為具備自行評估風險之知識與經驗，故部分告知與銷售限制得以放寬；一般投資人資訊與議價能力較弱，說明義務、適合度審查與可銷售商品範圍均較嚴格。

(C)錯誤。專業投資人身分係放寬保護密度而非限縮可投資標的，其可投資範圍通常較一般投資人更廣而非更窄。

(D)錯誤。分類與交易金額上限無必然關係；若涉及金額或資產條件，通常反而是取得專業投資人身分之門檻要件。

4. 下列何種情形，依票券商負責人及業務人員管理規則，屬於不得充任票券商負責人之消極資格？
  1. (A)同時持有其他公開發行公司之少數股份，且未擔任該公司職務者
  2. (B)曾任其他票券商或金融機構之業務人員，具有相關實務經歷者
  3. (C)曾犯詐欺、背信、侵占等罪經判決有罪確定，尚未逾法定期間者
  4. (D)未曾於國外金融機構任職，欠缺境外票券市場之實際工作經驗者
解析

(A)錯誤。單純持有他公司少數股份不當然生利益衝突，法規所限制者為兼任職務或特定關係之情形。

(B)錯誤。曾任同業之業務人員屬正面經歷，常構成積極資格之一，並非不得充任之事由。

(C)正確。財產犯罪與誠信直接相關，票券商負責人掌管他人資金與信用，故此類前科在法定期間內構成不得充任之消極資格。

(D)錯誤。規則所定積極資格為國內外相關金融實務經歷或專業資格，並未要求須有國外任職經驗。

5. 票券商業務人員不得對客戶為虛偽不實或足致他人誤信之表示，此規範所欲保護之核心利益為何？
  1. (A)確保客戶基於正確資訊作成決定，並維護市場交易之誠信基礎
  2. (B)確保發行人能以最低之資金成本順利完成短期票券之發行作業
  3. (C)確保主管機關實施檢查時，能取得完整之會計憑證與交易紀錄
  4. (D)確保票券商彼此間之報價趨於一致，避免市場出現過度價格競爭
解析

(A)正確。票券交易高度依賴票券商就發行人信用與商品條件所為之說明，不實陳述將使客戶錯誤定價；禁止不實表示是資訊對稱與市場信賴之基礎。

(B)錯誤。降低發行成本是發行人之利益，不能以犧牲投資人取得正確資訊為代價。

(C)錯誤。會計憑證之完整屬帳簿與內部控制之要求，與對客戶陳述之真實性分屬不同規範。

(D)錯誤。價格競爭是市場機能之正常表現，法規並不以統一報價為目的，反而禁止聯合行為。

6. 票券金融管理法就票券商應維持一定之自有資本與風險性資產比率設有規定，此一資本適足規範最主要的制度目的為何？
  1. (A)確保票券商持有足以吸收其所承擔風險可能產生損失的自有資本，降低失卻清償能力並外溢至貨幣市場的風險
  2. (B)確保票券商每一會計年度的稅後純益均達成主管機關核定的獲利目標，未達成者應調整營運計畫並不得續辦新種業務
  3. (C)使票券商所保證發行之商業本票，得免依信用評等機構之評等作業辦理，逕行於次級市場流通
  4. (D)限制票券商經紀業務手續費收入占其總收入的比重，使收入結構向自營買賣利差傾斜
解析

(A)正確。資本適足規範的核心是「損失吸收」：自有資本是股東出資形成的緩衝，風險愈大所需緩衝愈厚，先由股東而非債權人與市場承擔損失，藉此降低票券商倒閉對貨幣市場的傳染。

(B)錯誤。主管機關並不核定金融機構的獲利目標；資本適足率衡量的是承受損失的能力，與獲利水準是不同概念，獲利高但槓桿過大者仍可能資本不足。

(C)錯誤。信用評等的要求來自票券發行與交易的相關規範及市場需求，與票券商自身的資本適足率並非替代關係，資本充足並不豁免發行人的評等義務。

(D)錯誤。資本適足率的分母是風險性資產，規範的是風險承擔規模而非收入結構；手續費收入比重屬營運策略，不是資本規範的標的。

7. 票券商的風險管理單位與內部稽核單位同屬控制機能，二者最主要的差別為何？
  1. (A)風險管理持續參與並即時監控日常業務所生的風險部位；內部稽核則獨立於業務與風險管理之外，事後查核控制制度的有效性並向董事會報告
  2. (B)風險管理人員由主管機關自其金融檢查人員中指派，內部稽核人員則由票券金融商業同業公會指派，二者均不受票券商董事會的指揮監督
  3. (C)二者的職能實質相同，票券商得由同一單位兼辦並由同一主管負責，僅須於內部控制制度中載明分工即可
  4. (D)風險管理僅負責信用與市場風險的衡量，內部稽核僅負責作業風險與資訊安全的查核，二者依風險類別分工而互不重疊，各自向不同的主管報告
解析

(A)正確。第二道防線是「一起做」——每日衡量部位、控管限額、事前把關；第三道防線是「回頭看」——獨立評估包含第二道在內的整套控制是否設計妥適並有效執行，並直接向董事會報告以確保其獨立性。

(B)錯誤。二者均為票券商內部設置的單位，由機構自行任用；主管機關與公會不指派機構的內部人員。

(C)錯誤。若由同一單位兼辦，等於自己查核自己所訂的控管，稽核的獨立性即不復存在，這正是三道防線要避免的情形。

(D)錯誤。分工的依據不是風險類別而是機能位置：風險管理涵蓋信用、市場、流動性與作業各類風險，內部稽核則查核所有這些控管是否有效運作。

8. 票券商依規定編製、申報並公告財務報告，此一資訊揭露義務對貨幣市場運作的主要意義為何？
  1. (A)使票券商得免除信用評等機構對其所為之評等作業，改以公告之財務報告替代
  2. (B)使票券商的自營持券部位得免除定期評價的義務，改以年度財務報告的數字認列
  3. (C)使投資人與交易對手得評估票券商的財務體質與履約能力，以市場紀律補充主管機關的監理
  4. (D)使票券商得據以向主管機關申請調高其保證背書餘額對淨值的倍數限額，擴大承作規模
解析

(A)錯誤。信用評等是評等機構的獨立判斷，財務報告是其分析的輸入資料而非替代品，揭露愈完整反而使評等更具基礎。

(B)錯誤。定期評價是部位風險管理的要求，與對外財務報告的申報公告義務並存，不生免除效果。

(C)正確。票券商的保證是投資人購買商業本票的信用基礎，交易對手是否願意拆出資金也取決於對其體質的判斷。公開財務資訊使這些判斷得以進行，體質轉弱者會較早面臨資金成本上升與額度緊縮的壓力，形成先於行政處分的市場約束。

(D)錯誤。限額依淨值與集中度規範計算，是規範適用的結果，不是以揭露換取放寬的對價。

9. 關於中央銀行與金融業拆款市場的關係，下列敘述何者最為正確？
  1. (A)央行逐日核定並公告隔夜拆款利率，金融機構不得在該利率之外議價成交
  2. (B)拆款屬銀行間的私法契約，央行的公開市場操作對其利率並無影響
  3. (C)央行以拆款者身分直接進場拆借資金，藉買賣的價差獲利並引導市場利率
  4. (D)央行透過準備金調節與公開市場操作影響資金鬆緊，藉以引導隔夜拆款利率
解析

(A)錯誤。隔夜拆款利率是市場成交的結果而非行政核定的價格；央行只設定政策利率並以操作引導，不直接管制成交利率。

(B)錯誤。拆款交易固然是私法契約，但其價格高度取決於準備金的多寡，正因如此才成為觀察政策鬆緊最靈敏的指標。

(C)錯誤。央行不是以營利為目的的拆款參與者；它改變的是體系的準備金總量，讓價格由市場供需形成。

(D)正確。拆款利率反映的是銀行準備金部位的鬆緊，央行藉公開市場操作、發行存單與準備率調整改變這個部位，利率便隨之移動，這是政策傳導的第一環。

10. 企業發行的融資性商業本票，原則上不被當作證券交易法所稱的有價證券，而由票券金融管理法規範，其主要理由為何？
  1. (A)因其發行人限於未公開發行的中小企業，不受證券主管機關的監督與管轄
  2. (B)因其為短期資金調度的貨幣市場工具，性質上屬票據而非募集資本的證券
  3. (C)因其單筆發行金額通常較小，未達公開募集的規模與公開性要求
  4. (D)因其依法一律不得背書轉讓，在次級市場缺乏流通性
解析

(A)錯誤。公開發行公司同樣可以且經常發行商業本票，發行人是否公開發行並非區分標準。

(B)正確。證交法的規範核心是企業向公眾募集長期資本的行為，因而環繞公開說明書、財務報告與內部人交易而設計。商業本票解決的是一年以內的營運資金缺口，法律關係建立在票據法之上，於是由票券金融管理法就其發行、簽證、承銷與保證另設專門規範。

(C)錯誤。商業本票的單筆發行金額往往相當可觀，金額大小從來不是區分兩套法規的標準。

  2. (B)浮動端須於期初支付權利金，以取得未來收取固定利息的權利
