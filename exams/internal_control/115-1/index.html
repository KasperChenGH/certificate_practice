1. 企業內部控制的營運目標，乃指有效果和有效率地利用資源。所謂營運「效果」主要是：
  1. (A)是否做對了事
  2. (B)資源運用（產出／投入）的表現
  3. (C)生產成本是否下降
  4. (D)如何以較佳的方法手段尋求資源
解析

(A)正確。營運效果（effectiveness）指目標達成的程度，也就是「是否做對了事」，衡量的是產出有沒有達到預期的目的；效率（efficiency）則是「是否把事情做對」，看投入與產出的比例。兩者常被混用，內部控制的營運目標同時要求兩者。

(B)錯誤。資源運用的產出對投入之比是「效率」的定義，衡量的是用了多少資源換到多少成果，而非目標是否正確達成。

(C)錯誤。生產成本下降代表相同產出所需的投入減少，屬效率面的改善；成本降了但產品賣不出去，效果並未達成。

(D)錯誤。以較佳的方法手段尋求資源談的是取得資源的方式，仍屬手段與效率層面，並非衡量目標是否達成的效果概念。

2. 內部控制制度能否將最高主管有效列入控制？
  1. (A)不能也不會列入
  2. (B)理論上能，但實務上視最高主管態度而定
  3. (C)能，且制度本身之設計即主要針對最高主管
  4. (D)視制度設計是否強而有力以決定
解析

(A)錯誤。內部控制制度確有針對最高主管的機制，例如董事會與審計委員會的監督，並非完全不能列入。

(B)正確。制度理論上可將最高主管納入控制，但管理階層凌駕控制是內部控制的固有限制，實際效果仍取決於最高主管的態度與治理機關能否發揮作用。

(C)錯誤。內部控制的主要對象是全體人員與各項作業流程，並非專為最高主管而設計。

(D)錯誤。制度設計再嚴密，仍可能被有權者凌駕，成效並非單由制度強度決定。

3. 美國COSO 報告指出企業內部控制組成要素中：
  1. (A)內部稽核人員的監督是其他組成要素的基礎
  2. (B)控制環境是其他組成要素的基礎
  3. (C)董事會及監察人的關注是其他組成要素的基礎
  4. (D)控制活動是其他組成要素的基礎

(A)錯誤。內部稽核屬監督要素的一環，本身也受控制環境影響，並非其他要素的基礎。

(D)錯誤。控制活動是依風險評估結果所設計的具體措施，位於控制環境之上而非其基礎。

4. COSO 2023 框架中加入的「永續性」概念主要是為了強調：

(C)錯誤。永續涵蓋環境、社會與治理三個面向，不只公司對環境的影響。

(D)錯誤。內部控制的目標本就包含營運、報導與遵循，並不限於財務報導的正確性。

5. 在COSO 2023 框架中，關於永續性報告，企業應如何處理永續資訊的準確性和透明度？
  1. (A)永續性資訊應與財務報告分開披露
  2. (B)應該確保永續性資訊的準確性、透明度，並與財務報告保持一致
  3. (C)永續性資訊不需要遵循與財務報告相同的準則
  4. (D)只需要遵循地方政府的規定，而非國際標準
解析

(A)錯誤。刻意與財務報告分開揭露並無助於品質，反而可能造成兩套資訊互相矛盾。

(B)正確。永續性資訊應確保準確、透明並與財務報告保持一致。若兩者對同一事件的敘述互相矛盾，使用者將無從判斷何者可信，永續資訊的決策有用性也隨之喪失。

(C)錯誤。永續資訊既然對外報導，就應受到與財務報告相當的品質要求與內部控制。

(D)錯誤。僅遵循地方規定將使資訊無法跨國比較，也不符合逐步趨同的永續揭露準則。

7. 某上市公司因未對子公司治理制定內控機制而受罰，請問下列哪一做法最適合改善此情況？

  2. (B)子公司採取彈性內控可因地制宜
  3. (C)對子公司內控制度進行整合規劃並監督執行

9. 企業之內部控制制度，採購部門完成採購程序，於確定採購內容及交期後，應通知哪一個部門準備驗收作業？

  2. (B)倉儲部門
  3. (C)運輸部門
  4. (D)財務部門
解析

(C)錯誤。運輸部門負責貨物的搬運與配送，不掌握訂單內容，也不負責點收入庫與建立庫存紀錄，不是驗收單位。

(D)錯誤。財務部門負責在驗收完成後憑訂單、驗收單與發票三單相符才付款；若財務也參與驗收，付款與驗收的牽制就消失了。

14. ISO 27001 中的遵循性，目標為避免違反任何法律、法令、法規或契約義務，以及任何安全要求。以下論述何者不適當？
  1. (A)組織應識別適用之法條、個人資訊的資料保護與隱私
  2. (B)建立指定資料保護專員後，由此專員對管理者、使用者和服務提供者，提供其各自的責任及應遵照的特定程序
  3. (C)公務機關或學術研究機構基於公共利益為統計或學術研究而有必要則不在此限
  4. (D)為規範個人資料之蒐集、處理及利用，以避免人格權受侵害，並促進個人資料之合理利用

68. 公開發行公司何種資料需經董事長、經理人及會計主管簽名或蓋章？
  1. (A)公開說明書
  2. (B)年報
  3. (C)季財務報告
  4. (D)每月營運公告資料
解析

(A)錯誤。公開說明書是募集發行有價證券時向投資人提供的說明文件，其編製與簽章依公司募集發行有價證券公開說明書應行記載事項準則另行規範，並由發行人與相關專業人員負責，不是證交法第14條所指的財務報告。

(B)錯誤。年報是提供股東會的綜合性資料，內容涵蓋公司概況、營運與公司治理等，財務報告只是其中一部分；年報本身不是財務報告，不適用董事長、經理人及會計主管三方簽章的規定。

(C)正確。證券交易法第14條規定，財務報告應經董事長、經理人及會計主管簽名或蓋章，並出具財務報告內容無虛偽或隱匿之聲明；依同法第36條，季財務報告屬公司應定期公告申報的財務報告，因此適用此簽章規定。要求三方具名，是讓財務報告的編製與呈報責任具體落到個人，一旦有虛偽隱匿即可追究刑事與民事責任。

(D)錯誤。每月營運情形（每月營收）公告是證交法第36條要求的月度營運資訊，屬簡要的營運數據，不是經編製的財務報告，不須經董事長、經理人及會計主管簽章及出具聲明。

69. 公開發行公司董事、監察人、經理人或持有公司股份超過10%之股東，對公司之上市股票，於取得後幾個月內再行賣出，因而獲得利益者，公司應請求將其利益歸於公司？
  1. (A)1 個月
  2. (B)3 個月
  3. (C)6 個月
  4. (D)12 個月
解析

(A)錯誤。一個月是遠短於法定期間的認定標準；若只抓一個月內的短線買賣，內部人只要持有超過一個月再賣出即可規避，歸入權制度幾乎無法發揮作用。

(B)錯誤。三個月並非證交法第157條的認定期間；證交法對內部人交易的相關期間設計是六個月，三個月是把期間記短了一半，會讓大量短線獲利脫離公司請求的範圍。

(C)正確。證券交易法第157條規定，發行公司董事、監察人、經理人或持有公司股份超過10%的股東，對公司上市股票於取得後六個月內再行賣出，或於賣出後六個月內再行買進而獲得利益者，公司應請求將其利益歸於公司。此為短線交易歸入權，採客觀的六個月期間推定，不問內部人是否實際利用內線消息，以免公司舉證困難而讓內部人輕易脫身。

(D)錯誤。十二個月是把歸入權的期間放寬了一倍；證交法採六個月，是在防止內部人利用資訊優勢短線套利與保障內部人正常投資之間取得平衡，一年將使內部人幾乎無法正常持股調整。
