1. 企業內部控制中，財務報導之可靠性目標特別自企業整體目標中予以標示出來，主要與下列何者有關？
  1. (A)與公司治理要求資訊透明化有關
  2. (B)股東與債權人之間存在資訊不對稱的問題
  3. (C)股東需取得適當的資訊俾為公司規劃正確的經營決策
  4. (D)公司必須取得適當的財務資訊向經濟部報告
解析

(A)正確。財務報導可靠性之所以自整體目標中單獨標示，是因為外部人只能倚賴公司揭露的資訊來判斷公司價值；公司治理要求資訊透明化，而可靠的財務報導正是透明化的基礎。

(B)錯誤。資訊不對稱主要存在於外部資金提供者與經營階層之間，而非股東與債權人彼此之間。

(C)錯誤。經營決策由經營階層規劃執行，股東並非以財報為公司制定經營決策。

(D)錯誤。財務報導的對象是廣泛的資訊使用者，不是為了向特定主管機關報告而設。

14. 在經適當設計之內部會計控制制度裡，同一個僱員不應被允許：
  1. (A)簽發支票並註銷支持文件
  2. (B)驗收貨品並編製驗收報告
  3. (C)編製應付憑單與簽發支票
  4. (D)提出商品的請購單與核對收到之商品
解析

(A)錯誤。簽發支票後隨即註銷（作廢戳記）支持文件，正是防止同一單據重複請款的必要配套，屬同一職務的正常作法。

(B)錯誤。驗收貨品與編製驗收報告本屬同一職能，由收料人員一併辦理並無不當。

(C)正確。應付憑單是核准付款的依據，簽發支票則是實際動用資產；兩者由同一人掌握，即可自行製造付款依據再把錢付出去，是最典型的不相容職務。
