1. 有關重大性(Materiality)，下列何項敘述正確？
  1. (A)重大性屬專業判斷
  2. (B)重大性判斷僅需考慮金額
  3. (C)重大性只與帳戶的品質因素有關
  4. (D)重大性標準之金額與查核風險水準存有正向關係
解析

(A)正確。重大性指誤述達到何種程度會影響報表使用者的決策，須同時衡量金額大小（量）與項目性質（質），例如涉及舞弊、違法或關係人交易的小額項目也可能重大。沒有單一公式能決定，所以本質上是查核人員的專業判斷。

(B)錯誤。只看金額會漏掉質的因素：一筆金額不大的管理階層舞弊或法令違反，因為關係到公司誠信與持續經營，對使用者決策的影響遠超過其數字，仍應視為重大。

(C)錯誤。這是把量的因素完全排除的另一極端。重大性判斷通常先以金額設定基準（例如稅前淨利的某一比率），再以質的因素調整，兩者缺一不可，並非只與品質因素有關。

(D)錯誤。兩者是反向關係：可接受的查核風險越低，查核人員設定的重大性金額就越小，以便偵出更小的誤述，須執行的查核程序也越多；重大性訂得越高，容忍的誤述越大，查核風險相對升高。

2. 內部控制制度能否將最高主管有效列入控制？
  1. (A)不能也不會列入
  2. (B)理論上能，但實務上視最高主管態度而定
  3. (C)能，且制度本身之設計即主要針對最高主管
  4. (D)視制度設計是否強而有力以決定
解析

(A)錯誤。內部控制制度確有針對最高主管的機制，例如董事會與審計委員會的監督，並非完全不能列入。

(B)正確。制度理論上可將最高主管納入控制，但管理階層凌駕控制是內部控制的固有限制，實際效果仍取決於最高主管的態度與治理機關能否發揮作用。

(C)錯誤。內部控制的主要對象是全體人員與各項作業流程，並非專為最高主管而設計。

(D)錯誤。制度設計再嚴密，仍可能被有權者凌駕，成效並非單由制度強度決定。

3. 由於高階經理人所從事的舞弊行為對公司的不利影響較大，因此建立紮實的舞弊防制計畫及控制制度是健全控制環境不可或缺的要素。惟建立紮實的舞弊防制計畫的基本要件是：
  1. (A)企業必須建立有效的人事紀錄
  2. (B)企業必須建立有效的行為準則
  3. (C)企業必須建立有效的家族分工
  4. (D)企業必須建立有效的績效制度
解析

(A)錯誤。人事紀錄用於記錄員工的任用、考核與異動，可以協助事後查證，但它本身不會宣示公司對誠信的要求，也不能拘束高階經理人的行為，不是舞弊防制計畫的基礎。

(B)正確。舞弊防制計畫的基本要件是企業建立有效的行為準則：它明文宣示公司對誠信與倫理的要求、對舞弊零容忍的立場，並同樣拘束高階經理人，是控制環境的基調。高階經理人有能力凌駕控制，唯有清楚且被落實的行為準則，才能讓其他控制活動與檢舉機制有依據可以運作。

(C)錯誤。家族分工指由家族成員分掌公司職務，與舞弊防制無關；家族成員之間往往缺乏制衡，反而是舞弊風險的來源之一。

(D)錯誤。績效制度是激勵與考核工具，若目標訂得過高或獎酬過度連結短期數字，反而會製造達標壓力而誘發舞弊；它需要受行為準則約束，本身不是防弊的基礎要件。

4. 以下甲公開發行公司自行評估內部控制制度之作法，何者有誤？
  1. (A)應先督促內部各單位及子公司每年至少辦理自行評估一次
  2. (B)內部稽核單位應覆核各單位及子公司之自行評估報告
  3. (C)自行評估的結果亦可能作為公司出具內部控制聲明書之依據
  4. (D)自行評估屬公司內部自治事項，相關資料可由公司自行決定是否製作及保存期限
解析

(A)錯誤。督促內部各單位及子公司每年至少自行評估一次，敘述正確。

(B)錯誤。內部稽核單位應覆核各單位及子公司的自行評估報告，敘述正確。

(C)錯誤。自行評估結果與稽核報告同為出具內部控制制度聲明書的主要依據，敘述正確。

(D)正確（即敘述有誤者）。自行評估是法定要求而非內部自治事項，其計畫、程序與工作底稿等資料應確實製作並依規定保存，公司不能自行決定做不做、留多久。

5. 甲公司為一上市公司，其分層負責層級之規定係投資金額達新臺幣5 千萬元以上者，應經董事會通過。該公司年度中召開董事會通過未來一年內擬投資之標的需達信評A-以上，且投資金額不得逾公司淨值的10%，至於實際投資標的及金額則授權董事長決定。請問以上投資程序是否符合公司內部控制規定？
  1. (A)不符合，因為公司實際投資流程與內控分層負責規定不符，可能受證交所違約金或主管機關依證交法處罰
  2. (B)符合，因為董事會已通過授權董事長辦理
  3. (C)不符合，但屬違反公司內部治理規章制度，故應無受行政裁罰之虞
  4. (D)符合，因為公司之分層負責層級非強制規定，可彈性務實執行
解析

(A)正確。分層負責一經納入內部控制制度即具拘束力，達門檻的投資應逐案經董事會通過；以概括授權董事長決定實際標的與金額，等於架空該規定，屬未依內控執行，可能招致主管機關依證交法處分。

(B)錯誤。董事會不得以概括授權規避自己訂定的分層負責金額門檻。

(C)錯誤。內部控制制度是依證交法授權訂定的法定制度，未確實執行即有行政責任，不只是內部治理問題。

(D)錯誤。分層負責層級一經訂入內控制度即應遵循，不得任意彈性處理。

6. 企業之內部控制制度，開立支票付款或收到支票時，規定要在支票正面「劃線」(通常在左上角)，其目的：
  1. (A)評估支票變現之品質

  3. (C)避免窗飾帳齡分析

7. COSO 2023 框架中加入的「永續性」概念主要是為了強調：
  1. (A)企業必須專注於短期財務表現
  2. (B)將環境、社會和治理(ESG)因素納入內部控制的整體框架
  3. (C)只關注公司對環境的影響
  4. (D)內部控制系統應只考慮財務報告的準確性
解析

(A)錯誤。強調永續正是要企業把視野從短期財務表現拉長到中長期的環境、社會與治理影響，與專注短期財務表現的方向相反。

(B)正確。COSO 於 2023 年發布針對永續報導的內部控制補充指引，將 2013 年架構的五要素延伸適用於永續資訊，要求把環境、社會與治理（ESG）因素納入整體內部控制架構，而非另設一套平行制度。理由是永續資訊已成為投資人決策依據，其可靠性需要與財務報導同等的控制。

(C)錯誤。永續涵蓋環境、社會與治理三個面向，只看環境影響是以偏概全，也忽略了勞工、供應鏈、董事會運作等同樣需要控制的資訊。

(D)錯誤。內部控制的目標本來就包含營運、報導與遵循三類，報導也不限於財務報告；永續概念的加入正是要把非財務的永續資訊納入報導可靠性的範圍，與只考慮財務報告準確性相反。

1. 內部稽核單位宜直屬哪一單位較理想？
  1. (A)總經理
  2. (B)董事會
  3. (C)股東會
  4. (D)財務長
解析

(A)錯誤。總經理是執行業務的最高經理人，也是內部稽核查核的對象之一；稽核若隸屬總經理，查到經營階層的缺失時便難以據實呈報，獨立性不足。

(B)正確。公開發行公司建立內部控制制度處理準則第十一條要求內部稽核單位隸屬於董事會。內部稽核的查核對象包括經理人在內的所有單位，唯有直接向董事會負責，才不受經營階層的指揮與人事壓力，維持獨立性與客觀性，稽核報告也才能直達負責治理的層級。

(C)錯誤。股東會是非常設機關，每年僅集會一至數次，無法承擔稽核單位的日常督導與人事管理，故不適合作為稽核的隸屬單位。

(D)錯誤。財務長主管會計與資金，是舞弊風險最集中、也最需要被稽核的職位；稽核隸屬財務長之下形同讓受查者管理查核者，是最嚴重的利益衝突。

2. 稽核人員如欲了解電腦系統之結構，最可能使用下列何種文件？
  1. (A)系統流程圖
  2. (B)紀錄之數額
  3. (C)程式清單
  4. (D)紀錄之佈置
解析

  2. (B)公務機關對個人資料之利用應於執行法定職務必要範圍內為之，並與蒐集之特定目的相符
  3. (C)有關病歷、醫療、基因、性生活、健康檢查及犯罪前科之個人資料，不得蒐集、處理或利用
  4. (D)從重要資產清冊中辨別個人資料
解析

(A)正確。ISO 27001 的資產管理要求組織識別所有資產、為重要資產造冊並給予適切保護，目的是在保護資產的同時讓組織能正常使用它。個人資料保護法第1條的立法目的同樣是在避免人格權受侵害的前提下促進個人資料的合理利用，兩者都是「保護與利用並重」，在精神上最為相近。

(B)錯誤。此為個資法對公務機關利用個人資料的限制，要求在執行法定職務必要範圍內且與蒐集目的相符，屬於利用階段的規範，與資產識別與造冊的整體精神不同。

(C)錯誤。此為個資法對病歷、基因、犯罪前科等特種個人資料的蒐集處理限制，是針對特定資料類型的禁止規定，與識別資產並適切保護的管理架構不是同一層次。

(D)錯誤。從資產清冊中辨別個人資料是實務上的作業步驟，並不是個資法的任何條文；題目問的是與哪一條文精神相近，此項答非所問。

15. 企業之內部控制制度，銷售部門接獲訂單，若為新客戶，且此客戶財力不佳，無法於貨到付現時，宜先：
  1. (A)進行是否接單之討論
  2. (B)退回訂單
  3. (C)再討論訂購之內容
  4. (D)堅持貨到付現
解析

(A)正確。新客戶沒有交易往來紀錄，財力不佳又無法貨到付現，代表授信風險偏高但仍可能是值得爭取的業務；內部控制的作法是先由業務與財務或授信部門共同評估客戶信用、是否要求擔保或預付、以及可承受的額度，討論是否接單。這樣既避免業務員自行放寬條件造成呆帳，也不會武斷地放棄可以透過條件設計而控管的交易。

(B)錯誤。直接退回訂單是連評估都不做就放棄交易，雖然完全避開了風險，但也放棄了可能透過預收貨款、擔保或降低額度來控管的業務機會，處理過於武斷。

(C)錯誤。再討論訂購內容處理的是品項、數量或規格，並沒有觸及問題的核心，也就是客戶付款能力不足帶來的信用風險；內容談妥了，收不到款的問題依然存在。

(D)錯誤。客戶已經表明無法貨到付現，堅持這個條件等於直接放棄交易，與退回訂單沒有實質差別；正確的作法是先評估風險，再決定是否以其他條件承接。

18. 請選出屬於風險胃納(Risk Appetite)的敘述：

20. 公開發行公司1 年內累積與同一相對人取得或處分同一性質標的交易金額達公司實收資本額20%或新臺幣3 億元以上者，應辦理公告申報，所稱1 年內係以何者時點為基準，往前追溯推算1年？
  1. (A)會計年度開始日
  2. (B)會計年度終了日
  3. (C)本次交易事實發生日
  4. (D)董事會決議日
解析

(A)錯誤。若以會計年度開始日起算，年底的交易只需累計短短數月，年初則幾乎不用累計，公司就能把大額交易拆到跨年度以規避公告門檻，準則不採此基準。

(B)錯誤。會計年度終了日是年報編製的基準，並不是累計交易金額的起算點；以年底往前推算一年等於曆年制，同樣讓跨年度拆單有機可乘。

(C)正確。「公開發行公司取得或處分資產處理準則」第31條規定，所稱一年內係以本次交易事實發生之日為基準，往前追溯推算一年。採滾動的一年而非曆年，任何一筆交易發生時都要回頭累計前一年內與同一相對人的同性質交易，才能防止把一筆大額交易拆成多筆規避申報。

(D)錯誤。董事會決議日可由公司自行安排，若以它為基準，公司只要調整開會時點就能改變累計範圍；準則採客觀的交易事實發生日，正是為了避免人為操縱。
