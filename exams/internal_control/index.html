1. 下列工作何者最有可能由審計委員會負責？
  1. (A)員工聘任與升遷的決定
  2. (B)規劃財務報表之審計工作

(C)錯誤。預算編製屬管理階層之營運規劃工作。

(D)正確。審計委員會之核心職責在督導內部控制制度之有效建置與運作，以及財務報導與外部審計之監督，屬監督角色而非執行角色。

2. 稽核人員自出貨單母體中抽樣，再對入統一發票(存根聯)，此項查核之目的，在確定以下何者？
  1. (A)凡送交顧客的商品均已開立發票
  2. (B)凡送交顧客的商品均已記入銷貨
  3. (C)凡已入帳銷貨均業已運出
  4. (D)凡已開立發票的銷貨均業已運出
解析

(A)正確。以出貨單為母體往發票查，測試的是完整性——凡已送交顧客的商品是否都開了發票，可查出貨已出但漏開發票的遺漏。

(B)錯誤。要確認出貨均已記入銷貨，應追查至銷貨帳簿而非發票存根。

(C)錯誤。應由帳上銷貨查回出貨單，方向與本題相反。

(D)錯誤。應以發票為母體查對出貨單，方向與本題相反。

3. 下列何種預防措施可以使重要財務資訊在電腦感染病毒後，在損失最小的情況下重新恢復？
  1. (A)使用者採用了防毒程式
  2. (B)電腦硬體採用不受電腦病毒影響之機種規格
  3. (C)採用祖父子檔案之境外儲存
  4. (D)採用平行模擬的雙軌作業以分散風險
解析

(A)錯誤。防毒程式屬預防與偵測手段，對已遭破壞的資料無法回復。

(B)錯誤。並無不受電腦病毒影響的硬體規格可言，病毒感染的是軟體與資料。

(C)正確。祖父子三代備份並置於境外（異地），即使線上檔案與本地備份同遭感染，仍可回溯到未受感染的前一代檔案重建資料，是損失最小的復原設計。

(D)錯誤。平行模擬是一種查核技術（以查核程式重跑並比對結果），不是資料備援與復原機制。

5. 儘管大部分管理者費盡心思的經營績效並非全然令人滿意，但下列何種態度是管理者的首要條件？
  1. (A)善良管理人的態度
  2. (B)自利或惡意的態度
  3. (C)拼命經營的態度
  4. (D)努力省思的態度

(B)錯誤。自利或惡意的態度違背忠實義務，正是舞弊與掏空的根源。

(C)錯誤。拼命經營表現的是投入程度，無法取代應有的注意義務與判斷品質。

(D)錯誤。省思有助於改善，但屬事後檢討，不是管理者職責的首要條件。

  2. (B)倉儲部門
  3. (C)運輸部門
  4. (D)財務部門

(C)錯誤。運輸部門僅負責貨物運送，不執行驗收把關。

(D)錯誤。財務部門依驗收紀錄與發票付款，若同時負責驗收即違反職能分離原則。

7. 有關公開發行公司召開視訊股東會規定，下列何者是錯誤的？
  1. (A)股東會無董事或監察人選舉議案
  2. (B)股東會無解任董事或監察人議案
  3. (C)股東會無讓與或受讓重要財產、解散、合併或分割等重要決議之議案
  4. (D)已上市上櫃公司應以委託股務機構辦理股務事務為限

(A)錯誤。此為得以視訊方式召開股東會的條件之一：議程中無董事或監察人選舉議案。

(B)錯誤。此同為得以視訊方式召開的條件：議程中無解任董事或監察人之議案。

(D)正確（即敘述有誤者）。規定並未限制上市上櫃公司召開視訊股東會時「僅得」委託股務代理機構辦理股務事務；自行辦理股務者並非當然不得召開。

8. 甲公司為一上市公司，其分層負責層級之規定係投資金額達新台幣5 千萬元以上者，應經董事會通過。該公司年度中召開董事會通過未來一年內擬投資之標的需達信評A-以上，且投資金額不得逾公司淨值的10%，至實際投資標的及金額則授權董事長決定。請問以上投資程序是否符合公司內部控制規定？
  1. (A)不符合，因為公司實際投資流程與內控分層負責規定不符，可能受證交所違約金或主管機關依證交法處罰
  2. (B)符合，因為董事會已通過授權董事長辦理
  3. (C)不符合，但屬違反公司內部治理規章制度，故應無受行政裁罰之虞
  4. (D)符合，因為公司之分層負責層級非強制規定，可彈性務實執行
解析

(A)正確。分層負責既規定 5 千萬元以上投資須經董事會通過，實務上卻改由董事會概括授權董事長決定標的與金額，等於架空核決權限，屬未依所訂內部控制制度執行，公司可能因此受主管機關依證券交易法處分。

(B)錯誤。董事會不得以概括授權免除自身依分層負責規定應逐案決議的責任。

(C)錯誤。公開發行公司建立並執行內部控制制度有法令依據，未確實執行並非單純的內部規章問題，仍有行政責任。

(D)錯誤。分層負責與核決權限是內部控制制度的必要內容，一經訂定即應遵循，不得任意變通。

9. 公開發行公司辦理背書保證因業務需要，而有超過背書保證作業程序所訂額度之必要且符合公司背書保證作業程序所訂條件者，應先踐行下列何種程序，方得為之？
  1. (A)經公司總經理同意並由其對公司超限可能產生之損失具名聯保
  2. (B)經公司董事會同意並由半數以上之董事對公司超限可能產生之損失具名聯保，並修正背書保證作業程序，報經股東會追認之
  3. (C)經公司董事長同意並由其對公司超限可能產生之損失具名保證，並修正背書保證作業程序，報經股東會追認之
  4. (D)經公司監察人同意並由其對公司超限可能產生之損失具名保證

(A)錯誤。總經理層級不足以核准突破董事會所訂之背書保證額度。

(B)正確。超限屬突破公司自訂上限的例外，故要求經董事會同意、並由半數以上董事對可能損失具名聯保以承擔責任，同時修正背書保證作業程序報請股東會追認，使制度與實際作法一致。

(C)錯誤。並非由董事長一人同意並具名保證即可，責任層級與程序均不足。

(D)錯誤。監察人職司監督，不參與業務決策之核准，由其同意並保證於制度上不合宜。

10. 下列敘述何者較正確？
  1. (A)現金郵寄收入應由會計於拆封後立即編列清單並予入帳
  2. (B)收取現金之櫃台應分散設立以分散風險，不宜集中
  3. (C)原始憑證應在付訖後予以銷印加蓋戳記，以免重複請款
  4. (D)銀行對帳單應寄交出納，按期編製銀行調節表
解析

(A)錯誤。郵寄現金收入的拆封造冊應由非會計人員辦理，會計不宜同時經手現金與入帳。

(B)錯誤。收取現金的櫃台宜集中以利監督與勾稽，分散反而增加失控與挪用風險。

(C)正確。原始憑證於付訖後銷印或加蓋戳記，可防止同一張單據被再次提出請款，是付款循環最基本的防重複支付控制。

(D)錯誤。銀行對帳單應由非出納人員收受並編製銀行調節表，否則出納可自行掩飾挪用款項。

12. 為期蒐集銷貨是否經過適當核准的查核憑證，查核人員將自下列何者母體中抽取樣本？
  1. (A)銷貨訂單檔
  2. (B)提單檔
  3. (C)應收帳款明細分類帳
  4. (D)銷貨發票檔
解析

(A)正確。銷貨核准（含信用核准）發生在接單階段，核准痕跡留存於銷貨訂單，故應自訂單檔抽樣。測試控制必須從控制實際執行的那份文件抽樣，不能從其下游結果抽樣。

(B)錯誤。提單反映出貨事實，適合測試「已出貨是否開立發票」，非核准。

(C)錯誤。應收帳款明細分類帳是入帳結果，抽樣方向較適合測試存在性。

(D)錯誤。銷貨發票為開立結果之文件，非核准控制之來源母體。

114年第2次｜企業內部控制理論與實務(含相關法規)｜第 70 題
14. 在企業控制環境中，可從哪些事項觀察管理者的管理哲學與經營風格？
  1. (A)管理者對參與社交活動所採取的行動
  2. (B)管理者對員工家庭計畫支持的態度
  3. (C)管理者對法令瞭解的程度
  4. (D)管理者對經營風險的態度和控制風險的方法

18. 請選出屬於風險胃納(Risk Appetite)的敘述：

  2. (B)急診病患95%的等待時間在15 分鐘以內
  3. (C)對於損失機率大於25%的計畫皆不執行
  4. (D)企業為了追求策略性的目標，願意接受較高的風險

(C)錯誤。損失機率大於 25% 即不執行，是具體的決策門檻，屬風險容忍度。

(D)正確。風險胃納是企業為追求價值與策略目標所「願意承擔的整體風險量」，屬概括性、方向性的宣示；容忍度則是為落實胃納而訂在個別目標上的可衡量界限。
