1. 依據美國COSO 報告(2013 年)及我國「建立內部控制制度核心原則」，內部控制之目標在合理保證達成企業的目標。其目標不包括下列何者？
  1. (A)營運有效果及有效率
  2. (B)對外的財務報告有欠透明
  3. (C)對內與對外的報導係可靠、及時
  4. (D)遵循相關法令規章
解析

(A)錯誤。營運有效果及有效率，是COSO所列內部控制三大目標之一。

(B)正確（即非屬內部控制目標者）。內部控制的報導目標是要使報導可靠、及時且透明，「有欠透明」是缺失而非目標，本選項把目標敘述成其反面。

(C)錯誤。對內與對外報導之可靠、及時，屬報導目標。

(D)錯誤。遵循相關法令規章，屬遵循目標。

2. 我國企業出具內控聲明書，是由誰表明自己確知建立、實施和維護內部控制制度的責任？
  1. (A)董事會及經理人
  2. (B)董事會或經理人
  3. (C)董事會
  4. (D)經理人、財務副總、內部稽核人員
解析

(A)正確。內部控制制度之建立、實施與維護是董事會與經理人共同的責任，故聲明書由兩者一併表明，用「及」而非「或」。

(B)錯誤。責任由二者共同承擔，不是擇一。

(C)錯誤。僅列董事會不足，經理人負實際執行與維護之責。

(D)錯誤。財務副總與內部稽核人員非聲明主體；內部稽核是監督者，不宜對自己監督的制度作聲明。

3. 公開發行公司背書保證應於事實發生日之即日起算2 日內公告申報之標準，下列何者有誤？
  1. (A)公開發行公司及其子公司背書保證餘額達公開發行公司最近期財務報表淨值50%以上
  2. (B)公開發行公司及其子公司對單一企業背書保證餘額達公開發行公司最近期財務報表淨值20%以上
  3. (C)公開發行公司或其子公司新增背書保證金額達新臺幣3 千萬元以上且達公開發行公司最近期財務報表淨值5%以上
  4. (D)公開發行公司及其子公司對單一企業背書保證餘額達新臺幣1 千萬元以上，且對其背書保證、長期性質之投資及資金貸與餘額合計數達公開發行公司最近期財務報表淨值20%以上
解析

(A)錯誤（此標準正確）。公司及其子公司背書保證餘額達最近期財務報表淨值50%以上，應公告申報。

(B)錯誤（此標準正確）。對單一企業背書保證餘額達淨值20%以上，應公告申報。

(C)錯誤（此標準正確）。新增背書保證金額達新臺幣3千萬元以上且達淨值5%以上，應公告申報。

(D)正確（即敘述有誤者）。本款係合計背書保證、長期性質之投資及資金貸與餘額的門檻，其所定之淨值比率並非20%；20%是前款「對單一企業背書保證餘額」的門檻，本敘述把兩者混用。

4. 某一家中等規模製造廠商生產部經理訂購超額的原料，並指定送至其目前經營副業之一家倉儲公司。該經理偽造驗收文件並且核准付款支票。下列何種查核程序最能偵察此項舞弊？
  1. (A)從現金支付中抽樣並比對至訂購單、驗收報告、發票及支票副本
  2. (B)從現金支付中抽樣並請供應商證實樣本中的購買數量、購買價格及運送日期及地點
  3. (C)觀察收料倉庫並盤點已驗收之原料；將盤點數量比對至收料人員完成的驗收報告
  4. (D)執行分析性測試，比較生產量、原料購買量及原料庫存水準；並調查其差異
解析

(A)錯誤。訂購單、驗收報告與支票都在該經理掌控或偽造範圍內，單據彼此相符並不能證明貨物真的進了公司。

(B)錯誤。供應商確實出貨並收款，其回函只會與單據一致，仍看不出公司實際未收到原料。

(C)正確。此舞弊的核心是「有單無貨」——料根本沒進公司倉庫，驗收文件卻是偽造的。實地觀察收料倉庫、盤點已驗收原料並與驗收報告比對，才能直接揭穿實體與帳載的落差。

(D)錯誤。分析性測試只能顯示異常差異，屬間接的線索，不如實地盤點來得直接有力。

5. 為強化上市櫃公司治理功能，對公司具有控制能力之法人股東應遵事項，何者是正確的？
  1. (A)得依經營之需求隨時改派董監代表
  2. (B)本於大股東之自身利益行使其投票權
  3. (C)對其他股東負有誠信義務
  4. (D)為特定股東之利益提名董事及監察人
解析

(A)錯誤。隨時改派董監代表會破壞董事會的獨立性與任期穩定，並非治理所鼓勵。

(B)錯誤。控制股東行使投票權時應以公司整體利益為考量，不得僅本於自身利益。

(C)正確。對公司具控制能力的法人股東，實質上支配公司決策，因而對其他（少數）股東負有誠信義務，不得利用控制力為自己謀取不當利益。

(D)錯誤。為特定股東利益提名董事及監察人，正是治理上應避免的利益輸送。

6. 甲公司以往主要從事茶葉進出口貿易業務，今年考量國內市場逐漸飽和，且評估國內中產階級人士飲用進口酒類的比重逐漸增加，故決定今年開始從事進出口酒類交易。另因部分客戶在海外，因此，有大部分酒類交易係由供應商直接配送至海外客戶端。公司考量上開交易模式變更及新業務之引進，可能會引起會計師或監理機關對於收入認列時點及報表表達等方面之注意。甲公司評估後決定修正內部控制制度並執行相關控管程序。請問甲公司發現改變產品、交易模式可能導致外界之注意，屬於風險管理程序之何項要素?
  1. (A)風險辨識
  2. (B)風險評量
  3. (C)風險回應
  4. (D)監督與審查機制
解析

(A)正確。察覺產品與交易模式改變可能引起會計師或監理機關注意，是「找出可能影響目標達成之事項」的動作，屬風險辨識階段。

(B)錯誤。風險評量是在辨識之後衡量發生可能性與影響程度，本題尚未進行衡量。

(C)錯誤。風險回應是決定承擔、規避、移轉或降低；題中修正內控制度才屬回應，發現風險本身不是。

(D)錯誤。監督與審查是對風險管理運作持續評估的機制，非本題所述之發現階段。

7. 公開發行公司取得或處分會員證或無形資產交易金額達下列何項標準者，除與政府機構交易外，應於事實發生日前洽請會計師就交易價格之合理性表示意見，會計師並應依會計研究發展基金會所發布之審計準則公報第20 號規定辦理？
  1. (A)公司實收資本額20%或新臺幣3 億元以上
  2. (B)公司實收資本額20%且達新臺幣3 億元以上
  3. (C)公司實收資本額10%或新臺幣2 億元以上
  4. (D)公司實收資本額10%且達新臺幣2 億元以上
解析

(A)正確。交易金額達公司實收資本額20%或新臺幣3億元以上者（與政府機構交易除外），應於事實發生日前洽請會計師就交易價格合理性表示意見；兩項標準採「或」的關係，只要滿足其一即須辦理，使資本規模大小不同的公司都被涵蓋。

(B)錯誤。兩項標準為擇一適用，只要達到其一即須辦理，並非須同時達到實收資本額20%且滿新臺幣3億元。

(C)錯誤。10%與新臺幣2億元並非本項規定所設之門檻。

(D)錯誤。金額與比例均非規定所定，且兩者亦非「且」的關係。

8. 若應收帳款之積極式函證之回函中，有數份表示已於期後一週內付訖，則稽核人員較可能作成之結論或進一步採取的行動為：
  1. (A)查核期後一週內應收帳款之所有變動情形
  2. (B)確認該批客戶是否取得現金折扣
  3. (C)針對期後一週內付款之客戶再度函證
  4. (D)順查其收款紀錄
解析

(A)錯誤。查核期後一週內所有應收帳款的變動範圍過廣，不符成本效益，也未針對回函所指的差異。

(B)錯誤。客戶是否取得現金折扣與帳款是否存在、是否已收回無關，非本項查核重點。

(C)錯誤。客戶已明確回覆並說明付款時點，再度函證不會取得新的證據。

(D)正確。客戶既稱已付款，最直接的驗證是順查期後的收款紀錄（收款傳票、銀行入帳紀錄）確認該筆款項確已收訖，藉以佐證帳款存在且回函屬實。

9. 下列情形何者會被視為內部控制的嚴重缺失？
  1. (A)資訊部門由副總經理領導，並向總經理報告
  2. (B)會計與出納皆向財務長報告
  3. (C)審計委員會由執行長、財務長及大股東共同組成
  4. (D)財務部門由副總經理領導，並向總經理報告
解析

(A)錯誤。資訊部門由副總經理領導並向總經理報告，是正常的組織層級安排。

(B)錯誤。會計與出納同隸財務長之下並無不可，關鍵在兩者職務是否確實分離。

(C)正確。審計委員會的功能在獨立監督管理階層，若由執行長、財務長等被監督對象及大股東組成，監督者與被監督者合而為一，獨立性蕩然無存；法令亦要求審計委員會由獨立董事組成。

(D)錯誤。財務部門由副總經理領導並向總經理報告，屬一般的呈報體系。

10. 企業之控制活動，資產和紀錄存取的控制可藉下列何者程序來達成？
  1. (A)只有有權授權的人才能進入資產和紀錄存放的地方
  2. (B)只有總經理才能進入存放空白支票的地點
  3. (C)只有有權授權的人方能接近會計紀錄
  4. (D)只有經授權的人才能使用或做資料異動程序
解析

(A)錯誤。僅限制進入資產與紀錄的存放地點，只涵蓋實體接近，未及於紀錄的使用與異動。

(B)錯誤。把權限集中於總經理一人並非通則，反而違反職能分工與相互牽制。

(C)錯誤。僅限制接近會計紀錄，範圍偏狹，未涵蓋資產的使用與資料的變更。

(D)正確。存取控制的核心是「只有經授權者才能使用資產或異動紀錄」，同時涵蓋實體接近與資料變更兩個面向，是最完整的表述。

11. 下列那一項證實分析性程序最能顯示可能有過時存貨的問題？
  1. (A)與前幾年的毛利率百分比做比較
  2. (B)與前幾年的存貨單位成本做比較
  3. (C)與前幾年的製造費用做比較
  4. (D)前幾年的庫存周轉率做比較
解析

(A)錯誤。毛利率變動的成因很多，包括售價、成本與產品組合，未必指向存貨過時。

(B)錯誤。單位成本反映採購或製造成本的變化，與存貨是否滯銷沒有直接關係。

(C)錯誤。製造費用的比較反映生產效率與產能利用情形，無法顯示存貨賣不出去。

(D)正確。存貨周轉率下降代表貨品停留在倉庫的時間拉長，正是呆滯、過時存貨最直接的分析性訊號，可據以鎖定需進一步查核評價的品項。

12. 企業須透過風險管理，適時取得資訊，辨認影響目標不能達成的內、外在風險，並分析其影響程度及可能性，接下來再針對風險做何種反應？

(D)錯誤。風險管理無須向國稅局備案，此與稅務申報無關。

13. 為了達成財務報導目的，必須建立有效的內部控制，而其中「風險評估」是其重要的一環。下列何者屬於風險評估的基本原則？
  1. (A)清楚暸解未能達成財務報導目標的風險
