1. 內部稽核與內部控制之關聯為何？
  1. (A)內部稽核人員設計內部控制的制度
  2. (B)內部稽核應保證內部控制有效執行
  3. (C)內部稽核驗證內部控制的執行與評估有效性
  4. (D)內部稽核人員建立企業內部控制的政策
解析

(A)錯誤。設計內部控制制度是經理人的職責，再由董事會通過；稽核若自行設計制度，日後就是自己查核自己設計的東西，獨立性隨之喪失。稽核可以對設計提出建議，但不能主導設計。

(B)錯誤。內部控制受成本效益、人為判斷與串通共謀等先天限制，只能提供合理保證；稽核的結論也建立在抽查之上，能評估與建議，卻無法「保證」制度必然有效執行。

(C)正確。內部稽核是內部控制的監督機制：透過查核驗證各項控制是否確實執行，評估其設計與執行的有效性，並提出改善建議供董事會與經理人採行。稽核站在制度之外看制度，正因為它不負責設計與執行，其評估結果才具獨立性。

(D)錯誤。內部控制政策的建立屬董事會與經理人的治理與管理責任，稽核人員只負責事後查核政策是否被遵循、是否仍屬妥適；由稽核建立政策，就混淆了經營者與監督者的角色。

2. 有關重大性（Materiality），下列何項敘述正確？
  1. (A)重大性屬專業判斷
  2. (B)重大性判斷僅需考慮金額
  3. (C)重大性只與帳戶的品質因素有關
  4. (D)重大性標準之金額與查核風險水準存有正向關係
解析

(A)正確。重大性是指錯誤或遺漏達到何種程度會影響報表使用者的決策，此門檻須綜合金額大小、事項性質與受查者情況判斷，沒有放諸四海皆準的公式，本質上屬查核人員的專業判斷。實務上雖常以稅前淨利或總資產的某一比例作為起點，最終仍由查核人員決定。

(B)錯誤。金額只是量的面向；金額不大但涉及舞弊、違反法令、使損益由盈轉虧或關係人交易的事項，因其性質仍可能屬重大，故質的因素同樣必須納入考量。

(C)錯誤。這與選項B恰好走向另一個極端。重大性同時包含量的因素（金額）與質的因素（性質），只看品質因素而忽略金額，同樣不完整。

(D)錯誤。兩者是反向關係：重大性金額訂得愈低，代表容忍的錯誤愈小，須執行更多查核程序把查核風險壓低；門檻愈高，所能接受的查核風險相對較高。把它記成正向關係，是把「門檻高」誤想成「查得更嚴」。

3. 企業風險管理的基本目標，是每一個企業的存在，都是在為其利害關係人：
  1. (A)創造價值
  2. (B)迎接風險
  3. (C)減損價值
  4. (D)設立控制架構
解析

(A)正確。COSO企業風險管理架構的基本前提是：每一個企業的存在，都是為了替其利害關係人創造價值。管理階層在追求價值的過程中必然面對不確定性，風險管理就是在風險胃納內處理這些不確定性，使價值得以創造並維持。

(B)錯誤。迎接或承擔風險是創造價值過程中的手段，企業要決定的是承擔多少、哪一類風險（風險胃納），而不是以承擔風險本身作為存在的目的。

(C)錯誤。減損價值正是風險失控的結果，也是風險管理要防止的事；把它當成企業存在的目標，恰好把因果顛倒了。

(D)錯誤。控制架構是達成目標的工具，屬風險管理架構中控制活動與監督等要素的範疇；企業並非為了設立控制架構而存在，架構是服務於價值創造的。

7. 企業須透過風險管理，適時取得資訊，辨認影響目標不能達成的內、外在風險，並分析其影響程度及可能性，接下來再針對風險做何種反應？
  1. (A)評估企業所應採取的控制活動
  2. (B)請董事長信箱答覆
  3. (C)直接副知獨立董事
  4. (D)不可抗力者須向國稅局備案
解析

(A)正確。COSO風險評估的順序是：辨認影響目標達成的內外在風險，分析其發生可能性與影響程度，再決定風險回應（規避、降低、分擔或接受），並據以評估與設計應採取的控制活動。控制活動是把風險評估結果落實到日常作業的環節，少了這一步，風險評估只是一份清單。

(B)錯誤。董事長信箱屬員工申訴或意見反映的溝通管道，是資訊與溝通要素的一部分，並不是對已辨認風險的因應程序，也不會產生任何控制活動。

(C)錯誤。將風險資訊副知獨立董事屬向治理單位傳遞資訊，有助於監督，但傳遞資訊本身不會降低風險的可能性或影響，仍須由管理階層決定回應方式並設計控制。

(D)錯誤。國稅局主管稅捐稽徵，與企業風險管理流程無關；不可抗力事件是企業自行評估後決定接受或轉嫁（如投保）的風險，並沒有向稅務機關備案的程序。

9. 內部稽核人員在撰寫報告前，以及完成稽核報告呈核前，是否應先與被稽核單位適當的管理者討論，以使得被稽核單位有機會對特定項目加以澄清？

  2. (B)不需多此一舉
  3. (C)看內部稽核之意願
  4. (D)沒有規定

(A)正確。稽核報告在撰寫前及定稿呈核前，應與受查單位適當層級的管理者討論查核發現，讓受查單位有機會澄清事實、補充資料並提出改善規劃。這是稽核實務的基本程序：可避免報告誤植事實、減少爭議，也讓受查單位更願意接受並落實改善建議。

(B)錯誤。報告前溝通不是多餘的手續，而是確認查核發現正確性的品質控制步驟；未經受查單位核對事實就呈核，報告一旦出錯，受損的是稽核的公信力。

(D)錯誤。內部稽核實務與各項稽核準則對報告前與受查單位的溝通均有要求，題目描述的正是這項規範的內容，並不是無規定可循。

11. 企業之內部控制制度，採購部門發現生產部門請購之原料，不僅過去無採購紀錄，且生產部門亦未指定廠牌，若供應商間之報價差異甚大，採購部門宜如何處理？
  1. (A)選擇價格最低者
  2. (B)選擇品質最佳者
  3. (C)請稽核人員到場共同決定品質條件
  4. (D)應再徵詢生產部門之意見
解析

(A)錯誤。生產部門尚未指定廠牌與規格時，各家報價的標的可能根本不同，比價沒有共同基礎；逕選最低價，很可能買到規格不符、無法使用的原料。

(B)錯誤。品質好壞須以使用單位的需求為準，採購部門並非技術判斷者；逕選「品質最佳」既可能超出需求多付成本，也越過了使用單位認定規格的權責。

(C)錯誤。稽核人員的職責是事後查核採購程序是否被遵循，若到場共同決定品質條件，就成了決策參與者，日後無法獨立查核自己參與過的採購案。

(D)正確。過去無採購紀錄、又未指定廠牌，而報價差異甚大，通常反映各供應商對規格的理解不同，此時應回頭請提出請購的生產部門確認規格與廠牌需求，再進行比價。採購循環的分工是使用單位負責規格、採購負責價格與程序，規格不明就不應進入議價。

12. 企業存在下列哪種情形，最有可能盜用資產或虛假交易之可能性？
  1. (A)兄弟在同一間公司服務
  2. (B)在一人兼任多職務時，保管兼紀錄
  3. (C)員工在外兼職
  4. (D)在一人兼任多職務時，批准兼執行
解析
