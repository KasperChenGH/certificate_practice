  1. (A)控制環境與監督等二項
  2. (B)控制環境、風險評估、控制作業等三項
  3. (C)控制環境、風險評估、控制作業、資訊與溝通等四項

2. 有關重大性(Materiality)，下列何項敘述正確？
  1. (A)重大性屬專業判斷
  2. (B)重大性判斷僅需考慮金額
  3. (C)重大性只與帳戶的品質因素有關
  4. (D)重大性標準之金額與查核風險水準存有正向關係
解析

(A)正確。重大性須綜合金額大小（量的因素）與項目性質、對決策的影響（質的因素）判斷，沒有單一公式，本質上屬專業判斷。

(B)錯誤。金額不大但涉及舞弊、法令違反或關係人交易者仍可能重大，故不能只看金額。

(C)錯誤。重大性同時包含金額因素，不是只與品質因素有關。

(D)錯誤。重大性標準金額與查核風險為反向關係：重大性訂得越低，可容忍的誤述越小，須執行的查核工作反而越多。

4. 請選出屬於風險胃納(Risk Appetite)的敘述：
  1. (A)生產部門的良率目標為達到99.99%以上
  2. (B)急診病患95%的等待時間在15 分鐘以內
  3. (C)對於損失機率大於25%的計畫皆不執行
  4. (D)企業為了追求策略性的目標，願意接受較高的風險
解析

(A)錯誤。良率 99.99% 是可衡量的具體績效門檻，屬風險容忍度而非風險胃納。

(B)錯誤。等待時間 15 分鐘以內是量化的容許區間，屬風險容忍度。

(C)錯誤。損失機率大於 25% 即不執行，是具體的決策門檻，屬風險容忍度。

(D)正確。風險胃納是企業為追求價值與策略目標所「願意承擔的整體風險量」，屬概括性、方向性的宣示；容忍度則是為落實胃納而訂在個別目標上的可衡量界限。

5. 在COSO 2023 框架中，企業應該如何將永續性納入風險評估過程？
  1. (A)永續性風險應僅在內部控制報告中進行提及
  2. (B)應評估企業面臨的所有永續性風險，並將其融入日常運營和決策中
  3. (C)只在年度報告中簡要提及永續性風險
  4. (D)只考慮財務風險，永續性風險不需要單獨處理

(A)錯誤。僅在內部控制報告中提及，並未真正進入風險評估流程。

(C)錯誤。年報簡要提及屬事後揭露，不具風險評估的實質。

(D)錯誤。永續風險可能轉化為法遵、商譽與供應鏈風險，不能排除於評估之外。

6. 有關COSO 內部控制整合架構與企業風險管理整合架構二項報告對風險概念的敘述，下列何者錯誤？

  2. (B)風險胃納係企業追求整體使命或願景時，所願意接受的變動程度
  3. (C)風險容忍度係針對某個特定目標，管理階層願意接受該目標無法達成之變動程度

7. 查核下列哪一會計科目時，最有可能發現循環挪用(Lapping)？
  1. (A)現金
  2. (B)備抵壞帳
  3. (C)應收帳款
  4. (D)應付帳款

(D)錯誤。應付帳款屬付款循環，非挪用客戶收款的藏身處。

15. 稽核人員最喜歡將通用稽核軟體用於：
