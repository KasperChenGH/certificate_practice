1. 美國COSO 報告定義企業內部控制有幾項組成要素？
  1. (A)控制環境與監督等二項
  2. (B)控制環境、風險評估、控制作業等三項
  3. (C)控制環境、風險評估、控制作業、資訊與溝通等四項
  4. (D)控制環境、風險評估、控制作業、資訊與溝通、監督等五項
解析

(A)錯誤。控制環境與監督只是五要素的首尾：控制環境是制度的基礎，監督是對制度的持續評估；中間辨識風險的風險評估、因應風險的控制作業與貫穿全體的資訊與溝通都被漏掉，制度無從運作。

(B)錯誤。控制環境、風險評估、控制作業是「找出風險並處理」的前三個要素，但缺少把資訊在組織內上下傳遞的資訊與溝通，也缺少檢查制度是否仍然有效的監督，COSO 並不採三要素說。

(C)錯誤。四項只差一個監督。若沒有監督要素，制度設計得再好也無法得知其是否隨環境變化而失效；COSO 特別把監督獨立成一項，正是要確保內部控制能持續有效。

(D)正確。COSO 架構將內部控制定義為控制環境、風險評估、控制作業、資訊與溝通、監督五項組成要素，我國「公開發行公司建立內部控制制度處理準則」亦採同一分類。五者互為支撐：環境是基礎，評估辨識風險，作業回應風險，資訊與溝通貫穿全體，監督確保制度持續有效，缺一即不完整。

2. 有關重大性(Materiality)，下列何項敘述正確？
  1. (A)重大性屬專業判斷
  2. (B)重大性判斷僅需考慮金額
  3. (C)重大性只與帳戶的品質因素有關
  4. (D)重大性標準之金額與查核風險水準存有正向關係
解析

(A)正確。重大性指誤述達到何種程度會影響報表使用者的決策，須同時衡量金額大小（量）與項目性質（質），例如涉及舞弊、違法或關係人交易的小額項目也可能重大。沒有單一公式能決定，所以本質上是查核人員的專業判斷。

(B)錯誤。只看金額會漏掉質的因素：一筆金額不大的管理階層舞弊或法令違反，因為關係到公司誠信與持續經營，對使用者決策的影響遠超過其數字，仍應視為重大。

(C)錯誤。這是把量的因素完全排除的另一極端。重大性判斷通常先以金額設定基準（例如稅前淨利的某一比率），再以質的因素調整，兩者缺一不可，並非只與品質因素有關。

(D)錯誤。兩者是反向關係：可接受的查核風險越低，查核人員設定的重大性金額就越小，以便偵出更小的誤述，須執行的查核程序也越多；重大性訂得越高，容忍的誤述越大，查核風險相對升高。

4. 請選出屬於風險胃納(Risk Appetite)的敘述：
  1. (A)生產部門的良率目標為達到99.99%以上
  2. (B)急診病患95%的等待時間在15 分鐘以內
  3. (C)對於損失機率大於25%的計畫皆不執行
  4. (D)企業為了追求策略性的目標，願意接受較高的風險
解析

(A)錯誤。良率 99.99% 是可衡量的具體績效門檻，屬風險容忍度而非風險胃納。

(B)錯誤。等待時間 15 分鐘以內是量化的容許區間，屬風險容忍度。

(C)錯誤。損失機率大於 25% 即不執行，是具體的決策門檻，屬風險容忍度。

(D)正確。風險胃納是企業為追求價值與策略目標所「願意承擔的整體風險量」，屬概括性、方向性的宣示；容忍度則是為落實胃納而訂在個別目標上的可衡量界限。

5. 在COSO 2023 框架中，企業應該如何將永續性納入風險評估過程？
  1. (A)永續性風險應僅在內部控制報告中進行提及
  2. (B)應評估企業面臨的所有永續性風險，並將其融入日常運營和決策中
  3. (C)只在年度報告中簡要提及永續性風險
  4. (D)只考慮財務風險，永續性風險不需要單獨處理

(A)錯誤。僅在內部控制報告中提及，並未真正進入風險評估流程。

(C)錯誤。年報簡要提及屬事後揭露，不具風險評估的實質。

(D)錯誤。永續風險可能轉化為法遵、商譽與供應鏈風險，不能排除於評估之外。

6. 有關COSO 內部控制整合架構與企業風險管理整合架構二項報告對風險概念的敘述，下列何者錯誤？
  1. (A)風險胃納(Risk Appetite)與風險容忍度(Risk Tolerance)均屬事前的觀念
  2. (B)風險胃納係企業追求整體使命或願景時，所願意接受的變動程度
  3. (C)風險容忍度係針對某個特定目標，管理階層願意接受該目標無法達成之變動程度
  4. (D)風險容忍度的範圍比風險胃納的範圍大
解析

(A)錯誤。風險胃納與風險容忍度都是事先設定的界線，敘述無誤。

(B)錯誤。風險胃納係企業追求使命願景時願意承受的整體變動程度，定義正確。

(C)錯誤。風險容忍度係就特定目標可接受的達成變異程度，定義正確。

(D)正確（即敘述有誤者）。風險容忍度是在風險胃納之下，就個別目標所訂的較窄界線，範圍應小於而非大於風險胃納。

7. 查核下列哪一會計科目時，最有可能發現循環挪用(Lapping)？
  1. (A)現金
  2. (B)備抵壞帳
  3. (C)應收帳款
  4. (D)應付帳款
解析

(A)錯誤。循環挪用的手法正是用後收的款項填補先前挪走的現金，帳上現金餘額與銀行對帳單通常仍能勾稽，光查現金科目不易看出異常，只有挪走的缺口未被填補時才會浮現。

(B)錯誤。備抵壞帳是期末依帳齡或經驗估計的評價科目，反映收不回的風險，並不逐筆記錄客戶的收款與沖銷；挪用者操縱的是入帳時點而非壞帳估計，查此科目找不到痕跡。

(C)正確。循環挪用（Lapping）是收款人員挪走甲客戶的付款，再用乙客戶稍後的付款沖銷甲的帳款，如此不斷往後遞延掩飾。痕跡留在應收帳款明細帳上：各客戶的入帳日期落後於實際收款日、沖銷金額與客戶對不上，所以查應收帳款並函證客戶、比對收款日與入帳日最能發現。

(D)錯誤。應付帳款屬採購付款循環，記錄公司欠供應商的款項，與客戶匯入的現金無關；挪用客戶收款的舞弊不會在應付帳款留下任何紀錄。

115年第2次｜企業內部控制理論與實務(含相關法規)｜第 8 題
9. 企業內部控制組成要素中，為確保制度能持續有效運作的一種隨著時間經過而評估執行內部控制品質的過程稱之為：
  1. (A)控制環境
  2. (B)風險評估
  3. (C)監督
  4. (D)資訊及溝通
解析

(A)錯誤。控制環境是管理階層的誠信、經營理念、組織結構與人事政策所形成的整體氛圍，它是其他要素運作的基礎，本身並不是「隨時間評估執行品質」的過程。

(B)錯誤。風險評估是辨識並分析可能妨礙目標達成的內外部風險，決定如何因應；它評估的是風險，不是內部控制本身執行得好不好。

(C)正確。監督是指隨時間經過持續評估內部控制執行品質的過程，透過持續性監督（融入日常作業）與個別評估（如內部稽核、自行評估）確認各要素是否仍有效運作，並回報缺失促其改善。設此要素的理由是制度會隨環境變遷而失效，必須有專責機制檢查制度本身。

(D)錯誤。資訊與溝通處理的是資訊如何被辨識、蒐集並在組織內外傳遞，使人員能履行職責；它是監督結果得以傳達的管道，但不是評估執行品質的過程本身。

10. 公開發行公司應實施內部稽核，其目的在於協助下列何者檢查及覆核內部控制制度之缺失及衡量營運之效果及效率，並適時提供改進建議，以確保內部控制制度得以持續有效實施及作為檢討修正內部控制制度之依據？
  1. (A)大股東
  2. (B)股東會
  3. (C)債權人
  4. (D)董事會及經理人
解析

(A)錯誤。大股東只是持股較多的股東，不參與公司的日常經營與治理決策；內部稽核隸屬董事會，其報告對象是治理與管理階層，不對個別股東服務。

(B)錯誤。股東會是公司最高意思機關，通常一年開會一次，無法逐案檢討內控缺失；內控制度的檢討修正是董事會與經理人的日常責任，稽核報告也是送董事會（或審計委員會）而非股東會。

(C)錯誤。債權人是外部關係人，依賴公司公開的財務報告與會計師意見來評估信用，不能使用公司內部稽核的檢查與覆核結果；內部稽核不是為債權人設的。

(D)正確。「公開發行公司建立內部控制制度處理準則」第10條規定，內部稽核之目的在於協助董事會及經理人檢查及覆核內部控制制度之缺失及衡量營運之效果及效率，並適時提供改進建議。稽核隸屬董事會、獨立於各業務單位，其發現正是治理層與管理階層檢討修正內控的依據。

11. 企業未落實資金貸與他人之作業程序，浮濫的將資金貸與他人，不僅無法達成遵循相關法令規定之目標，也會影響下列何項目標之達成？
  1. (A)營運效果及效率目標
  2. (B)資本公積轉增資計畫目標
  3. (C)組織記憶目標
  4. (D)資金貸與他人目標
解析

(A)正確。內部控制的三大目標是營運之效果及效率、報導之可靠性與相關法令之遵循。資金浮濫貸與他人，除了違反資金貸與的法令規定外，公司資金被占用、周轉受限、甚至收不回來，直接損害資源運用的效率與經營目標的達成，所以同時傷及營運目標。

(B)錯誤。資本公積轉增資是籌資或股利政策上的決策，不是內部控制所定義的目標類別；資金貸與是否浮濫也不會直接決定能否辦理轉增資。

(C)錯誤。內部控制的目標並沒有「組織記憶」這一項，這是把知識管理的用語混入內控架構，是純粹的干擾選項。

(D)錯誤。資金貸與他人是內部控制制度必須涵蓋的一項作業（控制作業循環），不是內控的目標；題目問的是未落實這項作業會影響哪個「目標」，作業本身不能是答案。
