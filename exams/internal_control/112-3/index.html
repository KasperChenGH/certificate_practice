1. 「合理保證」的觀念包括控制之成本不應大於其效益的原則。在分析特定控制的成本效益時，下列何者不是應考慮的因素？
  1. (A)若無控制的情形下，損失發生的頻率及金額
  2. (B)達成類似目標的其他替代性控制程序的有無及可行性
  3. (C)該控制對員工生產力及士氣的影響
  4. (D)高階主管對執行內部控制的態度
解析

(A)錯誤。若無控制時損失發生的頻率及金額，正是估計控制效益的基礎，必須考慮。

(B)錯誤。有無其他可達成相同目標且更經濟的替代控制，直接影響本項控制是否值得採行。

(C)錯誤。控制對員工生產力與士氣的影響屬隱性成本，應納入成本效益衡量。

(D)正確。高階主管對內部控制的態度屬控制環境（誠信與監督氛圍）的議題，會影響控制能否落實，但不是衡量某項控制成本與效益時的計算因素。

3. 建立內部控制係公司管理階層的責任，為了建立有效的內部控制，公司應採取以下何種作法：
  1. (A)新興科技具有無法想像之風險，且易有資安漏洞，故企業應儘量雇用人員執行控制、定期稽核
  2. (B)所有的上市及上櫃公司均應就其營運訂定八大循環之控制作業
  3. (C)應考量該公司及子公司整體環境、產業特性及營運活動建立內部控制制度，並隨時檢討、確實執行
  4. (D)為監理一致性且便於監督，證交所應就上市公司之產業及企業組織型態訂定內部控制制度標準規範，俾利企業經營
解析

(A)錯誤。面對新興科技的風險，應強化自動化控制與資安管理，而非以增聘人力執行人工控制取代。

(B)錯誤。營運循環應依公司實際業務性質增刪調整，並非所有公司都一律套用同一組固定循環。

(C)正確。內部控制必須依公司及子公司的整體環境、產業特性與營運活動量身設計，並隨時檢討、確實執行；制度是否有效，取決於是否貼合自身風險，而非抄用他人版本。

(D)錯誤。由證交所訂定統一標準規範，違背內控應因公司制宜的本質，也無法涵蓋各公司不同的風險。

  2. (B)甲公司應考量其子、孫公司所在地政府法令之規定及實際營運之性質，督促其建立內部控制制度

(D)錯誤。迴避是不從事該項活動的因應策略，非辨認過程。

8. 公開發行公司內部稽核人員之設置，何者正確？

  2. (B)公司內部稽核人員出缺，稽核工作可暫由不具利害衝突的稽核代理人執行
  3. (C)為提升集團稽核效能，母公司的內部稽核人員可同時擔任重要子公司的稽核人員

112年第3次｜企業內部控制理論與實務(含相關法規)｜第 13 題
13. 稽核人員或許無需函證決算日之應付帳款餘額，因為：
  1. (A)其與抽查截止之工作重複
  2. (B)決算日之應付帳款餘額，在完成審計以前可能尚未支付
  3. (C)與委託人之律師聯繫，可揭露因未償付債款而賣方將採取的所有法律行動
  4. (D)或許存有其他可靠的外部憑證，以證實此項餘額
解析

(A)錯誤。截止測試與餘額存在性、完整性的查核目的不同，不能視為重複工作。

(B)錯誤。決算日餘額尚未支付並非免除函證的理由，未清償的債務反而是查核重點。
