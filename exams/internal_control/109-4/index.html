1. 依據美國COSO 報告(2013 年)及我國「建立內部控制制度核心原則」，內部控制之目標在合理保證達成企業的目標。其目標不包括下列何者？
  1. (A)營運有效果及有效率
  2. (B)對外的財務報告有欠透明
  3. (C)對內與對外的報導係可靠、及時
  4. (D)遵循相關法令規章
解析

(A)錯誤（此項敘述無誤）。營運之效果及效率是 COSO 與公開發行公司建立內部控制制度處理準則第三條所列的第一項目標，涵蓋績效、獲利與資產安全。

(B)正確（此項敘述有誤）。內部控制的報導目標是要使對內與對外的報導可靠、及時、透明並符合相關規範；「對外的財務報告有欠透明」是內部控制要防止的缺失，不可能是它的目標，因此本項不屬於內部控制目標。

(C)錯誤（此項敘述無誤）。對內與對外的報導可靠、及時，正是報導目標的內容，且依準則定義報導包含財務與非財務報導。

(D)錯誤（此項敘述無誤）。遵循相關法令規章是內部控制三大目標之一的遵循目標，違反法令會帶來罰則與商譽損失，所以被納入控制範圍。

2. 美國COSO 報告(2013 年)指出，在企業內部控制組成要素中，何項為公司設計及執行內部控制制度之基礎？
  1. (A)風險評估
  2. (B)控制環境
  3. (C)資訊與溝通
  4. (D)控制作業
解析

(A)錯誤。風險評估是在既有的控制環境之上，辨識並分析達成目標的障礙；它決定「要控制什麼」，但不是整個制度的基礎。

(B)正確。控制環境是 COSO 五大組成要素的基礎，包括管理階層的誠信與道德價值、董事會的監督、組織結構與權責分派、人力資源政策等，它決定組織的紀律與架構，其他四個要素都建構在它之上。若高層本身不重視誠信，再嚴密的控制作業也可能被凌駕，因此 COSO 把它稱為其他要素的基礎。

(C)錯誤。資訊與溝通是讓各要素能夠運作的傳遞管道，使控制所需的資訊能在組織內外流通，但它本身依附於既有的控制環境。

(D)錯誤。控制作業是為因應風險評估結果而設計的具體政策與程序，如核准、覆核、職能分工，是建構在控制環境之上的執行層面。

3. 企業建立內部控制制度後，就能絕對確保各項交易活動的進行均有秩序、有效率地進行嗎？
  1. (A)只要管理者不踰越內部控制，即可絕對確保
  2. (B)只要監察人或審計委員會不疏於監督，即可絕對確保
  3. (C)無論如何僅能合理確保，不能絕對確保
  4. (D)只要全體員工宣誓不踰越內部控制，即可絕對確保
解析

(A)錯誤。管理階層踰越僅是固有限制之一，即使不踰越仍無法達到絕對確保。

(B)錯誤。監督再嚴密，仍受成本效益、人為錯誤與共謀等固有限制影響。

(C)正確。內部控制受成本效益考量、人為判斷錯誤、共謀舞弊及管理階層踰越等固有限制，只能提供合理確保而非絕對確保。理解此一界線，才不會對內控寄予不切實際的期待。

(D)錯誤。員工宣誓無法排除人為錯誤與共謀，制度仍僅能合理確保。

4. 欲企業所設計及執行之內部控制制度之要件為有效，下列何者有誤？
  1. (A)各組成要素及各攸關原則已經存在，且持續運作
  2. (B)五大組成要素能整體運作
  3. (C)設計及執行內部控制制度時無須考量其效益與成本
  4. (D)定期檢視內部控制制度，考量企業之規模、業務範圍、競爭狀況及風險水準等因素，並隨情況之變化適時調整
解析

(A)錯誤（此項敘述無誤）。COSO 2013 年架構判斷內部控制有效的第一個要件，就是各組成要素及其攸關原則均已存在且持續運作。

(B)錯誤（此項敘述無誤）。五大組成要素必須整體運作、互相配合，才能降低未達成目標的風險，這是有效性的第二個要件。

(C)正確（此項敘述有誤）。內部控制先天受成本效益限制，設計與執行任何控制都必須衡量其耗費的成本與可降低的風險損失，成本高於效益的控制不應採行。「無須考量效益與成本」違反內部控制的固有限制，因此本項敘述有誤。

(D)錯誤（此項敘述無誤）。企業規模、業務範圍、競爭狀況與風險水準都會隨時間改變，內部控制制度必須定期檢視並適時調整，才能持續有效。

5. 過去有效的內部控制，隨著時間及企業環境改變，未來不一定有效。因此，企業內部控制良窳之重點在：
  1. (A)是否具有辨識控制作業改變的能力
  2. (B)是否具有自我監督之機制，缺失ㄧ經辨認，即採取更正之行動
  3. (C)是否出具內部控制制度聲明書
  4. (D)內部控制制度聲明書是否據實反應缺失之不利影響
解析

(A)錯誤。辨識控制作業的改變只是察覺環境變動的第一步，若察覺後沒有相應的修正行動，控制仍會隨時間失效。

(B)正確。內部控制之所以會隨時間與環境改變而失效，是因為原本的控制未能配合調整；良窳的關鍵在於監督作業是否有效，也就是有沒有自我監督機制，持續評估控制運作情形，缺失一經辨認即採取更正行動。這種評估、發現、修正的回饋循環，才能讓制度動態維持有效。

(C)錯誤。出具內部控制制度聲明書是公開發行公司每年向主管機關申報的形式要求，聲明書本身並不能使控制變好，缺乏自我監督的公司一樣可以出具聲明書。

(D)錯誤。聲明書據實揭露缺失及其不利影響是誠實揭露的表現，但仍屬事後對外報告；決定內部控制良窳的是有沒有在平時發現並更正缺失，而不是揭露得誠實與否。

7. 會計師受託專案審查公開發行公司之內部控制制度，除主管機關另有規定外，其審查範圍為何？
  1. (A)各營運循環控制作業
  2. (B)營運之效果及效率之內部控制制度
  3. (C)與外部財務報導及保障資產安全有關之內部控制制度
  4. (D)相關法令遵循之內部控制制度
解析

(A)錯誤。各營運循環的控制作業是公司自行評估與內部稽核的查核對象；會計師受託專案審查的範圍由準則限定，不是逐一審查所有循環。

(B)錯誤。營運之效果及效率屬經營判斷，難以用會計師的專業程序客觀認定，準則並未把它納入會計師專案審查的範圍。

(C)正確。依公開發行公司建立內部控制制度處理準則第二十八條，會計師受託專案審查公開發行公司內部控制制度，除主管機關另有規定外，審查範圍為受查公司與外部財務報導及保障資產安全有關之內部控制制度。之所以限定在這兩者，是因為它們最直接影響投資人所依賴的財務報告的可靠性，也最能發揮會計師的專業。

(D)錯誤。相關法令遵循是內部控制三大目標之一，但會計師專案審查的法定範圍限於外部財務報導與資產安全，法令遵循不在其中。

11. 下列何者是內部稽核所扮演的主要角色？
  1. (A)協助外部審計人員從事財務報表查核工作
  2. (B)研究並負責提出增加生產效率的方法
  3. (C)檢查及複核內部控制制度之缺失，以及衡量營運之效果及效率
  4. (D)替董事長監督經理人的行為
解析

(A)錯誤。內部稽核的工作底稿可供外部審計人員參考，但協助財報查核只是附帶的配合事項，不是內部稽核存在的主要目的。

(B)錯誤。研究並提出增產方法是生產或工程部門的職責；內部稽核可以評估生產作業的效率並提出建議，但不負責設計與執行改善方案，否則就失去客觀的評估立場。

(C)正確。依公開發行公司建立內部控制制度處理準則第十條，內部稽核的目的在協助董事會及經理人檢查及覆核內部控制制度之缺失，衡量營運之效果及效率，並適時提供改進建議。內部稽核是獨立的評估者而非執行者，這條界線正是它獨立性與客觀性的來源。

12. 企業風險管理中，為避免某項攸關風險被忽略，應如何辨識風險事項，評估風險發生之可能性？
  1. (A)由同一人分別進行
  2. (B)由同一人同時進行
  3. (C)由不同人分別進行
  4. (D)由不同人同時進行
解析

(A)錯誤。由同一人分別進行仍屬單一觀點，難以避免既有盲點。

73. 薪資報酬委員會為決議時，其同意之標準為何？

  2. (B)全體成員二分之一以上出席，及出席成員過半數之同意
  3. (C)全體成員三分之二以上同意
  4. (D)全體成員二分之一以上同意
