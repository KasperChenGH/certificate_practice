1. 關於「公開發行公司股務處理準則」之適用對象,下列敘述何者正確?
  1. (A)僅適用於上市公司,上櫃與興櫃公司改依櫃買中心之自律規章辦理股務
  2. (B)適用於公開發行股票之公司,及受其委任辦理股務之股務代理機構
  3. (C)僅適用於自辦股務之公司,委外者依受任機構自訂之作業規範辦理即可
  4. (D)所有股份有限公司均一體適用,未公開發行者亦應依本準則設置股務單位
解析

(A)錯誤。準則以「公開發行」為適用門檻,而非以掛牌市場別劃分;上櫃、興櫃乃至未上市之公開發行公司同受規範,交易所與櫃買中心的規章是在其上再加的自律要求。

(B)正確。準則規範公開發行公司的股務事務,而公司將股務委外時作業實際由股務代理機構執行,故受任的代理機構同受拘束;否則公司只要委外即可脫法,規範將被架空。

(C)錯誤。恰好相反,委外並不使作業脫離準則;受任機構須依準則辦理,委任公司亦不因委外而免除其對股東的責任。

(D)錯誤。未公開發行之股份有限公司其股務悉依公司法及章程辦理,不受本準則規範;本準則是證券主管機關為公開發行公司的股務作業所設的行政規範。

2. 公開發行公司停止過戶期間內，集中市場買賣已集中保管股票的交割作業為何仍能照常進行？
  1. (A)因為停止過戶期間內成交的買賣，一律遞延至過戶開放後才辦理券款的交割
  2. (B)因為股東名簿的名義人仍為集保結算所，帳簿劃撥的移轉不變更股東名簿的記載
  3. (C)因為停止過戶期間內的買賣僅先移轉價金，有價證券俟過戶期間屆滿後才辦理撥轉
  4. (D)因為主管機關就停止過戶期間的買賣另訂有逐案申請的例外許可程序
解析

(A)錯誤。若交割遞延，市場流動性將在每次停止過戶期間中斷，這正是集中保管制度所要避免的結果。

(B)正確。停止過戶所凍結的是股東名簿的變更，而集中保管股票的名義人是集保結算所，買賣移轉只在集保帳簿內的帳戶間發生，不觸及股東名簿。買賣與交割因而不受影響，這是集中保管制度的重要實益之一。

(C)錯誤。集中市場的買賣是券款同時履行，不存在只移轉價金、有價證券延後移轉的安排。

(D)錯誤。這不是靠例外許可解決的問題，而是制度架構本身就使兩者互不衝突，毋須任何個案豁免。

3. 公司將股份作為員工獎酬發放，並與員工約定於一定期間內不得轉讓。此種安排在公司法上應如何定位？
  1. (A)屬純粹的勞動契約事項，與公司法之股份規定無涉
  2. (B)屬股份轉讓自由原則之法定例外，法律明文允許此種約定
  3. (C)屬違反股份轉讓自由原則之約定，該約定當然無效
  4. (D)屬公司得於章程對全體股東設定轉讓限制之一般依據
解析

(A)錯誤。閉鎖期的效力來自公司法對轉讓限制的特別容許，股務單位並須據以控管該批股份的過戶，並非單純的勞動契約議題。

(B)正確。公司法明文允許公司就發給員工之股份與員工約定於一定期間內不得轉讓，以發揮留才與利益綁定的效果；因為有法律明文，才不致牴觸不得以章程限制轉讓的原則。

(C)錯誤。若無法律明文，對股份轉讓設限確實有效力上的疑義；但員工獎酬股份的閉鎖期已有法律依據，並非當然無效之約定。

(D)錯誤。此一例外僅及於員工依獎酬取得之股份，公司不得援引為在章程中限制一般股東轉讓自由的依據。

4. 股務單位受理股票過戶申請時,其審核之核心事項為下列何者?
  1. (A)審查受讓人的信用狀況與財力來源,並就其資力是否足以持有該股份出具評估意見
  2. (B)審查該次轉讓價格是否與市價相當,並就顯不相當者通報稅捐稽徵機關
  3. (C)審查申請文件是否齊備、印鑑是否與留存印鑑相符、讓與人是否為名簿記載之股東
  4. (D)審查該次轉讓是否已經公司董事會決議同意並載明於議事錄
解析

(A)錯誤。股份的取得不以受讓人的財力為條件,股務單位既無查核財力的權限,也無評估其資力並表示意見的立場。

(B)錯誤。轉讓價格屬當事人自由約定,價格是否相當可能是稅捐機關關切的事項,不是股務單位的審核範圍。

(C)正確。過戶審核的本質是形式審查與同一性確認:確認申請人確為有權處分之人、意思表示為真正,並確認應附文件齊備;印鑑核對正是判斷申請真偽最直接的工具。

(D)錯誤。股份自由轉讓為股份有限公司的基本原則,公開發行公司的股份轉讓不需董事會同意,董事會亦無權以決議否准過戶。

5. 已辦妥設質登記之股份,嗣後申請辦理質權註銷登記時,下列敘述何者正確?
  1. (A)應由質權人會同申請或出具同意文件,以確認擔保關係確已消滅
  2. (B)須報經證券主管機關核准,並副知集保結算機構後始得註銷
  3. (C)由出質人檢具清償證明單獨申請即可註銷,毋須質權人參與
  4. (D)由公司於擔保債權清償期屆至時,依原設質登記資料逕行註銷
解析

(A)正確。註銷登記與設質登記採相同的雙方確認原則:設質時由雙方會同建立負擔,消滅時也應由質權人表示同意,股務單位才有客觀依據認定擔保關係已終結。

(B)錯誤。質權的設定與消滅屬私法關係,股務單位依規定文件辦理即可,不需主管機關逐案核准。

(C)錯誤。清償證明多由質權人出具,股務單位無從辨別其真偽;若容許出質人單方為之,質權人在名簿上的擔保外觀將隨時可能被抹除。

(D)錯誤。清償期屆至不等於債務已清償,公司也無從查證雙方的清償狀況,自不得逕行註銷。

6. 某公開發行公司預定召開股東常會,並因議案需要另行召開一次股東臨時會。依公司法有關股東會召集通知期間之規定,下列敘述何者正確?
  1. (A)股東常會應於開會三十日前通知,股東臨時會應於開會十五日前通知
  2. (B)股東常會與股東臨時會均應於開會十五日前通知各股東
  3. (C)股東常會應於開會十五日前通知,股東臨時會應於開會三十日前通知
  4. (D)股東常會與股東臨時會均應於開會三十日前通知各股東
解析

(A)正確。公司法就股東會召集通知定有不同期間,股東常會為開會三十日前、股東臨時會為開會十五日前。常會期間較長,是因常會須承認財務報表、選任董監等重大事項,股東需要較充裕的時間審閱議案並決定表決方式。

(B)錯誤。十五日為股東臨時會之通知期間;臨時會事由通常單一且具時效性,故期間較短,股東常會不得比照適用。

(C)錯誤。此為兩者對調之錯誤記憶。常會之通知期間長於臨時會,而非相反。

(D)錯誤。三十日係股東常會之通知期間;若臨時會亦一律須三十日,公司將無法及時處理具時效性之議案。

7. 投資人於某上市公司除息交易日當日買進該公司股票,並持續持有至基準日之後。關於其能否參與本次現金股利之分派,下列敘述何者正確?
  1. (A)不能參與,因其交割完成之時點已在最後過戶日之後,無法列入基準日股東名簿
  2. (B)可以參與,惟公司應自其應領股利中扣除相當於除息參考價之金額
  3. (C)不能參與,因除息交易日當日買進之股票依規定一律不得辦理過戶登記及領取股利
  4. (D)可以參與,因其於基準日當日確實持有該公司之股票
解析

(A)正確。有權領取股利者以基準日股東名簿之記載為準,而名簿之登載須先完成交割與過戶。於除息交易日買進者,其交割完成時已逾最後過戶日,故不列入名簿,這也是股價於當日須向下調整的原因。

(B)錯誤。除息參考價是交易所對當日開盤參考價所作之調整,並非自股利中扣款。

(C)錯誤。該股票仍可正常辦理過戶登記,只是完成時點落在停止過戶之後,無從趕上本次分派。

(D)錯誤。實際持有股票不等於名列基準日股東名簿;股務作業係以名簿記載認定權利人。

8. 公開發行公司將股務事務委任專業股務代理機構辦理後,關於責任歸屬,下列敘述何者正確?
  1. (A)股務代理機構僅負資料保管之責,其餘風險概由各股東自行承擔
  2. (B)責任歸屬由發行公司與股務代理機構於契約中約定後,即得對抗股東
  3. (C)發行公司對股東所負之股務相關責任,不因委任而免除
  4. (D)發行公司自委任生效日起完全免責,由股務代理機構單獨對股東負責
解析

(A)錯誤。股務代理機構受任辦理過戶、股東會、配發等事務,其責任遠不止於資料保管。

(B)錯誤。契約僅拘束當事人間之內部分擔,不能用以對抗契約以外之股東。

(C)正確。委任僅是作業層面之外包,股東之權利義務關係始終存在於股東與發行公司之間,故公司仍應負選任及監督之責,並就股務結果對股東負責。

(D)錯誤。若委任即可免責,公司將無誘因監督代理機構之作業品質,股東保障形同落空。

9. 實務上所稱的「空白委託書」（受託人欄或議案指示欄未填載即行交付流通），其最主要的問題是什麼？
  1. (A)公司將無從計算出席股數，該次股東會因而未達法定出席門檻，決議不能合法成立
  2. (B)空白委託書一律視為棄權票計入出席股數，將使議案無從達到法定的表決權數
  3. (C)空白委託書僅得用於股東常會，不得用於為改選董事、監察人而召開的股東臨時會
  4. (D)委託書脫離委託人的具體意思，得任意轉手填載，使表決權淪為流通標的
解析

(A)錯誤。出席股數依經查核有效的委託書計算，空白或有瑕疵者剔除即可，並不會使股東會因此無法成立。

(B)錯誤。空白委託書的處理是依其瑕疵性質判斷可否採認，並無一律視為棄權的規則；瑕疵委託書是被剔除，而非計為棄權票。

(C)錯誤。委託書的形式要求不因股東常會或臨時會、亦不因議案是否涉及改選而有不同，並無僅限常會使用的區分。

(D)正確。受託人欄空白，委託書就可以在市場上轉手，由持有者事後填上任何人的姓名；議案指示欄空白，代理人則可自由決定投票方向。兩者都使表決權與股東的真意脫節，正是規則要求載明受託人與逐項指示所欲防堵的核心弊端。

10. 下列何者通常不會構成委託書遭剔除、其所代理表決權不予計算的瑕疵？
  1. (A)使用非公司印發的委託書用紙
  2. (B)委託人於議案指示欄勾選「反對」
  3. (C)委託書上委託人未簽名亦未蓋章
  4. (D)委託書逾規定期限始送達公司
解析

(A)錯誤，此為瑕疵。委託書用紙須由公司印發，使用自製或他人印製的用紙，應記載事項可能不全且無從編號控管，是典型的形式瑕疵。

(B)正確。勾選反對只是委託人對議案所為的具體指示，正是委託書應載明的內容。受託人依此指示投下反對票，委託書完全有效，其代理的表決權應予計算。

(C)錯誤，此為瑕疵。委託人的簽章是委託意思存在的唯一憑據，也是與留存印鑑比對的對象；欠缺簽章的委託書無從確認真偽，應予剔除。

(D)錯誤，此為瑕疵。委託書須於規定期限前送達，公司才有時間查核並編製表決權資料；逾期送達者其代理的表決權不予計算。

11. 我國股票全面無實體發行後，股務單位日常受理的過戶案件，以下列何者為主？
  1. (A)贈與、繼承、法院拍賣等非集中交易的股份移轉
  2. (B)公司辦理現金增資時對認股人的新股撥發
  3. (C)投資人於集中市場買賣成交後逐筆遞送的過戶申請
  4. (D)股東將實體股票送存集中保管的繳存申請
解析

(A)正確。無實體化之後，需要股務單位逐案審核文件的，主要是不經集中市場成交的移轉，例如贈與、繼承、法院拍賣或判決移轉，這些原因各有其應檢附的證明文件。

(B)錯誤。新股撥發是增資作業的一環，由公司依認購結果配發，並非既有股份在股東之間的移轉。
