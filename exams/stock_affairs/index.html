1. 關於股務人員之專業訓練與職業道德要求,下列敘述何者正確?
  1. (A)應持續參加專業訓練,並遵守保密、利益迴避等職業道德要求
  2. (B)專業訓練僅限新進人員參加,具年資者與主管得一律免除
  3. (C)職業道德僅拘束自辦股務者,受任的股務代理機構人員不在此限
  4. (D)取得資格後即毋須再進修,職業道德亦僅屬道德勸說而無實質效果
解析

(A)正確。股務人員長期接觸股東個資與公司尚未公開的股權變動資訊,故除須以持續訓練維持法規知識的時效性外,並須遵守保密與利益迴避;這兩項要求分別對應「作業正確」與「資訊不被濫用」兩種風險。

(B)錯誤。資深人員與主管掌握核決權限,其判斷失誤的影響更大;訓練對象不因年資而豁免。

(C)錯誤。職業道德的要求隨作業而生,不隨僱主身分而異;受任機構人員接觸的股東資料範圍甚至更廣,更需受相同拘束。

(D)錯誤。公司法、稅法與股務相關規範時有修正,不進修者容易以舊規範辦理新案件;且股務人員違反保密或利用職務所知消息交易,可能涉及行政責任甚至刑責。

2. 股務單位為股東建立印鑑卡,其主要功能為何?
  1. (A)作為核對股東各項申請文件真偽的比對基準
  2. (B)作為公司發放股利時扣繳稅款的憑單
  3. (C)作為股東繳納股款的收訖憑證
  4. (D)作為股東委託他人出席股東會的授權文件
解析

(A)正確。股務作業多以書面申請為之,股務單位無從逐案面對股東本人,故需一個事先留存、可反覆比對的樣本;印鑑卡即是此一同一性判斷的基準,印鑑變更或掛失亦須依規定核對身分後辦理,不得僅憑口頭通知。

(B)錯誤。扣繳憑單是稅務文件,由公司依所得稅法規定製發,與印鑑核對是兩套不同的作業。

(C)錯誤。股款的繳納以繳款憑證或銀行入帳紀錄為證,與印鑑卡的功能無關。

(D)錯誤。委託出席須依規定使用委託書,印鑑卡本身不具授權效力,至多用於核對委託書上的印鑑是否相符。

3. 關於公開發行公司股東會之報到作業與出席股數之計算,下列敘述何者正確?
  1. (A)應以股東會當日各股東集中保管帳戶之實際餘額,逐一重新核算並認定其出席股數
  2. (B)僅親自到場並完成報到之股東所代表股數計入,其餘一律不予計算
  3. (C)完成報到之股東,與依規定以書面或電子方式行使表決權者,其股數均計入
  4. (D)凡於會場外領取股東會紀念品者,即視為完成報到並計入出席股數
解析

(A)錯誤。出席與表決之基礎為停止過戶後確定之基準日股東名簿,而非開會當日之集保帳戶餘額,股務單位不會重新核算。

(B)錯誤。書面及電子行使表決權者依法視為親自出席,漏未加計將低估出席股數,可能使已達定額之議案被誤判為不成立。

(C)正確。出席股數係報到股東所代表股數,加計視為親自出席之書面、電子行使表決權股數,這也是主席判斷是否已達法定出席定額的基礎。

(D)錯誤。紀念品之發放屬服務性措施,與報到程序及表決權之計算無關,領取者未必已繳交出席證或簽到卡。

4. 公司依公司法規定發行員工認股權憑證予員工後,關於該憑證之處分,下列敘述何者正確?
  1. (A)得轉讓予公司之其他在職員工,對員工以外之人則不得轉讓
  2. (B)得於證券集中交易市場或櫃檯買賣中心掛牌自由買賣
  3. (C)得自由轉讓予任何第三人,惟應向公司股務單位辦理轉讓登記
  4. (D)原則上不得轉讓,但因繼承而移轉者不在此限
解析

(A)錯誤。法律並未開放員工相互間之轉讓,認股權仍限由原受配之員工行使。

(B)錯誤。員工認股權憑證不在市場掛牌流通,與公司對外發行之認購權證性質不同。

(C)錯誤。自由轉讓將使認股權淪為一般有價證券,與其人身專屬之獎酬性質不符。

(D)正確。員工認股權之目的在於留住並激勵特定員工,若得自由轉讓即失去與該員工留任及績效之連結,故法律禁止轉讓,僅就繼承此一非自願之移轉設有例外。

5. 依規定，股東出席股東會所使用的委託書用紙，其來源應為下列何者？
  1. (A)由公司印發，並隨開會通知提供股東使用
  2. (B)由主管機關統一印製後，分送各公開發行公司使用
  3. (C)由股東自行製作，只要載明授權範圍即可
  4. (D)由徵求人自行印製，並於徵求場所發給股東
解析

(A)正確。公司法與委託書規則均要求股東出具公司印發的委託書。統一印製使應記載事項齊備、格式一致並得編號控管，股務單位才能核對真偽與勾稽，也避免徵求人以自訂格式規避應記載事項。

(B)錯誤。主管機關只訂定委託書的應記載事項與使用規範，並不代各公司印製用紙；用紙須由各公司自行印發並隨開會通知寄送。

(C)錯誤。股東自製的委託書無從編號控管，也可能漏載應記載事項，屬於典型的形式瑕疵，其所代理的表決權將不予計算。

(D)錯誤。徵求人縱使徵求行為合法，仍須使用公司印發的委託書用紙。使用非公司印發的用紙，是實務上委託書遭剔除的常見事由。

6. 同一股東就同一次股東會出具兩份以上委託書，分別委託不同的人出席，原則上應如何處理？
  1. (A)以最後送達公司者為準，先前所出具的委託書一律視為已經股東撤銷
  2. (B)由公司通知該股東到場，當場由其指定其中一人代理
  3. (C)全部視為無效，該股東視同未出席亦未委託，其股數並不計入出席股數
  4. (D)以最先送達公司者為準，但股東已聲明撤銷前一委託者，不在此限
解析

(A)錯誤。這正好是規則所不採的判準。若一律以後到者為準，任何人只要在期限內再取得一張委託書，就能推翻股東先前的委託，反而助長委託書的競相蒐集。

(B)錯誤。股務作業須有可操作的一致規則，逐案通知股東到場既不可行，也把應由規則決定的事推給個案處理。

(C)錯誤。重複委託反映的是股東確有委託的意思，只是對象不明。全部否定將使股東的表決權平白喪失，與保障股東權的立場不符。

(D)正確。重複委託採「先到為準」，理由在於後到者未必是股東真意的最新表達，也可能是他人再度取得的委託書。但若股東明確聲明撤銷前一委託，其真意已無疑義，即依新的委託辦理。

7. 投資人向參加人申請結清其保管劃撥帳戶時，下列何者為必要條件？
  1. (A)須由集保結算所派員至參加人營業處所實地查核帳載後，始得辦理結清
  2. (B)該帳戶的開設須已滿一定年限，且結清前一定期間內未曾發生任何劃撥異動
  3. (C)須先取得發行人或其股務代理機構出具的同意結清證明文件
  4. (D)帳戶內有價證券餘額為零，且無設質、法院扣押等尚未解除的限制記載
解析

(A)錯誤。集保結算所對參加人有查核機制，但那是常態性的業務監督，不是個別帳戶結清的前置程序。

(B)錯誤。帳戶的結清取決於帳上是否已無餘額與限制記載，與開戶期間長短或結清前有無劃撥異動均無關。

(C)錯誤。集保帳戶是投資人與參加人之間的帳戶關係，發行人及其股務代理機構均非當事人，不會也不需要出具同意結清的文件。

(D)正確。結清的前提是帳戶已無權利義務殘留：餘額須為零，且不得存在設質登記、法院扣押或其他限制處分的記載，否則第三人的權利將因帳戶消滅而落空。

8. 停止過戶期間內，投資人申請將集中保管的股票領回實體券會受到限制，其主要理由為何？
  1. (A)因為停止過戶期間集保結算所須暫停所有帳簿劃撥與交割作業
  2. (B)因為停止過戶期間股票的所有權暫時歸屬於發行人，投資人無從請求領回
  3. (C)因為停止過戶期間發行人須全力辦理股東會事務，無多餘人力處理實體券的領回申請
  4. (D)因為領回須將股票由名義人過戶為投資人本人名義，而股東名簿此時已停止變更
解析

(A)錯誤。帳簿劃撥並未停止，買賣交割在停止過戶期間仍照常進行，正因為它不涉及股東名簿的變更。

(B)錯誤。停止過戶只是暫停名簿的變更登記，股份所有權完全不受影響，更不會移轉給發行人。

(C)錯誤。人力調度不是法制上的限制理由；作業量大並不能作為限制投資人行使權利的正當依據。

(D)正確。集中保管的股票在股東名簿上登記於集保結算所名下，投資人領回實體券後必須將名義自集保結算所變更為本人，而這正是停止過戶期間被凍結的動作。限制的根源在於股東名簿無法變更，而不在集保帳務本身。

9. 某公開發行公司之董事以其持有之公司股份設定質權，設質數量已超過其選任當時所持有公司股份數額之二分之一。依公司法，就超過部分之股份，其效果為何？
  1. (A)該董事當然解任，並同時喪失其股東身分
  2. (B)質權設定無效，股務單位應拒絕辦理設質登記
  3. (C)該部分股份之股利應予提存，俟質權塗銷後始得由出質股東領取
  4. (D)於股東會不得行使表決權，且不算入已出席股東之表決權數
解析

(A)錯誤。當然解任是「轉讓」超過選任時持股半數的效果。設質並未移轉所有權，法律的反應是限制表決權，而非剝奪董事身分，更不影響其股東地位。

(B)錯誤。設質行為本身有效，股務單位仍應依規定辦理設質登記，並配合設質資訊的申報與公告；法律限制的是表決權的行使而非質權的設定。

(C)錯誤。設質不影響股利的歸屬，股利仍屬出質股東所有；是否用以清償擔保債權，屬出質人與質權人間的約定，不生提存問題。

(D)正確。設質雖不移轉股份所有權，卻使董事的實質經濟利害隨之減損，故公司法就超過部分限制其表決權行使，並明定不算入已出席股東之表決權數，以免影響出席數與同意數的計算。

10. 公司於會計年度終了辦理盈餘分派，依公司法其正確之順序為下列何者？
  1. (A)先彌補虧損，次分派股息及紅利，法定盈餘公積得於次年度補提
  2. (B)先完納稅捐並彌補虧損，次提列法定盈餘公積，最後分派股息及紅利
  3. (C)先分派股息及紅利，次提列法定盈餘公積，最後彌補虧損
  4. (D)先提列法定盈餘公積，次分派股息及紅利，最後彌補虧損
解析

(A)錯誤。法定盈餘公積的提列是當年度分派前的強制程序，不得以次年度補提為由而先行分派股利。

(B)正確。順序反映的是保護的優先性：先確保國家稅捐與過去虧損的填補，再強制累積法定盈餘公積以厚實資本、保障債權人，剩餘者才是可分配給股東的部分。法定盈餘公積累積已達法定額度者，得不再提列。

(C)錯誤。這正好把順序倒過來。若先分派股息紅利，等於在虧損未補、公積未提的情況下先把錢發給股東，直接侵蝕債權人的擔保基礎。

(D)錯誤。彌補虧損必須在提列公積之前；虧損未補而先提公積、再分派，會使帳面盈餘的計算失真。

11. 受理股東書面申請時發現印文與原留印鑑不符，下列處理何者適當？
  1. (A)請股東出具切結書並覓另一股東具名保證，即可免除該次驗印
  2. (B)以印文大致相似為由先行受理並完成過戶，事後再通知股東補辦印鑑變更的手續
  3. (C)直接以該申請書上的新印文更新印鑑卡，再據以受理原申請
  4. (D)退件並通知股東，俟其辦理印鑑變更或依可行的替代方式驗證身分後再行申請
解析

(A)錯誤。切結書只是單方承諾，加具保證人亦無法補足身分未經驗證的缺口，冒名者同樣寫得出切結書並找得到保證人。

(B)錯誤。驗印是事前控制，先受理並完成過戶再補正，會使不符的申請已經產生效果，事後補正無從回復。

(C)錯誤。以待審文件上的印文回頭更新印鑑卡，等於讓未經驗證的印章自行取得合法地位，是印鑑作業最嚴重的內控破口。
