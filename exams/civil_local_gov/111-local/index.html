2. 依司法院大法官解釋意旨，下列何者非屬對於地方自治團體財政自主權核心領域之侵害？
  1. (A)中央代替地方自治團體編製預算
  2. (B)規定由地方自治團體負擔國防事務之經費支出
  3. (C)規定代行處理之費用由被代行處理之地方機關負擔
  4. (D)規定地方自治團體應全額補助全民健康保險被保險人之保險費
解析

(A)錯誤。由中央代為編製預算，等於剝奪地方決定歲入歲出的權能，直接侵入財政自主的核心。

(B)錯誤。國防屬中央專屬事項，其經費本應由中央負擔；令地方分擔即屬對地方財政的不當侵奪。

(C)正確。代行處理的前提是該地方機關依法應作為而不作為，中央代其完成的本是它自己的職責；費用由被代行機關負擔只是回歸原本的責任分配，不構成對財政自主核心的侵害。

(D)錯誤。要求地方「全額」負擔保險費補助，已逾越合理的協力範圍，侵蝕其財政自主。

3. 下列何者非屬實施地方自治之目的？
  1. (A)防止國家權力集中並避免濫權
  2. (B)促進水平分權
  3. (C)確保法規範因地制宜、具體落實，增進行政效率
  4. (D)促進全國各區域均衡發展
解析

(A)錯誤。使權力不集中於中央、藉分權防止濫權，正是地方自治的目的之一。

(B)正確。地方自治處理的是中央與地方之間的「垂直」分權；水平分權指的是同一層級內行政、立法、司法等權力的分立，不是地方自治所欲達成的目的。

(C)錯誤。讓法規範能因地制宜、貼近在地需求並提高效率，是地方自治的重要功能。

(D)錯誤。促進各區域均衡發展，是實施地方自治的目的之一。

4. 依司法院大法官解釋，關於中央與地方權限劃分之均權原則，下列敘述何者正確？
  1. (A)均權原則僅適用於憲法未列舉事項
  2. (B)均權原則僅適用於立法院制定法律時
  3. (C)地方制度法已明確列舉地方自治團體之自治事項，故無適用均權原則而為判斷之空間
  4. (D)地方就自治事項制定自治法規，具體分工如有不明時，應本於均權原則而為判斷
解析

(A)錯誤。均權原則是權限劃分的一般判準，不以憲法未列舉事項為限。

(B)錯誤。均權原則不僅拘束立法者，行政與司法在判斷權限歸屬時同樣應予斟酌。

(C)錯誤。地方制度法的列舉不可能窮盡一切事務，遇有列舉未及或性質交錯者，仍須回到均權原則判斷。

(D)正確。事務究應由中央或地方處理，依其性質而定——有全國一致之性質者屬中央，因地制宜者屬地方；具體分工不明時，即應本於此一均權原則加以判斷。
