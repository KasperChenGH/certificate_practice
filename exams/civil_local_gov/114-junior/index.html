1. 有關地方自治團體法定地位或組織之意涵，下列何者錯誤？
  1. (A)地方自治團體公務人員由中央政府直接任命
  2. (B)地方自治團體掌理事項包括自治事項及委辦事項
  3. (C)地方自治團體具有公法人資格
  4. (D)地方自治團體是基於因地制宜的需要而發展出來的組織
解析

(A)正確。地方自治團體享有人事自主權，其公務人員由地方行政首長依法任免；若由中央直接任命，自治將形同虛設。此為錯誤敘述。

(B)錯誤。本題要選敘述錯誤者。地方自治團體同時掌理自治事項與上級交付的委辦事項。

(C)錯誤。本題要選敘述錯誤者。地方自治團體具公法人資格。

(D)錯誤。本題要選敘述錯誤者。地方自治正是基於因地制宜的需要而生。

2. 有關我國地方自治的敘述，下列何者錯誤？
  1. (A)地方立法機關得透過決議拒絕委辦事項
  2. (B)地方自治團體是地域團體公法人

(C)錯誤。本題要選敘述錯誤者。縣自治為憲法所保障的制度。

(D)錯誤。本題要選敘述錯誤者。地方自治的核心內涵包含團體自治與住民自治兩個面向。

3. 地方自治團體從事下列自治作為時，何者須經上級政府或主管機關核定？
  1. (A)縣（市）長任命副縣（市）長
  2. (B)鄉（鎮、市）或村（里）名稱變更

(C)錯誤。自律規則由地方立法機關發布，報上級政府備查。

(D)錯誤。未定有罰則的自治條例，公布後報備查即可；須核定的是定有罰則者。

4. 有關直轄市自治規則之敘述，下列何者正確？
  1. (A)自治規則發布後，除應送行政院備查外，亦應函送直轄市議會查照
  2. (B)除得規範直轄市之自治事項外，亦得規範委辦事項
  3. (C)得使用「要點」作為其名稱
  4. (D)僅得基於法律、法律授權之法規、自治條例之授權訂定
解析

(A)正確。自治規則除法律或自治條例另有規定外，應於發布後函報有關機關備查，並函送各該地方立法機關查照——備查與查照並行，前者對上、後者對議會。

(B)錯誤。規範委辦事項的是委辦規則；自治規則只處理自治事項。

(C)錯誤。自治規則的名稱限於規程、規則、細則、辦法、綱要、標準、準則七種，不包括「要點」。

(D)錯誤。自治規則得「依其法定職權」訂定，不以取得授權為必要。

5. 依司法院大法官解釋意旨，關於地方自治之敘述，下列何者正確？
  1. (A)基於共和國之理念與水平分權之功能，地方自治團體設有地方行政與立法機關之自治組織
  2. (B)依據憲法關於中央與地方權限劃分之規定，地方自治團體在特定事務之執行上乃獨立於中央而與之分權相抗
  3. (C)凡憲法上之各級地域團體享有就所有事項制定規章並執行之權，且具有自主組織權限者，方得為地方自治團體性質之公法人
  4. (D)地方自治團體為與中央政府共享統治權行使之主體，其與中央之關係為共同協力關係
解析

(A)錯誤。地方自治處理的是中央與地方之間的垂直分權，不是水平分權。

(B)錯誤。中央與地方並非分權相抗的對立關係，大法官強調的是彼此協力。

(C)錯誤。地方自治團體並非就「所有事項」都有制定規章並執行之權，其權限仍以憲法及法律劃定的範圍為限。

(D)正確。大法官指出地方自治團體是與中央共享統治權行使的主體，兩者在諸如社會福利等事務上互負協力義務，而非上下對立。

6. 若縣政府發現所轄鄉公所可能有依法應作為而不作為之情事，導致民眾權益受到嚴重影響，該縣政府決定代行處理，依地方制度法規定，下列敘述何者正確？
  1. (A)縣政府需命鄉公所於一定期限內為之，逾期仍不作為者，才能代行處理
  2. (B)縣政府應請內政部函知鄉公所此項處分決定
  3. (C)鄉公所若認為代行處理有違法之嫌，可提出行政救濟
  4. (D)代行處理所產生之費用，由兩機關共同分攤
解析

(A)錯誤。原則上固應先命其於一定期限內為之，但「情況急迫」時得逕予代行處理；此項未顧及該例外，過於絕對。

(B)錯誤。代行處理由縣政府自行為之並通知鄉公所，無須透過內政部函知。

(C)正確。代行處理是對地方自治團體發生法律效果的處分；鄉公所如認其違法，得依行政救濟程序爭訟，這是自治權受侵害時的保障。

(D)錯誤。代行處理的費用由被代行處理的機關全額負擔，不由兩機關分攤。

7. 有關地方民意代表享有不受逮捕權的敘述，下列何者錯誤？
  1. (A)其立法目的在防止司法權或行政權妨害議員之身體自由，阻礙地方立法機關功能之發揮
  2. (B)此項保障隨議員身分的喪失而消滅
  3. (C)地方民意代表如屬現行犯則不適用
  4. (D)地方民意代表在任期中任何時間皆享有
解析

(A)錯誤。本題要選敘述錯誤者。防止其他權力藉拘捕妨礙議會職權行使，正是此項保障的立法目的。

(B)錯誤。本題要選敘述錯誤者。保障附隨於代表身分，身分喪失即隨之消滅。

(C)錯誤。本題要選敘述錯誤者。現行犯不在保障之列。

(D)正確。不受逮捕的保障限於「會期內」，目的在確保代表能出席會議行使職權；任期中的非會期期間並不受此保障。此為錯誤敘述。
