1. 依地方制度法規定，下列何者非屬縣（市）自治事項？
  1. (A)縣（市）都市計畫之核定
  2. (B)縣（市）災害防救之規劃
  3. (C)縣（市）水資源基本資料調查
  4. (D)縣（市）勞資關係
解析

(A)正確。地方制度法列為縣（市）自治事項的是都市計畫之「擬定、審議及執行」；核定權保留給中央主管機關，作為對地方計畫的合法性監督。

(B)錯誤。縣（市）災害防救之規劃及執行，明列為自治事項。

(C)錯誤。縣（市）水資源基本資料調查，明列為自治事項。

(D)錯誤。縣（市）勞資關係事項，明列為自治事項。

2. 依地方制度法規定，下列何者非屬地方自治團體處理跨區域自治事務之方式？
  1. (A)與其他地方自治團體成立區域合作組織
  2. (B)與其他地方自治團體訂定協議
  3. (C)與其他地方自治團體訂定行政契約
  4. (D)與其他地方自治團體共同委託上級業務主管機關統籌辦理
解析

(A)錯誤。成立區域合作組織是法定的跨區域合作方式之一。

(B)錯誤。訂定協議是法定方式之一。

(C)錯誤。訂定行政契約是法定方式之一。

(D)正確。跨區域合作的設計是地方之間的「橫向」協力；把事務共同上交由上級機關統籌辦理，等於回到由上而下的垂直管轄，不是法律所定的跨區域合作方式。

4. 關於直轄市議會之敘述，下列何者錯誤？
  1. (A)直轄市議會，除每屆成立大會外，定期會每6 個月開會1 次，由議長、主席召集之
  2. (B)副議長、副主席不依法召集時，由三分之一以上議員互推一人召集之
  3. (C)每年審議總預算之定期會，會期屆滿而議案尚未議畢或有其他必要時，得應直轄市長之要求，提經大會決議延長會期
  4. (D)直轄市議會延長之會期不得超過10 日，並不得作為質詢之用
解析

(A)錯誤。本題要選敘述錯誤者。定期會每六個月開會一次，由議長、主席召集。

5. 依地方制度法規定，下列何者非屬地方財政收入？
  1. (A)所得稅收入
  2. (B)工程受益費收入
  3. (C)罰款收入
  4. (D)規費收入
解析

(C)錯誤。罰款（罰鍰）收入屬地方財政收入之一。

(D)錯誤。規費是地方提供服務所收取的對價，屬地方財政收入。

7. 某縣政府擬就公共造產公有零售市場攤位之使用管理事項制定自治條例，下列敘述何者錯誤？
  1. (A)可基於自治條例之授權，就零售市場攤位之使用時間及應遵守事項，訂定自治規則
  2. (B)零售市場攤位申請資格及收費標準，應以自治條例定之
  3. (C)對於違反規定者，採取斷水斷電措施，應以自治條例定之
  4. (D)對於違反規定者，裁處新臺幣500 元至3000 元罰鍰，並得為連續處罰，應以自治條例定之
解析

(A)錯誤。本題要選敘述錯誤者。基於自治條例的授權訂定自治規則，補充執行細節，於法有據。

(B)錯誤。本題要選敘述錯誤者。申請資格與收費標準涉及居民權利義務，應以自治條例定之。

(C)正確。斷絕水電是行政執行法所定的直接強制方法，應依該法的程序為之，不是自治條例得自行創設的行政罰種類。此為錯誤敘述。

(D)錯誤。本題要選敘述錯誤者。罰鍰及連續處罰應以自治條例定之，且金額在法定的十萬元上限之內。

9. 有關直轄市議員言論及表決免責權之敘述，下列何者錯誤？
  1. (A)憲法未明定直轄市議員之言論及表決免責權
  2. (B)直轄市議員只要是在議場內所為之言論及表決，均無法律責任可言
  3. (C)直轄市議員就有關會議事項所為之言論及表決，對外不負責任
  4. (D)依司法院大法官解釋意旨，地方民意代表之言論及表決免責權，亦受保障
解析

(A)錯誤。本題要選敘述錯誤者。憲法就地方民意代表的免責權並無明文，其保障來自地方制度法與大法官解釋。

(B)正確。免責權保障的是「就有關會議事項」所為的言論及表決；與會議無關的言論（如藉機辱罵他人）縱在議場內為之，仍不受保障。此項以場所取代事項的判準，為錯誤敘述。

(C)錯誤。本題要選敘述錯誤者。就有關會議事項所為的言論及表決，對外不負責任。

(D)錯誤。本題要選敘述錯誤者。大法官解釋肯認地方民意代表亦享有言論免責的保障。

10. 關於地方財政支出之敘述，下列何者錯誤？
  1. (A)各級政府之一切支出，非經預算程序不得為之
  2. (B)中央不得將應自行負擔之經費，轉嫁予地方自治團體
  3. (C)中央使地方負擔經費，除不得侵害其財政自主權核心領域外，必須依法律或有法律明確授權之法規命令，始得為之
  4. (D)代行處理所支出之費用，應由代行處理之機關負擔
解析

(A)錯誤。本題要選敘述錯誤者。各級政府的一切支出非經預算程序不得為之。

(B)錯誤。本題要選敘述錯誤者。中央不得將應自行負擔的經費轉嫁給地方。

(C)錯誤。本題要選敘述錯誤者。使地方負擔經費須有法律或法律明確授權的依據，且不得侵害其財政自主核心。

(D)正確。代行處理費用應由「被代行處理」的機關負擔——因為它本來就該做而未做；由代行的上級機關自行吸收，等於獎勵地方怠惰。此項把負擔者寫反，為錯誤敘述。

11. 有關地方自治團體法定地位或組織之意涵，下列何者錯誤？
  1. (A)地方自治團體公務人員由中央政府直接任命
  2. (B)地方自治團體掌理事項包括自治事項及委辦事項
  3. (C)地方自治團體具有公法人資格
  4. (D)地方自治團體是基於因地制宜的需要而發展出來的組織
解析

(A)正確。地方自治團體享有人事自主權，其公務人員由地方行政首長依法任免；若由中央直接任命，自治將形同虛設。此為錯誤敘述。

(B)錯誤。本題要選敘述錯誤者。地方自治團體同時掌理自治事項與上級交付的委辦事項。

(C)錯誤。本題要選敘述錯誤者。地方自治團體具公法人資格。

(D)錯誤。本題要選敘述錯誤者。地方自治正是基於因地制宜的需要而生。

13. 依地方制度法規定，下列關於直轄市議會議長罷免案之敘述，何者正確？
  1. (A)議員經連署達到法定標準後，即可成案逕行表決
  2. (B)議員提案應附加直轄市百分之一以上市民連署提出
  3. (C)應由議員總額三分之一以上之簽署，始得提案
  4. (D)行政院對於罷免案僅得行使備查權
解析

(A)錯誤。連署只是提案要件，成案後仍須依法定程序召集會議並表決，不能逕行表決。

(B)錯誤。議長由議員互選產生，其罷免由議員提出，與市民連署無關。

(C)正確。議長、副議長的罷免案應敘述理由，並有議員總額三分之一以上之簽署，才能提出。

(D)錯誤。直轄市議會議長的罷免案應向行政院提出，行政院並負責召集罷免投票會議，不僅是備查。

14. 下列地方行政機關與地方立法機關關係之敘述，何者錯誤？
  1. (A)鄉（鎮、市）民代表會小組開會時，對特定事項有明瞭必要者，亦可邀請各該鄉（鎮、市）公所長以外有關業務機關首長或單位主管列席說明
  2. (B)基於住民自治，縣（市）長不得以府會衝突而拒絕向縣（市）議會進行施政報告
  3. (C)直轄市議會定期會開會時，市長施政報告及市政府各一級單位主管及所屬機關首長就主管業務之報告，均是向該地方自治團體人民直接負責之表現
  4. (D)基於議會自律，縣（市）議會得以府會衝突為由，拒絕該縣（市）長進行施政報告

(C)錯誤。本題要選敘述錯誤者。向議會提出施政與業務報告，實質上即是向該地方自治團體人民負責的表現。

15. 依地方制度法與財政收支劃分法的規定，鄉鎮市公所能課徵的地方稅只有：
  1. (A)地價稅
  2. (B)土地增值稅
  3. (C)契稅
  4. (D)臨時稅課
