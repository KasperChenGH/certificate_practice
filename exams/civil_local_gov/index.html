1. 依地方制度法規定，我國地方劃分之最小編組為何？
  1. (A)區
  2. (B)村
  3. (C)鄰
  4. (D)里
解析

(A)錯誤。區是直轄市或市之下的行政區劃，並非最小編組。

(B)錯誤。村是鄉之下的編組，其下還有鄰。

(C)正確。地方制度法規定村、里之下編組為鄰，鄰是我國地方劃分中最小的編組單位。

(D)錯誤。里是鎮、市、區之下的編組，其下同樣還有鄰。

2. 關於自治條例之制定，下列敘述何者錯誤？
  1. (A)新北市議會得制定自治條例，新北市板橋區不得制定自治條例
  2. (B)花蓮縣議會得制定自治條例，花蓮縣花蓮市民代表會亦得制定自治條例
  3. (C)高雄市議會得制定自治條例，高雄市茂林區民代表會亦得制定自治條例
  4. (D)澎湖縣議會得制定自治條例，澎湖縣望安鄉民代表會不得制定自治條例
解析

(A)錯誤。本題要選敘述錯誤者。板橋區是直轄市之下的一般區，不是地方自治團體，無立法機關。

(B)錯誤。本題要選敘述錯誤者。花蓮市是縣轄市，屬地方自治團體，其市民代表會得制定自治條例。

(C)錯誤。本題要選敘述錯誤者。茂林區是直轄市山地原住民區，依法為地方自治團體，其區民代表會得制定自治條例。

(D)正確。望安鄉是鄉，屬鄉（鎮、市）層級的地方自治團體，其鄉民代表會當然得制定自治條例（即鄉規約）。此項稱其不得制定，為錯誤敘述。

3. 關於地方公共設施之敘述，下列何者錯誤？
  1. (A)地方居民對於地方公共設施有使用之權
  2. (B)除法令有特別規定外，地方居民無請求地方自治團體設置特定公共設施之權利
  3. (C)地方自治團體得以公法或私法之形式提供公共設施
  4. (D)地方政府提供之公共設施不得向居民收取費用
解析

(A)錯誤。本題要選敘述錯誤者。居民對地方公共設施有依法使用的權利。

(B)錯誤。本題要選敘述錯誤者。除法令有特別規定外，居民並無請求設置特定公共設施的主觀公權利。

(C)錯誤。本題要選敘述錯誤者。地方自治團體得選擇以公法或私法的形式提供公共設施。

(D)正確。使用公共設施得依法徵收使用規費，例如停車費、場館使用費；並非一律不得收費。此為錯誤敘述。

4. 依地方行政機關組織準則之規定，下列何者非直轄市政府所屬一級機關之名稱？
  1. (A)局
  2. (B)處
  3. (C)中心
  4. (D)委員會
解析

(A)錯誤。局是直轄市政府所屬一級機關的法定名稱之一。

(B)錯誤。處是一級機關或一級單位得用的名稱。

(C)正確。地方行政機關組織準則所定的一級機關名稱為局、處、委員會；「中心」屬三級機關或所屬機構的名稱，不是一級機關。

(D)錯誤。委員會是一級機關的法定名稱之一。

5. 依地方制度法規定，下列何者非屬地方財政收入？
  1. (A)所得稅收入
  2. (B)工程受益費收入
  3. (C)罰款收入
  4. (D)規費收入
解析

(A)正確。所得稅屬國稅，是中央的財政收入；地方雖可能經由統籌分配獲得部分財源，但該稅本身不是地方稅收。

(B)錯誤。工程受益費由地方向因公共工程而受益者徵收，屬地方財政收入。

(C)錯誤。罰款（罰鍰）收入屬地方財政收入之一。

(D)錯誤。規費是地方提供服務所收取的對價，屬地方財政收入。

6. 依地方制度法，關於不同層級或內涵之地方自治體系敘述，下列何者正確？
  1. (A)臺南市將軍區與嘉義縣布袋鎮以內之編組分別稱作里與村
  2. (B)臺中市和平區與臺中市之關係，準用地方制度法關於縣（市）與直轄市關係之規定
  3. (C)高雄市那瑪夏區與高雄市之關係，準用地方制度法關於鄉（鎮、市）與縣關係之規定
  4. (D)臺北市與屏東市均再劃分為區
解析

(A)錯誤。鄉以內的編組才稱村；鎮、縣轄市及區以內的編組都稱里，故將軍區與布袋鎮都是「里」。

(B)錯誤。和平區是直轄市山地原住民區，其與直轄市的關係準用「鄉（鎮、市）與縣」的規定。

(C)正確。由山地鄉改制的直轄市山地原住民區為地方自治團體，其與直轄市的關係，準用地方制度法關於鄉（鎮、市）與縣關係的規定。

(D)錯誤。劃分為區的是直轄市與市；屏東市是縣轄市，其下的編組為里。

7. 關於委辦規則之敘述，下列何者錯誤？
  1. (A)鄉公所不得訂定委辦規則
  2. (B)委辦規則應函報委辦機關核定後發布
  3. (C)委辦規則得定名為規程
  4. (D)委辦規則得定名為綱要
解析

(A)正確。直轄市政府、縣（市）政府與鄉（鎮、市）公所，都得為辦理上級委辦事項而訂定委辦規則；鄉公所並不被排除。此為錯誤敘述。

(B)錯誤。本題要選敘述錯誤者。委辦規則應函報委辦機關核定後發布。

(C)錯誤。本題要選敘述錯誤者。委辦規則的名稱準用自治規則，得定名為規程。

(D)錯誤。本題要選敘述錯誤者。綱要同為得用的名稱之一。

8. 有關山地鄉鄉長之敘述，下列何者正確？
  1. (A)山地鄉鄉長由鄉內原住民選舉產生，每屆任期4 年
  2. (B)山地鄉鄉長得由不具山地原住民身分者擔任
  3. (C)山地鄉鄉長辭職、去職或死亡者，由縣政府派員代理，代理人應具山地原住民身分
  4. (D)山地鄉鄉長辭職、去職或死亡者，不論所遺任期長短，皆由代理人代理至該屆任期屆滿為止
解析

(A)錯誤。投票的是全體鄉民，不限原住民；法律限制的是「候選人」須具山地原住民身分。

(B)錯誤。山地鄉鄉長以山地原住民為限，這是為保障原住民族自治所設的積極要件。

(C)正確。山地鄉鄉長出缺時由縣政府派員代理，且代理人同樣應具山地原住民身分——否則以派代方式即可架空前述的身分保障。

(D)錯誤。所遺任期不足二年者才由代理人代理至任期屆滿；逾二年者仍應辦理補選。

9. 關於地方議會正副議長選舉罷免之敘述，下列何者錯誤？
  1. (A)正副議長之選舉採記名投票，並不違反憲法保障秘密投票規定
  2. (B)正副議長選舉及罷免之投票方式，事涉議員行使投票之法定職權，為議會自律事項，可由議會以自律規則定之
  3. (C)縣（市）議會正副議長之罷免應採取記名投票方式為之
  4. (D)鄉（鎮、市）代表會正副主席之罷免，縣政府應於收到罷免案25 日內，召集罷免投票會議，由出席代表就同意罷免或不同意罷免，以記名投票表決之
解析

(A)錯誤。本題要選敘述錯誤者。大法官認為正副議長選舉採記名投票，並未違反憲法對秘密投票的保障。

(B)正確。正副議長選舉罷免的投票方式涉及議員如何行使其法定職權，並非純粹的議會內部自律事項，須由中央以法律或法律授權的法規規定，不能由議會逕以自律規則定之。此為錯誤敘述。

(C)錯誤。本題要選敘述錯誤者。縣（市）議會正副議長的罷免應採記名投票。

(D)錯誤。本題要選敘述錯誤者。鄉（鎮、市）民代表會正副主席的罷免，由縣政府於法定期間內召集罷免投票會議，以記名投票表決。

10. 關於地方財政支出之敘述，下列何者錯誤？
  1. (A)各級政府之一切支出，非經預算程序不得為之
  2. (B)中央不得將應自行負擔之經費，轉嫁予地方自治團體
  3. (C)中央使地方負擔經費，除不得侵害其財政自主權核心領域外，必須依法律或有法律明確授權之法規命令，始得為之
  4. (D)代行處理所支出之費用，應由代行處理之機關負擔
解析

(A)錯誤。本題要選敘述錯誤者。各級政府的一切支出非經預算程序不得為之。

(B)錯誤。本題要選敘述錯誤者。中央不得將應自行負擔的經費轉嫁給地方。

(C)錯誤。本題要選敘述錯誤者。使地方負擔經費須有法律或法律明確授權的依據，且不得侵害其財政自主核心。

(D)正確。代行處理費用應由「被代行處理」的機關負擔——因為它本來就該做而未做；由代行的上級機關自行吸收，等於獎勵地方怠惰。此項把負擔者寫反，為錯誤敘述。

11. 若縣政府發現所轄鄉公所可能有依法應作為而不作為之情事，導致民眾權益受到嚴重影響，該縣政府決定代行處理，依地方制度法規定，下列敘述何者正確？
  1. (A)縣政府需命鄉公所於一定期限內為之，逾期仍不作為者，才能代行處理
  2. (B)縣政府應請內政部函知鄉公所此項處分決定
  3. (C)鄉公所若認為代行處理有違法之嫌，可提出行政救濟
  4. (D)代行處理所產生之費用，由兩機關共同分攤
解析

(A)錯誤。原則上固應先命其於一定期限內為之，但「情況急迫」時得逕予代行處理；此項未顧及該例外，過於絕對。

(B)錯誤。代行處理由縣政府自行為之並通知鄉公所，無須透過內政部函知。

(C)正確。代行處理是對地方自治團體發生法律效果的處分；鄉公所如認其違法，得依行政救濟程序爭訟，這是自治權受侵害時的保障。

(D)錯誤。代行處理的費用由被代行處理的機關全額負擔，不由兩機關分攤。

12. 依地方制度法規定，地方行政機關就其自治事項訂定自治規則之依據，不包括下列何者？
  1. (A)基於自治條例之授權
  2. (B)基於憲法規定
  3. (C)依法定職權
  4. (D)基於法律所授權法規之授權
解析

(A)錯誤。基於自治條例的授權訂定自治規則，是法定依據之一。

(B)正確。條文所列的依據是「依其法定職權」或「基於法律、自治條例之授權」；憲法只是整個規範秩序的上位依據，不是自治規則的直接授權來源。

(C)錯誤。依法定職權訂定，是法定依據之一。

(D)錯誤。基於法律所授權法規的授權訂定，是法定依據之一。

13. 對於地方民選公職人員所提之罷免案，投票結果滿足下列何種條件時，罷免案即為通過？
  1. (A)有效同意票數多於不同意票數
  2. (B)參與投票之人數達原選區選舉人總數四分之一以上，且有效同意票數多於不同意票數
  3. (C)有效同意票數多於不同意票數，且同意票數達原選舉區選舉人總數四分之一以上
  4. (D)有效同意票數多於不同意票數，且同意票數達原選舉區選舉人總數三分之一以上
解析

(A)錯誤。僅比較同意與不同意票數，將使極低投票率下的少數意見即可罷免民選公職。

(B)錯誤。門檻計算的是「同意票數」占選舉人總數的比例，不是投票人數的比例。

(C)正確。罷免通過須同時具備兩項要件：有效同意票多於不同意票，且同意票數達原選舉區選舉人總數四分之一以上。

(D)錯誤。門檻是四分之一，不是三分之一。

14. 下列何者非屬直轄市議會得召集臨時會之情事？
  1. (A)直轄市市長之請求
  2. (B)內政部之請求
  3. (C)議員三分之一以上之請求
  4. (D)直轄市政府移送之覆議案，待直轄市議會於法定期間內作成決議
解析

(A)錯誤。直轄市長得請求召集臨時會。

(B)正確。得請求召集臨時會者限於地方行政首長、議長及一定人數的議員，另加覆議案的法定情形；內政部是監督機關，不得介入議會何時開會，否則侵害議會自律。

(C)錯誤。議員三分之一以上得請求召集臨時會。

(D)錯誤。覆議案於休會期間移送者，應召集臨時會處理，屬法定情形。

17. 有關自治條例之敘述，下列何者錯誤？
  1. (A)直轄市、縣（市）、鄉（鎮、市）所制定之自治規則，其罰鍰最高以新臺幣10 萬元為限，並得規定連續處罰之
  2. (B)自治條例經各該地方立法機關議決後，如定有罰則時，應分別報經行政院、中央各該主管機關核定後始得發布
  3. (C)鄉（鎮、市）之自治條例發布後，應報請縣政府備查
  4. (D)縣（市）之自治條例經各該地方立法機關議決後，如未定有罰則時，應於公布後報請中央各該主管機關備查
解析

(A)正確。得規定罰鍰的是「自治條例」而非自治規則——罰則涉及人民權利義務，須經地方立法機關議決。此項把主體寫成自治規則，為錯誤敘述。

(B)錯誤。本題要選敘述錯誤者。定有罰則的自治條例應分別報經行政院或中央各該主管機關核定後發布。

(C)錯誤。本題要選敘述錯誤者。鄉（鎮、市）規約發布後應報縣政府備查。

(D)錯誤。本題要選敘述錯誤者。未定罰則的縣（市）規章，公布後報中央各該主管機關備查。

(C)錯誤。貨物稅已依財政收支劃分法設有分配予地方的機制，不在得附加徵收之列。

(D)錯誤。加值型營業稅同樣已有分配機制，不得由地方再行附加徵收。
