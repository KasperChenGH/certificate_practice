1. 有關金融業於「防制洗錢」裡所扮演之角色，下列敘述何者正確？
  1. (A)洗錢者將犯罪所得滲入全球金融體系之管道多元，故金融機構並非為重要之角色
  2. (B)提供防制洗錢之員工訓練，由低度防護措施國家之金融機構為之即可
  3. (C)因金融機構職員，較有可能透過當面接觸客戶獲取最新資訊並進行審查，此亦為金融機構成為防制洗錢重要角色原因之一
  4. (D)金融機構制定洗錢與資恐相關之政策及內控程序，係為避免受金融監理機構處以罰鍰，故無需了解洗錢及資恐相關風險
解析

(A)錯誤。滲入管道多元，正說明資金終究要經過金融體系，反而更凸顯金融機構作為守門人的重要性。

(B)錯誤。員工訓練應由各金融機構自行落實；低度防護措施國家的機構本身防制能力最弱，不能作為訓練的提供者。

(C)正確。第一線人員能當面接觸客戶、取得最新資料並即時察覺異常，這種資訊優勢是自動化系統難以取代的，也是金融機構在防制洗錢體系中被賦予守門人角色的主要理由。

(D)錯誤。制定政策與內控的目的在真正辨識並降低洗錢與資恐風險；只為規避罰鍰而流於形式，正是主管機關認定內控失效的典型情形。

2. 選出防制洗錢金融行動工作組織40 項建議中，關於執法部分正確的敘述為：
  1. (A)金融情報中心負責可疑交易報告的接收與分析，及沒收不法所得
  2. (B)執法與調查機關應有搜索、扣押的強制處分權
  3. (C)基於兩公約對人權保障，主管機關在進行調查時不應進入被調查者電腦系統
  4. (D)在清查自然人或法人帳戶時，因涉及財產隱私權、個人資料保護須事先取得當事人同意
解析

(A)錯誤。金融情報中心負責可疑交易報告的接收、分析與轉送，沒收不法所得屬檢察與司法機關的職權。

(B)正確。FATF 要求執法與調查機關具備搜索、扣押、取得證據及強制取證的權限；缺少強制處分權，追查與沒收犯罪所得便無法落實。

(C)錯誤。FATF 明確要求調查機關能取得電腦系統內的資料，人權保障是以正當法律程序節制，而非全面禁止取證。

(D)錯誤。清查帳戶若須事先取得當事人同意，形同事前通報，將使調查完全失效。

3. 有關於防制洗錢金融行動工作組織(Financial Action Task Force，簡稱FATF)所公布之「40 項建議」(40Recommendations) 中通匯銀行之相關規範，下列敘述何者錯誤？
  1. (A)金融機構對通匯銀行亦應踐履客戶盡職審查義務
  2. (B)金融機構應取得高階主管許可後，始建立新的通匯關係
  3. (C)金融機構對於「過渡帳戶(payable-through accounts)」需確認所往來之通匯銀行已確實執行客戶審查措施
  4. (D)各國應要求通匯往來銀行在該國取得執照或完成註冊登記
解析

(A)錯誤。此敘述正確，通匯關係中的往來銀行本身即為客戶，金融機構應對其踐履客戶盡職審查，蒐集其業務性質、聲譽及受監理情形。

(B)錯誤。此敘述正確，建立新的通匯關係前應取得高階主管許可，以確保風險由適當層級承擔。

(C)錯誤。此敘述正確，對過渡帳戶（payable-through accounts）應確認該通匯銀行已對可直接使用該帳戶的客戶執行客戶審查，並能於必要時提供相關資料。

(D)正確（即敘述有誤者）。FATF 對通匯業務的要求，是禁止與空殼銀行建立或維持通匯關係、並確認往來銀行未讓空殼銀行使用其帳戶；並非要求通匯往來銀行必須在對方國家取得執照或辦理註冊登記。

5. 金融機構對於恐怖分子應如何執行目標性金融制裁？
  1. (A)對於依法指定制裁之個人之金融帳戶、通貨或其他支付工具，向法院聲請止付
  2. (B)對於依法指定制裁之個人之金融帳戶禁止提款、匯款、轉帳，但允許其清償貸款
  3. (C)對於依法指定制裁之個人禁止任何財產或財產上利益之提供
  4. (D)對於依法指定制裁之個人實施強化審查，並申報其交易，由法務部調查局凍結其交易
解析

(A)錯誤。目標性金融制裁是依法直接發生效力的禁令，不以向法院聲請止付為要件，否則將延誤時效。

(B)錯誤。制裁效果為全面禁止提供財產上利益，不得以清償貸款為由放行資金。

(C)正確。對經依法指定制裁之個人、法人或團體，禁止提供任何財物或財產上利益。「目標性」指的是精準鎖定特定對象並凍結其全部資產與金融服務，而非只限制某幾類交易。

(D)錯誤。制裁的效果是禁止提供財產利益，不能以強化審查加申報替代；凍結效力依法發生，並非由調查局個案凍結。

(C)錯誤。自動化交易監控系統的警示功能本即為發現可疑或異常交易的主要工具，敘述無誤。

(D)錯誤。SWIFT可迅速且大量跨境移轉資金，確為洗錢者利用的管道，敘述無誤。

8. 客戶為國內外重要政治性職務人士(PEPs)時，下列敘述何者正確？

(B)正確。現任國外政府之PEPs應直接視為高風險客戶，並採強化審查。因外國官員的不法所得多需跨境移轉，我國機構難以查證其財富來源，故從嚴一律認定。

(C)錯誤。國內PEPs不採一律高風險，而是依個案風險評估決定等級。

(D)錯誤。國際組織之現任PEPs同樣採風險基礎方法判斷，並非唯一須直接視為高風險者。

12. 對於政治人物之防制洗錢應如何執行？
  1. (A)建立名單檢核政策及程序，於執行所有交易時，申報可疑交易
  2. (B)以風險為基礎，對高知名度政治人物之客戶或受益人與其家庭成員及有密切關係之人執行加強客戶審查程序
  3. (C)對國外政客或受益人與其家庭成員及有密切關係之人加強客戶審查程序；國內政客則以業務關係之長短評估是否取得高階管理層之同意
  4. (D)以風險為基礎，對高知名度政客加強客戶審查，對於政客之受益人與其家庭成員及有密切關係者，則視負面新聞之有無評估是否強化審查
解析

(A)錯誤。名單檢核只是工具，不能對所有交易一律申報可疑交易；應依風險程度決定審查強度。

(B)正確。對重要政治性職務人士本人、其家庭成員及有密切關係之人，均應以風險為基礎執行強化審查。範圍及於親屬與密切關係人，是因為其貪腐所得常透過這些人的帳戶持有與移轉。

(C)錯誤。國內政治人物不能僅以業務關係長短判斷，仍應依風險高低決定是否採取強化措施。

(D)錯誤。家庭成員與密切關係人的風險是隨本人身分而來，不能僅以有無負面新聞決定是否強化審查。
