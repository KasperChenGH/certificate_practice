1. 有關金融業於「防制洗錢」裡所扮演之角色，下列敘述何者正確？
  1. (A)洗錢者將犯罪所得滲入全球金融體系之管道多元，故金融機構並非為重要之角色
  2. (B)提供防制洗錢之員工訓練，由低度防護措施國家之金融機構為之即可
  3. (C)因金融機構職員，較有可能透過當面接觸客戶獲取最新資訊並進行審查，此亦為金融機構成為防制洗錢重要角色原因之一
  4. (D)金融機構制定洗錢與資恐相關之政策及內控程序，係為避免受金融監理機構處以罰鍰，故無需了解洗錢及資恐相關風險
解析

(A)錯誤。滲入管道多元，正說明資金終究要經過金融體系，反而更凸顯金融機構作為守門人的重要性。

(B)錯誤。員工訓練應由各金融機構自行落實；低度防護措施國家的機構本身防制能力最弱，不能作為訓練的提供者。

(C)正確。第一線人員能當面接觸客戶、取得最新資料並即時察覺異常，這種資訊優勢是自動化系統難以取代的，也是金融機構在防制洗錢體系中被賦予守門人角色的主要理由。

(D)錯誤。制定政策與內控的目的在真正辨識並降低洗錢與資恐風險；只為規避罰鍰而流於形式，正是主管機關認定內控失效的典型情形。

2. 依洗錢防制法第12 條第1 項規定，旅客或隨交通工具服務之人員出入境攜帶一定金額以上，應向海關申報；海關受理申報後，應向法務部調查局通報。此項管制稱為下列何者？
  1. (A)擴大沒收制度
  2. (B)通貨交易管制
  3. (C)確認客戶身分管制
  4. (D)強化邊境金流管制
解析

(A)錯誤。擴大沒收是針對犯罪所得及其孳息的沒收制度，與旅客攜帶現鈔出入境申報無關。

(B)錯誤。通貨交易管制指金融機構對達一定金額現金交易的申報，發生在金融體系內，不是海關申報。

(C)錯誤。確認客戶身分是金融機構對客戶履行的 KYC 義務，與海關受理申報無涉。

(D)正確。旅客攜帶現鈔或有價證券出入境的申報與通報，屬邊境金流管制。其用意在堵住繞過金融體系、直接以人身搬運現金跨境的洗錢缺口，因此才由海關把關並通報調查局。

3. 有關防制洗錢及打擊資恐的保密規定，下列敘述何者錯誤？
  1. (A)疑似洗錢或資恐交易申報事項有關之文書，均應以機密文件處理
  2. (B)稽核單位人員為執行業務需要，應得即時取得客戶資料與交易紀錄，惟仍應遵循保密之規定
  3. (C)金融機構及指定之非金融事業或人員對於達一定金額以上之通貨交易為申報者，免除其業務上應保守秘密之義務
  4. (D)防制洗錢專責單位人員為執行職務需要，應得即時取得客戶資料與交易紀錄，免除其業務上應保守秘密之義務
解析

(A)錯誤。此敘述正確，疑似洗錢或資恐申報相關文書均應以機密文件處理，避免洩漏申報事實。

(B)錯誤。此敘述正確，稽核人員為執行業務得即時取得客戶資料與交易紀錄，但仍受保密規定拘束。

(C)錯誤。此敘述正確，依法辦理達一定金額以上通貨交易申報者，免除其業務上應保守秘密之義務。

(D)正確（即敘述有誤者）。專責單位人員得即時取得客戶資料與交易紀錄，這是取得資料的權限，並不因此免除保密義務。免除保密義務的對象是依法申報的行為本身，而不是內部人員的資料取用。

4. 產險業由於多為損失填補型商品，並無高額保單價值/現金價值，而被視為普遍風險較低，但卻需要額外關注下列何項風險？
  1. (A)保險標的物所在地的國家是否為高風險國家地區
  2. (B)保險標的物所有人及與持有人/控制人的關係
  3. (C)被保險人的住所地或法人註冊地的國家風險
  4. (D)被保險人從事行業或職業類別是否屬於高風險行/職業
解析

(A)錯誤。保險標的物所在國家屬一般性的地域風險因子，各險種通用，非產險須額外關注之處。

(B)正確。產險的洗錢風險不在保單價值，而在標的物的權屬關係：以來源不明或非本人所有的財產投保，再使理賠金流向第三人，正是產險被利用的主要路徑，故須釐清所有人與持有人、控制人之間的關係。

(C)錯誤。被保險人住所地或法人註冊地所生的國家風險，同屬一般性的地域因子。

(D)錯誤。行業或職業類別屬客戶風險因子，並非產險特有而須額外關注者。

5. 下列何項表徵與利用保險業洗錢之態樣較無直接關聯？
  1. (A)躉繳大額保費
  2. (B)現金繳交保費
  3. (C)大額溢繳保費
  4. (D)對理賠條款詳加詢問
解析

(A)錯誤。躉繳大額保費可一次投入大量資金，是保險洗錢的典型態樣。

(B)錯誤。以現金繳交保費使資金來源難以追溯，屬典型表徵。

(C)錯誤。大額溢繳保費後再申請退還，可將資金轉為保險公司的退款而漂白，屬典型態樣。

(D)正確（即關聯較低者）。詳加詢問理賠條款是一般消費者理解保障內容的正常行為。洗錢者的特徵恰好相反：不在意保障與理賠，只關心解約、保單借款與資金能否快速取回。

9. 在保險業防制洗錢及打擊資恐風險因子判斷實務，關於「產品因子」方面的描述下列何者錯誤？
  1. (A)可評估該產品／服務內容是否涉及金流，且思考該交易可否透過現金進行交易
  2. (B)可評估該產品／服務內容是否有確認客戶身份的機制
  3. (C)針對新產品、新業務、新支付機制或新技術可能衍生之洗錢風險，需評估與思考(但不限)
  4. (D)在產品風險考量上，僅需針對保險公司內部目前有營運之產品進行風險管理，不需要盤點全公司產品或服務，亦不需要額外給予所有產品個別的風險評級
解析

(A)錯誤。此敘述正確，產品是否涉及金流、能否以現金進行交易，是產品風險的關鍵評估點。

(B)錯誤。此敘述正確，產品流程中有無確認客戶身分的機制，直接影響其被利用的難易。

(C)錯誤。此敘述正確，新產品、新業務、新支付機制或新技術所衍生的風險均須事前評估。

(D)正確（即敘述有誤者）。產品風險評估應盤點公司全部產品與服務並逐項給予風險評級，才能形成完整的風險地圖；只評估目前主要營運的商品，會在未盤點處留下無人管理的缺口。

10. 關於確認客戶身分的時點，下列何者錯誤？
  1. (A)與客戶建立業務關係時
  2. (B)新臺幣三萬元以上的國內匯款時
  3. (C)發現疑似洗錢或資恐交易時
  4. (D)對客戶資料真實性有所懷疑時
解析

(A)錯誤。此敘述正確，與客戶建立業務關係時即應確認客戶身分。

(B)正確（即敘述有誤者）。達門檻即須確認身分的臨時性交易，指的是一定金額以上的現金收付或跨境匯款；帳戶對帳戶的國內匯款雙方均有紀錄可追，並不因金額達三萬元而另生確認義務。

(C)錯誤。此敘述正確，發現疑似洗錢或資恐交易時，應確認客戶身分。

(D)錯誤。此敘述正確，對先前取得之客戶身分資料真實性有所懷疑時，應重新確認。

11. 就資恐防制法指定之制裁名單，下列敘述何者錯誤？
  1. (A)需經審議會決議後始得為指定，並應公告
  2. (B)國內名單指定之對象以我國人民為限
  3. (C)經指定之制裁個人，不以在中華民國領域內者為限
  4. (D)經聯合國安全理事會資恐相關決議案所指定之法人，主管機關得依法務部調查局提報指定為制裁名單，並公告之
解析

(A)錯誤。制裁名單之指定須經審議會決議並公告，敘述無誤。

(B)正確（即敘述有誤者）。國內制裁名單的指定對象不以我國人民為限，凡符合資恐要件之個人、法人或團體均得指定。制裁針對的是行為，不是國籍。

(C)錯誤。經指定之制裁個人不以身處中華民國領域內者為限，敘述無誤。

(D)錯誤。聯合國安理會資恐決議所列之法人，主管機關得依調查局提報指定並公告，敘述無誤。

(D)錯誤。同名帳戶電匯僅降低部分風險，不能作為免除盡職調查的理由。

  2. (B)不受銀行法相關規定限制
