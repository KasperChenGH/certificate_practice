1. 有關於防制洗錢金融行動工作組織(Financial Action Task Force，簡稱FATF)所公布之「40 項建議」(40Recommendations) 中通匯銀行之相關規範，下列敘述何者錯誤？
  1. (A)金融機構對通匯銀行亦應踐履客戶盡職審查義務
  2. (B)金融機構應取得高階主管許可後，始建立新的通匯關係
  3. (C)金融機構對於「過渡帳戶(payable-through accounts)」需確認所往來之通匯銀行已確實執行客戶審查措施
  4. (D)各國應要求通匯往來銀行在該國取得執照或完成註冊登記
解析

(A)錯誤。此敘述正確，通匯關係中的往來銀行本身即為客戶，金融機構應對其踐履客戶盡職審查，蒐集其業務性質、聲譽及受監理情形。

(B)錯誤。此敘述正確，建立新的通匯關係前應取得高階主管許可，以確保風險由適當層級承擔。

(C)錯誤。此敘述正確，對過渡帳戶（payable-through accounts）應確認該通匯銀行已對可直接使用該帳戶的客戶執行客戶審查，並能於必要時提供相關資料。

(D)正確（即敘述有誤者）。FATF 對通匯業務的要求，是禁止與空殼銀行建立或維持通匯關係、並確認往來銀行未讓空殼銀行使用其帳戶；並非要求通匯往來銀行必須在對方國家取得執照或辦理註冊登記。

2. 下列何者非現行洗錢防制法之內容？
  1. (A)必要時，法務部得會同中央目的事業主管機關指定受規範機構使用現金以外的支付工具
  2. (B)提供我國加入國際刑警組織的法源依據
  3. (C)允許我國協助他國執行財產沒收
  4. (D)設置定期經費制度，支付洗錢防制政策推行、培訓、國際合作等費用
解析

(A)錯誤。洗錢防制法確有於必要時指定受規範機構使用現金以外支付工具之機制。

(B)正確（即非該法內容者）。加入國際刑警組織屬國際組織參與事項，不是洗錢防制法所規範的範圍；該法處理的是洗錢犯罪、金流管制與司法互助。

(C)錯誤。協助他國執行財產沒收屬該法國際合作與沒收互助的內容。

(D)錯誤。該法設有經費（基金）機制，用以支應防制洗錢政策推行、教育訓練與國際合作。

3. 有關現行洗錢防制之相關法定遵循義務之敘述，下列何者正確？
  1. (A)洗錢犯罪之認定原則，除應證明為不法金流外，亦應以前置犯罪有罪為必要
  2. (B)考量我國詐欺集團車手猖獗情形，針對取得他人金融帳戶或使用假名取得金融帳戶等，以破壞金流秩序規範者，可予以罪刑化
  3. (C)為明確化客戶審查原則，金融機構於客戶審查規定僅限於大額通貨交易申報及可疑交易申報之情形
  4. (D)為透明化金流軌跡，必須透過金融機構履行客戶盡職審查、交易紀錄保存、落實大額通貨交易申報及可疑交易申報等義務，指定之非金融機構則僅著重於可疑交易申報義務即可
解析

(A)錯誤。洗錢罪的成立不以前置犯罪業經有罪判決為必要，僅須證明財物或利益係特定犯罪所得。

(B)正確。取得他人金融帳戶、以假名開立帳戶等行為，本身破壞金流可追溯的秩序並助長詐欺集團人頭帳戶氾濫，因此以罪刑化方式從供給端阻斷，而非僅事後追查車手。

(C)錯誤。客戶審查義務並不限於大額通貨交易申報與可疑交易申報兩種情形，建立業務關係及臨時性交易時即應執行。

(D)錯誤。指定之非金融事業或人員在其適用的業務範圍內，同樣須履行客戶審查與紀錄保存等義務，不僅止於可疑交易申報。

4. 為防制洗錢目的，有關證券商與客戶建立業務關係之敘述，下列何者錯誤？
  1. (A)新建立業務關係之客戶，應確定其風險等級
  2. (B)既有客戶已知風險等級，即無庸再進行評估
  3. (C)當高風險客戶進行交易時，應持續進行評估
  4. (D)高風險客戶應至少每年檢視一次、更新資料
解析

(A)錯誤。此敘述正確，新建立業務關係的客戶應於建立關係時確定其風險等級。

(B)正確（即敘述有誤者）。風險等級不是一次判定即終身有效，既有客戶仍須依定期檢視週期及觸發事件（交易異常、身分資料變動、負面訊息）重新評估，否則評級會與客戶實際行為脫節。

(C)錯誤。此敘述正確，高風險客戶進行交易時應持續評估其風險。

(D)錯誤。此敘述正確，高風險客戶應至少每年檢視並更新客戶資料一次。

113年第4次｜防制洗錢與打擊資恐｜第 22 題
5. 保險業者與客戶建立業務關係的管道，是評估客戶風險高低的因子之一，下列何者可能在此因子有較高風險？
  1. (A)業務員長期往來的客戶
  2. (B)透過電話投保之客戶
  3. (C)業務櫃台招攬的客戶
  4. (D)業務員的多年好友
解析

(A)錯誤。業務員長期往來的客戶，其身分與行為已可長期驗證，通路風險相對較低。

(B)正確。電話投保屬非面對面通路，無法當面核對本人與證件，冒名投保或以人頭要保的風險升高，因此在「建立業務關係管道」這項因子上風險較高。

(C)錯誤。臨櫃招攬可當面驗證客戶本人與證件，屬面對面通路。

(D)錯誤。業務員的多年好友屬熟識關係，身分可確認，非本因子的高風險情形。

113年第4次｜防制洗錢與打擊資恐｜第 28 題
6. 金融機構懷疑某客戶或交易可能涉及洗錢或資恐，且合理相信執行確認客戶身分程序可能對客戶洩漏訊息時，應採下列何項措施？
  1. (A)得不執行確認客戶之程序，而改以申報疑似洗錢或資恐交易
  2. (B)仍需執行確認客戶之程序，以判定是否需申報疑似洗錢或資恐交易
  3. (C)無需執行確認客戶之程序，亦無需申報疑似洗錢或資恐交易
  4. (D)待下次客戶再交易時再做確認客戶程序，及評估是否需申報疑似洗錢或資恐交易
解析

(A)正確。若合理相信執行確認客戶身分程序會使客戶知悉自己受到注意（tipping-off），應停止該程序，改以申報疑似洗錢或資恐交易；避免打草驚蛇而讓資金提前移轉、證據滅失。

(B)錯誤。堅持執行確認程序正好會洩漏訊息，與禁止洩密的要求相牴觸。

(C)錯誤。確認程序雖可不執行，但申報義務不因此免除。

(D)錯誤。延至下次交易再處理將錯失申報時機，資金早已流出。

7. 依「金融機構防制洗錢辦法」規定，銀行對客戶及交易有關對象之姓名及名稱檢核政策與程序，下列敘述何者錯誤？

  2. (B)至少應包括比對與篩檢邏輯、檢核作業之執行程序，以及檢視標準

  4. (D)應依據風險基礎方法，建立檢核政策及程序

(B)錯誤。此敘述正確，政策與程序至少應包括比對與篩檢邏輯、檢核作業的執行程序及檢視標準。

9. 不尋常的通貨使用為金融機構用來辨識疑似洗錢活動的小技巧，所謂不尋常通常「不包含」下列何者？
  1. (A)使用大量的現金
  2. (B)雖非大筆現金，但由多筆現金(或類現金)累積而成相對較大額的交易
  3. (C)沒有充分理由而要求保險公司支付現金
  4. (D)以現金在超商繳交相對小額保費

(A)錯誤。使用大量現金是最典型的不尋常通貨使用。

(B)錯誤。多筆現金或類現金累積成相對大額，屬化整為零（structuring）的規避手法，正是應注意的情形。

(C)錯誤。無充分理由而要求以現金給付，是刻意切斷金流軌跡的訊號。

(D)正確（即不包含者）。以現金在超商繳交相對小額保費，是一般民眾常見的便利繳費方式，金額與管道都符合日常消費習慣，不具異常性。

10. 客戶甲購買保險商品時，對於保障內容或給付項目完全不關心，僅關注保單借款成數、解約費用高低或變更受益人等程序，此時業務員乙應採取何等作為？
  1. (A)只要客戶能負擔得起保費，都應接受其投保申請
  2. (B)這可能是一個疑似洗錢之警訊，故應更了解客戶甲的投保動機
  3. (C)監控疑似洗錢是保險公司的事，業務員只負責讓客戶甲在要保書上簽名
  4. (D)客戶甲對於保障內容或給付項目完全不關心，代表客戶已完全了解商品，而無須了解投保動機
解析

(A)錯誤。負擔得起保費不等於資金來源合法，保費支付能力不能作為受理投保的唯一判準。

(B)正確。只在意保單借款成數、解約費用與變更受益人，卻不關心保障內容，顯示投保目的在資金的進出與移轉而非風險保障，是保險洗錢的典型警訊，第一線業務員應進一步了解其投保動機。

(C)錯誤。防制洗錢是全體從業人員的義務，業務員為直接接觸客戶者，責任無從推給公司。

(D)錯誤。不關心保障內容無法推論為已充分了解商品，恰恰是需要進一步查證的訊號。

12. 就資恐防制法指定之制裁名單，下列敘述何者錯誤？
  1. (A)需經審議會決議後始得為指定，並應公告
  2. (B)國內名單指定之對象以我國人民為限
  3. (C)經指定之制裁個人，不以在中華民國領域內者為限
  4. (D)經聯合國安全理事會資恐相關決議案所指定之法人，主管機關得依法務部調查局提報指定為制裁名單，並公告之
解析

(A)錯誤。制裁名單之指定須經審議會決議並公告，敘述無誤。

(B)正確（即敘述有誤者）。國內制裁名單的指定對象不以我國人民為限，凡符合資恐要件之個人、法人或團體均得指定。制裁針對的是行為，不是國籍。

(C)錯誤。經指定之制裁個人不以身處中華民國領域內者為限，敘述無誤。

(D)錯誤。聯合國安理會資恐決議所列之法人，主管機關得依調查局提報指定並公告，敘述無誤。

13. 依FATF 40 項建議與洗錢防制法第8 條規定，要求金融機構及指定之非金融事業或人員因執行業務而辦理國內外交易，應留存必要交易紀錄，交易紀錄之保存，自交易完成時起，應至少保留幾年？

  2. (B)五年

(C)錯誤。七年並非規定之保存年限。

(D)錯誤。十年並非規定之保存年限。

16. 下列何種保險繳費方式洗錢風險最大，應加強確認客戶身分？
  1. (A)躉繳
  2. (B)月繳
  3. (C)季繳
  4. (D)年繳
解析

(A)正確。躉繳一次投入大額資金，可在短期內把資金放進保單再藉解約取回，洗錢風險最高。金額大、期間短、與客戶繳費能力不相稱，正是加強確認身分的理由。

(B)錯誤。月繳金額分散且期間長，資金放置效率低，風險相對小。

(C)錯誤。季繳屬分期繳，單次金額有限且需長期維持，資金放置效率低於躉繳。

(D)錯誤。年繳雖單次金額較大，仍不及躉繳一次到位的風險。

17. 金融機構依賴第三方進行客戶審查工作，客戶審查之最終責任由誰負責？
  1. (A)金管會
  2. (B)第三方
  3. (C)金融機構
  4. (D)金管機構與第三方共同負擔
解析

(A)錯誤。金管會是監理機關，不代替機構承擔客戶審查責任。

(B)錯誤。得依賴第三方執行，但責任不因委託而移轉給第三方。

(C)正確。依賴第三方進行客戶審查時，最終責任仍由該金融機構負擔。否則機構將可藉外包規避義務，整套審查制度即被架空。

(D)錯誤。並非與第三方共同分擔，責任仍完全歸屬金融機構。

18. 有關帳戶與交易之持續監控，下列敘述何者錯誤？
  1. (A)金融機構應整合客戶之基本資料及交易資料，以強化交易監控功能
  2. (B)交易監控時應利用資訊系統，輔助發現疑似洗錢交易，但觀察臨櫃交易行為是否異常也很重要
  3. (C)交易監控態樣應納入公會態樣，不可自行增列監控表徵
  4. (D)對於風險等級較低之客戶，可以以合理較寬鬆之金額門檻作為審查交易之基礎
