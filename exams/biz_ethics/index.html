1. 某公司評估是否關閉一條長期虧損的產線時，逐一估算關廠對股東、員工、供應商與當地社區所產生的利益與損害，並選擇整體淨效益最大的方案。此一判斷方式最接近下列何種倫理學說？
  1. (A)義務論，以行為本身是否符合道德義務衡量對錯
  2. (B)德行論，以行為者是否具備良好品格衡量對錯
  3. (C)正義論，以利益與負擔的分配是否公平衡量對錯
  4. (D)效益論，以行為結果對相關各方的總體效益衡量對錯
解析

(A)錯誤。義務論主張某些行為的對錯不取決於結果，而取決於是否履行了道德義務或符合可普遍化的原則；若採義務論，重點會是公司對員工是否負有先行告知、協助安置等義務。

(B)錯誤。德行論關注的是行為者的品格（如誠實、正義、節制），問「一個有德行的經營者會怎麼做」，而非計算各方得失的總和。

(C)錯誤。正義論關注利益與負擔在成員間分配是否公平，會追問關廠的成本是否不成比例地落在最弱勢者身上，而不是只看整體淨效益是否為正。

(D)正確。效益論（功利主義）以行為所產生的結果為判準，主張應選擇能為受影響各方帶來最大整體淨效益的方案，題示的加總比較正是其典型運作方式。

2. 某跨國企業內部規範全面禁止疏通費，即使在若干法域此類支付被容忍。就企業倫理而言，支持此一「零容忍」政策最有力的理由是下列何者？
  1. (A)疏通費只出現在少數特定國家，全面禁止不會造成任何營運上的實際不便
  2. (B)它仍是以金錢換取公務行為，會助長索賄文化並使內部界線難以維持
  3. (C)疏通費的單筆金額通常過高，會顯著侵蝕企業在當地的營業利潤與現金流量
  4. (D)疏通費無法取得正式收據，因此在會計帳上完全無法認列為營業費用
解析

(A)錯誤。事實上禁止疏通費在部分法域確實會造成通關或行政延誤，正因如此才需要倫理上的堅持與替代做法。

(B)正確。零容忍的理由是倫理與管理的雙重考量：本質上它仍是對公務人員個人的給付，會強化「不付錢就不辦事」的環境；管理上，一旦開了「小額可以」的口子，第一線人員就沒有清楚可執行的界線，合規制度隨之瓦解。

(C)錯誤。疏通費通常金額不大，利潤侵蝕並非其主要問題所在；若以金額大小作理由，反而暗示金額小就可接受。

(D)錯誤。會計處理是技術問題，且實務上企業仍可能以其他科目入帳，這不是倫理上的核心理由。

3. 布倫特蘭報告（Brundtland Report）對「永續發展」的經典界定，其核心內容是下列何者？
  1. (A)滿足當代的需要，同時不損及後代滿足其自身需要的能力
  2. (B)在不增加任何資源消耗的前提下，維持經濟成長率長期不變
  3. (C)以環境保護為唯一目標，必要時全面停止經濟開發活動
  4. (D)由已開發國家單獨承擔全部減量責任，開發中國家不受限制
解析

(A)正確。這是永續發展最廣被引用的定義，其倫理重心在世代間的公平：當代的選擇不得預先耗盡或破壞後代賴以生存與發展的自然與社會資本。

(B)錯誤。永續發展並不主張零資源消耗或固定成長率，而是要求發展方式不侵蝕未來的能力基礎。

(C)錯誤。永續發展一向被理解為環境、社會與經濟三面向的兼顧，而非以停止發展為手段。

(D)錯誤。責任如何在國家間分配是後續談判中的重要爭點（涉及共同但有差別的責任），但不是此定義本身的內容。

4. 某企業以顯著篇幅宣傳其單一產品線使用回收材料，但未提及該產品僅占營收極小部分，且公司整體用水與排放持續增加。此種溝通方式最適合以下列何者形容？
  1. (A)漂綠，以選擇性揭露的正面事實掩蓋整體環境績效
  2. (B)重大性原則，聚焦於對利害關係人最重要的少數議題
  3. (C)利害關係人議合，優先回應消費者最關心的面向
  4. (D)情境分析，以特定產品線推估整體的環境表現
解析

(A)正確。漂綠不必然包含不實陳述；以真實但不具代表性的片段營造整體環保的印象，同樣使閱聽人形成錯誤結論，因此完整性與比例是永續溝通的基本要求。

(B)錯誤。重大性是用來決定「該揭露什麼」的篩選原則，它要求納入重大的負面議題，不能用來正當化只講好消息。

(C)錯誤。議合是與利害關係人對話以了解其關切，並非挑選對自己有利的訊息對外宣傳。

(D)錯誤。情境分析是評估不同未來情境下的風險與韌性，與以單一產品代表全公司績效無關。

5. 某主管向部屬明示「願意配合應酬並接受肢體碰觸，年度考績與升遷才會好看」。此行為在職場性騷擾的分類上最接近下列何者？
  1. (A)職場的權勢霸凌行為
  2. (B)性別上的間接歧視
  3. (C)交換式（對價型）性騷擾
  4. (D)敵意工作環境型性騷擾
解析

(A)錯誤。職場霸凌指持續的貶抑、孤立、過度要求或不當歸咎，重點在權力濫用而未必具性或性別意涵，兩者可能併存但概念不同。

(B)錯誤。間接歧視指表面中立的規定對特定群體造成不利效果，屬制度層面的差別衝擊，與針對個人的性要求無關。

(C)正確。交換式性騷擾的特徵是以僱用、考績、升遷或其他勞動條件的利益或不利益，作為順從或拒絕性要求的交換條件，通常由具人事影響力者所為，本題正是此一結構。

(D)錯誤。敵意環境型指以性或性別相關的言語、圖像或行為，造成使人難以正常工作的冒犯氛圍，不以職務上的利益交換為要件。

6. 在擬定資遣名單的篩選標準時，下列何者最可能構成就業歧視，而非正當的經營判斷？
  1. (A)以「年資較長、已接近退休年齡」作為優先列入名單的依據
  2. (B)以「該職務因產線關閉而確定消滅」作為列入名單的依據
  3. (C)以「近三年可查證的績效評核結果」作為名單排序的依據
  4. (D)以「所具技能與轉型後業務需求不符」作為列入名單的依據
解析

(A)正確。以接近退休為由優先資遣，實質上是以年齡為篩選變項，且常隱含降低退休給付成本的動機。此類標準與職務履行能力無關，屬於典型的年齡歧視。

(B)錯誤。職務本身因組織調整而消滅，是與人無涉的客觀事由，屬於經濟性解僱中最容易被接受的正當理由。

(C)錯誤。以既有且可查證的績效紀錄排序，標準客觀、可供事後檢驗，只要評核制度本身無偏頗即屬正當依據。

(D)錯誤。技能與轉型後職務需求的契合度，直接關乎工作能否履行，屬於與職務相關的正當考量，但仍應搭配再訓練或轉調的評估。

7. 上市上櫃公司依誠信經營守則設置推動誠信經營的專責單位，就制度設計而言，下列敘述何者最為適當？
  1. (A)由董事長個人指定親信擔任，以確保指揮順暢
  2. (B)應定期向董事會報告誠信經營政策的執行情形
  3. (C)宜隸屬於業務單位，以便貼近第一線的營運需要
  4. (D)僅於發生重大違規案件時才需要啟動運作
解析

(A)錯誤。以個人信任關係決定人選會使該單位淪為特定人的延伸，反而削弱其對高階人員行為的監督功能。

(B)正確。誠信經營專責單位負責制定與執行防範不誠信行為的措施，並須定期向董事會報告執行情形，使董事會得以監督，避免制度流於形式。

(C)錯誤。專責單位若隸屬於被監督的業務單位，將無法保持獨立性；制度上應使其超然於承攬業務的部門之外。

(D)錯誤。專責單位的工作以事前預防為主，包括教育訓練、防範措施的訂定與檢討，並非只在事後救火。

8. 業務主管對於誇大產品效能的行銷文案表示：「同業講得比我們還誇張，而且文案是行銷部寫的、法務也看過了，這不是我一個人的事。」此番說法同時運用了道德脫離中的哪兩種機制？
  1. (A)有利比較與責任分散
  2. (B)扭曲後果與責備受害者
  3. (C)道德辯護與非人化
  4. (D)委婉標籤與扭曲後果
解析

(A)正確。以更惡劣的同業作為參照使自身行為顯得可接受，是有利比較；強調多個單位共同參與、無人單獨決定，則是責任分散。兩者都不否認行為存在，而是削弱行為與自我譴責之間的連結。

(B)錯誤。扭曲後果是宣稱危害輕微或不存在，責備受害者是主張對方應為結果負責，本題說法並未觸及消費者所受影響。

(C)錯誤。道德辯護指將行為包裝成服務更高目的，非人化指剝奪對象的人格特質；本題並未主張任何崇高理由，也未貶抑消費者。

(D)錯誤。委婉標籤是以中性詞彙重新命名行為，本題並未替誇大行為換名，且同樣未涉及對後果輕重的評估。

9. 某公司倫理守則明訂不得以不當利益取得訂單，但業務主管仍在部門會議上公開嘉勉以招待與回扣拿下大單的部屬。此一情形對組織倫理最主要的傷害是？
  1. (A)使公司在交際費核銷與相關憑證保存上的行政作業成本明顯增加
  2. (B)造成業務部門與研發部門之間的年度預算分配比例失衡
  3. (C)使公司無法在永續報告書中完整揭露公益捐贈的金額與對象
  4. (D)使倫理守則喪失可信度，員工學到真正受獎勵的是結果而非守則
解析

(A)錯誤。行政成本是次要且技術性的影響，並非此情境的倫理核心問題。

(B)錯誤。預算分配屬資源配置議題，與獎勵違反守則的行為所造成的規範崩壞無關。

(C)錯誤。公益捐贈金額的揭露與業務部門的取單手段是兩件事，並不因此受阻。

(D)正確。員工是從被獎勵與被懲罰的實例中學習組織的真實規範；公開表揚違反守則的作法，等於宣告守則不算數，其破壞力遠大於守則從未訂定。

10. 從領導倫理的觀點，主管將某項決策權限授權予部屬後，關於責任歸屬的正確理解是？
  1. (A)責任隨權限一併移轉予部屬，主管自此不再負責
  2. (B)責任由主管與部屬平均分擔，各負一半
  3. (C)責任歸屬應待事件發生後由稽核單位逐案認定
  4. (D)主管仍應就授權範圍內的結果負監督責任與最終責任
解析

(A)錯誤。若責任可隨授權完全移轉，主管將可藉由授權規避一切後果，這正是實務上最常見的卸責藉口。

(B)錯誤。責任並非可以機械均分的數量，主管與部屬各自因其角色（監督與執行）而負不同性質的責任。

(C)錯誤。責任歸屬應在授權當下即已清楚界定；事後才由稽核認定，代表授權時的權責劃分本身就有缺陷。

(D)正確。權責相符原則下，可以授出的是執行的權限，不能授出的是監督與最終負責；主管仍須選對人、設好界限並持續監督，否則授權會淪為卸責的工具。

11. 某廠牌手持電鑽依規格量產、每台品質一致，但其開關位置使使用者在正常握持時容易誤觸而啟動。就產品責任的瑕疵分類而言，這最可能屬於下列何者？
  1. (A)製造瑕疵
  2. (B)設計瑕疵
  3. (C)警告瑕疵
  4. (D)標示不符
解析

(A)錯誤。製造瑕疵指個別產品偏離既定設計或規格而成為不良品，通常只出現在少數件數；本例每一台都相同，問題不在生產失誤。

(B)正確。設計瑕疵指依既定設計製造出來的產品整批都帶有不合理的危險，缺陷來源是設計決策本身，判斷上通常會問是否存在成本可行的較安全替代設計。

(C)錯誤。警告瑕疵是產品的設計與製造均無問題，但廠商未就無法排除的殘餘風險提供充分的使用指示或警語。

(D)錯誤。標示不符多屬包裝、成分或規格揭露的合規爭議，並非因產品結構本身導致使用者受傷的責任類型。

12. 某品牌商每年赴海外供應商稽核勞動條件，作法是提前數週通知、僅查閱工廠提供的出勤與薪資表冊，結果年年合格。此稽核設計最可能被質疑之處是：
  1. (A)勞動條件屬供應商與其所在國主管機關之事，品牌商不宜介入
  2. (B)稽核頻率過高，重複查核同一事項而排擠供應商的正常產能
  3. (C)事先通知且僅倚賴受稽者提供的文件，易被事前整備所規避
  4. (D)改由供應商自行填報自評問卷，可節省差旅與人力成本
解析

  1. (A)問題在於未取得司機書面同意，若補簽同意書即無爭議
  2. (B)公務車既屬企業財產，企業就不得在其上安裝任何形式的定位設備

17. 銀行導入AI信用評分模型後，客戶詢問自己為何被拒貸，承辦人員回答「這是模型算出來的，我們也不知道原因」。就AI決策倫理而言，此回應的主要問題是：
  1. (A)對受決策影響者提供可理解的理由，是課責與救濟的前提
  2. (B)金融機構本即不得使用任何統計模型進行授信與否的決策

  4. (D)銀行應完整公開模型的程式碼與訓練資料，否則即屬不透明

(D)錯誤。可解釋性要求的是對當事人提供有意義、可理解的決策理由，不等於公開全部原始碼與資料，後者還涉及營業秘密與其他客戶的隱私。

  1. (A)屬於正常的資訊蒐集能力展現，市場本應獎勵反應較快速的人
  2. (B)屬於利用客戶與市場尚未取得的資訊搶先交易，違反公平原則

(D)錯誤。金額大小影響的是損害程度，不改變行為的本質，小額的搶先交易仍是搶先交易。

  2. (B)法院並不具備審理金融消費爭議的專業與權限，故須由專責機構代為裁判

20. 某產業公會於例會後，五家主要廠商各自在同一週內宣布相同幅度的調價。事後查出會中曾討論「合理價格區間」。就競爭倫理與公平交易法而言，此情形最可能被評價為下列何者？
  1. (A)垂直限制競爭，因為調價將直接影響下游經銷商的最終售價
  2. (B)不公平競爭中的仿冒行為，因為各家業者的售價完全相同
  3. (C)聯合行為，因為業者間就價格達成意思聯絡而共同限制競爭

(C)正確。聯合行為的核心要件是同一產銷階段的競爭者間有「合意」或意思聯絡，而共同決定價格、數量或交易對象等，藉此限制競爭；公會場合的價格討論正是典型的意思聯絡管道。

(D)錯誤。公會可以做技術標準、教育訓練等自律，但一旦觸及價格、產量或市場分割，即逾越自律而構成聯合行為。
