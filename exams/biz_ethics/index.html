1. 羅爾斯（J. Rawls）在其正義理論中提出「無知之幕」的思想實驗，其主要用意在於？
  1. (A)由社會全體效益加總的結果，論證最大多數人的最大幸福為唯一正當目標
  2. (B)說明自由市場交易所形成的所得分配，只要過程自願即必然合乎正義
  3. (C)主張正義的內容應由各社會依其歷史傳統與文化脈絡各自認定
  4. (D)使制度的選擇者不知自己將處於何種社會位置，以確保所選原則公平
解析

(A)錯誤。「最大多數人的最大幸福」是效益論的口號；羅爾斯正是為了反對效益論可能為了總體效益犧牲少數人，才提出以公平程序導出正義原則。

(B)錯誤。認為市場自由交易所形成的分配即屬正當，較接近諾齊克（R. Nozick）的權利／資格理論，而非羅爾斯的立場。

(C)錯誤。這是倫理相對論的主張；羅爾斯要導出的是理性人在公平條件下都會同意的普遍原則。

(D)正確。無知之幕要求選擇正義原則的人暫時不知道自己的階級、天賦與地位，因而無法量身訂做對自己有利的規則，藉此排除偏私、使選出的原則具有公平性。

2. 永續報告書委請外部機構執行「有限確信」與「合理確信」，兩者最主要的差別在於？
  1. (A)合理確信的查核程序較廣泛深入，所提供的保證程度高於有限確信
  2. (B)有限確信必須由會計師事務所執行，合理確信則須由第三方驗證機構執行
  3. (C)有限確信的結論以正面文字表達，合理確信以消極文字表達
  4. (D)有限確信只能用於財務資訊，合理確信只能用於非財務資訊
解析

(A)正確。兩者的差異在於執行程序的範圍與深度，以及因此可降低到的風險水準；合理確信投入的查核工作較多，保證程度較高，有限確信則屬較低程度的保證。

(B)錯誤。執行者是會計師事務所或第三方驗證機構，與確信程度是兩個獨立的選擇，並無題示的對應關係。

(C)錯誤。實務上恰好相反：有限確信多以「未發現…有重大不符」之消極（負面）文字表達，合理確信才以正面文字直接表示意見。

(D)錯誤。確信程度的高低與資訊屬財務或非財務無關；永續報告書所含者多為非財務資訊，兩種程度都可適用。

3. 公司若將銷售人員的薪酬幾乎完全連結於當期業績達成率，從領導倫理的角度看，最可能引發的風險是？
  1. (A)使員工過度重視長期客戶關係而忽略當期營收的達成
  2. (B)導致公司無從辨識高績效員工與低績效員工的差異
  3. (C)使人事成本無法隨營收變動而調整，加重固定支出
  4. (D)誘使員工為求達標而採取誇大不實或美化數字等不當手段
解析

(A)錯誤。方向相反。純業績連結會使員工過度偏重當期成交，長期客戶關係反而是被犧牲的一方。

(B)錯誤。此種制度在辨識當期業績高低上其實非常鮮明，問題出在它衡量的面向過於單一。

(C)錯誤。變動薪酬正是隨營收浮動的設計，反而降低固定人事成本，此選項與制度本身的性質不符。

(D)正確。獎酬制度是組織最強的行為訊號，當它只獎勵結果而不問手段時，等於把達標的壓力轉化為走捷徑的誘因，這也是許多重大商業弊案共同的制度根源。

4. 企業倫理制度的設計可分為「遵循（compliance）導向」與「誠信（integrity）導向」兩種取向，後者的主要特徵是？
  1. (A)以共享價值為核心，引導成員自發作出合乎倫理的判斷
  2. (B)由外部主管機關逐案核定成員行為是否適當
  3. (C)僅適用於規模較小、尚未公開發行公司的簡化制度
  4. (D)以偵查、稽核與懲處作為防止違法行為的主要手段
解析

(A)正確。誠信導向以組織共同認可的價值為基礎，透過領導示範、教育與制度設計使成員內化標準，在守則未涵蓋的灰色地帶也能自行作出合宜判斷；它並不排斥遵循機制，而是在其之上再進一步。

(B)錯誤。倫理判斷若須逐案外求核定，制度即無從運作；兩種取向都以企業自行建置內部機制為前提。

(C)錯誤。兩種取向是設計理念的差別，與公司規模或是否公開發行無關，大型企業同樣可能停留在純遵循導向。

(D)錯誤。以查核與懲處防堵違法是遵循導向的作法，其標準來自外部法令，目標是避免受罰。

自編練習題｜工商倫理｜第 27 題
5. 車廠品保部門發現某零件在特定情況下可能失效並危及乘員，發生率不高但後果嚴重，且目前尚無消費者投訴。就生產倫理而言，最能被辯護的做法是：
  1. (A)等到有實際事故或主管機關要求時再處理，以免造成商譽損失
  2. (B)主動通報並召回改正，同時對外說明風險情形與處置方式
  3. (C)僅在後續生產的新車改用新零件，已售出車輛不另處理
  4. (D)私下通知經銷商，於車主回廠保養時默默更換該零件
解析

(A)錯誤。以「尚無投訴」為由拖延，等於把可預見的人身風險當成商譽成本在計算；安全風險一經確認即產生行動義務，不以外部壓力出現為條件。

(B)正確。廠商對已售出的產品負有持續的安全責任，發現足以危及人身的缺陷時，主動揭露與召回既能消除風險，也讓消費者得以自行判斷是否使用。

(C)錯誤。只改善新車是把既有風險完全留給已購車的消費者承擔，並未履行對已流入市場產品的補救義務。

(D)錯誤。默默更換雖能修補部分車輛，卻刻意隱匿風險資訊，未回廠的車主無從得知，等於以維修率取代告知。

自編練習題｜工商倫理｜第 34 題
6. 某工廠排放廢水使下游養殖業者受損，而此項損失並未反映在該廠的生產成本中。此種情形在倫理與經濟學上稱為：
  1. (A)道德風險
  2. (B)負外部性
  3. (C)沉沒成本
  4. (D)逆選擇
解析

(A)錯誤。道德風險是締約後因後果由他方承擔而改變行為，同樣發生在契約關係內部，而非未參與交易的第三人。

(B)正確。負外部性指生產或消費行為的成本落在未參與該交易的第三人身上；因該成本未進入廠商的成本函數，產品價格會低於真實社會成本，產量也隨之過高。

(C)錯誤。沉沒成本指已支出且無法回收的成本，是決策時應予忽略的項目，與成本被轉嫁給第三人無關。

(D)錯誤。逆選擇是締約前的資訊不對稱使品質較差的一方留在市場，發生在交易當事人之間。

7. 某清潔劑廠商公布對照測試，宣稱去污力優於競品，但測試僅採用自家配方最擅長的一種污漬，且競品是以低於其建議濃度稀釋後使用。此廣告的主要倫理瑕疵在於：
  1. (A)此類測試應由政府檢驗機關執行，才具有公信效力
  2. (B)未事先取得競品廠商授權而使用其商標名稱
  3. (C)比較條件經刻意挑選與設定，數據雖真實卻不具代表性
  4. (D)去污力純屬主觀感受，本來就不應以數據方式呈現
解析

(A)錯誤。測試不必然須由政府執行，具公信力的第三方實驗室亦可；關鍵是方法公開、條件對等且結果可被複驗。

(B)錯誤。指名比較時合理使用競品名稱通常是被允許的；問題不在名稱的使用，而在比較是否公平。

(C)正確。挑選對自己最有利的單一情境、又讓對照組在不當條件下受測，會使一個範圍極窄的結果被消費者理解為全面性的優越；每個數字都可能為真，得出的整體印象卻是假的。

(D)錯誤。去污力可用標準化方法客觀衡量，並非不可量化；爭議在於衡量的設計，而非能否量化。

自編練習題｜工商倫理｜第 49 題
8. 某電商以「配送商品」為告知目的取得顧客手機號碼，其後將該名單提供給集團內關係企業進行保險行銷。此作法在個資與行銷倫理上的核心問題是：
  1. (A)超出蒐集時所告知的特定目的而利用，未就新用途取得同意
  2. (B)關係企業與原公司同受一控制主體支配，得視為同一蒐集主體
  3. (C)只要行銷簡訊載明來源並附有退訂連結，即已履行全部應盡義務
  4. (D)手機號碼未附姓名即不足以識別特定個人，故不屬個人資料
解析

(A)正確。告知特定目的是當事人同意的基礎，同意的範圍不會大於當初被告知的用途；把為配送而留的號碼移作保險行銷，等於在當事人未曾評估的用途上使用其資料，也使原本的告知失去意義。

(B)錯誤。集團的控制關係不會使不同法人自動成為同一蒐集主體，跨公司提供仍屬將個資提供予第三人。

(C)錯誤。載明來源與提供退訂是事後補救的最低配備，無法回溯正當化一開始即欠缺依據的目的外利用。

(D)錯誤。個人資料不以單獨附有姓名為必要，凡得以直接或間接方式識別特定個人者均屬之，個人資料保護法就其蒐集、處理與利用設有規範。

自編練習題｜工商倫理｜第 57 題
9. 公司資安部門主張為防止機密外洩，應全面側錄所有員工的公司電子郵件內容。在勞資與資訊倫理上，判斷此種監看是否可被接受，最核心的檢驗是：
  1. (A)是否已在勞動契約中載明員工拋棄一切隱私期待
  2. (B)是否事前明確告知監看政策，且手段與所欲防範的風險相稱
  3. (C)是否由資安部門而非人資部門執行，以確保專業與中立
  4. (D)是否僅監看主管階層，因為主管接觸的機密資訊較多
解析

(A)錯誤。以概括條款要求員工拋棄一切隱私期待屬形式同意，在地位不對等的僱傭關係中欠缺實質效力，也不能取代比例原則的檢驗。

(B)正確。職場監看的正當性建立在目的正當、事前告知與比例原則之上，員工應能預見監看的範圍與方式，手段也不得逾越防範風險所必要的程度。若存在侵害更小的替代方案，全面側錄即難通過相稱性檢驗。

(C)錯誤。執行單位為何只影響內控設計，不是正當性的關鍵，由誰執行並不能使一個過度侵入的監看變得正當。

(D)錯誤。依職級決定監看範圍是風險評估的一種考量，但不是核心檢驗，針對特定群體的差別監看反而可能引發公平性爭議。

自編練習題｜工商倫理｜第 64 題
10. 銀行導入AI信用評分模型後，客戶詢問自己為何被拒貸，承辦人員回答「這是模型算出來的，我們也不知道原因」。就AI決策倫理而言，此回應的主要問題是：
  1. (A)對受決策影響者提供可理解的理由，是課責與救濟的前提
  2. (B)金融機構本即不得使用任何統計模型進行授信與否的決策
  3. (C)只要模型的整體準確率夠高，個別案件即無須給予任何說明
  4. (D)銀行應完整公開模型的程式碼與訓練資料，否則即屬不透明
解析

(A)正確。當事人若無從知悉不利決定的理由，就無法檢視其中是否有錯誤資料或不當因素，也無法有效申訴。可解釋性正是讓演算法決策能被檢驗與課責的必要條件，「機器決定的」不構成免責事由。

(B)錯誤。以統計模型輔助授信是普遍且合法的作法，倫理要求的是模型可解釋、可稽核與可申訴，而非全面禁用。

(C)錯誤。整體準確率高不代表個案正確，被誤判的個人承擔的是全部損失，說明義務正是為個案而存在。

(D)錯誤。可解釋性要求的是對當事人提供有意義、可理解的決策理由，不等於公開全部原始碼與資料，後者還涉及營業秘密與其他客戶的隱私。

自編練習題｜工商倫理｜第 72 題
11. 某證券商研究部門即將發布對某上市公司的調升評等報告，自營部門主管得知後，於報告發布前先行買進該檔股票。此行為最貼切的定性是：
  1. (A)屬於正常的資訊蒐集能力展現，市場本應獎勵反應較快速的人
  2. (B)屬於利用客戶與市場尚未取得的資訊搶先交易，違反公平原則
  3. (C)屬於避險操作，可以降低證券商發布報告之後的部位風險
  4. (D)只要自營部門買進的數量不大，即不生任何倫理上的疑慮
解析

(A)錯誤。此處的資訊優勢並非來自研究能力，而是來自機構內部的職務接觸，把內部資訊等同於市場洞察是對公平競爭的曲解。

(B)正確。搶在自家報告公開前建立部位，是利用尚未對外揭露的資訊搶先交易，客戶依報告進場時面對的是已被推升的價格。這同時是資訊隔離失靈與忠實義務的違反。

(C)錯誤。事前建倉並非避險，避險是為既有部位建立反向保護，而不是為預期的市場反應提前獲利。

(D)錯誤。金額大小影響的是損害程度，不改變行為的本質，小額的搶先交易仍是搶先交易。

自編練習題｜工商倫理｜第 79 題
12. 某銀行將分行與理專的獎酬幾乎完全綁定於特定高費率商品的銷售量，並設定逐月調高的目標。就組織倫理而言，此制度最值得警惕之處是：
  1. (A)這種誘因結構會系統性地把從業人員推向不當銷售，非僅個人操守問題
  2. (B)唯一的問題是可能導致人事成本上升，進而侵蝕分行的獲利
  3. (C)只要同時公告「禁止不當銷售」的內規並要求員工簽署，誘因設計即無疑慮
  4. (D)獎酬制度屬企業自治事項，與從業人員的倫理風險並無關聯
解析

(A)正確。當報酬幾乎只獎勵銷售量與費率，從業人員每天都被迫在自身利益與客戶利益之間取捨，違規就從偶發的個人操守問題變成可預期的結構性結果。有效的治理應調整誘因，例如納入客訴、留存率與適合度品質，而非僅事後懲處第一線。

(B)錯誤。人事成本高低是財務議題，本題的核心是誘因對行為的扭曲。

(C)錯誤。書面禁令與簽署紀錄若與實際獎懲相互矛盾，員工會依真正影響收入的訊號行動，規範與誘因不一致時通常是誘因勝出。

(D)錯誤。獎酬設計決定員工每日面對的誘因，是組織倫理最具影響力的槓桿之一，並非與倫理無涉的管理細節。

13. 關於掠奪性定價（predatory pricing）在倫理上受到非難的主要理由，下列敘述何者最為適切？

  2. (B)低價會使政府稅收減少，因而間接損害社會整體的福利水準
  3. (C)短期低價的消費者利益，是以驅逐對手後長期漲價與選擇減少為代價換來的
  4. (D)任何低於同業平均售價的行為，都會使既有競爭者受損因而在倫理上不被容許
解析

(A)錯誤。掠奪性定價受非難的對象是市場與競爭者，不是股東；何況掠奪者通常預期日後可回收。

(B)錯誤。稅收並非競爭倫理的判準，這個理由與掠奪性定價的危害機制無關。

(C)正確。掠奪性定價的倫理問題不在「便宜」，而在其目的與後果：以可承受的短期虧損排除競爭者，待市場結構改變後再回收，消費者最終面對更高價格與更少選擇。

(D)錯誤。低於同業售價可能只是效率較高或成本較低的正當競爭，競爭本來就會使部分業者受損，這不構成倫理非難。

  2. (B)在部落中挑選數位具影響力的個別人士簽署同意書，以代表全體族人的意見
  3. (C)在決策定案前以可理解的方式充分告知，並依部族自身程序取得無脅迫的同意
  4. (D)在工程動工之後，就已經發生的各項實際影響向當地部落說明並發放補償金

(D)錯誤。動工後才說明已違反「事先」要素；此時同意與否無法再影響決策，參與只剩形式。

17. 某公司規定所有職員一律不得申請部分工時或彈性工時，理由是「便於排班管理」。此規定形式上對全體員工一體適用，實際上卻使負擔主要家庭照顧責任的員工大量離職。此情形最接近下列何者？
  1. (A)直接歧視
  2. (B)職場騷擾
  3. (C)具正當事由的差別待遇
  4. (D)間接歧視
解析

(A)錯誤。直接歧視是明文或明示以性別、年齡、婚育等特徵為區別依據，本題的規定文字對所有人一律適用，並未指名任何群體。

(B)錯誤。職場騷擾指以言語或行為對特定人造成敵意、羞辱或冒犯的環境，屬於針對個人的對待方式，與制度性規定造成的分布差異不同。

(C)錯誤。要主張正當事由，雇主須證明該規定與職務必要性有實質關聯且無較小侵害的替代方案；「便於管理」屬行政便利，通常不足以支撐。

(D)正確。間接歧視指表面中立的規定、標準或作法，在實際運作上對特定群體造成顯不利益的效果。判斷重點不在於雇主的主觀意圖，而在於該規定所產生的差別衝擊，以及雇主能否證明其為必要且無侵害較小的替代方案。

  2. (B)個人道德發展層次無法測量，招募時應完全放棄任何品格面向的評估

  1. (A)法律型倫理氣候，以符合外部法令與專業規範為主要考量
  2. (B)工具型倫理氣候，以自身或組織利益的極大化為主要考量
