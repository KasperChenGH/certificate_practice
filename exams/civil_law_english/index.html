1. 依現行規定，有關立法委員之選舉，下列敘述何者正確？
  1. (A)一人一票，票票等值，故當選人之得票數必須相同才能當選
  2. (B)政黨必須獲得百分之三以上之選票才能分配不分區席次
  3. (C)原住民僅以山地原住民為限
  4. (D)不論縣市人口多少，至少應選一人
解析

(A)錯誤。票票等值指每一張選票的影響力相同，不是要求當選人得票數相同。

(B)錯誤。分配不分區席次的政黨得票門檻是百分之五，不是百分之三。

(C)錯誤。原住民立法委員分為平地原住民與山地原住民，各三人。

(D)正確。增修條文明定區域立法委員按人口比例分配，但「每縣市至少一人」，以確保人口稀少的縣市仍有代表。

3. 依司法院大法官解釋，有關受刑人所得主張之基本權利，下列敘述何者正確？
  1. (A)因與其他受刑人一同於監獄內服刑，並同受監督，不得主張隱私權
  2. (B)因受刑人之人身自由受到限制，從而不得主張財產權、秘密通訊自由等基本權利
  3. (C)受刑人之表現自由應受如何之保障，與其人格發展自由無關
  4. (D)要求受刑人投稿須題意正確，涉及言論之事前檢查
解析

(A)錯誤。受刑人雖受監督，仍保有一定程度的隱私期待，並非全然不得主張。

(B)錯誤。人身自由受限制不等於其他基本權一併喪失；受刑人仍享有財產權與秘密通訊自由等權利。

(C)錯誤。表現自由與人格自由發展密切相關，不能謂無關。

(D)正確。要求投稿須「題意正確」，等於由監獄就內容預先審查決定可否發表，屬對言論的事前檢查，對表現自由構成嚴重干預。

4. 依憲法第8 條及相關司法院大法官解釋意旨，關於人身自由，下列敘述何者錯誤？
  1. (A)所謂「法官保留原則」，係指對於人民之審問與處罰，僅限於具有審判權之法官所構成之獨任或合議之法院，始得為之
  2. (B)傳染病防治之強制隔離措施，其所須踐行之正當法律程序，亦須與刑事處罰之限制被告人身自由一樣交由法院決定，不得由衛生主管機關逕行決定
  3. (C)法務部行政執行署所屬人員依行政執行法規定，對於欠稅不繳之納稅義務人進行拘提與管收，並不違反憲法第8 條第1 項規定
  4. (D)對於經常逃學或逃家之少年所進行之強制收容，仍須經法院加以裁定後，始得為之
解析

(A)錯誤。本題要選敘述錯誤者。審問處罰須由有審判權的法院為之，即法官保留。

(B)正確。大法官認為傳染病的強制隔離目的在迅速阻斷疫情，性質與刑事處罰不同，由專業的衛生主管機關逕行決定並設事後救濟即可，不以法官保留為必要。此為錯誤敘述。

(C)錯誤。本題要選敘述錯誤者。行政執行的拘提管收須經法院裁定，制度設計上並不違憲。

(D)錯誤。本題要選敘述錯誤者。對少年的強制收容涉及人身自由，須經法院裁定。

5. 有關徵收之憲法規定，下列敘述何者正確？

  2. (B)被害人須具有承諾能力，不以成年為限，也不以民法上之行為能力為標準
  3. (C)承諾須出於被害人之自由意思，不受強暴、脅迫之影響
  4. (D)承諾可以在行為前表示，也可以在行為後表示
解析

(D)正確。承諾必須於行為前或行為時已經存在並持續，行為後才表示的同意屬事後追認，不能溯及阻卻該行為的違法性。此為錯誤敘述。
