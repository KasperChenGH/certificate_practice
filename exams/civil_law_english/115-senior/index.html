4. 依司法院釋字第718 號解釋，有關緊急性及偶發性集會遊行之敘述，下列何者正確？
  1. (A)法律對緊急性及偶發性集會遊行，均得採行事前許可制予以管制
  2. (B)法律對緊急性及偶發性集會遊行，均不得採行事前許可制予以管制
  3. (C)法律對緊急性集會遊行，得採行事前許可制予以管制，但事前許可制不得適用於偶發性集會遊行
  4. (D)法律對偶發性集會遊行，得採行事前許可制予以管制，但事前許可制不得適用於緊急性集會遊行

(C)錯誤。該號解釋對緊急性與偶發性集會採同一結論，並未區分處理。

(D)錯誤。兩類集會均不得採事前許可制，並無其一得採許可制的差別。

5. 關於國家賠償請求權，依司法院釋字第624 號解釋之意旨，下列敘述何者正確？
  1. (A)軍事機關依軍事審判法令對人民身體自由所致之侵害，不得請求國家賠償
  2. (B)人民之自由、權利於刑事訴訟程序中受有損害，得依法向國家請求賠償
  3. (C)因刑事訴訟與軍事審判性質不同，立法者得規定限於依刑事訴訟程序受理案件所致侵害，始得請求國家賠償
  4. (D)軍事審判所致冤獄之賠償請求權人，得直接適用國家賠償法請求賠償
解析

(A)錯誤。軍事審判所致人身自由的侵害同屬國家行為所生的損害，不得一概排除於賠償之外。

(B)正確。人民的自由、權利因國家行使公權力而於刑事訴訟程序中受有損害者，得依法請求國家賠償，這是憲法保障人民訴訟權與國家賠償請求權的當然結果。

(C)錯誤。冤獄的本質不因審判系統而異，以受理程序的不同作為得否請求賠償的分類標準，欠缺正當理由而違反平等原則。

(D)錯誤。軍事審判所致的冤獄，應比照冤獄賠償的規定辦理，而非逕行適用國家賠償法。

6. 依憲法及法律規定，下列何者有服兵役義務？
  1. (A)在臺居住，有永久居留權之22 歲外國人
  2. (B)於28 歲因歸化而取得我國國籍之男子
  3. (C)於10 歲時放棄國籍並取得外國籍者
  4. (D)20 歲之我國籍女子
解析

(A)錯誤。憲法第20條規定人民有依法律服兵役之義務，兵役法第1條則明定中華民國男子依法皆有服兵役之義務，義務主體以具有我國國籍為前提；外國人縱在臺有永久居留權，仍不是我國國民，不負此義務。

(B)正確。兵役法第1條規定中華民國男子依法皆有服兵役之義務，第3條規定男子自年滿18歲之翌年1月1日起役，至屆滿36歲之年12月31日除役；因歸化取得我國國籍的男子即為我國國民，兵役法第36條並明定歸化我國國籍者應補行徵集，28歲仍在役齡之內，故負有服兵役義務。

(C)錯誤。10歲時放棄我國國籍並取得外國籍者，已非我國國民，兵役義務以國籍為前提，喪失國籍後即不負此義務；何況其放棄時尚未達役齡。

(D)錯誤。現行兵役法所定的義務主體是「中華民國男子」，女子並不負服兵役義務；志願役的女性是自願從軍，不是在履行憲法上的兵役義務。

7. 憲法第21 條規定的受國民教育權，保障的主體是下列何者？
  1. (A)學生
  2. (B)家長
  3. (C)教師
  4. (D)學校
解析

(A)正確。憲法第21條規定「人民有受國民教育之權利與義務」，權利的主體是「受」教育的人，也就是接受國民教育的學生本人；國家相對負有設置學校、提供就學機會的義務，使學齡人民得以受教。

(C)錯誤。教師受憲法保障的是講學自由，依據是憲法第11條，與人民受國民教育的權利屬於不同條文、不同主體。

(D)錯誤。學校是實施國民教育的機構，是國家履行提供教育義務的工具，本身不是享有受教育權的主體。

11. 關於我國法規範之法源（法規範之淵源），下列敘述何者正確？
  1. (A)憲法增修條文不屬於憲法一部分，效力低於憲法，可由法律加以修正
  2. (B)法律是指行政院提出草案，經立法院同意通過，行政院長公布後生效之規範
  3. (C)判例因可能侵犯立法權而遭廢除，目前由最高法院或最高行政法院之大法庭裁定統一法律見解
  4. (D)行政機關可以基於法律之授權訂定法規命令，也可以基於職權訂定行政規則，後者效力高於法律
解析

(A)錯誤。憲法增修條文是依憲法所定修憲程序制定，與憲法本文同屬憲法位階、效力相同，只能依修憲程序變更，不能以法律修正。

(B)錯誤。法律案除行政院外，立法委員、考試院、監察院、司法院等亦得提出；法律經立法院三讀通過後是由總統公布而非行政院院長公布，行政院院長僅為副署。

(C)正確。判例是最高法院從裁判中選編、具有拘束下級法院效力的法律見解，被批評為由司法機關形成一般性規範而有侵犯立法權之虞；2019年法院組織法修正後廢除判例制度，改由最高法院與最高行政法院設大法庭，以裁定統一法律見解，且大法庭裁定僅對提案的該案件有拘束力，不再是通案規範。
