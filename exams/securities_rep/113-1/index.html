1. 「證券交易法施行細則」係由下列何機關所訂定？
  1. (A)財政部
  2. (B)行政院
  3. (C)金融監督管理委員會
  4. (D)經濟部
解析

(A)錯誤。財政部是金管會成立前的證券主管機關，早年施行細則確由財政部訂定，但主管機關已於民國93年改為金管會，現行施行細則由金管會修正發布。

(B)錯誤。行政院是金管會的上級機關，但證交法授權訂定施行細則的是主管機關本身，不需由行政院訂定。

(C)正確。證券交易法第182條之1規定施行細則由主管機關定之，而證交法的主管機關是金融監督管理委員會。掌握「主管機關等於金管會」這個定位，可一併判斷證交法體系下多數命令與函釋的發布機關。

(D)錯誤。經濟部主管公司法與公司登記事務，公司法施行細則類的規範才與它有關，證交法施行細則不歸經濟部。

2. 下列選項中，何者可作為股份有限公司之發起人出資項目？
  1. (A)對公司事業所需之技術
  2. (B)對公司事業所需之財產
  3. (C)現金
  4. (D)選項(A)(B)(C)皆可
解析

(A)錯誤。技術確實可以作價作為發起人的出資，但財產與現金同樣可以，只選技術會漏掉另外兩種法定的出資方式。

(B)錯誤。公司事業所需的財產可以抵充股款，但這只是其中一種出資方式，現金與技術同樣被允許。

(C)錯誤。現金當然可以出資，但公司法並未限定發起人只能以現金出資，財產與技術經作價後亦可。

(D)正確。公司法第131條規定，發起人之出資除現金外，得以公司事業所需之財產、技術抵充之，所以三者皆可。允許非現金出資，是讓公司能直接取得營運真正需要的資源，而不必先變現再購入；作價須經核定，以防高估出資稀釋其他股東。

3. 關於公司申請停止公開發行之規範，下列敘述，何者正確？
  1. (A)應有代表已發行股份總數二分之一以上股東出席之股東會，以出席股東表決權過半數之同意行之
  2. (B)應有代表已發行股份總數三分之二以上股東出席之股東會，以出席股東表決權過半數之同意行之
  3. (C)應由三分之二以上董事之出席，及出席董事過半數之同意行之
  4. (D)全體董事三分之二以上同意行之
解析

(A)錯誤。二分之一出席、過半數同意是普通決議的門檻，用於一般議案；停止公開發行影響股東流通權益，公司法要求特別決議。

(B)正確。公司法第156條之2規定，公司申請停止公開發行應有代表已發行股份總數三分之二以上股東出席的股東會，以出席股東表決權過半數之同意行之。採特別決議，是因停止公開發行將使股票喪失公開市場的流通性與資訊揭露保障，對小股東影響重大。

(C)錯誤。三分之二董事出席、出席董事過半數同意是董事會特別決議的門檻，用於發行新股等董事會權限事項；停止公開發行屬股東會權限。

(D)錯誤。全體董事三分之二以上同意仍只是董事會層級的決定；是否退出公開市場攸關全體股東，不能由董事會單獨決定。

  4. (D)對證券經紀商之買賣數量加以限制

(A)錯誤。命令停止一部或全部之買賣，確為主管機關之法定權限。

(C)錯誤。對證券自營商之買賣數量加以限制，屬法定權限。

6. 公開發行公司董、監、經理人及大股東持有股數如有變動時，應於每月幾日前將上月份持有股數變動之情形向公司申報；公司應於每月幾日前彙總向主管機關申報？
  1. (A)5 日；10 日
  2. (B)5 日；15 日
  3. (C)10 日；15 日
  4. (D)10 日；20 日
解析

(A)錯誤。內部人向公司申報的每月五日是對的，但公司彙總向主管機關申報的期限是每月十五日，十日只給公司五天彙整，不是法定期限。

(B)正確。證券交易法第25條規定，董事、監察人、經理人及持股超過百分之十的股東應於每月五日以前將上月份持有股數變動情形向公司申報，公司再於每月十五日以前彙總向主管機關申報。分兩階段、間隔十日，是留給公司彙整與核對內部人資料的作業時間。

(C)錯誤。公司端的十五日正確，但內部人向公司申報的期限是每月五日，不是十日；十日才申報會壓縮公司彙整的時間。

(D)錯誤。十日與二十日兩個期限都與法定的五日、十五日不符，整體把揭露時點往後推了五天，延誤市場得知內部人持股變動的時間。

7. 甲為Z 上市公司董事長，其於某年1 月10 日以每股10 元買進Z 公司股票一萬股，又於同年3 月15 日以每股18 元賣出Z 公司股票一萬股。甲之行為應負證券交易法上何種責任？
  1. (A)沖洗買賣
  2. (B)短線交易
  3. (C)內線交易
  4. (D)甲並無任何法律責任
解析

(C)錯誤。題目未提及甲獲悉任何重大未公開消息，不能逕行認定為內線交易。

8. 上市公司監察人請求內部人將短線交易之利益歸入於公司，自獲得利益之日起幾年間不行使而消滅之？

9. 主管機關得因證券商之分支機構自行停止營業而撤銷其許可之期間基準為何？

(A)錯誤。連續一個月停業可能只是裝修、搬遷或人事調整，若以此即可撤銷許可，會對正常營運中的短暫停業造成過度干預。

(B)錯誤。連續兩個月仍未達證交法第59條所定的期間；法律給了三個月的容忍期，讓證券商有合理時間恢復營業。

(C)正確。證券交易法第59條規定，證券商或其分支機構於許可登記後三個月內未開始營業，或雖已開業而自行停止營業連續三個月以上者，主管機關得撤銷其特許或許可。長期停業代表該據點已無實質營運，繼續保留許可只會造成監理名冊與實況不符。

113年第1次｜證券交易相關法規與實務｜第 13 題
12. 某實收資本額二億元之證券經紀商轉型成為綜合證券商，其最低實收資本額與營業保證金總計需增加多少元？
  1. (A)二億五千萬元
  2. (B)四億五千萬元
  3. (C)六億五千萬元
  4. (D)八億五千萬元
解析

(A)錯誤。二億五千萬元是把綜合證券商的資本額誤記為四億元（單一承銷或自營商的門檻）所得：增資二億元再加保證金五千萬元；實際三種業務資本額須併計為十億元。

  2. (B)次二營業日
  3. (C)次三營業日
  4. (D)次四營業日
解析

(A)錯誤。次一營業日是決議後緊接的第一個營業日，若以此為起算日，證券商與投資人連一個完整營業日都沒有時間收到公告並調整信用部位，因此規範不採此日。

(B)正確。得為融資融券之受益憑證，經受益人大會決議由封閉式變更為開放式時，應自次二營業日起暫停融資融券交易。開放式基金的受益憑證可隨時向發行機構申請買回，市場流通數量不再固定，無法再作為信用交易可靠的擔保品與券源，所以必須停止融資融券；保留一個營業日的緩衝，則是讓證券商完成公告與部位處理。

(C)錯誤。次三營業日會讓已知不適合信用交易的標的多開放一個營業日，投資人可在明知即將停資停券之下繼續建立新的融資融券部位，規範採較早的次二營業日。

(D)錯誤。次四營業日的緩衝更長，同樣讓不宜作為信用交易標的的受益憑證多留在信用市場數日，並非規範所定的起算時點。

43. 下列何者不得融資融券？
  1. (A)零股交易
  2. (B)鉅額交易
  3. (C)全額交割股票
  4. (D)選項(A)(B)(C)皆是
解析

(A)錯誤。零股交易確實不得融資融券，因為信用交易以整張為單位辦理擔保品計算與強制回補；但鉅額交易與全額交割股票同樣被排除，只選此項並不完整。

(B)錯誤。鉅額交易是在一般撮合之外以議價或競價成交的大宗買賣，不能以融資融券方式進行；不過零股與全額交割股票也一樣被排除，因此本項並非完整答案。

(C)錯誤。全額交割股票因公司財務或營運異常而被列管，交易須先繳足款券，當然不得融資融券；但零股與鉅額交易也同樣不得，故仍應選皆是。

(D)正確。零股交易、鉅額交易與全額交割股票都不得融資融券。零股與鉅額交易的成交方式和一般整股撮合不同，無法套用信用交易的擔保品維持率計算與處分程序；全額交割股票則是公司已出現財務或營運警訊，若再允許以借來的資金或證券交易，違約風險會被放大。信用交易的前提是標的流動性穩定、品質受控，三者都不符合。

44. 證券商辦理有價證券買賣融資融券業務所需之有價證券，得以何種方式取得券源？
  1. (A)向其他證券商申請標購
  2. (B)洽臺灣證券交易所議借
  3. (C)向證券金融事業轉融券
  4. (D)以自營買進股票墊用
解析

(A)錯誤。證券商券源不足時參加的是「標借」，而且是向證交所的標借系統申請，由證券所有人或其他有券的機構出借；「向其他證券商標購」既不是法定程序的名稱，也不是券源取得方式。

(B)錯誤。議借是標借仍不足時，於當日下午二時前洽特定人（證券所有人）議定條件借入；證交所只負責確認條件並通知集保辦理交割，它本身不持有股票、不會出借，因此並沒有「洽證交所議借」這種方式。

(C)正確。證券商辦理融資融券業務所需的有價證券，得向證券金融事業辦理轉融通，即轉融券。證券金融事業居於證券商上游的融通角色，各證券商自有券源不足時可透過它調度，使信用交易在個別券商券源短缺時仍能維持運作；再不足時才進入標借、議借程序。

(D)錯誤。自營業務是證券商以自有資金為自己買賣，其部位與經紀、信用交易帳務必須嚴格區隔，不得將自營買進的股票充作客戶融券的券源，否則自營部位會與客戶利益混同。

(B)正確。發行人的股票在交易所上市買賣，交易所因提供交易場所與相關服務，每年依發行有價證券的總面值向發行人收取上市費（櫃買市場對應稱為上櫃費）。以總面值而非市價計費，是讓費用隨掛牌規模而定、不受股價漲跌影響，收費才穩定可預期。
