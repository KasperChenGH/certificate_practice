1. 「證券交易法施行細則」係由下列何機關所訂定？
  1. (A)財政部
  2. (B)行政院
  3. (C)金融監督管理委員會
  4. (D)經濟部
解析

(A)錯誤。財政部為金管會成立前之證券主管機關，現已非證交法主管機關。

(B)錯誤。行政院非證交法之主管機關，施行細則非由其訂定。

(C)正確。證券交易法的主管機關為金融監督管理委員會，施行細則由主管機關依母法授權訂定。掌握「主管機關＝金管會」這個定位，可一併判斷證交法體系下多數命令與函釋的發布機關。

(D)錯誤。經濟部主管公司登記等公司法事務，與證交法施行細則無涉。

2. 下列選項中，何者可作為股份有限公司之發起人出資項目？
  1. (A)對公司事業所需之技術
  2. (B)對公司事業所需之財產
  3. (C)現金
  4. (D)選項(A)(B)(C)皆可
解析

(A)錯誤。技術確實可作為出資項目，但本題三者皆可，故非完整答案。

(B)錯誤。財產確實可作為出資項目，但本題三者皆可，故非完整答案。

(C)錯誤。現金當然可作為出資，但本題三者皆可，故非完整答案。

(D)正確。三個選項的共同點是都屬法律允許用來抵充股款的出資標的：除現金外，公司事業所需之財產與技術經作價後亦得出資。允許非現金出資，是讓公司能直接取得營運真正需要的資源，而不必先變現再購入。

3. 關於公司申請停止公開發行之規範，下列敘述，何者正確？
  1. (A)應有代表已發行股份總數二分之一以上股東出席之股東會，以出席股東表決權過半數之同意行之
  2. (B)應有代表已發行股份總數三分之二以上股東出席之股東會，以出席股東表決權過半數之同意行之
  3. (C)應由三分之二以上董事之出席，及出席董事過半數之同意行之
  4. (D)全體董事三分之二以上同意行之
解析

(A)錯誤。此為普通決議之門檻，不足以決議停止公開發行。

(B)正確。停止公開發行應有代表已發行股份總數三分之二以上股東出席之股東會，並經出席股東表決權過半數同意。採特別決議，是因停止公開發行將使股票喪失公開市場的流通性與資訊揭露保障，對小股東影響重大。

(C)錯誤。此屬股東會權限，非由董事會決議即可為之。

(D)錯誤。此屬股東會特別決議事項，不能僅由全體董事三分之二以上同意決定。

5. 在證券交易所上市之有價證券之市場價格，發生連續暴漲或暴跌情事，並使他種有價證券隨同為非正常之漲跌，而有影響市場秩序或損害公益之虞者，主管機關得依法的權限，下列何者為非？
  1. (A)得命令停止其一部或全部之買賣
  2. (B)得命令終止其一部或全部之買賣
  3. (C)對證券自營商之買賣數量加以限制
  4. (D)對證券經紀商之買賣數量加以限制
解析

(A)錯誤。命令停止一部或全部之買賣，確為主管機關之法定權限。

(B)正確（即敘述有誤者）。主管機關的權限是「停止」買賣或限制買賣數量，並無命令「終止」買賣之規定。停止是因應市場異常的暫時性措施，終止則等同剝奪該證券的交易地位，兩者性質與程序完全不同，不能混用。

(C)錯誤。對證券自營商之買賣數量加以限制，屬法定權限。

(D)錯誤。對證券經紀商之買賣數量加以限制，屬法定權限。

7. 甲為Z 上市公司董事長，其於某年1 月10 日以每股10 元買進Z 公司股票一萬股，又於同年3 月15 日以每股18 元賣出Z 公司股票一萬股。甲之行為應負證券交易法上何種責任？
  1. (A)沖洗買賣
  2. (B)短線交易
  3. (C)內線交易
  4. (D)甲並無任何法律責任
解析

(A)錯誤。沖洗買賣指同一人自買自賣製造交易活絡假象，本題並無此情形。

(B)正確。甲為內部人，取得股票後六個月內再行賣出並獲有差價利益，構成短線交易，公司得行使歸入權請求其返還利益。短線交易採形式判斷，不問是否實際利用內線消息，目的是從源頭壓抑內部人的短線進出誘因。

(C)錯誤。題目未提及甲獲悉任何重大未公開消息，不能逕行認定為內線交易。

(D)錯誤。六個月內反向交易且獲有利益，已生歸入權之法律效果，並非全無責任。

10. 為提升證券商國際化業務能力，開放證券商從事外幣計價或連結國外標的之衍生性金融商品，證券商經營自行買賣外國有價證券業務若非屬自有資金投資或避險需求者，就涉及資金匯出入部分，應經下列何者許可？

12. 某實收資本額二億元之證券經紀商轉型成為綜合證券商，其最低實收資本額與營業保證金總計需增加多少元？
  1. (A)二億五千萬元
  2. (B)四億五千萬元

  4. (D)八億五千萬元

(C)錯誤。六億五千萬元並非本題應增加之金額。

(D)正確。綜合證券商須兼營經紀、自營、承銷三種業務，最低實收資本額合計十億元，故須自二億元增資八億元；營業保證金亦須由僅經營經紀業務的水準提高為三種業務合計之數，再增提五千萬元，兩者合計八億五千萬元。本題的解法是「三種業務門檻加總後，扣掉原本已具備的經紀業務部分」。

13. 下列何者不能於證券集中保管事業開設保管劃撥帳戶，成為參加人？

(D)錯誤。發行無實體有價證券之發行人得開設帳戶成為參加人。

15. 下列上櫃有價證券得為融資融券之條件何者有誤？

解析

(C)錯誤。此為所定條件之一，公司設立登記須屆滿三年以上。

(D)錯誤。此為所定條件之一，實收資本額須達新臺幣三億元以上。

  2. (B)買賣前應注意ETF 的折溢價，儘量避免交易市價偏離淨值過大的ETF
  3. (C)溢價是市價高於淨值，溢價表示買盤熱絡，應該趕快跟著搶購
  4. (D)ETF 達發行額度上限，發行人無法再受理申購時，ETF 可能會持續溢價
