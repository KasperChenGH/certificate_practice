1. 依公司法規定，除部分特例外，公司投資總額不得超過其實收股本多少比率？
  1. (A)50％
  2. (B)40％
  3. (C)30％
  4. (D)10％
解析

(A)錯誤。百分之五十會允許公司把半數以上的實收股本投到其他公司，超出公司法第十三條所定的上限，資金偏離本業的程度更高。

(B)正確。公司法第十三條規定，公開發行股票之公司為他公司有限責任股東時，其所有投資總額，除以投資為專業或公司章程另有規定或經股東會特別決議者外，不得超過本公司實收股本百分之四十。限制轉投資是避免公司資金大量流向本業以外、形成複雜的交叉持股而稀釋股東對資金用途的監督。

(C)錯誤。百分之三十比法定上限嚴格，公司法並未把轉投資限縮到此一水準；把上限記成三十是常見的混淆，法條數字是四十。

(D)錯誤。百分之十遠低於法定上限，若以此為限，多數集團公司的正常轉投資都會違法；公司法第十三條的數字是四十。

2. 發行人為募集設立，其募集與發行有價證券案應採下列哪一種方式？
  1. (A)申報生效制
  2. (B)申請核准制
  3. (C)申報核准制
  4. (D)兼採申報生效制及申請核准制
解析

(A)正確。證券交易法第二十二條自民國九十五年修正後規定，有價證券之募集及發行非向主管機關申報生效後不得為之，發行人募集與發行有價證券處理準則據此對包括募集設立在內的案件採申報生效制。申報生效制不由主管機關為投資價值背書，而是要求發行人完整揭露，申報後於一定期間內未經退回即生效，重心放在資訊揭露而非實質審查。

(B)錯誤。申請核准制是主管機關實質審查後准駁的舊制度，證券交易法第二十二條修正後已不再採用，募集設立案也不例外。

(C)錯誤。「申報核准制」並不是任何法規使用的制度名稱，是把申報生效與申請核准兩個名詞混在一起的誤稱。

(D)錯誤。現行制度單一採申報生效制，並無兼採兩制的情形；兼採是證券交易法第二十二條修正前的過渡狀態。

3. 依「證券交易法」規定，因命令停業之證券商，於其了結停業前所為有價證券之買賣或受託事務之範圍內，視為：
  1. (A)強制停業
  2. (B)尚未停業
  3. (C)暫時停業
  4. (D)永久停業
解析

(A)錯誤。強制停業描述的是主管機關命令停業這個處分本身，而題目問的是停業後了結事務期間的法律地位，兩者是處分與擬制效果的關係。

(B)正確。證券交易法第68條規定，因命令停業之證券商，於其了結停業前所為有價證券之買賣或受託事務之範圍內，視為尚未停業；經撤銷特許者於了結目的範圍內亦仍視為證券商。若停業當下業務能力立即消滅，未交割的買賣與未了結的委託將無人處理，反而害到客戶，故在「了結」範圍內擬制其仍在營業。

(C)錯誤。暫時停業是指停業處分有期限、期滿可復業，與第68條要處理的問題無關；該條談的是了結既有事務時證券商身分是否存續，不是停業期間長短。

(D)錯誤。永久停業等於撤銷特許，而第68條連撤銷特許的證券商都在了結目的範圍內仍視為證券商，可見法律意旨是讓善後得以完成，並非宣告其永久消滅。

4. 依照證券交易法之規定，下列何者非為內線交易規範主體？
  1. (A)持有該公司之股份百分之五之股東
  2. (B)該公司之法人董事代表人
  3. (C)該公司離職三個月的董事
  4. (D)從董事長獲悉消息之董事長司機
解析

(A)正確（即非規範主體者）。內線交易的規範主體之一是持有公司股份「超過百分之十」之股東；持股百分之五之股東未達此門檻，不在其列。設定持股門檻的理由是：達一定持股比例者通常有管道接觸公司內部資訊。

(B)錯誤。法人董事之代表人屬規範主體，其因職務當然接觸重大消息。

(C)錯誤。離職未滿六個月之董事仍屬規範主體，離職三個月者在內；否則只要辭職即可規避。

(D)錯誤。自董事長獲悉消息之司機屬「消息受領人」，同受規範，內線交易不以身分職位為限，而及於實際知悉消息者。

5. 券商經營涉有外匯業務之衍生性金融商品交易業務時，應就涉及資金匯出入部分向何機關申請許可？
  1. (A)金融監督管理委員會
  2. (B)中央銀行
  3. (C)經濟部
  4. (D)財政部
解析

(A)錯誤。金管會核准的是證券商經營衍生性金融商品交易「業務」本身；一旦商品涉及外匯而有資金匯出入，那是外匯業務，另須向外匯業務主管機關中央銀行取得許可，兩個許可缺一不可。

(B)正確。證券商經營涉有外匯業務的衍生性金融商品交易，就涉及資金匯出入的部分，應向中央銀行申請許可。依管理外匯條例，外匯業務由中央銀行掌理，凡牽動新臺幣與外幣兌換、資金進出國境者，都須由央行把關，以維持外匯市場秩序與國際收支的管理。

(C)錯誤。經濟部主管公司登記、工商與投資審議等事務，與外匯資金的匯出入管理無關。

(D)錯誤。管理外匯條例將財政部定為外匯「行政」主管機關，實際掌理外匯業務、核准資金匯出入的是中央銀行；證券商的匯出入許可要向央行申請。

6. 關於ETF 折溢價風險，何者錯誤？
  1. (A)折價是市價低於淨值，可能因市場需求不足造成
  2. (B)買賣前應注意ETF 的折溢價，儘量避免交易市價偏離淨值過大的ETF
  3. (C)溢價是市價高於淨值，溢價表示買盤熱絡，應該趕快跟著搶購
  4. (D)ETF 達發行額度上限，發行人無法再受理申購時，ETF 可能會持續溢價
解析

(A)錯誤。此敘述正確，折價指市價低於淨值，常因買盤或市場需求不足所致。

(B)錯誤。此敘述正確，應避免買賣市價偏離淨值過大的ETF。

(C)正確（即敘述有誤者）。溢價代表買進價格高於ETF實際持有資產的價值，追高買進將承擔溢價收斂時的額外損失，不應以買盤熱絡為由搶購。ETF的合理定價錨在淨值，價格與淨值的偏離本身就是風險而非利多。

(D)錯誤。此敘述正確，發行額度用罄無法受理申購時，套利機制失靈，ETF可能持續溢價。

7. 股票已在證券交易所上市或在證券商營業處所買賣之公司自辦股務事務者或代辦股務機構，多久時間接受集保結算所之股務單位股務作業評鑑？
  1. (A)每年
  2. (B)每兩年
  3. (C)每三年
  4. (D)每六個月
解析

(A)錯誤。每年評鑑會使股務單位頻繁接受外部評核，成本過高；集保結算所實務上是以三年為一個評鑑週期，中間年度則以查核與輔導方式監理。

(B)錯誤。每兩年並非集保結算所股務作業評鑑的週期；集保結算所的評鑑制度以三年為一輪，期間並參酌查核及裁罰紀錄評核。

(C)正確。上市櫃公司自辦股務者及代辦股務機構，應每三年接受集保結算所辦理的股務單位股務作業評鑑，評鑑項目包含管理制度、法令遵循及執行業務的正確性。定期外部評鑑可確保過戶、股東名簿管理及股利發放等作業品質，維持股務單位的中立性並保障股東權益。

(D)錯誤。每六個月是半年一次，比每年更頻繁，並非集保結算所評鑑的週期；如此密集的評鑑會使股務單位疲於應付，也非監理所需。

8. 下列何者為對公開發行公司無義務申報持股變動之人？
  1. (A)董事
  2. (B)監察人
  3. (C)檢查人
  4. (D)經理人
解析

(A)錯誤。董事為證券交易法所定之內部人，持股變動應依規定申報。

(B)錯誤。監察人同列內部人，負有申報持股變動之義務。

(C)正確。持股變動申報義務課予董事、監察人、經理人及大股東等內部人，目的在防範利用未公開資訊交易。檢查人係就特定事項受選任執行檢查，不具持續掌握內部消息的地位，故無此義務。

(D)錯誤。經理人屬內部人，其持股變動須申報。

1. 股東會決議對董事提起訴訟，公司應自決議之日起多久時間內提起？
  1. (A)三十日
  2. (B)六十日
  3. (C)九十日
  4. (D)六個月
解析

(A)正確。公司法第212條規定，股東會決議對董事提起訴訟時，公司應自決議之日起三十日內提起。期間定得短，是避免公司拖延而使追訴實益流失；公司逾期未提，監察人或符合資格的少數股東另有代表公司訴訟的途徑。

(B)錯誤。六十日比規定多了一倍；股東會既已決議追訴，程序上不需要兩個月準備，拖得愈久董事愈有時間處分財產或湮滅證據。

(C)錯誤。九十日等於一整季，公司法對股東會決議後提起訴訟的期限沒有這麼長，這只是三十日的三倍干擾數字。

(D)錯誤。六個月是公司法第214條少數股東請求監察人對董事提起訴訟時，必須「繼續六個月以上」持有股份的持股期間要件，不是公司提起訴訟的期限。

109年第4次｜證券交易相關法規與實務｜第 14 題
2. 證券商非經何單位許可，並與中華民國證券櫃買中心簽訂證券商經營櫃檯買賣有價證券契約，不得經營櫃檯買賣業務？
  1. (A)財政部
  2. (B)金管會
  3. (C)中央銀行
  4. (D)經濟部

15. 股票交易之手續費是：
  1. (A)只對買進收取
  2. (B)只對賣出收取
  3. (C)買進、賣出均收取
  4. (D)選項(A)(B)(C)皆非
解析

(A)錯誤。手續費是證券商提供受託買賣服務的報酬，買進時證券商同樣提供了委託、撮合與交割服務，因此買進也要收取，不是只對買進收費。

(B)錯誤。只在賣出時課徵的是證券交易稅（股票為成交金額千分之三），它是政府的稅，不是證券商的手續費；把兩者混為一談就會選到這一項。

(C)正確。股票交易的手續費買進與賣出都收取，目前上限為成交金額千分之1.425。手續費是證券商提供受託買賣服務的報酬，買賣雙向都有服務事實，所以雙向收取；這與證券交易稅只在賣出時課徵不同，一趟完整的買賣成本是兩次手續費加一次交易稅。

(D)錯誤。手續費雙向收取是明確的規則，(C)已正確描述，因此不存在皆非的情形。

16. 公司董事會設有常務董事者，其名額至少三人，最多不得超過董事人數多少比例？
  1. (A)二分之一
  2. (B)三分之一
  3. (C)四分之一
  4. (D)五分之一
解析

(A)錯誤。若上限為二分之一，常務董事會可取得半數董事席次，在董事會休會期間形同以半數人取代全體董事會運作，公司法不允許如此高的比例。

(B)正確。公司法第208條規定，董事會設有常務董事者，名額至少三人，最多不得超過董事人數三分之一，由董事互選之。常務董事在董事會休會期間依法令、章程及董事會決議執行職務，人數過多等同以少數常設機關架空董事會，故以三分之一為上限。

(C)錯誤。四分之一低於法定上限；以九席董事為例，四分之一只有二人多，連「至少三人」的下限都湊不齊，可見不是公司法採用的比例。

(D)錯誤。五分之一同樣低於三分之一的上限，董事須達十五人才能選出三名常務董事，會使多數中小型公司無法設置常務董事，與公司法設計不符。

  2. (B)三

  4. (D)二十

(B)錯誤。三個營業日並非櫃買中心規定的公告時點；預告期太短，持有人與證券商也難以完成轉換申請的作業。

(C)正確。依櫃買中心規定，轉換公司債及附認股權公司債的發行人辦理變更股票每股面額時，應於向經濟部申請變更登記日之前五個營業日，將債券停止轉換（認購）期間等事項在指定的網際網路資訊申報系統公告。面額變更會影響轉換價格與可換得股數，五個營業日的預告期讓持有人有時間在停止轉換前決定是否行使權利。

(D)錯誤。二十個營業日約一個月，比規定的五個營業日長得多，會使發行人在申請變更登記前被迫過早凍結轉換權，並非規範所採。

18. 目前證券商營業處所受託買賣有價證券的交易手續費上限為多少？
  1. (A)0.1425%
  2. (B)0.15%
  3. (C)0.1%
  4. (D)0.2%
解析

(A)正確。證券商受託買賣有價證券向委託人收取的手續費，依證券交易法第85條由證券交易所（集中市場）及證券商同業公會（營業處所）向主管機關申報核定，目前核定的上限為成交金額的千分之1.425，即0.1425%。這是「上限」而非固定費率，證券商得在此範圍內自行折讓，市場上常見的手續費折扣競爭就是在這個天花板之下進行。

(B)錯誤。0.15%是把千分之1.425進位成千分之1.5的誤記；若上限真是如此，每筆委託的最高成本會高於現行核定值，證券商收到0.1425%以上的費用即屬超收。

(C)錯誤。0.1%大約是券商給予折讓後客戶實際負擔的費率水準，它落在上限之下，是折扣的結果，不是主管機關核定的上限本身。

(D)錯誤。0.2%高於核定上限；若以此為上限，買賣一趟的手續費合計可達0.4%，加上賣出時千分之三的證券交易稅，交易成本會明顯高於現行制度。

115年第1次｜證券交易相關法規與實務｜第 50 題
19. 上市公司董事經法院裁判解任確定後，自裁判確定日起，幾年內不得充任上市、上櫃或興櫃公司之董事、監察人及依公司法第二十七條第一項規定受指定代表行使職務之自然人？
  1. (A)1 年
  2. (B)3 年
  3. (C)5 年
  4. (D)10 年
解析

(A)錯誤。一年的失格期間過短，被解任者只要等一屆股東會之後就能回鍋或轉任其他上市櫃公司，無法達到排除不適任者的效果；投保法所定期間是三年。

(B)正確。證券投資人及期貨交易人保護法第十條之一規定，董事或監察人經法院裁判解任確定後，自裁判確定日起三年內不得充任上市、上櫃或興櫃公司的董事、監察人及依公司法第二十七條第一項受指定代表行使職務的自然人。設有失格期間並涵蓋法人代表人，是要防止被解任者立即轉任他公司或改以法人代表身分回任，使解任裁判失去意義。

(C)錯誤。五年不是投保法所定的失格期間；公司法第三十條對董事消極資格是依犯罪類型另定不同年限，與此處裁判解任後的三年是不同制度。

(D)錯誤。十年出現在投保法第十條之一的另一處：保護機構的解任訴權自解任事由發生時起經過十年而消滅，那是訴權的時效，不是被解任者的失格期間。

20. 目前證券金融事業得經營下列哪些業務？
  1. (A)對證券商辦理承銷之融資
  2. (B)承銷認股之融資
  3. (C)有價證券買賣之融資融券
  4. (D)選項(A)(B)(C)皆是
解析

(C)錯誤。有價證券買賣之融資融券是證券金融事業最主要的業務，但對證券商承銷的融資與承銷認股融資同樣是其法定業務。

(D)正確。證券金融事業的核心功能是為市場提供資金與券源，依證券金融事業管理規則，其得經營之業務包括有價證券買賣之融資融券、對證券商辦理承銷之融資、承銷認股之融資等。三者分別對應次級市場信用交易與初級市場承銷的資金需求，都是證金公司的法定業務。
