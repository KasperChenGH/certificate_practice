1. 依「證券交易法」第6 條規定，下列何者視為有價證券？
  1. (A)利率交換契約
  2. (B)匯票
  3. (C)支票
  4. (D)新股權利證書
解析

(A)錯誤。利率交換為衍生性金融商品契約，非證券交易法所稱之有價證券。

(B)錯誤。匯票屬票據法規範之票據，非有價證券。

(C)錯誤。支票為支付工具，屬票據而非有價證券。

(D)正確。證券交易法第6條明定新股認購權利證書、新股權利證書，以及各種有價證券之價款繳納憑證或表明其權利之證書，均「視為」有價證券。這是為避免以憑證形式規避發行與交易的管理。

2. 證券商受僱人對外執行業務及在集中交易市場所為之一切行為，證券商應負何種責任？
  1. (A)部分責任
  2. (B)無須負責
  3. (C)完全責任
  4. (D)可負可不負
解析

(A)錯誤。法規並未採部分責任的設計。

(B)錯誤。證券商不得以係受僱人個人行為為由主張免責。

(C)正確。證券商之受僱人對外執行業務及在集中交易市場所為之一切行為，視為證券商本人之行為，證券商應負完全責任。此一嚴格責任促使證券商確實選任與監督員工，也讓交易相對人不必查究內部授權。

(D)錯誤。責任由法律直接課予，非證券商可自行選擇。

3. 依「公司法」規定，下列何者非股份有限公司的負責人？
  1. (A)公司經理人
  2. (B)公司監察人
  3. (C)公司董事
  4. (D)公司股東
解析

(A)錯誤。經理人在執行職務範圍內即為公司負責人。

(B)錯誤。監察人在執行職務範圍內即為公司負責人。

(C)錯誤。董事是股份有限公司的當然負責人。

(D)正確。股東僅是出資人，不執行公司業務，故非公司負責人。公司法是以有無執行業務或監督之權限、而非出資身分來認定負責人，因為負責人責任的基礎在於對公司事務的支配力。

4. 有關委託書徵求人之相關規定，以下何者為非？
  1. (A)徵求人應依股東委託出席股東會
  2. (B)委託人應親自填具徵求人姓名
  3. (C)徵求人違反主管機關處分已逾三年者
  4. (D)徵求人於委託書簽章後，即可轉讓他人使用
解析

(A)錯誤。徵求人本即應依股東委託之意旨出席股東會並行使表決權，此敘述無誤。

(B)錯誤。為確保委託出於真意，委託人應親自填具徵求人姓名，此敘述無誤。

(C)錯誤。曾受主管機關處分但已逾規定年限者即回復擔任徵求人之資格，此敘述無誤。

(D)正確（即敘述有誤者）。委託書具人身信賴性質，徵求人不得將取得之委託書轉讓他人使用。若容許轉讓，股東的表決權將流向其完全不知情的對象，徵求制度的揭露與課責即落空。

6. 依「證券交易法」之規定，得請求懲罰性民事賠償的是：
  1. (A)短線交易行為
  2. (B)內線交易行為
  3. (C)人為炒作股票行為
  4. (D)不實公開說明書
解析

(A)錯誤。短線交易係由公司行使歸入權取回差價利益，性質上非懲罰性賠償。

(B)正確。內線交易對善意從事相反買賣之人負損害賠償責任，情節重大者法院得將賠償額提高至三倍，屬懲罰性民事賠償。因內線交易舉證困難、獲利誘因大，須以超額賠償提高違法成本。

(C)錯誤。操縱股價之民事賠償屬填補實際損害，法無加倍賠償之規定。

(D)錯誤。公開說明書不實由法定責任主體負連帶賠償，性質為損害填補。

(D)錯誤。經理人屬內部人，其持股變動須申報。

9. 證券商辦理融資融券業務，下列哪一敘述不正確？

  4. (D)證券商受理開立信用帳戶，應詳實徵信

(C)錯誤。此敘述正確，法人開戶應另函證委託人確認確係授權開戶。

(D)錯誤。此敘述正確，證券商受理信用開戶應詳實徵信。

11. 集中交易市場採逐筆交易之時段為：

  2. (B)盤中

  4. (D)夜盤

(C)錯誤。收盤採集合競價，並非逐筆交易。

(D)錯誤。集中交易市場的股票交易並無夜盤時段。

12. 下列證券商經營受託買賣外國有價證券業務之敘述，何者正確？
  1. (A)為保護投資人，不論委託人屬性，均應交付風險預告書
  2. (B)證券商解說風險作業不得採電子化方式辦理
  3. (C)特定投資標的於國外發行地僅限專業投資人投資或屬私募商品者，證券商不得接受非專業投資人投資

15. 證交所提供之交易資訊有傳輸中斷情事時，證券商可否請求賠償？
  1. (A)得向證交所請求賠償
  2. (B)應循行政救濟程序處理
  3. (C)應透過證券商業同業公會請求證交所賠償

(D)正確。交易資訊傳輸中斷時，證券商不得向證交所請求賠償。此係雙方業務章則所定的免責安排：資訊傳輸涉及大量不可控的技術環節，若逐次中斷均須負賠償責任，市場基礎設施將無法承擔。

16. 股份有限公司發行新股時，除有特別規定者外，應保留原發行新股總額百分之多少股份由公司員工承購？
  1. (A)百分之十至百分之十五
  2. (B)百分之十二
  3. (C)百分之十
  4. (D)百分之二十至百分之二十五
解析

(A)正確。公司發行新股時，除有特別規定者外，應保留原發行新股總額百分之十至百分之十五之股份由員工承購。定為區間而非單一數字，是讓公司得依人力政策在此範圍內自行決定保留比例。

(B)錯誤。百分之十二落在區間內，但法條所定是一個區間而非固定比例。

(C)錯誤。百分之十僅為區間下限，非完整的法定內容。

(D)錯誤。百分之二十至二十五高於法定區間。

19. 禁止利用內線消息買賣之立法意旨為：
  1. (A)基於公平原則，求投資人之立足點平等
  2. (B)禁止任何人因資訊而買賣
  3. (C)鼓勵投資人進行市場研究
  4. (D)減少市場投機性
解析

(A)正確。禁止內線交易旨在維護市場資訊公平，使投資人立於相同資訊基礎上決策。若內部人得以未公開重大消息獲利，一般投資人將失去參與市場的信心。

(B)錯誤。法律禁止的是利用未公開之重大消息，並非禁止任何人依資訊買賣。

(C)錯誤。市場研究為合法且受鼓勵之行為，非本制度之立法目的。

(D)錯誤。減少投機並非內線交易禁止規定之立法意旨。

115年第2次｜證券交易相關法規與實務｜第 18 題
20. 以下有關買賣委託之敘述，何者錯誤？
  1. (A)買賣申報價格分為限價與市價
  2. (B)市價係指委託人未限定價格
  3. (C)限價賣出時，不得在限價以上成交
  4. (D)限價買進時，不得在限價以上成交
解析

(A)錯誤。此敘述正確，買賣申報之價格確分為限價與市價兩種。

(B)錯誤。此敘述正確，市價委託即委託人不限定價格，依市場價格成交。

(C)正確（即敘述有誤者）。限價賣出的限制是「不得低於限價成交」，在限價以上成交對賣方更有利，當然允許。限價單的本質是設定對委託人不利方向的價格底線，而非上限。

(D)錯誤。此敘述正確，限價買進不得以高於限價之價格成交。
