1. 已設置審計委員會之公開發行公司，依法應經審計委員會決議之特定事項，應得全體委員多少比例之同意？
  1. (A)四分之三
  2. (B)三分之二
  3. (C)二分之一
  4. (D)全體成員
解析

(A)錯誤。四分之三不是審計委員會的決議門檻；證交法對審計委員會採全體成員過半數同意，沒有訂到四分之三這麼高的特別多數。

(B)錯誤。三分之二是證券交易法第14-5條第2項的門檻：應經審計委員會決議的事項未獲其全體成員二分之一以上同意時，得由全體董事三分之二以上同意行之，那是董事會的替代門檻，不是審計委員會本身的門檻。

(C)正確。依證券交易法第14-5條，應經審計委員會決議的事項須經審計委員會全體成員二分之一以上同意，並提董事會決議；未獲同意者，得由全體董事三分之二以上同意行之。門檻以全體成員而非出席成員計算，可防止低出席率稀釋監督強度。

(D)錯誤。法律並不要求全體成員一致同意；若採一致決，任何一位獨立董事都能單獨否決，反而使委員會難以運作。

2. 若參加證券櫃買中心債券等殖成交系統，應以哪種方式為之？
  1. (A)自營
  2. (B)經紀
  3. (C)議價
  4. (D)選項(A)(B)(C)皆正確
解析

(A)正確。參加櫃買中心債券等殖成交系統，應以自營方式為之，即證券自營商以自有資金與部位直接和對手方成交。該系統以殖利率報價、由系統自動成交，參與者必須自行承擔債券價格與利率變動的風險，因此限於有自營資格、能自負盈虧的證券商參加，而非替客戶受託買賣。

(B)錯誤。經紀是證券商受託為客戶買賣並收取手續費，風險由客戶承擔；等殖成交系統是自營商之間的成交平台，不接受受託買賣的委託單。

(C)錯誤。議價是在證券商營業處所由買賣雙方逐筆商議價格的交易方式，屬於等殖成交系統以外的另一種債券交易途徑，不是參加該系統的方式。

(D)錯誤。三者皆可等於容許以受託與議價方式進入等殖系統，但該系統的設計是自營商以自有部位透過系統成交，僅有自營一種參加方式。

3. 證券承銷商出售證券時，負有代理發行人交付何種文書之義務？
  1. (A)投資說明書
  2. (B)公開說明書
  3. (C)委託書
  4. (D)風險預告書
解析

(A)錯誤。投資說明書是私募或特定金融商品向投資人提供的說明文件，不是證交法課予承銷商代為交付的法定文書。

(B)正確。證券交易法第七十九條規定，證券承銷商出售其所承銷之有價證券，應代理發行人交付公開說明書。公開說明書是投資人判斷是否認購的法定資訊來源，承銷商直接面對認購人，課予其交付義務，可確保投資人在認購前確實取得完整揭露，違反者依證交法負賠償責任。

(C)錯誤。委託書是股東委託他人出席股東會行使表決權的文件，適用公開發行公司出席股東會使用委託書規則，與承銷無關。

(D)錯誤。風險預告書用於期貨、權證、興櫃股票等高風險商品開戶或首次交易時由投資人簽署，不是承銷商出售證券時代發行人交付的文書。

4. 證券集中交易市場實施股市監視制度辦法係依據何項法令訂定？
  1. (A)證券交易所管理規則
  2. (B)公布或通知注意交易資訊暨處置作業要點
  3. (C)證券交易法施行細則
  4. (D)證券商管理規則
解析

(A)正確。證券集中交易市場實施股市監視制度辦法是證交所依證券交易所管理規則的授權訂定，並報經主管機關核定後施行。監視制度屬交易所對自己市場的自律職權，所以其法源放在規範交易所本身的管理規則中，由交易所擬訂細節、主管機關把關。

(B)錯誤。公布或通知注意交易資訊暨處置作業要點是證交所依監視制度辦法再訂定的下位執行細則，規定何時公布注意交易資訊、何時採取處置，它本身以監視辦法為依據，不可能反過來成為監視辦法的法源。

(C)錯誤。證券交易法施行細則是金管會依證交法授權訂定的細則，內容如重大事項的認定與申報格式，並未授權訂定監視制度辦法。

(D)錯誤。證券商管理規則規範的對象是證券商的財務與業務行為，不是交易所；監視制度由交易所執行，其法源自然不在證券商的管理規則中。

5. 下列關於「證券承銷」之敘述何者正確？
  1. (A)可有「包銷」或「代銷」兩種方式
  2. (B)證券自營商須經證券主管機關專案許可，始能例外從事承銷業務
  3. (C)可分為發行市場上之承銷與流通市場之承銷兩種層次
  4. (D)證券承銷商與發行人之間，係特定法律關係，而非屬契約關係
解析

(A)正確。證券承銷分為包銷與代銷兩種方式：包銷由承銷商承擔銷售不足之風險，代銷則僅代為銷售。兩者差別在風險歸屬，故包銷之承銷商須具備較高之財務能力。

(B)錯誤。承銷業務屬證券承銷商之業務，非證券自營商經專案許可即得辦理。

(C)錯誤。承銷為發行市場（初級市場）之行為，流通市場並無承銷可言。

(D)錯誤。承銷商與發行人間係依承銷契約而生之契約關係，並非單純的法定關係。

6. ESG 中的S 不包含以下何者？
  1. (A)商業模式
  2. (B)人權
  3. (C)員工福利
  4. (D)勞工關係
解析

(A)正確。ESG 的 S（Social，社會）關注企業與人及社會的關係，例如人權、勞工關係、員工福利、供應鏈勞動條件與社區參與。商業模式屬於公司經營策略與治理層面的議題，或作為永續報告的整體脈絡說明，不歸入社會構面，因此是 S 所不包含的項目。

(B)錯誤。人權是社會構面的核心議題，包括禁止強迫勞動、童工與歧視，各永續揭露準則都把它列在 S 之下。

(C)錯誤。員工福利涉及企業如何對待自身員工，例如薪酬、健康安全與訓練，是社會構面中的典型項目。

(D)錯誤。勞工關係涵蓋勞資溝通、結社自由與集體協商，是社會構面評估企業對待勞動者方式的重要指標。

7. 有關「公司法」之公司，下列敘述何者正確？
  1. (A)外國公司在中華民國境內營業須經我國政府許可
  2. (B)公司以其本公司所在地為住所
  3. (C)受本公司管轄之分支機構稱為子公司
  4. (D)是否為外國公司，依負責人國籍定之
解析

(A)錯誤。現行公司法已廢除外國公司認許制度，外國公司於我國營業依規定辦理分公司登記即可。

(B)正確。公司以其本公司所在地為住所。住所決定管轄法院、文書送達及登記主管機關，故法律須明定其認定標準。

(C)錯誤。受本公司管轄之分支機構為分公司；子公司則為具獨立法人格之他公司。

(D)錯誤。是否為外國公司，依其是否依外國法律組織登記而定，與負責人國籍無關。

112年第2次｜證券交易相關法規與實務｜第 29 題
9. 下列選項中，何者可作為股份有限公司之發起人出資項目？
  1. (A)對公司事業所需之技術
  2. (B)對公司事業所需之財產
  3. (C)現金
  4. (D)選項(A)(B)(C)皆可
解析

(A)錯誤。技術確實可以作價作為發起人的出資，但財產與現金同樣可以，只選技術會漏掉另外兩種法定的出資方式。

(B)錯誤。公司事業所需的財產可以抵充股款，但這只是其中一種出資方式，現金與技術同樣被允許。

(C)錯誤。現金當然可以出資，但公司法並未限定發起人只能以現金出資，財產與技術經作價後亦可。

(D)正確。公司法第131條規定，發起人之出資除現金外，得以公司事業所需之財產、技術抵充之，所以三者皆可。允許非現金出資，是讓公司能直接取得營運真正需要的資源，而不必先變現再購入；作價須經核定，以防高估出資稀釋其他股東。

10. 「證券交易法」第一百五十七條之一「內線交易」構成要件，指該消息明確後，未公開前或公開後多少小時內，不得買入或賣出？
  1. (A)12 小時
  2. (B)18 小時
  3. (C)24 小時
  4. (D)36 小時
解析

(A)錯誤。12小時不是證交法所定的沉澱期；若只有半天，在傍晚公開的消息尚未經過一個完整交易日，內部人就能在次日開盤時搶先交易。

(B)正確。證券交易法第157條之1規定，內部人實際知悉有重大影響股價的消息時，在該消息明確後，未公開前或公開後十八小時內，不得買賣該公司股票。設沉澱期，是讓市場有時間消化並將資訊反映於價格，避免內部人搶在一般投資人反應之前先行成交。

(C)錯誤。24小時並非法定沉澱期；證交法採十八小時，是考量消息多於收盤後公開，十八小時已能涵蓋次一交易日開盤前的時間。

(D)錯誤。36小時不是證交法所定的期間；沉澱期過長會不必要地限制內部人的正常交易，法律採十八小時已足以讓市場消化資訊。

11. 下列何者不得融資融券？

  2. (B)鉅額交易
