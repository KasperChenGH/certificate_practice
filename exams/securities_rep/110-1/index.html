1. 依「公司法」規定，下列何者非股份有限公司的負責人？
  1. (A)公司經理人
  2. (B)公司監察人
  3. (C)公司董事
  4. (D)公司股東
解析

(A)錯誤。經理人在執行職務範圍內即為公司負責人。

(B)錯誤。監察人在執行職務範圍內即為公司負責人。

(C)錯誤。董事是股份有限公司的當然負責人。

(D)正確。股東僅是出資人，不執行公司業務，故非公司負責人。公司法是以有無執行業務或監督之權限、而非出資身分來認定負責人，因為負責人責任的基礎在於對公司事務的支配力。

2. 「公司法」所稱之「關係企業」，指獨立存在而相互間具有何關係之企業？甲.有控制與從屬關係之公司；乙.相互投資之公司；丙.公司與他公司之董事有半數以上相同
  1. (A)僅甲
  2. (B)僅甲、乙
  3. (C)僅甲、丙
  4. (D)甲、乙、丙皆是
解析

(A)錯誤。僅列控制從屬關係，遺漏相互投資及董事半數以上相同之情形。

(B)錯誤。遺漏丙，董事半數以上相同者仍在關係企業的規範範圍內。

(C)錯誤。遺漏乙，相互投資之公司亦屬關係企業。

(D)正確。關係企業包括有控制與從屬關係之公司及相互投資之公司；而兩公司董事有半數以上相同者，法律推定為有控制與從屬關係，故三者皆屬之。以推定處理形式上未持股但人事重疊的情形，是為了防止藉人事控制規避關係企業規範。

3. 有關股東會之決議，對公司已發行股份之總數及表決權數之計算，下列敘述，何者正確？甲、無表決權股東之股份不算入已發行股份總數；乙、對表決事項有自身利害關係而不得行使表決權之股份數，不算入已發行股份總數
  1. (A)僅甲正確
  2. (B)僅乙正確
  3. (C)甲、乙皆正確
  4. (D)甲、乙皆錯誤
解析

(A)正確。甲敘述無誤：無表決權股東之股份不算入已發行股份總數。至於乙，有自身利害關係而不得行使表決權之股份，是不算入「已出席股東之表決權數」，而非不算入已發行股份總數——兩者扣除的基礎不同，正是本題要辨的重點。

(B)錯誤。乙把扣除的基礎弄錯了，甲才是正確敘述。

(C)錯誤。乙不正確，不能認定兩者皆對。

(D)錯誤。甲是公司法明定的計算方式，並非錯誤。

5. 「證券交易法」所謂發行，係指發行人於募集後，依法定方式所為之何種行為？
  1. (A)向主管機關申請登記
  2. (B)交付公開說明書
  3. (C)製作有價證券
  4. (D)製作並交付有價證券
解析

(B)錯誤。交付公開說明書屬募集與承銷階段的義務，非發行的定義。

(C)錯誤。僅製作而未交付，尚不構成證交法所稱之發行。

(D)正確。發行指發行人於募集後，依法定方式製作並交付有價證券（含以帳簿劃撥方式交付）之行為。定義同時要求製作與交付，因為唯有交付，證券所表彰的權利才真正移轉到投資人手中。

6. 依「證券交易法」第一百五十七條之一明定之內線消息，狹義而言是指下列何者？
  1. (A)有重大影響公司股票價格之消息
  2. (B)有重大影響公司經營策略之消息
  3. (C)金融監督管理委員會之重大政策消息
  4. (D)大型研究機構發布經濟數據
解析

(A)正確。狹義的內線消息指涉及公司財務、業務，而對其股票價格有重大影響之消息。規範核心在於公司內部人比市場更早取得的資訊，故限於與該公司本身有關者。

(B)錯誤。判準是對股票價格有無重大影響，而非是否影響經營策略。

(C)錯誤。主管機關之政策屬市場面消息，非特定公司之內部消息。

(D)錯誤。研究機構發布之經濟數據為公開資訊，不構成內線消息。

7. 計算短線交易利益時，得自列入計算之差價利益扣除下列何者？
  1. (A)借款購買股票之利息
  2. (B)買賣股票所獲配之股息
  3. (C)買賣高價買進低價賣出之虧損部分
  4. (D)買賣所支付之證券商手續費
解析

(A)錯誤。借款購買股票之利息屬個人資金成本，不得自差價利益中扣除。

(B)錯誤。所獲配股息與買賣差價無關，不得扣除。

(C)錯誤。短線交易利益採最高賣價與最低買價依序相配的計算方式，虧損部分不得用以沖抵。

(D)正確。計算短線交易歸入利益時，得扣除證券商手續費及證券交易稅等直接交易成本。歸入權的目的在剝奪內部人的實際所得，故只扣除取得該利益必然發生的交易費用，不容其以其他損失沖銷。

110年第1次｜證券交易相關法規與實務｜第 16 題
16. 公司買回股份應自申報日起多久執行完畢？
  1. (A)1 個月
  2. (B)2 個月
  3. (C)3 個月
  4. (D)4 個月
解析
