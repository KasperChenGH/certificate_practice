1. 依「公司法」規定，下列何者非股份有限公司的負責人？
  1. (A)公司經理人
  2. (B)公司監察人
  3. (C)公司董事
  4. (D)公司股東
解析

(A)錯誤。經理人在執行職務範圍內即為公司負責人。

(B)錯誤。監察人在執行職務範圍內即為公司負責人。

(C)錯誤。董事是股份有限公司的當然負責人。

2. 「公司法」所稱之「關係企業」，指獨立存在而相互間具有何關係之企業？甲.有控制與從屬關係之公司；乙.相互投資之公司；丙.公司與他公司之董事有半數以上相同
  1. (A)僅甲
  2. (B)僅甲、乙
  3. (C)僅甲、丙
  4. (D)甲、乙、丙皆是
解析

(A)錯誤。僅列控制從屬關係，遺漏相互投資及董事半數以上相同之情形。

(B)錯誤。遺漏丙，董事半數以上相同者仍在關係企業的規範範圍內。

(C)錯誤。遺漏乙，相互投資之公司亦屬關係企業。

(D)正確。關係企業包括有控制與從屬關係之公司及相互投資之公司；而兩公司董事有半數以上相同者，法律推定為有控制與從屬關係，故三者皆屬之。以推定處理形式上未持股但人事重疊的情形，是為了防止藉人事控制規避關係企業規範。

3. 有關股東會之決議，對公司已發行股份之總數及表決權數之計算，下列敘述，何者正確？甲、無表決權股東之股份不算入已發行股份總數；乙、對表決事項有自身利害關係而不得行使表決權之股份數，不算入已發行股份總數
  1. (A)僅甲正確
  2. (B)僅乙正確
  3. (C)甲、乙皆正確
  4. (D)甲、乙皆錯誤
解析

(A)正確。公司法第一百八十條規定，股東會之決議，對無表決權股東之股份數，不算入已發行股份之總數（甲正確）；至於對決議事項有自身利害關係而依第一百七十八條不得行使表決權之股份數，同條規定是不算入「已出席股東之表決權數」，而非不算入已發行股份總數（乙錯誤）。兩者扣除的基礎不同：無表決權股從已發行總數中拿掉，利害關係股則只在出席表決權數中扣除。

(B)錯誤。乙把扣除基礎弄錯了。利害關係股東的股份仍算在已發行股份總數內，只是在計算出席股東表決權數時扣除；反而甲才是公司法明定的計算方式。

(C)錯誤。甲雖正確，乙不正確，因此不能認定兩者皆對。利害關係股份影響的是出席表決權數的計算，不是已發行股份總數。

(D)錯誤。甲是公司法第一百八十條第一項的明文，無表決權股份不算入已發行股份總數，並非錯誤敘述。

4. 證券商向證券交易所申請股票上市者，應先取得何機關之同意函？
  1. (A)上市審議委員會

(C)錯誤。證券商業同業公會是自律團體，只能制定自律規範與協助會員，沒有核發主管機關同意函的公權力。

5. 「證券交易法」所謂發行，係指發行人於募集後，依法定方式所為之何種行為？
  1. (A)向主管機關申請登記
  2. (B)交付公開說明書
  3. (C)製作有價證券
  4. (D)製作並交付有價證券
解析

(A)錯誤。向主管機關申報（我國採申報生效制）是募集發行有價證券的程序要件，發生在募集之前；證交法對「發行」的定義描述的是募集完成後製作與交付證券的行為。

(B)錯誤。交付公開說明書是募集與承銷階段對認購人的資訊揭露義務，由發行人或承銷商履行，並非證交法第八條對發行的定義。

(C)錯誤。僅製作而未交付，證券所表彰的權利尚未移轉到投資人手中，證交法的定義要求製作「並交付」，缺一不可。

(D)正確。證券交易法第八條規定，發行指發行人於募集後製作並交付，或以帳簿劃撥方式交付有價證券之行為。定義同時要求製作與交付，因為唯有交付，投資人才實際取得證券所表彰的權利；無實體發行時，則以帳簿劃撥登載取代實體交付。

6. 依「證券交易法」第一百五十七條之一明定之內線消息，狹義而言是指下列何者？
  1. (A)有重大影響公司股票價格之消息
  2. (B)有重大影響公司經營策略之消息
  3. (C)金融監督管理委員會之重大政策消息
  4. (D)大型研究機構發布經濟數據
解析

(A)正確。證券交易法第一百五十七條之一所稱之內線消息，狹義而言是指涉及公司之財務、業務或該證券之市場供求、公開收購，其具體內容對其股票價格有重大影響，或對正當投資人之投資決定有重要影響之消息。規範核心在於公司內部人比市場更早取得足以影響股價的資訊，並利用此資訊優勢買賣，故判準是「對股價有重大影響」。

(B)錯誤。判準是對股票價格有無重大影響，而非是否影響經營策略；經營策略的變動若不影響股價，即使內部人知悉也不構成內線消息。

(C)錯誤。主管機關的政策消息屬影響整體市場的公開政策資訊，不是特定公司的內部消息，也不是公司內部人因職務而獨占的資訊。

(D)錯誤。研究機構發布的經濟數據是對外公開的資訊，任何人皆可取得，不存在資訊不對稱，不構成內線消息。

9. 證券商每設置一家國內分支機構，應於開業前一次繳存交割結算基金新臺幣多少元？
  1. (A)一百萬元
  2. (B)三百萬元
  3. (C)五百萬元
  4. (D)一千萬元
解析

(A)錯誤。一百萬元是把繳存金額記低了；證券商管理規則第十條所定的分支機構交割結算基金是三百萬元，一百萬元不足以對應分支機構增加所帶來的交割違約曝險。

(B)正確。證券商管理規則第十條規定，證券商每增設一國內分支機構，應於開業前向證券交易所一次繳存交割結算基金新臺幣三百萬元，自開業次一年起，其原繳金額減為新臺幣五十萬元。交割結算基金是集中市場共同的違約防線，營業據點增加代表受託交易量與違約曝險增加，故按分支機構家數加提。

(C)錯誤。五百萬元是同規則第十條對證券自營商開業前應繳存交割結算基金的金額，也是第九條中每增設一分支機構應增提營業保證金的金額，不是分支機構的交割結算基金。

(D)錯誤。一千萬元是證券商管理規則第九條中證券自營商應提存營業保證金的金額，與分支機構的交割結算基金無關；分支機構開業前應繳的是三百萬元。

10. 證券經紀商於集中交易市場受託買賣有價證券應繳存交割結算基金於：
  1. (A)臺灣銀行
  2. (B)集中保管結算所
  3. (C)臺灣證券交易所
  4. (D)證券商公會
解析

(A)錯誤。臺灣銀行是一般商業銀行，可能是證券商的往來銀行，但交割結算基金必須交給負責集中市場結算交割的機構，並非銀行。

(B)錯誤。集中保管結算所辦理有價證券集中保管、帳簿劃撥與款券結算作業，但集中市場的交割結算基金是依證交法及證券商管理規則向證券交易所繳存，並非繳給集保結算所。

(C)正確。證券商管理規則第十條規定，證券經紀商於集中交易市場受託買賣有價證券，應於開業前向證券交易所繳存交割結算基金。證交所是集中市場買賣的主辦機構，依證交法規定，證券商違約時由證交所指定其他證券商代為交割，並先動用交割結算基金代償差額，因此基金必須由證交所收存才能即時動用。

11. 證券承銷商出售證券時，負有代理發行人交付何種文書之義務？
  1. (A)投資說明書
  2. (B)公開說明書
  3. (C)委託書
  4. (D)風險預告書

12. 得與證券交易所訂立使用有價證券集中交易市場契約之證券商為下列何者？
  1. (A)經紀商、承銷商
  2. (B)自營商、經紀商
  3. (C)承銷商、自營商
  4. (D)僅限綜合證券商
解析

(A)錯誤。經紀商確實得訂約，但承銷商辦理包銷或代銷屬發行市場業務，不在集中交易市場買賣有價證券，不得與證交所訂立使用集中交易市場契約。

41. 證交所買賣申報之競價方式為？

(B)錯誤。逐筆交易與連續競價指的是同一種撮合方式（國外稱連續競價），此選項把同一制度寫成兩種，又漏掉開收盤的集合競價。

(C)錯誤。連續競價不是我國制度的用語，且盤中已改採逐筆交易；盤中改制前是每數秒一次的集合競價，也不叫連續競價。

42. 客戶與證券經紀商因委託買賣證券所生之爭議，得向何者申請調處？

  3. (C)平均價格
  4. (D)前二營業日收盤平均價格

(B)錯誤。開盤價只反映開盤集合競價的結果，無法反映故障前盤中已經形成的價格資訊，若採開盤價等於抹去整段盤中交易。

(C)錯誤。當日平均價格是所有成交的加權平均，不是任何一筆實際成交的價格，用它當收盤價會與市場最後的實際價位脫節。

(D)錯誤。前二營業日收盤平均價格完全不含當日的交易資訊，當日既然已有成交，就沒有理由回頭用歷史價格當收盤價。

44. 逐筆交易制度中，若委託不能全部成交時，則全數取消不予成交，此委託方式為？

  2. (B)IOC
  3. (C)FOK
  4. (D)ICO
解析

(A)錯誤。ROD（Rest of Day）為當日有效委託，未成交的部分留在委託簿繼續等待，直到收盤才失效，不會因為不能全部成交就取消。

(B)錯誤。IOC（Immediate or Cancel）是立即成交否則取消，允許部分成交，只把當下無法成交的剩餘數量取消；題目要求的是全部成交或全部取消。

(C)正確。FOK（Fill or Kill）指委託必須立即全部成交，否則全數取消，不接受部分成交。逐筆交易制度下這三種委託條件與限價、市價搭配使用；FOK適合需要整筆同時建立部位的策略，可避免只成交一部分而留下失衡的部位。

(D)錯誤。ICO 不是任何委託種類，只是把 IOC 的字母顛倒的干擾選項。
