2. 有關「公司法」之公司，下列敘述何者正確？

  2. (B)公司以其本公司所在地為住所

(C)錯誤。受本公司管轄之分支機構為分公司；子公司則為具獨立法人格之他公司。

(D)錯誤。是否為外國公司，依其是否依外國法律組織登記而定，與負責人國籍無關。

(D)錯誤。此敘述正確，董事違反股東常會召開期限規定者，依法處以罰鍰。

5. 對公開說明書之重要內容記載，能證明已經合理調查，並有正當理由確認其簽證或意見為真實者，而不負賠償責任者，係下列何人？

解析

(A)錯誤。發行人就公開說明書主要內容之虛偽或隱匿負責任最重，不得以已盡調查為由免責。

(B)錯誤。曾在公開說明書上簽章之職員，其免責要件是能證明已盡相當之注意並有正當理由確信主要內容無虛偽隱匿，與題目所述文字不同。

(C)錯誤。證券承銷商之免責要件同為已盡相當之注意，非題目所述之「合理調查、確信簽證或意見為真實」。

(D)正確。會計師、律師、工程師等專門職業或技術人員，對其簽證或意見部分，若能證明已經合理調查並有正當理由確信為真實，即不負賠償責任。法律對不同主體設定不同的免責門檻，是因專家只就自己專業出具的意見負責，不必為整份公開說明書擔保。

6. 關於公開發行公司私募有價證券對象之規定，下列敘述何者錯誤？
  1. (A)得對銀行業、票券業、信託業、保險業、證券業或其他經主管機關核准之法人或機構私募，無家數限制
  2. (B)得對符合主管機關所定條件之自然人、法人或基金私募，不得超過35 人
  3. (C)得對發行公司或其關係企業之董事、監察人及經理人私募，無人數限制
  4. (D)私募股份時，無須保留給原有股東認購
解析

(A)錯誤。此敘述正確，對金融、票券、信託、保險、證券業等專業機構私募，不受家數限制。

(B)錯誤。此敘述正確，符合主管機關所定條件之自然人、法人或基金，應募人數受三十五人上限拘束。

(C)正確（即敘述有誤者）。公司或其關係企業之董事、監察人及經理人，與前述符合條件之自然人、法人或基金合計，人數不得超過三十五人，並非不受限制。設人數上限是為維持私募「非公開招募」的本質，避免變相對外募集而規避公開發行的資訊揭露義務。

(D)錯誤。此敘述正確，私募不適用原股東優先認購之規定，無須保留給原有股東認購。

112年第2次｜證券交易相關法規與實務｜第 7 題
7. 違反「證券交易法」第一百五十七條之一之內線交易行為，其刑事責任為何？
  1. (A)七年以下有期徒刑、拘役或科或併科十五萬元以下罰金
  2. (B)五年以下有期徒刑、拘役或科或併科新臺幣二百四十萬元以下罰金
  3. (C)三年以上十年以下有期徒刑，得併科新臺幣一千萬元以上二億元以下罰金
  4. (D)一年以下有期徒刑、拘役或科或併科新臺幣一百八十萬元以下罰金
解析

(A)錯誤。七年以下有期徒刑沒有最低刑度，十五萬元以下罰金相對於內線交易動輒數千萬元的不法利益更是微不足道，這種刑度無法達到嚇阻效果，證交法對內線交易所定的是有下限的重刑。

(B)錯誤。五年以下有期徒刑、拘役或科或併科二百四十萬元以下罰金，是證交法對情節較輕的證券犯罪類型所用的刑度級距；內線交易與操縱市場同列重大證券犯罪，不在此級距。

(C)正確。違反證交法第一百五十七條之一的內線交易，依同法第一百七十一條處三年以上十年以下有期徒刑，得併科新臺幣一千萬元以上二億元以下罰金；犯罪所得達一億元以上者刑度再加重。刑度訂得如此重，是因內線交易直接破壞市場資訊平等，屬證交法列為重大證券犯罪的類型。

(D)錯誤。一年以下有期徒刑、拘役或科或併科罰金是輕罪的刑度型態，適用於證交法中違反程序或申報義務的輕微違規；內線交易的法定刑起點就是三年有期徒刑。

8. 依證交法規定公司買回之股份，除為維護公司信用及股東權益所必要之買回，並辦理銷除股份者外，其餘情形所買回之股份，應於買回之日起幾年內將其轉讓？逾期未轉讓者，視為公司未發行股份，並應辦理變更登記。
  1. (A)1 年
  2. (B)2 年
  3. (C)3 年
  4. (D)5 年
解析

(A)錯誤。一年太短：公司買回的庫藏股多用於轉讓給員工或作為可轉換公司債、附認股權證券的轉換來源，若一年內未轉讓就強制視為未發行股份，等於逼公司在短期內處分，反而不利股東。

(B)錯誤。二年並非證交法所定的期限，也不是任何一款買回股份的轉讓期限；證交法對一般情形給的是五年。

(C)錯誤。三年是證交法第二十八條之二修正前的舊規定，也是公司法第一百六十七條之一非公開發行公司買回股份轉讓員工的期限；證交法現行規定已放寬為五年。

(D)正確。依證交法第二十八條之二第四項，公司買回的股份除為維護公司信用及股東權益而買回並辦理銷除者外，應於買回之日起五年內轉讓；逾期未轉讓者視為公司未發行股份，並應辦理變更登記。設定期限是避免公司長期持有庫藏股，使實際流通股數與股權結構長期失真。

112年第2次｜證券交易相關法規與實務｜第 9 題
9. 主管機關發現證券商有違反「證券交易法」者，除依法處罰外，得視情節之輕重，為下列處分，並得命其限期改善，何者錯誤？
  1. (A)命令該證券商解除違法董事、監察人或經理人之職務
  2. (B)對公司或分支機構就其所營業務之全部或一部為三個月以內之停業
  3. (C)對公司或分支機構營業許可之撤銷或廢止
  4. (D)警告
解析

(A)錯誤（此項敘述無誤）。證交法第六十六條明定主管機關得命令證券商解除違法的董事、監察人或經理人職務，這是針對人的處分，用來排除違規決策者而不必停止整個公司營業。

(B)正確（此項敘述有誤）。證交法第六十六條所定的停業處分，是對公司或分支機構就其所營業務的全部或一部為六個月以內的停業，並非三個月以內。停業直接影響客戶交易與公司收入，屬重大處分，法律以明確的期間上限劃出主管機關裁量的邊界，題目把上限縮短為三個月，所以是錯的敘述。

(C)錯誤（此項敘述無誤）。對公司或分支機構營業許可的撤銷或廢止，是第六十六條所列最重的處分，用於情節重大、已不適合繼續經營證券業務的情形。

(D)錯誤（此項敘述無誤）。警告是第六十六條所列最輕的處分，用於情節輕微的違規，並得同時命其限期改善。

10. 當證券商經營證券業務時，禁止下列何項行為？
  1. (A)代客戶保管有價證券、款項、印鑑或存摺
  2. (B)於銀行設立專用之存款帳戶辦理對客戶交割款項之收付
  3. (C)經客戶同意將客戶交割款項留存於證券商交割專戶
  4. (D)於客戶成交後，製作買賣報告書
解析

(A)正確（即禁止之行為）。證券商不得代客戶保管有價證券、款項、印鑑或存摺。禁止的理由在於避免證券商實質控制客戶資產而生挪用風險，客戶資產應與證券商自有財產分離。

(B)錯誤。於銀行設立專用存款帳戶辦理客戶交割款項收付，正是規定所要求之作法。

(C)錯誤。經客戶同意將交割款項留存於證券商交割專戶，屬容許之作法。

(D)錯誤。成交後製作買賣報告書為證券商應盡之義務。

112年第2次｜證券交易相關法規與實務｜第 11 題
11. 證券商稅後盈餘所提列之特別盈餘公積，得為以下何項行為？
  1. (A)繳納稅捐
  2. (B)填補公司虧損
  3. (C)償還負債
  4. (D)酬勞員工
解析

(A)錯誤。稅捐是公司經常性的營業支出，應以當期損益負擔；若允許動用特別盈餘公積繳稅，等於把為虧損準備的緩衝挪作日常開銷，公積很快就會被掏空。

(B)正確。依證交法第四十一條及證券商管理規則，證券商應於每年稅後盈餘提存一定比率的特別盈餘公積，且除填補公司虧損，或特別盈餘公積已達實收資本額一定比率而得以部分撥充資本外，不得使用。其功能是作為證券商發生虧損時的資本緩衝，保障客戶與市場；若可任意動用，強制提列便失去意義。

(C)錯誤。償還負債屬正常的資金調度，應以營運現金流或其他資金來源支應；特別盈餘公積並非償債準備，動用它償債會削弱公司吸收虧損的能力。

(D)錯誤。員工酬勞是盈餘分派的一環，依公司章程從當年度獲利中提撥；特別盈餘公積是已從盈餘中限制起來不得分派的部分，正好與分派給員工的方向相反。

112年第2次｜證券交易相關法規與實務｜第 13 題
12. 證券經紀商實收資本額與提存營業保證金之金額，分別為新臺幣多少？
  1. (A)二億元與四千萬元
  2. (B)四億元與五千萬元
  3. (C)二億元與五千萬元
  4. (D)二億元與二千萬元
解析

(A)正確。融資融券是證券商對「受託買賣」的委託人提供資金或證券的授信，前提是必須有客戶及受託買賣關係，因此辦理信用交易業務的證券商必須經營證券經紀業務。經紀商掌握客戶的委託、交割與帳戶資料，才能對客戶授信並在擔保品不足時執行追繳與處分。

(B)錯誤。公債業務只是自營或經紀業務中的一種標的，並非獨立的證券業務種類，與對客戶授信也沒有關聯。

(C)錯誤。自營業務是證券商以自有資金為自己買賣有價證券，沒有委託人可供授信，所以單純自營商不能辦理融資融券。

(D)錯誤。承銷業務是協助發行人在初級市場銷售有價證券，面對的是發行人與認購人，與次級市場對委託人融通資金或證券無涉。

38. 證券商辦理委託人融資買進與融券賣出沖抵之交易，下列敘述何者錯誤？
  1. (A)應先與客戶簽定概括授權同意書
  2. (B)目前為適用於上市、上櫃股票
  3. (C)自動沖抵委託人不必逐筆申請
  4. (D)資券相抵不必列入當日其融資融券限額內計算
解析

(A)錯誤。此敘述正確，辦理自動沖抵應先與客戶簽定概括授權同意書。

(B)錯誤。此敘述正確，資券相抵目前適用於上市及上櫃股票。

(C)錯誤。此敘述正確，經概括授權後由系統自動沖抵，委託人不必逐筆申請。

(D)正確（即敘述有誤者）。當日相抵的融資買進與融券賣出，仍應分別計入該委託人當日的融資融券限額。額度控管看的是當日實際下單的授信規模，不因盤後互抵而視為未使用。

39. 國內現行當日沖銷交易之股票課徵稅率為：
  1. (A)千分之一
  2. (B)千分之一點五
  3. (C)千分之一點四二五
  4. (D)千分之三
解析

(A)錯誤。千分之一是證券交易稅條例對公司債、金融債券以外的其他有價證券（如受益憑證、ETF）所定的稅率，並非股票當日沖銷交易適用的稅率。

(B)正確。依證券交易稅條例，現股當日沖銷交易的股票證券交易稅減半課徵，稅率為賣出金額的千分之一點五。一般賣出股票的稅率為千分之三，當沖減半是為降低短線交易成本、提升市場流動性的租稅措施，且屬有期限的暫時規定，主管機關已多次延長。

(C)錯誤。千分之一點四二五是證券商受託買賣的手續費上限費率，買進與賣出時各收一次，屬證券商的收入，不是政府課徵的證券交易稅。

(D)錯誤。千分之三是一般（非當沖）賣出股票的證券交易稅率，於賣出時由證券商代徵；當沖交易是在此稅率基礎上減半。

40. 證券商辦理有價證券借貸業務與辦理有價證券買賣融資融券業務，對每種證券出借與融券總金額合計不得超過其淨值：
  1. (A)3%
  2. (B)5%
  3. (C)6%
  4. (D)10%
解析

(A)錯誤。百分之三並非證券商辦理借貸與融資融券業務所定的每種證券出借與融券合計上限；上限過低會使券商幾乎無法對熱門股提供融券，信用交易市場會失去功能。

(B)正確。依證券商辦理有價證券借貸管理辦法及融資融券管理辦法，證券商對每種證券的出借與融券總金額合計，不得超過其淨值的百分之五。這是單一標的的集中度上限，避免券商在個別股票上承擔過度集中的券源與回補風險；出借與融券合併計算，是因兩者都是把券借出去，暴露的風險相同。

(C)錯誤。百分之六不是任何一項融資融券或借貸業務的比率；證券商對個股的限額只有融資百分之十與出借加融券百分之五兩個數字。

(D)錯誤。百分之十是證券商對每種證券「融資」總金額不得超過淨值的比率；題目問的是出借與融券合計，其上限是較低的百分之五，因為借出證券的回補風險比借出資金更難控制。
