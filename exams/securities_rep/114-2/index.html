1. 股東就其持有之股份於一定條件下，得分別行使表決權，有人亦稱之「股東分割投票制度」。依現行法相關適用「股東分割投票制度」之股東，下列敘述何者正確？
  1. (A)需為公開發行公司之股東
  2. (B)以自然人股東為限
  3. (C)需係為自己持有股份之股東
  4. (D)需為持有公司已發行股份總數百分之十以上股份之股東
解析

(A)正確。表決權分別行使（股東分割投票）的規定，適用對象限於公開發行公司之股東。之所以限於公開發行公司，是因這類公司常有信託業、保管機構等替多位實質受益人集中持股的情形，若只能整批同向投票，將無法反映背後不同投資人的意向。

(B)錯誤。適用對象並不以自然人股東為限，實務上多為法人（如信託或保管機構）。

(C)錯誤。恰好相反，須為「為他人」持有股份之股東，才有將表決權分別行使的必要。

(D)錯誤。並無須持有已發行股份總數百分之十以上之持股門檻。

2. 股份有限公司於章程訂明以當年度獲利狀況之定額或比率，分派員工酬勞，應於多少比例之董事出席，並在董事會過半數同意後決議行之？
  1. (A)三分之一
  2. (B)二分之一
  3. (C)三分之二
  4. (D)全數
解析

(A)錯誤。三分之一之出席門檻低於法定要求，本項決議須三分之二以上董事出席。

(B)錯誤。二分之一為一般董事會決議之出席門檻，員工酬勞分派須三分之二以上董事出席。

(C)正確。章程訂明以當年度獲利之定額或比率分派員工酬勞者，應有三分之二以上董事出席、出席董事過半數同意之董事會決議。提高出席門檻是因該事項直接分配公司盈餘，影響股東權益。

(D)錯誤。法令未要求全體董事出席，門檻為三分之二以上出席、出席董事過半數同意。

114年第2次｜證券交易相關法規與實務｜第 2 題
3. 有關股東會之決議，對公司已發行股份之總數及表決權數之計算，下列敘述何者正確？甲、無表決權股東之股份不算入已發行股份總數；乙、對表決事項有自身利害關係而不得行使表決權之股份數，不算入已發行股份總數
  1. (A)僅甲對
  2. (B)僅乙對
  3. (C)甲、乙皆正確
  4. (D)甲、乙皆錯誤
解析

(A)正確。無表決權股東之股份不算入已發行股份總數；至於因自身利害關係不得行使表決權者，其股份僅不算入出席股東之表決權數，仍計入已發行股份總數，故僅甲正確。

(B)錯誤。乙之敘述誤把「不算入表決權數」擴張為「不算入已發行股份總數」。

(C)錯誤。乙有誤，因利害關係不得行使表決權之股份仍計入已發行股份總數，故非兩者皆對。

(D)錯誤。甲之敘述與規定相符，並非兩者皆錯。

5. 已依證交法發行之公司得於一定條件下對特定人招募有價證券，稱之為何種行為？
  1. (A)私募
  2. (B)公開募集

  4. (D)掛牌
解析

(A)正確。已依證交法發行之公司對特定人招募有價證券者為私募。私募對象具備風險辨識能力，故免除公開募集的申報生效程序，但相對受轉售之限制。

(C)錯誤。發行指製作並交付有價證券之行為，非招募方式之名稱。

(D)錯誤。掛牌指有價證券在市場開始交易，與招募行為無涉。

7. 下列何者無須經審計委員會同意？
  1. (A)重大之資金貸與
  2. (B)私募可轉換公司債

114年第2次｜證券交易相關法規與實務｜第 7 題
8. 依我國證券交易法規定選任獨立董事公開發行股份有限公司，有重大之資產或衍生性商品交易事項於提董事會討論時，如獨立董事有反對意見或保留意見，請問應如何處理？
  1. (A)董事會議不得為決議
  2. (B)董事會議所為決議無效
  3. (C)應於董事會議事錄記載
  4. (D)董事會議所為決議得撤銷
解析

(A)錯誤。獨立董事之反對意見不影響董事會之議決能力，會議仍得依法作成決議。

(B)錯誤。決議不因獨立董事持反對意見而無效，法定效果是將其意見載明於議事錄。

(C)正確。獨立董事有反對或保留意見者，應於董事會議事錄載明。獨立董事的監督功能在於留下可追溯的意見紀錄，供股東與主管機關事後檢視，而非賦予其否決權。

(D)錯誤。法無因獨立董事反對即得撤銷董事會決議之規定，其意見僅須載明議事錄。

9. 對非特定人公開招募者，應檢具有價證券公開招募申報書連同應檢附書件，向金管會___後，於金管會及其指定機構收到有價證券公開招募申報書之日起屆滿___生效？

114年第2次｜證券交易相關法規與實務｜第 10 題
11. 下列敘述何者錯誤？
  1. (A)主管機關於審查發行人所申報之財報時，若發現發行人有不合法規之事項，得處以命令糾正
  2. (B)發行人不得以有價證券募集之核准，作為保證證券價值之宣傳
  3. (C)有價證券募集之核准，得藉以作為證實申請事項
  4. (D)有價證券發行後，主管機關得隨時命令發行人提出財務、業務報告
解析

(A)錯誤。此敘述無誤，主管機關審查申報之財務報告發現不符法令者，得命令發行人糾正。

(B)錯誤。此敘述無誤，法令明文禁止發行人以募集核准作為保證證券價值之宣傳。

(C)正確（即敘述有誤者）。核准募集僅代表申報書件形式與程序符合規定，主管機關並未擔保內容真實或證券價值，故不得藉以作為證實申請事項之宣傳。

(D)錯誤。此敘述無誤，有價證券發行後主管機關仍得隨時命令發行人提出財務、業務報告以持續監理。

114年第2次｜證券交易相關法規與實務｜第 13 題
14. 證券商除由金融機構兼營者依有關法令規定外，其經營自行買賣有價證券業務者，持有單一證券商所發行普通公司債之投資成本總額，不得超過該證券商淨值之___；持有所有證券商所發行普通公司債之投資成本總額，不得超過該證券商淨值之___？
  1. (A)5%；10%
  2. (B)5%；20%
  3. (C)10%；15%
  4. (D)10%；20%
解析
