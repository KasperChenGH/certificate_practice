1. 股東就其持有之股份於一定條件下，得分別行使表決權，有人亦稱之「股東分割投票制度」。依現行法相關適用「股東分割投票制度」之股東，下列敘述何者正確？
  1. (A)需為公開發行公司之股東
  2. (B)以自然人股東為限
  3. (C)需係為自己持有股份之股東
  4. (D)需為持有公司已發行股份總數百分之十以上股份之股東
解析

(A)正確。表決權分別行使（股東分割投票）的規定，適用對象限於公開發行公司之股東。之所以限於公開發行公司，是因這類公司常有信託業、保管機構等替多位實質受益人集中持股的情形，若只能整批同向投票，將無法反映背後不同投資人的意向。

(B)錯誤。適用對象並不以自然人股東為限，實務上多為法人（如信託或保管機構）。

(C)錯誤。恰好相反，須為「為他人」持有股份之股東，才有將表決權分別行使的必要。

(D)錯誤。並無須持有已發行股份總數百分之十以上之持股門檻。

2. 股份有限公司於章程訂明以當年度獲利狀況之定額或比率，分派員工酬勞，應於多少比例之董事出席，並在董事會過半數同意後決議行之？
  1. (A)三分之一
  2. (B)二分之一
  3. (C)三分之二
  4. (D)全數
解析

(A)錯誤。三分之一之出席門檻低於法定要求，本項決議須三分之二以上董事出席。

(B)錯誤。二分之一為一般董事會決議之出席門檻，員工酬勞分派須三分之二以上董事出席。

(C)正確。章程訂明以當年度獲利之定額或比率分派員工酬勞者，應有三分之二以上董事出席、出席董事過半數同意之董事會決議。提高出席門檻是因該事項直接分配公司盈餘，影響股東權益。

(D)錯誤。法令未要求全體董事出席，門檻為三分之二以上出席、出席董事過半數同意。

114年第2次｜證券交易相關法規與實務｜第 2 題
3. 有關股東會之決議，對公司已發行股份之總數及表決權數之計算，下列敘述何者正確？甲、無表決權股東之股份不算入已發行股份總數；乙、對表決事項有自身利害關係而不得行使表決權之股份數，不算入已發行股份總數
  1. (A)僅甲對
  2. (B)僅乙對
  3. (C)甲、乙皆正確
  4. (D)甲、乙皆錯誤
解析

(A)正確。公司法第180條分兩層規定：無表決權股東的股份數，不算入已發行股份之總數（甲正確）；對表決事項有自身利害關係而不得行使表決權的股份數，則是不算入「已出席股東之表決權數」，仍計入已發行股份總數（乙錯誤）。無表決權股本來就永遠不能投票，所以從分母整體剔除；利害關係股只是就特定議案迴避，它的持有人仍可出席並就其他議案投票，因此只從該議案的表決權數中扣除。

(B)錯誤。乙的敘述把「不算入已出席股東之表決權數」擴張成「不算入已發行股份總數」；利害關係股只就特定議案迴避，不影響已發行股份總數的計算，因此乙錯而甲對。

(C)錯誤。甲正確但乙錯誤：因自身利害關係不得行使表決權的股份仍計入已發行股份總數，只是不算入出席股東的表決權數，兩者的扣除位置不同，不能說皆正確。

(D)錯誤。甲的敘述與公司法第180條第1項相符，無表決權股份確實不算入已發行股份總數，因此不是兩者皆錯。

4. 下列哪一種不是「證券交易法」第18 條所稱證券服務事業？

(D)錯誤。證券集中保管公司提供保管與帳簿劃撥服務，屬證券服務事業。

5. 已依證交法發行之公司得於一定條件下對特定人招募有價證券，稱之為何種行為？
  1. (A)私募
  2. (B)公開募集
  3. (C)發行
  4. (D)掛牌
解析

(A)正確。證券交易法第7條將「私募」定義為已依本法發行股票之公司依第43條之6規定，對特定人招募有價證券之行為。私募對象限於銀行等金融機構、符合條件的法人或自然人及公司內部人，這些人具備風險辨識與承擔能力，因此免除公開募集的申報生效程序與公開說明書，但相對地所取得的有價證券受轉售限制，以防止私募成為規避公開發行審查的管道。

(B)錯誤。公開募集（募集）是對非特定人公開招募有價證券，須向主管機關申報生效並交付公開說明書；題目所述「對特定人」招募正好與公開募集相反。

(C)錯誤。發行是指發行人於募集後製作並交付有價證券的行為，是招募完成後的下一步，不是對特定人或非特定人招募的方式名稱。

(D)錯誤。掛牌是有價證券在證交所或櫃買中心開始交易的通稱，屬次級市場的程序，與向誰招募資金的發行市場行為無關。

6. 以竊取、毀壞或其他非法方法危害證券交易所、證券櫃檯買賣中心或證券集中保管事業之核心資通系統設備功能正常運作者，依「證券交易法」有何刑事處罰？
  1. (A)處一年以上七年以下有期徒刑，得併科新臺幣一千萬元以下罰金
  2. (B)處一年以上七年以下有期徒刑，得併科新臺幣五千萬元以下罰金
  3. (C)處三年以上十年以下有期徒刑，得併科新臺幣一千萬元以下罰金
  4. (D)處三年以上十年以下有期徒刑，得併科新臺幣五千萬元以下罰金

(D)錯誤。刑度與罰金額度均非本罪所定，本罪為一年以上七年以下並得併科一千萬元以下罰金。

7. 下列何者無須經審計委員會同意？
  1. (A)重大之資金貸與
  2. (B)私募可轉換公司債
  3. (C)財務、會計或內部稽核主管之任免

8. 依我國證券交易法規定選任獨立董事公開發行股份有限公司，有重大之資產或衍生性商品交易事項於提董事會討論時，如獨立董事有反對意見或保留意見，請問應如何處理？
  1. (A)董事會議不得為決議
  2. (B)董事會議所為決議無效
  3. (C)應於董事會議事錄記載
  4. (D)董事會議所為決議得撤銷
解析

(A)錯誤。獨立董事之反對意見不影響董事會之議決能力，會議仍得依法作成決議。

(B)錯誤。決議不因獨立董事持反對意見而無效，法定效果是將其意見載明於議事錄。

(C)正確。獨立董事有反對或保留意見者，應於董事會議事錄載明。獨立董事的監督功能在於留下可追溯的意見紀錄，供股東與主管機關事後檢視，而非賦予其否決權。

(D)錯誤。法無因獨立董事反對即得撤銷董事會決議之規定，其意見僅須載明議事錄。

9. 對非特定人公開招募者，應檢具有價證券公開招募申報書連同應檢附書件，向金管會___後，於金管會及其指定機構收到有價證券公開招募申報書之日起屆滿___生效？
  1. (A)申報生效；七個營業日
  2. (B)申報核准；七個營業日
  3. (C)申報生效；十個營業日
  4. (D)申報核准；十個營業日
解析

(A)正確。對非特定人公開招募採申報生效制，自金管會及其指定機構收到申報書之日起屆滿七個營業日生效。申報生效制由發行人對資訊真實性負責，主管機關不作實質價值認可。

(B)錯誤。現行制度為申報生效而非申報核准，主管機關不對證券價值作實質認可。

(C)錯誤。制度名稱為申報生效無誤，但生效期間為七個營業日而非十個營業日。

(D)錯誤。制度名稱與生效期間均不正確，應為申報生效並屆滿七個營業日生效。

114年第2次｜證券交易相關法規與實務｜第 9 題
10. 甲為Z 上市公司之獨立董事，持有Z 公司已發行股份20 萬股。若甲於民國113 年11 月1日將所持有之股票10 萬股向X 商業銀行質押借款，下列敘述，何者正確？
  1. (A)Z 公司應於甲將股票質權設定後五日內，將甲之出質情形，向主管機關申報並公告之
  2. (B)甲應於同年11 月15 日以前將持有股數設質之情形，通知公司
  3. (C)甲應於同年12 月5 日以前將持有股票設質之情形，向公司申報
  4. (D)Z 公司應於同年12 月15 日以前，彙總向主管機關申報
解析

(A)正確。證券交易法第25條就董事、監察人、經理人及大股東的股票設質另設一套快速揭露程序：出質人應即通知公司，公司應於質權設定後五日內將出質情形向主管機關申報並公告。甲於11月1日設質，Z公司即應在設質後五日內申報公告。內部人大量質押往往預告其資金壓力與可能的斷頭賣壓，市場需要及時而非按月得知。

(B)錯誤。設質的通知義務是「應即通知公司」，沒有兩週的緩衝；11月15日才通知，等於把設質當成一般持股變動的月報事項，會延誤公司五日內申報公告的時點。

(C)錯誤。「次月五日以前向公司申報」是證交法第25條針對上月份持有股數變動的月報程序；設質並不改變持股數，且法律要求即時通知，不適用這個月報期限。

(D)錯誤。「次月十五日以前彙總向主管機關申報」同樣是持股變動月報中公司端的期限；設質情形是公司在設質後五日內個別申報並公告，不是併入月報彙總。

11. 下列敘述何者錯誤？
  1. (A)主管機關於審查發行人所申報之財報時，若發現發行人有不合法規之事項，得處以命令糾正
  2. (B)發行人不得以有價證券募集之核准，作為保證證券價值之宣傳
  3. (C)有價證券募集之核准，得藉以作為證實申請事項
  4. (D)有價證券發行後，主管機關得隨時命令發行人提出財務、業務報告

(A)錯誤。此敘述無誤，主管機關審查申報之財務報告發現不符法令者，得命令發行人糾正。

(B)錯誤。此敘述無誤，法令明文禁止發行人以募集核准作為保證證券價值之宣傳。

114年第2次｜證券交易相關法規與實務｜第 11 題
12. 依「證券交易法」及「公開發行公司董事監察人股權成數及查核實施規則」規定，公開募集及發行有價證券之公司，公司實收資本額在新臺幣三億元以下者(無選任獨立董事)，全體董事所持有記名股票之股份總額不得少於公司已發行股份總額___，全體監察人不得少於___？
  1. (A)5%；0.5%
  2. (B)7.5%；0.75%
  3. (C)10%；0.1%
  4. (D)15%；1.5%
解析

(A)錯誤。5%與0.5%是實收資本額超過二十億至四十億元公司適用的成數；資本額愈大，董監所需持股成數愈低，三億元以下的公司用的是最高的一級。

(B)錯誤。7.5%與0.75%對應的是實收資本額超過十億至二十億元的級距；套到三億元以下的小公司會低估其董監應持有的股份。

39. 證券商非經下列何單位許可，並與證券櫃檯買中心簽訂證券商經營櫃檯買賣有價證券契約，不得經營櫃檯買賣業務？
  1. (A)財政部
  2. (B)金管會
  3. (C)中央銀行
  4. (D)經濟部
解析

(A)錯誤。財政部是金管會於民國93年成立前的證券主管機關，證券商業務許可權早已移轉給金管會，現行法規已不再由財政部許可。

(B)正確。證券商經營櫃檯買賣業務須經金管會許可，並與證券櫃檯買賣中心簽訂證券商經營櫃檯買賣有價證券契約。許可是主管機關對業務准入的公權力把關，契約則規範使用市場的權利義務，二者缺一不可。

(C)錯誤。中央銀行主管貨幣與外匯事務，證券商只有在業務涉及資金匯出入時才須向央行申請許可，經營櫃檯買賣本身不歸央行管。

(D)錯誤。經濟部主管公司登記與商業事務，證券商的公司設立登記雖由經濟部辦理，但證券業務的許可屬金管會權限。

40. 證券商經營櫃檯買賣，下列敘述何者正確？
  1. (A)證券承銷商不得自行買入或賣出，但得代客買賣
  2. (B)證券自營商，應自行買入或賣出，亦得代客買賣
  3. (C)證券經紀商，應自行買入或賣出，但不得代客買賣
  4. (D)兼具證券自營商及經紀商者，於每次買賣時之書面文件區別自行或代客買賣
解析

(A)錯誤。證券承銷商不得經營櫃檯買賣之自行買賣或受託買賣，並非「得代客買賣」。

(B)錯誤。自營商僅得自行買入賣出，不得受託代客買賣。

(C)錯誤。敘述顛倒，經紀商係受託代客買賣，不得自行買賣。

(D)正確。兼具自營與經紀身分者，應於每次買賣之書面文件載明係自行或代客買賣。此為防止證券商在自有部位與客戶委託間搶帽子或對作的基本區隔要求。

41. 下列何者之交易方式不屬於與推薦證券商或造市商議價交易？

  3. (C)登錄於櫃買中心「開放式基金受益憑證交易平台」之基金
  4. (D)登錄於櫃買中心「黃金現貨交易平台」之黃金

(A)正確（即不屬議價交易者）。上櫃股票採等價成交系統以電腦自動撮合，屬競價交易，與興櫃等須向推薦證券商或造市商議價的模式不同。

(B)錯誤。興櫃股票由推薦證券商報價，投資人與其議價成交。

(C)錯誤。開放式基金受益憑證交易平台係與造市商議價成交。

42. 指數股票型證券投資信託基金(ETF)受益憑證通常須上市滿多久，才能進行融資融券交易？
  1. (A)3 個月
  2. (B)6 個月
  3. (C)12 個月
  4. (D)無限制
解析

(A)錯誤。3個月不是任何信用交易資格的觀察期；一般股票要求上市滿六個月，ETF則完全沒有期間限制。

(B)錯誤。上市滿六個月是一般上市股票得為融資融券的條件之一，用來觀察新股的價格與財務表現；ETF不適用這項個股門檻。

(C)錯誤。12個月並非ETF或個股得為信用交易的條件；把ETF想成需要更長觀察期，反而與其風險較分散的特性相反。

(D)正確。依有價證券得為融資融券標準，ETF受益憑證得為融資融券交易，不受上市滿一定期間的限制。個股設掛牌期間門檻是要觀察其價格與財務體質，ETF追蹤指數、成分分散且淨值透明，不存在同樣的個別公司風險，故無須觀察期。

43. 目前證券商營業處所受託買賣有價證券的交易手續費上限為多少？
  1. (A)千分之一點四二五
  2. (B)千分之一點五
  3. (C)千分之一
  4. (D)千分之二
解析

(A)正確。營業處所受託買賣有價證券之手續費上限為千分之一點四二五，與集中交易市場一致。設定上限可避免經紀商對投資人超收，實務上多在此上限內折讓競爭。

(B)錯誤。千分之一點五高於法定上限，受託買賣手續費上限為千分之一點四二五。

(C)錯誤。千分之一為部分券商折讓後之實收費率，並非法規所定之費率上限。

(D)錯誤。千分之二高於法定上限，受託買賣手續費上限為千分之一點四二五。
