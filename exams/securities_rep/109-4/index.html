1. 依「證券交易法」第6 條規定，下列何者視為有價證券？
  1. (A)利率交換契約
  2. (B)匯票
  3. (C)支票
  4. (D)新股權利證書
解析

(A)錯誤。利率交換契約是衍生性金融商品，由銀行或期貨相關法規管理，證券交易法第6條的有價證券範圍不包含此類契約。

(B)錯誤。匯票是票據法規範的票據，屬支付與信用工具，證券交易法未將票據納入有價證券的範圍。

(C)錯誤。支票同樣是票據法上的支付工具，用於付款而非表彰投資性權利，不屬於證券交易法的有價證券。

(D)正確。證券交易法第6條第2項明定，新股認購權利證書、新股權利證書及各種有價證券的價款繳納憑證或表明其權利的證書，視為有價證券。這些憑證雖然還不是股票本身，卻已表彰取得股票的權利並可流通，若不納入管理，就能以憑證形式規避發行與交易的規範。

2. 依公司法規定，持有已發行股份總數超過百分之__之股東，須申報至中央主管機關建置或指定之資訊平臺；其有變動，應於變動後__日內為之？
  1. (A)十，十五
  2. (B)十，十
  3. (C)十五，十五
  4. (D)十五，十
解析

(A)正確。公司法第22-1條規定，持有已發行股份總數超過百分之十的股東，公司應申報至中央主管機關建置或指定的資訊平臺；其有變動者，應於變動後十五日內申報。此制度是為了讓公司的實質控制者透明化，配合防制洗錢與打擊資恐的國際要求。

(B)錯誤。門檻百分之十正確，但變動後的申報期間是十五日而非十日；十五日與公司登記事項變更後應辦理變更登記的期限一致，十日則短於此。

(C)錯誤。申報門檻是超過百分之十，不是百分之十五；若門檻訂在百分之十五，持股一成多的實質控制者就不必揭露，透明化的目的會打折扣。

(D)錯誤。門檻與期間都不對：門檻是百分之十而非十五，變動後申報期間是十五日而非十日。

3. 下列關於公司負責人之敘述，何者錯誤?
  1. (A)公司之非董事，而實質上執行董事業務，與公司法董事同負民事、刑事及行政罰之責任
  2. (B)在執行職務範圍內，公司之清算人為公司負責人
  3. (C)有限公司、股份有限公司之負責人為董事
  4. (D)重整監督人在執行職務範圍時，不屬於公司負責人
解析

(A)錯誤（此敘述正確）。實質上執行董事業務之人（實質董事）與董事同負民事、刑事及行政罰責任。

(B)錯誤（此敘述正確）。清算人於執行職務範圍內為公司負責人。

(C)錯誤（此敘述正確）。有限公司與股份有限公司之負責人為董事。

(D)正確（即敘述有誤者）。重整人與重整監督人在執行職務範圍內，同屬公司負責人。公司負責人分為「當然負責人」（如董事）與「職務負責人」（經理人、清算人、重整人、重整監督人、檢查人等），後者以是否在執行公司職務範圍內為判準。

4. 公開發行公司內部稽核單位作成之稽核報告、工作底稿及相關資料應至少保存幾年？
  1. (A)三年
  2. (B)四年
  3. (C)五年
  4. (D)七年
解析

(A)錯誤。三年短於規定的年限；內控缺失往往在數年後才被揭露，若稽核報告與底稿只保存三年，事後追查時可能已經銷毀。

(B)錯誤。四年不是規定的年限，也不對應內控制度中任何保存期間，它只是介於三年與五年之間的數字。

(C)正確。依公開發行公司建立內部控制制度處理準則，內部稽核單位作成的稽核報告、工作底稿及相關資料至少應保存五年。保存期間訂得長，是為了讓主管機關與會計師事後仍能追查內控缺失及其改善追蹤紀錄，五年也與商業會計法對會計憑證的保存年限一致。

(D)錯誤。七年是美國沙賓法對審計工作底稿要求的保存年限，我國內控處理準則對稽核報告與底稿的最低保存年限是五年。

5. 上市公司持股超過百分之十之大股東，得於申報之日起幾日後，依主管機關所定持有期間及每一交易日得轉讓數量比例在集中市場轉讓持股？
  1. (A)二日
  2. (B)三日
  3. (C)四日
  4. (D)五日
解析

(A)錯誤。二日是證券交易法第36條公司財報不一致或發生重大事項時的公告申報期限，不是大股東轉讓持股的等待期間。

(B)正確。依證券交易法第22-2條，持股超過百分之十的大股東要在集中市場轉讓持股，應先向主管機關申報，並於申報之日起三日後，依主管機關所定持有期間及每一交易日得轉讓數量比例轉讓。先申報再等待三日，是要讓市場先取得內部人即將出脫的資訊，避免大額轉讓對股價造成突襲。

(C)錯誤。四日不對應證交法內部人持股相關的任何期限；等待期間是三日，四日只是多一天的干擾數字。

(D)錯誤。五日是證券交易法第28-2條公司買回股份執行完畢後向主管機關申報的期限，用在庫藏股，不是大股東轉讓持股的等待期間。

6. 證券商從事具有股權性質之投資，其轉投資總金額不得超過證券商淨值百分之多少？
  1. (A)二十
  2. (B)四十
  3. (C)五十
  4. (D)七十
解析

(A)錯誤。百分之二十低於規定的上限；若限制到兩成，證券商設立子公司或投資期貨、投信等關聯事業的空間會過小，規定並未訂得這麼嚴。

(B)正確。依證券商管理規則第18-1條，證券商轉投資證券、期貨、金融及其他事業，其全部事業投資總金額不得超過該證券商淨值的百分之四十，並應符合公司法第13條的規定。以淨值設限，是避免自有資本過度暴露於權益部位的風險，確保證券商保有足夠資本履行交割與營運義務。

(C)錯誤。百分之五十等於淨值的一半，超過規定的四成；若轉投資可占淨值一半，證券商自有資本承受子公司虧損的緩衝就太薄。

(D)錯誤。百分之七十不是規定的比率；轉投資占淨值七成時，證券商本業的資本幾乎都押在子公司身上，主管機關不會允許這樣的集中風險。

7. 為促進我國普惠金融與金融科技發展，下列何者可依金融科技發展與創新實驗條例申請辦理證券業務創新實驗？
  1. (A)證券商
  2. (B)證券金融事業
  3. (C)科技業
  4. (D)以上皆可進行申請
解析

(A)錯誤。證券商固然可以申請，但申請資格不以證券商為限。

(B)錯誤。證券金融事業可以申請，但答案不以其為限。

(C)錯誤。科技業可以申請，但答案不以其為限。

(D)正確。金融科技發展與創新實驗條例對申請人採開放設計，不以持牌金融機構為限，故證券商、證券金融事業與科技業均得申請辦理證券業務創新實驗。開放非金融業申請，正是監理沙盒鼓勵跨業創新的用意。

8. 公司買回股份應自申報日起多久執行完畢？
  1. (A)一個月
  2. (B)二個月
  3. (C)三個月
  4. (D)四個月
解析

(A)錯誤。一個月短於規定的期間；買回股份需在市場上分批進行，若只給一個月，公司為了在期限內買足可能集中買進而影響股價，規定給的是兩個月。

(B)正確。依證券交易法第28-2條，公司買回自己股份應於向主管機關申報之日起二個月內執行完畢，並於期間屆滿或執行完畢後五日內向主管機關申報執行情形。設定兩個月的期限，是防止公司長期以買回宣告支撐股價卻遲不執行，也讓市場能在確定期間內評估買回的影響。

(C)錯誤。三個月比規定多了一個月；期間愈長，公司利用買回宣告影響股價卻不真正執行的空間愈大，規定將期限壓在兩個月。

(D)錯誤。四個月不是規定的期間；買回股份的執行期限是兩個月，四個月等於允許公司拖延一整個季度以上，違背限期執行的目的。

9. 依「公司法」規定，董事任期不得超過幾年，但連選得連任？
  1. (A)一年
  2. (B)二年
  3. (C)三年
  4. (D)四年
解析

(A)錯誤。一年短於公司法所定的任期上限；若每年都要改選董事，經營政策難以延續，公司法給的上限是三年。

(B)錯誤。二年不是公司法的任期上限；公司可以在章程中訂較短的任期，但法定上限是三年，題目問的是上限。

(C)正確。公司法第195條規定董事任期不得逾三年，但連選得連任，監察人的任期也是同樣的上限。設有任期上限，是讓股東能定期以改選檢驗並更換經營者，連選得連任則保留經營的延續性。

(D)錯誤。四年超過公司法允許的上限；任期愈長股東更換不適任董事的機會愈少，公司法將上限定在三年。

10. 股東會決議對董事提起訴訟，公司應自決議之日起多久時間內提起？
  1. (A)三十日
  2. (B)六十日
  3. (C)九十日
  4. (D)六個月
解析

(A)正確。公司法第212條規定，股東會決議對董事提起訴訟時，公司應自決議之日起三十日內提起。期間定得短，是避免公司拖延而使追訴實益流失；公司逾期未提，監察人或符合資格的少數股東另有代表公司訴訟的途徑。

(B)錯誤。六十日比規定多了一倍；股東會既已決議追訴，程序上不需要兩個月準備，拖得愈久董事愈有時間處分財產或湮滅證據。

(C)錯誤。九十日等於一整季，公司法對股東會決議後提起訴訟的期限沒有這麼長，這只是三十日的三倍干擾數字。

(D)錯誤。六個月是公司法第214條少數股東請求監察人對董事提起訴訟時，必須「繼續六個月以上」持有股份的持股期間要件，不是公司提起訴訟的期限。

11. 已設置審計委員會之公開發行公司，依法應經審計委員會決議之特定事項，應得全體委員多少比例之同意？
  1. (A)四分之三
  2. (B)三分之二
  3. (C)二分之一
  4. (D)全體成員
解析

(A)錯誤。四分之三不是審計委員會的決議門檻；證交法對審計委員會採全體成員過半數同意，沒有訂到四分之三這麼高的特別多數。

(B)錯誤。三分之二是證券交易法第14-5條第2項的門檻：應經審計委員會決議的事項未獲其全體成員二分之一以上同意時，得由全體董事三分之二以上同意行之，那是董事會的替代門檻，不是審計委員會本身的門檻。

(C)正確。依證券交易法第14-5條，應經審計委員會決議的事項須經審計委員會全體成員二分之一以上同意，並提董事會決議；未獲同意者，得由全體董事三分之二以上同意行之。門檻以全體成員而非出席成員計算，可防止低出席率稀釋監督強度。

(D)錯誤。法律並不要求全體成員一致同意；若採一致決，任何一位獨立董事都能單獨否決，反而使委員會難以運作。

12. 依現行「證券交易法」之規定，公司設置審計委員會者，其成員為何？
  1. (A)獨立董事三人與常務董事二人
  2. (B)獨立董事一人與常務董事二人
  3. (C)獨立董事二人與常務董事一人
  4. (D)由全體獨立董事組成
解析

(A)錯誤。審計委員會的成員全部必須是獨立董事，常務董事屬經營階層，不能加入；獨立董事三人雖符合最低人數，加上常務董事就不合規定。

(B)錯誤。常務董事不得擔任審計委員會成員，且獨立董事只有一人也不足法定的三人下限。

(C)錯誤。常務董事不得加入審計委員會，獨立董事二人也未達三人的最低人數。

(D)正確。依證券交易法第14-4條，審計委員會應由全體獨立董事組成，人數不得少於三人，其中一人為召集人，且至少一人應具備會計或財務專長。全部由獨立董事組成，才能維持對經營階層的獨立監督，發揮取代監察人的功能。

13. 發行人交付之公開說明書因內容虛偽、隱匿而致生損害善意相對人者，其民事制度採下列何種責任？

(A)錯誤。3個營業日對應的是連續三個營業日被列為注意股票即進入處置的觸發條件，不是處置本身持續的期間；若處置只有三天，降溫效果尚未發揮就已解除。

(B)錯誤。在題目當時的規定下，5對應的是第一次處置期間約每五分鐘撮合一次的間隔，而非處置天數；不過依115年8月10日起實施的新制，處置期間已縮短為5個營業日，作答仍以題目當時的十日規定為準。

(C)正確。依當時規定，櫃檯買賣有價證券於最近30個營業日內第一次被列為處置股票者，櫃買中心自次一營業日起10個營業日，改以人工管制之撮合終端機執行撮合，約每五分鐘撮合一次並得預收款券。放慢撮合節奏可降低短線追價與炒作，若30個營業日內第二次被處置則加重管制。此規定自115年8月10日起已修正，處置期間縮短為5個營業日並統一約每2分鐘撮合一次。

(D)錯誤。15個營業日超過第一次處置的期間，處置的目的是短期冷卻過熱交易而非長期限制，時間過長會妨礙正常投資人的交易；即使是加重管制的第二次處置，舊制也是10個營業日。

38. 櫃買中心繼續提列特別給付結算基金之上限為多少？
  1. (A)新臺幣一億元
  2. (B)新臺幣三億元
  3. (C)新臺幣六億元
  4. (D)新臺幣十億元
解析

(A)錯誤。新臺幣一億元是櫃買中心首次提撥特別給付結算基金的金額，繼續提撥部分另有上限，兩者合計四億元；把首次提撥額誤當成繼續提撥上限就會選到此項。

(B)正確。櫃買中心提撥之特別給付結算基金包括首次提撥一億元及繼續提撥上限三億元，合計四億元，與證券商提撥部分共同組成共同責任制給付結算基金，作為證券商履行給付結算義務的擔保。設定上限是因該基金屬證券商違約時的補充財源，主要責任仍由證券商依規模與風險值提撥承擔，無須無限累積而閒置資金。

(C)錯誤。新臺幣六億元高於繼續提撥的上限，若以此為準，櫃買中心自有提撥將超過一億加三億的四億元總額，與基金以證券商提撥為主的設計不符。

(D)錯誤。新臺幣十億元已接近整個共同責任制給付結算基金規模的一半，遠超過櫃買中心繼續提撥三億元的上限；基金主要來源是證券商依家數與交易量提撥的部分，不是櫃買中心自有資金。

39. 櫃檯買賣證券經紀商因執行受託買賣發生錯誤，須為買回、轉賣者，應如何處理？
  1. (A)於發生錯誤兩日內以錯帳處理專戶為之
  2. (B)於發生錯誤次一營業日以違約處理專戶為之
  3. (C)於發生錯誤當日或次一營業日以任一客戶之買賣帳戶為之
  4. (D)於發生錯誤當日或次一營業日以錯帳處理專戶為之
解析

(A)錯誤。使用錯帳處理專戶的方向對，但處理期限並非發生錯誤後兩日內，而是當日或次一營業日。

(B)錯誤。違約處理專戶是處理客戶不履行交割之用；經紀商自身受託作業錯誤應走錯帳專戶，兩種專戶性質不同。

(C)錯誤。錯帳絕不得掛入任何客戶帳戶，否則等於以客戶名義承擔券商的作業過失，必須使用專設之錯帳處理專戶。

(D)正確。受託買賣發生錯誤而須買回或轉賣者，應於發生錯誤當日或次一營業日以錯帳處理專戶為之。設專戶的用意在於把券商自身的作業錯誤與客戶帳戶完全隔離，並留下可稽核的軌跡。

40. 目前證券商營業處所受託買賣有價證券的交易手續費上限為多少？
  1. (A)千分之零點二八
  2. (B)千分之一點四二五
  3. (C)千分之一
  4. (D)千分之三
解析

(A)錯誤。千分之零點二八約為上限的五分之一，若把手續費上限訂在這個水準，經紀業務將難以支應人員、系統與交易所經手費等成本，券商也失去折讓競爭的空間。

(B)正確。證券商營業處所受託買賣有價證券之手續費，上限為成交金額千分之一點四二五，證券商得在此上限內自行議定折讓。訂定上限是為了防止經紀商利用通路地位向投資人收取過高費用，同時保留折扣空間讓券商以價格競爭。

(C)錯誤。千分之一是指數股票型基金及認購（售）權證等賣出時適用的證券交易稅稅率，是繳給國庫的稅，不是券商收取的手續費上限。

(D)錯誤。千分之三是賣出股票時課徵的證券交易稅稅率，由賣方負擔並繳給國庫；手續費則是買賣雙方都付給證券商的服務報酬，兩者性質不同。
