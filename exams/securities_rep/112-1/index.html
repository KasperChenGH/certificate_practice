1. 股份有限公司業務之執行，由何機關決定之？
  1. (A)股東會
  2. (B)董事會
  3. (C)董事
  4. (D)審計委員會
解析

(A)錯誤。股東會為意思機關，僅就法律或章程所定事項決議，不決定日常業務執行。

(C)錯誤。董事個人無單獨決定公司業務執行之權，須以董事會合議為之。

(D)錯誤。審計委員會的職能在監督與審查，不決定業務執行。

2. 持有已發行股份總數多少之股東得以書面向公司提出董事候選人名單？
  1. (A)百分之一
  2. (B)百分之三
  3. (C)百分之五
  4. (D)百分之十
解析

(A)正確。依公司法第一百九十二條之一，持有已發行股份總數百分之一以上股份的股東，得以書面向公司提出董事候選人名單。門檻訂得低，是為了讓少數股東也能參與董事提名，避免提名權由經營團隊或大股東獨占，落實候選人提名制度的股東民主精神。

(B)錯誤。百分之三是公司法上股東請求董事會召集股東臨時會或聲請法院選派檢查人等權利的持股門檻，提名董事候選人的門檻較此更低。

(D)錯誤。百分之十已是公司法上重大事項的門檻等級，例如聲請法院裁定重整或請求解散公司；以此作為提名門檻，等於只有大股東能提名董事。

3. 我國「公司法」所稱公司組織之性質為何？
  1. (A)以公益為目的之社團法人
  2. (B)以營利為目的之社團法人
  3. (C)營利之財團法人
  4. (D)不以營利為目的之團體
解析

(A)錯誤。公司的成立目的若是公益，就是公益社團法人或財團法人，例如協會或基金會；公司法明定公司以營利為目的，兩者的定性不同。

(B)正確。公司法第一條規定，公司是以營利為目的，依公司法組織、登記、成立的社團法人。定性為社團而非財團，是因公司以股東（人的結合）為基礎，由股東出資並透過股東會形成意思；定性為營利，是因公司經營所得須分配給股東，不同於公益團體。

(C)錯誤。財團法人以捐助財產為成立基礎，沒有社員或股東，也不得將所得分配給捐助人，因此不可能是營利性質；公司則是股東組成的社團。

(D)錯誤。公司既以營利為目的，又依法登記取得法人格，並非不以營利為目的的一般團體；後者指的是合作社、協會等。

(B)正確。依公開發行公司獨立董事設置及應遵循事項辦法，獨立董事兼任其他公開發行公司獨立董事不得逾三家。設有上限是要確保獨立董事有足夠時間投入各公司的董事會與功能性委員會，避免同時掛名過多公司而流於形式，失去監督功能。

(D)錯誤。十家遠高於辦法上限，等於允許職業獨董大量掛名，正是設置兼任上限所要防止的情形。

12. 有價證券融資融券交易在暫停融資買進或融券賣出之前，由下列何機構執行分配？
  1. (A)證券金融公司
  2. (B)證券交易所及證券櫃檯買賣中心
  3. (C)金融監督管理委員會
  4. (D)證券商業同業公會
解析

38. 當信用帳戶的擔保維持率不足，證券商通知補繳差額後幾個營業日內未補繳足夠金額，可能將面臨「斷頭」?
  1. (A)1 個
  2. (B)2 個
  3. (C)3 個
  4. (D)5 個
解析

(A)錯誤。1 個營業日只給投資人一天籌措資金，緩衝過短；融資融券業務規定給的是 2 個營業日，一天內就處分擔保品會使投資人來不及匯款或調度股票。

(B)正確。信用帳戶整戶擔保維持率低於 130% 時，證券商會通知委託人補繳差額；依證券商辦理有價證券買賣融資融券業務操作辦法，委託人未於通知送達之日起 2 個營業日內補繳足額，證券商得處分其擔保品，即俗稱的斷頭。兩個營業日的緩衝是在保障證券商債權與給投資人合理籌資時間之間取得平衡，緩衝過長則股價續跌時擔保品恐已不足清償。

(C)錯誤。3 個營業日是把補繳期限多算了一天；若擔保品在通知後還能停留三天不處分，股價連續下跌時擔保品價值可能已跌破融資金額，證券商的債權將無法確保。

(D)錯誤。5 個營業日相當於整整一週交易日，遠超過法定期限；如此長的緩衝會讓信用交易的風險控管失去即時性，法規不採此期限。

42. 有關證券經紀商手續費敘述，以下何者正確？
  1. (A)只對賣出收取
  2. (B)收取上限為千分之三
  3. (C)買進與賣出時各計算一次
  4. (D)為固定費率，無折扣空間
解析

(A)錯誤。「只對賣出收取」是證券交易稅的特徵，證交稅由賣方負擔；手續費是經紀商提供受託買賣服務的對價，買進與賣出都要收取。

(B)錯誤。千分之三是證券交易稅對股票賣出所課的稅率，不是手續費上限；證券經紀商手續費費率上限為千分之一點四二五。

(C)正確。證券經紀商手續費於買進與賣出時各計算一次，一買一賣共收取兩次，每次以成交金額乘以費率計算。手續費是經紀商提供受託買賣勞務的對價，每一次受託成交都提供了服務，因此每次都應計收；這也是投資人計算交易成本時須把手續費乘以二的原因。

(D)錯誤。手續費費率是「上限」而非固定費率，證券商得在上限內自訂折扣，實務上電子下單折扣普遍存在，並非無折扣空間。
