1. 股份有限公司業務之執行，由何機關決定之？
  1. (A)股東會
  2. (B)董事會
  3. (C)董事
  4. (D)審計委員會
解析

(A)錯誤。股東會為意思機關，僅就法律或章程所定事項決議，不決定日常業務執行。

(B)正確。公司業務之執行，除法律或章程另有規定應由股東會決議者外，均由董事會決議行之。所有權與經營權分離的設計，是讓專責且可課責的合議機關負責經營決策。

(C)錯誤。董事個人無單獨決定公司業務執行之權，須以董事會合議為之。

(D)錯誤。審計委員會的職能在監督與審查，不決定業務執行。

2. 持有已發行股份總數多少之股東得以書面向公司提出董事候選人名單？
  1. (A)百分之一
  2. (B)百分之三
  3. (C)百分之五
  4. (D)百分之十

(A)正確。持有已發行股份總數百分之一以上股份之股東，得以書面向公司提出董事候選人名單。門檻訂得低，是為讓少數股東也能參與董事提名，避免提名權由經營團隊獨占。

(B)錯誤。百分之三並非董事候選人提名之持股門檻，法定門檻低於此數。

(C)錯誤。百分之五並非提名董事候選人所要求之持股比例。

(D)錯誤。百分之十門檻過高，並非董事候選人提名之持股門檻。

3. 我國「公司法」所稱公司組織之性質為何？
  1. (A)以公益為目的之社團法人
  2. (B)以營利為目的之社團法人
  3. (C)營利之財團法人
  4. (D)不以營利為目的之團體
解析

(A)錯誤。公司以營利為目的，非以公益為目的之社團法人。

(B)正確。公司法所稱公司，為以營利為目的，依公司法組織、登記、成立之社團法人。定性為社團而非財團，是因公司以股東（人的結合）為基礎，而非以捐助財產為基礎。

(C)錯誤。財團法人以捐助財產為成立基礎，與公司之社團性質不符。

(D)錯誤。公司以營利為目的且具法人格，非不以營利為目的之一般團體。

4. 下列關於「證券承銷」之敘述何者正確？
  1. (A)可有「包銷」或「代銷」兩種方式
  2. (B)證券自營商須經證券主管機關專案許可，始能例外從事承銷業務
  3. (C)可分為發行市場上之承銷與流通市場之承銷兩種層次
  4. (D)證券承銷商與發行人之間，係特定法律關係，而非屬契約關係
解析

(A)正確。證券承銷分為包銷與代銷兩種方式：包銷由承銷商承擔銷售不足之風險，代銷則僅代為銷售。兩者差別在風險歸屬，故包銷之承銷商須具備較高之財務能力。

(B)錯誤。承銷業務屬證券承銷商之業務，非證券自營商經專案許可即得辦理。

(C)錯誤。承銷為發行市場（初級市場）之行為，流通市場並無承銷可言。

(D)錯誤。承銷商與發行人間係依承銷契約而生之契約關係，並非單純的法定關係。

5. 下列關於召集董事會之敘述，何者正確？
  1. (A)每屆第一次董事會，由過半數當選之董事於改選後十五日內召開之
  2. (B)過半數之董事得以書面記明提議事項及理由，請求董事長召集董事會
  3. (C)董事會之召集，應於三日前通知各董事及監察人。但章程不同規定者，從其規定
  4. (D)董事會召集之通知，經相對人同意，以電子方式為之者，得不載明事由
解析

(A)錯誤。每屆第一次董事會係由所得選票代表選舉權最多之董事召開，並非「過半數當選之董事」。

(B)正確。過半數之董事得以書面記明提議事項及理由，請求董事長召集董事會。此係為避免董事長怠於召集而使董事會無從運作，賦予多數董事召集請求權。

(C)錯誤。但書係指章程有「較高」規定者從其規定，而非章程有不同規定即可，以免章程反而縮短通知期間。

(D)錯誤。董事會召集之通知應載明事由，縱經相對人同意以電子方式為之，仍不得省略事由之記載。

  1. (A)變更機構名稱

解析

(B)錯誤。變更資本額應先報主管機關核准。

(D)錯誤。與其他證券公司合併涉及組織與營業之重大變動，應先報主管機關核准。

8. 證券主管機關審核有價證券之募集與發行係採用何種制度？
  1. (A)採申報生效制
  2. (B)兼採申報生效及申請核准制
  3. (C)採實質審查及申請核准制
  4. (D)採申請核准制
解析

(A)正確。我國有價證券之募集與發行採申報生效制，發行人備齊書件申報，經一定期間屆滿即生效。此制把投資價值的判斷交還市場，主管機關只確保揭露充分，不為發行條件之良窳背書。

(B)錯誤。現行制度以申報生效為原則，並非本題所指之兼採兩制。

(C)錯誤。現行制度非實質審查與核准制，主管機關不對發行條件作實質價值認定。

(D)錯誤。申請核准制為舊制，現行已改採申報生效制。

9. 有關證券商經營受託買賣外國有價證券業務，對專業投資人規定之敘述，何者正確？
  1. (A)適用金融消費者保護法第四條之定義
  2. (B)專業投資人應符合之資格條件，應由證券商盡合理調查之責任
  3. (C)非專業投資人於未符合專業投資人資格前，得申請變更為專業投資人
  4. (D)證券商針對專業投資人之評估方式，應納入瞭解客戶制度並報經股東會通過
解析

(A)錯誤。專業投資人之資格條件另有規範，並非逕行援用金融消費者保護法之定義。

(B)正確。客戶是否符合專業投資人之資格條件，證券商應盡合理調查之責任並取得客觀證明。把查證義務課予證券商，是因為列為專業投資人可減省許多保護程序，若僅憑客戶自稱，保護機制形同虛設。

(C)錯誤。未符合資格條件者，不得逕行申請變更為專業投資人。

(D)錯誤。相關評估方式應納入認識客戶制度並報經董事會通過，而非股東會。

11. 證券經紀商為辦理對客戶交割款項之收付，應於金融機構設立何種性質之帳戶為交割專戶？
  1. (A)活期存款
  2. (B)定期存款
  3. (C)支票存款
  4. (D)以上皆可
解析

(A)正確。證券經紀商辦理客戶交割款項收付之交割專戶，應為活期存款帳戶。交割款須隨時可供當日撥付，只有活期存款兼具流動性與即時性，能配合每日款券交割的時程。

(B)錯誤。定期存款無法隨時動支，不符交割時效要求。

(C)錯誤。支票存款並非規定之交割專戶性質。

(D)錯誤。並非任一種存款皆可，必須為活期存款。

(C)錯誤。金管會為監理機關，不執行個別額度之分配。

(D)錯誤。同業公會為自律團體，無執行分配之權責。

16. 有價證券交易爭議之仲裁，除依「證券交易法」之規定外，依何法之規定為之？
  1. (A)公司法
  2. (B)票據法
  3. (C)仲裁法
  4. (D)民法

(D)錯誤。手續費訂有上限，證券商得於上限內給予折扣，並非固定不二價。
