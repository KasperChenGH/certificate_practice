1. 下列文句「」中的成語，何者使用錯誤？
  1. (A)警方接到報案趕到現場，匪徒早已「杳如黃鶴」，不見蹤影
  2. (B)這項工程最終靠著大家「任勞任怨」、努力不懈，才得以完成
  3. (C)王教授的演講十分精彩，全場人士聽得「津津有味」，讚嘆不已
  4. (D)我們公司非常嚴格，對任何流程的監控都小心翼翼，「瑕不掩瑜」
解析

(A)錯誤。「杳如黃鶴」比喻一去不返、無影無蹤，與匪徒早已不見蹤影相合，用法正確。

(B)錯誤。「任勞任怨」指做事不辭勞苦、也不怕他人埋怨，用來形容眾人努力完成工程並無不當。

(C)錯誤。「津津有味」形容興味濃厚，可用於聽講或閱讀，與演講精彩相合。

(D)正確。「瑕不掩瑜」指小缺點掩蓋不了整體的優點，用於評價略有瑕疵的人事物；此處在說監控嚴格、毫無疏漏，語意不合，屬誤用。

  1. (A)萊爾德衝浪時，總能以技巧避開危險
  2. (B)透過衝巨浪，萊爾德提升了衝浪技巧
  3. (C)萊爾德不費吹灰之力救起溺水的同伴
  4. (D)萊爾德征服恐懼的方法是直接面對它
解析

(A)錯誤。引文明說他和朋友「曾經在衝浪時出過嚴重的事故，被巨浪重擊」，同伴幾乎喪命，可見危險並未被技巧避開；「像是與死神跳一首腳步繁複的雙人舞」也是在說風險始終存在。

(B)錯誤。全段講的是他如何面對恐懼——送醫、掉頭回海裡、答以「不能害怕」；衝巨浪是否使技巧精進，引文完全沒有交代。

(C)錯誤。引文寫他「用盡力氣把重傷的同伴拖回岸邊送上救護車」，是竭盡全力；同伴是被巨浪重擊重傷，也不是溺水。此項把過程說得輕易，與敘述相反。

(D)正確。事故後他把重傷的同伴送上救護車，「第一件事竟是拿著浪板掉頭回到海裡」，事後被問難道不怕，只答「不能害怕」——不迴避、立即回到令他恐懼的現場，正是以直接面對來征服恐懼。

  2. (B)登高望遠可以提升人格境界、精神效能

  4. (D)登山的考驗可使人看淡得失，感悟生命

(D)錯誤。引文談的是尋得歸依與安頓生命，全段沒有得失的題目；把「看淡得失」讀進來，是拿常見的登山感悟去套這段文字。

6. 「婚宴後沒幾個月，先生告別了年近九十的姑丈。下半年，我的小表舅在壯年意外過世。回想上一回與他們相聚，就在自己的婚宴上。才曉得婚宴留下什麼，才領會從俗的益處。」下列選項，何者最接近本文意旨？
  1. (A)婚宴繁瑣，能免則免
  2. (B)個人婚宴，眾人相會
  3. (C)婚喪喜慶，擇日為宜
  4. (D)親友相會，定期為宜
解析

(A)錯誤。作者的結論是「才領會從俗的益處」，對婚宴這類俗禮轉為肯定；此項主張能免則免，與「從俗的益處」正好相反。

(B)正確。婚宴後姑丈與小表舅相繼離世，作者回想「上一回與他們相聚，就在自己的婚宴上」，這才明白婚宴留下的是眾人齊聚的那一刻——一場屬於個人的婚宴，成了眾人難得的相會，也就是他所領會的「從俗的益處」。

(C)錯誤。「擇日為宜」談的是婚喪喜慶的日期選擇；引文完全沒有觸及擇日或吉凶，談的是婚宴把親友聚在一起這件事後來顯出的意義。

(D)錯誤。引文感慨的是那一次相聚事後成了最後一面，屬於事與願違的追憶；「定期為宜」把它翻成一條行為建議，作者並未提出這樣的主張。

112年特種考試地方政府公務人員考試｜國文｜第 33 題
9. 下列文句「」中的成語，使用最適當的是：
  1. (A)面對世事無常，不禁使人產生「曾經滄海」之嘆
  2. (B)經過一番努力，他終於能「克紹箕裘」，光大門楣
  3. (C)他向來精打細算，善用「買櫝還珠」的策略而致富
  4. (D)網路上的諸多訊息，有可能是「爍石流金」的謠言，並非事實
解析

(A)錯誤。「曾經滄海」指見過大世面後不再看重尋常事物，多用於情感，不是感嘆世事無常。

(B)正確。「克紹箕裘」指能繼承父祖的事業，與光大門楣相合。

  1. (A)人們因換工作或搬家、移民，將會失去曾認同團體的情緒
  2. (B)我們不屬於該團體，也將因該團體的集體情緒而獲得認同
  3. (C)團體認同只是暫時性的現象，團體不必過於在乎形塑認同
  4. (D)團體內部無條件的團體認同，往往可對其他團體構成威脅
解析

(A)錯誤。文中說對先前所屬團體的集體情緒，「在我們不再屬於那個團體之後，還會持續下去」。

(B)錯誤。文中並未說不屬於該團體的人仍會因其集體情緒而獲得認同。

(C)錯誤。文中說團體認同可能只是暫時現象，但並未因此主張團體不必在乎形塑認同。

(D)正確。集體理性情緒若無條件且無從改變，團體從中獲得的優勢就會放大；「倘若少了這些特質，團體就不太能對敵對團體構成威脅」。
