1. 有關期貨結算機構查察結算會員之規定，下列敘述何者錯誤？
  1. (A)應查察結算會員之財務、業務及內部稽核作業情形
  2. (B)發現有違反法令或不當情事者，應即為適當處置，並通知主管機關及期貨交易所
  3. (C)結算會員內部稽核作業有重大缺失者，應即為專案檢查，並予輔導
  4. (D)結算會員不能履行結算、交割義務時，應即為專案檢查，並通報主管機關督導承受結算會員接辦結算及交割事務
解析

(A)錯誤。此敘述正確，結算機構應查察結算會員之財務、業務及內部稽核作業。

(B)錯誤。此敘述正確，發現違法或不當情事應即處置並通知主管機關及期貨交易所。

(C)錯誤。此敘述正確，內部稽核作業有重大缺失者應為專案檢查並予輔導。

(D)正確（即敘述有誤者）。結算會員已不能履行結算、交割義務時，事態不是「檢查與輔導」所能處理，結算機構應立即依業務規則代為履行並動用擔保履約財源、為必要之處置。專案檢查與輔導係針對內部稽核有重大缺失但尚能履約者，本選項將兩種情形的處理方式對調。

115年第1次｜期貨法規與自律規範｜第 8 題
2. 期貨信託事業應將重大影響受益人權益之事項，於事實發生之日起2 日內公告並向主管機關申報，該重大影響受益人權益之事項，包括下列哪些情事？ Ⅰ.受主管機關行政處分；Ⅱ.因會計師事務所內部調整，變更公司之簽證會計師；Ⅲ.向不特定人募集之期貨信託基金恢復計算買回價格；Ⅳ.向不特定人募集之期貨信託基金合併；Ⅴ.向不特定人募集之期貨信託基金之契約終止
  1. (A)Ⅰ、Ⅱ、Ⅲ、Ⅳ
  2. (B)Ⅱ、Ⅲ、Ⅳ、Ⅴ
  3. (C)Ⅲ、Ⅳ、Ⅴ
  4. (D)Ⅰ、Ⅱ、Ⅲ、Ⅳ、Ⅴ
解析

(A)錯誤。納入Ⅰ與Ⅱ且漏列Ⅴ。規則所列的是行政處分「致不能繼續營業」之類足以動搖事業存續的情形，泛稱受行政處分並不當然構成；而契約終止直接消滅受益權，反而必須申報。

(B)錯誤。納入Ⅱ。規則在變更簽證會計師一項明文將「因會計師事務所內部調整而變更」排除，因為那是事務所人事安排，不涉及查核意見或財務狀況的變化。

(C)正確。Ⅲ恢復計算買回價格、Ⅳ基金合併、Ⅴ基金契約終止，都直接改變受益人能否買回、以什麼條件繼續持有受益權，屬期貨信託事業管理規則所定應於事實發生之日起二日內公告、向主管機關申報並抄送同業公會的重大事項。Ⅰ僅泛指受行政處分、Ⅱ屬事務所內部調整而變更會計師，均不在此列。

(D)錯誤。並非全部列舉皆屬之。全選忽略了規則對Ⅰ所設的「致不能繼續營業」門檻，也忽略了Ⅱ在條文中被明文排除。

115年第1次｜期貨法規與自律規範｜第 22 題
3. 依我國期貨交易法對於期貨交易契約之分類，下列在臺灣期貨交易所交易之契約，何者敘述錯誤？
  1. (A)黃金期貨契約係屬期貨交易法定義之期貨契約
  2. (B)黃金選擇權契約係屬期貨交易法定義之選擇權契約
  3. (C)臺指選擇權契約係屬期貨交易法定義之期貨選擇權契約
  4. (D)股票選擇權契約係屬期貨交易法定義之選擇權契約
解析

(A)錯誤（此項敘述無誤）。黃金期貨約定於未來特定期間依特定價格與數量買賣黃金或結算差價，標的是商品本身，正是期貨交易法所定義的期貨契約。

(B)錯誤（此項敘述無誤）。黃金選擇權的買方支付權利金後取得買賣「黃金」的權利，標的為商品而非期貨契約，屬期貨交易法所稱之選擇權契約。

(C)正確（此項敘述有誤）。期貨交易法所稱期貨選擇權契約，指買方支付權利金後取得買賣「期貨契約」的權利；臺指選擇權履約後取得的是依股價指數現金結算的價差，標的是指數而不是期貨契約，故屬選擇權契約。判斷關鍵在於履約後拿到的是現貨（或現金結算），還是一個期貨部位。

(D)錯誤（此項敘述無誤）。股票選擇權以個股為標的，履約後取得的是股票而非期貨部位，屬選擇權契約而非期貨選擇權契約。

115年第2次｜期貨法規與自律規範｜第 1 題
4. 有關期貨商製作與交付買賣報告書之規定，下列敘述何者錯誤？
  1. (A)期貨商受託從事期貨交易，應於成交後製作買賣報告書交付期貨交易人確認
  2. (B)期貨商受託從事期貨交易，於客戶成交後，如已辦理交易確認並留存紀錄，毋須再請客戶於買賣報告書上簽名或蓋章
  3. (C)期貨交易人委託代理人代理買賣，期貨商應按月製作買賣報告書交付期貨交易人確認
  4. (D)期貨交易人委託代理人代理買賣，而由代理人確認買賣報告書者，須檢附期貨交易人本人之委託書
解析

(A)錯誤（本敘述正確）。受託從事期貨交易應於成交後製作買賣報告書交付交易人確認。

(B)錯誤（本敘述正確）。已辦理交易確認並留存紀錄者，得免再請客戶於買賣報告書簽章。

(C)正確（即敘述有誤者）。買賣報告書係逐筆於成交後製作交付，並非按月彙總；按月編製交付的是對帳單。兩者功能不同：報告書供逐筆確認成交條件，對帳單供核對期間內部位與權益餘額。

(D)錯誤（本敘述正確）。由代理人確認買賣報告書者，須檢附本人之委託書以證明代理權限。

115年第2次｜期貨法規與自律規範｜第 15 題
5. 期貨商兼營槓桿交易商之淨值低於新臺幣多少金額時，應即停止辦理槓桿保證金契約交易業務，並向主管機關、期貨交易所及證券櫃檯買賣中心提出改善計畫？
  1. (A)新臺幣八億元
  2. (B)新臺幣七億元
  3. (C)新臺幣六億元
  4. (D)新臺幣五億元
解析

(A)錯誤。新臺幣八億元是上一層的申報門檻：依槓桿交易商管理規則第十一條第二項，淨值低於八億元或調整後淨資本額少於客戶未沖銷部位所需保證金總額百分之二十時，應向主管機關、期貨交易所及櫃買中心申報，但尚不必停辦業務。

(B)錯誤。七億元落在申報門檻（八億元）與停辦門檻（六億元）之間；在這個區間規則要求的是申報並設法改善財務，還沒到必須停止承作槓桿保證金契約的程度。

(C)正確。依槓桿交易商管理規則第十一條第三項，期貨商兼營槓桿交易商之淨值低於新臺幣六億元，或調整後淨資本額少於客戶未沖銷部位所需保證金總額百分之十五時，除處理原有交易外，應即停止辦理槓桿保證金契約交易業務，並向主管機關、期貨交易所及證券櫃檯買賣中心提出改善計畫。門檻分兩層（八億元／百分之二十申報，六億元／百分之十五停辦），是因為槓桿交易商在店頭市場自任交易相對人，客戶的暴險直接就是它自己的暴險。

(D)錯誤。淨值一旦低於六億元即已觸發停辦與提出改善計畫，不必等跌到五億元；門檻若訂在五億元，等於容許業務在風險已明顯升高的期間繼續承作。

115年第2次｜期貨法規與自律規範｜第 29 題
6. 根據中央銀行114 年12 月份銀行衍生性金融商品交易量統計資料，下列哪一種商品之交易金額最高？
  1. (A)換利(IRS)契約
  2. (B)換匯(Fx Swaps)契約
  3. (C)遠期契約(Outright Forwards)
  4. (D)賣出選擇權(Sold Options)契約
解析

(A)錯誤。換利（IRS）是純粹的利率避險工具，承作筆數與名目金額都遠不及銀行每日為調度外幣資金而做的換匯，統計上金額居後。

(B)正確。國內銀行衍生性金融商品交易金額長期以換匯（FX Swaps）居首：它同時是短期外幣資金的調度工具，銀行以本幣換入美元支應放款與投資，到期再換回，天期短、周轉快，因此名目金額被反覆累計而遠高於其他商品。本題引用特定月份的央行統計，個別月份排名可能隨資金情勢變動，但換匯居首是我國長期結構特徵。

(C)錯誤。遠期外匯（Outright Forwards）多為進出口商鎖定匯率的實需交易，金額通常排在換匯之後，因為它不具備銀行間反覆調度資金的周轉性質。

(D)錯誤。選擇權類商品在國內銀行的衍生性商品中屬相對小眾，賣出選擇權更受風險控管與監理限制，占整體交易金額比重很低。

7. 假設西園公司持有投資組合價值為1 億8,000 萬元，貝它(β)值為1.1。目前臺股期貨指數為為33,600點，每點價值200 元，若西園公司打算利用臺股期貨將投資組合貝它值降低至約0.8。假設不考慮保證金之下，則西園公司應如何調整避險部位？
  1. (A)買進4 口臺股期貨
  2. (B)賣出4 口臺股期貨
  3. (C)買進8 口臺股期貨
  4. (D)賣出8 口臺股期貨
解析

(A)錯誤。方向錯誤。買進期貨會提高投資組合的貝它值，要調降曝險應放空期貨。

(B)錯誤。方向錯誤且口數不足，4口僅約對應貝它降低0.15。

(C)錯誤。8口的規模正確，但買進期貨等於加碼多頭曝險，反而把貝它值推得更高。

(D)正確。避險口數＝(1.1−0.8)×180,000,000÷(33,600×200)＝54,000,000÷6,720,000≈8口；因目的是降低系統風險曝險，故放空8口臺股期貨。

8. 有關壓力測試方法，下列敘述何者錯誤？
  1. (A)簡單敏感度測試是針對特定市場因子設計可能變化的情形，再加以分析損失程度
  2. (B)情境分析的事件來源有歷史情境及假設情境
  3. (C)假設股價指數波動增減達40%，為假設情境分析的參考情境之一
  4. (D)極值理論是條件機率壓力測試法之
解析

(A)錯誤。此敘述正確：簡單敏感度測試針對單一市場因子設定變動幅度，再衡量損失程度。

(B)錯誤。此敘述正確：情境分析的事件來源可分為歷史情境與假設情境。

(C)錯誤。此敘述正確：設定股價指數波動大幅增減，是常見的假設情境參數之一。

(D)正確（即敘述錯誤者）。極值理論是直接對損失分配的尾端建模、估計極端損失的統計方法，屬無條件機率取向，並非條件機率型的壓力測試法。

115年第1次｜衍生性商品之風險管理｜第 35 題
9. 關於回顧測試與壓力測試，下列敘述何者最正確？
  1. (A)前者主要利用極端市場情境評估投資組合損失；後者則比較VaR 與實際損益
  2. (B)前者主要檢驗風險模型預測能力；後者則評估極端市場情境下之潛在損失
  3. (C)兩者皆以歷史平均損失作為主要分析依據，透過各種隨機模型進行模擬
  4. (D)兩者皆以歷史平均損失加上主觀判斷作為主要分析依據
解析

(A)錯誤。兩者的定義被互換了：以極端情境估算潛在損失的是壓力測試，拿 VaR 與事後實際損益比對、計算穿透次數的才是回顧測試。

(D)錯誤。買入股價−履約價把方向寫反了，那是履約價低於成本時的股票端虧損，而且完全漏掉了權利金這一項收入。

15. 假設某資產的條件變異數服從GARCH(1,1)模型：σt² = ω + αεt−1² + βσt−1²已知ω= 0.00002，α= 0.05，β= 0.90 則其無條件（長期）變異數最接近下列何者？
  1. (A)0.00020
  2. (B)0.00040
  3. (C)0.00050
  4. (D)0.00100
解析

(A)錯誤。0.00020 對應分母 0.1，等於只扣掉 β（1−0.90＝0.10）而漏掉 α。無條件變異數的分母必須是 1−α−β，兩個持續性參數都要扣。

(B)正確。GARCH(1,1) 取無條件期望值時 E[σ²]＝ω＋αE[σ²]＋βE[σ²]，整理得長期變異數＝ω/(1−α−β)＝0.00002/(1−0.05−0.90)＝0.00002/0.05＝0.0004。α＋β＝0.95 代表衝擊半衰期很長、波動均值回歸緩慢，這也是為什麼 α＋β 趨近 1 時長期變異數會急速放大。

(C)錯誤。0.00050 須分母為 0.04，亦即 α＋β＝0.96；題目給的 0.05＋0.90 只有 0.95。分母小一點點，長期變異數就會被高估兩成以上。

(D)錯誤。0.00100 須分母為 0.02（α＋β＝0.98），把持續性估得比題目高，長期變異數因而被放大為正確值的 2.5 倍。
