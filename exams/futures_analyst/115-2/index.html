1. 依我國期貨交易法對於期貨交易契約之分類，下列在臺灣期貨交易所交易之契約，何者敘述錯誤？
  1. (A)黃金期貨契約係屬期貨交易法定義之期貨契約
  2. (B)黃金選擇權契約係屬期貨交易法定義之選擇權契約
  3. (C)臺指選擇權契約係屬期貨交易法定義之期貨選擇權契約
  4. (D)股票選擇權契約係屬期貨交易法定義之選擇權契約
解析

(A)錯誤（此項敘述無誤）。黃金期貨約定於未來特定期間依特定價格與數量買賣黃金或結算差價，標的是商品本身，正是期貨交易法所定義的期貨契約。

(B)錯誤（此項敘述無誤）。黃金選擇權的買方支付權利金後取得買賣「黃金」的權利，標的為商品而非期貨契約，屬期貨交易法所稱之選擇權契約。

(C)正確（此項敘述有誤）。期貨交易法所稱期貨選擇權契約，指買方支付權利金後取得買賣「期貨契約」的權利；臺指選擇權履約後取得的是依股價指數現金結算的價差，標的是指數而不是期貨契約，故屬選擇權契約。判斷關鍵在於履約後拿到的是現貨（或現金結算），還是一個期貨部位。

(D)錯誤（此項敘述無誤）。股票選擇權以個股為標的，履約後取得的是股票而非期貨部位，屬選擇權契約而非期貨選擇權契約。

2. 依我國期貨交易法對於期貨選擇權契約定義之敘述，下列何者正確？
  1. (A)當事人約定於未來特定期間依特定價格及數量等交易條件買賣約定標的物，或於到期前或到期時結算差價之契約
  2. (B)當事人約定選擇權買方支付權利金，取得購入或售出之權利，得於特定期間内，依特定價格及數量等交易條件買賣約定標的物
  3. (C)當事人約定選擇權買方支付權利金，取得購入或售出之權利，得於特定期間內，依特定價格及數量等交易條件買賣期貨契約；選擇權賣方，於買方要求履約時，有依選擇權約定履行義務；或雙方同意於到期前或到期時結算差價之契約
  4. (D)當事人約定一方支付一定成數之款項，雙方於未來特定期間内，依約定方式結算差價
解析

(A)錯誤。這是「期貨契約」的定義：約定未來依特定價格、數量買賣標的物或結算差價，雙方權利義務對等，完全沒有權利金與選擇是否履約的設計。

(B)錯誤。這是一般「選擇權契約」的定義，買方取得的是買賣「約定標的物」（現貨、指數等）的權利，標的並非期貨契約，故比題目所問低一個層次。

(C)正確。期貨選擇權契約的核心是買方支付權利金後取得「買賣期貨契約」的權利，賣方於買方要求履約時負履約義務，或雙方約定於到期前或到期時結算差價。它與一般選擇權唯一的分野就在標的物是期貨契約，履約後買方得到的是一個附保證金與逐日結算義務的期貨部位。

(D)錯誤。這是「槓桿保證金契約」的描述：一方支付一定成數款項，雙方於未來特定期間依約定方式結算差價，屬槓桿交易商在店頭市場承作的業務，不是期貨選擇權。

3. 依我國期貨交易法，關於公司制期貨交易所與期貨商訂立之使用期貨集中市場契約，下列何者正確？甲.期貨商因解散而終止契約時應繳納違約金；乙.期貨商違反業務規則時應繳納違約金；丙.應訂明期貨交易經手費標準；丁.期貨商違反期貨交易所章程時應繳納違約金
  1. (A)乙、丙
  2. (B)乙、丙、丁
  3. (C)甲、丁
  4. (D)甲、乙
解析

(A)錯誤。乙、丙成立，但漏了丁。期貨交易法第三十九條第一項第二款援引第二十五條第一項各款，其中明列「違反期貨交易所章程、業務規則、受託契約準則或其他章則」，故違反章程與違反業務規則同屬應繳納違約金的事由。

(B)正確。依期貨交易法第三十九條第一項，使用期貨集中交易市場契約應訂明：期貨交易經手費標準（丙）、期貨商有第二十五條第一項各款情事（含違反章程或業務規則）時應繳納違約金或停止、限制其交易或終止契約（乙、丁），以及被指定代為了結他期貨商交易時的履約義務。交易所藉這紙契約把自律規範轉成可直接執行的契約義務，不必等主管機關作出行政處分；經手費訂明於契約則可避免差別待遇。

(C)錯誤。甲不成立：依第四十條，該契約除依約定事項終止外，因當事人一方解散、業務許可被撤銷或歇業而終止，屬獨立的終止事由，與違約無關，自不生違約金問題。

(D)錯誤。甲不成立（解散而終止並非違約），且漏列丙的經手費標準與丁的違反章程，涵蓋範圍過窄。

4. 期貨交易所有下列何種事項時，應於知悉事實發生或處理完成後5 日內，向主管機關申報？甲.交易系統發生故障或中斷之情形；乙.因商務仲裁而對財務或業務有重大影響者；丙.期貨商逾期繳交保證金；丁.期貨集中交易市場監視及處理情形
  1. (A)乙、丁
  2. (B)丙、丁
  3. (C)甲、乙、丁
  4. (D)甲、丁
解析

(A)正確。依期貨交易所管理規則第八條第二項，該條第四款至第九款事項應於知悉事實發生或處理完成後五日內申報，其中第八款為「期貨集中交易市場監視及處理情形」（丁），第九款為因訴訟、行政爭訟、商務仲裁或和解事件對財務或業務有重大影響者（乙）。這類事項須調查或處理完成後才能完整說明，故給五日；直接影響交易進行的事件期限更短。

(B)錯誤。丁固然屬五日內申報，但丙（會員或期貨商逾時繳交或無法繳交保證金）列於第八條第一項第三款，與第一、二款同屬應於事實發生之次日前申報的急件，因為它直接牽動結算安全。

(C)錯誤。甲（交易系統與交易資訊傳輸系統發生故障或中斷）是第八條第一項第二款，屬事實發生之次日前即須申報的事項，不適用五日的期限。

(D)錯誤。甲屬次日前申報而非五日內，且本選項漏列第九款的商務仲裁等事件對財務業務有重大影響（乙）。

6. 依我國期貨交易法之規定，期貨結算會員因期貨結算所生之債務，其債權人對該結算會員之交割結算基金受償之順序，下列敘述何者正確？
  1. (A)期貨結算會員受償之順位在期貨交易人之前
  2. (B)期貨交易人受償之順位在期貨結算機構之前
  3. (C)期貨結算會員受償之順位在期貨結算機構之前
  4. (D)期貨結算機構受償之順位在期貨交易人之前
解析

(A)錯誤。結算會員本身為債務人，不得優先於其客戶受償。

(B)錯誤。期貨結算機構之受償順位在期貨交易人之前，本項顛倒。

(C)錯誤。結算會員之受償順位不可能優先於期貨結算機構。

(D)正確。交割結算基金之受償順序，期貨結算機構優先於期貨交易人，期貨交易人再優先於結算會員。結算機構居於中央對手方地位，其債權優先受償才能確保整體結算體系不因單一會員違約而崩解。

7. 依期貨結算機構管理規則第十二條規定，期貨結算機構經主管機關許可並依法登記後，應向國庫繳存營業保證金。營業保證金之金額應為多少？又由期貨交易所或其他機構兼營之期貨結算機構應繳存之營業保證金，下列何者正確？
  1. (A)實收資本額百分之十；應按指撥專用營運資金百分之五繳存
  2. (B)實收資本額百分之五；應按指撥專用營運資金百分之五繳存
  3. (C)新臺幣四億元；實收資本額百分之十繳存
  4. (D)新臺幣二億元；應按指撥專用營運資金百分之五繳存
解析

(A)錯誤。百分之十高於規則所定比率。期貨結算機構管理規則第十二條明定營業保證金為實收資本額的百分之五，兼營者亦為指撥專用營運資金的百分之五，兩者比率相同，不存在一邊十、一邊五的設計。

(B)正確。依期貨結算機構管理規則第十二條，期貨結算機構經許可並依法登記後，應以現金、政府債券或金融債券向國庫繳存相當於實收資本額百分之五的營業保證金；由期貨交易所或其他機構兼營者，則按其指撥之專用營運資金百分之五繳存。採比例而非定額，可使擔保金額隨機構規模同步放大；繳存國庫則確保這筆錢在機構失卻清償能力時仍能用於賠償。

(C)錯誤。本條採比例制，並未規定固定金額。期貨結算機構最低實收資本額為新臺幣十億元（期貨結算機構設置標準第三條），按百分之五計算約為五千萬元，與四億元相差甚遠；且兼營者的計算基礎是指撥專用營運資金，不是實收資本額。

(D)錯誤。後段的百分之五雖與規定相符，前段的定額敘述仍不成立；新臺幣二億元是期貨經紀商的最低實收資本額（期貨商設置標準第八條），與結算機構的營業保證金是兩件事。

8. 下列有關期貨結算機構提存之賠償準備金之敘述何者正確？
  1. (A)按在期貨交易所或非在期貨交易所之期貨交易，分別提存
  2. (B)第一次應各提存新臺幣2 億元
  3. (C)每季按結算、交割手續費收入之15%繼續分別提存
  4. (D)提存金額分別已達資本總額或指撥專用營運資金時，可停止提存
解析

(A)正確。依期貨結算機構管理規則第十五條，賠償準備金應按「在期貨交易所」與「非在期貨交易所」之期貨交易分別提存。兩類交易的交易對手、契約規格與結算風險性質不同，分開提存才不會拿場內交易人的準備金去填補店頭交易的違約損失。

(B)錯誤。第一次應分別一次提存的是新臺幣五億元，不是二億元；二億元是期貨經紀商的最低實收資本額，與賠償準備金的提存金額無關。

(C)錯誤。繼續提存的比率是結算、交割手續費收入的百分之二十，且應於每季終了後十五日內提存；用百分之十五會使準備金的累積速度落後於業務量的成長。

(D)錯誤。停止提存的標準是提存金額分別已達資本總額（兼營者為指撥專用營運資金）的一點五倍，而不是僅達一倍；多留半倍的緩衝，才足以吸收單一結算會員違約的衝擊。

9. 下列有關期貨商業務員之敘述，何者錯誤？
  1. (A)初任及離職滿二年再任業務員者，應於到職後半年內參加職前訓練；在職人員應每三年參加在職訓練

(C)錯誤。水平意味通膨完全不隨失業率變動，那比較接近曲線極度平坦化的短期近似討論，不是長期的結論。
