1. 依我國期貨交易法之規定，當事人約定，於未來特定期間，依特定價格及數量等交易條件買賣約定標的物，或於到期前或到期時結算差價之契約是何種契約？
  1. (A)遠期契約
  2. (B)交割結算契約
  3. (C)期貨契約
  4. (D)結構型契約
解析

(A)錯誤。遠期契約是由雙方私下議定、於店頭市場交易的非標準化契約，沒有集中結算與逐日結算，違約風險由對手自行承擔，期貨交易法將其與期貨契約分列。

(B)錯誤。交割結算並非期貨交易法所定義的契約種類，而是期貨契約到期時履行義務的程序，由期貨結算機構負責辦理。

(C)正確。期貨交易法第三條所稱期貨契約，即「當事人約定，於未來特定期間，依特定價格及數量等交易條件買賣約定標的物，或於到期前或到期時結算差價之契約」，題幹文字與法條定義完全相同。定義中「結算差價」一語特別重要，正是它把不必實物交割的現金結算商品納入本法規範。

(D)錯誤。結構型契約是將固定收益商品與衍生性商品組合而成的商品（如保本型、股權連結型商品），屬銀行或證券商銷售的金融商品，不在期貨交易法所定義的契約類型之列。

2. 依我國期貨交易法之規定，非在期貨交易所進行之期貨交易，基於下列哪些考量，財政部或中央銀行得於掌管事項範圍內公告不適用期貨交易法之規定？ Ⅰ.金融；Ⅱ.貨幣；Ⅲ.外匯；Ⅳ.經濟；Ⅴ.公債
  1. (A)Ⅰ、Ⅱ、Ⅲ、Ⅳ
  2. (B)Ⅰ、Ⅱ、Ⅲ、Ⅴ
  3. (C)Ⅰ、Ⅲ、Ⅳ、Ⅴ
  4. (D)Ⅱ、Ⅲ、Ⅳ、Ⅴ
解析

(A)錯誤。誤把「經濟」當成列舉事由，同時漏掉公債。期貨交易法列的是金融、貨幣、外匯、公債四項政策考量，「經濟」範圍過於廣泛，並未入法。

(B)正確。期貨交易法第三條規定，非在期貨交易所進行之期貨交易，基於金融、貨幣、外匯、公債等政策考量，得經主管機關於主管事項範圍內或中央銀行於掌理事項範圍內公告，不適用本法之規定。這一豁免是為了讓銀行間的換匯、利率交換等店頭交易，留在金融與外匯主管機關既有的監理架構下，避免雙重管轄。

(D)錯誤。納入未列舉的「經濟」，並漏掉金融；金融是主管機關（金管會）主管事項範圍的基本用語，不可能被排除在列舉之外。

3. 依我國期貨交易法之規定，主管機關得經下列何者核准，與外國政府機關、機構或國際組織，就資訊交換、技術合作、協助調查等事項，簽訂合作協定？
  1. (A)總統府
  2. (B)行政院
  3. (C)財政部
  4. (D)中央銀行
解析

(A)錯誤。總統府不是行政監督體系中核可行政協定的機關。國際合作協定屬行政權的對外事務，由行政院層級把關即可，無須提報總統府。

(B)正確。期貨交易法規定，主管機關得經行政院核准，與外國政府機關、機構或國際組織就資訊交換、技術合作、協助調查等事項簽訂合作協定。要求行政院核准的理由是：這類協定涉及對外關係與我國資訊的跨境提供，已超出單一主管機關的權限，須由行政院統籌其與外交、國安政策的一致性。

(C)錯誤。財政部主管的是財政、稅務與國庫事務；期貨市場的主管機關已移由金融監督管理委員會擔任，財政部並非核准機關。

(D)錯誤。中央銀行掌理貨幣、外匯與金融穩定事項，在非交易所期貨交易的豁免公告上有其角色，但簽訂國際合作協定的核准權不在央行。

4. 依我國期貨交易法之規定，若公司制期貨交易所有5 席監察人，其中幾席應由主管機關指派？
  1. (A)1
  2. (B)2
  3. (C)3
  4. (D)4
解析

(A)正確。期貨交易法第三十六條規定，公司制期貨交易所之董事、監察人至少四分之一由非股東之相關專家擔任，其中半數由主管機關指派。監察人五席時，四分之一為一點二五席、至少須二席非股東專家，其半數即一席由主管機關指派。指派席次的用意是把公益與市場秩序的觀點帶進交易所治理，避免交易所純依股東利益訂定市場規則。

(B)錯誤。二席是非股東專家監察人的總數，不是主管機關指派的數目；該二席中另一半由董事會遴選，再報主管機關核定。

(C)錯誤。三席已達五席中的多數，等同由主管機關掌握監察權，與交易所採民營自治、主管機關僅派員監督的制度設計不符。

(D)錯誤。四席遠高於法定比例。法條的門檻是「至少四分之一由非股東專家擔任、其中半數由主管機關指派」，不是多數席次保留給官方。

5. 依我國期貨交易法之規定，公司制期貨交易所股票轉讓之對象不包括下列何者？
  1. (A)保險業
  2. (B)證券商
  3. (C)證券金融事業
  4. (D)銀行
解析

(A)正確。期貨交易法第三十七條第二項將公司制期貨交易所股票轉讓、出質之對象，限於依法設立之期貨業、證券商、證券金融事業、銀行，或經主管機關核准之證券及期貨相關機構；保險業不在列舉之內。限制股東身分是要讓股權留在與期貨市場交易、結算業務直接相關且受同一監理體系規範的金融機構手中，確保股東利益與市場健全運作一致。

(B)錯誤。證券商是條文明文列舉的受讓對象，且多數同時兼營期貨業務，與期貨市場運作直接相關。

(C)錯誤。證券金融事業屬條文列舉的受讓對象，其融資融券業務與集中市場的交易、結算機制關係密切。

(D)錯誤。銀行是條文明文列舉的受讓對象，在結算交割的資金清算環節扮演關鍵角色。

(D)錯誤。於每年稅後盈餘項下提列特別盈餘公積，屬結算機構應提列之項目。

8. 有關期貨結算機構查察結算會員之規定，下列敘述何者錯誤？
  1. (A)應查察結算會員之財務、業務及內部稽核作業情形
  2. (B)發現有違反法令或不當情事者，應即為適當處置，並通知主管機關及期貨交易所
  3. (C)結算會員內部稽核作業有重大缺失者，應即為專案檢查，並予輔導
  4. (D)結算會員不能履行結算、交割義務時，應即為專案檢查，並通報主管機關督導承受結算會員接辦結算及交割事務
解析

(A)錯誤。此敘述正確，結算機構應查察結算會員之財務、業務及內部稽核作業。

(B)錯誤。此敘述正確，發現違法或不當情事應即處置並通知主管機關及期貨交易所。

(C)錯誤。此敘述正確，內部稽核作業有重大缺失者應為專案檢查並予輔導。

(D)正確（即敘述有誤者）。結算會員已不能履行結算、交割義務時，事態不是「檢查與輔導」所能處理，結算機構應立即依業務規則代為履行並動用擔保履約財源、為必要之處置。專案檢查與輔導係針對內部稽核有重大缺失但尚能履約者，本選項將兩種情形的處理方式對調。

115年第1次｜期貨法規與自律規範｜第 8 題
9. 期貨結算機構對違反該機構業務規則之結算會員，可施予之處分有哪些？ Ⅰ.撤銷營業許可；Ⅱ.課以違約金；Ⅲ.警告；Ⅳ.停止或限制其於期貨結算機構所為結算、交割；Ⅴ.除名
  1. (A)Ⅰ、Ⅱ、Ⅲ、Ⅳ
  2. (B)Ⅰ、Ⅱ、Ⅲ、Ⅴ
  3. (C)Ⅰ、Ⅱ、Ⅳ、Ⅴ
  4. (D)Ⅱ、Ⅲ、Ⅳ、Ⅴ
解析

(A)錯誤。含Ⅰ撤銷營業許可。期貨結算機構與結算會員之間是契約與自律關係，撤銷營業許可屬剝奪營業資格的公權力處分，只有主管機關能為之。

(B)錯誤。同樣誤含Ⅰ，又漏掉Ⅳ停止或限制結算、交割——那正是結算機構在會員違約時最直接、最有效的風險隔離手段。

(C)錯誤。誤含Ⅰ，並漏掉Ⅲ警告。警告是最輕微的自律處分，用於情節尚輕、尚不需影響其結算權限的違規。

(D)正確。期貨結算機構管理規則規定，結算機構對違反其業務規則之結算會員，得課以違約金，並得警告或停止、限制其於結算機構所為之結算、交割，情節重大者並得予以除名。這四項都源於會員契約，屬自律範疇；撤銷營業許可則是主管機關的公權力，這條界線正是本題的考點。

115年第1次｜期貨法規與自律規範｜第 9 題
10. 依我國期貨交易法之規定，期貨商因期貨業務所生債務之債權人，對於期貨商下列何項款項有優先受清償之權？
  1. (A)賠償準備金
  2. (B)營業保證金
  3. (C)結算保證金
  4. (D)特別盈餘公積
解析

(A)錯誤。賠償準備金是期貨結算機構應提存、用於履行結算交割責任的財源，義務人是結算機構而非期貨商，與期貨商客戶債權的受償順位無關。

(B)正確。期貨交易法第六十條規定，期貨商應於開始營業前向主管機關指定之金融機構繳存營業保證金，且期貨商因期貨業務所生債務之債權人，對該營業保證金有優先受清償之權；動用後低於法定額度者並應補足。這等於先替客戶圈出一筆不受其他一般債權人追及的財產，在期貨商倒閉時提供最低限度的保障。

(C)錯誤。結算保證金是期貨商（結算會員）向結算機構繳存、用以擔保其結算交割義務的部位保證金，由結算機構依規則運用，不是留給期貨商一般業務債權人受償的財產。

(D)錯誤。特別盈餘公積是依公司法或相關規定自盈餘中提列的會計項目，屬淨值而非特定提存財產，債權人對它沒有優先受償權，公司清算時仍排在所有債權之後。

  2. (B)AI 具有跨產業擴散性並能誘發互補性創新

34. 資本移動性的增加，將使得浮動匯率制度下貨幣政策的效果：
  1. (A)增強
  2. (B)減弱
  3. (C)不變
  4. (D)不一定
解析

(A)正確。依Mundell-Fleming模型，浮動匯率下寬鬆貨幣政策壓低國內利率，引發資金外流、本幣貶值，淨出口增加而放大產出效果。資本移動性愈高，同樣的利差會帶動愈大的資金流動與愈強的貶值，匯率管道的放大效果愈明顯；資本完全移動時貨幣政策效果達到最大。

(B)錯誤。效果隨資本移動性上升而減弱的是固定匯率制度下的貨幣政策：央行必須賣出外匯買回本幣以守住匯率，等於把原先注入的貨幣又抽回，資本移動性愈高抽回愈快。

(C)錯誤。資本移動性直接決定資金流動與匯率調整的幅度，也就決定了匯率管道的強弱，政策效果不會維持不變。

(D)錯誤。在Mundell-Fleming的架構下，浮動匯率搭配資本移動性提高，貨幣政策效果變強的方向是明確的，並非不確定。
