1. 投顧公司經金管會許可經營全權委託業務後，應如何續行業務申請程序？
  1. (A)於三個月內申請換發營業執照
  2. (B)檢附公司章程
  3. (C)備齊書件直接函送金管會核發營業執照
  4. (D)選項(A)(B)(C)皆是
解析

(A)正確。經許可經營全權委託投資業務後，應於三個月內向主管機關申請換發營業執照。許可只是資格取得，須在期限內完成執照換發程序，業務範圍的變更才會反映在執照上並得以實際開辦。

(B)錯誤。公司章程僅係申請時應檢附之書件之一，並非本題所問之續行程序本身。

(C)錯誤。應依規定期限申請換發營業執照，而非備齊書件逕行函送核發。

(D)錯誤。僅（A）為正確之續行程序，其餘敘述不符規定。

2. 下列何者得擔任境外基金之總代理人？甲.證券投資信託事業；乙.證券投資顧問事業；丙.證券經紀商
  1. (A)僅丙
  2. (B)僅甲、乙
  3. (C)僅甲、丙
  4. (D)甲、乙、丙皆可
解析

(A)錯誤。除證券經紀商外，投信與投顧事業亦得擔任總代理人。

(B)錯誤。除投信、投顧事業外，證券經紀商亦得擔任總代理人。

(C)錯誤。投顧事業亦在得擔任總代理人之列。

(D)正確。證券投資信託事業、證券投資顧問事業與證券經紀商均得擔任境外基金之總代理人。三者都屬受監理、具備投資人服務與申報能量的機構，故均開放擔任，惟仍須符合資格條件並經核准。

3. 有關證券投資信託事業業務之經營，下列敘述何者錯誤？
  1. (A)提供分析意見或推介建議
  2. (B)接受客戶全權委託投資業務
  3. (C)運用證券投資信託基金從事證券及其相關商品之投資
  4. (D)向特定人私募證券投資信託基金交付受益憑證
解析

(A)正確（即敘述有誤者）。提供分析意見或推介建議屬證券投資顧問事業之業務，非投信事業本身之業務範圍。投信的角色是募集並運用基金為投資人操作，與對外提供投資建議在功能與責任上分屬兩類特許業務。

(B)錯誤。此為投信事業得經營之業務，投信經核准後得辦理全權委託投資。

(C)錯誤。此為投信事業之核心業務，運用基金從事證券及相關商品投資。

(D)錯誤。此為投信事業得經營之業務，向特定人私募基金並交付受益憑證。

4. 小明為甲投顧公司之董事，近日擬投資於丙投信公司，並有意擔任乙投顧公司之監察人，下列敘述何者為正確？
  1. (A)小明得為丙公司監察人
  2. (B)小明不得擔任乙公司監察人
  3. (C)小明得擔任乙公司監察人
  4. (D)選項(A)(B)正確
解析

(A)錯誤。投顧事業之董事亦不得兼任其他投信事業之監察人，投資與兼任職務是兩回事。

(B)正確。小明既為甲投顧公司之董事，即不得再擔任乙投顧公司之監察人。同業間互相兼任會使客戶資訊與投資決策在競爭同業之間流通，並產生忠實義務的衝突，故予禁止。

(C)錯誤。同業間兼任受有禁止，不得擔任乙公司監察人。

(D)錯誤。（A）之敘述並不正確，故此選項不成立。

5. 投信投顧公會審查申請經營全權委託案件，下列何者有誤？
  1. (A)須提出審查意見
  2. (B)於申請核准及換發執照階段，皆須提出審查意見
  3. (C)由金管會擬定之審查要點辦理
  4. (D)投信投顧公會應擬定審查要點報金管會備查
解析

(A)錯誤。公會受理全權委託申請案件確須提出審查意見，此敘述正確。

(B)錯誤。於申請核准及換發執照兩個階段，公會皆須提出審查意見，敘述正確。

(C)正確（即敘述有誤者）。審查要點係由投信投顧公會擬訂後報金管會備查，並非由金管會擬定。由自律機構先行審查、主管機關事後備查，是自律與行政監督的分工設計。

(D)錯誤。公會應擬定審查要點報金管會備查，此敘述與規定相符。

6. 有關全權委託投資業務，下列何者為正確？
  1. (A)每一全權委託投資帳戶之全權委託保管機構以一家為限
  2. (B)全權委託投資買賣契約簽約完成，受任人即可運用委託投資資產從事有價證券當日沖銷交易
  3. (C)客戶不得於全權委託投資契約存續期間變更全權委託保管機構
  4. (D)受任人於全權委託投資契約存續期間，應與客戶每二年至少進行一次訪談，以修正或補充客戶資料
解析

(A)正確。每一全權委託投資帳戶之保管機構以一家為限。單一帳戶對應單一保管機構，資產部位與交割才有唯一可勾稽的紀錄，分散保管會使監督與對帳失效。

(B)錯誤。運用委託投資資產從事當日沖銷交易，須與客戶另行約定，非簽約完成即當然可為。

(C)錯誤。客戶得於契約存續期間以書面通知變更全權委託保管機構。

(D)錯誤。二年並非規範所定之訪談頻率，客戶資料應以更高頻率檢視更新。

7. 投信事業申請（報）募集投信基金經核准後，未能於核准申請通知函送達後一定期限內開始募集，應如何處理？
  1. (A)向主管機關申請延展六個月
  2. (B)申請中斷時效
  3. (C)呈報公會延展六個月
  4. (D)向主管機關申請延展三個月
解析

(A)正確。核准後未能於所定期限內開始募集者，應向主管機關申請延展六個月，並以一次為限。設定期限是避免取得核准後長期閒置，佔用核准資源又使公開資訊過時。

(B)錯誤。法規並無「申請中斷時效」之處理方式。

(C)錯誤。延展屬主管機關權限，非向公會呈報。

(D)錯誤。延展期間並非三個月。

8. 投顧事業可否從事期貨或衍生性商品之宣導廣告？
  1. (A)應申請公會核准
  2. (B)應取得兼營期貨顧問業務之許可
  3. (C)事實發生後向同業公會報備
  4. (D)事實發生後向金管會報備
解析

(A)錯誤。公會核准並不能取代業務許可，廣告權限不得超出所獲許可之業務範圍。

(B)正確。期貨及衍生性商品之顧問屬期貨顧問業務，投顧事業須先取得兼營期貨顧問業務之許可，才得就此類商品從事宣導廣告。

(C)錯誤。未取得許可即宣傳，事後報備亦不能補正。

(D)錯誤。此屬事前許可事項，非事後向金管會報備即可。

9. 信託業兼營全權委託投資業務，擬運用所有信託財產購買甲上市公司股票，應注意投資之限額為何？
  1. (A)不超過甲已發行股份總額之20%
  2. (B)不超過甲已發行股份總額之10%
  3. (C)不超過所有受託金額10%
  4. (D)不超過受託投資資產淨資產價值之10%
解析

(A)錯誤。百分之二十非規定所定之限額。

(B)正確。運用所有信託財產投資任一上市公司股票，不得超過該公司已發行股份總額之百分之十。此為對單一發行公司的持股上限，目的在防止受託機構藉客戶資產取得對特定公司之控制力。

(C)錯誤。限額係以被投資公司已發行股份總額為分母，而非以受託金額計算。

(D)錯誤。此係以受託資產淨值為基準的分散規範，與本題所問之單一公司持股上限不同。

110年第1次｜投信投顧相關法規｜第 10 題
10. 投信事業對於業務往來之證券商，應採行哪些管理事項？
  1. (A)應簽訂書面約定，將退還手續費捐贈給慈善機構
  2. (B)定期對財務、業務及服務品質為評比
  3. (C)書面約定除退還之手續費外，不得接受證券商之其他利益
  4. (D)選項(A)(B)(C)皆是
解析

(A)錯誤。投信事業本即不得收受證券商退還之手續費，捐贈慈善機構不能使其正當化。

(B)正確。對業務往來之證券商應定期就財務、業務及服務品質進行評比。以客觀評比決定下單分配，可避免經理人依私人利益選擇券商，確保交易成本與執行品質對基金受益人最有利。

(C)錯誤。所謂「除退還之手續費外不得接受其他利益」的說法本身即有問題，退還手續費本就不得收受。

(D)錯誤。（A）（C）之敘述均與規範相牴觸，故非皆是。

11. 以下有關境外基金之敘述，何者為非？
  1. (A)境外基金之私募不得為一般廣告或公開勸募
  2. (B)境外基金是指於中華民國境外設立，具證券投資信託基金性質者
  3. (C)所有境外基金之銷售或代理募集者，皆需經中央銀行同意
  4. (D)任何人非經主管機關核准或向主管機關申報生效後，不得在中華民國境內從事或代理募集、銷售、投資顧問境外基金
解析

(A)錯誤。此敘述正確，私募本即不得為一般性廣告或公開勸誘。

(B)錯誤。此敘述正確，境外基金指於我國境外設立、具證券投資信託基金性質者。

(C)正確（即敘述有誤者）。境外基金之募集銷售須經主管機關（金管會）核准或申報生效，並非一律須經中央銀行同意；中央銀行僅在涉及外匯事項時才會被洽商。

(D)錯誤。此敘述正確，未經核准或申報生效不得在國內從事或代理募集、銷售、投資顧問境外基金。

12. 信託業兼營全權委託投資業務之操作，針對非專業投資機構之客戶，下列敘述何者錯誤？
  1. (A)應依據投資分析作成投資決定
  2. (B)分析、決定、執行及檢討等控制作業應留存紀錄，並至少保存五年
  3. (C)投資分析與決定應有合理基礎及依據
  4. (D)客戶不得要求查詢資產交易情形
解析

(A)錯誤。此敘述正確，投資決定應以投資分析為依據，不得憑臆測操作。

(B)錯誤。此敘述正確，分析、決定、執行及檢討之紀錄應留存並至少保存五年。

(C)錯誤。此敘述正確，投資分析與決定須有合理基礎及依據。

(D)正確（即敘述有誤者）。客戶對其委託投資資產之交易情形有查詢權，受任人不得拒絕。資產畢竟屬於客戶，全權委託只是授與操作裁量權，並未剝奪客戶知悉自身資產狀況的權利。

110年第1次｜投信投顧相關法規｜第 14 題
13. 投信事業或投顧事業經營全權委託投資業務，與客戶簽訂全權委託投資契約，以下敘述何者正確？
  1. (A)得接受共同委任或信託，但以三人為限
  2. (B)契約應載明客戶為公開發行公司之董事、監察人、經理人或10%以上之股東，其股權異動之有關法律責任
  3. (C)委託投資資產應於簽約後十日內分次存入全權委託保管機構
  4. (D)選項(A)(B)(C)皆是
解析

(A)錯誤。共同委任或信託之人數上限並非三人。

(B)正確。客戶若為公開發行公司之董事、監察人、經理人或持股達一定比例之股東，其股權異動涉及申報與短線交易等法律責任，契約須予載明。因為全權委託由受任人下單，但內部人身分的申報義務仍歸屬客戶本人，必須事先釐清。

(C)錯誤。委託投資資產應存入全權委託保管機構，「簽約後十日內分次存入」非規定所定之方式。

(D)錯誤。（A）（C）之敘述均不符規定，故非皆是。

14. 下列何者不是「中華民國證券投資信託暨顧問商業同業公會會員及其銷售機構從事廣告及營業促銷活動行為規範」之主要目的？
  1. (A)為宣傳基金產品專業安全
  2. (B)為保障投資人權益
  3. (C)為維護證券投信事業之專業形象
  4. (D)督促證券投資信託事業經營業務應恪遵之自律規範
解析

(A)正確（即非屬主要目的者）。行為規範是自律性的行為約束，目的在防止不當招攬與誇大宣傳，而不是替基金產品背書「專業安全」；任何暗示基金安全的宣傳本身正是規範要防堵的對象。

(B)錯誤。保障投資人權益確為該規範之主要目的。

(C)錯誤。維護投信事業之專業形象確為該規範之目的之一。

(D)錯誤。督促業者恪遵自律規範確為該規範之目的。
