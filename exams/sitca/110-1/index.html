1. 投顧公司經金管會許可經營全權委託業務後，應如何續行業務申請程序？
  1. (A)於三個月內申請換發營業執照
  2. (B)檢附公司章程
  3. (C)備齊書件直接函送金管會核發營業執照
  4. (D)選項(A)(B)(C)皆是
解析

(A)正確。依經營全權委託投資業務管理辦法第7條，應自金管會許可經營全權委託投資業務之日起三個月內，填具申請書並檢具規定書件申請換發營業執照；有正當理由者，得於期限屆滿前由同業公會轉報金管會申請展延一次，並以三個月為限。許可只是取得資格，營業執照上登載的業務項目才是對外得經營的範圍，故須在期限內完成換發。

(B)錯誤。公司章程是申請換發營業執照時應檢具的書件之一，屬文件清單而非許可後應進行的程序；備妥章程並不會使新增的全權委託業務登載到營業執照上。

(C)錯誤。程序是由業者在三個月內主動申請換發原有營業執照，而非備齊書件即可請金管會逕行核發新照。投顧事業本已持照，增列全權委託業務是在既有執照上換發登載，展延也須經同業公會轉報，並無直接函送核發的途徑。

(D)錯誤。(C)所述逕送核發與第7條的三個月申請換發不符，(B)只是應檢附書件之一，並非續行程序本身，三者不能同時成立。

3. 有關證券投資信託事業業務之經營，下列敘述何者錯誤？

  2. (B)接受客戶全權委託投資業務
  3. (C)運用證券投資信託基金從事證券及其相關商品之投資
  4. (D)向特定人私募證券投資信託基金交付受益憑證

(D)錯誤。此為投信事業得經營之業務，向特定人私募基金並交付受益憑證。

4. 小明為甲投顧公司之董事，近日擬投資於丙投信公司，並有意擔任乙投顧公司之監察人，下列敘述何者為正確？
  1. (A)小明得為丙公司監察人
  2. (B)小明不得擔任乙公司監察人
  3. (C)小明得擔任乙公司監察人
  4. (D)選項(A)(B)正確
解析

(A)錯誤。同業兼任的禁止不限於投顧對投顧：甲投顧的董事若同時擔任投信事業的監察人，一樣同時置身兩家受託操作他人資產的公司內部，可取得彼此的研究與下單資訊。買進丙公司股票是投資行為，與擔任丙公司監察人是兩件事，不能由前者推論後者可行。

(B)正確。投信投顧事業的董事、監察人、經理人受同業兼任禁止的拘束，小明既為甲投顧公司董事，即不得再出任乙投顧公司監察人。兩家公司對同一批客戶競爭，推介標的與進出時點屬高度敏感資訊，同一人跨坐兩邊必然發生忠實義務衝突，也難防資訊互通與對作。

(C)錯誤。方向正好相反，同業間兼任是被禁止而非原則允許。監察人的職責是監督乙公司的業務執行，由競爭同業的現任董事擔任，監督的獨立性從一開始就不存在。

(D)錯誤。(A)的敘述並不正確，投顧事業的董事亦不得擔任投信事業的監察人，因此(A)(B)無法同時成立，只有(B)符合規定。

  2. (B)於申請核准及換發執照階段，皆須提出審查意見

6. 有關全權委託投資業務，下列何者為正確？
  1. (A)每一全權委託投資帳戶之全權委託保管機構以一家為限
  2. (B)全權委託投資買賣契約簽約完成，受任人即可運用委託投資資產從事有價證券當日沖銷交易
  3. (C)客戶不得於全權委託投資契約存續期間變更全權委託保管機構
  4. (D)受任人於全權委託投資契約存續期間，應與客戶每二年至少進行一次訪談，以修正或補充客戶資料
解析

(A)正確。全權委託的架構是操作權與保管權分離：受任人只有投資決定權，客戶資產存放於全權委託保管機構開立的專戶。每一全權委託投資帳戶所對應的保管機構以一家為限，資產部位、交割與淨值才有唯一可勾稽的紀錄；若同一帳戶由數家分別保管，對帳與監督都會失效。

(B)錯誤。當日沖銷屬高風險的短線操作，須與客戶另行以書面約定授權後才得為之，並非契約一簽完即當然包含。全權委託的投資範圍與方式本來就應參酌客戶資力與交易經驗個別議定。

(C)錯誤。保管機構原則上由客戶指定，契約存續期間客戶亦得依約定程序通知變更，並非被鎖定不得更換；保留變更權，客戶才能在保管機構的服務或信用出現問題時保護自己的資產。

(D)錯誤。訪談的目的在確認客戶的財務狀況、投資目的與風險承受度是否仍與契約所訂投資方針相符，因此規範要求的檢視間隔明顯短於兩年。間隔拉長到每二年一次，期間客戶處境可能已完全改變，投資方針卻仍照舊執行。

7. 投信事業申請（報）募集投信基金經核准後，未能於核准申請通知函送達後一定期限內開始募集，應如何處理？
  1. (A)向主管機關申請延展六個月
  2. (B)申請中斷時效
  3. (C)呈報公會延展六個月
  4. (D)向主管機關申請延展三個月
解析

(A)正確。基金申請核准或申報生效後，事業應於通知函送達日起所定期間內開始募集；未能如期開始者，應於期限屆滿前向金管會申請延展，延展期間為六個月並以一次為限。設期限的理由是核准所依據的基金架構、費用與市場條件都會過時，久未募集的核准若無限期存在，等於讓業者囤著一張隨時可用的額度。

(B)錯誤。法規並無申請中斷時效這種程序。時效中斷是民法上請求權的概念，與行政核准效力的存續無關；募集期限屆至只能以事前申請延展處理，逾期則核准失其效力。

(C)錯誤。基金募集的核准與延展都屬金管會的權限，同業公會擔任的是自律、彙送與備查的角色。向公會呈報並不能延長金管會核准的效力，公會也無權替主管機關決定延展。

(D)錯誤。三個月是取得全權委託投資業務許可後應申請換發營業執照的期間（經營全權委託投資業務管理辦法第7條），與基金募集的延展無關；募集未能開始時得申請的延展期間為六個月。

8. 投顧事業可否從事期貨或衍生性商品之宣導廣告？
  1. (A)應申請公會核准
  2. (B)應取得兼營期貨顧問業務之許可
  3. (C)事實發生後向同業公會報備
  4. (D)事實發生後向金管會報備
解析

(A)錯誤。廣告是否須申請公會核准並不是重點。從事期貨或衍生性商品宣導的前提是業者具備從事該項業務的資格，未取得兼營期貨顧問業務的許可，即使廣告經公會看過也仍屬未經許可的業務行為。

(B)正確。投顧事業要從事期貨或衍生性商品的宣導廣告，前提是已取得兼營期貨顧問業務的許可。期貨顧問是期貨交易法下另一項須許可的業務，投顧事業僅具證券投資顧問的資格，若未取得期貨顧問許可就對期貨或衍生性商品作宣導，等於是以廣告從事未經許可的業務。

(C)錯誤。廣告及營業活動依自律規範固然有事後向投信投顧公會申報備查的機制，但備查檢視的是廣告內容，無法補正業務資格的欠缺。未取得兼營期貨顧問許可即對期貨或衍生性商品宣導，本身就是未經許可從事該項業務，事後報備不會使其合法。

(D)錯誤。廣告的事後申報是循自律機制向投信投顧公會辦理，金管會並不逐件受理廣告報備；且即使報備，未取得期貨顧問許可的問題也不會因此解決。

9. 信託業兼營全權委託投資業務，擬運用所有信託財產購買甲上市公司股票，應注意投資之限額為何？
  1. (A)不超過甲已發行股份總額之20%
  2. (B)不超過甲已發行股份總額之10%
  3. (C)不超過所有受託金額10%
  4. (D)不超過受託投資資產淨資產價值之10%
解析

(A)錯誤。20%在全權委託中確有其位置，但那是帳戶層次的分散限制——運用委託投資資產投資任一上市（櫃）公司股票，不得超過該委託投資帳戶淨資產價值之20%，分母是客戶帳戶而非被投資公司股本，與以已發行股份總額為分母的持股上限是兩套不同的規定。

(B)正確。信託業兼營全權委託投資業務，運用其所有信託財產投資任一上市（上櫃）公司股票，合計不得超過該公司已發行股份總額之10%。分母是被投資公司的股本，衡量的是影響力：受託機構管理的是他人資產，若可藉眾多客戶的資金取得單一公司高比例股權，等於用客戶的錢取得對該公司的控制力，且持股過重時也難以在市場上退出。

(C)錯誤。以所有受託金額的10%為限，量到的是受託機構自身的業務規模，管不到對特定公司的持股集中度。同一筆金額投在大型股與小型股上所代表的股權比重差距極大，用受託金額當分母無法限制控制力。

(D)錯誤。以受託資產淨資產價值為分母的比率屬於單一帳戶的分散規範（該類限制的比率為20%），防的是客戶帳戶對單一標的押注過重；而受託機構對某一發行公司的持股上限須以該公司已發行股份總額計算，兩者分母不同、目的也不同。

10. 投信事業對於業務往來之證券商，應採行哪些管理事項？
  1. (A)應簽訂書面約定，將退還手續費捐贈給慈善機構
  2. (B)定期對財務、業務及服務品質為評比
  3. (C)書面約定除退還之手續費外，不得接受證券商之其他利益
  4. (D)選項(A)(B)(C)皆是
解析

(A)錯誤。投信事業不得收受證券商退還的手續費，因為下單量是以受益人的資產換來的，回饋若由事業支配，就是拿基金的交易成本換取自己的利益；改以捐贈慈善機構的形式，支配權仍在事業手上，並不能使收受行為正當化。

(B)正確。投信事業對業務往來的證券商，應定期就其財務、業務及服務品質進行評比，並以評比結果作為分配下單的依據。基金的下單量本身就是一種可分配的利益，若由經理人憑私人關係決定給哪一家券商，成本與執行品質的損失由受益人承擔；以客觀評比決定分配，才能落實為受益人爭取最佳執行的義務。

(C)錯誤。這個敘述把前提寫反了：退還手續費本身即屬不得收受的利益，不能當成除此之外不得接受其他利益的例外基準；正確的界線是任何形式的回饋利益都不得收受。

(D)錯誤。(A)與(C)都與不得收受證券商回饋利益的規範相牴觸，真正屬於應採行管理事項的是對往來證券商的定期評比，故非三者皆是。
