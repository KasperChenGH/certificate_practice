1. 「鼓勵境外基金深耕計畫」之優惠措施中，總代理人申請代理境外基金之每次送件基金檔數上限為幾檔？
  1. (A)2 檔
  2. (B)3 檔
  3. (C)4 檔
  4. (D)5 檔
解析

(A)錯誤。2檔並非該計畫所定之每次送件上限。

(B)正確。深耕計畫之優惠措施中，總代理人申請代理境外基金每次送件之基金檔數上限為3檔。此屬對符合深耕條件業者放寬的行政便利措施。

(C)錯誤。4檔並非該計畫所定之每次送件上限。

(D)錯誤。5檔並非該計畫所定之每次送件上限。

2. 投信公司募集下列何種基金無需經過中央銀行同意？
  1. (A)國內募集投資國內且未涉及資金之匯出、匯入之股票型基金
  2. (B)貨幣市場基金
  3. (C)外幣計價基金
  4. (D)國外募集投資國內基金
解析

(A)正確。於國內募集、投資國內且未涉及資金匯出入之股票型基金，不生外匯收支問題，故無須經中央銀行同意。中央銀行的同意權著眼於外匯與資金流動，與此類純內國基金無涉。

(B)錯誤。貨幣市場基金運用於短期票券等貨幣市場工具，涉及中央銀行貨幣政策職掌，仍須經其同意。

(C)錯誤。外幣計價基金涉及外匯，須經中央銀行同意。

(D)錯誤。於國外募集投資國內之基金涉及資金匯出入，須經中央銀行同意。

3. 甲投信公司對所經營之乙投信基金之保管，應注意之事項，下列何者為真？
  1. (A)委由基金保管機構保管
  2. (B)甲公司之債務人得對乙基金之資產請求
  3. (C)乙資產與基金保管機構之各種基金同一帳戶保管分別設會計帳記錄
  4. (D)基金保管機構對乙之基金資產與甲之自有財產統一保管
解析

(A)正確。投信基金資產應委由基金保管機構保管。基金為獨立財產，交由與投信事業分離的保管機構持有，投資決定權與資產持有權才不會落在同一人手上。

(B)錯誤。基金資產獨立於投信事業之自有財產，投信事業之債權人不得對基金資產請求。

(C)錯誤。保管機構應將各基金分別獨立設帳保管，不得置於同一帳戶，僅在會計帳上區分並不足夠。

(D)錯誤。基金資產不得與投信事業之自有財產或保管機構自有財產混同保管。

114年第2次｜投信投顧相關法規｜第 4 題
4. 投信事業運用每一投信基金，應於每會計年度終了後幾個月內，編具年報？並經誰簽署後公告之？
  1. (A)一個月；投信投顧公會
  2. (B)二個月；基金保管機構
  3. (C)二個月；投信投顧公會
  4. (D)四個月；基金保管機構
解析

(A)錯誤。一個月之期限過短，且年報並非由公會簽署。

(B)正確。應於每會計年度終了後二個月內編具年報，並經基金保管機構簽署後公告。由持有基金資產的保管機構簽署，等於對帳務與資產部位作獨立勾稽，而非投信事業自說自話。

(C)錯誤。期限雖為二個月，但簽署者為基金保管機構，不是同業公會。

(D)錯誤。四個月並非規範所定之編製期限。

5. 總代理人得在國內代理幾個境外基金管理機構之基金銷售？
  1. (A)限五個
  2. (B)限三個
  3. (C)限二個
  4. (D)一個以上
解析

(A)正確。一名總代理人在國內至多得代理五個境外基金管理機構之基金銷售。設定上限是避免單一總代理人責任過度集中，超出其人力與履行義務的負荷能力。

(B)錯誤。三個並非規範所定之上限。

(C)錯誤。二個並非規範所定之上限。

(D)錯誤。並非毫無上限，法規對代理之機構家數設有明確限制。

6. 有關「債券型基金」之敘述，下列何者正確？甲.得投資達基金淨資產價值20%之轉換公司債；乙.資產組合之加權平均存續期間應在1 年以上；丙.不得投資正向浮動利率債券
  1. (A)僅甲
  2. (B)僅乙
  3. (C)甲、丙
  4. (D)甲、乙、丙皆正確
解析

(A)錯誤。僅甲並不正確，甲所述之可轉換公司債投資比率高於規範上限。

(B)正確。僅乙為真：債券型基金資產組合之加權平均存續期間應在一年以上。存續期間下限用來確保基金確實維持債券型的利率風險屬性，不致名為債券型卻操作成類貨幣市場基金。

(C)錯誤。甲之比率過高；丙亦有誤，債券型基金得投資正向浮動利率債券，受限制者為反向浮動利率債券。

(D)錯誤。甲、丙均有誤，僅乙正確。

7. 投信事業發行受益憑證募集投信基金，應先向申購之投資大眾交付：
  1. (A)投資說明書
  2. (B)公開說明書

(C)錯誤。財務報告並非應先交付投資人之文件。

(D)錯誤。證券投資信託契約副本非應先行交付申購人之法定文件。

114年第2次｜投信投顧相關法規｜第 9 題
8. 有關投信事業募集基金、運用基金資產應遵守之規定，下列何者有誤？
  1. (A)不得投資於未上市、未上櫃股票或私募有價證券
  2. (B)不得從事證券信用交易
  3. (C)不得轉讓基金所購入股票發行公司股東會之委託書
  4. (D)不得投資正向浮動利率債券
解析

(A)錯誤。不得投資未上市、未上櫃股票或私募有價證券，係因流動性與評價不足，此敘述正確。

(B)錯誤。不得從事證券信用交易，避免基金以融資融券放大槓桿，敘述正確。

(C)錯誤。不得轉讓所購入股票發行公司股東會之委託書，敘述正確。

(D)正確（即敘述有誤者）。基金得投資正向浮動利率債券；受限制的是反向浮動利率債券等具槓桿或利率反向連動性質的商品，兩者風險特性截然不同。

9. 依證券投資信託基金管理辦法規定貨幣市場基金之加權平均存續期間不得大於幾日？
  1. (A)90 日
  2. (B)180 日
  3. (C)300 日
  4. (D)360 日
解析

(A)錯誤。90日並非規範所定之加權平均存續期間上限。

(C)錯誤。300日並非規範所定之上限。

(D)錯誤。360日並非規範所定之上限。

11. 傘型基金以資產配置為其理念，下列有關傘型基金之規範敘述何者錯誤？
  1. (A)傘型基金係於該基金下投資不同之子基金
  2. (B)子基金依資產配置理念，選擇某一種類基金為區隔配置或交叉組合各種基金
  3. (C)子基金數得超過三檔，且應依次申請同時募集
  4. (D)子基金間不得有自動轉換機制，子基金間之轉換須由投資人申請方得辦理
解析

(A)錯誤。傘型基金於同一架構下設置不同子基金，敘述正確。

(B)錯誤。子基金依資產配置理念作區隔配置或交叉組合，敘述正確。

(C)正確（即敘述錯誤者）。子基金檔數設有上限而不得超過，且各子基金應同時申請、同時募集，並非「依次申請」分批辦理，否則傘型架構的整體資產配置設計即無從落實。

(D)錯誤。子基金間不得設自動轉換機制，轉換須由投資人申請，敘述正確。

114年第2次｜投信投顧相關法規｜第 13 題
12. 投信投顧事業審查投資人全權委託申請符合法定條件時，與客戶應簽立下列哪些契約？甲.全權委託投資契約；乙.與全權委託保管機構共同簽訂三方權義協定書
  1. (A)僅甲
  2. (B)僅乙
  3. (C)甲、乙皆是
  4. (D)甲、乙皆非
解析

(A)錯誤。僅簽全權委託投資契約，未涵蓋保管機構之權責。

(B)錯誤。三方權義協定書之外，仍須與客戶簽訂全權委託投資契約。

(D)錯誤。兩份文件皆為法定應簽立者。

13. 投信公司運用甲投資人全權委託投資資產，投資於A 上市公司股票，應注意下列何限制？
  1. (A)不超過甲委託資產淨資產價值之10%
  2. (B)不超過甲委託資產淨資產價值之20%
  3. (C)不超過甲委託資產總額30%
  4. (D)不超過甲委託資產總額40%
解析

(A)錯誤。10%並非規範所定之個股投資上限。

(C)錯誤。上限係以淨資產價值計算，且30%非所定比率。

(D)錯誤。上限係以淨資產價值計算，且40%非所定比率。

114年第2次｜投信投顧相關法規｜第 17 題
