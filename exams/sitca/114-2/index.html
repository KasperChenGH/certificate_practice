1. 「鼓勵境外基金深耕計畫」之優惠措施中，總代理人申請代理境外基金之每次送件基金檔數上限為幾檔？
  1. (A)2 檔
  2. (B)3 檔
  3. (C)4 檔
  4. (D)5 檔
解析

(A)錯誤。2檔低於計畫給予的額度。深耕計畫的優惠是在境外基金機構已於臺灣投入研究、產品設計或人力等資源的前提下，放寬其總代理人送審基金的行政便利；若每次只能送2檔，業者仍得反覆送件，達不到縮短產品上架時程的效果。計畫所定的上限是3檔。

(B)正確。「鼓勵境外基金深耕計畫」是金管會以行政便利與額度放寬（例如國內投資人投資個別境外基金的比率由50%提高至70%）換取境外基金機構在臺實質投入的措施，其中一項優惠是總代理人申請代理境外基金時，每次送件的基金檔數上限為3檔。一次併送多檔可省下重複的申報與審查程序，讓已深耕臺灣的業者較快把完整產品線搬上架。

(C)錯誤。4檔超過計畫所定的3檔。每次送件檔數若放得太寬，主管機關同時要審查大量新基金的中文公開說明書、投資策略與費用揭露，審查品質會被稀釋，因此優惠的幅度以3檔為度而非無限放寬。

(D)錯誤。5檔是境外基金管理辦法第3條第2項對「總代理人得代理的境外基金管理機構家數」所設的上限（以五家為限），屬代理對象的家數限制，與深耕計畫每次送件基金檔數的3檔是兩回事，容易互相混淆。

2. 投信公司募集下列何種基金無需經過中央銀行同意？
  1. (A)國內募集投資國內且未涉及資金之匯出、匯入之股票型基金
  2. (B)貨幣市場基金
  3. (C)外幣計價基金
  4. (D)國外募集投資國內基金
解析

(A)正確。於國內募集、投資國內且未涉及資金匯出入之股票型基金，不生外匯收支問題，故無須經中央銀行同意。中央銀行的同意權著眼於外匯與資金流動，與此類純內國基金無涉。

(B)錯誤。貨幣市場基金運用於短期票券等貨幣市場工具，涉及中央銀行貨幣政策職掌，仍須經其同意。

(C)錯誤。外幣計價基金涉及外匯，須經中央銀行同意。

(D)錯誤。於國外募集投資國內之基金涉及資金匯出入，須經中央銀行同意。

3. 甲投信公司對所經營之乙投信基金之保管，應注意之事項，下列何者為真？
  1. (A)委由基金保管機構保管
  2. (B)甲公司之債務人得對乙基金之資產請求
  3. (C)乙資產與基金保管機構之各種基金同一帳戶保管分別設會計帳記錄
  4. (D)基金保管機構對乙之基金資產與甲之自有財產統一保管
解析

(A)正確。投信基金資產應委由基金保管機構保管。基金為獨立財產，交由與投信事業分離的保管機構持有，投資決定權與資產持有權才不會落在同一人手上。

(B)錯誤。基金資產獨立於投信事業之自有財產，投信事業之債權人不得對基金資產請求。

(C)錯誤。保管機構應將各基金分別獨立設帳保管，不得置於同一帳戶，僅在會計帳上區分並不足夠。

(D)錯誤。基金資產不得與投信事業之自有財產或保管機構自有財產混同保管。

4. 投信事業運用每一投信基金，應於每會計年度終了後幾個月內，編具年報？並經誰簽署後公告之？
  1. (A)一個月；投信投顧公會
  2. (B)二個月；基金保管機構
  3. (C)二個月；投信投顧公會
  4. (D)四個月；基金保管機構
解析

(A)錯誤。兩段都不對。一個月不足以完成基金年度帳務結算與查核作業；且投信投顧公會是自律組織，並不持有基金資產，無從就年報所載的資產部位為簽署，簽署者應是保管基金資產的基金保管機構。

(B)正確。投信事業運用每一投信基金，應於每會計年度終了後二個月內編具年報，並經基金保管機構簽署後公告。由持有基金資產、負責保管與交割的保管機構簽署，等於對基金的部位與帳務作一次獨立勾稽，而不是投信事業自己說自己的績效；期限訂為二個月，也讓受益人在年度結束後不久就能取得完整資訊。

(C)錯誤。二個月的期限正確，但簽署者不是同業公會。公會的職能是訂定自律規範並查核會員行為，並未經手基金資產，無法核對基金的持股與現金部位；能與投信事業的帳互相勾稽的是基金保管機構。

(D)錯誤。四個月接近公開發行公司年度財務資訊的節奏（證交法第36條為會計年度終了後三個月內公告申報年度財務報告），投信基金每日計算淨值、帳務較單純，年報期限反而更短，定為二個月。

114年第2次｜投信投顧相關法規｜第 5 題
5. 總代理人得在國內代理幾個境外基金管理機構之基金銷售？
  1. (A)限五個
  2. (B)限三個
  3. (C)限二個
  4. (D)一個以上
解析

(A)正確。境外基金管理辦法第3條第2項規定，總代理人代理境外基金之募集及銷售，以五家境外基金管理機構為限。總代理人要對每一家機構的基金負起公開說明書中譯本更新、資訊揭露、申購買回款項收付與投資人申訴處理的責任，家數無限擴張會超出其人力與履行義務的能力；營業保證金也隨代理家數遞增（一家三千萬元，逐家加計），使責任與提存相稱。

(B)錯誤。三家是營業保證金級距中的一階（代理三家境外基金管理機構提存七千萬元），而不是可代理的家數上限；辦法允許同一總代理人代理至五家。

(C)錯誤。二家同樣只是提存級距之一（五千萬元）。真正是「單一」的是反方向的限制：一家境外基金管理機構在國內只能委任一個總代理人，但一個總代理人可代理多家機構，最多五家。

(D)錯誤。「一個以上、不設上限」描述的是銷售機構——境外基金管理辦法第3條第3項規定銷售機構得代理一個以上境外基金；總代理人則明定以五家境外基金管理機構為限，兩種角色的限制不同。

6. 有關「債券型基金」之敘述，下列何者正確？甲.得投資達基金淨資產價值20%之轉換公司債；乙.資產組合之加權平均存續期間應在1 年以上；丙.不得投資正向浮動利率債券
  1. (A)僅甲
  2. (B)僅乙
  3. (C)甲、丙
  4. (D)甲、乙、丙皆正確
解析

(A)錯誤。甲的比率過高。證券投資信託基金管理辦法第27條第2項規定，債券型基金投資轉換公司債、附認股權公司債、交換公司債及具損失吸收能力債券的總金額，不得超過基金淨資產價值之10%，不是20%。這些標的帶有股權性質，比重放到兩成，基金報酬就會明顯隨股價起伏而背離債券型的定位。

(B)正確。只有乙成立。證券投資信託基金管理辦法第29條規定債券型基金資產組合的加權平均存續期間應在一年以上（基金成立未滿三個月、契約終止日前一個月或主要投資於正向浮動利率債券者除外），以確保基金確實承擔債券的利率風險，不致名為債券型卻操作成準貨幣市場基金。甲的上限是10%而非20%；丙則方向相反，第27條把正向浮動利率債券明文排除在禁止投資的結構式利率商品之外。

(C)錯誤。甲、丙都不成立。甲所稱的轉換公司債等總額上限，第27條定的是淨資產價值10%；丙把規範方向弄反了，第27條禁止債券型基金投資結構式利率商品，但明文將正向浮動利率債券排除在禁止之列，受限制的是反向浮動利率這類與利率走勢相反連結的結構式商品。

(D)錯誤。甲的比率（應為10%）與丙的方向（正向浮動利率債券得投資）都有誤，只有乙的存續期間一年以上符合第29條，因此三者皆正確不成立。

114年第2次｜投信投顧相關法規｜第 8 題
7. 投信事業發行受益憑證募集投信基金，應先向申購之投資大眾交付：
  1. (A)投資說明書
  2. (B)公開說明書
  3. (C)經會計師查核簽證之財務報告
  4. (D)證券投資信託契約副本
解析

(A)錯誤。投資說明書是私募基金向特定人招募時交付的說明文件，應募對象限於銀行、保險、專業投資人等有能力自行評估風險者；公開募集面對的是一般投資大眾，應先交付的法定文件是公開說明書。

(B)正確。投信事業募集基金發行受益憑證，應先向申購的投資大眾交付公開說明書，其應記載事項由主管機關訂定。公開說明書載明基金的投資範圍與策略、風險揭露、各項費用、經理公司與基金保管機構等資訊，是投資人作成決定前的法定資訊基礎；先交付再受理申購，才能認定投資人已有機會知悉風險，記載不實時也有可歸責的文件與責任主體。

(C)錯誤。經會計師查核簽證的財務報告屬事後的定期財務揭露，是投信事業與各基金應編製、申報並公告的資訊；新募集的基金在申購階段還沒有財務報告可供交付，投資人決策所需的資訊來自公開說明書。

(D)錯誤。證券投資信託契約是投信事業與基金保管機構之間所訂的契約，其重要內容已摘要載入公開說明書，投資人另有閱覽或抄錄的途徑，但法律要求申購前先行交付的文件是公開說明書，而不是契約副本。

114年第2次｜投信投顧相關法規｜第 9 題
8. 有關投信事業募集基金、運用基金資產應遵守之規定，下列何者有誤？
  1. (A)不得投資於未上市、未上櫃股票或私募有價證券
  2. (B)不得從事證券信用交易
  3. (C)不得轉讓基金所購入股票發行公司股東會之委託書
  4. (D)不得投資正向浮動利率債券
解析

(A)錯誤。不得投資未上市、未上櫃股票或私募有價證券，係因流動性與評價不足，此敘述正確。

(B)錯誤。不得從事證券信用交易，避免基金以融資融券放大槓桿，敘述正確。

(C)錯誤。不得轉讓所購入股票發行公司股東會之委託書，敘述正確。

(D)正確（即敘述有誤者）。基金得投資正向浮動利率債券；受限制的是反向浮動利率債券等具槓桿或利率反向連動性質的商品，兩者風險特性截然不同。

9. 依證券投資信託基金管理辦法規定貨幣市場基金之加權平均存續期間不得大於幾日？
  1. (A)90 日
  2. (B)180 日
  3. (C)300 日
  4. (D)360 日
解析

(A)錯誤。90日只有規定上限的一半。把加權平均存續期間壓到三個月以內，基金幾乎只能持有極短天期的票券，收益貼近隔夜利率，也無法為受益人取得正常的貨幣市場收益；證券投資信託基金管理辦法所定的上限是180日。

(B)正確。依證券投資信託基金管理辦法，貨幣市場基金資產組合的加權平均存續期間不得大於180日。存續期間就是利率敏感度的度量，把它限制在半年以內，利率走升時淨值的跌幅才會極小，投資人才能把貨幣市場基金當成準現金工具隨時申購買回而不致產生明顯損失。

(C)錯誤。300日已接近規定上限的兩倍。存續期間拉到十個月，基金的利率敏感度會與短期債券型基金相當，卻仍以貨幣市場基金的名義供投資人當現金替代工具使用，這種名實不符正是上限要防止的。

(D)錯誤。360日幾乎等於一年，反而落在債券型基金「加權平均存續期間一年以上」（第29條）的門檻附近，與貨幣市場基金追求低波動、高流動性的定位正好相反；貨幣市場基金的上限是180日。

10. 依據證券投資信託事業募集證券投資信託基金處理準則，因故意、過失或違反銷售契約或法令規定，致損害投資人之權益者，應負損害賠償責任。下列何者為應負賠償責任之主體？
  1. (A)基金銷售機構及其董事
  2. (B)基金銷售機構及其董事、經理人
  3. (C)基金銷售機構及其董事、經理人、受僱人
  4. (D)基金銷售機構及其董事、監察人、經理人、受僱人
解析

(A)錯誤。只列銷售機構及其董事，漏掉監察人、經理人與受僱人。實際接觸投資人、說明基金內容並完成適合度評估的往往是受僱人員，把責任限縮在董事層級，投資人反而找不到真正經手的人負責。

(B)錯誤。加上經理人仍不完整，還漏掉監察人與受僱人。監察人對機構業務有監督職責，受僱人則是銷售行為的實際執行者，兩者都在準則所列的賠償責任主體之內。

(C)錯誤。董事、經理人、受僱人之外還包括監察人。監察人雖不執行業務，但對銷售作業與內部控制的監督有其職責，準則並未把它排除在損害賠償責任主體之外。

(D)正確。依證券投資信託事業募集證券投資信託基金處理準則，因故意、過失或違反銷售契約、法令規定致損害投資人權益者，基金銷售機構及其董事、監察人、經理人、受僱人均應負損害賠償責任。責任主體採廣列方式，是避免機構以內部分工、職位層級或「那是業務員個人行為」推卸責任，也讓機構有動機把教育訓練與銷售控管做在事前。

43. 依「證券投資信託事業經理守則」規定，經手人員個人交易買入某種股票須持有至少幾日以上？
  1. (A)10 日
  2. (B)30 日
  3. (C)15 日
  4. (D)20 日
解析

(A)錯誤。十日不到兩週交易日，仍屬短線操作的範圍，經手人員可以在一波行情內完成進出，無法切斷職務資訊與個人獲利之間的連結；守則所定的最短持有期間比這長。

(B)正確。依證券投資信託事業經理守則，經手人員個人交易買入某種股票後須持有至少三十日以上。設定最短持有期間的用意不是限制理財，而是讓經手人員無法利用職務上知悉的基金買賣計畫作短線進出：若必須抱滿三十日，搶在基金前面買進再倒給基金的操作就不再有把握獲利，誘因自然降低。

(C)錯誤。十五日約為三週，仍在短線區間。守則要拉長的是個人部位與職務資訊脫鉤的時間，十五日不足以讓資訊優勢消退，也不是守則明定的期間。

(D)錯誤。二十日雖比十日長，仍短於守則所定的期間。經手人員個人交易的最短持有期間訂在三十日，正是以一個月以上的鎖定期換取對短線利益衝突的抑制。
