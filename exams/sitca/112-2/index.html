2. 證券投資信託基金管理辦法之規定，證券投資信託基金之淨資產價值由誰計算？
  1. (A)證券投資信託公司
  2. (B)基金保管銀行
  3. (C)投信投顧公會
  4. (D)證券投資信託契約約定
解析

(A)正確。依證券投資信託基金管理辦法，基金的淨資產價值由證券投資信託事業計算，再由基金保管機構複核。把計算與保管、複核分由兩個獨立機構承擔，形成相互勾稽：投信事業掌握投資決策與評價方法，保管機構掌握實際持有的資產與現金，兩邊對不上帳就會被發現，可以防止以評價手法美化淨值或掩飾資產短少。

(B)錯誤。基金保管機構負責基金資產的保管、款券收付與淨值的複核，是勾稽的一方而非計算者。若由保管機構自行計算再自行複核，獨立複核的意義就消失了。

(C)錯誤。投信投顧公會是自律組織，辦理自律規範、會員與人員登錄及資訊彙整申報等事務，並不介入個別基金每日淨值的計算。

(D)錯誤。誰計算淨值是法規明定的分工，不容當事人以契約變更；若可自由約定，投信事業就可能把計算與保管交由同一方，內部牽制隨之消失。

4. 金管會對國內初次募集發行之股票型基金申報生效案件，於金管會收到申報書即日起屆滿幾個營業日生效？
  1. (A)12
  2. (B)15
  3. (C)20
  4. (D)30
解析

(A)正確。國內初次募集發行之股票型基金採申報生效制，自金管會收到申報書即日起屆滿十二個營業日生效。申報生效制的特點是期間屆滿即自動生效，不必等逐案核准；股票型基金的投資標的與操作方式已高度標準化，審查重點在書件是否完備與是否符合既定規範，故以較短的法定期間取代實質審查，兼顧發行效率與監理。

(B)錯誤。十五個營業日常被誤認成半個月，但申報生效期間是以營業日計算而非日曆日的半月，股票型基金初次募集適用的期間比這短。

(C)錯誤。二十個營業日已接近一個完整月份的交易日數。若標準化程度最高的股票型基金都要等這麼久，申報生效制相較核准制的效率優勢便不存在。

(D)錯誤。三十個營業日約一個半月，募集計畫與當時的市場環境早已脫節。申報生效制的設計就是以屆滿一定營業日自動生效取代個案審查，期間不會拉到這種長度。

5. Y 投信公司發生對投資人權益有重大影響事項，依法應如何處理？
  1. (A)於事實發生之日起二日內申報
  2. (B)於事實發生後三日內公告
  3. (C)於事實發生後三日內抄送主管機關
  4. (D)於事實發生之日起二日內公告並向金管會申報
解析

(A)錯誤。只申報而不公告，等於資訊僅到主管機關手上，受影響的受益人仍不知情。重大影響事項的處理是公告與申報並行，缺了公告這一半，投資人無從決定是否申購或買回。

(B)錯誤。只公告而未向金管會申報，主管機關便無法及時檢視與介入，且日數也不合規定。公告與申報各有其對象與功能，不能相互取代。

(C)錯誤。抄送並非法定的處理方式，且日數也不符規定。法規要求的是對外公告並向主管機關申報，把文件抄送備查無法達到揭露與監理的雙重效果。

(D)正確。對投資人權益有重大影響之事項，投信事業應於事實發生之日起二日內公告並向金管會申報。兩道程序缺一不可：公告讓投資人在申購、買回的決定上不致資訊落後，申報則讓主管機關能立即檢視事業的處理與後續影響；期限壓在二日，是因為重大事項對基金淨值與申購買回的影響往往即時發生。

112年第2次｜投信投顧相關法規｜第 7 題
7. 若某上市公司增資發行100 萬股新股，甲投信公司所發行之5 支基金均看好該公司欲認購，甲投信公司所有基金最多共可認購多少股？
  1. (A)1 萬股
  2. (B)3 萬股
  3. (C)5 萬股
  4. (D)10 萬股
解析

(A)錯誤。一萬股只是一百萬股的百分之一，把比率記成百分之一才會得到這個數字。規範就同一次發行新股所設的合計上限不是百分之一，這樣的限制也會使基金幾乎無法參與一般規模的現金增資。

(B)錯誤。三萬股相當於百分之三，而百分之三是證券投資信託基金管理辦法就每一基金參與任一公司承銷股票所定的比率；本題問的是甲投信五支基金合計可認購的上限，適用全部基金合計的比率，不是單一基金的比率。

(C)錯誤。五萬股即百分之五，介於每一基金的百分之三與全部基金合計的百分之十之間，辦法並沒有這個級距；把兩道限制取中間值就會得到這個數字。

(D)正確。依證券投資信託基金管理辦法，同一投信事業運用其所經理之全部基金認購同一次發行之新股，合計不得超過該次發行股數之百分之十，一百萬股×10%＝十萬股。以全部基金合計計算，是為了防止業者以分設多支基金的方式規避單一持股上限，並避免同一事業對單一發行人取得過大的影響力。

(C)錯誤。董事會為公司內部機關，其同意不能排除法令的強制規定。

(D)錯誤。公會為自律組織，無權同意受任人保管客戶資產。

112年第2次｜投信投顧相關法規｜第 9 題
9. 投信投顧事業為招攬與促銷全權委託投資之業務而製作之有關資料，於對外使用前，應先經內部適當審核，其中有關廣告、公開說明會及其他公開促銷活動之資料，應於事實發生後幾日內向同業公會申報？
  1. (A)五日
  2. (B)七日
  3. (C)十日
  4. (D)十五日
解析

(A)錯誤。五日短於規範所定的期限。這類資料的控管方式是對外使用前先經內部適當審核、事後再向公會申報，申報期間須留給業者完成內部審核與留存紀錄，過短會使申報流於形式。

(B)錯誤。七日是投顧契約客戶得以書面終止契約的天數（自收受書面契約之日起七日內），屬投資人的冷靜期，與廣告及公開促銷資料向同業公會申報的期限不是同一件事。

(C)正確。為招攬與促銷全權委託投資業務所製作的廣告、公開說明會及其他公開促銷活動資料，應先經內部適當審核，並於事實發生後十日內向同業公會申報。採事前內部審核、事後向公會申報而非逐件事前核准，是因為行銷有時效性；由公會事後抽核，既保留自律監督與違規追究的空間，也不至於讓每一份文宣都卡在審查流程上。

(D)錯誤。十五日等於事後半個月才進入自律監督的視野，違規廣告的影響已經擴散，事後申報的把關意義大減；規範定的是事實發生後十日內。

10. 甲投信公司接受乙投資人全權委託投資資產，對於乙投資帳戶內上市公司股票所生之股息、股利依規定應如何分配？
  1. (A)分配至乙全權委託投資帳戶
  2. (B)直接分配給乙投資人
  3. (C)分配至甲公司帳戶
  4. (D)分配至全權委託保管機構
解析

(A)正確。委託投資資產所生的股息、股利屬該資產的孳息，依全權委託的架構應分配至乙的全權委託投資帳戶，由受任人在契約所定方針下繼續運用。孳息隨本金歸屬客戶是全權委託的基本設計：客戶的資產始終存放在保管機構名下的專戶，受任人只有運用決定權而無所有權，所以任何因該資產產生的收益都必須回到同一帳戶，才能在淨資產價值與績效計算上完整反映。

(B)錯誤。直接付給乙個人會把孳息抽離委託投資資產，使帳戶的資產價值與績效計算失真，客戶下次核對月報時也對不上；孳息應留在帳戶內續行運用，客戶要取用則走契約約定的提取程序。

(C)錯誤。撥入甲公司帳戶等於受任人取得客戶資產的收益，違反受任人不得將委託投資資產與自有財產混同、不得為自己利益使用客戶資產的基本義務，情節重者更可能構成侵占。

(D)錯誤。保管機構只是依契約保管資產、辦理款券收付與複核，並非受益主體。股息股利雖由保管機構代為收取，仍須計入客戶的全權委託投資帳戶，不會留在保管機構自己的帳上。

112年第2次｜投信投顧相關法規｜第 12 題
12. 下列何者可為投信事業之發起人？ 甲、受破產之宣告，已復權者；乙、使用票據經拒絕往來尚未期滿者；丙、無行為能力或限制行為能力者
  1. (A)僅甲
  2. (B)僅乙
  3. (C)僅甲、丙
  4. (D)甲、乙、丙皆不可
解析

(C)錯誤。這一組以公關部門取代投資研究部門。全權委託是受任人自行決定投資標的與時機，沒有研究部門支撐，投資決策將缺乏可查核的依據，也難以說明操作符合客戶的投資方針。

(D)錯誤。這一組漏掉最關鍵的全權委託專責部門。專責部門的意義在於人員、資訊與作業流程與其他業務分離，避免經理人同時接觸自營、投顧或其他客戶的委託資訊；少了它，其餘部門的設置無法補足利益衝突的隔離。

34. 投信事業委由國外代理機構將所持有之外國有價證券辦理出借，以下敘述何者正確？
  1. (A)國外代理機構須成立滿兩年以上
  2. (B)國外代理機構保管之資產達3,000 億美元以上
  3. (C)借券擔保品維持率分別不得低於100%及105%
  4. (D)借貸期間自借貸成交日起算不得超過9 個月
解析

(A)錯誤。對國外代理機構的要求著重於其是否受當地主管機關監理、具備相當的信用評等與有價證券保管、借貸作業能力，而不是單純的成立年限；成立滿兩年並不能說明機構的償付能力與作業水準。

(B)錯誤。規範對國外代理機構確有保管資產規模等實力要求，但三千億美元不是所定的數額。這個量級只有極少數全球保管銀行達得到，若真以此為門檻，實際上等於禁止投信基金辦理外國有價證券出借。

(C)正確。委由國外代理機構辦理外國有價證券出借時，借券擔保品的維持率分別不得低於百分之一百及百分之一百零五，且擔保品須逐日按市價評價，不足時即應補繳。出借的風險在於借用人屆期不返還證券，基金只能靠擔保品受償；維持率訂在足額之上並留一段緩衝，是為了讓擔保品在市價下跌時仍足以買回同種證券，緩衝太薄則一次跳空就可能出現擔保不足。

(D)錯誤。九個月不是規範所定的借貸期間上限。基金必須隨時應付受益人買回，出借期間若拉長到近一年，標的被借走而無法即時召回，會直接影響基金的變現能力與淨值計算，因此期間上限訂得較短，並搭配得隨時終止借貸的約定。

35. 下列對於投信基金之管理敘述，何者為非？
  1. (A)應符合法令或投信契約所准許之投資範圍、投資方針及投資限制進行
  2. (B)應基於投資當時所能取得之最佳條件，於顧及市場現況下執行交易

  4. (D)如修改分配方法，應以電話通知方式告知，並不得令客戶遭受損失

36. 投信公司擔任2 家境外基金管理機構之總代理人，需提存多少營業保證金？
  1. (A)新臺幣2,000 萬元
  2. (B)新臺幣3,000 萬元
  3. (C)新臺幣5,000 萬元
  4. (D)新臺幣7,000 萬元
解析

(A)錯誤。新臺幣二千萬元是境外基金管理辦法就銷售機構以自己名義為投資人向總代理人申購境外基金所定的提存額，涵蓋的是銷售機構身分，不是擔任總代理人依代理家數應提存的金額。

(B)錯誤。三千萬元是擔任一家境外基金管理機構總代理人的提存額。本題擔任二家，應按級距加計，不能停留在一家的金額。

(C)正確。依境外基金管理辦法第十條，總代理人依所代理的境外基金管理機構家數提存營業保證金：一家三千萬元、二家五千萬元、三家七千萬元，每多一家加計二千萬元，故擔任二家總代理人應提存新臺幣五千萬元。採級距遞增是因為總代理人要對其所代理的每一家機構、每一檔基金負責文件申報、資訊揭露與投資人權益處理，代理家數越多、潛在賠償責任越大，擔保也必須同步加厚。

(D)錯誤。七千萬元是擔任三家境外基金管理機構總代理人的提存額，比本題多算了一家。級距每增加一家加二千萬元，二家與三家之間正好相差這個數字。

37. 基金銷售機構終止辦理基金銷售業務者，應即通知投信事業，並由投信事業於事實發生日起幾日內，向投信投顧公會申報並公告？
  1. (A)二日
  2. (B)五日
  3. (C)七日
  4. (D)十日
解析

(A)正確。基金銷售機構終止辦理基金銷售業務者，應即通知投信事業，並由投信事業自事實發生日起二日內向投信投顧公會申報並公告。期限訂得極短，是因為銷售通路的異動直接影響投資人申購、買回與定期定額扣款的管道：投資人若不知道原本的銷售機構已停止承作，可能錯過扣款或無法及時辦理買回，因此要求在兩日內同時完成對公會的申報與對外公告。

(B)錯誤。五日已使投資人有將近一週不知道自己的申購買回管道已經終止，定期定額扣款可能因此中斷；規範對通路異動採用的是更短的兩日期限。

(C)錯誤。七日是投顧契約客戶得書面終止契約的期間所用的天數，與銷售機構異動的揭露義務無關。通路資訊事關投資人能否順利交易，期限比這短得多。

(D)錯誤。十日是基金定期報告類申報的節奏，用在通路終止這種即時影響交易的事項上明顯過慢。等到十日後才公告，受影響的投資人可能已經無法扣款或辦理買回。

38. 代理境外基金在國內募集及銷售需經哪一機關核准？
