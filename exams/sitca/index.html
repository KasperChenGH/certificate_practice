1. 下列關於證券投資信託事業或證券投資顧問事業(下稱「受任人」)經營全權委託投資業務之敘述，何者正確？
  1. (A)投資經理人及其代理人之指定，應由受任人決定
  2. (B)受任人與客戶簽訂全權委託投資契約後，應自行保管受託投資資產
  3. (C)受任人應與客戶個別簽訂全權委託投資契約，除法令或金融監督管理委員會另有規定外，不得接受共同委任或信託
  4. (D)受任人與客戶簽訂全權委託投資契約前，應有五日以上之期間，供客戶審閱全部條款內容
解析

(A)錯誤。投資經理人及其代理人之指定不由受任人單方決定，而應由客戶與受任人共同議定。客戶既然交出投資決定權，至少應能知悉並同意是誰為其操作，否則受任人可隨時更換人員而客戶毫無所知。

(B)錯誤。受任人不得自行保管委託投資資產，應由客戶另與全權委託保管機構簽約保管。決策權與保管權分離是全權委託的核心防線，否則受任人可同時決定買賣並動用資產，挪用時無人可擋。

(C)正確。依全權委託投資業務管理辦法，受任人應與客戶個別簽訂全權委託投資契約，除法令或金管會另有規定外，不得接受共同委任或信託。個別簽約才能依各客戶的資力、投資經驗與目的分別議定投資方針與範圍，並使每一客戶的資產、損益與權責清楚可分；若接受多人共同委任，實質上就成了未經核准的集合式基金，規避了基金募集應有的核准與資訊揭露程序。

(D)錯誤。簽約前的審閱期間應為七日以上，五日不足。審閱期是不得少於的下限，把七日寫成五日等於削減客戶在簽約前理解投資範圍、費用與風險的法定時間。

2. 下列何者可為投信事業之發起人？ 甲.受破產之宣告，已復權者；乙.使用票據經拒絕往來尚未期滿者；丙.無行為能力或限制行為能力者
  1. (A)僅甲
  2. (B)僅乙
  3. (C)甲、丙
  4. (D)甲、乙、丙皆不可
解析

(A)正確。僅甲可為投信事業之發起人。受破產宣告者本有資格障礙，但已復權表示破產程序已終結、法律上的權利限制解除，資格障礙隨之消滅，自得擔任發起人。乙（票據拒絕往來尚未期滿）與丙（無行為能力或限制行為能力）則仍在障礙存續中：一是票信瑕疵未消，一是欠缺完全的意思能力，都還不能承擔設立投信事業所需的責任。

(B)錯誤。使用票據經拒絕往來且尚未期滿者，信用瑕疵仍在存續期間內，代表其票信紀錄尚未回復，不得擔任發起人；須待拒絕往來期間屆滿，該項障礙才消滅。本項同時漏掉了已復權的甲本可擔任。

(C)錯誤。甲可以，但丙不可以。無行為能力或限制行為能力者無法獨立為完全有效的意思表示，而發起設立公司涉及認股、簽署章程與承擔設立責任，性質上不容由欠缺行為能力者擔任。

(D)錯誤。並非皆不可。甲的關鍵字是已復權——資格條件所限制的是障礙仍存續的人，一旦復權，破產帶來的限制即不再適用；若連已復權者都永久排除，等於把資格限制變成終身失格。

1. 投信事業申請（報）募集投信基金經核准後，未能於核准申請通知函送達後一定期限內開始募集，應如何處理？
  1. (A)向主管機關申請延展六個月
  2. (B)申請中斷時效
  3. (C)呈報公會延展六個月
  4. (D)向主管機關申請延展三個月
解析

(A)正確。基金申請核准或申報生效後，事業應於通知函送達日起所定期間內開始募集；未能如期開始者，應於期限屆滿前向金管會申請延展，延展期間為六個月並以一次為限。設期限的理由是核准所依據的基金架構、費用與市場條件都會過時，久未募集的核准若無限期存在，等於讓業者囤著一張隨時可用的額度。

(B)錯誤。法規並無申請中斷時效這種程序。時效中斷是民法上請求權的概念，與行政核准效力的存續無關；募集期限屆至只能以事前申請延展處理，逾期則核准失其效力。

(C)錯誤。基金募集的核准與延展都屬金管會的權限，同業公會擔任的是自律、彙送與備查的角色。向公會呈報並不能延長金管會核准的效力，公會也無權替主管機關決定延展。

(D)錯誤。三個月是取得全權委託投資業務許可後應申請換發營業執照的期間（經營全權委託投資業務管理辦法第7條），與基金募集的延展無關；募集未能開始時得申請的延展期間為六個月。

2. 投顧事業未能依規定之期間內申請核發營業執照者，且未依時限申請展期，金管會得為如何之處理？
  1. (A)通知其補正
  2. (B)通知其展期
  3. (C)駁回申請案
  4. (D)廢止其許可
解析

(A)錯誤。通知補正處理的是書件不全或記載瑕疵的申請案；期限已過而根本未提出申請時，並無可補正的對象，時間經過本身也不是補件所能回復的瑕疵。

(B)錯誤。展延必須由業者在期限屆滿前敘明正當理由主動申請，並以一次為限；主管機關不會主動通知業者展期，否則原訂期限將形同虛設。

(C)錯誤。駁回的前提是有繫屬中的申請案。逾期未申請執照又未申請展延時，主管機關要處理的是先前那張許可的效力，而非某一件待審的申請。

(D)正確。依設置標準，取得許可後應於所定期間內申請核發營業執照，有正當理由者得於期限屆滿前申請展延；逾期未申請又未依時限申請展延者，金管會得廢止其許可。許可附有時效，是為了避免業者取得資格後長期不開業，留下一張隨時可轉手的空殼許可，也讓主管機關能收回未使用的核准資源。

3. 下列何者非證券投信投顧公會廣告及營業活動行為規範之適用對象？
  1. (A)投信事業
  2. (B)投顧事業
  3. (C)基金銷售機構
  4. (D)證券自營商
解析

(A)錯誤。投信事業為該行為規範之當然適用對象。

(B)錯誤。投顧事業為該行為規範之當然適用對象。

(C)錯誤。基金銷售機構直接面對投資人進行招攬，亦為適用對象。

(D)正確（即非屬適用對象者）。該規範為投信投顧公會之自律規範，適用於其會員及其銷售機構；證券自營商從事自行買賣，不屬該公會廣告及營業促銷活動規範之對象。

4. 金管會對國內初次募集發行之股票型基金申報生效案件，於金管會收到申報書即日起屆滿幾個營業日生效？
  1. (A)12
  2. (B)15
  3. (C)20
  4. (D)30
解析

(A)正確。國內初次募集發行之股票型基金採申報生效制，自金管會收到申報書即日起屆滿十二個營業日生效。申報生效制的特點是期間屆滿即自動生效，不必等逐案核准；股票型基金的投資標的與操作方式已高度標準化，審查重點在書件是否完備與是否符合既定規範，故以較短的法定期間取代實質審查，兼顧發行效率與監理。

(B)錯誤。十五個營業日常被誤認成半個月，但申報生效期間是以營業日計算而非日曆日的半月，股票型基金初次募集適用的期間比這短。

(C)錯誤。二十個營業日已接近一個完整月份的交易日數。若標準化程度最高的股票型基金都要等這麼久，申報生效制相較核准制的效率優勢便不存在。

(D)錯誤。三十個營業日約一個半月，募集計畫與當時的市場環境早已脫節。申報生效制的設計就是以屆滿一定營業日自動生效取代個案審查，期間不會拉到這種長度。

5. 下列對於投信事業有關廣告的規定，何者為非？
  1. (A)公司所有廣告內容只須得主管機關核可後，便可對外發出，無須確保所有廣告符合法令及同業公會相關規定
  2. (B)公司應確保任何關於基金表現及全權委託帳戶表現之敘述屬實
  3. (C)公司為拓展業務所製作之廣告應注意是否符合公平交易法、證券交易法及其他相關法規之規定
  4. (D)公司員工為廣告及其他營業促銷活動，應遵守的法規包括證券交易法、投信投顧事業管理規則、基金管理辦法，主管機關或自律組織依法發布之規定
解析

(A)正確（即敘述有誤者）。廣告合法性的責任在事業自身，必須自行確保內容符合法令及公會規範並經內部審核，不因取得主管機關核可即免除該義務。

(B)錯誤。確保基金與全權委託帳戶績效敘述屬實，是廣告的基本要求，敘述正確。

(C)錯誤。廣告仍須遵守公平交易法、證券交易法等相關法規，敘述正確。

(D)錯誤。員工從事廣告及促銷活動須遵守所列法令與自律規範，敘述正確。

6. 下列哪一種法律並非投顧事業以信託方式經營全權委託投資業務時所應遵守之法律？
  1. (A)信託業法
  2. (B)證券投資信託及顧問法
  3. (C)信託法
  4. (D)銀行法
解析

(A)錯誤。以信託方式經營全權委託，即屬兼營信託業務，須遵守信託業法。

(B)錯誤。全權委託投資業務本身即由證券投資信託及顧問法規範。

(C)錯誤。信託關係之成立與受託人義務由信託法規範，自應遵守。

(D)正確（即非應遵守者）。銀行法規範的是銀行之設立與業務，投顧事業並非銀行，兼營信託業務亦不因此適用銀行法。

112年第2次｜投信投顧相關法規｜第 36 題
7. 甲投信公司對所經營之乙投信基金之保管，應注意之事項，下列何者為真？
  1. (A)委由基金保管機構保管
  2. (B)甲公司之債務人得對乙基金之資產請求
  3. (C)乙資產與基金保管機構之各種基金同一帳戶保管分別設會計帳記錄
  4. (D)基金保管機構對乙之基金資產與甲之自有財產統一保管
解析

(A)正確。投信基金資產應委由基金保管機構保管。基金為獨立財產，交由與投信事業分離的保管機構持有，投資決定權與資產持有權才不會落在同一人手上。

(B)錯誤。基金資產獨立於投信事業之自有財產，投信事業之債權人不得對基金資產請求。

(C)正確。投信事業受私募股權基金相關機構委任，就其子公司擔任普通合夥人之私募股權基金及受託管理之私募股權基金進行引介時，得引介專業投資機構與高資產客戶參與投資。私募股權基金存續期長、資訊揭露有限、幾無次級市場流動性，且投資人常負有資本承諾的後續出資義務，故僅開放給具備風險辨識能力與承受損失能力的這兩類對象，而不對一般投資人招攬。

(D)錯誤。規範並非一律禁止引介，而是限定引介對象。全面禁止會使國內資金無從參與私募股權投資；規範選擇的是以對象資格控管風險，而非封閉整個管道。

20. 提供自動化投資顧問服務者，實收資本額應達新臺幣多少金額以上？
  1. (A)二千萬元
  2. (B)三千萬元
  3. (C)四千萬元
  4. (D)五千萬元
解析

(A)錯誤。二千萬元是證券投資顧問事業一般的最低實收資本額（證券投資顧問事業設置標準第五條），提供自動化投資顧問服務者須達到更高的門檻，不能僅以一般投顧的資本額標準經營此項服務。

(B)錯誤。三千萬元介於一般投顧的二千萬元門檻與自動化投資顧問服務所要求的金額之間，並非規範所定的數額。資本額門檻通常對應業務的風險等級，自動化服務的等級高於單純提供研究分析建議。

(C)錯誤。四千萬元同樣只是介於一般投顧門檻與自動化投資顧問服務要求之間的數字。演算法一旦上線，同一模型會同時對大量客戶產生建議，錯誤是規模化發生的，因此門檻訂在更高的水準。

(D)正確。提供自動化投資顧問服務者，實收資本額應達新臺幣五千萬元以上，高於一般投顧事業二千萬元的最低實收資本額。門檻提高的理由在於風險性質改變：演算法直接對眾多客戶作成投資建議並可能執行自動再平衡，業者須有足夠資本支撐系統建置、資訊安全、模型驗證與人員控管，並在模型或系統出錯導致大量客戶同時受損時具備賠償能力。
