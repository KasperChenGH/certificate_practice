1. 投顧公司經金管會許可經營全權委託業務後，應如何續行業務申請程序？
  1. (A)於三個月內申請換發營業執照
  2. (B)檢附公司章程
  3. (C)備齊書件直接函送金管會核發營業執照
  4. (D)選項(A)(B)(C)皆是
解析

(A)正確。經許可經營全權委託投資業務後，應於三個月內向主管機關申請換發營業執照。許可只是資格取得，須在期限內完成執照換發程序，業務範圍的變更才會反映在執照上並得以實際開辦。

(B)錯誤。公司章程僅係申請時應檢附之書件之一，並非本題所問之續行程序本身。

(C)錯誤。應依規定期限申請換發營業執照，而非備齊書件逕行函送核發。

(D)錯誤。僅（A）為正確之續行程序，其餘敘述不符規定。

2. 投顧事業未能依規定之期間內申請核發營業執照者，且未依時限申請展期，金管會得為如何之處理？
  1. (A)通知其補正
  2. (B)通知其展期
  3. (C)駁回申請案
  4. (D)廢止其許可
解析

(A)錯誤。逾期未申請亦未展期，並非以補正處理。

(B)錯誤。展期須由業者於期限內主動申請，主管機關不會逕行通知展期。

(C)錯誤。此時並無待審之申請案可資駁回。

(D)正確。未於規定期間內申請核發營業執照，又未依時限申請展期者，金管會得廢止其許可。許可具有時效，逾期不作為即視同無經營意願，避免許可長期閒置形成殼資格。

4. 有關全權委託投資業務，下列何者為正確？
  1. (A)每一全權委託投資帳戶之全權委託保管機構以一家為限
  2. (B)全權委託投資買賣契約簽約完成，受任人即可運用委託投資資產從事有價證券當日沖銷交易
  3. (C)客戶不得於全權委託投資契約存續期間變更全權委託保管機構
  4. (D)受任人於全權委託投資契約存續期間，應與客戶每二年至少進行一次訪談，以修正或補充客戶資料
解析

(A)正確。每一全權委託投資帳戶之保管機構以一家為限。單一帳戶對應單一保管機構，資產部位與交割才有唯一可勾稽的紀錄，分散保管會使監督與對帳失效。

(B)錯誤。運用委託投資資產從事當日沖銷交易，須與客戶另行約定，非簽約完成即當然可為。

(C)錯誤。客戶得於契約存續期間以書面通知變更全權委託保管機構。

(D)錯誤。二年並非規範所定之訪談頻率，客戶資料應以更高頻率檢視更新。

5. 下列對於投信事業有關廣告的規定，何者為非？
  1. (A)公司所有廣告內容只須得主管機關核可後，便可對外發出，無須確保所有廣告符合法令及同業公會相關規定
  2. (B)公司應確保任何關於基金表現及全權委託帳戶表現之敘述屬實
  3. (C)公司為拓展業務所製作之廣告應注意是否符合公平交易法、證券交易法及其他相關法規之規定
  4. (D)公司員工為廣告及其他營業促銷活動，應遵守的法規包括證券交易法、投信投顧事業管理規則、基金管理辦法，主管機關或自律組織依法發布之規定
解析

(A)正確（即敘述有誤者）。廣告合法性的責任在事業自身，必須自行確保內容符合法令及公會規範並經內部審核，不因取得主管機關核可即免除該義務。

(B)錯誤。確保基金與全權委託帳戶績效敘述屬實，是廣告的基本要求，敘述正確。

(C)錯誤。廣告仍須遵守公平交易法、證券交易法等相關法規，敘述正確。

(D)錯誤。員工從事廣告及促銷活動須遵守所列法令與自律規範，敘述正確。

112年第2次｜投信投顧相關法規｜第 21 題
6. 下列哪一種法律並非投顧事業以信託方式經營全權委託投資業務時所應遵守之法律？
  1. (A)信託業法
  2. (B)證券投資信託及顧問法
  3. (C)信託法
  4. (D)銀行法
解析

(A)錯誤。以信託方式經營全權委託，即屬兼營信託業務，須遵守信託業法。

(B)錯誤。全權委託投資業務本身即由證券投資信託及顧問法規範。

(C)錯誤。信託關係之成立與受託人義務由信託法規範，自應遵守。

(D)正確（即非應遵守者）。銀行法規範的是銀行之設立與業務，投顧事業並非銀行，兼營信託業務亦不因此適用銀行法。

112年第2次｜投信投顧相關法規｜第 36 題
7. Y 投信公司發生對投資人權益有重大影響事項，依法應如何處理？
  1. (A)於事實發生之日起二日內申報
  2. (B)於事實發生後三日內公告
  3. (C)於事實發生後三日內抄送主管機關
  4. (D)於事實發生之日起二日內公告並向金管會申報
解析

(A)錯誤。僅申報而未公告，未使投資人得以知悉，不符規定。

(B)錯誤。僅公告而未向主管機關申報，且日數亦不符規定。

(C)錯誤。抄送並非法定方式，且日數不符規定。

(D)正確。對投資人權益有重大影響之事項，應於事實發生之日起二日內公告並向金管會申報。公告使投資人知悉、申報使主管機關得以監督，兩者缺一不可。

9. 有關證券投資顧問事業之人員配置，下列敘述何者有誤？
  1. (A)總經理、部門主管，除法令另有規定外，應為專任
  2. (B)分支機構之經理人及業務人員得為兼任
  3. (C)投顧業務人員得提供證券投資推介建議
  4. (D)投顧業務人員經核准得辦理全權委託投資業務
解析

(A)錯誤。總經理、部門主管除法令另有規定外應為專任，此敘述無誤。

(B)正確（即敘述有誤者）。分支機構之經理人及業務人員同樣應為專任，不得兼任。要求專任是為確保執行業務者的注意力與忠實義務不被其他職務稀釋，也便於責任歸屬。

(C)錯誤。投顧業務人員本即得從事證券投資推介建議，此敘述無誤。

(D)錯誤。業務人員經核准並符合資格者得辦理全權委託投資業務，此敘述無誤。

10. 下列有關投顧事業與特定投資人約定提供投資諮詢服務契約之敘述，何者正確？
  1. (A)契約自客戶收受書面契約日起生效，不得任意終止
  2. (B)應訂定書面證券投資顧問契約
  3. (C)證券投資顧問契約範本由金管會擬定
  4. (D)依民法通用契約標準範本為遵循
解析

(A)錯誤。契約生效與終止另有規範，且客戶依規定得終止契約，並非不得任意終止。

(B)正確。提供投資諮詢服務應與客戶訂定書面證券投資顧問契約。書面化可確定服務範圍、收費與雙方權責，避免事後就有無提供建議、建議內容為何發生爭議。

(C)錯誤。契約範本係由同業公會擬訂並報主管機關核定，非由金管會擬定。

(D)錯誤。並無依民法通用契約標準範本辦理之規定，應依證券投資顧問契約之規範。

114年第2次｜投信投顧相關法規｜第 48 題
11. 傘型基金以資產配置為其理念，有關傘型基金之規範下列敍述何者錯誤？
  1. (A)傘型基金係於該基金下投資不同之子基金
  2. (B)子基金依資產配置理念，選擇某一種類基金為區隔配置或交叉組合各種基金
  3. (C)子基金數得超過三檔，且應一次申請同時募集
  4. (D)子基金間不得有自動轉換機制，子基金間之轉換須由投資人申請方得辦理
解析

(A)錯誤。本項敘述正確：傘型基金係於該基金架構下投資不同之子基金。

(B)錯誤。本項敘述正確：子基金依資產配置理念選擇某一種類基金為區隔配置或交叉組合。

(C)正確（即錯誤敘述者）。子基金數有其上限而非「得超過三檔」。傘型基金的設計是讓投資人在有限的幾檔子基金間配置，子基金過多會使架構失去區隔配置的意義並增加管理複雜度。

(D)錯誤。本項敘述正確：子基金間不得有自動轉換機制，轉換須由投資人申請。

114年第3次｜投信投顧相關法規｜第 17 題
12. 下列有關投信事業對於基金資產運用之指示權之敘述何者正確？
  1. (A)得複委任他人代行
  2. (B)原則上不得複委任他人處理
  3. (C)不需盤點檢查保管機構所保管的基金資產
  4. (D)投信事業不得指示基金保管機構處分資產
解析

(A)錯誤。指示權具高度屬人性，不得任意複委任他人代行。

(B)正確。投信事業對基金資產之運用指示權，原則上不得複委任他人處理。受益人是基於對該投信事業專業能力的信賴而投資，若可任意轉手他人操作，信賴基礎即不復存在。

(C)錯誤。投信事業仍應盤點檢查保管機構所保管之基金資產，這是其對受益人的監督義務。

(D)錯誤。投信事業本即得指示基金保管機構處分資產，此正是運用指示權的內容。

114年第3次｜投信投顧相關法規｜第 41 題
14. 境外基金之募集及銷售不成立時，總代理人應依境外基金管理辦法規定，將款項退款至以下何者帳戶？
  1. (A)投資人指定之銀行帳戶
  2. (B)總代理人
  3. (C)銷售機構
  4. (D)選項(A)(B)(C)皆可
解析

(A)正確。境外基金募集及銷售不成立時，總代理人應將款項退還至投資人指定之銀行帳戶。款項須直接回到投資人手中，不得停留在中介機構，以避免挪用風險。

(B)錯誤。退款不得退至總代理人帳戶，否則資金仍在中介機構手中，失去退款的保障意義。

(C)錯誤。退款不得退至銷售機構帳戶，理由同上。

(D)錯誤。三者並非皆可，僅得退至投資人指定之銀行帳戶。

15. 關於證券投資信託事業就氣候相關財務資訊之揭露，以下敘述何者正確？

16. 下列證券投顧事業人員之行為，何者符合規定？

  2. (B)同意他人靠行使用該投顧事業之名義執行業務
  3. (C)與客戶為投資有價證券收益共享或損失分擔之約定

19. 有關境外基金總代理提存之營業保證金，下列何者敘述錯誤？
  1. (A)應以現金、銀行存款、政府債券或金融債券提存
  2. (B)不得設定質權或以任何方式提供擔保
  3. (C)應分散提存於不同金融機構
  4. (D)提存金融機構之更換或營業保證金之提取，應經投信投顧公會轉報金管會核准後始得為之
解析

(A)錯誤。以現金、銀行存款、政府債券或金融債券提存，符合規範，敘述無誤。

(B)錯誤。營業保證金不得設定質權或以任何方式提供擔保，敘述無誤。

(C)正確（即敘述有誤者）。營業保證金不得分散提存於不同金融機構。集中提存才能在需要動用時迅速、完整地清償，分散反而增加執行成本與時間。

(D)錯誤。提存機構之更換或保證金之提取須經公會轉報金管會核准，敘述無誤。

20. 依據會員及其銷售機構從事廣告及營業活動行為規範對於基金廣告之規定，以下敘述何者正確？
  1. (A)廣告中得以獲利為廣告，只要有事實或理論根據，不須同時報導其風險
  2. (B)未經金管會核准募集之基金可先行從事廣告活動測試市場
  3. (C)平面廣告應揭示警語，有聲廣告應以影像或聲音揭示警語
  4. (D)單純登載投資管理專門知識或服務等標榜企業形象而不涉及產品之廣告亦應標示警語
解析

(A)錯誤。以獲利為廣告內容者，應同時報導其風險，不得僅呈現有利之一面。

(B)錯誤。基金須經核准或申報生效後始得從事廣告及銷售活動，不得先行廣告測試市場。

(C)正確。警語須以受眾實際接收得到的形式呈現，故平面廣告以文字揭示，有聲廣告則須以影像或聲音揭示，避免以形式上有揭示但實際看不到、聽不到之方式規避。

(D)錯誤。單純標榜企業形象、登載專門知識或服務而不涉及個別產品之廣告，不以標示警語為必要。
